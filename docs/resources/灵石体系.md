## 一、灵石的物理化学性质

### 什么是灵石

灵石是天地灵气在特定地质条件下，经过漫长岁月在岩石中结晶而成的能量矿石。其本质是**灵气在矿物晶体中的稳态凝聚态**。

### 形成条件

| 条件 | 参数 | 说明 |
|:-----|:-----|:-----|
| 灵气浓度 | ≥ 100标准单位/m³ | 低于此浓度无法结晶 |
| 时间积累 | 数百年~数万年 | 下品需百年，上品需万年 |
| 地脉稳定性 | 持续稳定 | 地动会破坏结晶过程 |
| 载体矿质 | 硅酸盐类最佳 | 花岗岩、石英岩孕矿率最高 |

### 物理特性

| 特性 | 说明 | 写作用途 |
|:-----|:-----|:---------|
| 颜色 | 下品淡白/浅蓝 → 中品纯白 → 上品深蓝/紫 → 极品七彩 | 通过颜色判断品质是常见情节 |
| 光泽 | 下品暗淡 → 中品明亮 → 上品璀璨 | 老修士一眼可辨真假 |
| 硬度 | 莫氏7~9级（切割需灵刃） | 凡人无法破坏 |
| 灵气逸散 | 未切割时几乎不逸散，切割后加速 | 灵石切割是专门手艺 |
| 共振性 | 同属性灵石可产生共振增幅 | 可叠加用于阵法 |
| 纯度 | 下品50%~70%，中品70%~85%，上品85%~95%，极品95%+ | 纯度影响吸收效率 |

## 二、灵石开采

### 矿脉类型

| 类型 | 深度 | 产出 | 开采难度 | 危险等级 |
|:-----|:----:|:----:|:--------:|:--------:|
| 浅层矿 | 地表~百米 | 下品为主 | 低 | 低 |
| 中层矿 | 百米~千米 | 中下品混产 | 中 | 中（妖兽、坍塌） |
| 深层矿 | 千米~万米 | 上中品 | 高 | 高（地火、魔气） |
| 富矿脉 | 不限 | 高浓度产出 | 视深度而定 | 争夺激烈 |
| 仙脉 | 特殊空间 | 仙石 | 不可测 | 传说级 |

### 开采权归属

| 归属 | 占比 | 特点 |
|:-----|:----:|::-----|
| 宗门控制 | ~50% | 管理规范，产量稳定 |
| 家族控制 | ~20% | 规模小，世代传承 |
| 商会控制 | ~15% | 产量大，主要用于贸易 |
| 王朝控制 | ~10% | 规模最大，管理严格 |
| 散修共有 | ~5% | 产量不稳定，冲突高发 |

### 开采危险（写作素材）

| 危险类型 | 表现 | 可引发剧情 |
|:---------|:-----|:-----------|
| 矿脉坍塌 | 结构不稳引发塌方 | 矿难求生，意外发现深层矿藏 |
| 灵气暴动 | 灵气突然失控爆炸 | 疑有人破坏，调查真相 |
| 妖兽盘踞 | 妖兽被灵气吸引筑巢 | 矿工遭遇兽潮，主角出手 |
| 矿脉诅咒 | 矿石含上古怨念 | 采出的灵石让人走火入魔 |
| 其他势力偷袭 | 矿权争夺引发械斗 | 宗门冲突导火索 |

## 三、灵石的修炼用途

### 吸收效率

| 境界 | 适用灵石 | 日消耗量 | 日修为增益 |
|:----:|:---------|:--------:|:----------:|
| 炼气期 | 下品 | 1~10枚 | 显著 |
| 筑基期 | 下品~中品 | 10~100枚 | 中等 |
| 金丹期 | 中品~上品 | 10~100枚中品 | 较低（需配合丹药）|
| 元婴期 | 上品~极品 | 1~10枚上品 | 辅助性质 |
| 化神以上 | 极品~仙石 | 不定 | 聊胜于无，重在感悟 |

### 特殊修炼方式

- **灵石聚灵阵**：以灵石布阵，在阵中修炼可提升效率30%~100%
- **灵石淬体**：高阶体修将灵石碾碎，以灵气浸润肉身
- **灵石喂丹**：某些丹方需要将灵石粉末作为药引
- **灵石传功**：将修为封入灵石，后人可直接吸收（但会损耗七成）

## 五、灵石的分级判定法

### 肉眼鉴别法（低阶）

- 看颜色：淡白=下品，纯白=中品，深蓝=上品
- 看光泽：暗淡=下品，明亮=中品，璀璨=上品

### 灵力感应法（中阶）

- 以神识探入灵石内部，感受灵气纯度
- 纯度越高，神识反馈越清澈
- 若有杂质感或黏滞感，则为低品质或假灵石

### 天平衡量法（高阶）

- 以标准法器称量灵石释放灵气速率
- 下品：10单位/刻；中品：100单位/刻；上品：1000单位/刻
- 此法可以精确测定灵石等级，误差<1%

| 造假方式 | 原理 | 识别方法 |

| 灌灵法 | 将普通石料浸泡在灵液中，表面吸附灵气 | 放置一日后灵气消散 |
| 剥皮法 | 下品灵石表面包裹高阶灵石薄片 | 切开后露馅 |

> **写作建议**：假灵石是制造冲突的好工具——主角收到假灵石报酬，引出追查造假团伙的支线。
