# 天青地白

## 品阶
六阶（天地灵材级）。天青地白是天地交泰、阴阳调和的至宝，天然蕴含天地二气，是炼制"天人合一"类法宝的最佳材料。

## 外观
此石天生二色：上半截如雨过天青，湛然澄澈，仿佛天际之色凝固其中；下半截如白玉无瑕，温润纯净，恍若大地灵气所钟。两色之间界限分明，绝无混杂，仿若天与地的分野。

质地坚硬异常，敲之有清越金石之声，如钟磬和鸣。重量适中，不轻不重，握于掌心有一股沉稳厚重之感。以灵识探之，可感天青部分有轻灵之气上浮，地白部分有厚重之气下沉，二气循环不息，自成一个小天地。

天青部分的颜色并非一成不变——晴天呈明亮的天蓝，阴天则变为浅灰，雷雨前夕最深，几乎成墨蓝色。而地白部分始终洁白如雪，无论外界环境如何变化，其白不改。

最玄妙的是，将天青地白置于静室之中，午夜子时以灵识观察，可见天青部分有淡淡的清气上腾，地白部分有微微的浊气下沉，二气在石面上方一尺处交汇盘旋，形成一圈肉眼不可见、唯灵识可感的太极漩涡。

## 起源
上古之世，共工怒触不周山，天倾西北、地陷东南。天河水倾泻而下，大地沦为泽国。女娲娘娘取五色石以补苍天，炼石三万六千五百零一块，补天用了三万六千五百块，余下一块未用。

此石上半如青天、下半如白玉，两块截然不同的颜色在石中天然共存，阴阳调和、刚柔并济。女娲心想，若是将这块奇石也用去补天，世间便再无如此完美的天地交泰之物了。于是她将此石留在了昆仑山最高处，引天池之水浇灌、以地脉之气温养。

补天之后，女娲娘娘力竭而逝，身躯化为天地间最本源的灵气。而那块留下的奇石，在天池之底经过数万年的天地灵气浸润，渐渐繁衍出了小小的矿脉。这便是天下天青地白的始祖。

## 矿脉产地
天青地白产于天地双脉交汇之处，极为罕见。所谓天地双脉，指自九天垂落的天灵脉与自地核升腾的地灵脉在某一点相遇，二气交融、历经万年凝结而成此石。

已知产地不过三处——昆仑山天池之底、蜀山剑峰之巅的云海深处、以及东海归墟的万丈海眼之下。开采条件极为苛刻：须在特定时辰（春秋分日、昼夜等长之时）方可接近矿点，且每次开采不得超过一炷香时间，否则天地二气失衡、矿脉自毁。

## 材料特性
- **灵气传导性**：极品。天青地白对天地二气的传导近乎完美，是炼制"天人合一"类法宝的最佳材料
- **熔点**：极高。需以天地交汇之力熔炼，寻常火焰不可伤其分毫
- **坚硬度**：上品。天青部分偏刚、可承受极大冲击，地白部分偏韧、不易折断，二者结合刚柔并济
- **天地交泰**：天然蕴含"天地交泰"之力，以此材料炼制之物可引动天地灵气共鸣

## 炼器用途
炼制飞剑：天青地白炼制的飞剑兼具天之轻灵与地之厚重，刚柔并济、无坚不摧。炼制防御法宝：天地二气循环形成的护罩极为稳固。

炼制破界法器：天地二气的交融之力可破除空间壁障。炼制阵法核心：用作两仪微尘阵、天地交泰阵等大阵的阵眼。炼制渡劫法器：渡天劫时，天地交泰之力可帮助修士调和体内灵气。

**禁忌**：天青地白不可用于炼制偏阴或偏阳的法器——其阴阳调和的特性会被破坏，使法宝失去平衡。

## 炼化方法
开采天青地白须精通"天地诀"——左手掐天诀引天灵之气护住天青部分，右手掐地诀引地灵之气护住地白部分，以玉刀沿两色界限缓缓切开。若切偏一分，天地二气立时失衡，整块矿石瞬间化为齑粉。

此石贵在天成，讲究"不琢"。提纯非为去杂——天青地白天生纯净无杂——而是"养性"。将开采所得的原石置于天地灵气交汇之处温养百年，使其天地二气更为圆融。

## 著名法宝
- **天地玄黄塔**（传说中的先天至宝）—— 相传以天青地白为主材，辅以玄黄之气炼制，塔成可镇天地气运
- **青白双剑**（蜀山派失传的镇派飞剑）—— 一剑天青、一剑地白，双剑合璧可引天地之力，曾斩杀上古妖王
- **乾坤尺**（散仙乾坤道人所留）—— 以天青地白炼制，尺出可丈量天地、破开虚空

## 典故与传说
昆仑山来了一个采药的老道士，在天池边歇脚时无意间看到池底深处有一块双色奇石在闪闪发光。他挖出此石带回道观当作镇纸使用。

此后怪事连连：每逢春秋分日，道观上空会出现祥云瑞光，方圆百里灵气浓郁十倍不止。附近的修士闻讯赶来探查，方才认出这块镇纸竟是传说中的天青地白。

老道士说："此石乃女娲娘娘留给大地的礼物，放在我这里，灵气可以泽被一方水土。若被哪位大能独占，不过多一件攻击法宝罢了，岂不辜负了娘娘的慈悲？"

于是老道士将天青地白供奉于道观正殿，供天下修士前来瞻仰。后世炼器师常说，每一块天青地白里都藏着女娲娘娘补天时的一缕慈悲——所以用它炼制的法宝，永远带着一股济世为怀的正气，绝不会沦为彻底的魔器。
