# 驱邪符

> 驱邪符是驱除邪祟的符箓，可驱除一切邪祟。其外形为一张黄色符纸，上画驱邪咒文。传说驱邪符乃上古时期一位大能模仿驱邪符所创。

---

## 品阶

| 项目 | 内容 |
|------|------|
| 初始品阶 | 二阶·符箓 |
| 最高品阶 | 六阶·符箓 |
| 所属类别 | 辅助类·驱邪符箓 |
| 稀有程度 | 常见 |

## 外形描写

驱邪符外形为一张黄色符纸，上画驱邪咒文。符纸由驱邪草制成，散发着淡淡的清香。不同品阶的驱邪符大小不同——低阶仅能驱除简单邪祟，高阶还可驱除强大邪祟。

## 功能与效果

- **驱除邪祟**：可驱除一切邪祟
- **驱邪范围**：每升一品，驱邪范围翻倍
- **驱邪时间**：每升一品，驱邪时间翻倍

## 炼制方法

- **主要材料**：驱邪草、灵墨、符纸
- **炼制条件**：需筑基期以上修为，掌握基础符箓术
- **炼制时间**：低阶一日，高阶需数日

## 使用限制

- 驱邪符为一次性消耗品
- 驱邪符无法驱除品阶高于本身的邪祟
- 驱邪符对活人无效

## 著名典故

上古时期，有一位名为"驱邪子"的大能，因常年闭关修炼，无暇驱除邪祟，于是发明了驱邪符。驱邪符因其方便实用，成为修士必备之物。

## 同类对比

与**净身符**相比，驱邪符驱邪能力更强。与**辟火珠**相比，驱邪符更加便宜。
