# 传讯鹤

> 传讯鹤是传递消息的纸鹤，可飞行传讯，是修士常用的通讯工具。其外形为一只纸鹤，由传讯纸折叠而成，内刻传讯阵法。传说传讯鹤乃上古时期一位大能模仿仙鹤传信所创。

---

## 品阶

| 项目 | 内容 |
|------|------|
| 初始品阶 | 一阶·符箓 |
| 最高品阶 | 五阶·法宝 |
| 所属类别 | 辅助类·通讯符箓 |
| 稀有程度 | 常见 |

## 外形描写

传讯鹤外形为一只纸鹤，由传讯纸折叠而成。纸鹤表面有细密的纹路，是传讯阵法的外在表现。不同品阶的传讯鹤大小不同——低阶仅手掌大小，高阶可达翼展三尺。

## 功能与效果

- **传递消息**：可将消息传递给指定修士，最远可达百里
- **飞行速度**：低阶约百里/时辰，高阶可达千里/时辰
- **持续时间**：低阶约一个时辰，高阶可达一日

## 炼制方法

- **主要材料**：传讯纸、灵墨、传讯砂
- **炼制条件**：需筑基期以上修为，掌握基础传讯阵法
- **炼制时间**：低阶半个时辰，高阶需数个时辰

## 使用限制

- 传讯鹤为一次性消耗品
- 传讯鹤可能被拦截或击落
- 传讯鹤无法传递图像或声音

## 著名典故

上古时期，有一位名为"传讯子"的大能，因常年闭关修炼，无暇外出传递消息，于是发明了传讯鹤。传讯鹤因其方便实用，成为修士必备之物。

## 同类对比

与**传讯符**相比，传讯鹤传递距离更远。与**传讯玉佩**相比，传讯鹤更加便宜。
