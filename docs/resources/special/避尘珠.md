# 避尘珠

> 避尘珠是避尘的宝珠，可避开灰尘，保持佩戴者清洁。其外形为一颗白色宝珠，由避尘石炼制而成，内刻避尘阵法。传说避尘珠乃上古时期一位大能模仿避尘珠所创。

## 外形描写

避尘珠外形为一颗白色宝珠，由避尘石或其他避尘属性材料制成。珠面有细密的纹路，是避尘阵法的外在表现。珠可发出避尘之光，避开灰尘。

## 功能与效果

- **避开灰尘**：可避开灰尘，保持佩戴者清洁
- **避尘范围**：每升一品，避尘范围翻倍
- **避尘时间**：每升一品，避尘时间翻倍

## 炼制方法

- **主要材料**：避尘石、避尘玉、避尘砂
- **炼制条件**：需筑基期以上修为，掌握避尘阵法
- **炼制时间**：低阶七日，高阶需数月

## 使用限制

- 避尘珠需以灵力为燃料
- 避尘珠无法避开品阶高于本身的灰尘
- 避尘珠对液体无效

## 著名典故

上古时期，有一位名为"避尘子"的大能，在昆仑山发现了一颗避尘珠。他将其带出，用以避开灰尘，保持佩戴者清洁。

## 同类对比

与**净身符**相比，避尘珠更加持久。与**辟火珠**相比，避尘珠更加便宜。
