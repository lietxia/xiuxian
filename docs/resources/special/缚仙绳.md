# 缚仙绳

> 缚仙绳是束缚仙人的绳索，可自动缠绕仙人，使其无法动弹。其外形为一条绳索，由仙藤炼制而成，内刻缚仙阵法。传说缚仙绳乃上古时期一位大能模仿缚仙绳所创。

---

## 品阶

| 项目 | 内容 |
|------|------|
| 初始品阶 | 七阶·仙器 |
| 最高品阶 | 九阶·仙器 |
| 所属类别 | 辅助类·束缚法器 |
| 稀有程度 | 传说级 |

## 外形描写

缚仙绳外形为一条绳索，由仙藤或其他仙属性材料制成。绳索表面有细密的纹路，是缚仙阵法的外在表现。绳索可长可短，最长可达千丈。

## 功能与效果

- **束缚仙人**：可自动缠绕仙人，使其无法动弹
- **束缚时间**：每升一品，束缚时间翻倍
- **束缚数量**：低阶仅能束缚一人，高阶可束缚多人

## 炼制方法

- **主要材料**：仙藤、缚仙石、仙血
- **炼制条件**：需大乘期以上修为，掌握缚仙阵法
- **炼制时间**：低阶数年，高阶需数十年

## 使用限制

- 缚仙绳对非仙人效果大减
- 缚仙绳无法束缚品阶高于本身的仙人
- 缚仙绳惧怕仙火，被灼烧后会失去效力

## 著名典故

上古时期，有一位名为"缚仙子"的大能，在昆仑山发现了一条缚仙绳。他将其带出，用以束缚仙人，保护一方平安。

## 同类对比

与**困兽索**相比，缚仙绳对仙人效果更好。与**天罗地网**相比，缚仙绳更加便携。
