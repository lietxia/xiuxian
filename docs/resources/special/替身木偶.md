# 替身木偶

**品阶：** 四品（替死类·消耗品）

---

## 来源/诞生

上古傀儡宗秘传之术，后流入散修之手。取百年槐木心为骨，以精血为引，刻七道替死符文于腔内，再置于阴煞之地祭炼七七四十九日方成。

亦有传闻，极北雪原深处有一种"泣血树"，其木天生带一丝灵性，砍伐时树干会渗出红色汁液，以之雕刻人偶，成功率远超寻常槐木。因此每一尊真正的替身木偶，背后都有一棵泣血树的性命。

制作之法代代单传，至今已近失传。市面上偶尔出现的替身木偶，多半是仿制品——只能挡三成威力的攻击，真货可遇不可求。

至于傀儡宗的起源，可追溯至上古时期一位名为**公输机**的散修。此人本是一名凡间木匠，因机缘踏入修行路后，始终忘不了木工手艺。他将凡间机关术与修仙禁制结合，开创了傀儡一脉。而替身木偶，据说是他晚年目睹道侣渡劫失败后，痛不欲生之际所创——"若有一物能替人挡劫，世间便少一些遗憾。"公输机最终是否成功用此物救过谁，已不可考，但其悲愿确实成就了一件奇物。

## 外观描述

一掌高的木制小人，五官模糊，无男女相。通体深褐色，触手温润如玉，绝非木质应有的温度。胸口处刻有一枚指甲盖大小的血色符文，隐隐泛光。

将自身一滴精血滴入木偶眉心，木偶脸上便会慢慢浮现出主人的面容轮廓，虽不清晰，但熟识之人一眼能认。血契完成之后，木偶的重量会略微增加，仿佛多了一缕魂魄寄居其中。更奇者，每逢月圆之夜，木偶表面会浮现出一层极淡的银色光晕，如同呼吸般明灭不定。老辈修士说，那是替死符文在与主人的命数进行最后校准。

若将木偶放在耳边轻轻摇晃，能听到里面有极细碎的声响，如同枯叶摩擦——据说是槐木中封存的那一缕灵性在做梦。

## 特殊能力

佩戴在身，当主人遭受**致命一击**的瞬间，替身木偶会自动碎裂，以自身承受全部伤害，同时将主人传送至百丈外的随机安全位置。

碎裂时发出一声极轻的闷响，如同有人在你耳边叹了口气。

此物不辨攻击类型——刀剑、法术、毒咒、禁制，无一不可替。曾有记载，一位化神期修士自爆元婴，其弟子凭一枚替身木偶硬生生扛了下来，只是木偶碎裂后化为齑粉，连渣都没剩。

值得注意的是，替身效果并非无差别覆盖一切伤害。若受到的是持续性的伤害（如业火焚身、剧毒蔓延），木偶只替承受触发瞬间的那一次致命冲击，后续的持续伤害仍需主人自行应对。此外，某些涉及因果律的攻击——比如咒杀之术中以命换命的"同归术"——木偶能否完全替代，至今仍有争议。曾有案例显示，木偶碎了，咒师也死了，但受术者仍然元气大伤，似乎因果层面并未完全转移。

## 使用限制/代价

- **一次性消耗品。**碎裂即毁，无法修复。
- 同一人身上同时只能绑定一枚，多带无用。
- 只挡一次。若有人接连设下连环杀局，第一击木偶碎后，第二击便只能硬扛。
- 精血绑定后需七日方可生效，不能临阵现绑。
- 替身传送的落点随机，偶尔会出现传送到悬崖边上、妖兽巢穴中的尴尬情况。
- 有一种偏门说法：用替身木偶逃过一次死劫，此人命数中便会多出一道"暗劫"，日后会以另一种方式应劫。但此说未经证实。
- 以泣血树为材的木偶传送距离更远（可达三百丈），但泣血树千年才能成材，极为罕见。
- 仿制品不仅替死效果大打折扣，还有一定概率在关键时刻失灵——曾有修士被仇家追杀时，仿制木偶碎裂后只挡了半击，传送失效，结局惨烈。

## 著名持有者/相关传说

**散修周不疑**曾花尽毕生积蓄购得一尊替身木偶，百年后遭仇家围攻，木偶救他一命，却被随机传送到一座古传送阵上，阴差阳错送入上界秘境，反而得了大机缘。世人皆叹命数难测。

**傀儡宗遗址出土**的木偶残骸上，有人发现了一行蝇头小字："愿替君死，不问归期。"传说这是初代傀儡宗宗主刻给亡妻的——那尊木偶至今仍完好无损地躺在她棺椁旁，据说不是因为没触发过，而是因为她的面容一直还留在木偶脸上。

**北境风雪城**曾有一位筑基期的女修，倾尽家财购得一尊泣血木替身木偶，却不是为了自己——她将它绑在了身中奇毒的凡人大哥身上。旁人不解，她说："他替我挡过一刀，我替他挡一次命。"三年后大哥果然遭遇意外，木偶碎裂，他毫发无损。只是那女修从此多了一道心魔，每逢下雨天便莫名心痛。有高僧路过时点破："你的木偶替你大哥死了，但你的心意替他活着。这是善因，非恶果。"女修听后，心魔遂解。

**万宝楼拍卖会**上曾出现过一尊据传是公输机亲手雕刻的替身木偶，起拍价便是十万灵石。最终被一位蒙面人以三十七万灵石拍走。有人私下议论，那声音听起来像是一位寿元将尽的元婴老怪——或许他并非为自己而拍。

## 制作/获取方法

正宗替身木偶的制作分为五步：

1. **选材。**百年以上的槐木心为基准，泣血树最佳，阴槐木次之。木料须在至阴之日砍伐，砍伐前要以朱砂在树干上画"引灵符"三日，将周围的阴气导入木中。
2. **雕刻。**须由筑基期以上修为的傀儡师动手，以神识引导刻刀，一气呵成，不可中断。人偶的四肢比例必须与主人一致，否则替死时会出现"偏替"——本该替左胸的伤，结果替了右臂。
3. **刻符。**在木偶腔内以精金粉混合自身精血，书写七道替死符文。符文顺序不可错乱，错一道则前功尽弃。
4. **祭炼。**将木偶置于阴煞之地（古战场、乱葬岗、极阴之地皆可）四十九日，每日正午以祭炼者的灵力温养一次。期间木偶不可接触阳光，不可被人窥视。
5. **开光。**最后一夜，祭炼者需割破指尖，以血在木偶眉心点下"灵窍"，使其开启替死功能。此后木偶便可出售或赠与他人使用。

成功率：即便是熟练的傀儡师，成功率也不过三成。失败时木偶会自行裂开，其中阴气反噬，轻则伤及祭炼者经脉，重则折损寿元。这也是替身木偶价格高昂的根本原因。

市面上的仿制品，多为省去阴煞祭炼步骤、以普通灵力替代的简化版。这种木偶只能挡约三成伤害，且无传送功能，只适合低阶修士防身。

## 同类对比

**替身木偶 vs 替死符：**替死符为一次性符箓，品阶通常为三品，制作成本较低，但只能替一次法术伤害，且无传送功能。替身木偶虽贵，但无论刀剑法术还是禁制陷阱，一概可替，附带随机传送更为实用。

**替身木偶 vs 分身术：**分身术以灵力化出一个假身迷惑敌人，真身可借此逃脱。但分身术被识破后毫无作用，而替身木偶是实打实承受伤害，可靠性不可同日而语。不过分身术可多次施展，替身木偶只能用一次。

**替身木偶 vs 傀儡替身：**傀儡宗的另一种法术"傀儡替身"可以用一具战斗傀儡在战场上替主人挡住致命一击，但傀儡本身价值不菲且体型庞大，不适合随身携带。木偶小巧便携，隐蔽性强，适合散修和刺客型修士。

**搭配建议：**替身木偶与**隐匿符**或**遁地符**配合使用效果最佳——木偶替死的瞬间传送配合隐匿或遁地法术，能在敌人反应不及之时彻底消失。与**护身软甲**搭配亦可，软甲挡小伤，木偶保大命，形成双重保障。
