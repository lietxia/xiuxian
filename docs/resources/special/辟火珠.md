# 辟火珠

> 辟火珠是辟火的宝珠，可辟开火焰，保护佩戴者免受火焰伤害。其外形为一颗红色宝珠，由辟火石炼制而成，内刻辟火阵法。传说辟火珠乃上古时期一位大能模仿辟火珠所创。

## 外形描写

辟火珠外形为一颗红色宝珠，由辟火石或其他辟火属性材料制成。珠面有细密的纹路，是辟火阵法的外在表现。珠可发出辟火之光，辟开火焰。

## 功能与效果

- **辟开火焰**：可辟开火焰，保护佩戴者免受火焰伤害
- **辟火范围**：每升一品，辟火范围翻倍
- **辟火时间**：每升一品，辟火时间翻倍

## 炼制方法

- **主要材料**：辟火石、辟火玉、辟火砂
- **炼制条件**：需筑基期以上修为，掌握辟火阵法
- **炼制时间**：低阶七日，高阶需数月

## 使用限制

- 辟火珠需以灵力为燃料
- 辟火珠无法辟开品阶高于本身的火焰
- 辟火珠对水属性攻击无效

## 著名典故

上古时期，有一位名为"辟火子"的大能，在昆仑山发现了一颗辟火珠。他将其带出，用以辟开火焰，保护佩戴者免受火焰伤害。

## 同类对比

与**避水珠**相比，辟火珠辟火能力更强。与**避尘珠**相比，辟火珠更加实用。
