# 避水珠

**品阶：** 五品（辅助类·法器）

---

## 来源/诞生

避水珠并非天然形成，而是取自**深海蛟龙**或**鲛人一族**的体内内丹，经炼器师打磨后制成。其中最上品者，来自万年蛟龙的胆囊，取出的珠子自带一丝龙气，不仅能避水，还能震慑低阶水族。

鲛人一族对此物深恶痛绝——因为避水珠的原料，正是他们族中长老坐化后体内凝结的"泪丹"。鲛人一生流泪极少，死后泪丹却是上好的避水材料。人族修士常偷偷潜入鲛人墓穴盗取此物，两族因此结下深仇。

也有传闻说，极西之地的**无尘海**中有一种蚌，产的珍珠天生便有避水之能，但一甲子才产一粒，数量极为稀少。

追溯避水珠的起源，相传最早的一枚出自**上古龙族**之手。龙族天生操水，其中一位名为**敖广**的龙王，想为不能下水的陆生将士制作一件避水之宝。他取自己蜕下的逆鳞，以龙焰煅烧九日，投入深海镇压千年，最终凝成一枚通体幽蓝的宝珠，入水则水自分流。此珠后来被命名为"分水珠"，是避水珠的始祖。据说敖广之后将此珠赠予了一位人族将领，作为两族交好的信物。如今这枚分水珠的下落早已迷失在历史长河中，但所有的避水珠制作工艺，或多或少都模仿了龙族当年的思路——以水族之体魄，制御水之器具。

## 外观描述

淡蓝色圆珠，约小指指甲盖大小，通体莹润，内中似有波光流转。放在耳边，能隐约听到极轻极远的水声——有人说那是海潮，有人说是珠内封印了一缕海的记忆。

持珠者周身的雨水会不自觉地偏开滑落，仿佛有一层无形的伞。

若是蛟龙内丹所制的避水珠，珠身表面会有细密的鳞片状纹路，迎着光可见如龙鳞般的微光闪烁。而鲛人泪丹所制的避水珠，则色泽更偏幽蓝，手感更温润，如同凝固的眼泪，中心处常有一缕极细的白丝——那是鲛人离世时最后一道思念所化。无尘海蚌珠则通体浑圆如满月，无纹无痕，最受女修青睐，常被镶嵌在发簪或项链上作为装饰。

此外，避水珠在遇到不同水质时，颜色会有微妙变化：寻常河水中为淡蓝，海水中转为深蓝，遇到灵泉灵脉时会泛出青绿色，而若遇到黄泉弱水等凶水，则会骤然转为灰白色——这是危机预警，持珠者见之色变，当立即远离。

## 特殊能力

持避水珠者可在水下自由行动：

- 入水则水自分流，周身三丈之内滴水不沾
- 可于水底自由呼吸，如在陆地
- 水压于身如无物，千丈深海亦可行走自如
- 在水中移动速度不减反增，如同游鱼
- 分水开路，可在瀑布正中逆行而上
- 若以灵力催动，可在水下形成一间"气室"，容纳多人

不仅是水下行舟，暴雨天撑开避水珠，方圆三丈滴水不落，堪称最优雅的避雨之物。曾有修士戏言：带此珠走江湖，下雨天都不用打伞。

蛟龙内丹所制的上品避水珠，更有一项额外能力——**御水术增幅**。持珠者在水下施展水系法术时，法术威力可提升三到五成，且施法速度加快。因为珠中龙气会自然调动周围的水灵气，辅助施术者。这对于水系修士而言，避水珠不仅是辅助器，更是一枚隐形的修为增幅法器。

此外，避水珠还能在一定程度上感测水下的危险。当附近有强大水兽、暗流漩涡、水下禁制时，珠体会微微发热或变冷，如同预警。经验丰富的水下探险者能通过珠子的温度变化判断危险的种类和距离：骤热为妖兽，骤冷为禁制，持续微振为暗流。

## 使用限制/代价

- 避水珠只避凡水、灵水。某些特殊水质（如九天玄水、黄泉弱水）无法隔绝。
- 遇到精通水系法术的大能，对方可以强行控制水分开之域，将持珠者反困于气泡之中。
- 长时间在水下使用，消耗灵力颇为可观。若灵力不济，避水范围会逐渐缩小，最终失效。
- 避水珠的抵抗水压能力有上限。据说在万丈海沟深处，有修士的避水珠当众碎裂，那人瞬间被水压碾成了肉饼。
- 鲛人一族视持避水珠之人为仇敌，若在海中相遇，不死不休。
- 蛟龙内丹所制的避水珠若被蛟龙一族感知到，也会引来麻烦——龙族虽未像鲛人那般仇恨，但自家后辈的内丹被人做成珠子佩戴，终究不是愉快的事。曾有修士在东海深处被一条巡海夜叉拦住去路，对方盯着他胸前的避水珠看了半晌，冷冷地说了一句"那是我的族叔"，然后转身离去。那修士当天便连夜逃离了东海。
- 避水珠使用后会自然沾染水气，若不定期以灵力烘干，珠面会生长出极细的水藻。水藻虽无害，但会影响美观，且会逐渐削弱避水效果。保养方法是每三个月将珠子置于烈日下暴晒一日，或用真火略微烘烤。

## 著名持有者/相关传说

**东海龙宫**曾悬赏百万灵石，征集盗取避水珠的贼人。事情的起因是一位人族散修潜入龙宫宝库，偷走了一枚千年蛟珠炼制的避水珠，还顺走了龙太子的一壶酒。龙宫震怒，但那散修靠那枚避水珠潜入深海裂隙，找到了一株万年血珊瑚，炼化后修为大进，从此再不惧龙宫追杀。

**渡厄僧**曾持一枚避水珠踏海而行，从东海岸边一直走到了西海尽头。有人问他为何不御剑飞行，他说："走路比飞踏实，海比地诚实。"

**鲛人族的复仇**也是一段令人唏嘘的往事。一百二十年前，一个名为"海枭"的散修团伙专以盗取鲛人泪丹为生，十年间盗掘了鲛人七座古墓，得泪丹十二枚，炼制了十二枚避水珠。鲛人王震怒，发动全族追杀。海枭团伙一路逃窜，最终被围困在南海一座孤岛上。鲛人战士围岛三月，海枭团伙弹尽粮绝，十二人中有十一人选择捏碎避水珠跳海决战——却忘了鲛人在水中才是真正的主宰。最终仅一人生还，那人保住了手中的避水珠，却从此不再下海，将其挂在自家堂前作为警示。"避水珠能避水，避不了鲛人的怒火。"这是他晚年常说的一句话。

**北冥冰海**的传说则更为玄妙。据说北冥冰海深处有一处"水眼"，是天下万水的源头，周围的水流急如刀割，连蛟龙都不敢靠近。但若持有一枚无尘海蚌珠所制的避水珠，便可安然接近水眼。曾有探险者在水眼旁发现了一座上古祭坛，上面刻着："分水于此，天地始分。"——竟像是比龙族始祖分水珠更早的遗迹。当然，去的人都没能带回任何实物证据，因为接近水眼之后，连避水珠也扛不住那里的压力，只能远远看上一眼便仓促撤回。

## 制作/获取方法

避水珠的原料来源有三种，制作工艺也因此不同：

**蛟龙内丹法：**
1. 取得蛟龙内丹（需要猎杀或机缘获得已故蛟龙的遗丹）。蛟龙至少需三千年道行，内丹方有足够的避水之性。
2. 由炼器师以真火将内丹中驳杂的妖力剔除，只保留纯粹的"控水"本源。此过程需七七四十九日。
3. 以"定水诀"将控水本源封印于丹内，使其由内向外持续释放斥水之力。
4. 最后以灵泉水淬火七日，使其稳定成型。

**鲛人泪丹法：**
1. 获取鲛人泪丹（通常来自鲛人长老去世后的遗体，或鲛人悲极而泣时滴落的泪水凝固而成）。后一种极其罕见，因为鲛人一生落泪不过三五次。
2. 泪丹本身已带天然避水属性，只需稍加打磨，嵌入"分水阵"禁制即可。
3. 因鲛人泪丹的避水之力来自情感（悲伤或执念），制成的避水珠效果往往比蛟龙内丹法更为柔和稳定，且额外带一丝安抚水兽的功效。
4. 此法无需真火淬炼，但需由精通水属性的修士以水灵力温养十日，使其"活"过来。

**无尘海蚌珠法：**
1. 前往极西无尘海，寻找栖息在海底灵泉口附近的"月华蚌"。此蚌每甲子才产一粒珍珠。
2. 等待月华蚌自然开口吐珠（不可强行撬开，否则珠失其灵）。
3. 珍珠本身避水效果较弱（仅能避方圆三尺），但胜在纯净无副作用，且制作时只需稍加打磨即可，无需复杂炼制。

市价参考：鲛人泪丹避水珠约两万灵石起，蛟龙避水珠五万灵石起，无尘海蚌珠因产量极低，往往有价无市，曾被拍到八万灵石一枚。而带有龙气的万年蛟珠避水珠，从未低于十五万灵石。

## 同类对比

**避水珠 vs 分水符：**分水符是消耗性符箓，五品，贴于身上可使水流分开约一炷香的时间。优点是便宜（数十灵石一张），缺点是持续时间短且只能一人使用。避水珠虽贵，但可永久使用，且可惠及周围多人。

**避水珠 vs 避水诀：**避水诀为水系基础法术，筑基期修士便可掌握。优点是无需外物，但水下行动速度受到限制，且持续施法消耗灵力，无法用于长时间深海探索。避水珠则解放了双手和灵力，让修士在水下也能全力施为。

**避水珠 vs 水遁术：**水遁术是水系高阶遁法，可瞬间在水中移动百里，是逃命和突袭的绝技。但水遁术无法让修士在水下长时间停留，只是一种移动手段。二者功能互补——水遁赶路，避水珠探索。

**搭配建议：**避水珠与**水系攻击法宝**搭配，在水下战力倍增。与**储物袋中的防水符**配合，可确保物资不受潮。若要与鲛人一族打交道，切记不要佩戴避水珠，否则谈判尚未开始便已结仇。对于猎杀水兽的修士，避水珠配合**擒龙网**是一套经典组合——珠开道，网收妖，效率极高。
