# 储物袋

> 储物袋是最基础的储物法器，以虚空兽皮制成，内含独立空间。其外形为一个布袋，由虚空兽的皮炼制而成，内刻简易空间阵法。传说储物袋乃上古时期修士模仿虚空兽的天赋神通所创。

## 外形描写

储物袋外形为一个布袋，由虚空兽皮或其他空间属性材料制成。袋子表面有细密的纹路，是空间阵法的外在表现。不同品阶的储物袋大小不同——低阶仅能存放几立方米物品，高阶可达数十立方米。

## 功能与效果

- **储物**：可存放物品，内部时间静止，食物不会腐坏，活物无法进入
- **空间大小**：一品约一立方米，每升一品空间翻倍，五阶可达16立方米
- **重量减轻**：储物袋内的物品重量不计入佩戴者负担

## 炼制方法

- **主要材料**：虚空兽皮、空间灵木、纳物砂
- **炼制条件**：需筑基期以上修为，掌握基础空间阵法
- **炼制时间**：低阶三日，高阶需数月

## 使用限制

- 无法存放活物
- 无法存放品阶高于储物袋本身的法器
- 空间崩溃时内部物品会散落在虚空中
- 储物袋易被利刃划破，导致空间崩溃

## 著名典故

上古时期，修士们发现虚空兽的皮具有储物功能，于是开始模仿其天赋神通炼制储物袋。储物袋因其制作简单、成本低廉，成为低阶修士最常用的储物法器。

## 同类对比

与**空间戒指**相比，储物袋空间较小且更易损坏。与**储物腰带**相比，储物袋更轻便但容量较小。
