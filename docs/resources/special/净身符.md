# 净身符

> 净身符是清洁身体的符箓，激活后可自动清洁全身。其外形为一张黄色符纸，上画净身咒文。传说净身符乃上古时期一位洁癖大能所创，以清净草为墨，画下净身咒文。

---

| 项目 | 内容 |
|------|------|
| 初始品阶 | 一阶·符箓 |
| 最高品阶 | 三阶·符箓 |
| 所属类别 | 辅助类·清洁符箓 |
| 稀有程度 | 常见 |

## 外形描写

净身符外形为一张黄色符纸，上画净身咒文。符纸由清净草制成，散发着淡淡的清香。不同品阶的净身符大小不同——低阶仅能清洁身体，高阶还可清洁衣物。

## 功能与效果

- **清洁身体**：激活后可自动清洁全身，去除污垢和异味
- **清洁衣物**：高阶净身符还可清洁衣物，去除污渍
- **持续时间**：低阶约一炷香，高阶可达一个时辰

## 炼制方法

- **主要材料**：清净草、灵墨、符纸
- **炼制条件**：需筑基期以上修为，掌握基础符箓术
- **炼制时间**：低阶一日，高阶需数日

## 使用限制

- 净身符为一次性消耗品
- 净身符无法清洁法器
- 净身符对剧毒无效

## 著名典故

上古时期，有一位名为"净身真人"的大能，因常年闭关修炼，无暇清洁身体，于是发明了净身符。净身符因其方便实用，成为修士必备之物。

## 同类对比

与**净水瓶**相比，净身符更加便携。与**辟尘珠**相比，净身符清洁效果更好。
