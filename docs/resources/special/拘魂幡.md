# 拘魂幡

> 拘魂幡是拘束魂魄的幡旗，可拘束敌人魂魄，使其无法逃脱。其外形为一面幡旗，由拘魂石炼制而成，内刻拘魂阵法。传说拘魂幡乃上古时期一位大能模仿拘魂幡所创。

## 外形描写

拘魂幡外形为一面幡旗，由拘魂石或其他拘魂属性材料制成。幡面有细密的纹路，是拘魂阵法的外在表现。幡可发出拘魂之光，拘束敌人魂魄。

## 功能与效果

- **拘束魂魄**：可拘束敌人魂魄，使其无法逃脱
- **拘魂范围**：每升一品，拘魂范围翻倍
- **拘魂数量**：低阶仅能拘束一人，高阶可拘束多人

## 炼制方法

- **主要材料**：拘魂石、拘魂铜、拘魂砂
- **炼制条件**：需元婴期以上修为，掌握拘魂阵法
- **炼制时间**：低阶数月，高阶需数年

## 使用限制

- 拘魂幡需以魂力为燃料
- 拘魂幡无法拘束品阶高于本身的敌人
- 拘魂幡对活人效果大减

## 著名典故

上古时期，有一位名为"拘魂子"的大能，在昆仑山发现了一面拘魂幡。他将其带出，用以拘束敌人魂魄，使其无法逃脱。

## 同类对比

与**锁魂链**相比，拘魂幡拘束能力更强。与**摄魂铃**相比，拘魂幡更加实用。
