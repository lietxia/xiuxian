# 九曲灵参（六阶灵药）

## 外观

九曲灵参，其形类人而多曲。通体莹白如玉，长约尺许，根须繁茂，主根蜿蜒九转，每一转折恰似龙蛇盘绕，故名"九曲"。参体表面有细密金纹，纵横交错如天然道纹，以神识探查，可见金纹中隐隐有流光运转，生生不息。

其气清奇，非花非木，乃是一种令人神魂俱醉的甘醇之香。凡人闻之，可延寿三载；修士闻之，丹田灵力自行运转，周天通畅。传说在九曲灵参生长之地周围十丈，草木皆沾染其灵气，常年不枯，冬日亦青翠如春。

最奇者，每逢月圆之夜，九曲灵参会自土中缓缓升起半寸，根须离地而舞，仿佛在吸纳月华。参体上的金纹会随月华流转而闪烁，明灭不定，如呼吸之节律。此象名曰"参拜月"，乃九曲灵参成熟之徵兆。

## 药性

- **性味**：性平微温，味甘厚而气醇
- **五行**：土行为主，兼纳四行——土居中宫，调和四方，故九曲灵参能容纳五行之力而不相冲
- **归经**：入肾经、心包经，兼通冲脉、督脉、任脉
- **毒性**：无毒。然药力磅礴，金丹以下修士服之，经脉不堪重负，轻则经脉胀裂三月不能动弹，重则丹田崩毁。故修真界有谚云："九曲非金丹，入口即黄泉。"
- **禁忌**：服用期间严禁房事、戒大怒、避阴寒之地；不可与破气类药物同用，否则药力尽泄，前功尽弃

## 功效

九曲灵参乃凝结元婴之圣药，其功效全在"九曲"之中。每一条曲转，均蕴含一缕先天道韵，九曲齐全则道韵圆满，可助修士窥见元婴之机。

- **九曲灵参丹**（六阶丹方）：以九曲灵参为主药，佐以玛瑙角、千叶露、千年茯苓、地脉黄精炼制。金丹大圆满修士服用后，凝结元婴的成功率可提升四至五成。若配合渡厄丹同时服用，成功率可达七成以上——此为修真界已知最高的结婴辅助手段。
- **九曲参汤**（五阶药方）：九曲灵参切薄片三片，以灵泉水文火慢炖七日，汤汁乳白如奶。元婴期以下修士每服一碗，可增百年修为，且药性温和，不伤根基。
- **参须续命散**（四阶药方）：九曲灵参的细小须根晒干磨粉，加入血灵芝、百年黄精炼制成散。重伤垂危之际，以灵酒送服一钱，可吊住性命七日不散，足够等待救援。
- **直接含服**：危急时切一小片（如指甲盖大小）含于舌下，可瞬间补充大量灵力，但此法暴殄天物，药力浪费七成以上，非到万不得已无人用之。

## 产地

九曲灵参生于地脉灵髓汇聚之处，对生长环境之挑剔堪称灵药之最。其生长之地必须同时满足三个条件：其一、地底深处必有一条上品灵脉经过；其二、地表须有千年古木遮阴，不可受烈日直射；其三、周围十里之内不得有金铁之矿，否则金气克木，灵参不生。

主要分布于：
- **中州龙脉山**：此山乃中州最大灵脉之龙首所在，地气最旺。山中有三处灵穴，每隔三千年方有一株九曲灵参成熟。此地产参品质最佳，九曲分明，金纹完整，历来被中州三大宗门轮流看守。
- **东海蓬莱岛**：海外仙岛，灵气充沛，但岛上参种已近乎灭绝。最后一次发现是两千年前，一株五千年九曲灵参被一只元婴期玄龟守护，采参者与玄龟大战七日，最终玄龟负伤遁走，灵参被采，但采参者也因此重伤，三年后不治身亡。
- **南疆十万大山**：瘴气弥漫之地，人迹罕至，偶有散修在此发现野生灵参。但此地灵参多在四曲以下，品质不及中州。

采集之难，不在妖兽守护，而在灵参自身。六阶灵药已具灵智，九曲灵参更是其中佼佼者——它能感知危险，在修士靠近之前便缩入地底深处，以根须卷土掩埋自身，任你掘地三尺也难觅其踪。唯有以特制的"寻参玉碟"定位其灵气所在，再以"锁灵阵"封固四周地脉，使参无法遁逃，方可挖掘。

## 年份与药效

- **百年九曲灵参**：参体初具形状，约一二曲转，金纹若隐若现。药力尚弱，可强身健体、延年益寿，对凝结元婴无甚助益。
- **五百年九曲灵参**：三至四曲，金纹渐显，已可炼制低阶参汤。金丹修士服之可大增修为，但尚不足以辅助结婴。
- **千年九曲灵参**：六至七曲，金纹明亮，九曲之势已成大半。此时已有辅助结婴之效，但成功率仅提高一至二成。
- **三千年九曲灵参**：九曲齐全，金纹如丝如缕遍布参体。此为"大成"之态，可炼真正的九曲灵参丹，助元婴凝结成功率大增。修真界所见之参，多为三千年上下。
- **万年九曲灵参**：参体由莹白转为淡金，称为"金参"，传说中已可以土遁之法自由行走。万年灵参已不须炼丹——直接服食，可使化神期修士突破至炼虚期的概率提升三成。但万年金参近万年来从未现世，仅存于古籍记载之中。

## 相关典故

千年前，中州有一金丹散修名曰"韩不鸣"，天资平庸，灵根驳杂，修至金丹大圆满已耗尽寿元，只余三十年可活。若不能结婴，则寿尽而亡。

韩不鸣倾尽家财，购得一株三千年九曲灵参，又四处奔波凑齐玛瑙角、千叶露等辅药，请得一位六阶炼丹师开炉炼丹。然炼丹之日，丹炉突发异响——炉盖震动，裂缝隐现，竟是药力冲突，丹炉将炸！

韩不鸣心知此丹若失，此生再无结婴之望。他竟以自身精血为引，逼出心头精血三滴注入丹炉，强行稳住药力。炼丹师大惊，此乃失传的"血引镇丹术"，虽能救丹，但施术者折寿十年。

丹成之日，炉开九色霞光冲天，百里可见。韩不鸣服丹后闭关三年，成功凝结元婴，寿元大增。但他因施展血引之术，折损十年阳寿，比起同等元婴修士，寿元少了百年。

有人问他可曾后悔，韩不鸣大笑："不鸣则已，一鸣惊人。若无此丹，我三十年便死；如今虽折寿十年，却有千年可活。这买卖，划算！"

自此，"韩不鸣血引结婴"之事传为佳话。而他当年所用之丹方——九曲灵参丹，亦因此事闻名天下，成为修真界结婴首选丹方。
