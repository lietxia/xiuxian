# 地不容（四阶灵药）

## 外观

地不容，其名源于其性——"地不容"者，大地所不容也。此草天生不见天日，生于地下数十丈深处，形如一块黑色石块，表面凹凸不平，布满细密裂纹，与寻常矿石无异。

其大小如拳头至西瓜不等，外皮漆黑如墨，坚硬如铁。以手敲击，发出沉闷的"咚咚"声，如同敲击实心石球。但若以灵目观之，可见石壳内有无数细如发丝的红色脉络在缓缓流动——那是地不容的"血脉"。

将其剖开，内中并非石质，而是一种黑色的胶状物质，质地如冷却的沥青，却散发着浓郁的药香——初闻如松脂，再闻如麝香，三闻则令人精神大振。

地不容无叶无花无茎，只有这一颗"石蛋"般的存在。它的"根系"是那些红色脉络——从石壳中延伸而出，在周围土壤中蔓延数丈，吸收地脉灵气。

其气被泥土封闭，只有剖开石壳后才能闻到。那气味浓郁而独特，闻之令人感到全身筋骨酥麻，如同被一双无形的大手按摩。

## 药性

- **性味**：性温，味甘辛，入口如嚼胶质
- **五行**：偏土金二行——土主承载，金主坚固，土金相生故能强筋健骨
- **归经**：入肝经（肝主筋）、肾经（肾主骨）
- **毒性**：无毒，但药力猛烈——服用后会感到全身骨骼发出咔咔响声，持续约一个时辰
- **禁忌**：骨折未复位者不可直接服用——地不容会加速骨骼生长，若断骨位置不正，愈合后骨骼畸形

## 功效

地不容专治一切跌打损伤、骨折筋伤，乃体修外伤圣药。

- **接骨续筋**（核心功效）：骨折者服用地不容胶状物，可在一个时辰内止痛，在七日内使断骨完全愈合——且愈合后的骨骼比受伤前更加坚韧。
- **跌打损伤**：扭伤、挫伤、瘀血肿胀，以地不容胶状物外敷，可在一个时辰内消肿止痛。
- **地不容续骨膏**（四阶药膏）：地不容胶状物配伍乳香、没药、血竭、自然铜，调制成膏。外敷可治疗一切外伤，愈后不留疤痕。
- **强筋健骨**：长期服用地不容胶状物，可使筋骨强度提升三成——体修者常以此物作为日常辅助修炼之品。
- **服用感受**：胶状物入腹黏稠如蜜，一股温热之力从胃部扩散至四肢百骸。骨骼会发出细微的咔咔声，如同在重新排列组合。整个过程持续约一个时辰，期间会感到筋骨酥麻，极为舒适。

## 产地

地不容只生长在地下数十丈深处的"死土"之中——需满足三个条件：其一，土壤中没有蚯蚓等生物活动（"死土"之意）；其二，地下有微弱的地脉灵气经过；其三，上方地表曾有大量生物死亡——生物的尸骸渗入土壤，成为地不容的养料。

已知产地：
- **古战场遗址地下**：万年前正魔大战的战场遗址，地下数十丈处埋骨无数，地不容在此生长。但古战场遗址多有怨气，采集时需抵御怨念侵蚀
- **地下矿洞深处**：开采灵石矿脉时，偶尔会在矿洞深处发现地不容。矿工们视其为吉祥物——发现地不容意味着矿脉品质上佳
- **火山灰地层**：火山喷发后的地层中，地不容在火山灰与尸骨的混合物中生长。但火山地层温度极高，采集困难

采集地不容极为困难——它深埋地下数十丈，外表与普通石块无异，极难辨识。有经验的采药人会观察地面植被：地不容生长之处，地面植被会比周围矮小瘦弱——因为地不容在地下吸收了大部分养分。

更麻烦的是，地不容的外壳坚硬如铁，必须以法宝级别的利器才能剖开。普通法器砍上去，只会溅出一串火星。

## 年份与药效

| 年份 | 特征 | 药效 |
|------|------|------|
| 百年 | 如拳头大小，外壳薄，黑色胶状物少 | 可治普通跌打损伤 |
| 三百年 | 如西瓜大小，外壳厚，胶状物丰富 | 可接骨续筋，对筑基期修士有效 |
| 千年 | 外壳出现红色脉络，胶状物呈深黑色 | 可炼地不容续骨膏，对金丹期修士有效 |
| 三千年 | 外壳红色脉络密布如血管，胶状物散发红光 | 可治元婴期修士的骨骼之伤 |
| 万年 | 外壳裂开，内有黑色晶体形成 | 可令断肢重生，体修圣品 |

## 配伍建议

**最佳配伍**：
- 地不容 + 乳香 + 没药 + 血竭 → 地不容续骨膏
- 地不容 + 自然铜 + 骨碎补 → 接骨丹
- 地不容 + 龙骨粉 + 虎骨 → 强筋健骨散

**禁忌配伍**：
- 地不容 + 活血化瘀类药物 → 药性相冲，愈合的骨骼会变脆
- 地不容 + 寒凉药物 → 寒凝血脉，骨骼愈合速度减半

## 相关典故

上古时期，蚩尤与黄帝战于涿鹿。蚩尤麾下有一猛将名"刑天"，被黄帝斩首后，以乳为目、以脐为口，继续战斗。

刑天最终力竭倒地，其尸身融入大地。万年之后，刑天尸身所在之处，长出了一种奇异的黑色石块——形如拳头，内含胶状物，散发着刑天不屈的战意。

第一位发现此物的是一位矿工。他在挖矿时挖到一块黑色石块，不慎被石块划破手指。他惊讶地发现，伤口在触碰石块后竟然瞬间愈合。

矿工将石块带回家，剖开后发现内中的黑色胶状物。他以之治愈了无数跌打损伤，名声大噪。

后来，一位路过的修士认出此物乃刑天尸身所化，蕴含刑天不屈的战意——"刑天舞干戚，猛志固常在"。修士以此物为主药，炼成"刑天续骨膏"，在修真界广为流传。

至今，体修在服用地不容前，都会先握紧拳头，大喊一声"刑天"——以此纪念那位不屈的战神，也以此激发药力。

修真界流传着一句话："地不容，刑天魂。服下去，骨如钢。战神虽死，战意长存。"
