# 八角莲（四阶灵药）

## 外观

八角莲生于毒瘴之地，却出淤泥而不染。其形如莲，却非水生——挺立于腐叶泥土之中，高约尺余，一根独茎直立如剑，顶端托举一朵金色莲花。

最奇在其叶。茎秆底部轮生八片叶子，呈八角形排列，每片叶子形如盾牌，叶脉呈放射状，从中心向八个方向延伸，如同一枚微缩的八卦阵图。叶色墨绿，边缘镶着一圈紫黑色——那是毒素沉积的痕迹。

莲花盛开时，花瓣层层叠叠，共八层，每层八片，共六十四片花瓣，色作金黄，花蕊朱红，形如火焰。整朵花在毒雾中熠熠生辉，如同一盏明灯照亮周遭。

八角莲的气息极为特殊——初闻是腐臭的毒气，再闻却转为清甜的莲香，三闻则令人神清气爽，体内毒素如被无形之手缓缓拔出。

其根茎如藕，洁白如玉，却含有剧毒——根茎之毒比花叶更烈十倍，触之即溃烂。

## 药性

- **性味**：性凉，味甘苦，入口先麻后甜
- **五行**：偏木火二行——木主疏泄，火主炼化，木火相生故能以火炼毒
- **归经**：入脾经、肝经，兼走奇经八脉
- **毒性**：根茎有剧毒，花叶无毒。根茎汁液沾肤即溃烂，入腹则五脏俱损
- **禁忌**：非蛊修或毒修不可用；服用时需以特殊手法将花叶与根茎分离，不可使根茎汁液混入花叶

## 功效

八角莲乃南疆蛊修至宝，专克蛊毒。

- **解蛊毒**（核心功效）：无论何种蛊毒——金蚕蛊、蛇蛊、蝎蛊、情蛊——以八角莲花瓣煎水饮之，可在三个时辰内将蛊虫逼出体外。蛊虫遇八角莲之气如遭天敌，会自行从宿主体内爬出。
- **八角炼蛊丹**（四阶丹药）：以八角莲花瓣为主药，配合蛊虫炼制。服后可令本命蛊虫品阶提升一阶，且蛊虫对主人的反噬概率降低五成。
- **毒瘴免疫**：长期服用八角莲花瓣粉末，可令身体对毒瘴产生永久免疫——行走毒雾如履平地。
- **以毒攻毒**：八角莲根茎汁液稀释万倍后外敷，可治疗一切恶疮脓肿——以剧毒之物攻毒，效果远超寻常解毒药。
- **服用感受**：花叶入腹清凉舒适，如饮冰泉。若有蛊虫在体内，会感到腹中虫子在剧烈挣扎，随后从口中或肛门排出。

## 产地

八角莲只生长在南疆蛊林的深处——需满足三个条件：其一，地下有蛊虫巢穴，蛊虫排泄物为其养料；其二，上方有天然毒雾遮蔽，日光不可直射；其三，周围必有至少三种以上毒物共生。

已知产地：
- **万蛊谷**：南疆最大的蛊虫栖息地，谷底八角莲成片生长，但谷中蛊虫无数，寻常修士入内便是送死
- **五毒教禁地**：五毒教以秘法培育八角莲，作为解蛊毒的储备药材。外人不得靠近
- **苗疆古墓地**：苗族先人墓地中偶有八角莲生长，吸收尸毒与蛊毒，品质极佳

采集八角莲需戴寒蚕丝手套，以玉刀切割花叶，单独存放。根茎不可触碰——曾有采药人贪心挖掘根茎，结果手掌在三日内烂见白骨，最终截肢保命。

## 配伍建议

**最佳配伍**：
- 八角莲花瓣 + 金银花 + 甘草 → 万能解蛊汤
- 八角莲花瓣 + 本命蛊虫 → 八角炼蛊丹
- 八角莲根茎（稀释）+ 黄连 + 黄柏 → 外敷恶疮膏

**禁忌配伍**：
- 八角莲 + 任何蛊虫滋补药物 → 药性相冲，蛊虫暴走
- 八角莲根茎 + 任何内服药物 → 剧毒入腹，必死无疑

## 相关典故

上古时期，南疆有一蛊师名"蛊婆"，以金蚕蛊闻名天下。她下的蛊无人能解，连元婴修士都忌惮三分。

一日，蛊婆爱上了一位正道修士。修士得知她的身份后，愤而离去，并留下一句话："你这辈子都别想洗清手上的血。"

蛊婆痛定思痛，散尽全身蛊虫，独自进入万蛊谷寻找解蛊之法。她在谷中苦修百年，终于发现八角莲可解天下蛊毒。

她以八角莲为主药，创出"万蛊归宗诀"——将自身化为解蛊之体，走到哪里，哪里的蛊虫便自动消亡。她以此法行走南疆百年，解除了无数中蛊者的痛苦。

临终前，她将毕生心得刻于八角莲叶上，留给后人。那片叶子至今保存在五毒教禁地中，叶上文字在月光下会发出金色光芒。

南疆蛊修至今仍流传一句话："八角莲开，万蛊归宗。不是蛊师，莫入此门。"
