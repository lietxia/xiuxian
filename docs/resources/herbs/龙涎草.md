# 龙涎草（地阶上品）

## 外观

龙涎草以龙涎为养分——所谓龙涎，即真龙之唾液。真龙一族虽然极少在凡间露面，但它们偶尔会降临某处山谷饮水休息，其唾液滴落之处，便有龙涎草生长。

龙涎草形如麦穗，秆高约三尺，顶端抽出金色的穗状花序，密密麻麻的小花排列成宝塔状。整株龙涎草从秆到叶都是金色的——不是枯黄的金，而是如同黄金铸就的璀璨金色，阳光下闪闪发光。

最特别的是，龙涎草即使在无风的天气里也会微微摆动——仿佛有什么看不见的力量在轻轻吹拂。据说那是因为龙涎草中残留着一丝真龙的气息，使它不完全受凡间规律约束。

龙涎草散发的气味浓郁而霸道，是一种极其充沛的灵气味道——就像是灵气被压缩成固体后散发出的气息。站在龙涎草丛中，不用修炼，灵气就会自动往身体里钻。

## 药性

- **性味**：性温，味甘香浓郁
- **五行**：全属性亲和——龙涎蕴含真龙之力，真龙乃万灵之长，对任何属性的灵力都有融合作用
- **毒性**：无毒。但药力太过充沛，修为不够者服用会导致灵气溢满经脉——就像小杯子装大桶水，会撑破的

## 功效

龙涎草是修真界公认的"万能灵气补充剂"，也是炼制高阶丹药的重要辅料。

- 直接服用可迅速补充大量灵力——特别适合在战斗或逃命时快速恢复
- 长期服用可拓宽经脉、增强丹田容量
- 可炼 **龙涎续灵丹**，在灵力枯竭时服用，可瞬间恢复七成灵力
- 可炼 **龙涎筑基液**，筑基期修士沐浴其中，可极大提升筑基质量
- 龙涎草是多种高阶丹药的必需辅料——它的全属性亲和特性可以中和不同药材之间的冲突，让药材更好地融合
- 龙涎草的种子晒干后磨粉，加入灵茶中，可使茶水清香四溢，灵气逼人

## 产地

龙涎草只生长在真龙曾经停留过的地方——必须是真龙在此饮水休息、留下了唾液。普通妖兽的涎液不行，蛟龙或亚龙的涎液也不行，必须是纯正的真龙。

龙涎草从发芽到成熟需要的时间并不长——二三十年就足够了，比大部分灵药都快得多。但关键是种子从哪里来？龙涎草开花结籽后，种子需要沾染真龙气息才能发芽，否则就是一颗普通的草籽。

所以龙涎草的产地完全是随机的——真龙去哪里，龙涎草就在哪里出现。已知的几个产地都是历史上真龙曾经光顾过的地方：东海苍龙渊附近的山谷、西域不周山下的龙饮泉、以及中州万妖山脉深处的一处无名水潭。

采集龙涎草本身没有危险——守护它的往往是龙涎带来的灵气吸引了强大妖兽聚集。换句话说，龙涎草周围必有高阶妖兽。而且龙涎草一旦被采摘，周围聚集的妖兽就会暴怒——因为它们的灵气来源被断了。

## 年份与药效

- **十年龙涎草**：已经可以入药，灵力充沛，可作为大部分丹药的辅料
- **百年龙涎草**：金色更深，穗状花序更为饱满，可炼续灵丹
- **五百年龙涎草**：已经不能叫草了——它会长成一棵小树，根系深入地下数丈，整片山谷都会被它的灵气笼罩。这种级别的龙涎草已经算是天材地宝了

## 相关典故

关于龙涎草，修真界有一个流传很广的"钓龙"故事。

五百年前，有一位散修叫"龙痴"，他毕生愿望就是见一次真龙。他研究了所有关于龙的记载，发现龙最喜欢在月圆之夜到清澈的水潭边饮水。于是他绞尽脑汁，想到了一个疯狂的办法——种龙涎草来吸引真龙。

他花了三十年时间，从各处收集龙涎草的种子和龙涎气息，最终在一个荒谷中成功地种出了一小片龙涎草。然后他就蹲在草丛里等着——等了二十年。

第二十年的一个月圆之夜，真龙真的来了。

但龙痴太激动了，一下子从草丛中跳了出来，把龙吓了一跳。龙喷了他一脸龙息，然后就飞走了。

龙痴虽然没有得到龙的任何东西，但他被龙息喷过后，体质发生了巨大的变化——他的肉身变得异常坚韧，而且对水属性功法的亲和力提升了数倍。后来他凭借这个体质，硬是修炼到了化神期。

他晚年时跟人说起这件事，笑着说："我没钓到龙，但龙给了我一口唾沫。值了。"
