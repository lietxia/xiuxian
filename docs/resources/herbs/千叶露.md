# 千叶露（六阶灵材）

## 外观

千叶露，非草非木，乃千年古木千片叶尖于黎明时分凝结之晨露，得天时、地利、木灵三者合一，方可成就。

其状与寻常露珠无异——清澈透明，圆润如珠。然以灵力观之，则见每一滴中皆有一缕翠绿色光丝缓缓游动，宛如活物。此乃千年古木的草木精华凝聚而成，乃千叶露真正价值所在。

千叶露的气味淡极而幽——初闻无味，再闻则有一股清冽木香缓缓渗入肺腑，令人神清气爽，仿佛置身于万年古木之下。以舌尖轻尝，甘甜清冽，入喉后一股清凉之气自丹田升起，散入四肢百骸。

千叶露有一奇特性——不会蒸发。将一滴置于玉碗中暴晒三日，露珠依旧圆润如初。盖因露中草木精华形成了微型灵气场锁住水分。唯有以丹火炼化或以灵力引导，方可使此灵气场消散。

每片叶子一夜仅凝千叶露一滴，且须在日出前卯时一刻至三刻之间采集，太阳一出，草木精华便散，化作普通露水。故"千叶"之名，既有千叶之功，亦有千次方成一滴之喻。

## 药性

- **性味**：性凉，味甘淡，气清冽
- **五行**：木行为主，兼含水行之润——木水相生，使药力通达全身
- **归经**：入肝经、肺经，兼走十二经络，尤善引药入络
- **毒性**：无毒。千叶露至纯至净，是修真界最温和的药引之一
- **禁忌**：忌与燥火之物同贮；盛放容器须为玉器或琉璃——金克木，金铁之器会消解千叶露药力

## 功效

千叶露之功不在"补"而在"引"——如军中向导，能带领药力精准到达该去之处。

- **九曲灵参丹药引**（六阶丹方）：若无千叶露引导，九曲灵参的雄浑药力会在丹田中横冲直撞。千叶露的清凉和缓之力恰可如春风化雨般牵引药力沿经脉有序运行。一引一镇——千叶露引导前行，玛瑙角镇住不散，二者一阴一阳，相辅相成，方将九曲灵参的药效发挥到极致。
- **千叶化毒液**（五阶药方）：千叶露配伍解毒草、百年甘草，可解百毒，对火毒、丹毒尤有奇效。
- **千叶通络汤**（四阶药方）：千叶露为主，辅以红花、川芎、地龙干熬制。治疗经脉淤堵，可在十日内打通闭塞经脉。
- **甘露养颜方**（三阶药方）：千叶露混合玉蜂蜜、珍珠粉，每日涂抹面部，可使肌肤如玉。此方在女修中极受欢迎。
- **直接饮用**：一滴千叶露吞服，可清心明目、消除疲劳。斗法消耗过度时，能迅速恢复神识清明。

## 产地

千叶露的形成条件极为苛刻，须树龄三千年以上的灵木，在灵气充沛之地生长，方可使叶片蕴含足够草木精华来凝聚露水。符合条件者不过万年建木、千年菩提、千年桂树、千年青松寥寥数种。

主要产地：
- **南海菩提岛**：一株万年生菩提树，是修真界已知最大的一株。但受佛门大能守护，非佛门弟子不得靠近
- **中州灵木谷**：建木、桂树、青松皆有，三大宗门联手管理，每年按比例分配千叶露
- **散修秘境**：一些上古秘境中有不知年岁的古木，但秘境凶险万分，非大气运者不可入

采集之法：日出前一个时辰到达树下，以玉杯或琉璃瓶接取叶尖滴落的露水。不可触碰叶片（叶片受惊则明日不凝露），不可大声说话（声波震落露珠），甚至不可心怀恶意（草木有灵，会收敛露水）。一名熟练采露人，一个早晨最多采集百余滴。

## 年份与药效

千叶露不以年份论，而以"集露之木的树龄"论品质：
- **千年古木之露**：品质普通，草木精华约三成
- **三千年古木之露**：品质尚佳，草木精华约五成
- **五千年古木之露**：品质上乘，草木精华约七成，露中绿丝清晰可见
- **万年古木之露**：稀世珍品，露呈淡翠色，草木精华近十成。可炼八阶丹药，百年难遇

千叶露保存不易，须以玉瓶密封，置于灵脉之上温养。保存得当可维持药力百年不失；随意存放则三月后药力衰减，一年后与普通露水无异。

## 相关典故

传说上古时期，女修"青萝"爱慕一位名叫"长青"的男修。长青修炼所需一种罕见之水——千年古木晨露。青萝每黎明前往古木下以玉杯接取露水，风雨无阻坚持三年，双手生冻疮，面容憔悴，却从不抱怨。

三年后她攒够分量前去寻找长青——却发现长青早已与他人结为道侣。青萝未哭未闹，只将玉瓶放在长青洞府门口，转身回到那棵古木下，靠着树干坐化。

次日清晨，人们发现她已坐化，但周围的每一片草叶上都凝结了晶莹露珠——明明是清晨，却有千万滴露水同时显现。

此后这棵古木所凝露水便比别处更多、更清、更甜。有人说，那是青萝的泪水化成的。修真界至今仍有性情中人在接取千叶露时，会心中感念那位叫青萝的女子——若无她的痴情，世间或不知千叶露的真正价值。
