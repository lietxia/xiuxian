# 星魂花（天阶下品）

## 外观

星魂花是修真界最美丽的花朵之一，它的美不属于人间——属于星空。

白天的星魂花毫不起眼，就是一株灰扑扑的低矮草本植物，叶片暗淡无光，花苞紧缩成一颗灰色小球，看起来和路边的野草没什么两样。

但一到夜晚，星魂花就会展现出它真正的面目。当夜幕降临、星辰初现之时，星魂花的花苞会缓缓绽放，每一片花瓣都散发出淡淡的银蓝色荧光。花瓣上布满了天然的星图纹路——那是真正的星辰图案，不是随意形成的。每一株星魂花的花瓣纹路都不一样，对应着夜空中的不同星域。

盛开的星魂花，远望如同一团银蓝色的星云悬浮在地面上空，美得令人窒息。它散发出的光芒并非普通的荧光，而是如同星光一般纯净而清冷。据说在星魂花旁边打坐修行，会感到自己仿佛置身于浩瀚星空之中。

星魂花散发的气味也与众不同——不是花香，而是一种清冽如冰的气息，仿佛夜风从高天之上吹来的味道。

## 药性

- **性味**：性凉，味淡中带一丝甜
- **五行**：偏水属性，但同时蕴含少量的星辰之力——这是星魂花最独特的地方，它的药性中带有一丝来自天外的力量
- **毒性**：无毒。但星魂花蕴含的星辰之力对修为太低的人可能造成眩晕感——如同仰望星空太久会感到渺小和晕眩一样

## 功效

星魂花是修炼神识、参悟天机的绝佳灵药。

- 服用后可壮大神识，提升精神力的凝聚度和感知范围
- 对参悟天道法则有辅助作用——星魂花中蕴含的星辰之力可以帮助修士更好地理解天地运行的规律
- 可炼 **星魂悟道丹**，服下后进入顿悟状态，对功法瓶颈的突破有奇效
- 可炼 **七星护魂灯**（以星魂花汁为灯油），点燃后可保护修士在危险的秘境中不被邪祟侵扰神识
- 星魂花的花瓣贴在额头上，可以帮助修士回忆遗忘的记忆——对搜魂术造成的记忆缺失有一定疗效

## 产地

星魂花的生长条件极为诡异：它需要吸收星辉之力才能生长，而星辉在地面上极为稀薄。所以星魂花通常生长在海拔极高的山峰顶端——越接近天空越好。

已知产地包括：天柱山的最高峰——摘星崖，那里常年罡风呼啸，普通修士站都站不稳；昆仑山脉的接天峰，据说那里伸手可摘星辰；西域大漠中的星陨谷——一颗陨石坠落后形成的巨坑，那块陨石带来了浓厚的星辰之力，使得整座山谷成了星魂花的乐土。

采集星魂花需要在夜间进行——因为白天星魂花处于休眠状态，贸然采摘会导致它迅速枯萎。而且采摘时必须用玉刀，不可用铁器触碰，否则会污染它的星辰之力。

## 年份与药效

- **百年星魂花**：花瓣上只有寥寥数颗星光纹路，可炼初级悟道丹
- **五百年星魂花**：花瓣上的星图纹路已经清晰可见，可炼中品星魂丹，对金丹修士突破元婴有辅助效果
- **千年星魂花**：花瓣上的星图已经演化出一小片星域，银蓝光芒如实质一般，可炼上品悟道丹，对参悟法则之力大有帮助

## 相关典故

修真界有个神秘的宗门叫"观星阁"，以观测星象、推演天机著称。观星阁与星魂花有着极深的渊源——据说观星阁的创始人是一位痴迷于星空的修士，他在天柱山摘星崖上枯坐了一百年，不吃不喝不睡，就为了观察星辰的运行。

一百年后，他周围长满了星魂花。那些星魂花的花瓣纹路与他在一百年中观测到的星图完全一致。他恍然大悟：原来星魂花是星辰之力烙印在大地上的印记，每一朵花都在记录天空的历史。

他创立观星阁后，以星魂花为镇派之宝，历代阁主都以星魂花辅助观星。观星阁最神奇的地方是——他们有办法让星魂花的花瓣纹路显示过去的星象。这意味着，你可以通过一朵千年星魂花，看到一千年前的夜空是什么样子。

观星阁靠这个能力，在修真界享有极高的地位——很多宗门都会花大价钱请他们推算吉日、预测天机。但他们也有一个不能触碰的禁忌：永远不能试图通过星魂花看到未来的星象。

曾经有一位观星阁主不信邪，强行动用秘术以星魂花窥探未来。他看到了七日后会发生的事——然后七日后他死了。没有人知道他看到了什么，但从此以后，观星阁的阁训多了一条："过去可知，未来不可测。星魂花不载未至之事。"
