# 雪莲子（天阶上品）

## 外观

雪莲子生于万年玄冰深处，乃寒冰精华凝结而成。其形如莲子，大小如鸽卵，通体晶莹剔透，洁白如雪，内部隐约可见一缕银白色光晕缓缓流转。若将雪莲子置于掌心，可见其周围空气遇冷凝结成细密水珠，整颗莲子仿佛笼罩在一团朦胧雾气之中。

雪莲子本身不散发气味，但若以灵力催动，会溢出一种极淡的清冷气息，闻之如置身万丈雪山之巅，令人心神澄澈。丹田中的灵力会随之变得凝实，仿佛被寒气淬炼过一般。

令人称奇的是，雪莲子虽然至寒，却不会冻结周围之物。取一颗放入寻常水中，水会变得清冽甘甜，饮之可解百毒。若将雪莲子置于暗室，它会发出柔和的银白色荧光，光芒虽淡，却足以照亮三尺之内。一颗万年雪莲子的光芒，可堪比夜明珠。

更有一种说法：雪莲子若在极光之下绽放，会吸收极光之彩，内部银光变为七彩流光。这种吸收了极光的雪莲子被称为"极光雪莲"，药效更为玄妙，但百年难遇一次。

## 药性

- **性味**：性大寒，味甘淡，回味清甜
- **五行**：纯水属性，兼带一丝阴寒之力，上应天上的太阴星
- **归经**：入肾经、心经。肾主水，故雪莲子的药力最先作用于肾水系统
- **毒性**：无毒。但体质虚寒或修炼阴寒功法者不可多服，否则寒气入髓，难以化解
- **禁忌**：孕妇忌用；脾虚泄泻者慎用；服用期间不可同时服用人参、鹿茸等大补阳气之物
- **配伍注意**：雪莲子性至寒，通常须以阳性药材中和，否则久服会损伤阳气

## 功效

雪莲子乃增补修为的绝佳灵药，尤其适合火属性功法的修士用来调和体内燥火之气。

- **直接服用**：一颗百年雪莲子，可直接增加十年精纯修为，无须炼化，入口即化。一缕冰凉之意自喉间下行，至丹田时化成一股精纯的清灵之气，自动汇入经脉之中。
- **雪莲清心丹**（天阶中品）：以雪莲子为主药，配以清心草、无根水炼制。突破心魔劫时有奇效，能在心魔入侵之时护住灵台清明，不被幻象所惑。根据修真界统计，服用雪莲清心丹后渡心魔劫的成功率从不足三成提升至七成以上。
- **玄冰玉露丸**（天阶下品）：雪莲子配合玄冰玉髓、千年寒髓炼制。治疗火毒入体、灼伤经脉等症，能在三日之内清除体内火毒，修复灼伤经脉。魔道修士常有修炼阴火功法的，走火入魔时也靠此丹救命。
- **雪莲养魂液**（地阶上品）：取雪莲子磨粉，以灵泉融化，加入安魂草汁液。对神魂受创、魂力亏损有温养之效，尤其适合夺舍之后的修士稳固神魂。
- **外敷用法**：碾碎外敷，可治一切火毒烧伤，不留疤痕。冰原上的猎户被冰兽所伤，也会用雪莲子粉末止血——虽然奢侈，但确实好用。
- **服用感受**：雪莲子入口即化作一股清流，冰凉之意从丹田升起，沿着经脉缓缓流淌。所过之处，经脉中的燥热之气被一一中和，如同炎炎夏日饮下一碗冰水，通体舒泰。药力可持续七日，期间修士会发现自己的灵力中多了一股清寒之意，施展冰属性法术的威力会提升两成。

## 产地

雪莲子只出产于极北冰原万丈冰层之下，或是极少数万年不化的寒潭深处。修真界已知的产地在三处：

- **北极冰原·万载玄冰洞**：最大的已知产地，北冥家族世代守护。冰洞深入冰层三千丈，底部有万年玄冰矿脉，内藏雪莲子无数。但越往下越危险，深处的冰兽实力堪比化神修士。
- **昆仑山脉·寒冰潭**：位于昆仑山主峰背阴处的一口寒潭，潭水终年结冰，但冰层之下有暗流涌动，雪莲子便生长在冰与水的交界处。此处雪莲子产量极少，但品质极高。
- **南冥冰海**：极南之地的冰洋深处，偶有雪莲子随冰层漂移至近海。曾有一位渔夫在破冰捕鱼时捞到一颗千年雪莲子，一夜之间从凡人变成了筑基修士，轰动一时。
- **随机冰脉矿藏**：修真界偶尔会发现新的雪莲子产地，往往是在开采灵石矿脉时，挖穿了一层玄冰层后意外发现。每次发现都会引发一阵腥风血雨。

采集雪莲子需要深入冰层之下，非金丹修士不可为。更要命的是，雪莲子生长之处常有冰属性妖兽守护——万丈玄冰之中可能沉睡着远古冰蟒，其修为堪比元婴修士。曾有合体期大能前往北极冰原寻找万年雪莲子，与守护冰兽大战三日，最终虽得莲子数颗，却也负伤而归。

采集手法也有讲究：不能以金属器物触碰雪莲子，否则会使其灵气外泄。必须以温玉制成的玉铲、玉盒采集盛放。取出后一个时辰内须以灵力封存，否则外层会开始融化。

## 年份与药效

- **百年雪莲子**：鸽卵大小，银光如薄雾。一颗可增十年修为，助筑基修士突破瓶颈，市价约一千中品灵石。
- **五百年雪莲子**：大如核桃，内部银光凝实如液。一颗可增八十年修为，对金丹修士效果显著，市价约五千中品灵石。
- **千年雪莲子**：大如鸡子，内部银光浓郁如实质，表面有冰晶状纹路。一颗可增三百年修为，对元婴修士效果显著，市价三万中品灵石起步，且有价无市。
- **三千年雪莲子**：表皮转为冰蓝色，内部不再是银光而是蓝色冰芒。一颗可增八百年修为，对化神修士有效。整个修真界已知存量不超过十颗。
- **万年雪莲子**：淡蓝色而非纯白，大如婴儿拳头，内部有雪花状道纹浮现。一颗可助化神修士突破一阶，但已有万年未曾现世。传说中吞服万年雪莲子后，修士的丹田会凝结出一朵"冰莲元婴"，战力远超同阶。

## 相关典故

冰原深处有一支隐世修仙家族，复姓"北冥"，世代以采集雪莲子为业。他们体魄异于常人，不畏严寒，能在冰层中自由穿行。北冥家有一条祖训：雪莲子不可采尽，每处冰脉只取七成，留三成以续灵脉。正因如此，北冥家独占北极冰原数千年雪莲子产出而不衰。

千年前曾有一桩悬案：魔道修士"寒山老怪"潜入北冥家祖地，偷走了一枚即将成熟的万年雪莲子。北冥家倾巢追索，最终在东海之滨截住寒山老怪。一场大战，打得海面结冰百里，最终老怪被诛，但万年雪莲子也在争斗中碎裂消散。北冥家家主抚碎冰而泣，说了一句至今流传的话："一粒雪莲子，十年苦修功。万年造化物，一朝付东风。"

还有一个鲜为人知的传说：上古时期，极北冰原并非冰封之地，而是一片生机盎然的草原。天上有一位冰凤仙子，恋上了人间的一位牧羊少年。天帝震怒，将冰凤仙子囚于北极，她的泪水化为玄冰，覆盖了整片草原。而她心中的思念，则凝结成了雪莲子——外表至寒，内藏柔情。所以雪莲子虽然性寒，却不伤人，反而能解火毒。这大概就是传说中的"冰有柔情"吧。

如今的北极冰原上，每年冬至之夜，北冥家族都会举行"采莲祭"，由族长在玄冰洞口设坛祭天，感谢上天赐予雪莲子。祭典中最神秘的一道仪式，是将一颗百年雪莲子投入洞中深渊——名为"归莲"，意为将一部分收获还归天地，以保灵气不竭。
