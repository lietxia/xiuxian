# 碧落花（天阶上品）

## 外观

碧落花生于天地灵气最为纯净之处，色如碧玉，形如铃铛，花瓣薄如蝉翼，半透明状，可清晰看见花瓣内部有碧色汁液缓缓流动。

此花最独特之处在于其开放方式：每百年才开一朵，而且从不独自开放。每株碧落花共有九朵，从第一朵开放到第九朵齐聚，需要整整九百年。九朵碧落花同时盛放之时，方圆百里之内会被一片柔和碧光笼罩，天空中会出现一道碧色彩虹，被视为祥瑞之兆。

碧落花的气息极淡极幽，仿佛来自九天之上，不似凡间之物。闻之令人心境平和，杂念全消。若在花开之时静坐其旁修行，突破瓶颈的概率会大为提升。

## 药性

- **性味**：性凉，味甘
- **五行**：木属性为主，兼带一丝风属性
- **毒性**：无毒，且其气息就有解毒功效

## 功效

碧落花最大的功效，是炼制传说中的 **碧落丹**。碧落丹是修真界已知少数几种能帮助修士参悟大道的丹药之一。

- 服用碧落丹后，修士会进入一种"天人合一"的顿悟状态，持续数日至数月不等，对参悟功法、理解大道法则有不可思议之效
- 可炼 **碧落灵液**，沐浴后可净化肉身杂质，使皮肤如玉般莹润通透
- 单朵碧落花泡茶饮用，可解百毒、清心明目、延年益寿
- 传说碧落花的花瓣若夹入道卷之中，可使道卷不遭虫蛀、千年如新

## 产地

碧落花对生长环境的要求苛刻到令人发指。必须生长在灵脉的源头——即灵脉从地底涌出地面之处，灵气浓度必须达到雾化状态。而且周围百里之内不得有任何杀伐之气（包括妖兽厮杀、修士斗法都会影响其生长）。

已知的产地只有寥寥几处：东海蓬莱仙岛的灵脉源头、昆仑山脉深处的九天灵池畔、以及南疆十万大山中一处秘不示人的灵泉旁。

采集碧落花，最难的不是打斗——因为碧落花生长之处根本没有妖兽敢靠近（任何带有杀气的生灵靠近都会导致灵花枯萎），难的是等待。九朵齐聚需要九百年，而一旦其中一朵被提前采摘，剩下的花朵会立即枯萎。这意味着守护碧落花的人，需要守护整整九百年。

## 年份与药效

- **九百年（九花齐聚）**：碧落花成熟之时，九朵同开，方可炼碧落丹
- **每朵花的年份**：第一朵一百年，第二朵两百年……第九朵九百年。单朵花的药效远不如九花齐聚
- **传说有万年碧落花**：九朵花开后会渐渐转为淡青色，再过数千年会合为一朵九瓣奇花，被称为"碧落合和"，服之可直接悟通一门大道法则

## 相关典故

碧落花的名字中，"碧落"二字在修真界指代上天、九天之上。取此名，意在说明此花非人间之物。

关于碧落花，最著名的故事是蓬莱仙岛的一段往事：三千年前，蓬莱仙岛有一株碧落花即将九花齐聚。蓬莱掌门集全派之力守护，设下大阵隔绝外界一切纷扰。眼看第九朵花即将绽放，不料蓬莱内部出了叛徒——一位长老被魔道收买，在花开前夜试图盗取已开的八朵碧落花。

东窗事发后，这位长老拼死逃遁，手中握着八朵碧落花。花开时节已过，八朵碧落花在他手中渐渐枯萎。他逃至海边，被蓬莱弟子追上，最终自爆而亡。八朵碧落花全部毁于一旦。

蓬莱掌门看着那株只剩一颗花苞的碧落花，沉默良久，只说了一句话："八百年的等待，毁于一个人的贪念。"

那株碧落花至今仍在蓬莱仙岛，等待下一个九百年。
