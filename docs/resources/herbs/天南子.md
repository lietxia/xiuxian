# 天南子（四阶灵药）

## 外观

天南子，其名源于其形——果实排列如南天星宿，七颗主星环绕一颗暗星，与天上南天星座一一对应。其株矮小如灌木，高约尺余，枝条纤细如铁丝，呈深紫色，叶片细小如针，色作墨绿。

最奇在其果。每株天南子结果八颗，七明一暗——七颗明亮者呈紫色，在夜间发出微弱紫光；一颗暗淡者呈黑色，吸收光线而不反射。八颗果实排列成南天星座的形状，悬于枝头，如同一幅微缩的星图。

果实大小如葡萄，表皮光滑如釉，内有八粒种子，每粒种子都呈不同的形状——或圆或扁或尖，对应南天星座中的不同星体。

天南子的根系极为奇特——它没有主根，只有八条侧根，每条侧根对应一颗果实，从地下吸收养分。若一条侧根受损，对应的果实便会枯萎。

其气清淡如夜空，闻之令人感到心神宁静、思维敏捷，仿佛置身于浩瀚星空之下。

## 药性

- **性味**：性凉，味甘淡，入口如嚼星光
- **五行**：偏水木二行——水主智慧，木主生发，水木相生故能开智
- **归经**：入心经、肝经，兼走泥丸宫（神识之府）
- **毒性**：无毒，但服用后会感到头部微微胀痛——那是神识被强行扩张的感觉
- **禁忌**：神识受损者不可服用；服用期间不可接触噪音——噪音会干扰星辰之力的吸收

## 功效

天南子可壮大神识、提升悟性，乃参悟功法时辅助突破的圣品。

- **壮大神识**（核心功效）：服用一颗天南子果实，神识范围可扩大五十丈。长期服用（每月一颗，连续一年），神识强度可提升一倍。
- **提升悟性**：参悟功法时服用一颗天南子，可在一个时辰内进入"星悟"状态——思维如星辰般清晰，功法中的疑难之处如星光照亮黑暗，豁然开朗。
- **天南悟道丹**（四阶丹药）：以天南子八颗果实为主药，配合悟道茶叶、菩提子、星魂花炼制。服后可进入持续七日的顿悟状态，对参悟功法、理解大道法则有奇效。
- **星象推演辅助**：修炼推演类功法的修士，服用天南子后推演速度提升三倍，且推演结果更为准确。
- **服用感受**：果实入腹清凉如含冰块，一股清凉之力从丹田直冲泥丸宫。随后会感到头部微微胀痛，如同有人在颅内点了一盏灯——痛过之后，思维变得异常清晰，记忆力和理解力大幅提升。

## 产地

天南子只生长在高海拔、空气稀薄、星光充沛的山顶——需满足三个条件：其一，海拔至少三千丈，接近天穹；其二，周围无高山遮挡，可一览星空；其三，山顶有微弱灵脉经过，提供生长所需灵气。

已知产地：
- **天柱山·摘星崖**：天柱山最高峰，海拔五千丈，终年云雾缭绕但山顶晴朗。摘星崖上的天南子品质最佳，但山顶罡风如刀，金丹修士难以立足
- **昆仑山·接天峰**：昆仑山脉最高峰，海拔七千丈，伸手可摘星辰。接天峰上的天南子吸收日月精华，药力最为充沛。但峰顶温度极低，非元婴修士不可久留
- **南疆·观星台**：南疆十万大山中有一处天然石台，石台之上视野开阔，天南子在石缝中生长。但石台周围有毒瘴弥漫，采集困难

采集天南子必须在晴朗的夜晚进行——白天采摘的果实药力只有夜晚的一半。采摘时需以玉剪剪断果柄，不可用手拉扯——手温会灼伤果实，使其药力流失。

## 相关典故

上古时期，有一位星官名"南正"，掌管南天星象。南正观测星象万年，发现南天星座中有一颗暗星——它不发光，却影响着周围七颗亮星的运行轨迹。

南正以毕生心血推演这颗暗星的奥秘，却始终不得其解。临终前，他将自己的神识融入南天星座，化为一颗种子落入人间。

种子在一座高山顶上生根发芽，长出了一株矮小的灌木——天南子。天南子的八颗果实，正是南正对南天星座的理解——七颗亮星代表已知的知识，一颗暗星代表未知的奥秘。

第一位发现天南子的是一位苦行僧。他在山顶打坐时，看到一株灌木在星光下发出微弱紫光。他摘下一颗果实服下，当晚便进入了"星悟"状态——他看到了南天星座的运行规律，悟出了一套推演功法。

此功法名为"南天推演术"，可预测天象变化、推算吉凶祸福。苦行僧以此术行走天下，救人无数，最终功德圆满，飞升而去。

修真界至今仍流传着一句话："天南子，南正魂。服一颗，悟星辰。"修炼推演类功法的修士，在参悟前都会先服一颗天南子，以"星悟"状态推演天机。
