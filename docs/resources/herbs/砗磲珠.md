# 砗磲珠（五阶灵药）

## 外观

砗磲珠非草木灵药，乃深海万年砗磲所产之珠。其形如卵，大小不一——小的如黄豆，大的如鸽卵，通体洁白如凝脂，表面有细密的螺旋纹路，如同大海的波浪被凝固在珠中。

其质地温润如玉，入手清凉——冬日握之不冰，夏日握之不热，四季恒温。以手摩擦会产生一种特殊的静电，可吸引细小的纸屑或灰尘。

最奇在其"呼吸"。砗磲珠虽为死物，却有生命——珠子会缓慢地起伏，一呼一吸之间间隔约一炷香时间。呼气时，珠子释放出一缕清香；吸气时，周围的灵气被吸入珠中。

砗磲珠有一异象——在月光下，砗磲珠会发出柔和的银白色荧光，如同一轮微缩的明月。此荧光可照亮方圆一丈，在海底极为醒目。

其气清淡如海水，闻之令人感到心神宁静、如同置身于海底世界。

## 药性

- **性味**：性寒，味甘咸，入口如含海水
- **五行**：纯水属性，蕴含海洋精华
- **归经**：入心经（心主神明）、肾经（肾主水）
- **毒性**：无毒，药性温和
- **禁忌**：脾胃虚寒者慎用；孕妇忌用

## 功效

砗磲珠可安神定魄、美容养颜，乃女修梦寐以求的至宝。

- **安神定魄**（核心功效）：砗磲珠能安抚心神——修士因修炼过度导致的心悸失眠、心神不宁，以砗磲珠粉末冲服，可在一个时辰内安神定魄，进入深度睡眠。
- **美容养颜**：砗磲珠粉末是美容圣品——女修以之敷面，可令肌肤如玉般莹润、细滑如脂。长期服用砗磲珠粉末，可令容颜衰老速度减半。
- **砗磲安神丹**（五阶丹药）：以砗磲珠为主药，配伍珍珠粉、琥珀、酸枣仁炼制。服后可进入深度冥想状态，神识恢复速度提升三倍。
- **明目消翳**：砗磲珠粉末点眼，可消除眼睛中的翳障——修士因修炼不当或外伤导致的视力下降，以之点眼可在七日内恢复视力。
- **服用感受**：入腹后感到一股清凉之力从丹田向头部扩散，随后会感到紧绷的神经逐渐放松，心悸感消失，心境如平静的湖面。

## 产地

砗磲珠只产于深海万年砗磲体内——需满足三个条件：其一，砗磲年龄至少万年；其二，水深至少千丈，水压极大；其三，海底有灵脉经过，提供灵气。

已知产地：
- **南海·万丈海沟**：南海最深的海沟，水深万丈，海沟底部有万年砗磲栖息。砗磲珠在砗磲体内形成，但海沟底部水压极大，非元婴修士不可下潜
- **东海·龙宫秘境**：东海龙宫的秘境中有一片砗磲林，砗磲珠品质最佳。但龙宫秘境非龙族不得入
- **西海·珊瑚海**：西海有一片广袤的珊瑚礁海域，砗磲在珊瑚礁中栖息，砗磲珠时有发现。但海域中有海兽守护，采集困难

采集砗磲珠需以法宝级别的利器剖开砗开砗磲——砗磲壳坚硬如铁，普通法器无法伤其分毫。采集后须立即以灵泉水浸泡，否则砗磲珠会因失水而开裂。

## 相关典故

上古时期，龙宫有一位公主名"砗磲"，生性善良，最爱在海底嬉戏。一日，海底火山爆发，滚烫的岩浆涌入龙宫，砗磲公主为救龙宫，以自身灵力封堵岩浆，最终力竭而亡。

她的身体化为无数砗磲珠，在海底继续散发柔和的光芒。从此，海底的砗磲珠便有了灵性——砗磲珠能安神定魄，据说就是因为砗磲公主生前拥有一颗宁静的心。

第一位发现砗磲珠妙用的是一位渔夫。他在海底捞到一颗洁白的珠子，回家后放在床头。当晚，他多年不愈的心悸失眠竟然奇迹般好转。

渔夫大喜，将砗磲珠献给当地的修士。修士认出此乃灵药，以之炼成砗磲安神丹，治好了无数心悸失眠患者。

此事传开后，砗磲珠从海底的装饰品变成了修真界治疗心悸失眠的圣药。

修真界至今仍流传着一句话："砗磲珠，龙女魂。安神定魄，万年深。"医修在治疗心悸失眠时，都会优先考虑砗磲珠——因为它药性温和，效果显著，且无任何副作用。

女修们更是将砗磲珠视为美容养颜的至宝——以砗磲珠粉末敷面，可令肌肤如玉般莹润。一颗砗磲珠在坊市中的售价高达数万中品灵石，且常年供不应求。
