# 冰心草（地阶中品）

## 外观

冰心草生于万年寒冰裂缝之中，与冰雪同色，极难辨识。其形如兰草，叶片细长如剑，丛生如簇，每簇七至九叶，叶色冰蓝半透明，内有白色脉络如冻住的血管。

最奇在其草心。每簇冰心草中央，有一根细如发丝的冰晶柱，高约寸许，顶端凝结一颗米粒大小的冰珠——此乃冰心草精华所聚，称为"冰心"。冰珠触手不化，却寒彻骨髓，握持超过三息，手指便会失去知觉。

冰心草无花无果，繁衍靠根系分裂。其根系在冰层中蔓延数丈，每到一处便萌发新株，形成一片冰心草草丛。在冰层中远望，如同一块块蓝色宝石镶嵌在冰块之中。

其气清冽如薄荷，却比薄荷更寒百倍——闻之如吞冰雪，鼻腔和肺部一阵刺痛，随即头脑变得异常清醒，杂念全消。

## 药性

- **性味**：性极寒，味淡如冰水，入口无感，片刻后寒意才从舌根蔓延
- **五行**：纯水属性，兼带一丝金气——金生水，寒上加寒
- **归经**：入心经（心主神明，冰心草专清心火）、肺经
- **毒性**：无毒，但寒性极重。体质虚寒者服用会导致体温骤降，严重者心跳停止
- **禁忌**：脾肾阳虚者绝对禁用；服用期间不可同时服用任何热性药物

## 功效

冰心草专克心魔燥火，乃闭关突破时护道圣品。

- **冰心镇魔丹**（地阶中品）：以冰心草草心冰珠为主药，配以雪莲子、清心莲、玄冰玉液炼制。闭关突破前含服一颗，可在体内形成一层"冰心护罩"，护住灵台清明。心魔入侵时，冰心护罩会自动释放寒气，将心魔冻散。据修真界统计，服用冰心镇魔丹后渡心魔劫的成功率可提升四成。
- **清心诀辅助**：修炼清心类功法时，在冰心草旁打坐，可令功法修炼速度提升两倍。
- **走火入魔急救**：修士走火入魔、体内真火暴走时，将冰心草草心冰珠塞入口中，可在三个时辰内平息体内燥火——但代价是此后三个月内修为无法寸进。
- **服用感受**：冰珠入腹，一股极致的寒意从丹田升起，如坠冰窟。但奇妙的是，这种寒冷并不令人痛苦，反而感到前所未有的清醒——思维如冰面般平滑，杂念如雪花般消融。

## 产地

冰心草只生长在万年寒冰的裂缝中——需满足三个条件：其一，冰层年龄至少万年；其二、冰层中有细微裂缝，水汽可在裂缝中循环；其三，冰层下方有灵脉经过，提供微弱灵气。

已知产地：
- **北极冰原·万载冰缝带**：冰原深处有一条绵延百里的冰缝带，宽不过尺，深达千丈，缝壁两侧长满冰心草。此地寒气之烈，金丹修士无防护待不过一炷香
- **昆仑山·寒冰涧**：昆仑山脉深处的一处冰涧，涧底有灵脉经过，冰心草在冰壁上丛生。但涧底同时栖息着冰魄寒蟾，其修为堪比元婴修士
- **北冥深渊·冰晶洞**：北冥深渊底部有一处天然冰晶洞，洞内冰心草品质最佳，但深渊中水压极大，非化神修士不可深入

采集冰心草必须以玉钳夹取，不可用手触碰——皮肤触碰冰心草会瞬间粘住，撕下一层皮来。采集后须立即放入寒玉盒中保存，否则草心冰珠会在一个时辰内融化。
