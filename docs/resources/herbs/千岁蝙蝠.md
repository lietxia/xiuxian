# 千岁蝙蝠（四阶灵药·活物灵药）

## 外观

千岁蝙蝠非草木灵药，乃活物成精。其形如寻常蝙蝠，却大如鹰隼，双翼展开可达丈余。通体漆黑如墨，唯有翼膜呈半透明状，在月光下可见翼膜内有银色纹路流转，如同一张微缩的星图。

其眼浑圆，色作赤红，在黑暗中发出幽幽红光，如两盏鬼灯。千岁蝙蝠目不能视物——它们的眼睛早已退化，全靠超声波感知世界。但那双红眼并非摆设，而是能释放一种特殊的精神波动，令对视者产生短暂的眩晕。

其粪粒粒如珠，色黑油亮，称为"夜明砂"——攒之如豆大，气味腥臭刺鼻，却在黑暗中发出微弱荧光。

千岁蝙蝠最珍贵者在其翼膜。翼膜薄如蝉翼，却坚韧如钢丝，且天然具备隐匿气息的功效——将翼膜覆于身上，可屏蔽元婴期以下修士的神识探查。

其声尖锐刺耳，超出人耳听觉范围，但能以神识感知——千岁蝙蝠以超声波互相交流，频率之高，连元婴修士都觉得刺耳。

## 药性

- **性味**：性寒，味咸腥，入口如嚼生肉
- **五行**：偏水金二行——水主隐匿，金主肃杀，金水相生故其性阴寒
- **归经**：入肝经（肝开窍于目）、肾经
- **毒性**：活物本身无毒，但其血液直接服用会导致暂时性失明——需以特殊手法炼制后方可入药
- **禁忌**：孕妇忌用；气血两虚者慎用；不可与热性药物同服

## 功效

千岁蝙蝠全身皆宝，乃修真界最实用的活物灵药之一。

- **翼膜隐身衣**（核心用途）：以千岁蝙蝠翼膜为主材，配合隐匿类阵法，可炼制"蝙蝠翼衣"。穿上后可在元婴期以下修士面前完全隐身——不仅视觉隐匿，连气息和声音都会被屏蔽。
- **夜明砂明目丹**（四阶丹药）：千岁蝙蝠粪便（夜明砂）配伍决明子、菊花、枸杞，可炼夜明砂明目丹。服后获得永久夜视能力，黑暗中视物如白昼。
- **蝙蝠血通脉散**：千岁蝙蝠血液以灵酒稀释后服用，可疏通眼部经脉，治愈一切眼疾——近视、远视、青光眼、白内障，无有不愈。
- **超声波探测**：以千岁蝙蝠翼膜炼制的法器，可发出超声波探测周围环境——在浓雾、密室、地下等视觉受限环境中极为实用。
- **服用感受**：蝙蝠血入腹，一股凉意直冲双目，随后双目会短暂失明约一炷香时间。恢复视力后，会发现视野变得异常清晰——能看清百丈外蚊虫的翅膀纹路。

## 产地

千岁蝙蝠只生活在极深极暗的洞穴中——需满足三个条件：其一，洞穴深度至少千丈，终年不见阳光；其二，洞内有地下暗河，提供充足湿气；其三，洞内有大量普通蝙蝠栖息，千岁蝙蝠以普通蝙蝠的粪便为食。

已知产地：
- **幽冥洞**：中州最大的一处地下洞穴系统，深达万丈，洞内栖息着数以百万计的蝙蝠。千岁蝙蝠在洞穴最深处，与蝙蝠群共生。但洞内阴气极重，且有鬼物游荡
- **南疆万蝠洞**：南疆十万大山深处的一处溶洞，洞内蝙蝠数量之多，飞起来遮天蔽日。千岁蝙蝠在洞顶倒挂，与普通蝙蝠混居，极难辨识
- **东海海底洞穴**：海底深处有一处天然洞穴，洞内无海水侵入，千岁蝙蝠在此栖息。但洞穴入口在水下千丈，非元婴修士不可入

捕捉千岁蝙蝠极为困难——它们听觉敏锐，能感知百丈内的任何声响，且飞行速度极快，在洞穴中穿梭如风。唯一的办法是以"引蝠香"（以蝙蝠粪便和腐肉制成的香料）引诱其前来，再以特制的金丝网捕捉。

更麻烦的是，千岁蝙蝠在洞穴中往往成群结队——一只受惊，万只起飞，形成"蝙蝠风暴"，将入侵者淹没。

## 配伍建议

**最佳配伍**：
- 千岁蝙蝠翼膜 + 隐匿阵法 + 天蚕丝 → 蝙蝠翼衣
- 夜明砂 + 决明子 + 菊花 → 夜明砂明目丹
- 蝙蝠血 + 灵酒 + 枸杞 → 蝙蝠通脉散

**禁忌配伍**：
- 千岁蝙蝠 + 任何光属性灵药 → 药性相克，隐身效果全失
- 千岁蝙蝠 + 大蒜 → 大蒜气味会刺激蝙蝠躁动，无法捕捉

## 相关典故

上古时期，有一位盗圣名"夜无影"，以偷盗各大宗门宝库闻名。他的盗窃手段并非高深法术，而是一件以千岁蝙蝠翼膜炼制的隐身衣。

夜无影凭借此衣，偷遍天下无敌手——他潜入昆仑派藏宝库，取走镇派之宝"昆仑镜"；他潜入天机阁禁地，偷看天机阁镇阁功法；他甚至潜入过龙族的宝库，偷走了一枚龙蛋。

各大宗门悬赏百万灵石捉拿夜无影，却连他的影子都找不到。

最终，夜无影栽在了一个小小的失误上——他在偷盗合欢宗时，身上沾合欢宗特有的"迷情香"。此香与千岁蝙蝠翼膜发生反应，使隐身衣短暂失效了一息时间。

就这一息，被合欢宗宗主发现了。宗主一掌将夜无影从隐身状态中震出，擒获。

夜无影被押上审判台时，笑着说："我偷了一辈子，最后败给了一味香料。天意啊。"

他的隐身衣被合欢宗收藏，至今仍是镇宗之宝。而夜无影本人则被合欢宗囚禁，被迫教授隐匿之术——当然，是在重重禁制之下。

修真界至今仍流传着一句话："千岁蝙蝠一张衣，偷天换日无人知。唯有迷情香一息，盗圣从此入牢笼。"
