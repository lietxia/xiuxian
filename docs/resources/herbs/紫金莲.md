# 紫金莲（地阶上品）

## 外观

紫金莲生于灵泉之眼——即灵泉水从地底涌出之处，以泉水纯净灵力为养分。其莲叶大如圆盘，色作深紫，叶脉呈现出金色的纹路，阳光下熠熠生辉。莲花绽放时呈紫金之色，花瓣尖端有一抹淡金，雍容华贵。

紫金莲最珍贵者不在花，而在莲蓬中的莲子。莲蓬宛如紫金铸就，内含九颗莲子，每颗莲子大小如龙眼，外壳紫黑发亮，内里却洁白如雪。剥开莲子外壳，会闻到一股清幽的莲香，闻之令人心旷神怡。

有趣的是，紫金莲的花瓣会随昼夜变化而开合。白日舒展如伞盖，夜间则收拢如含苞。收拢之时花瓣边缘会散发微弱的紫金色光芒，在夜色中宛如一盏琉璃灯。

## 药性

- **性味**：性平微凉，味甘香
- **五行**：水木双属性，水主滋润，木主生机
- **毒性**：无毒。莲子芯（即莲子中的绿芽）微苦，有小毒，须去芯后方可入药

## 功效

紫金莲以安神定魄、稳固神魂著称，是修真界修炼神识相关功法的修士必备灵药。

- 紫金莲子服之可安神定魄，对心魔侵扰、神魂不稳有奇效
- 长期服用可壮大神识，使精神力更为凝练
- 可炼 **紫金定神丹**，突破境界时服用可保灵台清明，不被心魔所趁
- 可炼 **莲心清魂汤**，治疗神魂受创、失魂落魄之症
- 莲叶晒干可泡茶，有养颜美容之效——女修尤为喜爱
- 莲藕更是珍贵，千年紫金莲的藕节可用于炼制分身之法宝材料

## 产地

紫金莲只生长在灵泉之眼上。所谓灵泉之眼，是地下水脉汇聚的灵气最为浓郁之处，泉水常年不断，水温冬暖夏凉，水质甘甜清冽。

已知的紫金莲产地不多：武夷山脉的碧水灵泉、蜀中的龙泉眼、东海修行世家"紫府"的祖传灵泉。其中以紫府家的紫金莲最为有名——据说他们家族名称就源于此莲。

采集紫金莲的难度不在于守护妖兽（灵泉周围很少有凶兽），而在于移栽。紫金莲离开灵泉之眼后，必须在三个时辰内以灵玉盒封存，否则莲子的灵力会迅速流失，变成一颗普通的莲子——虽然还能吃，但已无药效。

## 年份与药效

- **百年紫金莲**：莲子如龙眼大小，可安神，对筑基修士有效
- **五百年紫金莲**：莲子大如鸽卵，可炼定神丹，对金丹修士有显著效果
- **千年紫金莲**：莲子外壳呈暗金色，内里洁白如玉，药力极为温和醇厚，对元婴修士的神魂稳固大有帮助
- **三千年紫金莲**：传说莲子会由白色转为淡金色，称为"金莲子"，服之可令神识化为实质，万里之内一念可达

## 相关典故

在修真界，紫金莲与"情"字颇有渊源。

传说有一对散修道侣，男修修炼的是刚猛霸道的雷法，女修修炼的则是阴柔的水系功法。两人功法相克，双修之时常常互伤经脉。后来女修偶然得到一颗千年紫金莲子，服下后神魂稳固，居然能够以柔克刚，将两人的灵力完美调和。

从此两人双修再无阻碍，合创了一门阴阳双修功法，名为"莲雷诀"，在修真界传为佳话。

另有一个凄美的说法：紫金莲之所以有安神定魄之效，是因为莲根深扎灵泉之眼，千年万载一动不动，象征着"坚定不移"。修士服用此莲，便是借了莲的这份坚定，来稳固自己摇摇欲坠的神魂。
