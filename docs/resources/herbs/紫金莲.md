# 紫金莲（地阶上品）

## 外观

紫金莲生于灵泉之眼——即灵泉水从地底涌出之处，以泉水纯净灵力为养分。其莲叶大如圆盘，色作深紫，叶脉呈现出金色的纹路，阳光下熠熠生辉。莲叶表面并非光滑，而是布满细密的凸起，如同满天星斗，用手触摸有微微的颗粒感。

莲花绽放时呈紫金之色，花瓣尖端有一抹淡金，雍容华贵。花瓣质地厚重如绸缎，层层叠叠包裹着中心的莲蓬。每片花瓣内侧都有天然形成的金色纹路，纹路的走向各不相同，细看之下宛如一幅微型的阵图。有阵法大师曾以紫金莲花瓣上的纹路为灵感，创出了一套"紫金锁魂阵"，专门用于稳固神魂。

紫金莲最珍贵者不在花，而在莲蓬中的莲子。莲蓬宛如紫金铸就，在阳光下反射出金属般的光泽，内含九颗莲子，每颗莲子大小如龙眼，外壳紫黑发亮，内里却洁白如雪。剥开莲子外壳，会闻到一股清幽的莲香，闻之令人心旷神怡。莲子的口感极佳，生食脆嫩甘甜，熟食绵软香糯。

有趣的是，紫金莲的花瓣会随昼夜变化而开合。白日舒展如伞盖，夜间则收拢如含苞。收拢之时花瓣边缘会散发微弱的紫金色光芒，在夜色中宛如一盏琉璃灯。若在月圆之夜，这光芒会增强数倍，照亮整片灵泉水面。

紫金莲还有一种罕见的变异品种——"墨玉紫金莲"。其通体漆黑如墨，唯有花瓣尖端的一抹金色在黑暗中格外醒目。墨玉紫金莲的药效是普通紫金莲的三倍，尤其对神魂方面的治疗效果更为显著，十万株中未必能出一株。

## 药性

- **性味**：性平微凉，味甘香，回味清甜不带苦涩
- **五行**：水木双属性，水主滋润，木主生机。水木相生，故药性温和绵长，不伤根基
- **归经**：入心经、肾经。心主神明，肾主藏精，故紫金莲能安神固精
- **毒性**：无毒。莲子芯（即莲子中的绿芽）微苦，有小毒，须去芯后方可入药。莲子芯晒干后单独泡茶，有清心降火之效，但不可多饮
- **禁忌**：外感风寒者慎用；痰湿壅盛者不宜多服；服用紫金定神丹期间忌饮酒、忌行房事
- **互补说明**：紫金莲虽然品阶为地阶上品，在安神定魄方面的效果不输于许多天阶灵药。正因为它专精一道，反而比许多高品阶的万金油灵药更有价值

## 功效

紫金莲以安神定魄、稳固神魂著称，是修真界修炼神识相关功法的修士必备灵药。

- **直接服用**：紫金莲子服之可安神定魄，对心魔侵扰、神魂不稳有奇效。生食一颗，清凉之意直透眉心泥丸宫，原本躁动的神魂会如被母亲轻抚的婴儿般安静下来。长期服用可壮大神识，使精神力更为凝练，感知范围逐步扩大。
- **紫金定神丹**（地阶上品丹方）：以紫金莲子为主药，配以安魂草、定神香、千年茯苓。突破境界时服用可保灵台清明，不被心魔所趁。对于冲击金丹、元婴等大境界的修士来说，此丹几乎是标配。据修真界统计，服用紫金定神丹后渡心魔劫的成功率可提升四到五成。
- **莲心清魂汤**（地阶中品）：紫金莲子去芯、莲叶晒干、莲须阴干，三味同煮。治疗神魂受创、失魂落魄之症。有修士被魔道搜魂术所伤，神魂破碎，喝此汤三年后竟然恢复如初。因此汤药性温和，可以长期服用。
- **紫金莲叶茶**：莲叶晒干后切丝泡茶，有养颜美容之效——女修尤为喜爱。长期饮用可令面色红润、肌肤细腻。莲叶茶还兼有安神助眠的效用，适合修炼过度导致失眠的修士。
- **莲藕炼器**：莲藕更是珍贵，千年紫金莲的藕节质地如玉，内含天然的聚灵纹理。可用于炼制分身之法宝材料——以紫金莲藕炼制的身外化身，与本体的契合度远高于普通材料。紫金莲的藕丝坚韧无比，可编织成内甲，穿上后能抵御神识攻击。
- **紫金香囊**：将干紫金莲花瓣装入香囊随身佩戴，可防止低阶心魔入侵。许多大宗门的弟子在出外历练时都会备一个。

## 产地

紫金莲只生长在灵泉之眼上。所谓灵泉之眼，是地下水脉汇聚的灵气最为浓郁之处，泉水常年不断，水温冬暖夏凉，水质甘甜清冽。

已知的紫金莲产地：

- **武夷山脉·碧水灵泉**：武夷山深处的一口灵泉，水质清冽，富含铁质，因此这里的紫金莲颜色偏深，紫色近乎墨色，药效也更为厚重。由武夷剑派守护。
- **蜀中·龙泉眼**：位于峨眉山下的一处泉眼，传说曾有真龙在此饮水，故而得名。此地紫金莲莲藕最为粗壮，是炼制分身法宝的首选材料。峨眉派女修常以紫金莲入药养颜。
- **紫府世家·祖传灵泉**：东海修行世家"紫府"的祖地之中有一口传承万年的灵泉——据说他们家族名称就源于此莲。紫府家的紫金莲品质最佳，数千年来从未断过。紫府家规：紫金莲不外卖只交换，想要紫金莲，必须拿出同等价值的功法或法宝来换。
- **天池秘境**：一座漂浮在空中的秘境，中央有一口悬空灵泉，紫金莲在其中生长。秘境每三百年开启一次，每次只开放七日，能够在里面采到多少紫金莲全凭机缘。

采集紫金莲的难度不在于守护妖兽（灵泉周围很少有凶兽），而在于移栽。紫金莲离开灵泉之眼后，必须在三个时辰内以灵玉盒封存，否则莲子的灵力会迅速流失，变成一颗普通的莲子——虽然还能吃，但已无药效。因此远距离运输紫金莲非常困难，这也导致了各地紫金莲各具特色，难以流通。

莲藕的采集更为讲究：必须在冬季灵泉枯水期，将藕节完整挖出，不能有丝毫损伤。一旦断了一截，藕中的灵液会瞬间流失，整段藕便报废了。

## 年份与药效

- **百年紫金莲**：莲子如龙眼大小，外壳紫黑有光泽。可安神，对筑基修士有效，市价约五百中品灵石。
- **三百年紫金莲**：莲子大如鸽卵，外壳出现金色斑点。药力比百年强三倍，对金丹初期修士有效，市价约一千五百中品灵石。
- **五百年紫金莲**：莲叶已完全变为深紫，金色叶脉愈发清晰。可炼紫金定神丹，对金丹修士有显著效果，市价约五千中品灵石。
- **千年紫金莲**：莲子外壳呈暗金色，内里洁白如玉，药力极为温和醇厚。对元婴修士的神魂稳固大有帮助，市价两万中品灵石以上。千年紫金莲的藕节已经可以作为炼制分身的材料。
- **三千年紫金莲**：传说莲子会由白色转为淡金色，称为"金莲子"，外壳上天然浮现出"卍"字纹或莲花纹。服之可令神识化为实质，万里之内一念可达——神识所及之处，如同亲临。紫府家有一枚三千年金莲子，被当作传家之宝。

## 相关典故

在修真界，紫金莲与"情"字颇有渊源。

传说有一对散修道侣，男修修炼的是刚猛霸道的雷法，女修修炼的则是阴柔的水系功法。两人功法相克，双修之时常常互伤经脉。后来女修偶然得到一颗千年紫金莲子，服下后神魂稳固，居然能够以柔克刚，将两人的灵力完美调和。

从此两人双修再无阻碍，合创了一门阴阳双修功法，名为"莲雷诀"，在修真界传为佳话。

另有一个凄美的说法：紫金莲之所以有安神定魄之效，是因为莲根深扎灵泉之眼，千年万载一动不动，象征着"坚定不移"。修士服用此莲，便是借了莲的这份坚定，来稳固自己摇摇欲坠的神魂。

还有一个关于紫府世家的故事：紫府家的开山老祖，本是一个资质平平的散修，因缘际会在一口灵泉旁发现了一株变异紫金莲——墨玉紫金莲。他服下莲子后，原本驳杂的灵根被洗涤纯净，从此修行一日千里，最终开创了紫府家业。他临终前留下遗嘱：紫金莲是紫府家的立家之本，后代子孙无论兴衰，都不得弃莲而去。紫府家恪守此训数千年，哪怕家族最衰落的时期，也没有变卖过一颗祖传灵泉中的紫金莲。这份坚守，大概正是紫金莲"坚定不移"之精神的传承吧。

明代有位游方道士曾路过紫府家，在灵泉旁题了一首诗，至今仍刻在泉边的石碑上："紫金莲开灵泉中，花叶千年不改容。修士若能如此意，何愁大道不成功。"诗虽浅白，道理却深。
