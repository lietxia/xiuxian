# 灵芝（天阶上品·仙草之首）

## 外观

灵芝，仙草之首，万药之灵。其形如伞盖，菌盖半圆形，质地木质化，表面有环状棱纹和辐射状皱纹，如同大地的年轮。

百年灵芝呈赤红色，菌盖如铜钱大小，散发淡淡清香。千年灵芝呈紫红色，菌盖如碗口大小，表面有金色纹路流转，菌盖边缘有一圈金色光晕。万年灵芝则通体晶莹如玉，菌盖如磨盘大小，内有五色光华流转，菌盖上方会形成一圈七彩光晕，持续不散。

最奇在其"呼吸"。灵芝虽为菌类，却有生命——菌盖会缓慢地起伏，一呼一吸之间间隔约一炷香时间。呼气时，菌盖释放出一缕清香；吸气时，周围的灵气被吸入菌盖之中。

万年灵芝已通灵化形——它会在夜间从菌盖中释放出一个半透明的"灵体"，形如婴儿，在菌盖上方嬉戏玩耍。灵体持续一个时辰后复归菌盖之中。此乃灵芝的"元神"，万年修为所化。

其气清香幽远，闻之令人心神安宁、百脉通畅。万年灵芝的香气可传百里，在香气范围内修炼，速度提升三成。

## 药性

- **性味**：性平，味甘，入口如嚼檀香
- **五行**：五行俱全——灵芝乃天地灵气孕育，五行均衡，无偏无倚
- **归经**：入五脏六腑，通行十二正经、奇经八脉
- **毒性**：无毒，药性温和绵久，乃最安全的滋补圣品
- **禁忌**：外感实邪未解时不宜服用——灵芝补益，实邪未解时补益会闭门留寇

## 功效

灵芝可起死回生、脱胎换骨，乃修真界至高无上的仙草。

- **起死回生**（核心功效）：修士只要还有一口气在，以万年灵芝煎水喂服，可在三个时辰内稳定伤势，在七日内恢复元气。若配合其他灵药，甚至可令断肢重生。
- **脱胎换骨**：长期服用灵芝，可逐渐改善体质——灵根品质提升、经脉拓宽、骨骼强化。此过程缓慢但效果惊人，服用万年灵芝百年，可令资质平庸者变为天才。
- **增寿元**：百年灵芝增寿十年，千年灵芝增寿百年，万年灵芝增寿千年。
- **灵芝还魂丹**（天阶上品）：以万年灵芝为主药，配合九叶灵芝、人参娃娃精血、龙血参炼制。服后可起死回生，哪怕魂魄离体七日，亦可召回。
- **服用感受**：入腹后感到一股温润之气从丹田缓缓扩散至四肢百骸，如同一双温暖的大手在按摩全身。药力可持续四十九日，期间修炼速度提升三成，且不会走火入魔。

## 产地

灵芝生于灵气浓郁的山林深处——需满足三个条件：其一，树龄千年以上的古木根部或树干上；其二，灵气浓度达到五阶灵脉以上；其三，周围环境清幽，无人打扰。

已知产地：
- **昆仑山·灵芝谷**：昆仑山脉深处的一处山谷，谷中古木参天，灵气浓郁如雾。谷中灵芝遍布，年份从百年到万年不等。但谷中有上古禁制，非有缘者不可入
- **南疆·万年林**：南疆十万最深处的一片原始森林，林中古木皆有数万年树龄，灵芝在古木根部茂盛生长。但林中妖兽横行，非元婴修士不可深入
- **东海·蓬莱仙岛**：蓬莱仙岛有一处灵芝园，园内灵芝皆为仙品，年份动辄数万年。但蓬莱仙岛隐于云雾之中，非大机缘不可寻

采集灵芝不可使用金属工具——金克木，金属触碰会使灵芝瞬间枯萎。必须以玉刀沿菌盖边缘切割，连同一部分古木一并取出。

万年灵芝已通灵，采集时需先以灵识与其沟通，获得其认可后方可采摘。若强行采摘，万年灵芝会自毁——菌盖碎裂，药力散逸，化为凡草。

## 相关典故

上古时期，有一位仙草名"芝女"，乃万年灵芝化形而成。芝女容貌绝世，心地善良，常化为白衣女子在人间行走，治病救人。

一日，芝女遇到一位垂死的少年——少年被妖兽所伤，五脏俱碎，魂魄将散。芝女不忍，割下自己的一片菌盖，捣烂喂给少年。

少年服后，五脏重续，魂魄归位，不仅活了下来，更因灵芝药力洗髓伐骨，从一介凡人变为天灵根修士。

少年感激涕零，问芝女："仙子救命之恩，何以为报？"

芝女微笑："我只要你做一件事——日后你若遇到需要帮助的人，便伸出援手，如同我今日帮你一样。"

少年点头，从此行走天下，救人无数。他后来成为一代仙尊，创立了"灵芝宗"，以灵芝为镇宗之宝，传承万年。

而芝女则在救少年后，因损耗了太多修为，重新化为菌盖，在古木上沉睡了万年。据说她至今仍在沉睡，等待有缘人将她唤醒。

修真界至今仍流传着一句话："灵芝仙草，起死回生。割肉救人，功德无量。"医修在救治重伤修士时，都会先焚香祭拜芝女——纪念那位割肉救人的灵芝仙子。
