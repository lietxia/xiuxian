# 玛瑙角（六阶灵材）

## 外观

玛瑙角非草木之属，乃妖兽之角经千年地气滋养石化而成。其形如弯月，长约半尺至一尺不等，通体呈赤红与琥珀金交织，光滑如镜，纹理如水波流转。以指尖轻叩，声如编钟，余韵悠长。

最奇者，玛瑙角内部有丝丝缕缕的血色纹路如血管分布——此乃妖兽角髓之残留。千年石化过程中角髓与石质融合，形成独特的"血丝玛瑙"纹理。对光细观，可见红光流转，仿佛角中仍有生命。

玛瑙角散发的不是草木清香，而是一股淡淡的腥甜之气——妖兽本源精气之味。低阶修士闻之气血翻涌，如被猛兽盯视；高阶修士则能从中分辨出妖兽生前的种族与修为。每一支玛瑙角的形状、纹理皆不相同，取决于妖兽种类、修为及石化环境。

## 药性

- **性味**：性温燥，味辛甘，略带腥气
- **五行**：偏土金二行——土主中和，金主收敛
- **归经**：入肝经、肾经，兼入奇经八脉
- **毒素**：含微弱妖兽精魄残念。未经处理直接使用，可能诱发心魔。炼丹前需以灵泉水浸泡七七四十九日方可祛除
- **禁忌**：心性不坚者慎用；与安神类药物同用需谨慎调配，否则反引心魔

## 功效

玛瑙角非提升修为之药，其真正价值在于"调和"与"稳固"。

- **九曲灵参丹辅药**（六阶丹方）：九曲灵参药力磅礴，九曲道韵各异。若无玛瑙角调和，九股药力互不相容，服之轻则经脉错乱，重则当场爆体。玛瑙角的金行收敛之性恰可镇住散逸之力，使药力凝聚归一。
- **玛瑙镇魂散**（五阶药方）：玛瑙角磨粉配安神花、百年莲子心炼制成散。元婴修士渡心魔劫时含服一钱，可固守本心不失。
- **角灵续骨膏**（五阶药方）：玛瑙角粉末混合千年石钟乳、玉蜂蜜调制成膏。涂抹断骨处，一个时辰内续接断骨，愈合后骨骼更为坚韧。
- **玛瑙护心佩**：小片玛瑙角打磨成佩饰佩戴于胸前，可在遭遇神魂攻击时自动释放防护光罩，抵挡一次元婴期级别的神魂冲击。

## 产地

玛瑙角需经历"兽死→埋葬→石化"三阶段方可形成：至少金丹期的有角妖兽死亡，其角完好无损；埋葬于富含灵气的土地之下三千年以上，地气浸润使角质石化；角中髓质与地脉灵力融合，最终形成玛瑙角。

已知产地：
- **北疆古战场**：万年前正魔大战之地，埋骨无数。地底时有玛瑙角出土，但部分沾染了煞气，使用时需加倍小心
- **西域地脉溶洞**：地下溶洞中灵脉穿行，地气浓郁，西域矿工开采灵石时偶尔掘出玛瑙角
- **东海妖兽坟场**：深海"葬角渊"海沟，无数妖兽陨落于此。但深海压力极大，非元婴期不敢下潜

鉴别要点：一看纹理，真品纹理自然如水波；二闻气味，真品有妖兽腥甜之气；三试硬度，真品以灵火灼烧不变色。

## 年份与药效

- **千年玛瑙角**：石化未完全，角中髓质尚存三分之一。药效减半，需加倍用量
- **三千年玛瑙角**：石化完成，角体坚硬如玉，血丝纹理清晰。此为市面主流年份
- **五千年玛瑙角**：石化彻底，角质近玉，药力精纯，寻常一半用量即可
- **万年玛瑙角**：已完全玉石化，通体剔透，血丝几不可见。可炼七阶以上丹药，百年难遇

## 相关典故

三百年前，北疆散修"铁角道人"得一奇遇——在古战场遗址中捡到一支八寸长的玛瑙角，血丝密布，至少五千年珍品。此人不识货，竟将玛瑙角磨成粉末每日泡水喝。喝了一月，浑身燥热难耐，夜夜梦见被独角妖兽追杀——正是角中残念作祟。

幸得一位路过的炼丹大师点破，告知正确用法并祛除其体内残念。铁角道人追悔莫及——那支玛瑙角若拍卖至少值三万中品灵石，却被当街边野药糟蹋大半。

铁角道人痛定思痛，拜入大师门下学习丹道，三十年如一，终成四阶炼丹师。每每与人说起此事，皆感慨："天下灵材，各有其用。不知其性而妄用，宝珠蒙尘，悔之晚矣。"
