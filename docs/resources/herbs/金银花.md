# 金银花（二阶灵药）

## 外观

金银花，其名源于其色——花初开时白色，二三日后转为黄色，黄白相映，如金似银。其形如缩小版的喇叭花，花大如铜钱，花细长如管，弯曲如钩，花瓣向外翻卷，形如微缩的龙爪。

其茎细长柔韧，呈暗红色，缠绕于其他植物上生长——金银花是攀援植物，不依附支撑物便无法直立。茎上有细密的绒毛，触摸有轻微的刺痒感。

叶片对生，形如卵形，叶面深绿，叶背淡绿，有细密的绒毛。最奇在其花——金银花总是成对开放，一蒂两花，形如双胞胎，故有"鸳鸯草"之称。

其气清香淡雅，如夏日清晨的茉莉花香——闻之令人感到神清气爽、心情愉悦。金银花的香气可传数十丈远，在金银花丛中待上一炷香时间，便会感到精神为之一振。

金银花有一异象——在雨后，金银花的花瓣上会凝结细密的水珠，在阳光下闪闪发光，如同一颗颗微小的钻石。

## 药性

- **性味**：性寒，味甘，入口清凉
- **五行**：偏金水二行——金主肃降，水主润下，金水相生故能清热
- **归经**：入肺经、心经、胃经
- **毒性**：无毒，药性温和
- **禁忌**：脾胃虚寒者慎用；气虚疮疡脓清者忌用

## 功效

金银花可清热解毒、疏散风热，乃治疗热毒疮疡与风热感冒的常用灵药。

- **清热解毒**（核心功效）：金银花能清除体内热毒——修士因热毒导致的痈疽疮疡、咽喉肿痛，以金银花煎水服用，可在三日内清热解毒。
- **疏散风热**：金银花能疏散风热——修士因风热导致的感冒发热、头痛咳嗽，以金银花煎水服用，可在三日内退热解毒。
- **金银花解毒汤**（二阶药方）：金银花配伍连翘、薄荷、荆芥、甘草，水煎服之。可解一切热毒——痈疽疮疡、风热感冒、瘴气中毒，均有良效。
- **疮疡外敷**：金银花捣烂外敷，可治疗痈疽疮疡——消肿排脓效果显著。
- **服用感受**：入腹清凉舒适，如饮冰镇金银花茶。若有热毒，会感到一股清凉之力从胃部向四肢扩散，所过之处燥热尽消。

## 产地

金银花喜生于温暖湿润、阳光充足的山坡——需满足三个条件：其一，阳光充足，不被遮蔽；其二，土壤排水良好，不可积水；其三，周围有支撑物可供攀爬。

已知产地：
- **中原·金银花坡**：中原有一处山坡，金银花在此成片生长。每年花开时，黄白相映，如同一片金银交织的锦缎
- 东荒·篱笆：东荒的农户常将金银花种植在篱笆旁，让其攀爬生长。既作观赏植物，又作解毒药材
- 南疆·山坡：南疆十万大山的缓坡上，金银花在草丛中生长。但山坡上多毒蛇，采集时需小心

采集金银花须在花初开白色时进行——此时药效最为充沛。采摘时需以剪刀剪取花朵，晒干保存。

## 年份与药效

| 年份 | 特征 | 药效 |
|------|------|------|
| 一年生 | 花朵单朵，白色 | 可治疗普通风热感冒 |
| 三年生 | 花朵数朵，黄白相映 | 可清热解毒，对筑基期修士有效 |
| 十年生 | 花朵数十朵，花香浓郁 | 可炼金银花解毒汤，对金丹期修士有效 |
| 五十年生 | 花朵金银相映，花香浓郁 | 可治疗元婴期修士的热毒疮疡 |
| 百年生 | 整株散发金银色光芒，花朵在阳光下闪闪发光 | 可治疗化神期修士的热毒重症 |

## 配伍建议

**最佳配伍**：
- 金银花 + 连翘 + 薄荷 → 金银花解毒汤
- 金银花 + 甘草 + 桔梗 → 清热解毒汤
- 金银花 + 蒲公英 + 野菊花 → 消肿排脓散

**禁忌配伍**：
- 金银花 + 温补类药物 → 药性相消
- 金银花 + 辛辣食物 → 助长热毒

## 相关典故

上古时期，有一位仙姑名"金银花"，以医术闻名天下。金银花仙姑在昆仑山脚种植了万亩金银花，每年花开时，黄白相映，如同一片金银交织的锦缎。

金银花仙姑活了一千岁，临终前对弟子说："我之所以长寿，全赖每日饮金银花茶。金银花能清热解毒、疏散风热，常饮可延年益寿。"

弟子们依此法每日饮金银花茶，果然个个长寿。此事传开后，金银花从一株普通的野花变成了修真界清热解毒的圣药。

修真界至今仍流传着一句话："金银花，解毒花。常饮之，寿命长。"医修在治疗热毒疮疡时，都会优先考虑金银花——因为它药性温和，价格低廉，且效果显著。

每年夏季金银花盛开时，医修们都会举行"金银花祭典"——采集金银花，晒干泡茶，免费赠送给贫困的修士。这一传统已延续了万年，成为医修界最重要的节日。
