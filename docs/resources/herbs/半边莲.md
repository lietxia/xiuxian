# 半边莲（二阶灵药）

## 外观

半边莲，其名源于其最奇之态——花朵只开半边，另半边永远含苞不放。其形如莲花缩小版，浮生于水田沼泽之中，茎叶细弱，匍匐蔓延，绿叶椭圆如豆，色泽碧绿。

最奇在其花。每朵花只绽开三至五瓣，且全部偏向一侧，另一侧则紧闭合拢，形如一位害羞的少女以袖半遮面。花色淡紫，花蕊洁白，清香淡雅。

其花向阳一侧盛开，背阴一侧含苞——若将植株旋转一百八十度，三日后花朵会重新转向，盛开的一侧再次朝向阳光。此象名曰"追阳"，乃半边莲独有之异象。

其气清淡如薄荷，却比薄荷多了一丝甜意。揉碎叶片，指腹会染上一层淡紫色汁液，三日不褪。

半边莲根茎极细，白色如丝，在水中蔓延数丈，每节皆可生根发芽，形成新的植株。一片沼泽中若有一株半边莲，三年后便会蔓延至整片水域。

## 药性

- **性味**：性凉，味甘淡，入口清凉
- **五行**：偏木水二行——木主疏泄，水主润下，水木相生故能清热解毒
- **归经**：入肺经、肝经，兼走肌表
- **毒性**：无毒，药性温和，乃最安全的解毒灵药之一
- **禁忌**：脾胃虚寒者不宜多服；孕妇慎用

## 功效

半边莲专治蛇虫咬伤与热毒疮疡，乃低阶修士行走江湖必备之解毒良药。

- **解蛇毒**（核心功效）：被毒蛇咬伤后，以半边莲捣烂敷于伤口，可在一个时辰内阻止蛇毒扩散。配合内服半边莲煎剂，可在三个时辰内将蛇毒尽数化解。对蝮蛇、眼镜蛇、银环蛇等常见蛇毒均有效。
- **热毒疮疡**：热毒引起的痈疽疮疡，以半边莲捣烂外敷，可在三日内消肿排脓，七日内愈合。
- **半边莲解毒汤**（二阶药方）：半边莲配伍金银花、甘草、野菊花，水煎服之。可解一切热毒——食物中毒、药物中毒、瘴气中毒，均有良效。
- **利水消肿**：半边莲利水功效显著，修士因灵力运转不当导致的水肿，服之可速消。
- **服用感受**：入腹清凉舒适，如饮冰镇薄荷水。若有热毒在体内，会感到一股凉意从胃部向四肢扩散，所过之处燥热尽消。

## 产地

半边莲喜生于水田、沼泽、溪边湿地——需满足三个条件：其一，水源清洁，不可有污物；其二，土壤肥沃，腐殖质丰富；其三，周围有蛇类栖息——半边莲与蛇类有奇妙的共生关系：蛇类的排泄物为其养料，而半边莲的气味又能驱赶蛇类的天敌。

已知产地：
- **江南水乡**：水田沟渠中随处可见，乃江南地区最常见的野生灵草。当地农户常在田埂上种植半边莲，既作解毒药材，又作观赏植物
- **南疆沼泽**：南疆十万大山的沼泽中，半边莲与毒蛇共生——越是毒蛇密集之处，半边莲越是茂盛。采药人需一边采莲一边防蛇
- **东荒湿地**：东荒沼泽地带，半边莲成片生长，但湿地中多蚊虫毒瘴，采集不易

采集半边莲极为简单——连根拔起即可，无需特殊工具。但需注意：半边莲根系脆弱，拔起时若断裂，残留根节会迅速发芽，来年更加茂盛。故有经验者只采地上部分，保留根系以待来年。

## 年份与药效

| 年份 | 特征 | 药效 |
|------|------|------|
| 一年生 | 茎叶细弱，花仅三瓣 | 可解普通蚊虫叮咬之毒 |
| 三年生 | 茎叶健壮，花五瓣，淡紫色深 | 可解常见蛇毒，外敷疮疡有效 |
| 十年生 | 茎叶粗壮，花七瓣，紫色浓郁 | 可炼半边莲解毒汤，解热毒 |
| 五十年生 | 茎叶泛紫光，花九瓣，花香浓郁 | 可解剧毒之蛇毒，对筑基期修士有效 |
| 百年生 | 整株散发淡紫色荧光，花十二瓣 | 可解金丹期蛇虫之毒，可炼二阶上品解毒丹 |

## 配伍建议

**最佳配伍**：
- 半边莲 + 金银花 + 甘草 → 半边莲解毒汤
- 半边莲 + 野菊花 + 蒲公英 → 热毒疮疡外敷方
- 半边莲 + 七叶一枝花 → 解蛇毒圣品（效果倍增）

**禁忌配伍**：
- 半边莲 + 温补类药物 → 药性相消
- 半边莲 + 寒凉过度之药 → 脾胃受损

## 相关典故

古时，有一位游方郎中名"半仙"，行走江湖数十年，以一手解毒绝技闻名天下。他的解毒秘方从不外传，只知以一味为主药——半边莲。

半仙年轻时曾被毒蛇咬伤，奄奄一息之际，梦见一位白衣女子。女子手持半边莲，捣烂敷于他伤口，蛇毒立解。女子留下一句话："半边莲花半边开，救人不求回报来。你若活命传此方，莫将名利挂心怀。"

半仙醒后果真痊愈，从此以半边莲为药，行走江湖救人无数。他从不收取诊金，只要求被救者种一株半边莲于田埂之上。

数十年后，江南水乡的田埂上处处可见半边莲，成为一道独特的风景。当地百姓称其为"半仙莲"，以纪念这位游方郎中。

半仙百岁而终，临终前将毕生解毒心得写成一本书——《半边莲解毒经》，流传于世。书中第一页写着："半边莲花半边开，救人不求回报来。解毒先须解毒心，莫让名利化尘埃。"

至今，江南水乡的采药人仍流传着一句话："田埂半边莲，毒蛇绕道走。采来救急用，胜似十两金。"
