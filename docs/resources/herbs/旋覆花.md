# 旋覆花（三阶灵药）

## 外观

旋覆花，其名源于其形——花朵形如旋涡，花瓣向内卷曲旋转，如同一朵被卷入漩涡的花。其形如菊，却比菊花小得多，整朵花不过铜钱大小，花色金黄，花瓣细长如发丝，从外向内层层卷曲，最终卷成一个实心的球状。

最奇在其旋转方向——旋覆花的花瓣永远在缓慢旋转，顺时针三圈，逆时针三圈，周而复始，永不停歇。以灵目观之，可见花瓣旋转时带动周围灵气形成微型漩涡，将灵气吸入花心。

其茎细如筷，高约尺余，茎上有细密绒毛，触摸有轻微的刺痒感。叶片互生，形如披针形，叶面深绿，叶背银白色，有细密的绒毛。

旋覆花的花序极为特殊——每根茎顶端开花数十朵，每朵花都向不同的方向旋转，如同一群微缩的陀螺在同时转动。

其气清淡如菊，却比菊多了一丝辛辣——闻之令人鼻黏膜微刺，随后感到胸腔一阵轻松，如同堵塞的气管被疏通。

## 药性

- **性味**：性温，味辛甘，入口微苦后甜
- **五行**：偏金土二行——金主肃降，土主运化，金土相生故能降气化痰
- **归经**：入肺经、胃经、大肠经
- **毒性**：无毒，药性温和
- **禁忌**：阴虚火旺者慎用；气虚下陷者忌用

## 功效

旋覆花可逆转气血、治疗咳喘痰多，乃治疗内伤咳血的特效灵药。

- **降气化痰**（核心功效）：旋覆花能逆转上逆之气——修士因修炼不当导致气机上逆、咳喘不止时，以旋覆花煎水服用，可在一个时辰内平息咳喘，令气机归位。
- **内伤咳血**：因内伤导致的咳血，以旋覆花配伍白芨、阿胶，可在三日内止血，七日内修复受损的肺部经脉。
- **旋覆花汤**（三阶药方）：旋覆花配伍半夏、生姜、大枣、甘草，水煎服之。可治疗一切气机上逆之症——咳喘、呕吐、呃逆、梅核气，均有良效。
- **痰多黏腻**：修士因体内湿气过重导致痰多黏腻、呼吸困难时，服用旋覆花可在三日内化解痰湿。
- **服用感受**：入腹后感到一股温和的力量从胃部向上推动，随后又向下沉降——如同有人在体内帮你把上逆的气机理顺。整个过程持续约一炷香时间，期间会感到胸腔逐渐轻松，呼吸变得顺畅。

## 产地

旋覆花喜生于河岸、路旁、田野等开阔之地——需满足三个条件：其一，土壤疏松排水良好；其二，阳光充足，不被遮蔽；其三，周围有水源但不受水淹。

已知产地：
- **中原河岸**：黄河、长江两岸的河滩地中，旋覆花成片生长。每年秋季花开时，金黄色的旋覆花如同一片金色的地毯铺在河滩上
- **东荒田野**：东荒的农田边缘，旋覆花与农作物共生。当地农户将其视为杂草，却不知其乃灵药
- **南疆山坡**：南疆十万大山的缓坡上，旋覆花在草丛中生长。但山坡上多毒蛇，采集时需小心

采集旋覆花须在花开最盛时（秋季）进行，以剪刀剪取花朵，晒干保存。采摘时需注意——旋覆花的花瓣在旋转，剪刀靠近时会感到一股微弱的旋转力，需用力稳住剪刀方可剪断。

## 年份与药效

| 年份 | 特征 | 药效 |
|------|------|------|
| 一年生 | 花朵单朵，旋转缓慢 | 可治疗普通咳喘 |
| 三年生 | 花朵数朵，旋转明显 | 可降气化痰，对筑基期修士有效 |
| 十年生 | 花朵数十朵，旋转有力 | 可炼旋覆花汤，对金丹期修士有效 |
| 五十年生 | 花朵旋转时带动周围灵气形成可见漩涡 | 可治疗元婴期修士的内伤咳血 |
| 百年生 | 整株散发金色光芒，花朵旋转如微型旋风 | 可逆转化神期修士的上逆气机 |

## 配伍建议

**最佳配伍**：
- 旋覆花 + 半夏 + 生姜 → 旋覆花汤
- 旋覆花 + 白芨 + 阿胶 → 止血散
- 旋覆花 + 桔梗 + 杏仁 → 宣肺化痰汤

**禁忌配伍**：
- 旋覆花 + 升提类药物 → 药性相冲
- 旋覆花 + 收敛固涩类药物 → 药效相消

## 相关典故

上古时期，有一位医圣名"扁鹊"，以医术闻名天下。扁鹊晚年时，遇到一位奇怪的病人——一位修士，咳喘不止，痰中带血，遍访名医无果。

扁鹊诊脉后发现，此修士的气机完全紊乱——本该下降的胃气上逆，本该上升的脾气下陷，气机在体内乱窜，如同无头苍蝇。

扁鹊翻遍医书，最终在一本古籍中找到了旋覆花的记载："旋覆花，花如旋涡，能逆转气机，令上逆者降，令下陷者升。"

扁鹊采来旋覆花，配伍半夏、生姜等药，煎成旋覆花汤让修士服下。三剂之后，修士的咳喘完全消失，气机归位，痰血尽止。

修士感激涕零，问扁鹊："此药如此神奇，为何古籍中记载甚少？"

扁鹊答："旋覆花虽神奇，却只生长在荒野河岸，不似灵芝人参那般生于深山灵脉，故不被修士重视。殊不知，药无贵贱，对症便是良药。"

此事传开后，旋覆花从一株无人问津的野花变成了修真界治疗气机紊乱的圣药。

修真界至今仍流传着一句话："旋覆花，转气机。不问贵贱，对症下药。"医修在治疗气机紊乱时，都会优先考虑旋覆花——因为它药性温和，价格低廉，且效果显著。
