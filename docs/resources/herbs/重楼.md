# 重楼（四阶灵药）

## 外观

重楼，其名源于其形——茎秆一轮一叶，七叶一轮，如同层层叠叠的楼阁。其茎高约尺余，直立如剑，茎上有明显的节，每节一轮叶片，每轮七片叶子，呈星形排列。

叶片椭圆形，长约寸许，叶色深绿，叶面光滑如蜡，叶脉呈放射状。最奇在其"轮生"之态——从下往上，第一轮七叶，第二轮七叶，第三轮七叶……如同微缩的宝塔。

其花单生于茎顶，花形如莲花，花色殷红，花蕊金黄，形如微缩的星辰。花开时，与下方的七轮叶子相映成趣，如同一座微缩的红色宝塔。

根茎粗壮，呈结节状，形如微缩的生姜，表面有环纹——每环代表一年生长。

其气辛辣刺鼻，如硫磺与烈酒混合，闻之双目流泪。但此气于毒修而言却是无上妙香——深吸一口，体内毒功运转速度立增三成。

## 药性

- **性味**：性寒，味苦，入口如吞苦胆
- **五行**：偏火毒二行——火主炎上，毒主杀伐，火毒相合故能清热解毒
- **归经**：入肝经、心经，兼走奇经八脉
- **毒性**：有小毒。直接服用过量会导致腹痛腹泻，须以甘草、金银花等解毒药材配伍
- **禁忌**：脾胃虚寒者忌用；孕妇忌用

## 功效

重楼可清热解毒、消肿止痛，乃治疗痈疽疮疡、毒蛇咬伤的圣品。

- **清热解毒**（核心功效）：重楼能清除体内热毒——修士因热毒导致的痈疽疮疡、咽喉肿痛，以重楼煎水服用，可在三日内清热解毒。
- **消肿止痛**：重楼能消肿止痛——修士因斗法导致的肿胀疼痛，以重楼捣烂外敷，可在一个时辰内消肿止痛。
- **解蛇毒**：重楼是蛇毒的解药——被毒蛇咬伤后，以重楼捣烂敷于伤口，可在一个时辰内阻止蛇毒扩散。
- **重楼解毒汤**（四阶药方）：重楼配伍半边莲、白花蛇舌草、金银花，水煎服之。可解一切热毒——痈疽疮疡、毒蛇咬伤、瘴气中毒，均有良效。
- **服用感受**：入腹清凉舒适，如饮冰镇苦茶。若有热毒，会感到一股清凉之力从胃部向四肢扩散，所过之处燥热尽消。

## 产地

重楼喜生于阴湿的山林下、溪边、灌丛中——需满足三个条件：其一，土壤湿润但不积水；其二，阳光不可直射，需有树荫遮蔽；其三，周围有岩石或灌木遮挡寒风。

已知产地：
- **南疆·重楼谷**：南疆十万大山中有一处山谷，谷中重楼成片生长。每年花开时，殷红色的花朵在绿叶中格外醒目
- 东荒·林下：东荒的森林中，重楼在林下成片生长。但森林中多毒蛇，采集时需小心
- 中原·山坡：中原的山坡上，重楼在草丛中生长。但山坡上多农户，采集时需避开农田

采集重楼须在秋季进行——此时根茎最为粗壮，药力最为充沛。挖掘时需以木铲或玉铲，从外围一尺处开始挖掘，逐渐向中心靠拢，最终将整株连根取出。

## 配伍建议

**最佳配伍**：
- 重楼 + 半边莲 + 白花蛇舌草 → 重楼解毒汤
- 重楼 + 金银花 + 甘草 → 清热解毒汤
- 重楼 + 乳香 + 没药 → 消肿止痛散

**禁忌配伍**：
- 重楼 + 温补类药物 → 药性相消
- 重楼 + 酒 → 酒性燥热，助长热毒

## 相关典故

上古时期，有一位毒师名"重楼"，以炼制毒药闻名天下。重楼晚年时，遇到一位奇怪的病人——一位修士，被毒蛇咬伤，遍访名医无果。

重楼诊脉后发现，此修士中的蛇毒极为罕见——乃是一种上古蛇毒，普通解药无效。他翻遍古籍，最终在一本古籍中找到了重楼（灵药）的记载："重楼，茎一轮一叶，七叶一轮，能清热解毒、消肿止痛。"

重楼采来重楼（灵药），配伍半边莲、白花蛇舌草等药，煎成重楼解毒汤让修士服下。三剂之后，修士的蛇毒尽解，伤势痊愈。

修士感激涕零，问重楼："此药如此神奇，为何古籍中记载甚少？"

重楼答："重楼虽神奇，却只生长在阴湿的山林下，不似灵芝人参那般生于深山灵脉，故不被修士重视。殊不知，药无贵贱，对症便是良药。"

此事传开后，重楼（灵药）从一株无人问津的野花变成了修真界治疗蛇虫咬伤的圣药。

修真界至今仍流传着一句话："重楼重楼，七叶一轮。清热解毒，消肿止痛。"医修在治疗蛇虫咬伤时，都会优先考虑重楼——因为它药性温和，价格低廉，且效果显著。
