# 肉芝（万年太岁·特殊品阶）

## 外观

肉芝者，太岁之精也，天地间最奇异之物。非草非木非石非金，乃地脉秽气与天地灵气交媾而生，集至浊至清于一体。其形如一团活肉，无骨无窍无首无足，通体赤红如玛瑙，表面光滑如婴儿肌肤，按之凹陷松手复圆——犹如活物呼吸。万年可大如磨盘，虽无口目却自行蠕动，一日不过寸许。

以利刃剖之不见血液，但见赤色浆汁缓缓渗出浓稠如蜜，异香扑鼻似血非血似花非花，闻之令人头脑昏沉飘飘欲仙。不惧刀兵水火——利剑斩之切口自合，烈火焚之油润反增，寒冰冻之温润如初。唯以玉刀方可切割。玉乃石中君子至清至洁，可制此至浊至秽之物。

其生长方式为"分体繁殖"——表面鼓一小包，七日脱落化为独立幼芝，自行蠕动而去寻阴湿之地。一株万年肉芝往往已"生"出千百小芝遍布地底，采之不尽。

## 药性

- **性味**：味甘酸，入口如膏，回味微腥
- **五行**：至浊土属性兼带癸水之精，乃"秽土"之属
- **归经**：入脾、胃、大肠，不入心经——其性浊，清者不纳
- **毒性**：有大毒。生服七窍流血必死。须以无根水浸泡四十九日、雄黄酒蒸晒九次、地浆水洗涤九次、玉鼎文火炼九九八十一日方可入药
- **禁忌**：未经炮制绝不可服；孕妇忌之；阴虚火旺者忌之；不可见铁器——铁腥激之毒性暴增十倍

## 功效

肉芝最核心功效——**生死人，肉白骨**。虽略夸张而相去不远。

- **续命还魂**：只要尚有一口气，炮制肉芝喂服三日内伤口愈合七日内断脉重续。若人死七日之内尸身未腐，以肉芝塞入口中缝合有三分可能起死回生。此逆天之能在修真界已是无价。
- **重塑肉身**：肉身被毁仅余元婴者，以万年肉芝配天魂草、地魄花可重塑肉身。虽不如原体灵敏感应，但胜在坚韧——寻常法宝难伤，历代渡劫失败的散仙多依此法转修。
- **肉芝膏**：炮制后捣烂成膏外敷，一个时辰止血生肌十二时辰愈合无痕。一瓶万金有价无市。战场上，一瓶肉芝膏就是一条命。
- **可炼神丹**：**太岁还魂丹**（天阶上品）起死回生逆天改命，每开一炉必引天劫。**肉芝续命膏**（天阶中品）任何重伤敷之即愈，各大势力战略储备。**秽土转生丹**（魔道·天阶下品）以尸气怨魂炼制，可将尸体炼成保留七成战力的尸傀。
- **服用感受**：炮制后入口如膏，温热药力如潮涌向全身，所过之处血肉经脉以肉眼可见速度愈合——同时伴万蚁噬身般的剧烈麻痒。须以莫大意志忍受，熬过则脱胎换骨，熬不过则药力逆行前功尽弃。

## 产地

肉芝性喜阴湿污秽，不入清灵之地。**幽冥深渊**产天下第一肉芝，阴气浓郁鬼气森森，曾出磨盘大的紫黑"冥芝"吸收万年死气，能救人也杀人。**南疆万蛊坑**吸收蛊毒，可炼"蛊芝丹"得百毒不侵之体。**古战场遗址**肉芝带杀伐之气，易引心魔。**西漠地下暗河**肉芝最纯净毒性最低，初学者首选。凡间**乱葬岗**亦有极微概率生成，但年份浅药力薄。

**采集**极为凶险：生长处多有剧毒瘴气，尸蟞、血蜈蚣、腐骨蛇盘踞。肉芝会散发扰乱心神的气场——曾有采药人喜而手取，却被迷了心智自噬手指而不自知。正确采法：以玉刀切割不可皮肤直接接触，割后立即密封于朱砂封口的玉盒中。全程屏息凝神不可起贪念，贪念一起心神立乱。

## 配伍建议

**最佳**：配续魂草、九幽泉水→太岁还魂丹；配地黄精、雪莲子→肉芝续命膏；配血玉髓、龙骨粉→肉芝塑身膏；配九叶灵芝、凤凰涅槃灰→涅槃重生丹。

**禁忌**：配朱砂内服阴阳激荡炸炉；配雄黄化为剧毒；配雷击木水火不容。一切工序忌铁器。

## 相关典故

万年之前，"不死真君"萧衍被上古遗迹禁制击中，肉身灰飞烟灭仅余元婴。他流落修真界受尽白眼，后得一残卷载"肉芝寄身术"，以全部身家换千年肉芝将元婴与之融合。融合过程极苦——肉芝浊气日夜侵蚀神智，他日日与心魔搏杀。萧衍挺了过来，以肉芝之身重修至合体期。刀枪不入自愈无匹，却因此无法感应天道——他在合体巅峰停滞五千年，终不能踏出最后一步。最终他舍弃肉芝之身以元神转世投胎，留一言："肉芝可续命，不可证道。吾辈所求者非不死，而是大道。"

南疆采药人另有一说：万蛊坑深处有株三万年肉芝已生朦胧灵智。每逢采药人遇险则伸肉须相救，但取走一滴本命精血为报酬——它在研究人之精血以悟化形之道。入万蛊坑若见紫金光，那是老肉芝在看你。跪下磕三个头，它会放你一条生路。

肉芝之珍贵，不在其难得，而在其不可替代。修真界万物皆可仿制，唯肉芝之起死回生之力无人能代。正因如此，各大势力明知肉芝产地凶险万分，仍不惜代价派人驻守——因为谁掌握了肉芝，谁就掌握了修真界的最后一道保命符。
