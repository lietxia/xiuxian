# 青冥草（地阶中品）

## 外观

青冥草生于阴阳交界之处——阳间与幽冥气息交会的地带。其形如兰草，叶片细长如剑，半青半黑，青色的一半如同翡翠，黑色的一半如同深渊，两种颜色在叶片上以一条笔直的中线截然分开，诡异而有序。

青冥草不开花不结果，繁衍靠的是根部分株。每株青冥草周围必然有数株小苗，呈环形排列，如同拱卫中间的王者。

最奇特的是青冥草的气息。它不散发任何味道——即使将叶片揉碎，也没有气味。但修士以神识探查时会发现，青冥草周围的温度比别处低上几度，而且隐隐有一种令人不安的感觉，仿佛有什么东西在看不见的地方注视着你。

民间传说，在青冥草旁边待久了，会看见阴兵过境。

## 药性

- **性味**：性寒，味辛涩
- **五行**：阴属性为主，兼带一丝木属性
- **毒性**：有毒。直接接触皮肤会导致局部麻痹，误食会腹痛如绞、七日不能进食——但不会致命，据说这是幽冥之力对活人的警告

## 功效

青冥草最独特的能力，是沟通阴阳两界。

- 以青冥草炼制的 **通灵香**，点燃后可令修士暂时打通阴阳眼，看见鬼魂与幽冥之物
- 可炼 **青冥幽魂丹**，治疗魂魄受损之症，对被人抽魂炼魄的修士有奇效
- 可炼 **阴阳两界散**，涂抹于双眼后可在一炷香时间内看见隐身之物
- 青冥草汁液画符，可增强驱鬼辟邪类符箓的威力三倍
- 对于修炼鬼道功法的修士，青冥草是至宝，可直接吸收其阴气化为己用

## 产地

青冥草的生长条件非常特殊——必须是阳间与幽冥气息交汇之处。这种地方通常出现在：

- 大型战场遗址，特别是埋葬了无数尸骨的古战场
- 极阴之地，如万年古墓、僵尸出没之地
- 某些特殊的灵脉节点，地底深处恰好有一条阴脉经过

采集青冥草的最大危险不是守护妖兽，而是环境本身。这种地方阴气极重，修为不够的修士进入后会阴气入体、折损阳寿。而且青冥草生长之地常有鬼物游荡，虽然没有意识，但会本能地攻击生人气息。

有经验的采药人会选择正午阳气最盛之时采集，并在身上佩戴纯阳法器。

## 年份与药效

- **百年青冥草**：半青半黑，界线清晰，可炼通灵香
- **五百年青冥草**：青色部分开始转为淡黑，黑色部分深如墨汁，药力更强，可炼幽魂丹
- **千年青冥草**：叶片几乎全黑，只在叶尖残留一丝青色，被称为"墨青"，可沟通阴阳两界，甚至短暂打开鬼门关

## 相关典故

鬼道宗门"幽冥宗"以青冥草为镇派之宝。幽冥宗的山门建在一处远古战场上，据说埋骨百万，阴气之重连飞鸟都不敢从上空经过。那片土地上的青冥草品质极佳，是幽冥宗立派的根基。

幽冥宗有一种秘术，以千年青冥草为引，可以召唤远古战魂附体，让修士获得战魂生前的一部分修为。但这种秘术极其凶险——战魂有可能反噬宿主，曾经有一位幽冥宗长老召唤出一位上古魔将的战魂，结果被战魂夺舍，屠杀同门数十人，最后宗主亲自出手才将其镇压。

正因如此，幽冥宗有一条铁律：不到元婴期，不准碰千年青冥草。

散修间流传着一句话："青冥草，半枯荣。阳间人，莫夜行。"意思是青冥草一边青一边黑，如同阴阳两界的分界线，提醒修士不要去不该去的地方，不要看不该看的东西。
