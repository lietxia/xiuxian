# 玉肌花（四阶灵药）

## 外观

玉肌花株高一尺有二，茎如碧玉，通体晶莹剔透，似可窥见其中灵液流转。每株只开一花，花大如碗口，花瓣六出，层层叠叠，少则三层，多则九层，每层花瓣皆薄如蝉翼、透如琉璃。

其色初开时为月白，三日转羊脂白，七日后化为温润玉色——非纯白，非乳白，而是上等和田籽料那种含光蕴润之白。花瓣表面细腻如婴儿肌肤，触之温凉滑腻，若有若无地散发出一股清幽冷香。此香极淡，似兰非兰，似梅非梅，闻之令人心神安泰、杂念顿消。

最为奇者，月华之夜玉肌花会自行吸纳月精，整朵花泛起一层朦朦清辉，宛如月宫仙葩降世。此时花瓣边缘会凝出极细小的露珠，称为"玉肌露"，乃炼丹珍品。

## 药性

- **性味**：性平微凉，味甘淡，入口生津
- **五行**：偏水木二行——水主滋养润泽，木主生长华发，二者合于肌肤
- **归经**：入肺经（肺主皮毛）与胃经（阳明主面）
- **毒性**：无毒，然生服效力极微，须以特殊法门提炼方可显效
- **禁忌**：忌与铁器接触——铁气伤玉质，会使药力大减。采摘必用玉刀或竹刀

## 功效

玉肌花乃天下女修倾心之物，其功效专攻体表容颜，于修炼本身助益不大，故许多男修视之为脂粉之物，殊不知此花另有玄妙。

- **定颜丹**（四阶丹药，核心用途）：以玉肌花为主材，辅以千年寒玉髓、雪莲子、百花蜜精等，可炼成定颜丹。服后容颜永驻于服用之时的状态，岁月不侵、时光不蚀。修真界一颗定颜丹价值连城，女修倾家荡产而求，男修亦多购之赠予道侣。
- **玉肌丹**（三阶丹药）：以玉肌花单味为主，辅以灵泉水炼之，可令肌肤莹白如玉、细滑如脂，虽不能永葆青春，亦可持续百年之久。修真界各大坊市中，玉肌丹常年供不应求。
- **玉肌露**（二阶药液）：玉肌花瓣上凝结之露珠，收集后以玉瓶盛装，每日涂面可祛斑除皱、焕肤生肌。凡人得之三滴，可去十年风霜。
- **驻颜香**（非丹药用途）：玉肌花晒干研粉，掺入熏香中点燃，其香可使人容光焕发、气血和畅。凡间贵族女子一克万金求之。
- **疗火毒灼伤**：玉肌花汁液外敷，对火属性功法造成的灼伤有奇效，愈后不留疤痕。曾有元婴修士面部被魔火所伤，以玉肌花汁敷之，三七日而复如初。

## 产地

玉肌花喜阴不喜阳，择月华充沛而日光不至之处生长。多生于朝北的悬崖峭壁之下、深山幽谷之中、瀑布水帘之后。需地下有上等玉矿脉，玉气滋润方可开花——故玉肌花之名，非徒有其表，实因玉矿而生。

已知主要产地：
- **南疆十万大山的月影谷**，谷中终年云雾缭绕，月华汇聚，所产玉肌花品质最佳，远销九国十三州
- **东海琼华岛**，岛上有一处灵玉矿脉，所生玉肌花带一丝水汽润泽，药性偏凉
- **昆仑山脉的寒玉崖**，海拔极高，昼夜温差极大，崖壁上零星生长着一些玉肌花——因采集极险，价格常为平地玉肌花的十倍以上

采集玉肌花必选月圆之夜，以玉刀割取，盛以玉盒。若以铁器触之或以木盒盛之，半个时辰内花瓣即枯黄失色，药力流失殆尽。此乃玉肌花最娇贵之处，亦其价格常年居高不下之根源。

## 年份与药力

- **百年玉肌花**：花瓣三层，可炼定颜丹，效力可保容颜千年不变
- **三百年玉肌花**：花瓣五层，玉色中透出淡淡莹光，可炼上品定颜丹，效力可保万年不老
- **千年玉肌花**：花瓣七至九层，通体如羊脂白玉，夜间自发清辉。此等年份的玉肌花已不用于炼丹——修士得之，往往直接炼化入体，可得"玉肌仙体"雏形，肉身防御大增

## 配伍

- **相生**：与雪莲子同用，寒润相济，药性更纯；与百花蜜精同用，药力温和持久
- **相克**：忌与赤阳花、炎精草等火属性灵药同用——水火相冲，药性尽毁；忌与铁精同炉——铁气入药，玉质染瑕
- **禁忌配伍**：不可与血凝草同炼，二者相遇则药力逆转，反而催人衰老。古有丹师误将此二物同炉，开炉时满室药香尽化为腐臭，所出丹药黑如焦炭、服之令人三日须白

## 轶事

修真界流传最广的玉肌花故事，莫过于千年前"玉面仙子"柳清漪之事。

柳清漪本是散修，资质平平，金丹期便已寿元过半，容颜日渐衰颓。彼时恰逢天魔宗少主放出狂言——要以天价收购千年玉肌花炼制定颜丹，献给合欢宗圣女以求双修。

柳清漪闻之，一怒之下潜入天魔宗藏宝库，盗走半部上古丹方残卷。残卷记载，玉肌花若以处子精血浇灌、以月华淬炼，可催生灵性，所炼定颜丹可令容颜重返少女之时。她耗费三十年光阴，遍寻九座玉矿，终在月影谷深处找到一株千年玉肌花，以心血养之三载。

花开之日，整座月影谷玉光大盛，半边天空都映出温润白光。柳清漪以此花炼成定颜丹服下，容颜一夜之间返还十八岁之貌，更因玉肌花药力洗髓伐骨，竟从金丹后期一举突破至元婴期。

此事传遍修真界后，玉肌花之名更为显赫。而那株被柳清漪以心血浇灌过的玉肌花母株，至今仍在月影谷深处生长，月月开花，年年不谢。有好事者称，偶尔还能在月夜见到一位白衣女子坐于花旁，抚花轻叹——不知是花魂，还是人魂。
