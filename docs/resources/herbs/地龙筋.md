# 地龙筋（天阶中品）

## 外观

地龙筋乃大地龙脉之精华凝聚而成，形如筋络——但不是一根，而是数十根粗细不等的筋状物纠缠盘绕在一起，粗的如儿臂，细的如麻线，通体呈黄褐色，表面布满岩石般的纹理。

地龙筋最神奇之处在于它的"活"。虽然是一株植物，但地龙筋会慢慢地蠕动——极其缓慢，肉眼几乎看不出来，但如果以灵力标记其位置，次日再来观察就会发现它确实移动过。据说这是因为地龙筋在地下会本能地向灵脉最浓郁的方向生长。

以手触摸地龙筋，触感坚韧而温润，不像植物，更像触摸一条沉睡巨龙的肌肉。用力按压会发现表面微微下陷然后弹回，弹性惊人。

地龙筋散发的气味也很独特——是一种混合了雨后泥土清香和岩石气息的厚重味道，闻之令人感到踏实、安稳。

## 药性

- **性味**：性温，味甘淡
- **五行**：纯土属性，土行之力极致凝聚
- **毒性**：无毒。但因其土行之力过于厚重，食用后会有短暂的沉重感——如同身上压了一块巨石，数个时辰后自行消散

## 功效

地龙筋是土属性灵药中的王者，以强化肉身、防御著称。

- 炼化后可极大增强肉身防御力，皮肤肌肉骨骼都会变得坚硬如岩石
- 修复骨伤、筋伤有奇效——哪怕是全身骨骼粉碎，一碗地龙筋汤喝下去，骨头也能重新长好
- 可炼 **地龙金刚丹**，服用后肉身坚硬堪比法宝，短时间硬抗飞剑攻击而不伤
- 可炼 **龙骨续筋膏**，接续断裂的灵脉和经脉，比任何同类丹药都好
- 地龙筋的汁液与黏土混合，可炼制天阶防御阵法的阵基材料

## 产地

地龙筋生长在龙脉深处——不是龙血参那样长在龙脉节点上的地表附近，而是深埋在地底百丈之下的龙脉主干中。它需要地脉之气日夜冲刷，方得以成形。

已知的产地绝大部分都是大宗门的不传之秘。明面上有记载的是中州神土宗的祖传龙脉矿坑、西域大漠深处的黄泉地窟、以及在古战场遗址之下偶尔发现的地下龙脉遗迹。

采集地龙筋几乎不可能单人完成。首先需要土遁术或钻地类法宝深入地下百丈，其次要准确寻找龙脉主干的方向，最后还要在地底挖掘——而土属性妖兽最喜欢呆在龙脉附近。曾有一个元婴期的土行宗长老带队，花了三年时间才从地底挖出一根完整的地龙筋，其间与妖兽恶战不下百场。

## 年份与药效

- **千年地龙筋**：长约三尺，粗如手臂，表面纹理清晰，可炼金刚丹，对元婴修士有效
- **三千年地龙筋**：长约五尺，粗如大腿，表面有天然的道纹浮现，炼制的丹药可让化神期修士肉身强度再上一层
- **万年地龙筋**：传说不在长度——万年地龙筋已经可以化形，它会在地下深处幻化成一条土黄色的小龙，自由穿行于岩石之间，几乎不可能被捕获

## 相关典故

神土宗以土系功法闻名天下，他们与地龙筋的关系始于一次意外。

三千年前，神土宗的开派祖师在闭关修炼时，忽然感到地脉剧烈震动。他以土遁术下到地底查探，发现了一条幼小的土黄色小龙正在岩石中游动——他以为是土系神兽，追了三天三夜，最终发现那不是龙，而是一株快要化形的万年地龙筋。

祖师没有采它，而是在它周围布置了一个聚灵阵，帮助它继续生长。从此之后，神土宗每隔一甲子就会派人下去看望这株地龙筋，为它添补阵法材料。那株地龙筋至今仍在神土宗地底深处，已经长到三丈有余——但它始终没有完全化形，仿佛在等待什么。

有人问神土宗宗主：为什么不去采那株万年地龙筋？宗主笑答："地龙筋是大地之脉的筋络，采了它，就等于抽了这片土地的筋。神土宗立宗于此，与大地同休。地龙筋在，则神土宗在。"
