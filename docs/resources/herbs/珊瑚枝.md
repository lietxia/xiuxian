# 珊瑚枝（四阶灵药）

## 外观

珊瑚枝非草木灵药，乃海底万年珊瑚灵木。其形如树枝，从海底珊瑚礁中抽出，高约三尺至一丈不等，枝干虬曲如龙蛇，色泽斑斓——红如凝血、粉如桃花、白如玉脂、黑如墨玉，以红珊瑚最为珍贵。

其质地坚硬如铁，却温润如玉——以手抚之，触感温凉滑腻，如同抚摸一块上好的羊脂玉。断面呈玻璃光泽，内有细密的年轮纹路，如同年轮般记录着万年的岁月。

最奇在其"生长"。珊瑚枝虽已采离海底，却仍能缓慢生长——每年生长约一寸，且会不断分枝，如同一棵活着的小树。将珊瑚枝置于灵泉水中，它会继续生长，枝干上会萌发新的枝条。

其气清淡如海水，闻之令人感到心神宁静、如同置身于海底世界。

珊瑚枝有一异象——在月光下，红珊瑚会发出微弱的红色荧光，如同一盏红色的灯笼。此荧光可照亮方圆一丈，在海底极为醒目。

## 药性

- **性味**：性寒，味甘咸，入口如含海水
- **五行**：偏水金二行——水主润下，金主收敛，金水相生故能明目
- **归经**：入肝经（肝开窍于目）、心经
- **毒性**：无毒，药性温和
- **禁忌**：脾胃虚寒者慎用；孕妇忌用

## 功效

珊瑚枝可定惊安神、明目消翳，乃治疗目疾的圣品。

- **明目消翳**（核心功效）：珊瑚枝能消除眼睛中的"翳障"——修士因修炼不当或外伤导致的视力下降、白内障、青光眼等眼疾，以珊瑚枝粉末点眼，可在七日内恢复视力。
- **定惊安神**：珊瑚枝能镇定心神——修士因惊吓导致的心神不宁、夜不能寐，以珊瑚枝煎水服用，可在一个时辰内安神定魄。
- **珊瑚明目丹**（四阶丹药）：以珊瑚枝为主药，配伍决明子、菊花、枸杞、夜明砂炼制。服后可永久提升视力——能看清千丈外的蚊虫翅膀纹路。
- **解毒消肿**：珊瑚枝粉末外敷，可治疗痈疽疮疡、毒蛇咬伤——解毒消肿效果显著。
- **服用感受**：入腹后感到一股清凉之力从胃部向头部扩散，双目会感到一阵清凉——如同用冰水洗眼。随后视力会变得异常清晰，连远处细微之物都看得一清二楚。

## 产地

珊瑚枝只生长在深海珊瑚礁中——需满足三个条件：其一，水深至少千丈，水压极大；其二，海底有灵脉经过，提供灵气；其三，水温恒定，不可有剧烈变化。

已知产地：
- **东海·万丈海沟**：东海最深的海沟，水深万丈，海沟底部有万年珊瑚礁。珊瑚枝在珊瑚礁中生长，但海沟底部水压极大，非元婴修士不可下潜
- **南海·珊瑚海**：南海有一片广袤的珊瑚礁海域，珊瑚枝在此生长最为茂盛。但海域中有海兽守护，采集困难
- **西海·龙宫秘境**：西海龙宫的秘境中有一片珊瑚林，珊瑚枝品质最佳。但龙宫秘境非龙族不得入

采集珊瑚枝需以法宝级别的利器切割——珊瑚枝坚硬如铁，普通法器无法伤其分毫。采集后须立即以灵泉水浸泡，否则珊瑚枝会因失水而开裂。

## 配伍建议

**最佳配伍**：
- 珊瑚枝 + 决明子 + 菊花 → 珊瑚明目丹
- 珊瑚枝 + 珍珠粉 + 麝香 → 明目消翳散
- 珊瑚枝 + 黄连 + 黄芩 → 清热解毒汤

**禁忌配伍**：
- 珊瑚枝 + 辛温发散药物 → 药性相冲
- 珊瑚枝 + 酒 → 酒性燥热，伤目

## 相关典故

上古时期，龙宫有一位公主名"珊瑚"，生性善良，最爱在珊瑚林中嬉戏。一日，海底火山爆发，滚烫的岩浆涌入珊瑚林，珊瑚公主为救珊瑚林，以自身灵力封堵岩浆，最终力竭而亡。

她的身体化为无数珊瑚枝，在海底继续生长。从此，海底的珊瑚林便有了灵性——珊瑚枝能明目消翳，据说就是因为珊瑚公主生前拥有一双明亮的眼睛。

第一位发现珊瑚枝妙用的是一位渔夫。他在海底捞到一枝红珊瑚，回家后放在床头。当晚，他多年不愈的眼疾竟然奇迹般好转。

渔夫大喜，将珊瑚枝献给当地的修士。修士认出此乃灵药，以之炼成珊瑚明目丹，治好了无数眼疾患者。

此事传开后，珊瑚枝从海底的装饰品变成了修真界治疗目疾的圣药。

修真界至今仍流传着一句话："珊瑚枝，龙女魂。明双目，见乾坤。"医修在治疗眼疾时，都会优先考虑珊瑚枝——因为它药性温和，效果显著，且无任何副作用。
