# 赤阳花（地阶上品）

## 外观

赤阳花乃太阳真火之力落入凡间所化。其形如向日葵，却比向日葵小得多——整朵花不过成人拳头大小。花瓣赤红如火，边缘微微卷曲，花蕊金黄灿烂，远远看去如同一团燃烧的火焰。

最令人惊叹的是，赤阳花会随着太阳在天空中的位置转动，始终将花盘对准太阳，如同在向太阳朝拜。正午时分，赤阳花最为灿烂，花瓣几乎完全舒展，散发出灼热的气息和耀眼的红光。到了夜晚，赤阳花会合拢花瓣，整个花苞状如一颗暗红色的石子，毫不起眼。

赤阳花的气息燥热而刚烈，闻之如同夏日正午站在沙漠中的感觉。靠近赤阳花，会感到皮肤微微发烫，周围草木都会枯黄。如果用手触摸花瓣，会感到一股灼热直透掌心——但神奇的是，手并不会被烫伤。

## 药性

- **性味**：性大热，味辛
- **五行**：纯火属性，蕴含一丝太阳真火之力
- **毒性**：有大毒。未经炮制直接服用会导致体内火毒攻心、焚身而亡。必须以寒性灵药中和后方可入药

## 功效

赤阳花乃至阳至烈之物，是修炼火属性功法的修士梦寐以求的灵药。

- 炼化后可大幅提升火属性灵根的品质，使修士对火行法则的感悟更深
- 可炼 **赤阳丹**，服用后可获得短暂的"太阳真火"护体，对对抗阴邪鬼物有奇效
- 可炼 **纯阳破障丹**，破除修行瓶颈——特别是卡在阴寒类功法瓶颈处的修士，一颗纯阳丹可破关
- 赤阳花的花粉收集后可用来炼制火属性符墨，画出的火符威力倍增
- 修炼至阳功法的修士，随身携带一朵赤阳花，可加速修炼速度

## 产地

赤阳花生长在阳气最盛之处。所谓阳气最盛，不是指气温最高，而是太阳精华汇聚之地。这种地方通常满足以下条件：

- 地势高而开阔，终日被阳光照射
- 地下有火灵脉经过
- 周围没有遮挡，不被高山或树木遮蔽阴影

已知产地包括：东海日出之岛的观日崖、南疆火焰山的向阳坡、西域大漠深处的阳石阵中。其中以东海观日崖的赤阳花最为有名——据说那是太阳出海后第一缕阳光照射到的地方。

采集赤阳花必须选在正午时分，趁它花盘完全舒展之时快速采摘。一旦被它的花瓣触及皮肤，会留下一个如同烙印般的红痕，数日不退。

## 年份与药效

- **百年赤阳花**：花瓣六层，可炼赤阳丹，对金丹期以下修士有效
- **五百年赤阳花**：花瓣九层，赤红中隐约有金色纹路，可炼纯阳丹，对元婴修士有效
- **千年赤阳花**：花瓣变为赤金色，被称为"金阳花"，花蕊中会凝聚出一滴"太阳真液"，乃无价之宝。传说服之可获太阳真火护体，万邪不侵

## 相关典故

关于赤阳花的来历，修真界流传着一个有趣的传说。

上古时期天上有十个太阳，后羿射落九日，那九个太阳坠入凡间，化作了九株赤阳花。这个传说当然不可信——如果真是太阳所化，赤阳花也不会只是地阶灵药了。但它道出了一个事实：赤阳花蕴含的太阳真火之力，确实比任何火属性灵药都要纯正。

历史上曾有魔修利用赤阳花害人的案例。三百年前，一位叫"赤炼君"的魔道散修将赤阳花粉掺入茶叶中，在坊市中贩卖。不知情的修士饮用后体内火毒暗积，会在三日后突然爆发，焚烧而死。赤炼君以此手段劫杀了数十位修士，最终被正道联盟追杀至死。

自此之后，修真界对赤阳花的买卖管制变得极为严格，没有炼丹师公会的许可，私人不得大量买卖赤阳花。

但是，不管正道如何严防死守，每年总有几朵赤阳花流入黑市，被那些急需破关的修士以天价买走。
