# 琥珀坠（五阶灵药）

## 外观

琥珀坠非草木灵药，乃万年松脂化石。其形如卵，大小不一——小的如指节，大的如人头，通体呈琥珀色，半透明，内有远古生灵被封印其中——或蚊虫、或树叶、或小花、或小鱼，栩栩如生，如同时间被凝固在树脂之中。

其表面光滑如玻璃，入手温润——冬日握之不冰，夏日握之不热，四季恒温。以手摩擦会产生静电，可吸引细小的纸屑或灰尘。

最奇在其内含物——琥珀坠中的远古生灵并非死物，而是处于一种"假死"状态。若以特殊手法将琥珀坠融化，内含的远古生灵会短暂复活——蚊虫会飞、树叶会舒展、小鱼会游动——持续约一炷香时间后重新化为化石。

其气清香如松脂，闻之令人心神安宁、百脉通畅。琥珀坠的香气可传数十丈远，在香气范围内修炼，速度提升两成。

琥珀坠有一异象——在阳光下，琥珀坠会折射出七彩光芒，如同一颗微缩的彩虹。

## 药性

- **性味**：性平，味甘淡，入口如嚼树脂
- **五行**：偏木土二行——木主生发，土主承载，木土相生故能安神活血
- **归经**：入心经（心主神明）、肝经（肝主疏泄）
- **毒性**：无毒，药性温和
- **禁忌**：阴虚火旺者慎用；孕妇忌用

## 功效

琥珀坠可安神定魄、活血化瘀，乃治疗心悸失眠与跌打损伤的圣品。

- **安神定魄**（核心功效）：琥珀坠能安抚心神——修士因修炼过度导致的心悸失眠、心神不宁，以琥珀坠粉末冲服，可在一个时辰内安神定魄，进入深度睡眠。
- **活血化瘀**：琥珀坠能化解瘀血——修士因斗法导致的内伤瘀血、皮下淤青，以琥珀坠粉末调酒服用，可在三日内化解瘀血。
- **琥珀安神丹**（五阶丹药）：以琥珀坠为主药，配伍酸枣仁、远志、柏子仁炼制。服后可进入深度冥想状态，神识恢复速度提升三倍。
- **小儿惊风**：琥珀坠粉末是治疗小儿惊风的圣品——婴儿因惊吓导致的啼哭不止、四肢抽搐，以琥珀坠粉末冲服，可在一个时辰内止惊。
- **服用感受**：入腹后感到一股温润之气从丹田向头部扩散，随后会感到紧绷的神经逐渐放松，心悸感消失，心境如平静的湖面。

## 产地

琥珀坠只生长在万年古松集中的山林中——需满足三个条件：其一，古松年龄至少万年；其二，松脂分泌旺盛；其三，松脂落入土壤中后，需经历万年的地质作用方可化为琥珀。

已知产地：
- **昆仑山·万年松林**：昆仑山脉深处有一片万年松林，松龄皆在万年以上。松林下方的土壤中埋藏着大量琥珀坠，品质最佳。但松林中有上古禁制，非有缘者不可入
- **东荒·古松岭**：东荒有一处古松岭，岭上古松参天，琥珀坠在土壤中时有发现。但古松岭已被一个大宗门占据，外人不得入
- **南疆·松风谷**：南疆十万大山中有一处松风谷，谷中古松密布，琥珀坠在谷中溪流中时有发现——松脂被雨水冲刷入溪，在溪底沉积万年化为琥珀

采集琥珀坠需挖掘古松根部的土壤，仔细筛选——琥珀坠与普通石块外观相似，需以灵目辨识。采集后须以丝绸包裹保存，不可与硬物碰撞——琥珀坠质地较脆，碰撞会碎裂。

## 相关典故

上古时期，有一位松神名"万年松"，乃昆仑山上一棵万年古松的树神。万年松修炼万年，即将化形，却在化形前夕遭遇天劫。

万年松以全部修为抵挡天劫，最终力竭倒地。它的松脂如泪般流淌，包裹住了周围的一切——蚊虫、树叶、小花、小鱼——将它们封印在树脂之中。

万年后，这些松脂化为琥珀坠，内含的远古生灵仍在假死状态中。第一位发现琥珀坠的是一位樵夫，他在昆仑山砍柴时捡到一块琥珀，内有蚊虫一只。

樵夫将琥珀带回家，放在床头。当晚，他多年不愈的心悸失眠竟然奇迹般好转。他大喜，将琥珀献给当地的修士。

修士认出此乃灵药，以之炼成琥珀安神丹，治好了无数心悸失眠患者。

此事传开后，琥珀坠从一块普通的松脂化石变成了修真界治疗心悸失眠的圣药。

修真界至今仍流传着一句话："琥珀坠，松神泪。安神定魄，万年松。"医修在治疗心悸失眠时，都会优先考虑琥珀坠——因为它药性温和，效果显著，且无任何副作用。
