# 血凤木

**品阶**：五阶灵植  
**别名**：凤凰血木、赤焰神木、涅槃枝

## 形貌

血凤木通体赤红如血，树干蜿蜒若飞凤展翅，树皮裂纹如凤羽鳞纹，细观之上有天生日月纹路。其木心呈浓郁血红之色，以灵目观之，可见血色霞光流转不定，如有生命。

叶如凤羽，五片一簇，边缘呈火焰状，秋日不落，反愈见赤红。风过林间，枝叶摇曳，若凤凰啼鸣，隐隐有清越之声。其花似凤凰冠羽，色赤金，绽时如火焚天穹，百里可见。

断木处有赤红汁液渗出，浓如鲜血，香如麝兰而带火气。此汁即**血凤髓液**，乃木中精华所在，一滴可令枯木逢春，生机盎然。

## 性质

**五行**：火（七分）、木（三分）  
**寒热**：大热，至阳  
**毒性**：无毒，然性燥烈，凡人触之如遭火灼  
**归经**：入心经、肝经

血凤木秉承南方离火之精，兼得东方乙木之气。火中有木，木中生火，阴阳相济，故为炼制元婴傀儡之无上宝材。

## 效用

血凤木为元婴级傀儡之核心骨架材料，其效用超乎寻常灵木：

一曰**傀儡灵枢**。血凤木所制傀儡，天然通灵，可承载元婴分魂。以其为基炼制的傀儡，能自行吸纳天地火灵之气，驱动时如有生命，身法灵动远胜铁木傀儡。元婴修士以分魂入驻，操控自如，如臂使指。

二曰**涅槃续命**。血凤木中蕴含凤凰涅槃之残存气机。大能修士坐化前，若以血凤木为棺，可保肉身千年不腐，魂魄不散，以待机缘重生。传闻上古有合体修士以此木封印自身，历经万年而复活。

三曰**炼器入丹**。血凤木心材可炼**涅槃丹**，元婴修士服之，可重塑肉身、修复道基。其粉末配以朱果、赤龙鳞，可炼**血凤灵甲**，火灵根修士着之，战力倍增。

## 产地

血凤木仅生于古凤凰陨落之地。传闻上古时期，凤凰一族与人族大能大战，陨落七只真凤，其血洒落大地，浸润地脉，历经十万年方生出血凤木。

今所存者，唯南疆**凤陨渊**深处尚有数株。另传闻东海**赤焰仙岛**上有血凤木林，然岛外有天然火行禁制，非化神修士不可入。

采集血凤木需以**玄冰玉刀**切割，以**寒玉盒**盛放。若以金铁之器触之，血凤髓液瞬间气化，灵性尽失。曾有元婴修士贪图便利，以寻常法器伐木，致使整株血凤木自燃殆尽，千年灵物化为灰烬，悔之莫及。

## 配伍

**相宜**：
- 配**天蚕丝**，可织血凤内甲，柔韧且能避火
- 配**万年温玉**，可调和血凤木燥烈之气，使傀儡阴阳平衡
- 配**玄冥重水**一滴，可镇其火气，便于刻阵

**相忌**：
- 忌与**玄冰铁**同用，冰火相冲，轻则傀儡失灵，重则爆裂
- 忌入**阴煞之地**，血凤木至阳，遇阴则损，灵性消退
- 忌以**凡火**熔炼，凤凰遗泽非凡火可配，必以三昧真火或地肺离火方可

## 逸闻

千年前南疆凤陨渊曾有一株三万年血凤木，高三十丈，赤光冲霄，夜中可见如烽火巨柱。当时的傀皇——玄机上人，携化神之力深入渊中，欲取此木炼制化神傀儡。

七日之后，上人出渊，神色萎靡，手中仅持一截尺长血凤木。问之，上人叹道："凤凰遗泽，岂容凡人亵渎？那木中已生灵智，化作凤影与我交手三日夜，我竟不能胜。"

此后玄机上人闭关百年，出关后炼制了一尊元婴巅峰凤凰傀儡，名曰"赤凤"。赤凤傀儡出世之日，天降赤霞，方圆千里灵禽朝拜。上人曰："此傀儡，仅得凤木三分神韵而已。"

赤凤傀儡今归天机阁收藏，为镇阁之宝之一，非大劫不出。
