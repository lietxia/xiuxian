# 万岁蟾蜍（天阶下品·活物灵药）

## 外观

万岁蟾蜍非草木灵药，乃活物成精。其形如寻常蟾蜍，却大如磨盘，通体呈暗金色，背部隆起九个肉瘤，排列如九宫格，每个肉瘤顶端有一小孔，呼吸间有金色雾气吞吐。

其皮粗糙如岩石，布满深褐色疙瘩，每个疙瘩中央有一圈银色纹路，如同年轮。细数其纹，便可知其寿数——每千年生一圈银纹，万岁蟾蜍背部银纹至少有十圈。

最奇在其眼。万岁蟾蜍双目浑圆，瞳孔呈竖金色，能视黑夜如白昼，更能看透修士体内经脉运转。被其注视者，会有一种被看穿五脏六腑的不适感。

其声如牛吼，低沉浑厚，每逢月圆之夜便会仰天长鸣，声传百里。此鸣非为求偶，而是在吐纳月华——鸣叫时，背部九孔同时喷出金色雾气，在头顶凝聚成一颗拳头大小的金色珠子，悬于空中缓缓旋转，持续一个时辰后复被吸入体内。此珠名为"蟾蜍金丹"，乃万岁蟾蜍万年修为所聚。

万岁蟾蜍身上散发一种奇特的腥香——初闻刺鼻欲呕，再闻甘如醴酪，三闻则令人精神大振、百脉通畅。

## 药性

- **性味**：性平微温，味甘腥，入口如吞活物
- **五行**：偏水土二行——水主润下，土主承载，水土相生故其性厚重绵长
- **归经**：入肾经、命门，兼走奇经八脉
- **毒性**：活物本身无毒，但其内丹未经炼化直接服用会导致体内生机暴涨——细胞疯狂分裂，最终化为满身肉瘤的怪物
- **禁忌**：非元婴以上修士不可服用内丹；服用期间不可接触寒性之物，否则药性相冲会导致经脉冻结

## 功效

万岁蟾蜍的内丹（蟾蜍金丹）乃增寿第一灵物。

- **增寿元**（核心功效）：一颗万年蟾蜍金丹可增寿五百至八百年，视蟾蜍实际寿数而定。寿元将尽者服之，可重获新生。此乃修真界已知最可靠的增寿手段，无任何替代品。
- **蟾蜍续命丹**（天阶下品）：以内丹为主药，辅以千年何首乌、雪莲子和玉蜂蜜炼制。服后可增寿三百年，且能治愈一切暗伤隐疾。
- **解百毒**：蟾蜍金丹天然克毒——以毒物饲喂万岁蟾蜍，毒物反而成为其养料。以内丹粉末入丹，可解天下奇毒。
- **明目通神**：蟾蜍血点眼可获得"蟾瞳"——夜视能力大增，且能看穿低阶幻术和隐身术。
- **服用感受**：内丹入腹如吞下一轮暖阳，温热之力从丹田扩散至四肢百骸。全身骨骼会发出细微的咔咔声，如同年久失修的机器重新运转。药力持续四十九日，期间修士会感到精力充沛、思维敏捷，仿佛回到少年时代。

## 产地

万岁蟾蜍只生活在极阴湿地——地底深处的暗河旁、万年沼泽的淤泥中、古墓深处的积水池里。它们喜暗畏光，终生不见天日，以地下暗流中的微生物和偶尔落入水中的尸骨为食。

已知产地：
- **幽冥暗河**：冥界与人间的交界处，一条流淌了万年的地下暗河中栖息着数十只万岁蟾蜍。此地阴气极重，非鬼修或元婴以上修士不可入
- **南疆万年沼泽**：沼泽底部淤泥中偶有万岁蟾蜍出没，但沼泽中同时栖息着无数毒虫蛇蟒，采集极为凶险
- **昆仑山底暗湖**：昆仑山脉地底深处有一处地下湖泊，湖水温热如泉，湖中生活着一群蟾蜍，据传最老者已活三万岁

捕捉万岁蟾蜍几乎不可能——它们感知危险的能力极强，稍有风吹草动便沉入淤泥深处，任掘地三尺也难觅其踪。唯一的办法是以"引蟾香"（一种以蟾蜍蜕皮制成的香料）引诱其浮出水面，再以特制的金丝网捕捉。

更麻烦的是，万岁蟾蜍在感到生命威胁时会自爆内丹——与其被擒，不如同归于尽。历史上无数修士费尽心机捕捉万岁蟾蜍，最终只得到一团金色血雾。

## 配伍建议

**最佳配伍**：
- 蟾蜍内丹 + 千年何首乌 + 雪莲子 → 蟾蜍续命丹
- 蟾蜍血 + 夜明砂 + 决明子 → 蟾瞳明目散
- 蟾蜍蜕皮 + 麝香 + 龙涎香 → 引蟾香（用于引诱其他蟾蜍）

**禁忌配伍**：
- 蟾蜍内丹 + 寒属性灵药 → 药性相冲，经脉冻结
- 蟾蜍内丹 + 其他增寿灵药 → 药力冲突，反折寿命

## 相关典故

上古时期，彭祖寿八百岁，欲求长生。他遍访名山大川，最终在地底暗河中遇见一只万岁蟾蜍。

彭祖以自身精血喂养蟾蜍三年，蟾蜍感其诚，吐出一颗内丹相赠。彭祖服后寿增至一千二百岁，但仍不满足。他再次寻访蟾蜍，欲求更多内丹。

蟾蜍叹曰："汝寿已超常人十倍，犹不知足。吾活万岁，日日躲藏于淤泥之中，不见天日，此等长生，汝愿否？"

彭祖默然。他看着蟾蜍浑浊的眼睛，忽然明白了一个道理——长生不是活得更久，而是活得值得。

彭祖最终放弃了追寻更多内丹，回到人间，将余生用于教导后人养生之道。他活到一千四百岁，无疾而终。

后世修士为讽刺那些贪求长生者，编了一句话："彭祖问蟾蜍，长生值不值。蟾蜍不回答，只顾躲淤泥。"
