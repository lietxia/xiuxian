# 宁神花（三阶灵药）

## 外观

宁神花，其名源于其效——宁神定魄，安抚心魂。其形如牡丹缩小版，花大如碗口，花瓣层层叠叠，共九层，每层九片，共八十一片花瓣，色作月白，如凝固的月光。

花瓣质地极为特殊——薄如蝉翼，却柔软如丝绸，触之温凉滑腻，如同抚摸一块上好的羊脂玉。花瓣表面有细密的银色纹路，在月光下会发出柔和的银光。

最奇在其花蕊。宁神花的花蕊呈淡金色，形如一枚微缩的莲花座，花蕊中央有一滴永不干涸的透明液珠——此乃宁神花精华所聚，称为"宁神露"。

宁神花的茎叶呈深绿色，叶片掌状五裂，叶面有细密的绒毛，触摸有轻微的麻痹感——那是宁神花的"自卫机制"，触碰者会感到手指微微发麻。

其气清幽淡雅，如月夜下的桂花香，闻之令人心神安宁、杂念全消。这香气可传数十丈远，在宁神花丛中待上一炷香时间，便会感到昏昏欲睡——不是困倦，而是一种深度的放松。

## 药性

- **性味**：性平微凉，味甘淡，入口如饮花蜜
- **五行**：偏水木二行——水主静，木主和，水木相生故能宁神
- **归经**：入心经（心主神明）、肝经（肝主疏泄）
- **毒性**：无毒，药性温和，是最安全的安神类灵药之一
- **禁忌**：服用后不宜立即进行高强度斗法——宁神效果会使反应速度降低三成

## 功效

宁神花可安抚神魂、安定心神，乃修炼神识类功法的辅助圣品。

- **安神定魄**（核心功效）：修炼神识类功法时，在宁神花旁打坐，可令功法修炼速度提升两倍，且走火入魔的风险降低五成。
- **宁神丹**（三阶丹药）：以宁神花为主药，配合酸枣仁、远志、柏子仁炼制。服后可进入深度冥想状态，神识恢复速度提升三倍。
- **失眠治疗**：修士因修炼过度导致失眠时，以宁神花花瓣泡茶饮用，可在一个时辰内入睡，且睡眠质量极佳——一觉醒来，神识饱满，精神焕发。
- **心魔预防**：闭关突破前，以宁神花花瓣铺满洞府，可降低心魔入侵的概率四成。
- **服用感受**：花瓣入腹清凉舒适，一股清凉之力从胃部向头部扩散。随后会感到紧绷的神经逐渐放松，杂念如落叶般飘散，心境如平静的湖面。

## 产地

宁神花喜生于清幽宁静、灵气充沛的山谷——需满足三个条件：其一，山谷四周有高山环绕，形成天然的避风港；其二，谷中有溪流经过，水声潺潺；其三，谷中不可有凶兽栖息——凶兽的杀气会破坏宁神花的生长环境。

已知产地：
- **中州·静心谷**：一处被群山环绕的幽谷，谷中溪流潺潺，灵气充沛，宁神花在溪边成片生长。此谷已被一个佛门宗派占据，作为修行道场
- **东荒·月影林**：一片古老的森林，月光透过树冠洒落，形成斑驳的光影。宁神花在林下生长，吸收月华之精。但林中有迷阵，外人难以深入
- **南疆·忘忧涧**：南疆十万大山中的一处山涧，涧水清澈见底，宁神花在涧边生长。但涧中有水妖守护，采集困难

采集宁神花必须在月圆之夜进行——此时花瓣完全舒展，药力最为充沛。采摘时需以玉剪剪断花茎，不可用手拉扯——手温会灼伤花瓣，使其药力流失。

## 配伍建议

**最佳配伍**：
- 宁神花 + 酸枣仁 + 远志 → 宁神丹
- 宁神花 + 紫金莲 + 菩提子 → 定慧丹
- 宁神花 + 百合 + 茯苓 → 安神汤

**禁忌配伍**：
- 宁神花 + 兴奋类药物 → 药性相消
- 宁神花 + 酒 → 酒性麻痹神识，药效全失

## 相关典故

上古时期，有一位琴师名"师旷"，以琴声闻名天下。师旷双目失明，却能以琴声感知天地万物。

师旷晚年时，神识开始衰退——他的琴声不再如从前那般动人心魄。他走遍天下，寻找恢复神识之法，最终在一处幽谷中发现了宁神花。

师旷在宁神花丛中结庐而居，日日以宁神花泡茶饮用。三年后，他的神识不仅完全恢复，更胜从前——他的琴声可以安抚猛兽、治愈心病、甚至让枯萎的花朵重新绽放。

临终前，师旷弹奏了最后一曲。琴声响起时，山谷中的宁神花同时绽放，花香弥漫百里。听到琴声的修士无不感到心神安宁，杂念全消。

师旷死后，他的琴化为一块玉石，埋在宁神花丛之下。据说在月圆之夜，将耳朵贴在地面上，仍能听到微弱的琴声。

修真界至今仍流传着一句话："宁神花，师旷琴。闻一曲，心安宁。"修炼神识类功法的修士，在闭关前都会在洞府中摆放一株宁神花，以助宁神定魄。
