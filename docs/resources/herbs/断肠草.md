# 断肠草（四阶灵药·至毒）

## 外观

断肠草，其名已道尽一切——服之肠断，腹痛如绞，天下至毒之物。其形如藤蔓，缠绕于大树之上，茎细如筷，色作紫黑，上有细密倒刺，触之即伤。

叶片心形，翠绿欲滴，叶面光滑如镜，叶脉呈暗红色，如血管般密布。最奇在其花——花色艳红如血，花形如喇叭，花蕊金黄，花香浓郁甜腻，闻之令人头晕目眩。

断肠草的果实最为致命——果实呈椭圆形，大如樱桃，成熟时由青转红，红得发亮，如同红宝石。此果实是断肠草毒性最集中的部位，一颗果实足以毒杀一位金丹修士。

其根茎如网，在地下蔓延数丈，与其他植物的根系纠缠在一起——被断肠草根系缠绕的植物会在三日内枯萎死亡，养分被断肠草吸收。

其气甜腻如蜜，却暗藏杀机——闻之令人产生食欲，想要摘食果实。这便是断肠草的"诱杀"机制：以香气引诱猎物，以毒性杀死猎物。

## 药性

- **性味**：性大热，味甜腻，入口如蜜，片刻后腹痛如绞
- **五行**：偏火毒二行——火主炎上，毒主杀伐，火毒相合故其性暴烈
- **归经**：入肠经、胃经，毒走全身经脉
- **毒性**：有剧毒。一片叶子可毒杀炼气修士，一颗果实可毒杀金丹修士，一株完整的断肠草可毒杀元婴修士。中毒症状：腹痛如绞、肠断血流、七窍流血、全身痉挛，一个时辰内死亡
- **禁忌**：非毒医不可用；未经炼制绝不可服用

## 功效

断肠草至毒，然以特殊手法炼制后可化为续命圣药——此乃毒医同源之极致体现。

- **断肠续命丹**（四阶丹药）：以断肠草为主药，经"九蒸九晒"炮制后，毒性转化为药性。服后可令濒死之人续命三日——三日之内若能找到真正的救治之法，便可活命。此丹乃"吊命"圣品，各大宗门药库必备。
- **以毒攻毒**：断肠草之毒可克制某些特殊蛊毒——以微量断肠草汁液入丹，可杀死体内的蛊虫。但剂量须极为精准，差之毫厘便是毒药而非解药。
- **断肠麻沸散**：断肠草配伍曼陀罗花、川乌、草乌，可炼制麻沸散——外敷可令局部失去痛觉，用于外科手术。
- **毒修辅助**：毒修炼化断肠草可大幅提升体内毒素威力——但风险极大，稍有不慎便会毒发身亡。
- **服用感受**：炮制后的断肠草入腹，先是一阵剧烈的腹痛（残余毒性），随后腹痛逐渐消退，取而代之的是一种奇异的舒适感——如同大病初愈，全身轻松。

## 产地

断肠草只生长在极阴湿、极腐臭之地——需满足三个条件：其一，地下有腐烂的尸骨或动物残骸；其二，空气湿度极高，终年雾气弥漫；其三，周围有其他植物可供缠绕。

已知产地：
- **乱葬岗**：凡间的乱葬岗中常有断肠草生长，吸收尸毒，毒性极强。但乱葬岗多有怨灵，采集时需抵御怨念侵蚀
- **南疆毒沼**：南疆十万大山的沼泽中，断肠草缠绕在枯树上生长，与毒虫蛇蟒为伴。沼泽中沼气弥漫，凡人入之即死
- **魔道炼尸地**：魔道炼制僵尸的场所，尸体堆积如山，断肠草在尸堆中茂盛生长。但魔道修士视断肠草为禁物，外人不得靠近

采集断肠草必须戴寒蚕丝手套，以玉刀切割，入玉盒密封。采集者需屏住呼吸——断肠草的花香吸入过多会产生幻觉，令人不由自主地摘食果实。

## 配伍建议

**最佳配伍**：
- 断肠草（炮制）+ 甘草 + 金银花 → 断肠续命丹
- 断肠草 + 曼陀罗花 + 川乌 → 麻沸散
- 断肠草 + 蛊虫 → 以毒攻毒之方

**禁忌配伍**：
- 断肠草 + 任何不经炮制的内服药物 → 剧毒入腹
- 断肠草 + 酒 → 酒助毒性，毒发速度暴增十倍

## 相关典故

上古时期，神农尝百草，一日遇七十毒。最后一种毒，便是断肠草。

神农服下断肠草后，腹痛如绞，肠子如同被寸寸折断。他知道自己命不久矣，便以最后一口气将断肠草的形状、气味、毒性记录在竹简上，留给后人。

神农的弟子们悲痛欲绝，却发现在神农的竹简最后一行写着："断肠草，毒之极也。然毒之极，便是药之始。以九蒸九晒之法炮制，可化毒为药，续命三日。"

弟子们依此法炮制断肠草，果然毒性大减，化为续命圣药。他们以此法救活了无数濒死之人，断肠草也从"天下至毒"变成了"毒医同源"的象征。

修真界至今仍流传着一句话："断肠草，毒中王。神农尝，留良方。九蒸晒，化毒为药。"毒医在炼制断肠草前，都会先焚香祭拜神农——纪念那位为天下苍生尝百草、最终死于断肠草的伟大先贤。

每年神农诞辰之日，毒医们会举行"断肠祭典"——将一株断肠草以九蒸九晒之法炮制，炼成断肠续命丹，免费赠送给贫困的修士。这一传统已延续了万年，成为毒医界最重要的节日。
