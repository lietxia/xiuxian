# 朱果（三阶灵药）

## 外观

朱果乃低阶灵药中名气最大者，原因无他——它的外貌太过引人注目。果实大小如鸽卵，浑圆饱满，表皮光滑如釉。其色殷红如血、赤若丹砂，在阳光照射下呈半透明状，隐隐可见果肉中灵液流转，宛如一枚内部有火焰跳动的红宝石。

朱果生于一种矮小的灌木——朱果藤。藤蔓蜿蜒如蛇，表皮暗褐色，布满细密鳞片，攀附于山崖石壁之上。叶片掌状五裂，春夏碧绿，入秋转为丹红。每根藤上三年开花、三年结果、三年成熟，九年方得一收，故有"九年朱果"之说。

花极美——花开时满藤缀满赤红色小铃铛般的花朵，形如倒挂的小灯笼，花蕊金黄，微风过处，满山都是淡淡的甜香。

熟透的朱果表面会渗出细密的金色纹路，形如蛛网——这是朱果药力外溢的表现，称为"金络纹"。金络纹越多，朱果品质越佳，价格也越昂贵。若是金络纹布满整颗果实，称之为"满纹朱果"，是朱果中的极品。

朱果香气浓郁甜美，类似熟透的樱桃混合着一丝酒香，闻之令人食指大动。凡人闻到此香，便会感到浑身暖洋洋的，四肢百骸充满力气。

## 药性

- **性味**：性温，味甘甜微酸，入腹暖意融融
- **五行**：偏火土二行——火主气血运行，土主养分吸收，二者合则催动修为暴涨
- **归经**：入心经（心主血脉）、脾经（脾主运化）
- **毒性**：微毒。未成熟之朱果（青涩未红者）有剧毒，食之令人腹中如有火焚，三日方可缓解。必须完全成熟至赤红色方可服用
- **禁忌**：不可多食——朱果药力猛烈，一次服用超过三枚，丹田会因灵力过载而胀痛，严重者经脉受损。体虚之人需以辅药中和药性，否则虚不受补

## 功效

朱果乃低阶修士的至宝，其药效核心在于"提升修为"四个字——直接、简单、粗暴。

- **增长修为**（核心功效）：服食一枚百年朱果，相当于炼气期修士苦修三年的灵力积累。朱果中的火土精华进入丹田后，会迅速转化为无属性灵力，沿着经脉扩散到全身。整个炼化过程约需七日，七日内修士灵力会持续增长，如同服下一枚灵力炸弹。
- **突破瓶颈**：炼气期突破筑基期时，一颗百年朱果可将成功率提升两成。这也是朱果之所以被称为"散修筑基三宝"之一的原因（另两宝是筑基丹和灵泉水）。许多散修倾尽家财也要购得一枚朱果，只为筑基时多一分保障。
- **朱果酿**（三阶灵酒）：朱果十枚捣碎，兑入百年灵米酒，密封于紫砂坛中发酵三年，可得朱果酿。此酒甘醇醇厚、入口绵柔，一杯下肚浑身发热，灵力如泉水般涌出。是低阶修士聚会时的珍品，坊市中一坛朱果酿可卖到三百灵石。
- **补血生力**（非修炼用途）：朱果汁液有极强的补血功效，凡人失血过多时，一碗朱果汁可以续命。军队中常备朱果干，战争时期给重伤士兵服用以吊命——当然，这种用法在修真者看来是暴殄天物。
- **炼丹辅材**：朱果是多种三阶四阶丹药的重要辅材。炼丹时加入少量朱果汁液，可以提升丹药的灵力和口感，使丹药入口即化、药力更易吸收。

## 产地

朱果藤对生长环境要求不高，只要有充足的阳光和中等浓度的灵气即可生长。一阶灵脉以上的区域便能存活，但灵气越充沛，朱果品质越好。

- **南疆十万大山**——规模最大的朱果产区。十万大山中多向阳山坡，灵气充沛，气候适宜，野生朱果藤漫山遍野。每年朱果成熟季节，散修们蜂拥而至，争相采摘
- **东域青木宗的朱果园**——修真界规模最大的朱果人工种植基地。青木宗以灵植术闻名，其培育的朱果品质稳定、产量可观，每年产出上等朱果数千枚，垄断了东域七成的朱果市场
- **各处散修洞府**——朱果是低阶修士最常种植的灵果之一。很多散修在洞府周围种几株朱果藤，既美观又能收获灵果。但散修种植的朱果因灵气不足，品质大多普通

采摘朱果须在果实完全成熟之时——即表皮呈现赤红色并生出金色纹路的时候。未熟不可摘，过熟则果肉中的灵力会逐渐散逸。采摘时要连果蒂一同摘下，放入玉盒中保存，可保鲜三年。

## 年份与药力

- **九年朱果**（初熟）：完全成熟的第一批果实，金络纹三到五条。可增炼气修士两年修为，凡间武者食之可增一甲子功力
- **百年朱果**：果实更大一圈，赤红中透出琥珀光泽，金络纹布满果面七八成。可增炼气修士三年修为，对筑基初期亦有奇效。这是市面上最常见的品质
- **五百年朱果**：果实近乎半透明，内部仿佛有红色的火焰在跳动，满纹几乎布满整颗果实。服之可助筑基期修士突破一个小境界。极为罕见，因朱果藤的生长寿命有限，超过三百年的朱果藤越来越少
- **千年朱果**：传说级别的存在。此时的朱果已非赤红色，而是转为深紫色，表面金络纹化作天然的道纹，散发着若有若无的大道韵律。服之可助金丹期修士感悟火行大道。整个修真界能拿出千年朱果的，屈指可数

## 配伍

- **相生**：与灵泉水同服，药力更温和，适合体虚者；与蜂蜜同食，口感更佳且药性绵长；配以清心莲服用，可防止朱果热气上涌导致的情绪烦躁
- **相克**：不宜与冰寒类灵药同时服用——冷热相激，效果互相抵消；不宜在服用朱果期间大量饮用寒潭水——会中和药力
- **禁忌配伍**：不可与龙血参同服——二者药性叠加会产生一种名为"血毒"的剧毒，轻则血脉贲张七窍流血，重则爆体而亡。修真界不乏贪心修士试图将朱果与龙血参同煮服用以求双重效果，结果十有八九死于非命

## 轶事

朱果在修真界流传最广的故事，关乎一位传奇散修——"朱果老人"莫问道。

莫问道本是凡人药农，于南疆十万大山中采药时，无意间坠入一处隐秘山谷。谷中灵气浓郁得几乎化为实质，遍地都是数百年甚至上千年的灵药。而山谷正中央，一株巨大的朱果藤覆盖了半面崖壁，藤上挂满了紫红色的千年朱果。

莫问道路不通修行，只当这是寻常野果，摘下便吃。一枚千年朱果入腹，灵力在他体内横冲直撞。他不通运功之法，几乎被灵力撑爆。危机关头，他本能地模仿在山中见过的野兽吐纳姿势，歪打正着地引导了灵力运转，竟在昏迷中自行筑基成功。

醒来后，他已拥有筑基期的修为和近乎不老的寿命。此后他在山谷中隐居三百年，日日以朱果为食、以灵泉为饮，竟无师自通地修炼到了金丹期。他出山后以"朱果老人"之名行走修真界，一身修为虽不算绝顶，但对朱果的药性了解无人可及。

他曾留下一句话，至今被低阶修士奉为经典：

"朱果虽好，终是外物。一枚朱果增三年修为，但若将这三年用于苦修，所得不仅于此，更有一份扎实的根基。外物可借一时之力，唯有自身修为才是安身立命之本。"

此话说得有理，但每逢坊市朱果上市，那些话便会被修士们抛到九霄云外——毕竟，苦修三年与一枚朱果之间，绝大多数人都会选择后者。
