# 烈阳花（天阶下品）

## 外观

烈阳花，其名源于其性——烈如阳，热如火。其形如向日葵，却比向日葵大出数倍——整朵花高达三尺，花盘如脸盘大小，花瓣赤红如火，边缘微微卷曲，花蕊金黄灿烂，远远看去如同一团燃烧的火焰。

最令人惊叹的是，烈阳花会随着太阳在天空中的位置转动，始终将花盘对准太阳，如同在向太阳朝拜。正午时分，烈阳花最为灿烂，花瓣几乎完全舒展，散发出灼热的气息和耀眼的红光——在百丈外直视烈阳花，双目会感到刺痛。

到了夜晚，烈阳花会合拢花瓣，整个花苞状如一颗暗红色的石子，毫不起眼。但花苞仍散发着温热，在暗处如同一颗余烬。

烈阳花的气息燥热而刚烈，闻之如同夏日正午站在沙漠中的感觉。靠近烈阳花，会感到皮肤微微发烫，周围草木都会枯黄。如果用手触摸花瓣，会感到一股灼热直透掌心——但神奇的是，手并不会被烫伤。

其花蕊中每隔百年会凝结出一滴"太阳真液"，色如熔金，是烈阳花最珍贵的部分。

## 药性

- **性味**：性大热，味辛烈，入口如吞火焰
- **五行**：纯火属性，蕴含一丝太阳真火之力
- **归经**：入心经（心属火）、督脉
- **毒性**：有大毒。未经炮制直接服用会导致体内火毒攻心、焚身而亡。必须以寒性灵药中和后方可入药
- **禁忌**：阴虚火旺者绝对禁用；水灵根修士绝对禁用；服用期间严禁靠近水源——水克火，会激发火毒暴走

## 功效

烈阳花乃至阳至烈之物，是修炼火属性功法的修士梦寐以求的灵药。

- **太阳真火觉醒**（核心功效）：火灵根修士服用烈阳花后，有几率觉醒"太阳真火"——一种比普通火焰温度高十倍的灵火。觉醒后，修士的火系法术威力提升三倍。
- **烈阳焚天丹**（天阶下品）：以烈阳花为主药，配合赤阳花、火灵果、凤凰羽灰炼制。服后可在体内凝聚一颗"烈阳火种"，此后修炼火系功法速度提升两倍。
- **纯阳破障丹**：烈阳花配伍破障草、龙血参，可炼纯阳破障丹——破除修行瓶颈，特别是卡在阴寒类功法瓶颈处的修士，一颗纯阳丹可破关。
- **火灵根提升**：火灵根修士服用后，灵根品质可提升一阶——下品升中品，中品升上品。
- **服用感受**：入腹后感到一股灼热之力从丹田爆发，如同吞下了一颗小太阳。全身皮肤会变得通红，散发蒸腾热气。药力冲击经脉时，会产生剧烈的灼痛感——但痛过之后，会感到前所未有的力量充盈全身。

## 产地

烈阳花生长在阳气最盛之处——需满足三个条件：其一，地势高而开阔，终日被阳光照射；其二，地下有火灵脉经过；其三，周围没有遮挡，不被高山或树木遮蔽阴影。

已知产地：
- **东海日出之岛·观日崖**：太阳出海后第一缕阳光照射到的地方。观日崖上的烈阳花品质最佳，但崖高千丈，罡风如刀
- **南疆火焰山·向阳坡**：火焰山的向阳坡，山体为火山岩，常年地热蒸腾。此地的烈阳花带一丝硫磺之气，对驱煞更有奇效
- **西域大漠·阳石阵**：大漠深处有一处天然的石阵，石块排列成聚光阵，将阳光聚焦于阵中央。阵中央的烈阳花因吸收了聚焦阳光，药力是普通烈阳花的五倍

采集烈阳花必须选在正午时分，趁它花盘完全舒展之时快速采摘。采集者需穿戴隔火蚕丝手套和面罩，以玉刀割取花茎。一旦被花瓣触及皮肤，会留下一个如同烙印般的红痕，数日不退。

## 相关典故

上古时期，天上有十个太阳，后羿射落九日。那九个太阳坠入凡间，其中一朵落在东海之滨，化为一朵奇花——烈阳花。

烈阳花继承了太阳的至阳之力，花开如烈日，热浪滚滚。第一位发现烈阳花的是一位火修，他在东海之滨看到一朵花在阳光下燃烧，以为是什么法宝，便伸手去摘。

手触花瓣的瞬间，一股灼热之力涌入体内——他没有被烫伤，反而感到体内的火灵力在疯狂运转。他当即盘膝而坐，运功引导药力，三天后突破了一个大境界。

此事传开后，无数火修涌向东海之滨寻找烈阳花。但烈阳花只生长在阳光最充沛的险地，且百年才开一次花，每次只开三日便凋谢。

千年后，一位火修大能以烈阳花为主药，炼成了"烈阳焚天丹"。服后觉醒了太阳真火，战力横扫同阶，人称"烈阳真君"。

烈阳真君晚年时留下了一句话："烈阳花虽好，却是双刃剑。火修若不能驾驭太阳真火，便会被太阳真火反噬。我这一生，三次差点被自己的火焰烧死。"

修真界至今仍流传着一句话："烈阳花，太阳魂。摘花人，须谨慎。能驭火，方为真。"
