# 菊花（二阶灵药）

## 外观

菊花，秋日之花，百花凋零时独放。其形如缩小版的牡丹，花大如铜钱，花瓣细长如管，层层叠叠，色作金黄——非秋日黄菊之淡黄，亦非金器之冷金，而是秋日午后阳光那种温暖而明亮的金色。

其茎高约尺余，直立如剑，上有细密的白绒毛。叶片互生，形如卵形，叶面深绿，叶背淡绿，边缘有浅裂，如同微缩的枫叶。

最奇在其花期——菊花只在秋季开花，且花期极长，从初秋到深秋，可持续三个月。在百花凋零的秋日，金黄色的菊花在寒风中傲然绽放，如同一团团微小的火焰。

其气清香淡雅，如秋日午后的阳光——闻之令人感到温暖、舒适，精神为之一振。菊花的香气可传数十丈远，在菊花丛中待上一炷香时间，便会感到神清气爽。

菊花有一异象——在霜降之后，菊花的花瓣会变得更加金黄，香气更加浓郁——霜打菊花，药效倍增。

## 药性

- **性味**：性微寒，味甘苦，入口清凉
- **五行**：偏木金二行——木主生发，金主肃降，木金相济故能清肝
- **归经**：入肝经（肝开窍于目）、肺经
- **毒性**：无毒，药性温和
- **禁忌**：脾胃虚寒者慎用；气虚胃寒者忌用

## 功效

菊花可清肝明目、清热解毒，乃治疗目赤肿痛与风热感冒的常用灵药。

- **清肝明目**（核心功效）：菊花能清肝火、明目——修士因肝火旺盛导致的目赤肿痛、视物模糊，以菊花泡茶饮用，可在三日内消退目赤，恢复视力。
- **清热解毒**：菊花能清除体内热毒——修士因风热导致的感冒发热、咽喉肿痛，以菊花煎水服用，可在三日内退热解毒。
- **菊花明目茶**（二阶药方）：菊花配伍枸杞、决明子，泡茶饮用。可永久提升视力——能看清百丈外的蚊虫翅膀纹路。
- **延年益寿**：长期饮用菊花茶，可延缓衰老——据说彭祖每日饮菊花茶，寿至八百岁。
- **服用感受**：入腹清凉舒适，如饮冰镇菊花茶。若有肝火，会感到一股清凉之力从胃部向头部扩散，双目会感到一阵清凉——如同用冰水洗眼。

## 产地

菊花喜生于阳光充足、土壤疏松的山坡——需满足三个条件：其一，阳光充足，不被遮蔽；其二，土壤排水良好，不可积水；其三，秋季气温骤降，有霜冻——霜冻是菊花开花的关键刺激。

已知产地：
- **中原·菊花台**：中原有一处山坡，土壤呈黄色，菊花在此成片生长。每年秋季花开时，满山金黄，如同一片金色的海洋
- **东荒·野地**：东荒的田野边缘，菊花与农作物共生。当地农户将菊花晒干泡茶，作为日常饮品
- 南疆·缓坡：南疆十万大山的缓坡上，菊花在草丛中生长。但山坡上多毒蛇，采集时需小心

采集菊花须在霜降之后进行——此时菊花经历了霜冻，药效最为充沛。采摘时需以剪刀剪取花朵，晒干保存。

## 年份与药效

| 年份 | 特征 | 药效 |
|------|------|------|
| 一年生 | 花朵单朵，淡黄 | 可治疗普通风热感冒 |
| 三年生 | 花朵数朵，黄色渐深 | 可清肝明目，对筑基期修士有效 |
| 十年生 | 花朵数十朵，黄色浓郁 | 可炼菊花明目茶，对金丹期修士有效 |
| 五十年生 | 花朵金黄色，花香浓郁 | 可治疗元婴期修士的目赤肿痛 |
| 百年生 | 整株散发金色光芒，花朵在霜降后绽放时周围冰雪融化 | 可治疗化神期修士的肝火重症 |

## 配伍建议

**最佳配伍**：
- 菊花 + 枸杞 + 决明子 → 菊花明目茶
- 菊花 + 桑叶 + 薄荷 → 疏风清热汤
- 菊花 + 金银花 + 甘草 → 清热解毒汤

**禁忌配伍**：
- 菊花 + 温补类药物 → 药性相消
- 菊花 + 辛辣食物 → 伤肝

## 相关典故

上古时期，有一位仙人名"菊花翁"，以种植菊花闻名天下。菊花翁在昆仑山脚种植了万亩菊花，每年秋季花开时，金黄色的菊花如同一片金色的海洋。

菊花翁活了一千二百岁，临终前对弟子说："我之所以长寿，全赖每日饮菊花茶。菊花能清肝明目、清热解毒，常饮可延年益寿。"

弟子们依此法每日饮菊花茶，果然个个长寿。此事传开后，菊花从一株普通的野花变成了修真界延年益寿的圣药。

修真界至今仍流传着一句话："菊花茶，仙人方。常饮之，寿命长。"医修在治疗目赤肿痛时，都会优先考虑菊花——因为它药性温和，价格低廉，且效果显著。

每年秋季菊花盛开时，医修们都会举行"菊花祭典"——采集菊花，晒干泡茶，免费赠送给贫困的修士。这一传统已延续了万年，成为医修界最重要的节日。
