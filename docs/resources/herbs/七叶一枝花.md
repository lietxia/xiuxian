# 七叶一枝花（地阶上品）

## 外观

七叶一枝花，灵草中最具杀意者。其形孤绝——一根独茎从土中抽出，高约尺余，茎顶轮生七片叶子，呈星形排列，叶色墨绿近黑，叶脉却是刺目的银白，如七道闪电凝固于叶片之上。

最奇者在其花。七叶正中，独擎一朵花色殷红的花，花瓣七片，与七叶一一对应，花蕊金黄，形如微缩的星辰。花与叶之间以一根细如发丝的茎相连，风吹叶动花摇，却永不相触——叶与花之间，永远保持一寸距离。

其气辛辣刺鼻，如硫磺与烈酒混合，闻之双目流泪，鼻黏膜如被刀割。但此气于毒修而言却是无上妙香——深吸一口，体内毒功运转速度立增三成。

七叶一枝花有一异象：每逢雷雨之夜，七叶上的银白叶脉会发出微弱荧光，与天上雷电遥相呼应，仿佛在接引天雷之力。

## 药性

- **性味**：性大寒，味辛烈，入口如吞刀片
- **五行**：偏金木二行——金主肃杀，木主生发，金克木故其性矛盾
- **归经**：入肝经、心包经，毒走奇经八脉
- **毒性**：有剧毒。七叶无毒，花亦无毒，然叶与花同时入口则化为封喉剧毒——此草天生自设杀局，叶与花永不相触，一旦人为使其相遇，便是死局
- **禁忌**：非毒修不可用；服用时必须以灵力隔离花叶，使其在体内亦不相触

## 功效

七叶一枝花乃毒道至宝，其功效在"毒"与"解"之间游走。

- **七叶解毒丹**（地阶上品）：仅取七叶炼制，可解天下百毒——蛊毒、蛇毒、丹毒、咒毒，无有不解。一颗服下，毒素会在三个时辰内被尽数逼出体外，化为黑汗。
- **花蕊封喉散**（地阶上品）：仅取花蕊炼制，无色无味，入水即化。修士饮下后一炷香内丹田碎裂，修为尽废。此散无解，除非事先服用过七叶解毒丹。
- **叶花同修**（毒修秘术）：毒修以特殊功法同时炼化叶与花，使其在体内保持一寸距离，以自身为炉鼎，将毒与解同时纳入——修成后万毒不侵，且能随意将体内毒素化为攻敌之器。
- **服用感受**：叶入腹如万蚁啃噬经脉，花入腹如烈火焚烧丹田。二者同时炼化时，痛与爽交替出现，如冰火两重天反复煎熬。

## 产地

七叶一枝花只生长在古战场遗址的尸骨堆中——需满足三个条件：其一，地下埋有至少千人尸骨；其二，尸骨中必有中毒而亡者；其三，上方需有雷云笼罩，年年有雷击此地。

已知产地：
- **长平古战场遗址**：战国长平之战，四十万赵军坑杀于此，其中不乏中毒身亡者。此地七叶一枝花品质最佳，但怨气冲天，寻常修士入内便会被怨念侵蚀神智
- **南疆万蛊坑边缘**：蛊毒与尸毒交汇之地，七叶一枝花与毒蛊共生，采摘时需同时应对毒蛊袭击
- **魔道炼魂谷**：魔道处置叛徒之地，尸体堆积成山，七叶一枝花在尸堆中茂盛生长

采集七叶一枝花不可使用金属工具——金克木，金属触碰会使其瞬间枯萎。必须以玉刀在子时采摘，且采摘者需屏住呼吸，否则呼出的阳气会激发花叶相吸，一旦花叶相触，整株化为剧毒雾气。

## 配伍建议

**最佳配伍**：
- 七叶 + 甘草 + 金银花 → 万能解毒丹
- 花蕊 + 砒霜 + 断肠草 → 封喉散（魔道禁药）
- 叶花同炼 + 毒龙胆 → 万毒不侵之体

**禁忌配伍**：
- 七叶一枝花 + 任何使其花叶相触的药物 → 化为剧毒雾气
- 七叶一枝花 + 纯阳之物 → 药性相冲，解毒效果全失

## 相关典故

上古时期，蚩尤与黄帝战于涿鹿。蚩尤麾下有一毒师，以七叶一枝花炼成"七叶封喉散"，毒杀黄帝麾下七员大将。黄帝震怒，派风后追缉毒师。

毒师逃至一处古战场，以自身为饵，将七叶一枝花的花叶同时吞入体内——花叶相触，化为剧毒雾气从毒师七窍喷出，笼罩方圆十里。风后以风遁逃离，但随行三百甲士尽数中毒身亡。

毒师以命为代价，在临死前悟出了"叶花同修"之法——若能在体内维持花叶一寸距离，便可驾驭这天下至毒而不自伤。他将此法刻于骨片之上，埋于七叶一枝花根下。

千年后，一位毒修偶然得到这片骨片，依此法修炼，终成毒道大能，创立"七叶宗"，以七叶一枝花为镇宗之宝。

至今，七叶宗仍有一条铁律：入门弟子须先服七叶，再服花蕊，在生死之间领悟那一寸距离的真谛。挺不过者，死。
