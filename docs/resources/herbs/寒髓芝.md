# 寒髓芝（天阶下品）

## 外观

寒髓芝生于万年玄冰的最深处，乃寒冰中的寒冰、精华中的精华。其形如骨髓——长条形，微弯，色呈惨白，表面覆盖着一层细密的冰霜纹路。如果仔细看，可以透过半透明的芝体看见内部有无数银白色的细丝盘旋交错，如同人体的经脉网络。

寒髓芝的大小不一，短的不过半指长，长的可达一尺有余。据说最长的寒髓芝是在北极冰原深处发现的，长达三尺三寸，宛如一根冰晶玉骨。

寒髓芝不散发任何气味——因为温度太低，所有气味分子都被冻结了。但修士以灵力探知时，会感到一股极致的寒意顺着灵力倒灌而来，仿佛要将神识都冻结。

将寒髓芝握在手中，不会感到冰冷刺骨——因为它太冷了，手反而会麻木而失去知觉。需要以火属性灵力包裹手掌，方可安全触碰。

## 药性

- **性味**：性极寒，味淡
- **五行**：纯水属性，与雪莲子同属至阴至寒之物，但寒髓芝的寒气更为纯粹
- **毒性**：有寒毒。直接服用会导致经脉冻结、丹田冰封。必须配合纯阳之物共同炼制

## 功效

寒髓芝是至阴至寒的顶级灵药，专攻神魂、阴脉相关领域。

- 炼化后可极大增强阴属性体质，对修炼阴寒功法者如虎添翼
- 可炼 **寒髓炼魂丹**，淬炼神魂，使神识更为凝练坚韧——渡劫时神魂不散就靠它
- 可炼 **玄阴洗脉丹**，将经脉彻底洗炼为阴属性，适合转修阴寒功法的修士
- 寒髓芝磨粉后加入阵盘，可布置天阶寒冰大阵
- 对于修炼火属性功法走火入魔的修士，一小片寒髓芝可压制体内暴走的火毒

## 产地

寒髓芝的产地比雪莲子更为苛刻。雪莲子尚可在寒潭深处找到，寒髓芝则必须生长在万年玄冰的核心——不是随便一块万年冰层就有，而是需要那块冰层本身也生长在极其特殊的极阴灵脉之上。

已知的产地只有一个半：北极冰原的万载玄冰洞最底层，算一个；昆仑山万丈冰峰之下，因为灵脉不够纯粹，产出的寒髓芝品质稍逊，算半个。

采集寒髓芝近于送死。万载玄冰洞每深入一丈，寒气就翻倍增长。元婴期修士可勉强下到百丈，化神期可至三百丈，而寒髓芝通常在五百丈以下的冰层中。也就是说，没有化神后期的修为，贸然下去就是给自己挖坟。

## 年份与药效

- **百年寒髓芝**：半指长短，色白微透，可炼初级炼魂丹
- **千年寒髓芝**：一尺左右，白中透青，内有银丝交错如云，为元婴修士趋之若鹜
- **万年寒髓芝**：传闻可达三尺以上，白中透紫，银丝密集如同实质，已生出微弱灵智。传说服之可将神魂淬炼至堪比大乘修士的境界

## 相关典故

关于寒髓芝，修真界有一句流传很广的话："寒髓生白骨，烈焰化红颜。"意思是寒髓芝虽然极寒，却可以修复破碎的魂魄——连白骨都能重新长出魂魄来，这是夸大其词了，但确实反映了寒髓芝对神魂的巨大作用。

最传奇的故事发生在一千二百年前。有一位女修的丈夫在雷劫中肉身被毁、魂魄破碎，只残留了数片魂魄碎片。女修为了救丈夫，独闯北极冰原，以金丹期的修为强行下到三百丈深处寻找千年寒髓芝。

她在冰窟中找到了寒髓芝，但也因为寒气入体，半个身子被冻成了冰雕。她以残存的半边身体爬出来，回到宗门时已是奄奄一息。她用最后的力气将寒髓芝交给师门，说了句"炼成丹，救他"，而后含笑而逝。

后来她丈夫被救活了，突破至化神期。他做的第一件事，就是杀回北极冰原，将那片冰窟中所有的寒冰妖兽屠戮殆尽。然后他在冰窟口立了一座冰碑，上面只刻了一个字——"妻"。
