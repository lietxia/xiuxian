# 半枝莲（三阶灵药）

## 外观

半枝莲，其名源于其最奇之形——同一株植物，一半赤红如火，一半雪白如冰，从根茎到叶片再到花朵，均呈阴阳两色，以一条笔直的中线截然分开。

其茎纤细如筷，高约尺余，左半赤红右半雪白，两色交界处有一条金色细线——那是阴阳二气在株内交锋的"战场"。

其叶对生，每片叶子均是一半红一半白，叶脉在红色部分呈金色，在白色部分呈银色，如同两幅不同的阵图。

最奇在其花。半枝莲花开两色——红色部分开红花，白色部分开白花，同株两花，一红一白，花形相同却颜色迥异。红花如火焰跳跃，白花如冰雪凝结，两花同时绽放，美得令人屏息。

其气亦分两味——左侧闻之燥热，右侧闻之清寒，同时闻之则感到一股奇异的力量在体内流转，阴阳二气交替冲刷经脉。

## 药性

- **性味**：性平（红半性热，白半性寒），味甘苦各半
- **五行**：阴阳各半——红半属火，白半属水，水火同株而不相灭
- **归经**：入任脉、督脉，兼走十二正经
- **毒性**：无毒，但单独服用红半或白半会导致阴阳失衡——红半服多则燥热如火焚，白半服多则寒彻如冰封
- **禁忌**：必须整株同时服用，不可偏废；单灵根修士慎用

## 功效

半枝莲专治经脉阴阳失调，乃双修修士调理经脉的圣品。

- **阴阳调和丹**（三阶丹药）：以整株半枝莲为主药，配以枸杞、当归、黄芪炼制。双修修士服用后，可令体内阴阳二气完美平衡——阳根修士不再燥热，阴根修士不再寒凉，双修时灵力交融更为顺畅。
- **经脉重塑**：修士因修炼不当导致经脉阴阳错位时，以半枝莲煎水服用，可在七日内将错位的经脉重新归位。
- **水火同修辅助**：同时修炼水火两种相克功法的修士，以半枝莲为辅，可降低走火入魔的风险五成。
- **服用感受**：整株入腹，一股热流和一股寒流同时从丹田升起，沿经脉向相反方向流淌。两股力量在体内交汇时，会产生一种奇异的舒适感——如同炎炎夏日跳入温泉，又如同凛冬腊月围炉取暖。

## 产地

半枝莲只生长在阴阳交汇之地——需满足三个条件：其一，地下同时有火灵脉和水灵脉经过，且两脉相距不过三尺；其二，地面有天然裂缝，阴阳二气从裂缝中同时涌出；其三，周围同时生长有火属性和水属性灵草。

已知产地：
- **昆仑山·阴阳涧**：昆仑山脉深处的一处山涧，涧底同时有火泉和寒泉涌出，半枝莲在泉眼交界处生长。此地阴阳二气极为浓郁，普通修士入内会感到体内灵力紊乱
- **南疆·冰火谷**：一处天然峡谷，左侧是火山口，右侧是冰川，半枝莲在峡谷中央的裂缝中生长。谷中温度极端——左侧热如熔炉，右侧冷如冰窖
- **东海·潮汐岛**：一座随潮汐涨落而阴阳交替的小岛——涨潮时海水（阴）淹没全岛，退潮时火山岩（阳）暴露。半枝莲在潮汐线处生长，每日经历阴阳交替

采集半枝莲必须以双手同时握住红白两半，以玉刀从中部切割——若只握一半，另一半会迅速枯萎。采集后须以阴阳玉盒（一半寒玉一半暖玉）保存。

## 配伍建议

**最佳配伍**：
- 半枝莲 + 枸杞 + 当归 → 阴阳调和丹
- 半枝莲 + 黄芪 + 党参 → 双补汤
- 半枝莲 + 火灵果 + 水灵果 → 水火同源丹

**禁忌配伍**：
- 半枝莲单独服用红半或白半 → 阴阳失衡
- 半枝莲 + 纯阳或纯阴药物 → 破坏阴阳平衡

## 相关典故

上古时期，有一对道侣——男子修炼火系功法《烈焰诀》，女子修炼水系功法《寒冰诀》。两人功法相克，双修时常常互相灼伤或冻伤，苦不堪言。

某日，男子在昆仑山采药时发现了半枝莲。他想起古籍中记载此草可调和阴阳，便采回送给女子。

女子以半枝莲为主药，炼成阴阳调和丹。两人同时服下，体内的火灵力与水灵力竟然开始自行交融——不再相克，反而相生。

他们以此为基础，创出了一套双修功法《冰火同源诀》，在修真界传为佳话。此功法修炼至大成，可令修士同时掌握水火两种相克之力，战力远超同阶。

后世双修修士为感念半枝莲的功劳，将其称为"道侣草"——寓意道侣之间，当如半枝莲一般，阴阳相济，缺一不可。

至今，修真界双修修士结为道侣时，仍有一项传统——互赠半枝莲一株，植于洞府之中。若半枝莲生长旺盛，便寓意道侣和睦；若半枝莲枯萎，则需警惕感情出现裂痕。

当然，这不过是美好寓意。真正的道侣之道，不在灵草，在人心。
