# 霓裳草（五阶灵药）

## 外观

霓裳草之形，堪称灵草中的绝色。其茎纤细柔韧，高约二尺，通体呈淡紫色，顶端生有十三片叶子，每片叶子形态各异，从小到大，由外向内层层包裹，宛如一位身着霓裳羽衣的舞女在翩翩起舞。

叶片之色更是绚烂——最外层的叶子为深紫，向内依次变为紫红、朱红、橙黄、淡金，最内层的嫩叶呈浅浅的月白色。十三片叶子，十三种颜色，交相辉映，如同一道凝固的彩虹。微风拂过，叶片轻轻摆动，流光溢彩，令人目眩神迷。

然霓裳草最美者不在其形，而在其香。白日里它几乎不散发任何气味，只有将鼻子凑到近前，才能闻到一丝若有若无的甜香。但到了夜晚——特别是月明星稀之夜——霓裳草会释放出一种极其诱人的香气，浓而不腻，甜而不俗，宛如绝世佳人在月下轻歌曼舞时飘散的香风。

这股香气对修士而言只是好闻而已，但对妖兽来说却有着致命的吸引力。妖兽闻到霓裳草的香气，会如同着了魔一般疯狂地寻香而来，神情亢奋，双目赤红，不找到香源绝不罢休。此草因此得了个凶名——"诱妖草"。

## 药性

- **性味**：性温，味辛香浓烈
- **五行**：木行为主，兼带一丝火行——木主生发，香能行散；火助其势，使其香气能远播数里
- **归经**：入脾经、胃经，兼走气分
- **毒性**：无毒。然其香气对妖兽有极强的致幻作用，可引发妖兽的狂躁与亢奋。若大量吸入霓裳草的香气，修士也会出现轻微的幻觉——曾有人在霓裳草丛中打坐，竟看见九天仙女下凡舞蹈，差点走火入魔
- **禁忌**：女性修士在孕期不可接触霓裳草——其香气太过浓烈，可能会影响胎儿的灵根发育；身边有灵兽宠物的修士也不宜种植霓裳草，否则灵兽会在夜间发狂，挣脱束缚寻香而去

## 功效

霓裳草最大的用途不在炼丹服食，而在"诱妖"与"制香"二途。

- **诱妖香**（五阶香方）：以霓裳草为主料，配以龙涎香、麝香、百年沉香，调制成香。点燃后香气可飘散方圆百里，吸引范围内的妖兽前来。此香用途极广——猎妖修士用以引诱妖兽入陷阱；宗门用以清剿某片区域的妖兽；亦有邪道修士以此香诱杀妖兽取丹。但需注意，诱妖香不分强弱，引来的妖兽可能远超使用者的应付能力，故有"焚香召祸"之说。
- **霓裳化形丹**（五阶丹方）：以霓裳草为药引，配合化形果、千年灵芝炼制。妖兽服之，可提前化形为人。普通妖兽修炼至元婴期方可化形，服用此丹后金丹期便可化形，是大妖培养后辈的珍品丹药。
- **霓裳幻神香**（四阶香方）：霓裳草配伍曼陀罗花、幻梦菇，可炼制出一种致幻香。点燃后可使吸入者陷入幻境，意志不坚者会在幻境中泄露内心秘密。魔道修士常用此香逼供或诱骗。
- **妖兽丹炼制辅料**：在炼制以妖兽内丹为主药的丹药时，加入少许霓裳草粉末，可以中和妖丹中的暴戾之气，使药性温和易吸收。
- **香囊佩饰**：将霓裳草叶片晒干后缝入香囊，佩戴在身上可使普通蛇虫鼠蚁退避三舍。但此香囊不可在野外使用——妖兽对这股气味极度敏感，反而会引来麻烦。

## 产地

霓裳草喜温暖湿润、灵气充沛的半阴环境。它不挑土壤，但对灵气浓度颇为挑剔——周围的灵气浓度至少达到五阶灵脉的标准，否则叶片会黯淡无光，香气也大打折扣。

主要产地：
- **南疆万花谷**：谷中四季如春，灵气充沛，是霓裳草最大的天然产地。每年春夏之交，满谷霓裳草同时开花，十三色交相辉映，远望如同一片七彩云霞落在山谷中。然而这片山谷也是南疆妖兽最密集的区域——无数妖兽被霓裳草的香气吸引而来，将此谷变成了猎人与猎物的角斗场。每年在此丧命的采药人不计其数，故此谷又有"葬花谷"的别称。
- **十万大山**：绵延数万里的原始山脉中，零星生长着野生的霓裳草。但山中妖兽横行，修为低的修士不敢轻易深入。
- **人工种植**：一些大宗门在宗门灵田中开辟专区种植霓裳草，布置专门的阵法隔绝香气外泄。人工种植的霓裳草品质虽不及野生，但胜在产量稳定、采集安全。一亩灵田可种百株，每株每年可采叶片两次。

采集之法需格外小心。首先须在正午时分进行——此时霓裳草香气最弱，妖兽大多在休息。其次采集者需以特制的"封香布"包裹口鼻，防止吸入过多香气产生幻觉。最后，采下的叶片须立即放入玉盒中密封，因为叶片一旦离茎，便会迅速释放大量香气——曾有人因动作慢了半拍，被突如其来的香气冲晕过去。

## 年份与药效

- **百年霓裳草**：十三叶齐全但颜色较浅，香气范围约一里。可炼低品诱妖香，吸引筑基期以下的妖兽
- **三百年霓裳草**：叶片颜色渐深，香气范围约十里。可炼中品诱妖香，吸引金丹期以下的妖兽
- **五百年霓裳草**：叶片颜色浓郁鲜艳，香气范围约五十里。可炼上品诱妖香，吸引元婴期以下的妖兽。此为市面上最受欢迎的年份
- **千年霓裳草**：最内层的月白色叶片开始转为淡金，称为"金心霓裳"。香气范围可达百里，甚至可能引来化神期的妖兽。这种级别的霓裳草已极为罕见，每次出现都会引发各大势力的争夺——既能用于炼制极品诱妖香围猎大妖，也可用作化形丹的核心药引

## 配伍建议

**最佳配伍**：
- 霓裳草 + 龙涎香 + 麝香 → 诱妖香（诱捕妖兽）
- 霓裳草 + 化形果 + 千年灵芝 → 霓裳化形丹（助妖兽化形）
- 霓裳草 + 妖丹 → 中和妖丹暴戾之气（提升成丹率）

**禁忌配伍**：
- 霓裳草 + 清心花：清心花专破迷幻，会直接中和霓裳草的致幻香气
- 霓裳草 + 冰魄草：一热一寒，药性相冲，同炉会破坏双方的药力
- 霓裳草 + 镇妖符：镇妖符之力克制一切妖兽相关之物，霓裳草的诱妖之效会被镇妖符压制

## 相关典故

三百年前，修真界曾因霓裳草发生过一桩惨案。

南疆有一小宗门名曰"百花谷"，以种植灵草为业。谷中一位长老偶然发现，在灵田中混种霓裳草可以驱赶虫害——其他灵草的虫害果然大幅减少。谷主大喜，下令扩大霓裳草的种植规模，以保护其他灵草。

然而他们忽略了一件事——那些被吸引来的妖兽不再满足于在外围徘徊，而是开始疯狂地冲击百花谷的护山大阵。第一波冲击时，护山大阵便出现裂痕。谷中修士拼尽全力修复阵法，击退妖兽。但到了第二个月圆之夜，更多、更强的妖兽闻香而来。

那一夜，百花谷的护山大阵在妖兽潮的冲击下彻底崩溃。谷中修士奋力抵抗，但妖兽数量实在太多——从炼气期的低级妖兽到金丹期的妖兽王都有。百花谷上下一百三十七人，最终只有十七人杀出重围，余者尽数葬身兽口。

事后清理现场时人们发现，百花谷满地都是霓裳草的残叶——它们在妖兽的践踏下散发出最后的香气，而那些香气又引来了更多的妖兽，形成了一个致命的循环。

自此之后，修真界便多了一条铁律："种植霓裳草者，须在灵田周围布置隔香大阵，违者以祸害同道论处。"百花谷的遗址至今仍是一片荒芜，寸草不生——据说那里残留的妖兽怨气和霓裳草的气息混合，形成了永久性的凶地。

幸存的百花谷弟子中，有一位后来成了著名的猎妖师。他每每想起当日惨状，都会告诫后人："霓裳草美则美矣，然美色之下藏着杀机。此草如美人，可远观而不可亵玩焉。"
