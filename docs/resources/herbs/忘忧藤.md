# 忘忧藤（地阶中品）

## 外观

忘忧藤是一种攀援类灵植，藤蔓纤细柔软，呈深紫色，表面覆盖着一层细密的绒毛，在月光下会反射出幽幽的紫光。藤蔓可以攀附在任何支撑物上——树木、岩石、墙壁，都能被它缠绕覆盖。

忘忧藤的叶子心形，翠绿中带着紫色的叶脉，巴掌大小。最有名的是它的果实——忘忧果。果实呈椭圆形，大小如枣子，成熟时由青转紫，表面光滑如琉璃，半透明状，可以看见内部的果肉和一颗小小的种子。摘下一颗忘忧果对着光看，会发现果实内部似乎有紫色的雾气在缓缓流动。

忘忧藤的花很小，藏在叶腋间，淡紫色，不仔细看几乎发现不了。但它的花香却很独特——不是浓烈的香气，而是一种若有若无的清甜气息，如同从很远的地方飘来的记忆。

最令人称奇的是，在忘忧藤下睡一觉，醒来会觉得神清气爽，心中的烦恼会减轻不少。这也是"忘忧"之名的由来。

## 药性

- **性味**：性平微凉，味酸甜
- **五行**：偏水木属性，水主润下，木主条达——有疏解郁结之效
- **毒性**：有小毒。忘忧果的果核有毒，不可嚼碎吞服，否则会使人昏睡七日不醒。果肉无毒

## 功效

忘忧藤以忘却忧愁、安神催眠著称，是修真界少有的作用于"心"的灵药。

- 忘忧果的果肉服下后可令人心情愉悦，忘却烦恼——对有心魔缠身之兆的修士有预防作用
- 可炼 **忘尘丹**，服下后可选择性遗忘一段记忆——对想要忘记痛苦经历、心魔根源的修士来说是救命良药
- 可炼 **忘忧安神茶**，长期饮用可改善心境，使人心胸开阔、少生杂念
- 忘忧藤的藤蔓晒干后编织成枕头，枕着睡觉可夜夜好梦、不为噩梦所扰
- 忘忧藤的汁液加入香炉中熏香，可使整个房间充满安宁祥和的气息

## 产地

忘忧藤喜欢生长在灵气温和、环境清幽之处。它不像其他灵药那样挑剔灵脉品质，只要有中等浓度的灵气、充足的水分、以及不太恶劣的环境，它就能生长。

但忘忧藤有一个奇怪的特性：它在悲伤的人身边会长得格外茂盛。如果一个修道之人在忘忧藤旁边长期处于悲伤或忧郁的状态，忘忧藤会疯狂生长，藤蔓会不自觉地伸向那个人，仿佛在安慰他。

因此，忘忧藤在修真界的散修群体中较为常见——很多独居的散修会在洞府门口种一株忘忧藤，算是半个伴儿。

广泛的产地包括：各大山脉的幽谷中、灵气充裕的山涧旁、甚至一些宗门的药圃中也会专门种植。

## 年份与药效

- **十年忘忧藤**：藤蔓已经可以采摘用做安神茶，果实可食，有轻微忘忧效果
- **百年忘忧藤**：藤蔓粗如手指，深紫色中泛着银光，果实药力充沛，一颗忘忧果可使人忘却烦恼三日
- **五百年忘忧藤**：藤蔓已经如同老树般粗壮，紫色的藤蔓上会生出一层金色的苔藓，被称为"金丝忘忧藤"。它的果实可以炼制上品忘尘丹——不只能让人忘记忧愁，还能让人彻底忘记一段特定的记忆

## 相关典故

忘忧藤在修真界有一个非常矛盾的评价。

一方面，忘尘丹是治疗心魔的良药。很多修士在修炼中产生了心魔，根源往往是一段痛苦的记忆或执念。忘尘丹可以帮助他们忘记那段记忆，从而根治心魔。各大宗门的心魔堂都常备忘尘丹。

但另一方面，忘尘丹也被滥用过。有些修士为了逃避现实——比如被道侣背叛、宗门被灭、渡劫失败——选择服用忘尘丹忘记一切，重新开始。但这真的是正确的选择吗？

修真界有一个著名的"七忘老人"的故事。这位散修一生经历了七次重大打击：师门被灭、道侣背叛、灵根被毁……每次他都选择服用忘尘丹，忘记一切从头再来。

但他第七次服用忘尘丹后，醒来时发现自己什么都不记得了——不记得自己是谁，不记得自己会什么功法，不记得自己的修为怎么来的。他变成了一个空有强大修为的白痴，在修真界流浪了数百年，最终不知所踪。

百草门的一位丹师听闻此事后，感慨道："忘忧藤可以忘记忧愁，但不能忘记人生。忧愁也是人生的一部分——忘记了忧愁，也就忘记了让你成长的经历。"

从此，百草门卖忘尘丹时多了一个规矩：必须要买丹人说明为何要忘，由丹师判断是否合理。如果只是想逃避现实，不卖。
