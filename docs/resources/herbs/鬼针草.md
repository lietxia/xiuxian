# 鬼针草（三阶灵药）

## 外观

鬼针草，其名源于其果——果实细长如针，色黑如墨，成束生长于茎顶，如同一束黑色的钢针。其形如杂草，高约尺余，茎细如筷，直立如剑，上有细密的白刺。

叶片互生，形如披针形，叶面深绿，叶背淡绿，边缘有细锯齿。最奇在其"针"——鬼针草的果实成熟后会自行弹射而出，如同一枚枚微小的飞针，可射入数丈外的泥土或动物皮毛中。

其花极小，白色，生于叶腋间，不仔细看几乎发现不了。但其花香却很独特——不是浓烈的香气，而是一种若有若无的清甜气息，如同从很远的地方飘来的清香。

其气清淡如薄荷，却比薄荷多了一丝辛辣——闻之令人感到鼻腔微刺，随后感到神清气爽。

鬼针草有一异象——在阴气浓郁之地，鬼针草的果实会发出微弱的黑色荧光，如同一束黑色的火焰。

## 药性

- **性味**：性凉，味苦辛，入口清凉
- **五行**：偏金木二行——金主肃降，木主生发，金木相济故能驱鬼
- **归经**：入肝经、肺经，兼走肌表
- **毒性**：无毒，药性温和
- **禁忌**：气血虚者慎用；孕妇忌用

## 功效

鬼针草可驱鬼辟邪、清热解毒，乃低阶修士行走江湖必备的辟邪灵草。

- **驱鬼辟邪**（核心功效）：鬼针草能驱赶鬼物——修士行走阴气浓郁之地时，将鬼针草叶片放入口中咀嚼，其气味可从毛孔散发，鬼物闻到后会自动远离。
- **清热解毒**：鬼针草能清除体内热毒——修士因热毒导致的痈疽疮疡、咽喉肿痛，以鬼针草煎水服用，可在三日内清热解毒。
- **鬼针草辟邪汤**（三阶药方）：鬼针草配伍艾草、菖蒲、雄黄，水煎服之。可驱赶一切鬼物——低阶鬼修遇之如遭火焚。
- **外敷消肿**：鬼针草捣烂外敷，可治疗跌打损伤导致的肿胀——消肿效果显著。
- **服用感受**：入腹清凉舒适，如饮冰镇薄荷茶。若有鬼物在附近，会感到一股清凉之力从胃部向四肢扩散，所过之处阴气消散。

## 产地

鬼针草喜生于荒野、路旁、田野等开阔之地——需满足三个条件：其一，土壤排水良好，不可积水；其二，阳光充足，不被遮蔽；其三，周围有阴气浓郁之地——鬼针草与阴气有奇妙的共生关系：阴气越重，鬼针草越是茂盛。

已知产地：
- 中原·荒野：中原的荒野中，鬼针草随处可见。当地农户将其视为杂草，却不知其乃灵药
- 东荒·路旁：东荒的路旁，鬼针草在草丛中生长。但路旁多行人，采集时需避开
- 南疆·墓地：南疆的墓地周围，鬼针草在阴气滋养下茂盛生长。但墓地中多鬼物，采集时需小心

采集鬼针草须在秋季果实时进行——此时果实最为坚硬，药力最为充沛。采摘时需戴手套——鬼针草的果实如针，会刺入皮肤。

## 年份与药效

| 年份 | 特征 | 药效 |
|------|------|------|
| 一年生 | 果实细如针，黑色 | 可驱赶普通游魂 |
| 三年生 | 果实粗如铁钉，黑色发亮 | 可驱鬼辟邪，对筑基期修士有效 |
| 十年生 | 果实可自行弹射，射程数丈 | 可炼鬼针草辟邪汤，对金丹期修士有效 |
| 五十年生 | 果实黑色荧光，射程十丈 | 可驱赶元婴期鬼物 |
| 百年生 | 整株散发黑色光芒，果实射程百丈 | 可驱赶化神期鬼物 |

## 配伍建议

**最佳配伍**：
- 鬼针草 + 艾草 + 菖蒲 → 鬼针草辟邪汤
- 鬼针草 + 金银花 + 甘草 → 清热解毒汤
- 鬼针草 + 雄黄 + 朱砂 → 驱鬼辟邪散

**禁忌配伍**：
- 鬼针草 + 温补类药物 → 药性相消
- 鬼针草 + 酒 → 酒性燥热，助长鬼气

## 相关典故

上古时期，有一位鬼王名"钟馗"，以捉鬼闻名天下。钟馗晚年时，遇到一位奇怪的病人——一位修士，被鬼物缠身，遍访名医无果。

钟馗诊脉后发现，此修士被一只厉鬼附身——厉鬼已融入修士的神魂，普通驱鬼之法无效。他翻遍古籍，最终在一本古籍中找到了鬼针草的记载："鬼针草，果实如针，色黑如墨，能驱鬼辟邪。"

钟馗采来鬼针草，配伍艾草、菖蒲等药，煎成鬼针草辟邪汤让修士服下。三剂之后，厉鬼被驱出体外，修士痊愈。

修士感激涕零，问钟馗："此药如此神奇，为何古籍中记载甚少？"

钟馗答："鬼针草虽神奇，却只生长在荒野路旁，不似灵芝人参那般生于深山灵脉，故不被修士重视。殊不知，药无贵贱，对症便是良药。"

此事传开后，鬼针草从一株无人问津的杂草变成了修真界驱鬼辟邪的圣药。

修真界至今仍流传着一句话："鬼针草，钟馗宝。驱鬼邪，保平安。"低阶修士行走江湖时，都会随身携带一株鬼针草——因为它药性温和，价格低廉，且驱鬼效果显著。
