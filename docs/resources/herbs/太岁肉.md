# 太岁肉（天阶上品）

## 外观

太岁肉不是肉——它是一种集天地灵气与地脉浊气于一身的奇异菌类。其形如肉团，无根无叶，就是一大团质地柔韧的肉质状物，大的如磨盘，小的如拳头，颜色呈黄褐色或灰白色，表面有细密的褶皱，看起来就像一块肥肉。

太岁肉最神奇的地方在于它会呼吸。不是修辞——是真的会呼吸。仔细观察可以发现太岁肉的表面会缓慢地起伏，一呼一吸之间间隔大概一炷香的时间。而且它有温度，摸上去温热，如同活物的体温。

太岁肉没有五官没有四肢，但它能感知周围的环境。如果你用手触碰它，它的表面会微微收缩。如果你用灵力探查它，它会散发出一种温和的"善意"——一种模糊的意识波动，表达的是欢喜和亲近。

太岁肉不散发气味——但它周围的花草会长得特别茂盛，动物也会不自觉地靠近。据说太岁肉所在之地，地气极为肥沃，种什么都长得好。

## 药性

- **性味**：性平，味甘
- **五行**：土属性为主——它本身就是地气精华凝聚而成，蕴含最纯粹的土行生机之力
- **毒性**：无毒。但太岁肉不能直接生吃——生吃会导致体内生机过剩，细胞疯狂分裂，最终长成肉瘤。必须经过炼制后方可服用

## 功效

太岁肉号称"生死人肉白骨"，这当然是夸张——但它的疗伤效果确实是修真界顶级的。

- 可治愈一切外伤——断肢重生、五脏修复、皮肉再生不在话下
- 对道基受损有奇效——哪怕是灵根破碎、丹田破裂，太岁肉都能修复
- 可炼 **太岁还生丹**，濒死之际服用，可将人从鬼门关拉回来
- 可炼 **地灵塑体膏**，帮助修士重塑肉身——对于肉身被毁、元婴逃脱的修士来说，这是重获新生的希望
- 一点太岁肉的汁液滴在灵田里，可使灵田的肥力提升数倍，灵药生长速度翻倍
- 传说太岁肉切下一块后，过一段时间会长回来——前提是保留一部分根茎

## 产地

太岁肉生长在地气最为浓郁之处——即地脉之气汇聚的中心点。这种东西通常会出现在几条地脉交汇的地方，或者是大地灵脉的泉眼处。它在地下深处生长，偶尔会破土而出。

已知的产地极少：中州大地深处的某个地脉汇聚点（位置被某个大宗门保密）、南疆密林深处的地气喷涌之地、以及——据说——在一些古老的帝王陵墓中也有发现（帝王陵墓选址讲究风水，往往会选在地脉交汇之处）。

采集太岁肉的难度在于它藏在地下。而且太岁肉有微弱的意识，它能够感应到采集者的意图。如果采集者心怀恶意，太岁肉会向地下更深处遁走。如果采集者心怀善意，太岁肉反而会主动靠近。

所以采集太岁肉有一个不成文的规矩：以诚相待。要在太岁肉旁边打坐，释放善意，等它自己现身。

## 年份与药效

- **百年太岁肉**：拳头大小，可治外伤，可炼初级还生丹
- **五百年太岁肉**：脸盆大小，肉质紧实，黄中带金，可炼高级还生丹，对金丹元婴修士的伤势有奇效
- **千年太岁肉**：磨盘大小，色泽纯金，表面会出现天然的"福"字纹路，被称为"金太岁"。可炼顶级还生丹，连化神期修士的致命伤都能治好

## 相关典故

太岁肉在修真界的名声很特别——它既是最好的药材，也是很多人心中的"不祥之物"。

民间有"太岁头上动土"的说法，意思是如果在太岁所在的位置动土施工，会招来灾祸。这种说法在修真界也有类似的版本：强行捕捉太岁肉的人，往往会遭遇不幸。

历史上有明确记载的一件事：八百年前，魔道一位化神期修士发现了地下有一块磨盘大的千年太岁肉。他大喜过望，用魔功强行将太岁肉从地下挖出。太岁肉在挣扎中发出了一种无声的"尖叫"——以神识可以感受到的波动向四面八方扩散。

当天夜里，那位化神期修士在自己的洞府中暴毙。没有任何外伤，没有任何中毒迹象，他的魂魄完好，身体却突然就死了。有人说他是被大地之力反噬了——太岁肉是地气精华所聚，强行掠夺就是与大地为敌。

但太岁肉真的是不祥之物吗？也不尽然。

在正道宗门"百草门"中，有一块传承了两千多年的太岁肉。这块太岁肉是百草门开派祖师传下来的，被供奉在灵脉泉眼中，以灵气温养。百草门的弟子可以在太岁肉旁边打坐修炼，太岁肉会主动散发出地气精华助他们修行。历代百草门门主都与这块太岁肉建立了深厚的情谊——他们称它为"老友"。

采与不采，恶与善，不在太岁肉，在人心。
