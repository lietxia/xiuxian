# 麒麟竭（天阶上品）

## 外观

麒麟竭的来历非常特殊——它并非正常生长的植物，而是麒麟之血浸染千年古树树脂后，树脂与血液共同凝结石化而成的奇物。其形如琥珀，大小不一，小的如指节，大的如人头，通体五色斑斓——赤橙黄绿青五种颜色交织在一起，形成绚丽的纹路，如同打翻了的调色盘。

麒麟竭的表面光滑如镜，入手温润如玉，比同等大小的玉石要轻。对着光看，可以看见内部有细如游丝的血色纹路，那是麒麟血的痕迹。有些麒麟竭内部还包裹着远古的昆虫或树叶——如同琥珀一样，但在五彩之色的映衬下显得格外梦幻。

麒麟竭会散发出一种极其特别的香气——不像花香，不像木香，而是一种温暖醇厚的药香，闻之令人心神安定，百脉通畅。但这香气极为霸道，只要一粒芝麻大小的麒麟竭，就可以让整间屋子香气弥漫，七日不散。

## 药性

- **性味**：性平，味甘微涩，回味悠长
- **五行**：兼具五行之力——麒麟乃瑞兽，血脉中蕴含五行精华。五色正对应五行：赤火、橙土、黄金、青木、绿水
- **毒性**：无毒。麒麟竭是所有灵药中最难能可贵的——它药性平和，五行调和，没有任何副作用

## 功效

麒麟竭被誉为"万能灵药"，虽然夸张了些，但它确实拥有极其广泛的功效。

- 可修复一切伤势——无论内伤外伤，刀伤剑伤还是法力反噬，麒麟竭都有极佳的疗效
- 可化解百毒——哪怕是中了天阶毒药，只要还有一口气在，麒麟竭都能救回来
- 可炼 **五行归元丹**，帮助修士调和体内的五行之力——对多灵根的修士来说是无价之宝
- 可炼 **麒麟护命丹**，服下后可在体内形成一层五行护盾，能抵挡三次致命攻击
- 麒麟竭磨粉后与朱砂混合，画出的符箓威力极为强大，特别是五行符箓
- 直接含在口中，可辟百毒、防瘴气，在毒瘴之地的探险中最为实用

## 产地

麒麟竭是麒麟血浸染树脂形成的，所以它的产地取决于两个条件：麒麟曾在此地受伤流血，以及当地有足够的古树树脂。

麒麟行踪不定，从不固定在某一处久留。所以麒麟竭的发现完全是随机的——可能在任何地方出现。历史上发现过的麒麟竭产地包括：中州的万妖山脉（有人见到麒麟与妖王大战后血迹斑斑地离去，果然在那里找到了一块麒麟竭）、南疆不归谷、东海的某个无名荒岛。

采集麒麟竭没有危险——毕竟它只是一块凝固的树脂，不会反抗。但运气成分极大。有人穷尽一生寻找麒麟竭而不得，有人在路边踢了一脚就踢出一块拳头大的。修真界有句俗话："麒麟竭，靠天得。不是你的，让你找到你也看不见。"

## 年份与药效

- **百年麒麟竭**：小如指甲盖，颜色较浅，可治伤解毒，药力有限
- **五百年麒麟竭**：大如拇指，五色鲜明，可炼五行丹，药效显著
- **千年麒麟竭**：大如鸡蛋，五彩斑斓夺目，内部血色纹路如活物般流动，可炼护命丹，对化神期修士也有奇效

## 相关典故

麒麟竭最著名的故事发生在魔道猖獗的年代。那时魔修四处肆虐，一位正道的化神期大能被魔道六位同阶修士围攻，身中九种剧毒、道基险些破碎。他被救回时已经奄奄一息，正道联盟束手无策。

一位炼丹宗师翻遍了所有古籍，最终在一本残页上看到了"麒麟竭"三个字。他用尽所有人脉，最终从一位古玩商手中找到了一块鸡蛋大小的千年麒麟竭。据说那位古玩商根本不知道这是什么，当成普通的五彩琥珀摆着卖。

炼丹宗师以千年麒麟竭为主药，辅以七种辅药，炼出了三颗五彩灵丹。那位大能服用后，体内九种剧毒尽解，破碎的道基竟然在七七四十九天内重新愈合。此事在修真界引起了轰动，麒麟竭从此声名大噪。

但是，关于麒麟竭也有一个令人无奈的真相：自那以后，修真界几乎掘地三尺寻找麒麟竭，却发现这东西比千年人参还稀有。有人统计过，修真界过去万年中发现的麒麟竭，总数不超过三十块。

瑞兽之血，岂是轻易能得的？
