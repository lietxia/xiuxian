# 白花蛇舌草（三阶灵药）

## 外观

白花蛇舌草，其名源于其形——叶片细长如蛇舌，扁平而尖，长约寸许，叶色深绿，叶面光滑如蜡，叶背淡绿，有细密的腺点。

其花极小，白色，生于叶腋间，不仔细看几乎发现不了。花萼五裂，花冠白色，花瓣五片，形如微小的星星。花开时有一股淡淡的清香，类似茉莉与薄荷的混合气味。

其茎纤细柔韧，呈淡绿色，匍匐于地面生长，节节生根，蔓延成片。一株白花蛇舌草可在一年内蔓延数丈，形成一片绿色的地毯。

最奇在其"驱蛇"之效——白花蛇舌草生长之处，蛇类会自动绕道而行。其气味对蛇类有强烈的驱赶作用，如同蛇类的天然克星。

其气清淡如薄荷，却比薄荷多了一丝苦涩——闻之令人感到口腔中有一股清凉的苦味。

## 药性

- **性味**：性凉，味甘苦，入口清凉
- **五行**：偏水木二行——水主润下，木主疏泄，水木相生故能清热利湿
- **归经**：入肝经、脾经，兼走肌表
- **毒性**：无毒，药性温和
- **禁忌**：脾胃虚寒者慎用；孕妇忌用

## 功效

白花蛇舌草专解蛇毒、清热利湿，乃低阶修士行走江湖必备的解毒灵草。

- **解蛇毒**（核心功效）：白花蛇舌草是蛇毒的天然解药——被毒蛇咬伤后，以白花蛇舌草捣烂敷于伤口，可在一个时辰内阻止蛇毒扩散。配合内服白花蛇舌草煎剂，可在三个时辰内将蛇毒尽数化解。对蝮蛇、眼镜蛇、银环蛇等常见蛇毒均有效。
- **清热利湿**：白花蛇舌草能清除体内湿热——修士因湿热导致的黄疸、痢疾、淋证，以白花蛇舌草煎水服用，可在三日内清除湿热。
- **白花蛇舌草汤**（三阶药方）：白花蛇舌草配伍半边莲、金银花、甘草，水煎服之。可解一切蛇虫之毒，对瘴气中毒亦有良效。
- **蛇伤预防**：行走蛇类密集之地时，将白花蛇舌草叶片放入口中咀嚼，其气味可从毛孔散发，蛇类闻到后会自动远离。
- **服用感受**：入腹清凉舒适，如饮冰镇薄荷水。若有蛇毒在体内，会感到一股凉意从胃部向伤口方向扩散，所过之处灼热感消退。

## 产地

白花蛇舌草喜生于湿润的田野、溪边、路旁——需满足三个条件：其一，土壤湿润但不积水；其二，阳光充足但不过于强烈；其三，周围有蛇类栖息——白花蛇舌草与蛇类有奇妙的共生关系：蛇类的排泄物为其养料，而白花蛇舌草的气味又能驱赶蛇类的天敌。

已知产地：
- **南疆·蛇谷**：南疆十万大山中有一处蛇谷，谷中蛇类密布，白花蛇舌草在谷中成片生长。采药人需一边采草一边防蛇
- **东荒·湿地**：东荒的湿地中，白花蛇舌草在溪边蔓延成片。但湿地中多蚊虫毒瘴，采集不易
- **江南·田野**：江南的水田边缘，白花蛇舌草随处可见。当地农户常采集晒干，作为解毒药材储备

采集白花蛇舌草极为简单——连根拔起即可，无需特殊工具。但需注意：白花蛇舌草茎叶脆弱，拔起时若断裂，残留根节会迅速发芽，来年更加茂盛。

## 年份与药效

| 年份 | 特征 | 药效 |
|------|------|------|
| 一年生 | 茎叶细弱，叶小如指甲 | 可解普通蚊虫叮咬之毒 |
| 三年生 | 茎叶健壮，叶长寸许 | 可解常见蛇毒，对筑基期修士有效 |
| 十年生 | 茎叶粗壮，叶长二寸，白花密集 | 可炼白花蛇舌草汤，对金丹期修士有效 |
| 五十年生 | 茎叶泛紫光，叶长三寸，花香浓郁 | 可解剧毒之蛇毒，对元婴期修士有效 |
| 百年生 | 整株散发淡紫色荧光，叶长四寸 | 可解化神期蛇虫之毒 |

## 配伍建议

**最佳配伍**：
- 白花蛇舌草 + 半边莲 + 金银花 → 白花蛇舌草汤
- 白花蛇舌草 + 七叶一枝花 → 解蛇毒圣品
- 白花蛇舌草 + 黄连 + 黄芩 → 清热解毒汤

**禁忌配伍**：
- 白花蛇舌草 + 温补类药物 → 药性相消
- 白花蛇舌草 + 酒 → 酒性燥热，助长蛇毒

## 相关典故

上古时期，有一位蛇神名"白娘子"，修炼千年化为人形，与一位凡人相恋。法海和尚以"人妖殊途"为由，将白娘子镇压于雷峰塔下。

白娘子被镇压前，流下一滴眼泪落入凡间，化为一片绿草——白花蛇舌草。此草叶如蛇舌，是白娘子对凡间的思念；花白如雪，是她纯洁的爱情。

第一位发现白花蛇舌草妙用的是一位牧童。他在放牛时被毒蛇咬伤，奄奄一息之际，看到一片绿草在风中摇曳。他本能地拔草敷于伤口，蛇毒竟然立解。

牧童将此事告诉村民，村民们纷纷采集白花蛇舌草作为解毒药材。白花蛇舌草从此在民间广为流传，成为治疗蛇虫咬伤的常用药。

修真界至今仍流传着一句话："白花蛇舌草，白娘子泪。解蛇毒，救苍生。"医修在治疗蛇虫咬伤时，都会优先考虑白花蛇舌草——因为它药性温和，价格低廉，且效果显著。

每年端午节（蛇类活跃之日），医修们都会举行"白花蛇舌草祭典"——采集白花蛇舌草，炼成解毒汤，免费赠送给贫困的修士。这一传统已延续了万年，成为医修界最重要的节日。
