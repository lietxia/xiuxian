# 地灵乳（五阶灵物）

## 外观

地灵乳非寻常草木之属，而是大地灵脉精气汇聚所化的液态灵物。其状如牛乳，色作乳白，质地浓稠，静置时表面浮有一层淡淡的银色灵光。灵光如云烟般缓缓流动，以神识观之，可见无数细小灵粒在乳液中旋转起舞，宛如星河流转。

将其盛入玉碗之中仔细观察，可见地灵乳分为三层：上层薄如蝉翼，色近透明，飘散着若有若无的金色微光，乃是灵气最轻最纯的部分，称为"灵华"；中层乳白浓稠，质地如融化的羊脂玉，是地灵乳的主体，称为"乳液"；下层沉淀着一层极薄的灰白色粉末，乃是地脉中的矿物精华，称为"地精粉"。

地灵乳无味——不是没有味道，而是它的味道超越了凡俗的酸甜苦辣。含入口中，只觉一股温润如春泉般的暖流自舌根下行，过咽喉、入丹田，所过之处四肢百骸无不舒畅。若有若无间，能感受到大地的厚重与沉稳——那是一种直抵灵魂深处的踏实感。

其香气亦极其独特，不浓不淡，如同雨后初晴时泥土的气息，混合着草木清香和矿石微涩，闻之令人心旷神怡、神思安宁。有修士形容——这味道像是大地在呼吸。

## 药性

- **性味**：性平微温，味甘醇，入口温润
- **五行**：纯土属性，蕴含大地本源精华。土生万物，故地灵乳可滋养任何属性的修士，是中正平和的滋补圣品
- **归经**：入脾经（脾属土，主运化）、肾经（肾主骨）、全身经脉
- **毒性**：无毒，堪称灵药中毒性最温和的几种之一。但不可多服——土气过盛会壅塞经脉，反而不美
- **禁忌**：忌以金属器皿盛放——金克土，地灵乳遇金则灵气逸散、药性大减。必以玉器或石器盛之；忌与纯金行灵药同服，土生金——金气过盛反过头来盗泄土气

## 功效

地灵乳乃大地精华所聚，功效以补益根基为主，是天下修士皆可受益的万金油灵物。

- **增厚根基**（核心功效）：地灵乳的土行精华可以滋润修士的根基，使修为更加稳固。对于根基不稳、修为虚浮的修士来说，地灵乳是最好的补药——它不像其他灵药那样猛烈提升修为，而是像大地一样厚实稳重，慢慢夯实基础。一粒地灵丹服下，可省去十年苦修般的根基打磨。
- **地灵丹**（五阶丹药，核心用途）：以地灵乳为主材，辅以厚土根、地黄精、万年石髓等，可炼地灵丹。此丹是土属性修士突破境界的绝佳助力，亦是非土属性修士稳固根基的至宝。突破大境界前服用一枚地灵丹，成功率可提升三成。
- **洗髓伐骨**：地灵乳中的地精粉可渗透骨髓，清除骨髓中的杂质毒素。每十日服一滴，连服一年，可令骨骼由白转玉、由玉转金，肉身强度大幅提升。此过程称为"地髓炼骨"，是体修梦寐以求的造化。
- **修复经脉**：地灵乳对受损经脉有极佳的修复效果。曾有金丹修士与人大战，经脉碎裂七成，医修断言再无望恢复。后得一瓶地灵乳，每日以之涂抹全身并以灵力炼化，三年后经脉尽复，且比受伤前更加坚韧宽大。
- **培植灵草**（非服用用途）：地灵乳以千分之一的比例兑入灵泉水中，用来浇灌灵草，可大幅加速灵草生长、提升灵药品阶。高阶灵植师无不珍藏地灵乳，关键灵草催熟时就靠它。
- **入阵**（阵法用途）：地灵乳可作为阵眼灵物，用于维持大地属性阵法的运转。一滴地灵乳可让一个四阶土行防御阵法持续运转三年不竭。

## 产地

地灵乳产自大地灵脉的节点深处，是大地的"血液"。它的生成需要两个条件：一是极其纯净的土灵脉，二是地脉压力足够大的环境——只有在地底深处、灵脉交汇处，灵气才能被压缩成液态。

- **地肺深处**——地脉最浓郁的所在，通常是十万丈之下的地心区域。此地灵压极大，寻常修士根本无法抵达，至少需要化神期以上的修为，配合土遁神通方可深入。地肺深处的地灵乳品质最高，称为"先天地灵乳"，蕴含一丝开天辟地时残留的混沌土气
- **大型灵脉的节点**——七阶以上的土灵脉，在灵脉交汇的节点处，有时会自然形成地灵乳池。这种地灵乳品质稍逊于地肺深处所产，但胜在产量相对较大，是修真界市面上地灵乳的主要来源
- **万年钟乳洞**——某些特殊的钟乳石洞中，石笋尖端的钟乳液经过万年积累，会转化为地灵乳。这种地灵乳产量极稀少，一个万年钟乳洞百年不过产三五滴，但带有一丝石中精华，效果偏向强筋健骨

地灵乳的采集极为讲究——必须选择地脉之气最旺的时辰（通常是子时到寅时之间），以灵玉制成的容器承接。容器不可太大，以小玉瓶为佳，每瓶盛装十滴即可。

## 年份与效力

地灵乳非草木，不按年份分级，而是按"纯度"区分：

- **三成纯度**：乳白色偏稀，灵光微弱——百年以内的地脉灵气凝结而成。可炼下品地灵丹，对筑基期以下有效
- **七成纯度**：乳白浓稠如膏，表面灵光明亮——五百年以上的沉淀积累。可炼中品地灵丹，对金丹元婴修士有效
- **十成纯度**：乳白中透出淡淡金色，状如融化的羊脂玉——三千年以上的地脉结晶。称为"金髓地灵乳"，可炼上品地灵丹，对化神以上修士亦有大用。此时地灵乳的灵光已凝而不散，在玉瓶中晃晃悠悠如同有生命一般

## 配伍

- **相生**：与厚土根同用，土行相生，地灵丹品质可提升一阶；与地黄精配伍，药力温和持久，适合长期服用筑基
- **相克**：忌与庚金类灵药大量同服——土生金，金气过盛反盗土气；忌与青龙木等木行至宝同服——木克土，药力会相互削弱
- **禁忌配伍**：不可与吞天蟒的蛇涎同用——蛇涎有极强的腐蚀性，会破坏地灵乳的灵性结构，使其化为毫无用处的浊水。曾有丹师贪图蛇涎的某种药性，将此二物同炉，开炉后满地浊水，百滴地灵乳毁于一旦

## 轶事

地灵乳在大地上存在的历史，比人类修仙还要久远。

传说天地初开之时，清气上升为天、浊气下沉为地。大地初成，尚不稳定，天道以大法力将一缕混沌土气封入地心深处，作为大地的"根基"。这缕混沌土气在亿万年中不断渗入地脉，与灵气结合，便化为了地灵乳。

所以地灵乳中其实蕴含着一丝开天辟地时的大道余韵。若能获得足够多的先天地灵乳并炼化入体，理论上可以感悟到土行大道的本源。

万年前有一位名为"厚土尊者"的大乘期修士，便是凭借在地肺深处闭关五千年，吸收了一整池先天地灵乳，参悟出"厚土载物"的大道真意，最终以土行大道渡劫飞升。他飞升之前，在闭关之地留下半池地灵乳，并刻下一行大字：

"后辈有缘者得之，莫负大地厚德。"

此后万年间，不知有多少修士深入地下追寻厚土尊者的闭关遗址，但至今无人寻获。有人说那半池地灵乳已被厚土尊者的传人取走，也有人说厚土尊者飞升时将整座洞府都带入了仙界。

但修真界始终流传着一句话：地灵乳不在于寻，而在于等——大地自有其意志，只有真正有缘之人，才能遇见大地馈赠的宝物。
