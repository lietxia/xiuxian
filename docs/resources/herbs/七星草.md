# 七星草（三阶灵药）

## 外观

七星草形如车前草而略小，叶片肥厚多汁，椭圆状，长约二三寸。最显著的特征是叶面七枚银白色斑点排列成北斗七星形状——天枢至瑶光，七枚斑点大小亮度各不相同，与天上北斗一一对应。七星草之名由此而来。

叶片底色墨绿，边缘微卷，表面覆一层细密白绒毛，触感柔软如丝绸。叶背淡紫色，有清晰网状脉络。整株紧贴地面，十余片叶子从根部放射状展开，宛如一朵绿色星花。

七星草花开极小，淡黄色，簇生叶丛中央，花期仅三日。花开时七枚银斑会微微发光，夜间尤为明显，仿佛地上的星星与天上北斗遥相呼应。此景名曰"星叶相映"，引得不少修士月夜专门观赏。

其气味极淡，揉碎叶片后方能嗅到一股青涩草腥——那是它的汁液特有的味道。

## 药性

- **性味**：性凉，味苦涩
- **五行**：偏水木二行——水主润下，木主生发，汁液中水行精华是制符关键
- **归经**：不入正经，专走络脉
- **毒性**：无毒。但汁液沾肤会留下一层银白印记，三五日方褪，故采者必戴手套
- **禁忌**：不可与火属性灵草同种——火克金，七星草叶上银斑属金性，火气太旺则银斑黯淡

## 功效

七星草不用于炼丹服食，其真正价值在于制符。

- **七星符纸**（核心用途）：将叶片捣烂取汁，与上等青竹纸浆混合，经浸泡、捶打、晾晒、压平四道工序制成符纸。七星草汁中的银斑精华使纸张具有天然灵力亲和力——用此符纸画符，灵力传导效率比普通符纸高出三至五倍。修真界七成以上商业符纸均含七星草成分。
- **星辉墨汁**（三阶配方）：七星草汁液混合朱砂、灵兽血、辰砂粉末调和成墨。用此墨画符，符箓威力可提升两成。
- **七星灵液**（二阶药方）：全草捣碎取汁兑入灵泉水发酵七日，可用于修补破损符箓，恢复其七成灵力。
- **驱虫**：晒干点燃产生的烟雾可驱赶蚊虫和低阶毒虫，炼气期修士山野露宿常备。
- **外敷止血**：新鲜叶片捣烂外敷可治普通外伤出血，但以七星草疗伤无异于暴殄天物。

## 产地

七星草适应性强，有充足水源、适中灵气和合适温度即可生长。一阶灵脉以上便可，但三阶灵脉上生长的品质最佳。喜湿润半阴，不耐暴晒，偏好疏松肥沃砂质土壤。

主要产地：
- **天符宗灵田**：拥有三千亩七星草田，年产数十万斤，供应半个修真界的符纸原料。天符宗还培育出"优种七星草"——叶片更大、银斑更亮、汁液更丰富
- **江南水乡**：多雨湿润，河网纵横，野生七星草随处可见。当地散修常采集卖给符箓商行换取灵石
- **东荒沼泽**：水源充沛，野生品质极佳，但多毒虫妖兽

七星草生长周期极短——播种到成熟仅三个月，一年可收三至四季。收割时齐根割叶保留根部，二十天后新叶复生，一株可连续收割三至五年。因产量极高，七星草是真正的"平民灵草"。

## 年份与药效

七星草与年份关系不大。真正影响品质的是灵气浓度、水源品质和土壤肥力。超过五年的老株叶片反而变薄变硬，出汁率下降，故有经验者种三年后全部翻新。

唯有一例外——"百年野生七星草"，生长于深山幽谷未经人工干预者。因常年吸收地脉灵气，银斑由银白渐变为淡金，称"金星七星草"。其汁液制成的符纸可承载金丹期以上高阶符箓的灵力，是符师们争相收购的珍品。

## 配伍建议

**最佳配伍**：
- 七星草汁液 + 青竹纸浆 → 七星符纸
- 七星草汁液 + 朱砂 + 灵兽血 → 星辉墨汁
- 七星草 + 灵泉水 → 七星灵液

**禁忌配伍**：
- 七星草 + 赤阳花：火行之力灼伤叶片
- 七星草 + 硫磺矿粉：燥烈之气破坏汁液灵力结构
- 七星草 + 寒铁粉：阴寒之气使汁液凝固

## 相关典故

千年前，符师"星符子"出身贫寒，买不起高阶符纸，便亲自种七星草制作符纸。他种的七星草银斑特别亮，制出的符纸品质不逊于大宗门上等符纸。

星符子花费三十年培出一种新种七星草——叶上七枚银斑不再排成北斗，而是按他自创的"七星聚灵阵"阵眼排列。用此草制符纸，画符时可自动吸收天地灵气，符箓威力提升一倍！天符宗宗主亲至欲高价收购此法，星符子笑拒："此草乃天地造化，非我一人之功。"

他将新种命名为"聚灵七星草"，种子免费分与天下符师。此后百年间，此草在修真界广为种植，极大提升了符箓整体水平。天符宗感佩其胸襟，在总坛立铜像一座，底座刻八字："一草济世，万符生辉。"

如今修真界最大众的七星符纸，因其造价低廉、品质稳定，被戏称为"散修的第一张符纸"——每一个从炼气期开始学画符的修士，都曾在七星符纸上画下人生中第一道符箓。
