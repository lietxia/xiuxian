# 青木藤（三阶灵药）

## 外观

青木藤，其名源于其色——藤蔓通体翠绿如碧玉，在阳光下泛着温润的光泽。其藤细长柔韧，粗如儿臂，可蔓延数十丈，攀附于大树或岩石之上。

最奇在其"韧性"——青木藤的藤蔓极难折断，以手拉扯会感到一股强大的弹力，松手后藤蔓会迅速恢复原状。以法宝级别的利器方可切断——普通法器砍上去，只会溅出一串火星。

叶片掌状五裂，叶面深绿，叶背淡绿，有细密的绒毛。叶脉呈放射状，如同一幅微缩的阵图。

其花极小，藏于叶腋间，淡黄色，不仔细看几乎发现不了。但其花香却很独特——不是浓烈的香气，而是一种若有若无的清甜气息，如同从很远的地方飘来的青木清香。

其气清香淡雅，闻之感到一股蓬勃的生机——仿佛置身于春天的森林之中。

## 药性

- **性味**：性温，味甘辛，入口如嚼青草
- **五行**：偏木土二行——木主生发，土主承载，木土相生故能强筋健骨
- **归经**：入肝经（肝主筋）、肾经（肾主骨）
- **毒性**：无毒，药性温和
- **禁忌**：阴虚火旺者慎用

## 功效

青木藤可续筋接骨、强筋健骨，乃体修日常修炼的辅助圣品。

- **续筋接骨**（核心功效）：青木藤能续接断裂的筋骨——修士因斗法导致的筋断骨折，以青木藤捣烂外敷，可在七日内续接筋骨。
- **强筋健骨**：长期服用青木藤汁液，可使筋骨强度提升三成——体修者常以此物作为日常辅助修炼之品。
- **青木藤强筋丹**（三阶丹药）：以青木藤为主药，配伍续骨草、自然铜、骨碎补炼制。服后可永久提升筋骨强度两成。
- **藤蔓炼器**：青木藤的藤蔓可编织成内甲——穿上后可抵挡金丹期修士的全力一击。
- **服用感受**：入腹后感到一股温和的力量从胃部向四肢扩散，所过之处筋骨酥麻，如同被一双无形的大手按摩。

## 产地

青木藤喜生于温暖湿润、阳光充足的森林——需满足三个条件：其一，有古树可供攀爬；其二，土壤湿润但不积水；其三，周围有灵脉经过。

已知产地：
- 南疆·古林：南疆十万大山的原始森林中，青木藤在古树上攀爬生长。但森林中多毒蛇猛兽，采集困难
- 东荒·藤谷：东荒有一处山谷，谷中青木藤密布，如同一片绿色的海洋。但山谷中有迷阵，外人难以深入
- 中原·山坡：中原的山坡上，青木藤在灌木丛中生长。但山坡上多农户，采集时需避开农田

采集青木藤须在春季进行——此时藤蔓最为柔韧，药力最为充沛。切割时需以法宝级别的利器——普通法器无法伤其分毫。

## 相关典故

上古时期，有一位木神名"句芒"，掌管天下草木。句芒有一根青木藤，是其本命法宝——藤蔓可长可短，可刚可柔，能捆仙缚神。

句芒晚年时，将青木藤的一段枝条插入人间，化为一片青木藤林。从此，人间便有了青木藤——它继承了句芒木神的生机与韧性。

第一位发现青木藤妙用的是一位体修。他在斗法中筋断骨折，奄奄一息之际，看到一根青木藤在风中摇曳。他本能地拔藤敷于伤口，筋骨竟然在七日内完全愈合。

体修大喜，将此事告诉同门。同门们纷纷采集青木藤作为疗伤药材。青木藤从此在体修中广为流传，成为续筋接骨的圣药。

修真界至今仍流传着一句话："青木藤，句芒枝。续筋骨，强体魄。"体修在修炼时，都会以青木藤为辅——因为它药性温和，效果显著，且能永久提升筋骨强度。
