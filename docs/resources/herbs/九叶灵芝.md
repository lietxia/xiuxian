# 九叶灵芝（天阶中品）

## 外观

九叶灵芝生于万丈峭壁之阴面，得地脉阴气滋养，受日月之华而不露。其形如扇，九片芝叶层层叠叠，自根部螺旋而上，每片叶子边缘泛金，叶面却嫣红如血，以手触之温润如玉，细观可见叶脉中隐隐有赤色流光游走。

其气清香而不浓烈，闻之令人神清目明，修行者靠近三尺之内，可觉丹田灵力微生感应。若是月圆之夜，九叶灵芝会散发淡淡红芒，远望如一点朱砂缀于崖壁之间。相传九叶齐全时，灵芝上方会形成一圈淡金色的光晕，宛如佛光，持续一夜方散。

更奇者，九叶灵芝的叶片会随时辰流转而微微颤动，每片叶子的朝向各不相同，仿佛在吸收不同方位的天地灵气。曾有高僧云游至此，见灵芝叶片颤动之态，从中悟出一套掌法，名为"九叶掌"，流传至今。

## 药性

- **性味**：性平微温，味甘中带苦
- **五行**：偏木火二行，木主生发，火主气血，木火相生故药力绵长
- **归经**：入心、肝、脾三经，兼走十二正经
- **毒性**：无毒，但年份不足五百年者药力猛烈，未经炼化直接服用可能导致经脉胀痛、气血逆行
- **禁忌**：阴虚火旺者慎用；服用期间忌食辛辣、腥膻之物；不可与朱砂、雄黄同服

## 功效

九叶灵芝乃淬炼肉身、增进修为的上品灵药。其功效与叶数直接相关，每增一叶药力翻倍。九叶齐全者，有脱胎换骨之效。

- **灵芝换骨丹**（天阶中品丹方）：以九叶灵芝为主药，辅以千年地黄精、血玉髓、龙骨粉炼制。服用后筋骨重塑，脱胎换骨，炼体修士突破瓶颈的成功率提升三成。元婴期以下修士服用，可硬抗同阶法宝一击而不伤。
- **九叶灵液**（天阶下品）：取九叶灵芝一片，以灵泉浸泡七日，辅以百年雪莲、玉蜂蜜调制。外敷可生肌活血、断骨续接；内服可增百年修为。对走火入魔导致的内伤有奇效，能在七日之内修复断裂经脉。
- **九叶护心散**（地阶上品）：九叶灵芝磨粉，配以珍珠粉、血竭末。用于心脉受损、心魔入侵之时，可护住心脉不失。紧急情况下来不及炼丹，直接口嚼九叶灵芝叶片亦可保命，但药力浪费七成。
- **服用感受**：初入口时甘甜满颊，随即一股热流自丹田升起，扩散至四肢百骸。药力如潮水般冲刷经脉，每冲刷一次，经脉便拓宽一分、坚韧一分。整个过程持续三日，期间修士需运功引导，不可中断。

## 产地

九叶灵芝仅生长于人迹罕至的万丈峭壁之上，且需满足三个条件：其一、崖壁朝北，终年不见烈日直射；其二、崖下必有阴河暗流，水汽上蒸形成独特小气候；其三、方圆百里内必有灵脉穿过。

主要分布在四大区域：
- **东荒断魂崖**：崖高三千丈，罡风终年不息。崖下有阴河名为"黄泉暗流"，此地九叶灵芝品质最佳，但守护妖兽乃是一条千年毒蟒，生有三目，目射毒光。
- **南疆迷瘴谷**：谷中终年毒雾弥漫，凡人入之即死。谷内峭壁之上偶有九叶灵芝出没，但毒雾与灵芝灵气混合，形成了特有的"瘴灵芝"，药性中带着三分毒性——用好了是以毒攻毒的圣药，用不好则是催命毒药。
- **昆仑阴面**：昆仑山脉北坡，常年积雪不化，罕见的冰属性九叶灵芝在此生长。叶片边缘泛蓝而非金色，药性偏寒，专治火毒入体。
- **散修秘境**：据传一些上古秘境中亦有九叶灵芝，年份动辄数千年，可惜秘境入口难寻。

采集之难，不在灵芝本身，而在其生长之地。万丈绝壁，罡风如刀，更有妖禽盘踞守护。曾有金丹修士为采一株七叶灵芝，坠崖而亡。常见守护妖兽有：铁翼鹰（金丹初期）、三目毒蟒（金丹后期）、乃至罕见的岩甲蜥（元婴初期）。

采参之法亦有讲究：
- **望气法**：先于远处观测崖壁，灵芝生长处必有若隐若现的赤色灵光，如烟如雾。有经验的采药人能凭望气判断灵芝的年份和叶数。
- **引蛇法**：若遇毒蟒守护，不可强攻。以雄黄酒混合麝香制成药丸，投至远处，毒蟒闻之必去追逐，趁此时机速采灵芝。
- **绳索法**：采药人以特制的蛟筋索系于腰间，由同伴在山顶固定，悬垂而下。须在罡风间歇的瞬息之间完成采摘，否则会被罡风吹得撞向崖壁，粉身碎骨。

## 年份与药效

- **百年（三叶以下）**：初具灵性，芝叶只开三片以下，可做普通疗伤丹药，能固本培元，对炼气期修士有效
- **五百年（五叶）**：药力初成，五叶齐开，可炼换骨丹，对筑基修士大有裨益，能助其突破至筑基后期
- **千年（九叶）**：大圆满之态，九叶齐齐绽放，可助元婴修士淬炼肉身，渡肉身劫时多三分把握
- **三千年（九叶转金）**：芝叶边缘的金色向叶面蔓延，开始转为"金芝"之态，药力是普通九叶灵芝的三倍
- **万年（金芝）**：传说中九叶已由赤红转为通体淡金，被称为"金芝"，叶脉中流动的不再是红色而是金色灵光。服之可肉身成圣，万法不侵。修真界已有三万年未曾见过金芝现世。

## 配伍建议

**最佳配伍**：
- 九叶灵芝 + 千年地黄精 + 血玉髓 → 灵芝换骨丹（肉身重塑）
- 九叶灵芝 + 雪莲子 → 水火既济散（调和阴阳、中和药性）
- 九叶灵芝 + 龙血参 → 双龙换骨汤（双倍强化，但药力极猛，非元婴不可试）
- 九叶灵芝 + 朱果 → 气血双补，适合炼体修士日常服用

**禁忌配伍**：
- 九叶灵芝 + 毒龙草：药性相冲，会产生剧毒
- 九叶灵芝 + 五灵脂：五灵脂破血行气，会削弱灵芝药力
- 九叶灵芝 + 雄黄：雄黄燥烈，灵芝温补，合用则燥热伤身

## 相关典故

上古时期，炼体流盛行之年代，九叶灵芝乃炼体修士梦寐以求之物。相传体修大能"铜骨上人"曾得一株千年九叶灵芝，炼化之后肉身硬抗金丹雷劫而无损，自此开创了"以力证道"一脉。

另有一个凄美的传说：古时有位女修，为救道侣深入绝壁采九叶灵芝，灵芝旁有一条千年毒蟒守护。女修与毒蟒搏斗七天七夜，最终斩杀毒蟒，自己也力竭而亡。她的血溅在灵芝上，从此九叶灵芝的叶片才有了那一抹嫣红。

还有一个鲜为人知的典故：三千年前，佛门高僧"药王菩萨"曾以九叶灵芝为主药，炼制了一炉"九转金身丹"，赠予当时的佛门护法金刚。金刚服后，肉身化作金身，刀枪不入、水火不侵，后来在正魔大战中以一己之力挡下了魔道三位大能的围攻，为正道争取了宝贵的时间。药王菩萨将此丹方刻于洛阳白马寺的石碑上，至今仍有拓本流传于世。

东荒一带的采药人中还流传着一句话："九叶灵芝九片叶，一片叶一条命。"意思是每一片九叶灵芝的背后，都有一条采药人的性命。虽是夸张之词，却也道尽了此物的难得与珍贵。

修真界拍卖场上，一株完整的千年九叶灵芝曾拍出八万中品灵石的天价，相当于一座小宗门三年的开销。即便是单片芝叶，在市面上的售价也不低于三千中品灵石，且时常有价无市。
