# 九叶灵芝（天阶中品）

## 外观

九叶灵芝生于万丈峭壁之阴面，得地脉阴气滋养，受日月之华而不露。其形如扇，九片芝叶层层叠叠，自根部螺旋而上，每片叶子边缘泛金，叶面却嫣红如血，以手触之温润如玉，细观可见叶脉中隐隐有赤色流光游走。

其气清香而不浓烈，闻之令人神清目明，修行者靠近三尺之内，可觉丹田灵力微生感应。若是月圆之夜，九叶灵芝会散发淡淡红芒，远望如一点朱砂缀于崖壁之间。

## 药性

- **性味**：性平微温，味甘中带苦
- **五行**：偏木火二行，木主生发，火主气血
- **毒性**：无毒，但年份不足五百年者药力猛烈，未经炼化直接服用可能导致经脉胀痛

## 功效

九叶灵芝乃淬炼肉身、增进修为的上品灵药。其功效与叶数直接相关，每增一叶药力翻倍。九叶齐全者，有脱胎换骨之效。

- 炼化后可大幅增强肉身强度，使筋骨如钢似铁
- 修复受损经脉，对走火入魔导致的内伤有奇效
- 可炼 **灵芝换骨丹**，助修士重塑筋骨，突破肉身瓶颈
- 亦可炼 **九叶灵液**，外敷可生肌活血，内服可增百年修为

## 产地

九叶灵芝仅生长于人迹罕至的万丈峭壁之上，且需满足三个条件：其一、崖壁朝北，终年不见烈日直射；其二、崖下必有阴河暗流，水汽上蒸形成独特小气候；其三、方圆百里内必有灵脉穿过。

采集之难，不在灵芝本身，而在其生长之地。万丈绝壁，罡风如刀，更有妖禽盘踞守护。曾有金丹修士为采一株七叶灵芝，坠崖而亡。

## 年份与药效

- **百年（三叶以下）**：初具灵性，可做普通疗伤丹药，能固本培元
- **五百年（五叶）**：药力初成，可炼换骨丹，对筑基修士大有裨益
- **千年（九叶）**：大圆满之态，九叶齐开，可助元婴修士淬炼肉身，渡劫时多三分把握
- **传说有万年九叶灵芝**，芝叶已由赤红转为淡金，被称为"金芝"，服之可肉身成圣，但从未有人见过

## 相关典故

上古时期，炼体流盛行之年代，九叶灵芝乃炼体修士梦寐以求之物。相传体修大能"铜骨上人"曾得一株千年九叶灵芝，炼化之后肉身硬抗金丹雷劫而无损，自此开创了"以力证道"一脉。

另有一个凄美的传说：古时有位女修，为救道侣深入绝壁采九叶灵芝，灵芝旁有一条千年毒蟒守护。女修与毒蟒搏斗七天七夜，最终斩杀毒蟒，自己也力竭而亡。她的血溅在灵芝上，从此九叶灵芝的叶片才有了那一抹嫣红。
