# 厚土参（五阶灵药）

## 外观

厚土参，其名源于其形——如同一只从地底伸出的巨人手掌，五指张开，掌纹清晰，仿佛要破土而出抓住什么。通体土黄色，表面有细密的横向纹路，如同年轮，又像大地的断层纹理。

其大小不一——百年者如成人手掌，千年者如磨盘，万年者如一张大床。参体表面粗糙如岩石，却隐隐泛着一层油润的光泽，如同大地在呼吸。

最奇在其"指甲"。厚土参的五指顶端，各有一块颜色略深的硬块，形如指甲，质地坚硬如铁——此乃厚土参精华所聚，称为"土甲"，是药力最雄厚的部分。

厚土参无叶无花，只有从地下伸出的"手掌"部分露出地面。地面以下，它的根系蔓延数十丈，与周围土壤融为一体——若不仔细分辨，很难将厚土参与周围泥土区分开来。

其气厚重如雨后泥土的芬芳，闻之令人感到踏实、安稳，仿佛脚下的大地变得更加坚实。

## 药性

- **性味**：性温，味甘厚如蜂蜜，入口绵密
- **五行**：纯土属性，得大地最本源之气
- **归经**：入脾经、胃经，兼走奇经八脉
- **毒性**：无毒，但药力厚重——修为不够者服用会感到全身沉重如被大地压住，动弹不得，需三日方可缓解
- **禁忌**：木灵根修士慎用——木克土，药力相冲

## 功效

厚土参可令修士与大地之力沟通，乃土系功法修士梦寐以求的圣品。

- **大地沟通**（核心功效）：服用厚土参后，修士可获得与大地沟通的能力——脚踏大地时，可感知方圆百丈内的地面震动、地下水流、矿脉走向。此能力对寻找灵脉、矿藏、地下暗河极为有用。
- **土遁术辅助**：修炼土遁术的修士，服用厚土参后土遁速度提升三倍，且遁地深度增加十倍。
- **厚土护体丹**（五阶丹药）：以厚土参为主药，配合地龙筋、万年石髓炼制。服后可在体表形成一层"厚土护甲"，防御力堪比同阶防御法宝。
- **土灵根提升**：土灵根修士服用后，灵根品质可提升一阶——下品升中品，中品升上品。
- **服用感受**：入腹后感到一股厚重之力从丹田下沉至双脚，随后双脚如同生根入地，与大地连为一体。此时若运功，可感到大地之力源源不断涌入体内，无穷无尽。

## 产地

厚土参只生长在地脉最浓郁的"土穴"之中——需满足三个条件：其一，地下百丈处有上品土灵脉经过；其二，地表为黄土高原或深厚土层，不可有岩石裸露；其三，方圆十里内不可有水源——水克土，水源会削弱地气。

已知产地：
- **中州黄土高原**：天下第一厚土参产地。黄土层厚达千丈，地脉浓郁，所产厚土参品质最佳。但黄土高原已被三大宗门瓜分，外人不得入内
- **西漠地下绿洲**：西漠沙漠地底深处有一处地下绿洲，绿洲下方的土壤中偶有厚土参生长。但沙漠中方向难辨，寻找绿洲本身便是九死一生
- **南疆红土地**：南疆十万大山的红色土壤中，厚土参与红土融为一体，极难辨识。当地苗民有独特的寻找之法——观察地面是否有微微隆起的手掌形土包

采集厚土参不可使用金属工具——金克土，金属触碰会使厚土参瞬间缩入地下深处。必须以木铲或玉铲，从参体外围一尺处开始挖掘，逐渐向中心靠拢，最终将整株连根取出。

更麻烦的是，厚土参会"逃跑"——当它感知到危险时，会缓慢地向地下缩回。虽然速度极慢（一日不过寸许），但若不及时挖掘，三天后便会缩入地下百丈，再也无法采得。

## 配伍建议

**最佳配伍**：
- 厚土参 + 地龙筋 + 万年石髓 → 厚土护体丹
- 厚土参 + 地灵乳 + 千年茯苓 → 土行归元汤
- 厚土参 + 人参 → 双参汤（土行双补）

**禁忌配伍**：

- 厚土参 + 水源附近采集的灵药 → 水克土，药力削弱

## 相关典故

上古时期，大地之上有一位土神名"后土"，掌管大地万物。后土有一独子，名"句芒"，生性好动，不愿困于大地，整日向往天空。

后土为让儿子安心，从自己掌心拔下一根汗毛，吹口仙气，化为一枚人参落入大地。此参形如手掌，得后土精血，蕴含大地本源之力。

后土对句芒说："此参名厚土，你若能与它心意相通，便能知晓大地的心声。当你听懂了大地，便不会再向往天空。"

句芒半信半疑，将厚土参服下。刹那间，他听到了大地的声音——河流是大地在歌唱，山脉是大地在呼吸，地震是大地在打鼾，矿脉是大地在积蓄力量。

句芒从此安于大地，成为第二代土神。而那株厚土参的种子，则散落人间，在各地的土穴中生根发芽。

修真界至今仍流传着一句话："厚土参，大地掌。服下去，听地响。"土系功法修士在服用厚土参前，都会先俯耳于地，聆听大地的声音——据说这样能增加与厚土参的亲和力，使药效倍增。
