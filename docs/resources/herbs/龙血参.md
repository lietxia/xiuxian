# 龙血参（天阶中品）

## 外观

龙血参乃天地灵气汇聚于龙脉之上，经万年孕育而成的天地灵根。其形如人参，却比寻常人参大出数倍，通体赤红如血，根须虬结盘错，远远望去如同一团燃烧的火焰。

最奇处在于其根须——寻常人参的根须细碎散乱，龙血参的根须却仿佛有生命一般，蜿蜒扭曲如龙形，五条主根各具姿态，或如龙爪探爪，或如龙尾摆动。有人曾得千年龙血参一株，其根须天然形成"五龙戏珠"之态，被视为无价之宝。

龙血参表皮粗糙，遍布细密鳞片状纹路，以指叩之发出金石之声。若以利刃划开表皮，会渗出殷红如血的汁液，浓稠如蜜，散发出浓郁的血腥味与药香混合的气息。

## 药性

- **性味**：性大热，味甘中带辛
- **五行**：纯土属性，借龙脉之势而生，蕴含土行厚德载物之力
- **毒性**：有小毒。未经炮制直接服用，会导致气血逆行、七窍流血，需以甘草、金银花等解毒药材配伍

## 功效

龙血参的药力霸道刚猛，乃淬炼肉身、强化气血的无上灵药。

- 炼化后可极大增强肉身力量，使修士拥有龙象之力
- 修复受损的骨骼经脉，断骨重生不在话下
- 可炼 **龙血锻体丹**，大幅提升肉身强度，元婴期以下修士服用后可肉身硬抗法宝一击
- 可炼 **血参补天膏**，治疗道基受损、灵根破碎等重症——虽然不能完全修复，却能稳住伤势争取时间
- 取一滴龙血参汁液，配合朱砂书写的符箓，威力可增三成

## 产地

龙血参只生长在地底龙脉或地表龙脉节点上。所谓龙脉，并非真有龙居于地下，而是山脉走势如龙、灵气汇聚如脉的特殊地势。在风水堪舆中称为"真龙结穴"之处，方有可能孕育出龙血参。

采集龙血参极为凶险。龙脉之地必有强大妖兽盘踞，而且龙血参一旦感应到有人靠近，会主动收敛气息，将根须缩入岩石深处。采参人必须以自身灵力与之沟通，如同驯服一匹烈马，稍有不慎就会惊走灵药。

更麻烦的是，龙血参生长之处往往紧邻地火岩浆，温度极高，非金丹修士无法靠近。

## 年份与药效

- **百年龙血参**：赤红如朱砂，根须已具龙形初态，可助金丹修士强化气血
- **千年龙血参**：色泽转为暗红，根须盘结如龙蟠，汁液浓稠如膏，可炼龙血丹，对元婴修士大有裨益
- **万年龙血参**：通体转为紫红，根须之上的鳞片纹路清晰可见，更有龙威隐隐散发。服用后可获真龙之体的一丝特性，但已有数千年不曾出产

## 相关典故

相传上古时期有一条真龙陨落于东荒山脉，其血肉融入大地，龙魂散入山川，形成了那一带的龙脉地势。后来龙脉之上长出了龙血参，世人认为那是真龙精血所化。

这自然是传说。但东荒龙血参确是天下第一，至今无人能超越。

千年前有位散修名号"药痴"，穷尽毕生心力寻找万年龙血参。他踏遍群山，最终在东荒无名深谷中发现了一株。但龙血参感应到他的气息，瞬间缩入地底百丈。药痴不肯放弃，在谷中坐了三十年，每日以自身灵气温养那片土地，最终感动了龙血参——它主动破土而出，落入药痴手中。

药痴以此炼制了一炉龙血丹，服后突破至化神期。他后来开宗立派，创立了"百草门"，门训只有四个字：以诚待药。
