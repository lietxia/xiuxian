# 龙血参（天阶中品）

## 外观

龙血参乃天地灵气汇聚于龙脉之上，经万年孕育而成的天地灵根。其形如人参，却比寻常人参大出数倍，通体赤红如血，根须虬结盘错，远远望去如同一团燃烧的火焰。

最奇处在于其根须——寻常人参的根须细碎散乱，龙血参的根须却仿佛有生命一般，蜿蜒扭曲如龙形，五条主根各具姿态，或如龙爪探爪，或如龙尾摆动。有人曾得千年龙血参一株，其根须天然形成"五龙戏珠"之态，被视为无价之宝。

龙血参表皮粗糙，遍布细密鳞片状纹路，以指叩之发出金石之声。若以利刃划开表皮，会渗出殷红如血的汁液，浓稠如蜜，散发出浓郁的血腥味与药香混合的气息。这汁液遇空气后会迅速凝结，变成血红色的胶状物，乃是最上等的天然胶合剂——用来炼制法宝时加入一滴，可提升法宝的韧性与灵性。

龙血参的叶片也别具一格。其叶呈掌状，五裂如龙爪，叶色深绿近黑，叶脉却是血红色，像是血管般密布于叶片之上。每年盛夏时节，龙血参顶端会开出一簇紫红色的小花，花形如龙首，人称"龙抬头"，花期仅三天，花谢后会结出细小如米的红色种子。

据说龙血参在雷雨之夜会散发出一股极淡的龙吟般的嗡鸣声，方圆数里内的蛇类妖兽会本能地朝其方向跪伏——这是真龙气息的威压，存在于万年龙血参的周围。

## 药性

- **性味**：性大热，味甘中带辛，入口辛辣如烈酒
- **五行**：纯土属性，借龙脉之势而生，蕴含土行厚德载物之力，兼得一丝龙气
- **归经**：入脾经、肾经、心经，大补元气
- **毒性**：有小毒。未经炮制直接服用会导致气血逆行、七窍流血，需以甘草、金银花等解毒药材配伍。炮制之法：先以黄酒浸泡七日，再以武火蒸制三昼夜，方可入药。
- **禁忌**：阴虚火旺者禁用；高血压、有出血倾向者禁用；孕妇禁用；服用期间切忌动怒——怒则气血上涌，可能引发龙血参未散的燥烈之性
- **特殊体质**：天生火灵根的修士对龙血参的耐受度高于常人，而水灵根修士服用风险加倍

## 功效

龙血参的药力霸道刚猛，乃淬炼肉身、强化气血的无上灵药。

- **直接炼化**：炼化后可极大增强肉身力量，使修士拥有龙象之力。炼化过程极为痛苦——如同全身骨骼被一寸寸敲碎又重组，需有大毅力者方可承受。但熬过去之后，实力提升极为显著。
- **龙血锻体丹**（天阶中品）：以龙血参为主药，辅以龙骨粉、血竭、千年地黄精。大幅提升肉身强度，元婴期以下修士服用后可肉身硬抗法宝一击而毫发无伤。突破瓶颈时服用此丹，肉身强度能跟上修为提升，减少走火入魔的概率。据记载，服此丹后肉身强度可提升三倍。
- **血参补天膏**（天阶下品）：以龙血参配合万年石钟乳、玉髓、紫河车炼制。治疗道基受损、灵根破碎等重症——虽然不能完全修复，却能稳住伤势，争取寻找天材地宝的时间。修真界有言："只要有一口气，血参补天膏就能吊住。"但这膏药药性极热，涂抹之时如烈火灼身，需以寒冰诀同时运功镇之。
- **龙血灵符墨**：取一滴龙血参汁液，配合朱砂书写的符箓，威力可增三成。制符大师视龙血参汁为上等符墨材料，一张以龙血参汁绘制的"金刚护体符"，价值万金。
- **血参养元汤**（地阶上品）：龙血参切片，与金鸡内金、黄芪同炖。适合大战之后气血亏虚的修士，一碗汤下去，三日之内气血恢复如初。
- **服用感受**：服下龙血参后，一股热浪自丹田爆发，如同岩浆涌入经脉。全身皮肤会在一个时辰内变得通红，散发蒸腾热气。药力冲击经脉时，会产生剧烈的胀痛感，仿佛每一寸经脉都被撑开。但药力过后，会感到前所未有的力量充盈全身，举手投足间充满爆发力。七日内，食量大增，需大量进食妖兽肉以补充肉身炼化所需的气血。

## 产地

龙血参只生长在地底龙脉或地表龙脉节点上。所谓龙脉，并非真有龙居于地下，而是山脉走势如龙、灵气汇聚如脉的特殊地势。在风水堪舆中称为"真龙结穴"之处，方有可能孕育出龙血参。

已知产地：
- **东荒龙脊岭**：天下第一龙血参产地。山脉走势宛如一条卧龙，龙头在东、龙尾在西，绵延三千里。相传上古真龙陨落于此，龙脊化作了这条山脉。此地产出的龙血参品质最高，但与天符门、万妖谷两大势力接壤，争斗不断。
- **南疆火龙窟**：地底岩浆河与龙脉交汇之处，形成了一种特殊的火属性龙血参。参体呈暗红色，带有熔岩般的纹路，药性更具火毒，适合修炼火属性功法的修士。
- **西域龙脉古矿**：曾经是上古龙族的一处巢穴，后来龙族离去，地脉中残存龙气，长出了龙血参。但此处已被开采过度，如今已很难找到百年以上的参。
- **东海龙渊**：海底龙脉，孕育的龙血参带有水属性，呈紫红色而非纯红，被称为"水龙参"，极其罕见。

采集龙血参极为凶险。龙脉之地必有强大妖兽盘踞——最常见的是地龙蜥（金丹后期）、赤焰蟒（元婴初期），甚至有记载出现过蛟龙（化神期）守护万年龙血参。而且龙血参一旦感应到有人靠近，会主动收敛气息，将根须缩入岩石深处。采参人必须以自身灵力与之沟通，如同驯服一匹烈马，稍有不慎就会惊走灵药。

更麻烦的是，龙血参生长之处往往紧邻地火岩浆，温度极高，非金丹修士无法靠近。曾有采药人发现了一株千年龙血参，却因修为不够无法靠近，眼睁睁看着它在岩浆河对岸招摇，那种绝望比死还难受。

采参之法分三等：下等者以蛮力挖掘，会损伤参体，药效损失三成；中等者以灵力包裹参体，连根带土完整取出；上等者先在参旁静坐三日，以自身灵力与参灵沟通，待参灵放下戒心后，参会自动脱离岩石落入采参人手中——此法所得龙血参药效完整，且参灵不散，可移栽。

## 年份与药效

- **百年龙血参**：赤红如朱砂，长约一尺，根须已具龙形初态。可助金丹修士强化气血，市价约两千中品灵石。
- **三百年龙血参**：色泽渐深，表皮鳞片纹路初现。可炼制龙血丹，对金丹后期修士有效，市价约五千中品灵石。
- **千年龙血参**：色泽转为暗红，根须盘结如龙蟠，汁液浓稠如膏。可炼龙血锻体丹，对元婴修士大有裨益。市价两万中品灵石以上，拍卖会上往往翻倍。
- **三千年龙血参**：参体变为紫红色，已经初具灵智，会在地底穿行移动，极难捕捉。此时龙血参已可称之为"参妖"，不能以普通灵药对待。
- **万年龙血参**：通体转为紫红带金，根须之上的鳞片纹路清晰可见，更有龙威隐隐散发。服用后可获真龙之体的一丝特性——皮肤会长出淡淡的鳞片纹路，防御力大增。但已有数千年不曾出产，修真界现存的万年龙血参，都是上古传承下来的。

**禁忌配伍**：
- 龙血参 + 麻黄：两者皆辛散，同用则大汗不止，可能虚脱
- 龙血参 + 黄连：黄连大寒，龙血参大热，水火不容，轻则药力全失，重则经脉受损

## 相关典故

相传上古时期有一条真龙陨落于东荒山脉，其血肉融入大地，龙魂散入山川，形成了那一带的龙脉地势。后来龙脉之上长出了龙血参，世人认为那是真龙精血所化。

这自然是传说。但东荒龙血参确是天下第一，至今无人能超越。

千年前有位散修名号"药痴"，穷尽毕生心力寻找万年龙血参。他踏遍群山，最终在东荒无名深谷中发现了一株。但龙血参感应到他的气息，瞬间缩入地底百丈。药痴不肯放弃，在谷中坐了三十年，每日以自身灵气温养那片土地，最终感动了龙血参——它主动破土而出，落入药痴手中。

药痴以此炼制了一炉龙血丹，服后突破至化神期。他后来开宗立派，创立了"百草门"，门训只有四个字：以诚待药。

另有一则令人扼腕的故事：三百年前，百草门的一位长老发现了一株三千年龙血参，但他贪心不足，想等它再长两百年达到五千年药效再采。于是他在参旁布下隐匿阵法，每日以灵气温养。不料此事被魔道探子得知，趁长老外出之际，魔道修士闯入阵中夺参。那龙血参已有灵性，在争斗中竟自断根须，断了魔道修士的念想。长老回来后，看着一地残根，老泪纵横。他拼凑残根试图移栽，终究没能救活。自此百草门立下规矩：灵药可待，不可贪。到了该采的时候，就是最好的时候。
