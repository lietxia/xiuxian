# 款冬花（三阶灵药）

## 外观

款冬花，其名源于其性——"款冬"者，款待冬天也。此花于腊月开花，凌寒独放，在万物凋零的寒冬中绽放出淡紫色的小花，如同在冰雪中燃烧的火焰。

其形奇特——花先于叶开放，在光秃秃的根茎顶端，直接绽放出一朵淡紫色的花。花形如喇叭，花蕊金黄，花瓣五片，向外翻卷，如同一只张开的小手掌在迎接雪花。

最奇在其花苞。款冬花的花苞在秋季形成，外包层层草绿色鳞片，形如一颗微缩的洋葱。花苞在冰雪中越冬，待来年腊月绽放——花苞在冰雪中不会冻死，反而因寒冷而积累更多药力。

其根茎短而粗壮，呈黄褐色，地下有横走的根茎，在土壤中蔓延。叶片在花谢后才生出，形如圆肾，叶面深绿，叶背密生白色绒毛。

其气清香如薄荷，却比薄荷多了一丝温暖——闻之令人感到胸腔一阵温暖，如同喝下一碗热汤。

## 药性

- **性味**：性温，味辛甘，入口温暖
- **五行**：偏金火二行——金主肃降，火主温煦，金火相济故能温肺化痰
- **归经**：入肺经、大肠经
- **毒性**：无毒，药性温和
- **禁忌**：肺热咳嗽者忌用——款冬花性温，热症用温药如火上浇油

## 功效

款冬花可温肺化痰、止咳平喘，乃治疗寒性咳喘的圣品。

- **温肺化痰**（核心功效）：款冬花能温暖肺脏、化解寒痰——修士因寒气入肺导致的咳喘、痰多清稀，以款冬花煎水服用，可在三日内化解寒痰，平息咳喘。
- **款冬花汤**（三阶药方）：款冬花配伍紫菀、杏仁、百部、半夏，水煎服之。可治疗一切寒性咳喘——无论是风寒袭肺、寒痰阻肺还是肺寒咳喘，均有良效。
- **腊月采摘特效**：腊月采摘的款冬花，因经历了整个寒冬的淬炼，药力比普通季节采摘的强三倍。
- **冬病夏治**：在夏季服用款冬花，可预防冬季寒性咳喘的发作——此乃"冬病冬治"之法。
- **服用感受**：入腹后感到一股温暖的力量从胃部向肺部扩散，如同一团温暖的火焰在胸腔中燃烧。随后会感到肺部逐渐放松，呼吸变得顺畅，痰液变得稀薄易咳。

## 产地

款冬花喜生于寒冷地区的山野、路旁、溪边——需满足三个条件：其一，冬季气温极低，有冰雪覆盖；其二，土壤排水良好，不可积水；其三，周围有岩石或灌木遮挡寒风。

已知产地：
- **北原雪原**：北原的冬季漫长而寒冷，款冬花在雪原边缘的山坡上生长。每年腊月，淡紫色的款冬花在白雪中绽放，如同一颗颗紫色的宝石
- **昆仑山雪线**：昆仑山脉的雪线附近，款冬花在岩石缝隙中生长。此处温度极低，但款冬花却能正常生长
- **北极冰原边缘**：北极冰原的边缘地带，款冬花在短暂的夏季迅速生长，在冬季开花。此处款冬花因经历了极寒，药力最为强劲

采集款冬花须在腊月进行——此时花开最盛，药力最为充沛。采摘时需拨开积雪，以剪刀剪取花朵，不可用手拉扯——手温会灼伤花朵。

## 年份与药效

| 年份 | 特征 | 药效 |
|------|------|------|
| 一年生 | 花朵单朵，淡紫色 | 可治疗普通风寒咳嗽 |
| 三年生 | 花朵数朵，紫色渐深 | 可温肺化痰，对筑基期修士有效 |
| 十年生 | 花朵数十朵，紫色浓郁 | 可炼款冬花汤，对金丹期修士有效 |
| 五十年生 | 花苞在冰雪中越冬后绽放，花瓣边缘有冰晶 | 可治疗元婴期修士的寒性咳喘 |
| 百年生 | 整株散发淡紫色荧光，花朵在冰雪中绽放时周围冰雪融化 | 可治疗化神期修士的肺寒重症 |

## 配伍建议

**最佳配伍**：
- 款冬花 + 紫菀 + 杏仁 → 款冬花汤
- 款冬花 + 麻黄 + 细辛 → 温肺散寒汤
- 款冬花 + 百合 + 麦冬 → 润肺止咳汤

**禁忌配伍**：
- 款冬花 + 寒凉药物 → 药性相消
- 款冬花 + 热性药物 → 温上加温，伤阴耗气

## 相关典故

上古时期，有一位医圣名"张仲景"，以《伤寒论》闻名天下。张仲景晚年时，遇到一位奇怪的病人——一位修士，每到冬季便咳喘不止，痰多清稀，遍访名医无果。

张仲景诊脉后发现，此修士的肺脏被寒气侵袭，寒痰阻肺，导致咳喘。他翻遍医书，最终在一本古籍中找到了款冬花的记载："款冬花，腊月开花，凌寒独放，能温肺化痰，止咳平喘。"

张仲景采来腊月采摘的款冬花，配伍紫菀、杏仁等药，煎成款冬花汤让修士服下。三剂之后，修士的咳喘完全消失，寒痰尽化。

修士感激涕零，问张仲景："此花为何能在腊月开花？"

张仲景答："款冬花之所以在腊月开花，是因为它体内蕴含着一股纯阳之气——这股纯阳之气能抵御严寒，也能温煦肺脏。修士若能效法款冬花，在寒冬中保持纯阳之气，便不会被寒气侵袭。"

此事传开后，款冬花从一株普通的野花变成了修真界治疗寒性咳喘的圣药。

修真界至今仍流传着一句话："款冬花，腊月开。温肺脏，化寒痰。"医修在治疗寒性咳喘时，都会优先考虑款冬花——因为它药性温和，价格低廉，且效果显著。

每年腊月，医修们都会举行"款冬祭典"——采集款冬花，炼成款冬花汤，免费赠送给贫困的修士。这一传统已延续了万年，成为医修界最重要的节日。
