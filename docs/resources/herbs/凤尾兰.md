# 凤尾兰（天阶下品）

## 外观

凤尾兰只生长在凤凰曾经栖息过的地方。其形如兰，叶片细长弯曲如凤羽，最长的可达数尺，呈流线型向四周舒展，姿态优雅。叶色不是普通的绿——而是渐变的，从根部的翠绿逐渐过渡到尖端的火红，整片叶子仿佛燃烧的羽毛。

凤尾兰的花朵更是绝美。花茎高高抽出，顶端绽放数朵蝶形小花，花色从金黄到赤红不等，花瓣边缘镶着一圈淡金色的光晕。花朵排列如同凤凰的尾羽展开，随风摇曳时真的像一只凤凰在翩翩起舞。

凤尾兰的气息温暖而芬芳，如同春日的阳光和花朵混合的味道。靠近凤尾兰，会感到一种蓬勃的生机和一种高贵的气息——仿佛有一只神鸟在俯瞰着你。

令人称奇的是，凤尾兰周围永远不会有毒虫蛇蚁靠近，甚至连蚊虫都没有。据说这是因为凤凰的气息残留，万虫避让。

## 药性

- **性味**：性温，味甘香
- **五行**：火木双属性——火主生机勃发，木主生长不息。两种属性在凤尾兰体内完美融合，既有火的刚烈，又有木的柔韧
- **毒性**：无毒。凤尾兰是所有灵药中最温和的几种之一，几乎没有副作用

## 功效

凤尾兰是火木双修的至宝，对修士的体质改善和灵根提升都有奇效。

- 炼化后可改善体质，使修士同时获得火属性与木属性的亲和力——对单一灵根的修士来说，相当于多了一条灵根
- 可炼 **凤尾涅槃丹**，效如其名——重伤濒死之际服用，可以涅槃重生，不仅伤势痊愈，修为还可能更进一步
- 可炼 **凤灵护心丹**，在心脏处形成一道火木之力交织的护盾，可抵挡一次致命攻击
- 凤尾兰叶片焙干泡茶，长期饮用可美容养颜、使肌肤如玉般温润——女修最为追捧
- 传说凤尾兰的花瓣若缝入衣中，可驱邪避秽、百毒不侵

## 产地

凤尾兰的生长条件只有一个限制——必须有凤凰停留过。凤凰乃神兽，千年难得一见，所以凤尾兰的稀有程度可想而知。

已知的产地自古以来不超过五处：南海梧桐岛（传说凤凰唯一栖息的岛屿）、中州凤鸣山的凤凰崖、西域火焰山附近的赤焰谷、以及天南十万大山最深处的万木谷。其中梧桐岛已经有三千年没有凤尾兰出产的记录了——因为凤凰三千年没有在那里出现过。

采集凤尾兰不难——因为它没有凶兽守护（凶兽不敢靠近），难的是找到它。修真界有一些专门追踪凤凰踪迹的组织，他们通过研究古籍和天象来推测凤凰可能出现的位置，每一次发现都会引起轰动。

## 年份与药效

- **百年凤尾兰**：叶长一尺左右，翠绿多于火红，药性温和，可炼基本的护心丹
- **五百年凤尾兰**：叶长三尺，火红与翠绿各半，药力充沛，可炼涅槃丹——但效果有限
- **千年凤尾兰**：叶长五尺以上，火红占七分，翠绿占三分，叶片边缘有淡金光晕，可炼完整的涅槃丹，真正拥有涅槃重生的能力

## 相关典故

南海梧桐岛是凤凰最常出没的地方，因此也是凤尾兰的最大产地。岛上有一个隐秘的修仙世家——"凤家"，据说他们的祖先曾救过一只受伤的凤凰，凤凰为了报恩，在岛上留下了一滴精血和数根尾羽。

凤家以那滴精血和尾羽为根基，创出了一门名为"凤凰诀"的功法，与凤尾兰配合使用效果倍增。凤家的女修个个容颜绝世，而且涅槃丹的炼制方法是凤家的不传之秘。

但凤家也有一个诅咒：凡是修炼凤凰诀的族人，一生只能动情一次。如果所爱之人背叛了她，她会如同凤凰浴火一般焚身而死。千年来，已有七位凤家女修死于这个诅咒。

有人说，那不是诅咒，而是凤尾兰在告诉世人：凤凰的爱，一生只有一次。
