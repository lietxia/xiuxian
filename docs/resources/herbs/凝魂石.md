# 凝魂石

**品阶**：五阶灵物  
**别名**：锁魂石、聚魂玉、幽冥珠

## 形貌

凝魂石非寻常草木，乃天地间阴气精华凝结之石。其形浑圆如卵，大者如拳，小者如豆，色泽青灰，半透明如凝脂。石中常有烟霞流动，色呈淡紫或幽蓝，如魂魄在其中游走不定。

以灵目观之，可见石心深处有许多细若游丝的亮线交织，如蛛网般密布。此乃**魂络**——天然形成的魂魄凝聚纹路。魂络愈多愈密，凝魂石之品质愈高。

凝魂石触手冰寒，非寻常之冷，而似有阴风透骨而入，直刺神魂。凡人触之，轻则寒颤三日，重则魂魄受损。然鬼修及修炼魂魄法门者持之，则感温润舒适，如归母胎。

夜深之时，凝魂石会发出极淡的光芒，闪烁如鬼火。若有新死之魂在侧，可见石中光华微动，似与魂魄呼应。

## 性质

**五行**：水（五分）、阴（三分）、土（二分）  
**寒热**：大寒，纯阴  
**毒性**：有阴毒，阳体修士久持伤及阳气本源  
**归经**：入心经、肾经、入丹田

凝魂石秉北方太阴之精而生，出自九幽冥土之下，历经万年阴气滋养，方得成形。

## 效用

凝魂石乃傀儡炼制中最为珍贵之核心材料——**傀儡魂枢**的关键载体：

一曰**凝魂锁魄**。修士坐化之际，若将一缕残魂封入凝魂石中，可保百年不散。以此石为傀儡核心，能承载修士分魂或灵兽之魂，使傀儡自行应敌。

二曰**傀灵觉醒**。以此石为傀儡之心，可使傀儡拥有简陋灵性。铁木为骨、凝魂石为心，便如造物初生——能辨认敌我、自主战斗，甚至积累战斗经验，越战越强。

三曰**入丹炼魂**。凝魂石磨粉配**养魂木**、**万年灵芝**，可炼**凝魂固魄丹**，专治魂魄创伤。亦可炼**阴阳转生丹**，助夺舍修士稳固魂魄于新躯。

四曰**鬼修至宝**。鬼修持此修炼，可凝聚阴气，加速魂体凝实，修行速度倍增。

## 产地

凝魂石生于极阴之地：**九幽地缝**深处，或**古战场遗址**——千万修士亡魂散逸，阴气凝结而成。然此类石多含怨念，使用前须净化。**万年古墓**中，大能尸身散发的魂气与地脉阴气结合，亦可生之。

采集须以**阳火玉盒**盛装，以**纯阳真气**包裹。若裸手触碰，阴毒入体，非元婴以上不可驱除。曾有筑基修士偶得凝魂石贴身存放三日，醒来后记忆全失，形同白痴。

## 年份与药力

| 年份 | 特征 | 用途 |
|------|------|------|
| 千年 | 青灰色，光芒微弱 | 可纳筑基期残魂，维持数年 |
| 三千年 | 色泽深沉，魂络渐密 | 可纳金丹魂魄，可炼金丹傀儡 |
| 五千年 | 半透明如脂，紫烟流转 | 可纳元婴残魂 |
| 万年 | 石心紫光如星辰，魂络成天然阵纹 | 可纳完整元婴，傀儡可生器灵 |
| 十万年 | 石中如有星河 | 通灵化形，传闻可炼化身傀儡 |

## 配伍

**相宜**：配**养魂木**滋养魂魄；配**万年温玉**调阴寒；配**轮回草汁**净化怨念。  
**相忌**：忌近**天雷**，纯阴之物遇雷则碎；忌与**赤阳石**同放，阴阳冲撞；忌沾**污血**，秽魂络。

## 逸闻

散修鬼叟，以炼傀之术闻名。其本不过金丹后期，却以一尊元婴中期骷髅傀儡纵横南域百年。人问其秘，笑曰："老夫不过得一鸽卵大凝魂石，石中封有上古元婴修士残魂，石为我用，我便如元婴修士。"

后探知，鬼叟入一上古洞府，见遗骸端坐蒲团，手捧凝魂石化石，石壁刻字："吾以残魂入石，待有缘人。"鬼叟得石后穷尽毕生，未能炼出石中残魂所记仇人。临终叹曰："石中有魂，魂中有恨，恨不知向谁。可叹！"

其骷髅傀儡亦随之消失，或传被天机阁收去，或说鬼叟临终一并毁去，以免落入歹人之手。
