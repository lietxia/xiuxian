# 红花（二阶灵药）

## 外观

红花，其名源于其色——花色红如血，鲜艳夺目。其形如菊，却比菊花小得多，整朵花不过铜钱大小，花瓣细长如管，层层叠叠，色作深红，花蕊橙黄，如同微小的火把。

其茎高约尺余，直立如剑，上有细密的白刺，触摸有轻微的刺痛感。叶片互生，形如披针形，叶面深绿，叶背淡绿，边缘有细锯齿。

最奇在其"染血"之效——将红花捣烂，汁液鲜红如血，沾在衣物或皮肤上，清水洗之不去，须以灵力方可化净。故采药者常因此露了行踪——手中红痕，三日方消。

其气清淡如菊，却比菊多了一丝辛辣——闻之令人感到鼻腔微刺，随后感到气血涌动。

红花的花期极短——只在清晨花开，正午便凋谢。采摘须在清晨进行，过时则药效大减。

## 药性

- **性味**：性温，味辛，入口微苦后甘
- **五行**：偏火金二行——火主气血运行，金主肃降，金火相济故能活血
- **归经**：入心经（心主血脉）、肝经（肝主疏泄）
- **毒性**：无毒，但孕妇绝对忌用——红花活血，会导致流产
- **禁忌**：月经量多者忌用；出血倾向者忌用

## 功效

红花可活血化瘀、通经止痛，乃治疗跌打损伤、瘀血阻滞的常用灵药。

- **活血化瘀**（核心功效）：红花能化解瘀血——修士因斗法导致的内伤瘀血、皮下淤青，以红花煎水服用，可在三日内化解瘀血。
- **通经止痛**：红花能疏通经脉——修士因气血不畅导致的经脉疼痛、关节僵硬，以红花煎水服用，可在一个时辰内止痛。
- **红花活血汤**（二阶药方）：红花配伍桃仁、当归、川芎，水煎服之。可治疗一切瘀血阻滞之症——跌打损伤、瘀血疼痛、经脉不畅，均有良效。
- **外敷消肿**：红花捣烂外敷，可治疗跌打损伤导致的肿胀——消肿效果显著。
- **服用感受**：入腹后感到一股温热的力量从胃部向四肢扩散，所过之处气血涌动。若有瘀血，会感到瘀血处微微发热，随后瘀血逐渐消散。

## 产地

红花喜生于阳光充足、土壤疏松的山坡——需满足三个条件：其一，阳光充足，不被遮蔽；其二，土壤排水良好，不可积水；其三，周围有岩石或灌木遮挡寒风。

已知产地：
- **中原·红山坡**：中原有一处山坡，土壤呈红色，红花在此成片生长。每年花开时，满山红艳如血，如同一片燃烧的火海
- **东荒·野地**：东荒的田野边缘，红花与农作物共生。当地农户将其视为杂草，却不知其乃灵药
- 南疆·缓坡：南疆十万大山的缓坡上，红花在草丛中生长。但山坡上多毒蛇，采集时需小心

采集红花须在清晨花开时进行——以剪刀剪取花朵，晒干保存。采摘时需注意——红花的花瓣在清晨最为娇嫩，手温会灼伤花瓣，使其药力流失。

## 年份与药效

| 年份 | 特征 | 药效 |
|------|------|------|
| 一年生 | 花朵单朵，淡红色 | 可治疗普通瘀血 |
| 三年生 | 花朵数朵，红色渐深 | 可活血化瘀，对筑基期修士有效 |
| 十年生 | 花朵数十朵，红色浓郁 | 可炼红花活血汤，对金丹期修士有效 |
| 五十年生 | 花朵深红近紫，花香浓郁 | 可治疗元婴期修士的内伤瘀血 |
| 百年生 | 整株散发红色光芒，花朵红如凝血 | 可治疗化神期修士的瘀血重症 |

## 配伍建议

**最佳配伍**：
- 红花 + 桃仁 + 当归 → 红花活血汤
- 红花 + 乳香 + 没药 → 活血止痛散
- 红花 + 川芎 + 丹参 → 通经活络汤

**禁忌配伍**：
- 红花 + 止血类药物 → 药性相冲
- 红花 + 孕妇 → 绝对忌用，会导致流产

## 相关典故

上古时期，有一位女医名"红娘"，以医术闻名天下。红娘年轻时，遇到一位受伤的修士——修士因斗法导致内伤瘀血，奄奄一息。

红娘翻遍医书，最终在一本古籍中找到了红花的记载："红花，花红如血，能活血化瘀、通经止痛。"

红娘采来红花，配伍桃仁、当归等药，煎成红花活血汤让修士服下。三剂之后，修士的瘀血尽化，伤势痊愈。

修士感激涕零，问红娘："此药如此神奇，为何古籍中记载甚少？"

红娘答："红花虽神奇，却只生长在普通的山坡上，不似灵芝人参那般生于深山灵脉，故不被修士重视。殊不知，药无贵贱，对症便是良药。"

此事传开后，红花从一株无人问津的野花变成了修真界治疗瘀血阻滞的圣药。

修真界至今仍流传着一句话："红花红，活血通。不问贵贱，对症下药。"医修在治疗瘀血阻滞时，都会优先考虑红花——因为它药性温和，价格低廉，且效果显著。
