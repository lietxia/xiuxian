# 貔貅

> 貔貅者，神兽也。有嘴无肛，能吞万物而不泄，故有进财之意的瑞兽。其形似狮而小，通体鳞甲呈金黄色，双目圆睁，嘴巴大张，似在吞噬万物。传说貔貅乃上古龙祖与天狮所生，继承了龙的威严与狮的勇猛。它一生好吞，能吞噬一切金银财宝，却从不排泄，故被视为招财进宝的瑞兽。

## 外形描写

貔貅体型壮硕，约八尺长，形似雄狮却覆盖金黄色鳞甲。狮首较大，比例协调，双目圆睁，精光四射，嘴巴大张，似在吞噬万物。脊背上生有一排锯齿状骨刺，从颈尾一直延伸到尾巴尖爪。四爪如狮，锋利无比，可撕裂金丹期修士的护甲。尾如钢鞭，末端有簇金黄毛，挥动时可释放金光。

## 血脉与进化

貔貅的血脉源自上古龙祖与天狮的结合，属于"龙系"旁支。进化路线如下：

- **一阶·幼体**：出生时仅能吞噬小块金银
- **三阶·成体**：能吞噬大块金银，转化为灵气
- **六阶·玄兽**：血脉觉醒，能吞噬一切金属性之物，增幅周围修士的财运
- **八阶·神兽**：血脉大成，可吞噬天地灵气，增幅周围修士修炼速度
- **九阶·仙兽**：血脉圆满，可化为招财之体，言出法随

每次进化需经历"天财劫"，承受天道的考验，唯有心正者方能通过。

## 天赋神通

- **吞金噬银**：天生神通，能吞噬一切金银财宝，将其转化为纯净灵气，增幅周围修士修炼速度。
- **招财进宝**：可形成一个招财领域，范围内修士的财运提升三成，持续约一炷香时间。
- **辟邪镇宅**：可震慑一切邪祟，保护主人的家园和财富。

## 培养方法

- **食物**：喜好各种金银财宝，尤以"金元宝""银锭"为食，每月需进食三块
- **栖息**：需在财气浓郁之地生活，如金库、钱庄、商铺旁
- **训练**：需经常让其吞噬金银，锻炼其转化能力
- **禁忌**：不可让其接触污秽之物，否则会污染其灵气

## 与主人羁绊

貔貅性情温和，易与主人建立感情。它会对主人的财富产生深厚的归属感，誓死守护。建立联系后，主人可通过神识与其沟通，感知其视野范围内的财气。若主人遭遇盗贼，貔貅会第一时间吞噬盗贼的财物，保护主人的财富。

## 著名坐骑与典故

上古时期，有一位名为"陶朱公"的大商贾，在金山偶遇一头受伤的幼貔貅。他将其救下并精心喂养三年，与其建立了深厚的感情。后来陶朱公凭借貔貅的吞金噬银神通，成为修真界最富有的修士，号称"貔貅一吞，万金归库"。

## 同类对比

与**金蟾**相比，貔貅战斗力更强，但招财能力稍逊。与**麒麟**相比，貔貅更加威猛，但祥瑞之气不足。貔貅的优势在于吞金噬银和招财进宝的能力，是商人和财主的瑞兽。
