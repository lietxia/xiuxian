# 风驹

> 风驹者，风属性灵兽也。速度极快，是修真界最常见的飞行坐骑。其形似马而小，通体皮毛呈淡青色，四蹄有风纹。传说风驹乃上古风神飞廉的坐骑后裔，继承了风神的速度。

## 外形描写

风驹体型优美，约七尺高，形似白马却通体淡青色皮毛。皮毛在阳光下泛出微光，如同微风拂面。马首较小但双目灵动，精光四射。四蹄有天然风纹，奔跑时会引动微风。马鬃和尾羽呈淡绿色，在风中飘舞，如同柳枝。

## 血脉与进化

风驹的血脉源自上古风神飞廉的坐骑，属于"兽系"风属性分支。进化路线如下：

- **一阶·幼体**：出生时皮毛呈白色，仅能慢跑
- **三阶·成体**：皮毛变淡青，能日行三千里，开始短距离滑翔
- **五阶·玄兽**：血脉觉醒，可化为风翼，长距离飞行
- **七阶·圣兽**：血脉大成，可化为风驹真身，掌控风之法则

每次进化需经历"风劫"，承受九天狂风的淬炼，方能脱胎换骨。

## 天赋神通

- **疾风奔跑**：天生神通，奔跑速度极快，日行五千里，是修真界最快的陆地坐骑之一。
- **风翼飞翔**：五阶后可化为风翼，长距离飞行，最大高度约三千丈。
- **风之庇护**：可形成一个风之庇护，减少风阻，提升速度。

## 培养方法

- **食物**：喜好风属性灵草，尤以"风灵草""天风花"为食，每月需进食三株
- **栖息**：需在开阔的草原或山巅生活，常年在风中活动
- **训练**：需经常带其奔跑，锻炼其速度和飞行能力
- **禁忌**：不可将其困于狭小空间，否则会皮毛脱落、修为倒退

## 与主人羁绊

风驹性情温和，易与主人建立感情。它一生可认多主，但每换一次主需重新建立感情。建立联系后，主人可通过神识与其沟通，感知其视野。若主人遭遇危险，风驹会拼死相护。

## 著名坐骑与典故

上古时期，有一位名为"飞廉子"的大能，在草原偶遇一头受伤的幼风驹。他将其救下并精心喂养三年，与其建立了深厚的感情。后来飞廉子凭借风驹的疾风奔跑神通，成为修真界最快的修士，号称"风驹一闪，万里云烟"。

## 同类对比

与**烈焰马**相比，风驹速度更快，但攻击力稍弱。与**虬龙**相比，风驹更加常见，但神通较弱。风驹的优势在于速度和飞行能力，是修真界最常见的飞行坐骑。
