# 烈焰马

> 烈焰马者，火属性灵兽也。四蹄生火，日行万里，通体赤红如炭，奔跑时如同一团移动的火焰。传说烈焰马乃上古火神祝融的坐骑后裔，继承了火神的火焰之力。

## 外形描写

烈焰马体型高大，约八尺高，通体覆盖赤红色的毛发，如同燃烧的火焰。马鬃和尾羽尤为特别，并非毛发，而是真正的火焰，在风中飘舞。四蹄如铁，蹄下有火焰纹路，奔跑时会在地面留下燃烧的蹄印。双目呈金黄色，在黑暗中会发出如同火炬般的光芒。

## 血脉与进化

烈焰马的血脉源自上古火神祝融的坐骑，属于"兽系"火属性分支。进化路线如下：

- **一阶·幼体**：出生时体毛呈淡红色，四蹄仅有微温
- **三阶·成体**：体毛变红，四蹄生火，能日行三千里
- **四阶·灵兽**：血脉觉醒，可口吐火焰，奔跑速度翻倍
- **六阶·玄兽**：血脉大成，四蹄火焰可化为火翼，短距离飞行
- **八阶·圣兽**：血脉圆满，可化为半马半龙之形，掌控火焰法则

每次进化需经历"火劫"，承受地火淬炼，方能脱胎换骨。

## 天赋神通

- **烈焰蹄**：天生神通，四蹄生火，奔跑时可在地面留下火焰轨迹，敌人触碰会被烧伤。
- **火翼飞翔**：六阶后可化为火翼，短距离飞行，最大高度约千丈。
- **火焰吐息**：口吐火焰，可焚烧前方扇形区域，覆盖范围约十丈。

## 培养方法

- **食物**：喜好火属性灵草，尤以"火灵草""赤焰花"为食，每月需进食五株
- **栖息**：需在干燥温暖的环境中生活，不可在潮湿寒冷之地
- **训练**：需经常带其奔跑，锻炼其速度和耐力
- **禁忌**：不可让其长时间浸泡在水中，否则会熄灭体内火源、修为倒退

## 与主人羁绊

烈焰马性情刚烈，只臣服于实力超过自己的主人。它一生可认多主，但每换一次主需重新建立感情。建立联系后，主人可通过神识与其沟通，感知其视野。若主人遭遇危险，烈焰马会拼死相护，但不会像神兽那样至死不渝。

## 著名坐骑与典故

上古时期，有一位名为"火云子"的大能，在火焰山偶遇一头受伤的幼烈焰马。他将其救下并精心喂养三年，与其建立了深厚的感情。后来火云子凭借烈焰马的速度和火焰神通，成为修真界最快的修士，号称"烈焰一闪，万里云烟"。

## 同类对比

与**风驹**相比，烈焰马速度稍逊但攻击力更强。与**龙驹**相比，烈焰马更加常见但神通较弱。烈焰马的优势在于火焰攻击和速度的平衡，是火修常用的坐骑。
