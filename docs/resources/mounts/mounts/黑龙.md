# 黑龙

> 黑龙者，龙族之暗系也。通体漆黑如墨，掌控暗与毒，是暗杀者的坐骑。其形似龙而修长，通体鳞甲呈漆黑色，双目赤红如血。传说黑龙乃上古龙祖与暗凤结合所生，继承了龙的威严与暗凤的阴毒。

## 外形描写

黑龙体型修长，可达八丈长，通体覆盖漆黑色鳞甲，在阳光下不反射任何光芒。龙首巨大，头顶双角如牛角般弯曲，双目赤红如血，在黑暗中发出幽光。脊背上生有一排锯齿状骨刺，从颈尾一直延伸到尾巴尖爪。四爪如鹰，锋利无比，可撕裂虚空。尾如蛟龙，末端有簇漆黑毛，挥动时可释放毒雾。

## 血脉与进化

黑龙的血脉源自上古龙祖与暗凤的结合，属于"龙族"暗系分支。进化路线如下：

- **一阶·幼体**：出生时通体深灰色，仅能呼出毒雾
- **三阶·成体**：鳞甲变漆黑，能口吐暗龙之息，飞行速度极快
- **七阶·圣兽**：血脉大成，可召唤黑暗，掌控暗之法则
- **九阶·仙兽**：血脉圆满，可化为黑龙真身，掌控暗夜之法则

每次进化需经历"暗劫"，承受暗域的淬炼，方能脱胎换骨。

## 天赋神通

- **暗龙之息**：天生神通，口吐暗龙之息，可腐蚀前方扇形区域，覆盖范围约三十丈。
- **黑暗领域**：可召唤黑暗领域，覆盖范围约十里，范围内敌人视野受限。
- **龙威震慑**：释放龙威，可震慑方圆千里内的一切生灵，低阶妖兽直接臣服。

## 培养方法

- **食物**：喜好暗属性灵草，尤以"黑龙草""暗凤花"为食，每月需进食一株
- **栖息**：需在暗域或深渊中生活，喜暗恶明
- **训练**：需经常带其翱翔云端，锻炼其飞行和控暗能力
- **禁忌**：不可让其长时间暴露在强光下，否则会鳞甲干裂、修为倒退

## 与主人羁绊

黑龙性情阴冷，只臣服于实力远超自己且拥有暗灵根或毒灵根的主人。它一生只认一主，需在其幼年时以自身精血喂养九年，方可建立血脉联系。建立联系后，主人可通过神识与其沟通，共享其视野。若主人遭遇危险，黑龙会拼死相护，甚至不惜自爆内丹与敌人同归于尽。

## 著名坐骑与典故

上古时期，有一位名为"暗帝"的大能，在暗域偶遇一头受伤的黑龙。他将其救下并精心喂养九年，与其建立了深厚的感情。后来暗帝凭借黑龙的暗龙之息神通，成为修真界最强的暗修，号称"黑龙一吟，暗夜降临"。

## 同类对比

与**赤龙**相比，黑龙更加阴毒，但火焰神通不足。与**白龙**相比，黑龙更加隐秘，但治愈能力不足。黑龙的优势在于暗属性掌控和暗杀能力，是暗杀者和暗修梦寐以求的坐骑。
