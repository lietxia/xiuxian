# 虬龙

> 虬龙者，无角之龙也。龙类的幼年形态，能大能小，能升能隐，是龙族中最灵活的存在。其形似龙而小，通体鳞甲呈青绿色，无角无鬣，双目灵动。传说虬龙乃龙族幼崽，尚未长出龙角，但已具备龙族的基本神通。

## 外形描写

虬龙体型修长，约六尺长，形似小龙却无角无鬣。通体覆盖青绿色鳞甲，在阳光下泛出金属光泽。龙首较小但双目灵动，精光四射，能看透万物。脊背上生有一排细密的锯齿状骨刺，从颈尾一直延伸到尾巴尖爪。四爪如鹰，锋利无比，可撕裂虎豹。尾如蛟龙，末端有簇青绿毛，挥动时可引动微风。

## 血脉与进化

虬龙的血脉源自上古龙族，是龙族的幼年形态。进化路线如下：

- **一阶·幼体**：出生时仅能游水，无翼无角
- **三阶·成体**：生出双翼，能飞行，鳞甲开始变色
- **四阶·灵兽**：血脉觉醒，能大能小，能升能隐
- **六阶·玄兽**：血脉大成，可化为半人半龙之形，掌握风之法则
- **八阶·圣兽**：血脉圆满，可化为真龙，飞升仙界

每次进化需经历"风雷劫"，承受天雷与狂风的淬炼，方能脱胎换骨。

## 天赋神通

- **大小如意**：天生神通，可大可小，大可达十丈，小可藏于掌心。
- **腾云驾雾**：可腾云驾雾，飞行速度极快，日行万里。
- **龙息吐纳**：口吐龙息，可焚烧前方扇形区域，覆盖范围约十丈。

## 培养方法

- **食物**：喜好风属性灵草，尤以"风灵草""天风果"为食，每月需进食三株
- **栖息**：需在灵气浓郁的山林或洞府中生活
- **训练**：需经常带其翱翔云端，锻炼其飞行能力
- **禁忌**：不可将其困于狭小空间，否则会鳞甲脱落、修为倒退

## 与主人羁绊

虬龙性情活泼，易与主人建立感情。它一生只认一主，需在其幼年时以自身精血喂养三年，方可建立血脉联系。建立联系后，主人可通过神识与其沟通，共享其视野。若主人遭遇危险，虬龙会拼死相护。

## 著名坐骑与典故

上古时期，有一位名为"御风子"的大能，在云端偶遇一头受伤的幼虬龙。他将其救下并精心喂养三年，与其建立了深厚的感情。后来御风子凭借虬龙的飞行速度和灵活神通，成为修真界最快的修士，号称"虬龙一闪，万里云霄"。

## 同类对比

与**蛟龙**相比，虬龙更加灵活，但攻击力稍弱。与**应龙**相比，虬龙更加常见，但神通较弱。虬龙的优势在于灵活性和飞行能力，是修真界最常见的龙族坐骑。
