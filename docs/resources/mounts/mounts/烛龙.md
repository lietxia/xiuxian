# 烛龙

> 烛龙者，钟山之神也。视为昼，瞑为夜，吹为冬，呼为夏，不饮不食不息，息为风。此乃上古神兽，掌控昼夜更替、四季轮回，是天地间最古老的存在之一。

## 外形描写

烛龙体型巨大，可达百丈长，人面蛇身，通体呈暗红色。它的眼睛是天地间最神奇的存在——睁眼即为白昼，闭眼即为黑夜，一眨眼便是一天一夜。口中常含一团火焰，照亮九重幽冥。四爪如龙，锋利无比，可撕裂虚空。脊背上生有一排骨刺，每根骨刺上都刻有一道时间符文，闪烁着神秘的光芒。

## 血脉与进化

烛龙的血脉源自上古开天辟地时的第一批生灵，是最古老的神兽之一。它没有进化路线，因为本身就是进化的终点。但它可以修炼提升实力，分为以下几个阶段：

- **幼年期**：刚出生时仅能影响方圆十丈的昼夜
- **成长期**：可影响方圆百里的昼夜和四季
- **成熟期**：可影响整个界面的昼夜更替
- **完全体**：可影响多个界面的时间流速

每个阶段的提升都需要漫长的岁月和庞大的灵气积累。

## 天赋神通

- **烛照九幽**：天生神通，口中火焰可照亮九重幽冥，一切鬼物亡魂在火焰下无所遁形。
- **昼夜更替**：睁眼为白昼，闭眼为黑夜，可随意控制方圆万里的昼夜变化。
- **四季轮回**：呼气为夏，吹气为冬，可控制方圆万里的季节变化。

## 培养方法

- **食物**：不需要进食，以天地灵气为食，尤其喜欢日月精华
- **栖息**：需在高山之巅或深海之底的灵气节点处修炼
- **训练**：需要漫长的岁月积累，无法通过短期训练提升
- **禁忌**：不可让其长时间离开灵气节点，否则会陷入沉睡

## 与主人羁绊

烛龙不会臣服于任何人，因为它本身就是与天地同级的存在。但如果有修士能与其建立友谊（通常需要数千年的陪伴），烛龙会允许修士骑乘。这种关系不是主仆，而是平等的友谊。若朋友遭遇危险，烛龙会出手相助，但不会拼死相护。

## 著名坐骑与典故

上古时期，有一位名为"时间道君"的大能，在钟山之巅与一头烛龙相伴万年，最终与其建立了深厚的友谊。时间道君凭借烛龙的神通，参悟了时间法则，成为修真界第一位以时间之道证道的大能，号称"烛龙一照，万古云霄"。

## 同类对比

与**鲲鹏**相比，烛龙更加古老神秘，但速度稍逊。与**麒麟**相比，烛龙战斗力更强，但祥瑞之气不足。烛龙的优势在于掌控昼夜和四季的能力，是时间大道修士梦寐以求的伙伴。
