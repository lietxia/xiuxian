# 火凤

> 火凤者，凤凰之属也。身披五彩羽翼，口吐南明离火，一声凤鸣可令百鸟朝拜。传说火凤乃上古凤凰一脉的后裔，继承了凤凰的涅槃重生之力。它生于火焰，死于火焰，又从火焰中获得永生。

## 外形描写

火凤体型优美，约一丈五尺长，通体覆盖五彩羽翼，在阳光下泛出七彩光华。凤首高昂，头顶七彩羽冠，双目如丹凤眼，精光四射。双翼展开可达三丈，羽翼上的火焰纹路仿佛有火焰在燃烧。四爪如鹰，锋利无比，可撕裂虚空。尾羽极长，约两丈，末端有簇五彩毛，挥动时可引动天地灵气。

## 血脉与进化

火凤的血脉源自上古凤凰一族，属于"凤系"正统。进化路线如下：

- **一阶·幼体**：出生时羽毛稀疏，仅能喷出小火苗
- **三阶·成体**：羽毛丰满，能口吐南明离火，飞行速度极快
- **七阶·圣兽**：血脉大成，可涅槃重生，死后从灰烬中复活
- **九阶·仙兽**：血脉圆满，可化为半人半凤之形，掌握火焰法则

每次进化需经历"涅槃劫"，在火焰中死亡又重生，方能脱胎换骨。

## 天赋神通

- **南明离火**：天生神通，口吐南明离火，可焚烧万物，对邪魔有天然克制，温度可达万度。
- **凤鸣九霄**：发出一声凤鸣，可震慑方圆千里内的一切生灵，低阶妖兽直接臣服。
- **涅槃重生**：血脉神通，死后可从灰烬中复活，恢复全部修为，但每次涅槃需间隔百年。

## 培养方法

- **食物**：喜好火属性灵草，尤以"凤凰胆""朱雀血"为食，每月需进食一株
- **栖息**：需在火焰浓郁之地修炼，如火山口、地火脉旁
- **训练**：需经常带其翱翔云端，锻炼其飞行和控火能力
- **禁忌**：不可让其接触水属性法宝或法术，否则会羽毛脱落、修为倒退

## 与主人羁绊

火凤性情高傲，只臣服于实力远超自己且拥有凤凰血脉或火焰大道感悟的主人。它一生只认一主，需在其幼年时以自身精血喂养九年，方可建立血脉联系。建立联系后，主人可通过神识与其沟通，共享其视野。若主人遭遇危险，火凤会拼死相护，甚至不惜涅槃重生保护主人。

## 著名坐骑与典故

上古时期，有一位名为"炎帝"的人皇，在昆仑山巅偶遇一头受伤的火凤。他将其救下并精心喂养九年，与其建立了深厚的感情。后来炎帝凭借火凤的南明离火神通，大败蚩尤，一统华夏，成为人族第一位炎帝。

## 同类对比

与**青鸾**相比，火凤战斗力更强但速度稍逊。与**朱雀**相比，火凤更加灵活但火焰威力稍弱。火凤的优势在于涅槃重生的能力，是火修梦寐以求的坐骑。
