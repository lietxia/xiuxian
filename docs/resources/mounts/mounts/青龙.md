# 青龙

> 青龙者，东方神兽，四象之首也。掌控木与风，是帝王坐骑。其形似龙而威猛，通体鳞甲呈青绿色，双目如日月，精光四射。传说青龙乃上古时期东方天帝太昊的坐骑，是四象中最尊贵的神兽。

## 外形描写

青龙体型威猛，可达十丈长，通体覆盖青绿色鳞甲，在阳光下泛出金属光泽。龙首巨大，头顶双角如鹿角般分叉，双目如日月，精光四射。脊背上生有一排锯齿状骨刺，从颈尾一直延伸到尾巴尖爪。四爪如鹰，锋利无比，可撕裂虚空。尾如蛟龙，末端有簇青绿毛，挥动时可引动狂风。

## 血脉与进化

青龙的血脉源自上古东方天帝太昊的坐骑，属于"龙族"四象分支。进化路线如下：

- **一阶·幼体**：出生时通体淡绿色，仅能呼出木灵之气
- **三阶·成体**：鳞甲变青绿，能口吐木灵之息，飞行速度极快
- **八阶·神兽**：血脉大成，可召唤万木，掌控木之法则
- **九阶·仙兽**：血脉圆满，可化为青龙真身，掌控生命之法则

每次进化需经历"天木劫"，承受天雷与木灵的双重淬炼，方能脱胎换骨。

## 天赋神通

- **木灵之息**：天生神通，口吐木灵之息，可催生万木，覆盖范围约百里。
- **春风化雨**：可召唤春风化雨，治愈大地，恢复生机。
- **龙威震慑**：释放龙威，可震慑方圆千里内的一切生灵，低阶妖兽直接臣服。

## 培养方法

- **食物**：喜好木属性灵草，尤以"青龙草""天木果"为食，每月需进食一株
- **栖息**：需在森林之巅或云端筑巢，常年在高空活动
- **训练**：需经常带其翱翔云端，锻炼其飞行和控木能力
- **禁忌**：不可让其接触金属性法宝或法术，否则会鳞甲脱落

## 与主人羁绊

青龙性情高傲，只臣服于实力远超自己且拥有木灵根或帝王之气的主人。它一生只认一主，需在其幼年时以自身精血喂养九年，方可建立血脉联系。建立联系后，主人可通过神识与其沟通，共享其视野。若主人遭遇危险，青龙会拼死相护，甚至不惜自爆内丹与敌人同归于尽。

## 著名坐骑与典故

上古时期，有一位名为"太昊"的东方天帝，在昆仑山偶遇一头受伤的幼青龙。他将其救下并精心喂养九年，与其建立了深厚的感情。后来太昊凭借青龙的木灵之息神通，成为修真界最强的木修，号称"青龙一吟，万木逢春"。

## 同类对比

与**白龙**相比，青龙治愈能力更强，但攻击力稍逊。与**应龙**相比，青龙更加尊贵，但神通稍弱。青龙的优势在于木属性掌控和帝王之气，是帝王和木修梦寐以求的坐骑。
