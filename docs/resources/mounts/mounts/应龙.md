# 应龙

> 应龙者，龙之巅峰也。有翼曰应龙，无翼曰蛟龙。应龙是龙类进化的最终形态之一，能大能小，能升能隐，掌控风雨雷电，是天地间最强大的神兽之一。

## 外形描写

应龙体型巨大，成年体可达十丈长，通体覆盖五彩鳞甲，在阳光下泛出七彩光华。龙首巨大，头顶双角如鹿角般分叉，双目如日月，精光四射。脊背上生有一对巨大的翅膀，翼展可达三丈，羽毛呈五彩之色。四爪如鹰，锋利无比，可撕裂虚空。尾如蛟龙，末端有簇五彩毛，挥动时可引动风云变色。

## 血脉与进化

应龙的血脉源自上古龙祖，是龙类进化的巅峰形态。进化路线如下：

- **一阶·幼体**：出生时无翼，仅能游水，通体呈青色
- **三阶·成体**：生出双翼，能飞行，鳞甲开始变色
- **五阶·蛟龙**：体型变大，能大能小，掌控风雨
- **七阶·角龙**：头顶生角，能引动天劫，实力大增
- **九阶·应龙**：血脉圆满，有翼能飞，掌控雷电，可呼风唤雨

每次进化需经历"天雷劫"，承受九重天雷的淬炼，方能脱胎换骨。

## 天赋神通

- **呼风唤雨**：天生神通，可引动天地灵气，制造狂风暴雨，覆盖范围约百里。
- **雷霆万钧**：口吐天雷，威力惊人，可劈碎山岳，对邪魔有天然克制。
- **龙威震慑**：释放龙威，可震慑方圆千里内的一切生灵，低阶妖兽直接臣服。

## 培养方法

- **食物**：喜好天材地宝，尤以"龙灵草""凤凰胆"为食，每月需进食一株
- **栖息**：需在灵气浓郁的高山之巅或深海龙宫中生活
- **训练**：需经常带其翱翔云端，锻炼其飞行和控雷能力
- **禁忌**：不可将其困于狭小空间，否则会鳞甲脱落、修为倒退

## 与主人羁绊

应龙性情高傲，只臣服于实力远超自己且拥有龙血或凤血的主人。它一生只认一主，需在其幼年时以自身精血喂养九年，方可建立血脉联系。建立联系后，主人可通过神识与其沟通，共享其视野。若主人遭遇危险，应龙会拼死相护，甚至不惜自爆内丹与敌人同归于尽。

## 著名坐骑与典故

上古时期，有一位名为"轩辕黄帝"的人皇，在昆仑山巅偶遇一头受伤的幼应龙。他将其救下并精心喂养九年，与其建立了深厚的感情。后来黄帝凭借应龙的飞行能力和控雷神通，大败蚩尤，一统华夏，成为人族第一位人皇。

## 同类对比

与**蛟龙**相比，应龙有翼能飞，神通更强。与**烛龙**相比，应龙更加灵活，但掌控力稍逊。应龙的优势在于全属性掌控和飞行能力，是修真界最顶级的坐骑之一。
