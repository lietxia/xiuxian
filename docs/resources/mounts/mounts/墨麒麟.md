# 墨麒麟

> 墨色麒麟，幽冥之兽，脚踏九幽，眼通阴阳。此兽乃麒麟一族中的异类，通体漆黑如墨，生于幽冥之地，却能穿梭两界，沟通生死。

## 外形描写

墨麒麟体型壮硕，约两丈长，通体覆盖漆黑的鳞甲，如同一块完美的黑玉雕琢而成。它的眼睛是唯一的色彩——一双金色的竖瞳，在黑暗中熠熠生辉，能看透九幽与人间。四蹄如牛，踏地无声，每一步都会留下淡淡的黑色印记，片刻后消散。独角如墨玉，螺旋纹路密布，能聚集天地间的阴属性灵气。尾如蛟龙，末端有簇黑毛，挥动时可撕裂虚空。

## 血脉与进化

墨麒麟的血脉源自上古神兽麒麟一族，因诞生于幽冥之地而发生异变。进化路线如下：

- **一阶·幼体**：出生时通体灰黑，能感知阴气流动
- **三阶·成体**：鳞甲变黑，能短距离穿梭阴阳两界
- **七阶·圣兽**：血脉大成，可自由出入幽冥，眼通阴阳
- **九阶·仙兽**：血脉圆满，能召唤幽冥之力，操控生死法则

每次进化需经历"幽冥劫"，承受九幽阴火的淬炼，方能脱胎换骨。

## 天赋神通

- **阴阳眼**：天生神通，能看透阴阳两界，识别一切鬼物亡魂，甚至能看见敌人的寿元与气运。
- **幽冥踏**：可踏破虚空，短距离瞬移，最大距离约百丈，在阴气浓郁处距离翻倍。
- **黑玉护体**：鳞甲坚硬无比，同阶修士的普通法宝难伤分毫，且能吸收阴属性法术为己用。

## 培养方法

- **食物**：喜好阴属性灵草，尤以"幽冥草""黄泉果"为食，每月需进食七株
- **栖息**：需在阴气浓郁之地修炼，如墓地、古战场、幽冥裂缝旁
- **训练**：需经常带其出入幽冥之地，锻炼其穿梭两界的能力
- **禁忌**：不可长时间暴露在烈日下，否则会鳞甲干裂、修为倒退

## 与主人羁绊

墨麒麟性情孤傲，只臣服于实力远超自己且通晓阴阳之道的主人。它一生只认一主，需在其幼年时以自身精血混合幽冥之气喂养三年，方可建立血脉联系。建立联系后，主人可通过神识与其沟通，感知其视野中的阴阳两界。若主人遭遇危险，墨麒麟会拼死相护，甚至不惜陨落。

## 著名坐骑与典故

上古时期，有一位名为"幽冥子"的大能，在九幽之地偶遇一头受伤的幼墨麒麟。他将其救下并精心喂养三年，与其建立了深厚的感情。后来幽冥子凭借墨麒麟的阴阳眼和幽冥踏神通，成为修真界最强的鬼修，号称"幽冥一踏，阴阳两隔"。

## 同类对比

与**白泽**相比，墨麒麟战斗力更强，但预知能力稍逊。与**谛听**相比，墨麒麟更加灵活，但探查范围较小。墨麒麟的优势在于穿梭阴阳两界的能力，是鬼修和冥修梦寐以求的坐骑。
