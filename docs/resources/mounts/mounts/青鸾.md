# 青鸾

> 青鸾者，凤凰之属也。木属性神鸟，能治愈万物，是医修的最佳坐骑。其形似鸾而小，通体羽毛呈青绿色，双目碧绿如宝石。传说青鸾乃上古凤凰与天鸾结合所生，继承了凤凰的高贵与天鸾的治愈之力。

## 外形描写

青鸾体型优美，约四尺长，形似鸾鸟却通体青绿色羽毛。羽毛在阳光下泛出翠绿色光泽，如同翡翠。鸾首较小，头顶翠绿羽冠，双目碧绿如宝石，能看透万物生机。双翼展开可达两丈，羽翼上的羽毛如同碧玉打磨。四爪如鸾，锋利但主要用于攀爬。尾羽极长，约一丈，末端有簇青绿毛，挥动时可释放治愈之光。

## 血脉与进化

青鸾的血脉源自上古凤凰与天鸾的结合，属于"凤系"旁支。进化路线如下：

- **一阶·幼体**：出生时羽毛稀疏，仅能释放微弱治愈之光
- **三阶·成体**：羽毛丰满，能治愈简单伤口，飞行速度极快
- **六阶·玄兽**：血脉觉醒，可治愈重伤，增幅周围修士的生命力
- **八阶·神兽**：血脉大成，可治愈濒死之人，甚至起死回生
- **九阶·仙兽**：血脉圆满，可化为青鸾真身，掌控生命之法则

每次进化需经历"天木劫"，承受天雷与木灵的双重淬炼，方能脱胎换骨。

## 天赋神通

- **治愈之光**：天生神通，可释放治愈之光，治愈伤口，恢复生命力。
- **生命增幅**：可形成一个生命领域，范围内修士的生命力提升三成。
- **净化毒素**：可净化一切毒素和诅咒，对毒修有天然克制。

## 培养方法

- **食物**：喜好木属性灵草，尤以"生命草""青鸾花"为食，每月需进食五株
- **栖息**：需在森林或灵木旁生活，常年在灵气浓郁之地活动
- **训练**：需经常带其翱翔云端，锻炼其飞行和治愈能力
- **禁忌**：不可让其接触死亡之气，否则会羽毛脱落、修为倒退

## 与主人羁绊

青鸾性情温和，易与主人建立感情。它会对主人的生命气息极为敏感，若主人生命垂危，青鸾会主动靠近治愈。建立联系后，主人可通过神识与其沟通，共享其视野。若主人遭遇危险，青鸾会拼死相护。

## 著名坐骑与典故

上古时期，有一位名为"药王"的大能，在昆仑山偶遇一头受伤的青鸾。他将其救下并精心喂养三年，与其建立了深厚的感情。后来药王凭借青鸾的治愈之光神通，成为修真界最强的医修，号称"青鸾一起，起死回生"。

## 同类对比

与**金翅大鹏**相比，青鸾治愈能力更强，但战斗力稍弱。与**火凤**相比，青鸾更加温和，但火焰神通不足。青鸾的优势在于治愈能力，是医修和丹修梦寐以求的坐骑。
