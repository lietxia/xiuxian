# 螭吻

> 螭吻者，龙生九子之九子也。性好吞火，常守于屋脊之上，辟火消灾。其形似鱼而小，通体鳞甲呈火红色，双目圆睁，似在吞噬火焰。传说螭吻乃上古龙祖与天鱼所生，继承了龙的威严与鱼的灵活。它一生好吞，能吞噬一切火焰，将其转化为灵气。

## 外形描写

螭吻体型较小，约五尺长，形似鱼却生有龙首。通体覆盖火红色鳞甲，在阳光下泛出金属光泽。龙首较小但双目圆睁，嘴巴大张，似在吞噬火焰。脊背上生有一排锯齿状骨刺，从颈尾一直延伸到尾巴尖爪。四爪短小但有力，可牢牢抓住屋脊。尾如鱼尾，末端有簇火红毛，挥动时可释放火星。

## 血脉与进化

螭吻的血脉源自上古龙祖与天鱼的结合，属于"龙系"旁支。进化路线如下：

- **一阶·幼体**：出生时仅能吞噬小火苗
- **三阶·成体**：能吞噬普通火焰，转化为灵气
- **五阶·玄兽**：血脉觉醒，能吞噬灵火，辟火消灾
- **七阶·圣兽**：血脉大成，可吞噬天火，免疫一切火焰攻击
- **九阶·仙兽**：血脉圆满，可化为火焰之体，以火为食

每次进化需经历"天火劫"，承受天火的淬炼，方能脱胎换骨。

## 天赋神通

- **吞火噬焰**：天生神通，能吞噬一切火焰，将其转化为纯净灵气，增幅周围修士修炼速度。
- **辟火消灾**：可形成一个辟火领域，领域内一切火焰攻击都会失效，持续约一炷香时间。
- **火眼金睛**：双目能看破一切幻术和隐身，照出妖邪原形。

## 培养方法

- **食物**：喜好各种火焰，尤以"天火""地火"为食，每月需吞噬三团
- **栖息**：需在屋脊或火炉旁生活，常年在火焰环绕之地修炼
- **训练**：需经常让其吞噬各种火焰，锻炼其转化能力
- **禁忌**：不可让其接触水属性之物，否则会熄灭体内火源

## 与主人羁绊

螭吻性情温和，易与主人建立感情。它会对主人的居所产生深厚的归属感，誓死守护。建立联系后，主人可通过神识与其沟通，感知其视野范围内的火焰。若主人遭遇火灾，螭吻会第一时间吞噬火焰，保护主人的安全。

## 著名坐骑与典故

上古时期，有一位名为"火云子"的大能，在火山偶遇一头受伤的幼螭吻。他将其救下并精心喂养三年，与其建立了深厚的感情。后来火云子凭借螭吻的吞火噬焰神通，成为修真界最强的火修，号称"螭吻一吞，万火归元"。

## 同类对比

与**嘲风**相比，螭吻防御力更强，但速度较慢。与**椒图**相比，螭吻更加灵活，但防御力不足。螭吻的优势在于吞火噬焰的能力，是火修和炼器师的最佳坐骑。
