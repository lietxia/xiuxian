# 黄龙

> 黄龙者，龙族之帝王也。通体金黄，掌控土与金，是皇权象征。其形似龙而威猛，通体鳞甲呈金黄色，双目如日月，精光四射。传说黄龙乃上古龙祖与地脉结合所生，继承了龙的威严与大地的厚重。

## 外形描写

黄龙体型威猛，可达十丈长，通体覆盖金黄色鳞甲，在阳光下闪闪发光。龙首巨大，头顶双角如鹿角般分叉，双目如日月，精光四射。脊背上生有一排锯齿状骨刺，从颈尾一直延伸到尾巴尖爪。四爪如鹰，锋利无比，可撕裂虚空。尾如蛟龙，末端有簇金黄毛，挥动时可引动山岳。

## 血脉与进化

黄龙的血脉源自上古龙祖与地脉的结合，属于"龙族"帝王分支。进化路线如下：

- **一阶·幼体**：出生时通体淡黄色，仅能呼出土灵之气
- **三阶·成体**：鳞甲变金黄，能口吐金灵之息，飞行速度极快
- **八阶·神兽**：血脉大成，可召唤山岳，掌控土之法则
- **九阶·仙兽**：血脉圆满，可化为黄龙真身，掌控大地之法则

每次进化需经历"地劫"，承受山岳的淬炼，方能脱胎换骨。

## 天赋神通

- **金灵之息**：天生神通，口吐金灵之息，可化为金色剑雨，覆盖范围约三十丈。
- **山岳召唤**：可召唤山岳，镇压敌人，对土属性修士有天然克制。
- **龙威震慑**：释放龙威，可震慑方圆千里内的一切生灵，低阶妖兽直接臣服。

## 培养方法

- **食物**：喜好土属性灵草，尤以"黄龙草""地脉精"为食，每月需进食一株
- **栖息**：需在山岳之巅或地脉旁生活，喜静恶动
- **训练**：需经常带其翱翔云端，锻炼其飞行和控土能力
- **禁忌**：不可让其接触木属性法宝或法术，否则会鳞甲脱落

## 与主人羁绊

黄龙性情高傲，只臣服于实力远超自己且拥有土灵根或帝王之气的主人。它一生只认一主，需在其幼年时以自身精血喂养九年，方可建立血脉联系。建立联系后，主人可通过神识与其沟通，共享其视野。若主人遭遇危险，黄龙会拼死相护，甚至不惜自爆内丹与敌人同归于尽。

## 著名坐骑与典故

上古时期，有一位名为"黄帝"的人皇，在昆仑山偶遇一头受伤的幼黄龙。他将其救下并精心喂养九年，与其建立了深厚的感情。后来黄帝凭借黄龙的金灵之息神通，大败蚩尤，一统华夏，成为人族第一位人皇。

## 同类对比

与**青龙**相比，黄龙攻击力更强，但治愈能力稍逊。与**应龙**相比，黄龙更加尊贵，但灵活性不足。黄龙的优势在于土金双属性掌控和帝王之气，是帝王和土修梦寐以求的坐骑。
