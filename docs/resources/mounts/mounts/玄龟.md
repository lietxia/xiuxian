# 玄龟

> 玄龟者，北方神兽也。龟蛇合体，掌控水与冰，寿元万载，是天地间最长寿的存在之一。其形似龟，背生龟甲，腹生蛇尾，通体漆黑如墨。传说玄龟乃上古时期北方玄武的后裔，继承了玄武的水冰之力。

## 外形描写

玄龟体型巨大，龟壳直径可达三丈，通体漆黑如墨，在阳光下泛出幽光。龟壳上有天然形成的纹路，似山川河流，蕴含天地之力。腹生蛇尾，长约两丈，蛇头呈三角形，双目赤红，能喷射毒液。四爪如龙，锋利无比，可撕裂精钢。蛇尾与龟身连接处覆盖细密鳞甲，是全身最脆弱的部位。

## 血脉与进化

玄龟的血脉源自上古北方玄武，是玄武一族的后裔。进化路线如下：

- **一阶·幼体**：出生时龟壳柔软，仅能游水
- **三阶·成体**：龟壳硬化，能口吐冰霜
- **七阶·圣兽**：血脉大成，龟壳坚如精钢，可抵御元婴期修士的攻击
- **九阶·仙兽**：血脉圆满，可化为半龟半蛇之形，掌控水冰法则

每次进化需经历"寒冰劫"，承受万年寒冰的淬炼，方能脱胎换骨。

## 天赋神通

- **玄冰护体**：天生神通，可释放寒冰护体，覆盖范围约三丈，范围内敌人速度降低五成。
- **龟蛇缠绕**：腹生蛇尾可缠绕敌人，蛇头喷射毒液，可腐蚀金丹期修士的护甲。
- **万年寿元**：寿元极长，可达万载，且能为主人延寿。

## 培养方法

- **食物**：喜好水属性灵草，尤以"玄冰草""寒潭鱼"为食，每月需进食七株
- **栖息**：需在深海或冰原中生活，喜寒畏热
- **训练**：需经常带其潜入深海，锻炼其水战能力
- **禁忌**：不可让其长时间暴露在烈日下，否则会龟壳干裂、修为倒退

## 与主人羁绊

玄龟性情温和，但只臣服于实力远超自己且拥有水灵根的主人。它一生只认一主，需在其幼年时以自身精血喂养九年，方可建立血脉联系。建立联系后，主人可通过神识与其沟通，共享其视野。若主人遭遇危险，玄龟会缩入龟壳，将主人护在壳内。

## 著名坐骑与典故

上古时期，有一位名为"玄武大帝"的大能，在北海偶遇一头受伤的幼玄龟。他将其救下并精心喂养九年，与其建立了深厚的感情。后来玄武大帝凭借玄龟的防御神通和万年寿元，成为修真界最长寿的大能，号称"玄龟一缩，万法难侵"。

## 同类对比

与**玄武**相比，玄龟防御力相当，但攻击力稍弱。与**霸下**相比，玄龟更加灵活，但负重能力不足。玄龟的优势在于极致的防御和延寿能力，是防御型修士的最佳坐骑。
