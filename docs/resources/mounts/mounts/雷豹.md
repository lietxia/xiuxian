# 雷豹

> 雷豹者，雷属性妖兽也。速度极快，能口吐雷电，是雷修的最佳坐骑。其形似豹而小，通体皮毛呈紫黑色，上有银色雷纹。传说雷豹乃上古雷兽与天豹结合所生，继承了雷兽的雷电之力与天豹的速度。

## 外形描写

雷豹体型矫健，约六尺长，形似花豹却通体紫黑色皮毛。皮毛上有银色雷纹，在阳光下闪闪发光，如同闪电。豹首较小但双目精光四射，能看透黑暗。四爪如豹，锋利无比，可撕裂金丹期修士的护甲。尾如钢鞭，末端有簇紫黑毛，挥动时可释放电弧。

## 血脉与进化

雷豹的血脉源自上古雷兽与天豹的结合，属于"兽系"雷属性分支。进化路线如下：

- **一阶·幼体**：出生时皮毛呈灰色，仅能释放微弱电弧
- **三阶·成体**：皮毛变紫黑，能口吐雷电，奔跑速度极快
- **五阶·玄兽**：血脉觉醒，可召唤雷云，增幅雷电法术威力
- **七阶·圣兽**：血脉大成，可化为半豹半龙之形，掌握雷之法则
- **九阶·仙兽**：血脉圆满，可化为雷豹真身，掌控雷电

每次进化需经历"雷劫"，承受天雷的淬炼，方能脱胎换骨。

## 天赋神通

- **雷电吐息**：天生神通，口吐雷电，可轰击前方扇形区域，覆盖范围约十五丈。
- **雷光护体**：可释放雷电护体，覆盖范围约三丈，触碰者受到电击伤害。
- **极速奔跑**：奔跑速度极快，日行五万里，是修真界最快的陆地坐骑之一。

## 培养方法

- **食物**：喜好雷属性灵草，尤以"雷灵草""天雷果"为食，每月需进食五株
- **栖息**：需在雷云密布的山巅或雷脉旁生活
- **训练**：需经常带其奔跑，锻炼其速度和雷电能力
- **禁忌**：不可让其长时间处于绝缘环境中，否则会雷电消散、修为倒退

## 与主人羁绊

雷豹性情刚烈，只臣服于实力超过自己且拥有雷灵根的主人。它一生可认多主，但每换一次主需重新建立感情。建立联系后，主人可通过神识与其沟通，感知其视野。若主人遭遇危险，雷豹会拼死相护。

## 著名坐骑与典故

上古时期，有一位名为"雷公"的大能，在雷泽偶遇一头受伤的幼雷豹。他将其救下并精心喂养三年，与其建立了深厚的感情。后来雷公凭借雷豹的雷电吐息神通，成为修真界最强的雷修，号称"雷豹一吼，九天雷动"。

## 同类对比

与**烈焰马**相比，雷豹速度更快，但火焰神通不足。与**风驹**相比，雷豹攻击力更强，但速度稍逊。雷豹的优势在于雷电攻击和速度的平衡，是雷修常用的坐骑。
