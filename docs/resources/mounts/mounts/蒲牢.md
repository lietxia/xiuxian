# 蒲牢

> 蒲牢者，龙生九子之七子也。性好鸣叫，常蹲于钟钮之上，声震九天。其形似龙而小，通体鳞甲呈青铜色，双目圆睁，似在呐喊。传说蒲牢乃上古龙祖与天鲸所生，继承了龙的威严与鲸的洪亮。它一生好鸣，一声吼出，可震碎山河。

## 外形描写

蒲牢体型较小，约六尺长，形似小龙却生有鲸首。通体覆盖青铜色鳞甲，在阳光下泛出金属光泽。鲸首较大，比例失调却显得威猛异常，双目圆睁，嘴巴大张，似在呐喊。脊背上生有一排锯齿状骨刺，从颈尾一直延伸到尾巴尖爪。四爪短小但有力，可牢牢抓住钟钮。尾如钢鞭，末端有簇青铜毛，挥动时可发出金属颤音。

## 血脉与进化

蒲牢的血脉源自上古龙祖与天鲸的结合，属于"龙系"旁支。进化路线如下：

- **一阶·幼体**：出生时仅能发出微弱叫声
- **三阶·成体**：声音变大，可震碎玻璃
- **五阶·玄兽**：血脉觉醒，一声吼出可震碎山石
- **七阶·圣兽**：血脉大成，可发出龙吟，声震百里
- **九阶·仙兽**：血脉圆满，可化为音波之体，以声杀敌

每次进化需经历"天音劫"，承受九天仙乐的洗礼，方能脱胎换骨。

## 天赋神通

- **龙吟九天**：天生神通，一声龙吟可声震百里，范围内敌人耳膜破裂，心神震荡。
- **震碎山河**：吼声可震碎山石，对土属性法宝有天然克制。
- **音波攻击**：可发出高频音波，直接攻击敌人神魂，对鬼道修士有天然克制。

## 培养方法

- **食物**：喜好音属性灵花，尤以"天籁花""音灵果"为食，每月需进食五朵
- **栖息**：需在钟旁或鼓旁生活，常年在声音回荡之地修炼
- **训练**：需经常让其鸣叫，锻炼其音波能力
- **禁忌**：不可让其长时间处于安静环境，否则会声音嘶哑、修为倒退

## 与主人羁绊

蒲牢性情刚烈，只臣服于实力超过自己的主人。它一生可认多主，但每换一次主需重新建立感情。建立联系后，主人可通过神识与其沟通，感知其视野。若主人遭遇危险，蒲牢会发出震耳欲聋的吼声，震慑敌人。

## 著名坐骑与典故

上古时期，有一位名为"钟离子"的大能，在昆仑山偶遇一头受伤的幼蒲牢。他将其救下并精心喂养三年，与其建立了深厚的感情。后来钟离子凭借蒲牢的龙吟九天神通，成为修真界最强的音修，号称"蒲牢一吼，山河破碎"。

## 同类对比

与**囚牛**相比，蒲牢攻击力更强，但音律美感不足。与**嘲风**相比，蒲牢更加威猛，但速度较慢。蒲牢的优势在于音波攻击能力，是音修常用的战斗坐骑。
