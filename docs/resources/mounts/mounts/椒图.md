# 椒图

> 椒图者，龙生九子之八子也。性好镇守，常守门户，辟邪驱鬼。其形似螺蚌，外壳坚硬，一旦闭合，万法难开。传说椒图乃上古龙祖与神螺所生，继承了龙的威严与螺的坚韧。它一生守护，从不懈怠，是门户、城池、宝藏的最佳守护者。

## 外形描写

椒图体型圆润，约六尺长，形似螺蚌却生有龙首。通体覆盖土黄色鳞甲，坚硬无比，普通法宝难伤分毫。龙首较小但双目精光四射，能看破一切幻术。外壳上有天然形成的纹路，似山川河流，蕴含大地之力。一旦闭合，外壳浑然一体，无任何缝隙，外力难入。四爪短小但有力，可牢牢抓住地面，任风吹雨打岿然不动。

## 血脉与进化

椒图的血脉源自上古龙祖与神螺的结合，属于"龙系"旁支。进化路线如下：

- **一阶·幼体**：出生时外壳柔软，仅能缓慢爬行
- **三阶·成体**：外壳硬化，能短距离滚动，防御力初现
- **六阶·玄兽**：血脉觉醒，外壳坚如精钢，可抵御元婴期修士的攻击
- **八阶·神兽**：血脉大成，外壳可自动修复，且能释放大地之力护体
- **九阶·仙兽**：血脉圆满，外壳化为先天至宝，万法不侵

每次进化需经历"地劫"，承受大地之力的淬炼，方能脱胎换骨。

## 天赋神通

- **螺蚌闭合**：天生神通，一旦闭合外壳，同阶修士的任何攻击都无法破防，持续约一盏茶时间。
- **大地护体**：可引动大地之力形成护盾，覆盖范围约十丈，范围内友军防御力提升三成。
- **破邪之眼**：双目能看破一切幻术与隐身，照出妖邪原形，对鬼道修士有天然克制。

## 培养方法

- **食物**：喜好土属性灵矿，尤以"地灵石""山岳精"为食，每月需进食三块
- **栖息**：需在高处或门户旁筑巢，常年在固定地点守护
- **训练**：需经常让其守护特定目标，锻炼其防御和感知能力
- **禁忌**：不可让其离开守护目标太远，否则会焦躁不安、修为倒退

## 与主人羁绊

椒图一生只认一主，需在其幼年时以自身精血喂养三年，方可建立血脉联系。它会对主人的家园、宗门产生深厚的归属感，誓死守护。建立联系后，主人可通过神识与其沟通，感知其视野范围内的一切。若主人遭遇危险，椒图会第一时间闭合外壳，挡在主人身前。

## 著名坐骑与典故

上古时期，有一位名为"守城真人"的大能，在建造护城大阵时，偶遇一头受伤的幼椒图。他将其救下并精心喂养三年，与其建立了深厚的感情。后来守城真人凭借椒图的防御神通，守住了被魔道围攻的城池，一战成名，号称"椒图一闭，万法难开"。

## 同类对比

与**嘲风**相比，椒图防御力更强但速度较慢。与**狻猊**相比，椒图更加稳重但攻击力不足。椒图的优势在于极致的防御能力，是守护型坐骑的首选。
