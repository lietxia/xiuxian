# 白泽

> 白泽者，神兽也。通晓万物，能言人语，知天下所有鬼怪名字，是天地间最博学的存在。其形似狮而小，通体雪白如霜，双目碧绿如宝石，能看透万物本质。传说白泽乃上古时期天地间灵气所化，是知识与智慧的化身。

## 外形描写

白泽体型优美，约八尺长，通体雪白如霜，无一根杂毛。狮首较大，比例协调，双目碧绿如宝石，能看透万物本质。狮鬃呈银白色，在风中飘舞，如同流动的月光。四爪如狮，锋利无比，踏雪无痕。尾如狮尾，末端有簇白毛，挥动时可释放净化之光。

## 血脉与进化

白泽的血脉源自上古时期天地间凝聚的灵气，是最博学的神兽。进化路线如下：

- **一阶·幼体**：出生时双目未开，仅能感知周围灵气
- **三阶·成体**：双目初开，能听懂兽语，开始学习万物知识
- **八阶·神兽**：血脉大成，能言人语，知天下鬼怪名字，可预知吉凶
- **九阶·仙兽**：血脉圆满，可化为全知之眼，洞察天地法则

每次进化需经历"天知劫"，承受天道的考验，唯有智慧通天者方能通过。

## 天赋神通

- **通晓万物**：天生神通，能言人语，知天下所有鬼怪名字，可预知吉凶祸福。
- **净化之光**：双目可释放净化之光，净化一切邪祟，对鬼道和魔道有天然克制。
- **智慧之眼**：能看透万物本质，识别一切幻术和伪装。

## 培养方法

- **食物**：喜好各种灵花灵草，尤以"智慧花""通明果"为食，每月需进食一株
- **栖息**：需在灵气浓郁的山林或洞府中生活
- **训练**：需经常带其游历四方，增长见识
- **禁忌**：不可让其接触邪祟之物，否则会污染其灵气

## 与主人羁绊

白泽只臣服于智慧通天、心地善良的主人。它一生只认一主，需在其幼年时以自身精血喂养九年，方可建立血脉联系。建立联系后，主人可通过神识与其沟通，共享其视野和知识。若主人遭遇危险，白泽会提前预警，帮助主人避开灾祸。

## 著名坐骑与典故

上古时期，有一位名为"黄帝"的人皇，在东海偶遇一头受伤的白泽。他将其救下并精心喂养九年，与其建立了深厚的感情。后来黄帝凭借白泽的通晓万物神通，平定了蚩尤之乱，一统华夏，成为人族第一位人皇。

与**獬豸**相比，白泽知识更加渊博，但战斗力稍弱。与**谛听**相比，白泽更加全面，但探查深度不足。白泽的优势在于通晓万物和预知吉凶的能力，是帝王和智者的最佳坐骑。
