# 睚眦

> 睚眦者，龙生九子之次子也。性好杀伐，常衔怒目，是兵器和刑具的守护神。其形似豺而小，通体鳞甲呈血红色，双目圆睁，怒发冲冠。传说睚眦乃上古龙祖与天狼所生，继承了龙的威严与狼的凶残。它一生好战，睚眦必报，是战场上的杀神。

## 外形描写

睚眦体型矫健，约八尺长，形似豺狼却覆盖血红色鳞甲。豺首较大，比例失调却显得凶狠异常，双目圆睁，怒发冲冠，嘴角常衔一柄微型宝剑。脊背上生有一排锯齿状骨刺，从颈尾一直延伸到尾巴尖爪。四爪如狼，锋利无比，可撕裂金丹期修士的护甲。尾如钢鞭，末端有簇红毛，挥动时可释放杀气。

## 血脉与进化

睚眦的血脉源自上古龙祖与天狼的结合，属于"龙系"旁支。进化路线如下：

- **一阶·幼体**：出生时鳞甲呈淡红色，仅能发出低吼
- **三阶·成体**：鳞甲变红，能口吐剑气，攻击力初现
- **六阶·玄兽**：血脉觉醒，可释放杀气，震慑敌人心神
- **八阶·神兽**：血脉大成，可化为半豺半龙之形，掌握杀伐法则
- **九阶·仙兽**：血脉圆满，可化为杀神，言出法随

每次进化需经历"杀劫"，承受无尽杀气的淬炼，方能脱胎换骨。

## 天赋神通

- **剑气纵横**：天生神通，口吐锋利剑气，可切割金丹期修士的护甲，威力惊人。
- **杀气震慑**：释放杀气，可震慑敌人心神，令其陷入恐惧，持续约三息时间。
- **怒目圆睁**：双目可释放怒光，照破一切幻术和隐身。

## 培养方法

- **食物**：喜好金属性灵矿，尤以"血纹钢""杀伐石"为食，每月需进食三块
- **栖息**：需在战场或刑场旁生活，吸收杀气修炼
- **训练**：需经常带其战斗，锻炼其杀伐能力
- **禁忌**：不可让其长时间远离战场，否则会杀气消散、修为倒退

## 与主人羁绊

睚眦性情凶残，只臣服于实力远超自己且杀伐果断的主人。它一生只认一主，需在其幼年时以自身精血喂养三年，方可建立血脉联系。建立联系后，主人可通过神识与其沟通，感知其视野中的杀气。若主人遭遇危险，睚眦会拼死相护，甚至不惜自爆与敌人同归于尽。

## 著名坐骑与典故

上古时期，有一位名为"杀神白起"的大将，在长平之战后偶遇一头受伤的幼睚眦。他将其救下并精心喂养三年，与其建立了深厚的感情。后来杀神白起凭借睚眦的剑气纵横和杀气震慑神通，成为修真界最强的杀修，号称"睚眦一怒，血流成河"。

## 同类对比

与**嘲风**相比，睚眦攻击力更强但速度较慢。与**囚牛**相比，睚眦更加凶残但辅助能力不足。睚眦的优势在于极致的杀伐能力，是杀修和战修的最佳坐骑。
