# 嘲风

> 嘲风者，龙生九子之三子也。性好冒险，常立于殿角檐头，俯瞰大地，震慑邪祟。其形似龙而小，通体鳞甲呈青绿色，四爪紧握脊背，昂首远眺，气势非凡。传说嘲风乃上古龙祖与天凤结合所生，继承了龙的威严与凤的傲骨。它一生好动，从不驻足，常在云端翱翔，俯瞰山河大地。

## 外形描写

嘲龙体型修长，约一丈二尺，通体覆盖青绿色鳞甲，在阳光下泛出金属光泽。龙首较小但棱角分明，双目如铜铃，精光四射。脊背上生有一排锯齿状骨刺，从颈尾一直延伸到尾巴尖爪。四爪如鹰，紧握有力，可撕裂虎豹。双翼退化消失，却能御风飞行，速度极快。尾如钢鞭，末端有三根尖刺，可在飞行中保持平衡。

## 血脉与进化

嘲风的血脉源自上古龙祖与天凤的结合，属于"龙系"旁支。进化路线如下：

- **一阶·幼体**：出生时无翼，仅能滑翔，鳞甲柔软呈浅绿色
- **三阶·成体**：鳞甲硬化，御风能力初现，可日行三千里
- **六阶·玄兽**：血脉觉醒，能召唤狂风护体，飞行速度翻倍
- **八阶·神兽**：血脉大成，可化为半人半龙之形，口吐风刃
- **九阶·仙兽**：血脉圆满，彻底化为真龙，飞升仙界

每次进化需经历"风雷劫"，承受九天玄风淬炼，方能脱胎换骨。

## 天赋神通

- **御风嘲天**：天生神通，可御风飞行，速度比同阶修士快三倍。飞行时周身环绕狂风，可吹散低阶法术。
- **破邪之眼**：双目能看破一切幻术与隐身，照出妖邪原形。对鬼道修士有天然克制。
- **风刃吐息**：口吐锋利风刃，可切割金丹期修士的护甲，威力惊人。

## 培养方法

- **食物**：喜好风属性灵草，尤以"风灵草""天风果"为佳，每月需进食三株
- **栖息**：需在高处筑巢，至少千丈以上山峰之巅，常年在云端活动
- **训练**：需经常带其翱翔云端，锻炼御风能力，否则会郁郁寡欢
- **禁忌**：不可将其困于低洼之地，否则会鳞片脱落、修为倒退

## 与主人羁绊

嘲风一生只认一主，需在其幼年时以自身精血喂养三年，方可建立血脉联系。建立联系后，主人可通过神识与其沟通，感知其所见所闻。若主人遭遇危险，嘲风会拼死相护，绝不退缩。但若主人陨落，嘲风会悲鸣三日，随后绝食而亡。

## 著名坐骑与典故

上古时期，有一位名为"御风子"的大能，在云端偶遇一头受伤的幼嘲风。他将其救下并精心喂养三年，与其建立了深厚的感情。后来御风子凭借嘲风的飞行速度，成为修真界最快的修士，号称"嘲风一笑，万里云霄"。

## 同类对比

与**蒲牢**相比，嘲风速度更快但攻击力稍弱。与**狻猊**相比，嘲风更加灵活但防御力不足。嘲风的优势在于速度与破邪之眼，是侦查和追击的最佳坐骑。
