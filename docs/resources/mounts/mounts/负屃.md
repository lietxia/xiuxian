# 负屃

> 负屃者，龙生九子之六子也。性好文学，常绕于碑头之上，是碑刻的守护神。其形似龙而小，通体鳞甲呈银白色，双目常闭，似在品味碑文。传说负屃乃上古龙祖与天书所生，继承了龙的威严与书的智慧。它一生好文，能读懂天地间的每一种文字——古文、今文、妖文、魔文，皆能辨其含义。

## 外形描写

负屃体型较小，约五尺长，形似小龙却生有书卷般的尾巴。通体覆盖银白色鳞甲，在阳光下泛出金属光泽。龙首较小但双目常闭，似在品味碑文。脊背上生有细密的绒毛，呈银白色，摸起来柔软如纸。四爪短小但有力，可牢牢抓住碑头。尾如书卷，末端有簇银白毛，挥动时可释放墨香。

## 血脉与进化

负屃的血脉源自上古龙祖与天书的结合，属于"龙系"旁支。进化路线如下：

- **一阶·幼体**：出生时仅能感知文字的气息
- **三阶·成体**：能读懂简单文字，开始模仿书写
- **五阶·玄兽**：血脉觉醒，能读懂一切文字，增幅周围修士的悟性
- **七阶·圣兽**：血脉大成，可与天地共鸣，引动文气潮汐
- **九阶·仙兽**：血脉圆满，可化为文道之体，言出法随

每次进化需经历"天书劫"，承受天道的考验，唯有智慧通天者方能通过。

## 天赋神通

- **通晓文字**：天生神通，能读懂天地间的每一种文字，包括古文、今文、妖文、魔文。
- **文气增幅**：可形成一个文气领域，范围内修士的悟性和记忆力提升三成。
- **碑刻守护**：可保护一切碑刻和书籍，防止其被破坏或篡改。

## 培养方法

- **食物**：喜好文属性灵花，尤以"墨香花""书灵果"为食，每月需进食五朵
- **栖息**：需在书院、藏书阁或碑林旁生活
- **训练**：需经常让其阅读各种文字，锻炼其理解能力
- **禁忌**：不可让其接触污秽之物，否则会污染其文气

## 与主人羁绊

负屃性情温和，易与主人建立感情。它会对主人的文学天赋极为敏感，若主人精通文墨，负屃会主动亲近。建立联系后，主人可通过神识与其沟通，感知其视野中的文字。若主人遭遇文道难题，负屃会轻声吟唱，启发主人的灵感。

## 著名坐骑与典故

上古时期，有一位名为"文曲星"的大能，在昆仑山偶遇一头受伤的幼负屃。他将其救下并精心喂养三年，与其建立了深厚的感情。后来文曲星凭借负屃的通晓文字神通，成为修真界最强的文修，号称"负屃一鸣，文动九天"。

## 同类对比

与**囚牛**相比，负屃辅助能力更强，但音律神通不足。与**白泽**相比，负屃更加专注，但知识面较窄。负屃的优势在于通晓文字和文气增幅的能力，是文修和学者的最佳坐骑。
