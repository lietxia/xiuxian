# 白龙

> 白龙者，龙族之异类也。通体雪白如霜，掌控冰与雪，是龙族中的王族。其形似龙而修长，通体鳞甲呈银白色，在阳光下泛出七彩光华。传说白龙乃上古龙祖与冰凤结合所生，继承了龙的威严与凤的高洁。

## 外形描写

白龙体型修长，可达十丈长，通体覆盖银白色鳞甲，在阳光下泛出七彩光华。龙首巨大，头顶双角如鹿角般分叉，双目如日月，精光四射。脊背上生有一排冰蓝色骨刺，从颈尾一直延伸到尾巴尖爪。四爪如鹰，锋利无比，可撕裂虚空。尾如蛟龙，末端有簇银白毛，挥动时可引动风雪。

## 血脉与进化

白龙的血脉源自上古龙祖与冰凤的结合，属于"龙族"王族。进化路线如下：

- **一阶·幼体**：出生时通体淡蓝色，仅能喷出冰霜
- **三阶·成体**：鳞甲变白，能口吐冰龙息，飞行速度极快
- **八阶·神兽**：血脉大成，可召唤暴风雪，覆盖范围约百里
- **九阶·仙兽**：血脉圆满，可化为冰龙真身，掌控冰之法则

每次进化需经历"冰劫"，承受万年寒冰的淬炼，方能脱胎换骨。

## 天赋神通

- **冰龙息**：天生神通，口吐冰龙息，可冻结前方扇形区域，覆盖范围约三十丈。
- **暴风雪**：可召唤暴风雪，覆盖范围约百里，范围内敌人速度降低五成。
- **龙威震慑**：释放龙威，可震慑方圆千里内的一切生灵，低阶妖兽直接臣服。

## 培养方法

- **食物**：喜好冰属性灵草，尤以"冰龙草""雪凤花"为食，每月需进食一株
- **栖息**：需在冰原或雪山中生活，喜寒畏热
- **训练**：需经常带其翱翔云端，锻炼其飞行和控冰能力
- **禁忌**：不可让其长时间暴露在烈日下，否则会鳞甲干裂、修为倒退

## 与主人羁绊

白龙性情高傲，只臣服于实力远超自己且拥有冰灵根或龙血的主人。它一生只认一主，需在其幼年时以自身精血喂养九年，方可建立血脉联系。建立联系后，主人可通过神识与其沟通，共享其视野。若主人遭遇危险，白龙会拼死相护，甚至不惜自爆内丹与敌人同归于尽。

## 著名坐骑与典故

上古时期，有一位名为"冰帝"的大能，在北极偶遇一头受伤的白龙。他将其救下并精心喂养九年，与其建立了深厚的感情。后来冰帝凭借白龙的冰龙息和暴风雪神通，成为修真界最强的冰修，号称"白龙一吟，万里冰封"。

## 同类对比

与**青龙**相比，白龙攻击力更强，但防御力稍逊。与**应龙**相比，白龙更加灵活，但神通稍弱。白龙的优势在于冰属性掌控和飞行能力，是冰修梦寐以求的坐骑。
