# 囚牛

> 囚牛者，龙生长子也。性好音律，常蹲于琴头听音，闻妙音则摇头晃脑，如遇知音。其形似龙而小，通体鳞甲呈金黄色，双目常闭，似在聆听天籁。传说囚牛乃上古龙祖与天音神女所生，继承了龙的威严与神女的乐感。它一生痴迷音乐，能听懂天地间的每一种声音——风声、水声、鸟鸣、虫唱，皆能辨其韵律。

## 外形描写

囚牛体型较小，约八尺长，通体覆盖金黄色鳞甲，在阳光下闪闪发光。龙首较大，比例失调却显得憨态可掬，双目常闭，似在聆听天籁。脊背上生有细密的绒毛，呈淡金色，摸起来柔软如丝。四爪短小，常蹲伏于琴头或笛尾。尾如琴弦，拨动时能发出悦耳的音符。

## 血脉与进化

囚牛的血脉源自上古龙祖与天音神女的结合，属于"龙系"旁支。进化路线如下：

- **一阶·幼体**：出生时双目未开，仅能感知音波振动
- **三阶·成体**：双目初开，能听懂简单旋律，开始模仿鸟鸣
- **五阶·玄兽**：血脉觉醒，能发出摄魂之音，扰乱敌人心神
- **七阶·圣兽**：血脉大成，能与天地共鸣，引动灵气潮汐
- **九阶·仙兽**：血脉圆满，一曲可令百花盛开、万物生长

每次进化需经历"天音劫"，承受九天仙乐的洗礼，方能脱胎换骨。

## 天赋神通

- **通灵之音**：天生神通，能发出悦耳的龙吟，听懂兽语、鸟语、虫鸣，可与万灵沟通。
- **摄魂龙吟**：发出一声龙吟，可扰乱敌人心神，令其陷入迷茫，持续约三息时间。
- **天音共鸣**：可与天地灵气共鸣，引动灵气潮汐，增幅范围内友军的法术威力。

## 培养方法

- **食物**：喜好音属性灵花，尤以"天籁花""音灵果"为佳，每月需进食五朵
- **栖息**：需在安静优雅的环境中生活，远离喧嚣嘈杂之地
- **训练**：需经常为其演奏音律，培养其音感和灵性
- **禁忌**：不可让其听到刺耳噪音，否则会暴怒伤人

## 与主人羁绊

囚牛性情温顺，易与主人建立感情。它会对主人的音律天赋极为敏感，若主人精通音律，囚牛会主动亲近。建立联系后，主人可通过音律与其沟通，囚牛能感知主人的情绪变化。若主人心情低落，囚牛会轻声吟唱，安抚主人的心灵。

## 著名坐骑与典故

上古时期，有一位名为"琴仙"的大能，在昆仑山巅弹奏古琴时，一头金色的幼囚牛从云端飞来，蹲在琴头聆听。此后，琴仙与囚牛形影不离，他以琴驭牛，以牛辅琴，创下了"一曲琴音动九天"的传说。

## 同类对比

与**嘲风**相比，囚牛速度较慢但辅助能力更强。与**狻猊**相比，囚牛攻击力不足但音律神通独一无二。囚牛的优势在于与主人的心灵相通和音律辅助，是音修的最佳坐骑。
