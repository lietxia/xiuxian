# 獬豸

> 獬豸者，神兽也。能辨是非曲直，识善恶忠奸，古代法官帽上饰之，象征公正。其形似羊而小，通体漆黑如墨，头顶独角，锐利无比。传说獬豸乃上古时期天地间正气所化，是正义与公正的化身。

## 外形描写

獬豸体型优美，约六尺长，形似山羊却通体漆黑如墨，在阳光下泛出金属光泽。头顶独角是它最显著的特征——角呈螺旋状，长约一尺，锋利无比，可刺穿精钢。双目呈金色，能看透人心，辨别是非曲直。四蹄如铁，踏地有声，每一步都会留下浅浅的蹄印。尾短小，常紧贴臀部。

## 血脉与进化

獬豸的血脉源自上古时期天地间凝聚的正气，是最公正的神兽。进化路线如下：

- **一阶·幼体**：出生时独角柔软，仅能感知善恶
- **三阶·成体**：独角硬化，能辨别简单的是非
- **六阶·玄兽**：血脉觉醒，能看透人心，辨别忠奸
- **八阶·神兽**：血脉大成，独角可释放正义之光，净化邪祟
- **九阶·仙兽**：血脉圆满，可化为正义化身，言出法随

每次进化需经历"天问劫"，承受天道的拷问，唯有心正者方能通过。

## 天赋神通

- **明辨是非**：天生神通，能看透人心，辨别忠奸善恶，任何谎言在它面前都无所遁形。
- **正义独角**：头顶独角可释放正义之光，净化一切邪祟，对鬼道和魔道有天然克制。
- **铁蹄镇邪**：四蹄踏地可释放震荡波，将隐藏的妖邪震出原形。

## 培养方法

- **食物**：喜好金属性灵矿，尤以"精金""玄铁"为食，每月需进食三块
- **栖息**：需在正气浓郁之地生活，如衙门、刑场、书院旁
- **训练**：需经常让其辨别是非，锻炼其感知能力
- **禁忌**：不可让其接触邪祟之物，否则会污染其正气

## 与主人羁绊

獬豸只臣服于正直无私的主人，若主人心生邪念，它会立即离去。它一生只认一主，需在其幼年时以自身精血喂养三年，方可建立血脉联系。建立联系后，主人可通过神识与其沟通，感知其视野中的善恶之气。若主人遭遇危险，獬豸会拼死相护，甚至不惜折断独角。

## 著名坐骑与典故

上古时期，有一位名为"包青天"的法官，在审理一桩冤案时，偶遇一头受伤的幼獬豸。他将其救下并精心喂养三年，与其建立了深厚的感情。后来包青天凭借獬豸的明辨是非神通，审清了无数冤案，号称"獬豸一触，冤情大白"。

## 同类对比

与**白泽**相比，獬豸战斗力更强，但预知能力稍逊。与**谛听**相比，獬豸更加正直，但探查范围较小。獬豸的优势在于明辨是非的能力，是法官和捕快的最佳坐骑。
