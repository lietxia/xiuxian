# 蛟龙

> 蛟龙者，有鳞曰蛟，龙类进化的中期形态。能兴云布雨，掌控江河，是龙族中与水最亲近的存在。其形似龙而粗壮，通体鳞甲呈深蓝色，双目如日月，能看透水底。传说蛟龙乃龙族与水中精怪结合所生，继承了龙的水性。

## 外形描写

蛟龙体型粗壮，约两丈长，形似真龙却更为粗犷。通体覆盖深蓝色鳞甲，在阳光下泛出幽光。龙首巨大，双目如日月，能看透水底。脊背上生有一排锯齿状骨刺，从颈尾一直延伸到尾巴尖爪。四爪如龙，锋利无比，可撕裂精钢。尾如蛟龙，末端有簇深蓝毛，挥动时可引动水浪。

## 血脉与进化

蛟龙的血脉源自上古龙族与水中精怪的结合，属于"龙族"旁支。进化路线如下：

- **一阶·幼体**：出生时仅能游水，无翼
- **三阶·成体**：生出双翼，能飞行，鳞甲开始变色
- **五阶·玄兽**：血脉觉醒，能兴云布雨，掌控江河
- **七阶·圣兽**：血脉大成，可化为半蛟半龙之形，掌握水之法则
- **九阶·仙兽**：血脉圆满，可化为真龙，飞升仙界

每次进化需经历"水劫"，承受九重巨浪的淬炼，方能脱胎换骨。

## 天赋神通

- **兴云布雨**：天生神通，可引动天地灵气，制造狂风暴雨，覆盖范围约百里。
- **蛟龙吐息**：口吐水柱，可冲击前方扇形区域，覆盖范围约三十丈。
- **水遁无形**：可在水中自由穿梭，速度比陆地上快三倍。

## 培养方法

- **食物**：喜好水属性灵草，尤以"水龙草""江河精"为食，每月需进食五株
- **栖息**：需在深江湖海中生活，喜水畏火
- **训练**：需经常带其潜入深海，锻炼其水战能力
- **禁忌**：不可让其长时间离开水源，否则会鳞甲干裂、修为倒退

## 与主人羁绊

蛟龙性情刚烈，只臣服于实力远超自己且拥有水灵根的主人。它一生只认一主，需在其幼年时以自身精血喂养三年，方可建立血脉联系。建立联系后，主人可通过神识与其沟通，共享其视野。若主人遭遇危险，蛟龙会拼死相护，甚至不惜自爆内丹与敌人同归于尽。

## 著名坐骑与典故

上古时期，有一位名为"龙王三太子"的大能，在东海偶遇一头受伤的幼蛟龙。他将其救下并精心喂养三年，与其建立了深厚的感情。后来龙王三太子凭借蛟龙的兴云布雨神通，成为修真界最强的龙修，号称"蛟龙一吟，江河倒流"。

## 同类对比

与**虬龙**相比，蛟龙攻击力更强，但速度稍逊。与**应龙**相比，蛟龙更加常见，但神通较弱。蛟龙的优势在于水属性掌控能力，是水修梦寐以求的坐骑。
