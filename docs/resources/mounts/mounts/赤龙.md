# 赤龙

> 赤龙者，龙族之战斗形态也。通体赤红如炭，掌控火与炎，是龙族中的战神。其形似龙而威猛，通体鳞甲呈赤红色，双目如炭火，精光四射。传说赤龙乃上古龙祖与天火结合所生，继承了龙的威严与火的力量。

## 外形描写

赤龙体型威猛，可达八丈长，通体覆盖赤红色鳞甲，如同燃烧的炭火。龙首巨大，双目如炭火，精光四射，令人不敢直视。脊背上生有一排锯齿状骨刺，从颈尾一直延伸到尾巴尖爪。四爪如鹰，锋利无比，可撕裂虚空。尾如蛟龙，末端有簇赤红毛，挥动时可引动火焰。

## 血脉与进化

赤龙的血脉源自上古龙祖与天火的结合，属于"龙族"战斗分支。进化路线如下：

- **一阶·幼体**：出生时通体淡红色，仅能喷出小火苗
- **三阶·成体**：鳞甲变红，能口吐三昧真火，飞行速度极快
- **七阶·圣兽**：血脉大成，可召唤火海，焚烧一切
- **九阶·仙兽**：血脉圆满，可化为火龙真身，掌控火之法则

每次进化需经历"天火劫"，承受天火的淬炼，方能脱胎换骨。

## 天赋神通

- **三昧真火**：天生神通，口吐三昧真火，可焚烧万物，对邪魔有天然克制，温度可达万度。
- **火海焚天**：可召唤火海，覆盖范围约百里，范围内敌人持续受到火焰伤害。
- **龙威震慑**：释放龙威，可震慑方圆千里内的一切生灵，低阶妖兽直接臣服。

## 培养方法

- **食物**：喜好火属性灵草，尤以"火龙草""凤凰胆"为食，每月需进食一株
- **栖息**：需在火山口或地火脉旁生活，喜热畏寒
- **训练**：需经常带其翱翔云端，锻炼其飞行和控火能力
- **禁忌**：不可让其接触水属性法宝或法术，否则会熄灭体内火源

## 与主人羁绊

赤龙性情刚烈，只臣服于实力远超自己且拥有火灵根或龙血的主人。它一生只认一主，需在其幼年时以自身精血喂养九年，方可建立血脉联系。建立联系后，主人可通过神识与其沟通，共享其视野。若主人遭遇危险，赤龙会拼死相护，甚至不惜自爆内丹与敌人同归于尽。

## 著名坐骑与典故

上古时期，有一位名为"炎帝"的人皇，在昆仑山偶遇一头受伤的幼赤龙。他将其救下并精心喂养九年，与其建立了深厚的感情。后来炎帝凭借赤龙的三昧真火神通，大败蚩尤，一统华夏，成为人族第一位炎帝。

## 同类对比

与**白龙**相比，赤龙攻击力更强，但防御力稍逊。与**应龙**相比，赤龙更加威猛，但灵活性不足。赤龙的优势在于极致的火焰掌控能力，是火修梦寐以求的坐骑。
