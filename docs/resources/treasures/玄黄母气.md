# 玄黄母气

> 天地灵气孕育之精华，修仙者梦寐以求的至宝。

玄黄母气诞生于天地灵气交汇之处，需历经千万年方可成形。

## 二、外观特征

玄黄母气外观独特，灵气逼人，散发着迷人的光泽。

## 三、功效详解}

玄黄母气具有非凡的功效，可大幅提升修士的修为和实力。

## 四、获取方式

玄黄母气极为罕见，只存在于灵气浓郁的秘境绝地之中。

## 五、使用方法

玄黄母气可直接服用，也可用于炼丹、炼器、布阵。

## 六、相关传说

传说上古大能曾以玄黄母气为引，炼制出逆天神丹。
