# 玄黄母气

> 品阶：神级九品 · 万物之母

## 诞生条件

玄黄母气诞生于天地初开之际。

盘古开天辟地，混沌初开，清阳之气上升为天，浊阴之气下沉为地。在清浊二气交汇之处，产生了一种名为"玄黄"的气体——玄为天色，黄为地色，玄黄二气交融，便是玄黄母气。

玄黄母气是万物之母，可化为任何物质。天地间的万物，皆由玄黄母气演化而来。

玄黄母气的形成条件极为苛刻：必须在天地初开时，清浊二气恰好交融；交融后必须被封存于特殊的容器中，不被后天灵气污染。

玄黄母气现世之时，天地间会响起大道之音，万籁俱寂，仿佛天地都在屏息。

## 外观特征

玄黄母气呈玄黄二色交织的雾气状，玄色在上，黄色在下，如同一幅微缩的天地景象。雾气不断流转，时而化为山岳，时而化为江河，时而化为草木，时而化为飞禽。

将玄黄母气吸入体内，会感到一股温润的气息在体内流转，如同与天地共鸣。玄黄母气无需炼化，可直接被身体吸收，转化为任何属性的灵力。

玄黄母气有一个奇特的特性：它会排斥后天灵气。在玄黄母气周围，后天灵气会被排开，形成一个"真空地带"。

## 功效

**造化万物**：玄黄母气可化为任何物质。只需以神识引导，便可将玄黄母气化为金木水火土任何属性的材料。

**镇压气运**：玄黄母气可镇压一方天地的气运。将玄黄母气供奉于宗门，可保宗门气运万年不衰。

**重塑肉身**：玄黄母气可重塑肉身。无论肉身受损多严重，只需以玄黄母气滋养，便可重塑出一具完美的肉身。

**感悟天地**：玄黄母气蕴含天地初开时的法则，修士以神识探入其中，可感悟天地从无到有的过程。

## 获取方式

玄黄母气只存在于天地初开时的遗迹中。

**天地初开遗迹**：一些天地初开时残留的空间碎片中，可能封存着玄黄母气。但这些遗迹极为隐秘，非大机缘者不可入。

**上古至宝内部**：一些上古至宝在天地初开时吸收了玄黄母气，至今仍有残留。如天地玄黄玲珑宝塔、盘古幡等。

**大能传承**：一些上古大能将玄黄母气作为传承之宝，留给后世弟子。如老子的天地玄黄玲珑宝塔，便蕴含玄黄母气。

## 使用方法

**造化万物**：以神识引导玄黄母气，可将其化为任何物质。此法需要极高的修为和精准的控制力。

**镇压气运**：将玄黄母气供奉于宗门的核心，可镇压宗门气运，保万年不衰。

**重塑肉身**：以玄黄母气滋养受损的肉身，可重塑出一具完美的肉身。

**炼器**：玄黄母气是炼制玄黄级法宝的核心材料。以玄黄母气为主材炼制的法宝，威力无穷。
