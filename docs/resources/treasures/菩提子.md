# 菩提子

> 品阶：仙级六品 · 悟道圣物

## 诞生条件

菩提子，乃是菩提树所结之籽。然并非所有菩提树都能结果。寻常菩提树不过凡木，百年枯荣，与修行无涉。唯有灵根级别的菩提古树，方能凝出蕴含道韵的菩提子。

真正能结果的上古菩提树，需生长于灵气充沛、天地法则交汇之处。其根须须扎入地脉，汲取九幽之下的阴灵之气；其枝叶须伸向云霄，承接九天之上的阳和之精。阴阳交融，天地交汇，菩提树方能积累到足够结子的道韵。

菩提树每千年方开一次花，花色纯白如雪，花开时方圆百里皆可闻到一股清幽的香气。花谢之后，还需再等千年，方能结出菩提子。也就是说，一颗菩提子的诞生至少需要两千年的积累。且每次结果不过九枚，每一枚都蕴含了菩提树两千年所吸收的天地道韵。

更为难得的是，菩提树在结子之后会进入千年的休眠期，期间不吸收灵气，不吐纳日月精华。因此，同一棵菩提古树每三千年才能产出一次菩提子。

## 外观特征

菩提子形如枣核，大小不过成人拇指的指节，却有一种说不出的沉凝之感。握在手中，沉甸甸的，仿佛握住的不是一颗小小的种子，而是一座山、一片天。

其色初为青绿，随着年份增长逐渐转为淡黄，最终化为晶莹剔透的金黄色。千年以下的菩提子呈青色，道韵尚浅；千年以上转为淡黄，已具灵性；三千年以上方为金黄色，此时才算是真正成熟的菩提子。

菩提子的表面有天然的纹路，这些纹路并非杂乱无章，而是天然形成的梵文印记。不同的菩提子表面的梵文各不相同，有的如同莲花，有的似万字，有的如宝瓶——每一道纹路都蕴含着大道至理，是天地法则的具象化呈现。

持菩提子在手，可感到一阵温和的气息从掌心传入，令人心神宁静、杂念不生。若在修行时将菩提子置于眉心，更可进入一种物我两忘的空明之境，平日里百思不解的修行难题，往往在这一刻豁然开朗。

最奇特的是，菩提子有时会发出轻微的声响，如同有人在远处诵经，又如同风过竹林，仔细倾听却又无声无息。这种"有声若无"的禅意，正是菩提子灵性的体现。

## 功效

菩提子被誉为"悟道圣物"，其最大功效在于帮助修士明悟大道。

**顿悟之助**：菩提子能够引导修士进入一种"顿悟"状态。在此状态下，修士对天地法则的感悟能力提升数十倍，平日里无法理解的玄奥道法，此时一目了然。许多修士修行数百年无法突破的瓶颈，在菩提子帮助下只需数年便可突破。

修真界一直流传着一句话："一颗菩提子，顶得百年苦修。"虽然有些夸张，但也足见其珍贵。曾有合体期修士持菩提子修行，将领悟时间从三百年缩短到了三十年，最终成功突破大乘期。

**静心凝神**：菩提子最为基础但最为实用的功效，是它的静心效果。将菩提子佩戴在身上，可以抵御心魔入侵，防止走火入魔。在闭关突破的关键时刻，菩提子能让修士保持心神的清明，不被外界的干扰所动摇。对于修炼魔道的修士而言，菩提子更是化解心魔的最佳法器。

**佛法加持**：菩提子对佛门修士的效果最为显著。一颗菩提子可让佛门修士的禅定境界大幅提升，对佛法的理解更加深透。用菩提子制成的佛珠，在诵经时会产生一种无形的加持力，使经文的威力倍增。

## 获取方式

菩提子的获取，考验的不仅是实力，更看重机缘。

**菩提古树**：修真界已知的菩提古树屈指可数。最有名的有三棵：其一在西方极乐世界的大雷音寺前，由佛祖亲自栽种，由佛门护法守护。其二在天竺灵山的深处，相传是达摩祖师所植。其三在东胜神洲的灵台方寸山中——此处也是传说中菩提祖师的道场，只是此树已被封印，无人知晓具体位置。

**佛门传承**：有些佛门大宗中，历代传承下来的菩提子作为镇宗之宝保存。这些菩提子一般不会轻易示人，只有对宗门有重大贡献的弟子才能得到赏赐。

**上古遗迹**：在上古佛门的遗迹或高僧坐化的洞府中，偶尔也能发现遗留的菩提子。这些菩提子虽然经历了漫长的岁月，但由于本身的灵性，不仅没有失去效用，反而因为岁月的沉淀而更加珍贵。

**守护**：菩提树周围必有佛门护法守护。最著名的当属那棵大雷音寺前的菩提古树，树下常年有八部天龙护法，寻常修士根本无法靠近。而灵台方寸山中的菩提树周围，则有强大的禁制阵法，传说此阵乃菩提祖师亲手所设，非有缘人不得入。

## 使用方法

**随身佩戴**：将一枚菩提子穿绳戴在颈间或手腕上，可时刻保持心神清明。这是最简单也是性价比最高的使用方法。菩提子会随着时间不断散发出温和的道韵，潜移默化地改善修士的悟性。

**含于口中**：在闭关参悟时，将菩提子含在舌下或者握在手中，可以更快地进入入定状态，领悟天地法则。此法比随身佩戴的效果更强，但消耗也更快，一枚菩提子大约可供百次左右的深层次入定。

**炼制佛珠**：将多枚菩提子串成念珠，具有强大的佛法加持效果。一百零八颗菩提子串成的念珠，是佛门的无上至宝，持之可万法不侵。

**入药炼丹**：菩提子是炼制"悟道丹"的主药。悟道丹服下后可让修士在短时间内进入顿悟状态，对于突破瓶颈极为有效。炼丹时辅以三光神水，效果更佳。

## 相关传说

**佛祖成道**：相传释迦牟尼佛当年在菩提树下静坐七七四十九天，最终大彻大悟，证得无上正等正觉。他坐悟的那棵菩提树，后来结出了一百零八颗菩提子，每一颗都蕴含了佛祖成道时的大道感悟。这串菩提子被称为"佛宝之祖"，如今供奉于大雷音寺中。

**五祖传法**：禅宗五祖弘忍传法给六祖慧能时，没有传经文、没有传法器，只传了一颗菩提子。弘忍对慧能说："菩提本无树，明镜亦非台。本来无一物，何处惹尘埃。你既已悟此偈，这颗菩提子便是你的法印。"慧能接过菩提子，当即开悟，成为一代禅宗大师。

**地藏愿力**：地藏王菩萨入地狱度化众生时，手中持有一串菩提念珠。此念珠以一百零八颗菩提子串成，每一颗都蕴含了地藏菩萨"地狱不空，誓不成佛"的大愿力。此珠后来成为地藏一脉的传承至宝。

**菩提祖师**：传说灵台方寸山的菩提祖师，其道号便源自他手中的一颗金色菩提子。此子乃是天地间第一颗菩提子，蕴含了天地初开之时的大道本源。菩提祖师观此子参悟了无上大道，方才成就了"须菩提"之名。
