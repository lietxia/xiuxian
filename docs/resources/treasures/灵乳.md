# 灵乳

> 品阶：地级五品 · 灵脉之乳

## 诞生条件

灵乳诞生于灵脉最核心的地带。

灵脉是大地灵气的通道，灵气在灵脉中流动，如同血液在血管中流淌。在灵脉最核心的位置，灵气的浓度高到了一个极致，灵气会从气态逐渐液化，凝结成乳白色的液体——这便是灵乳。

灵乳的形成需要三个条件：其一，灵脉必须足够古老（至少十万年）；其二，灵脉核心的灵气浓度必须达到临界值；其三，灵脉必须处于密封状态，不与外界空气接触。

灵乳每千年才会凝结一滴，因此极为珍贵。一条十万年的灵脉，核心处也不过积攒了百余滴灵乳。

灵乳凝结之时，灵脉会微微震颤，如同一颗心脏在跳动。灵脉周围的灵气浓度会短暂提升数倍。

## 外观特征

灵乳呈乳白色，质地粘稠如蜂蜜，散发着淡淡的清香。将灵乳放在光照下，会呈现珍珠般的光泽。

灵乳入口有浓郁的甘甜，如同琼浆玉液。一滴灵乳入腹，会感到一股温暖的气息在体内流转，滋养着四肢百骸。

灵乳有一个奇特的特性：它会自行吸收周围的灵气。将灵乳放在灵气充沛的地方，它的体积会缓慢增长。

## 功效

**洗髓伐毛**：灵乳可洗髓伐毛，改善修士的体质。服用一滴灵乳，可让体内的杂质排出体外，肉身更加纯净。

**固本培元**：灵乳可巩固根基，提升修炼资质。服用灵乳后，修士的灵根纯度会大幅提升。

**筑基辅助**：灵乳是筑基的绝佳辅助材料。在筑基时服用一滴灵乳，可大幅提升筑基的成功率。

**疗伤续命**：灵乳可修复受损的经脉和丹田。即便是重伤濒危之人，服用一滴灵乳也能稳住伤势。

## 获取方式

灵乳只产于灵脉最核心的地带，需深入地下万丈方可寻得。

**灵脉勘探**：通过地脉勘探术找到灵脉的核心位置，然后挖掘进入。但灵脉核心的温度和压力极高，非金丹期修士无法承受。

**上古遗迹**：一些上古遗迹的灵泉中可能存有灵乳。这些灵乳被封存在特殊的容器中，万年不腐。

**守护妖兽**：灵乳周围必有妖兽守护。最常见的是"灵脉蟒"，此蟒以灵乳为食，修为可达元婴期。

## 使用方法

**直接服用**：直接服用灵乳是最简单的方法。但不可贪多，普通修士一次一滴足矣，多了肉身承受不住。

**炼丹入药**：灵乳是炼制"筑基丹""培元丹"等丹药的必备材料。以灵乳为辅，可让药效提升数倍。

**浸泡沐浴**：将灵乳滴入灵泉中，以灵泉沐浴，可让灵乳的精华渗入体内，洗髓伐毛。

## 相关传说

**神农尝百草**：神农氏尝百草时，曾以灵乳解毒。无论中了什么毒，只需服用一滴灵乳，便可化解。

**灵乳化形**：传说灵乳积累到一定程度，会诞生灵智，化为"灵乳精灵"。灵乳精灵形如婴儿，通体雪白，是天地间最纯净的生命。

**王母蟠桃**：西王母的蟠桃园中，有一口灵泉，泉中便含有灵乳。蟠桃树以灵泉浇灌，才能结出蟠桃这等奇珍。
