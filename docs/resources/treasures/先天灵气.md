# 先天灵气

> 品阶：天级三品 · 混沌原始之气

## 诞生条件

先天灵气，是天地初开时残留下来的原始之气。

混沌未开之时，天地间充斥着一种名为"先天一炁"的原始之气。这种气是万气之母，可化为任何属性的灵气。盘古开天辟地，清阳之气上升为天，浊阴之气下沉为地，先天一炁分化为后天灵气。

然而，并非所有的先天一炁都转化为了后天灵气。有极少数先天一炁被封存在特殊的空间裂缝中，或者被某些上古至宝吸收，得以保留至今。

先天灵气的形成条件极为苛刻：必须是在天地初开时被封存，且封存之处必须完全隔绝后天灵气的侵蚀。一旦与后天灵气接触，先天灵气便会被污染，退化为后天灵气。

先天灵气现世之时，会引发一场"灵气风暴"——方圆万里的后天灵气会被先天灵气吸引，疯狂涌来，形成一个巨大的灵气漩涡。

## 外观特征

先天灵气并非固定形态，而是一团不断流转的雾气。雾气呈乳白色，时而凝聚成珠，时而散开为雾，变幻莫测。

先天灵气的气息极为独特——吸入一口，便觉全身毛孔张开，如同浸泡在温泉之中。与后天灵气不同，先天灵气无需炼化，可直接被身体吸收，转化为任何属性的灵力。

先天灵气有一个奇特的特性：它会排斥后天灵气。在先天灵气周围，后天灵气会被排开，形成一个"真空地带"。

## 功效

**重塑根基**：先天灵气可重塑修士的根基。无论修士的根基有多差，只要吸收足够的先天灵气，便可将根基重塑为完美状态。这是后天灵气永远无法做到的。

**提升资质**：先天灵气可提升修士的灵根资质。下品灵根吸收先天灵气后，可提升为中品；中品可提升为上品；上品可提升为天品。

**突破瓶颈**：先天灵气蕴含天地初开时的原始法则，可帮助修士突破任何瓶颈。无论是小境界还是大境界，先天灵气都有极大的助益。

**净化杂质**：先天灵气可净化修士体内的杂质，包括丹毒、药毒、心魔等一切负面因素。

## 获取方式

先天灵气只存在于极少数特殊之地：

一是混沌秘境，天地初开时残留的混沌空间碎片。秘境中先天灵气充沛，但秘境入口极为隐秘，且随时可能崩塌。

二是上古至宝内部，一些上古至宝在天地初开时吸收了先天灵气，至今仍有残留。如混沌珠、乾坤鼎等。

三是先天灵根，一些天地初开时诞生的先天灵根，其果实或种子中蕴含先天灵气。如人参果、蟠桃等。

## 使用方法

**直接吸收**：将先天灵气吸入体内，无需炼化，先天灵气会自动转化为修士所需的灵力。这是最直接的用法。

**炼丹**：先天灵气是炼制"先天丹"的主药。先天丹服下后，可让修士在短时间内获得先天灵气，大幅提升修为。

**布阵**：以先天灵气为阵眼布置的"先天聚灵阵"，可将后天灵气转化为先天灵气，供修士吸收。

## 相关传说

**盘古开天**：盘古开天时，先天一炁分化为后天灵气。但盘古在开天时，曾将一缕先天一炁封存在自己的心脏中。这颗心脏后来化为"盘古之心"，至今仍在跳动，源源不断地产生先天灵气。

**鸿钧讲道**：道祖鸿钧在紫霄宫讲道时，曾以先天灵气为媒介，向三千弟子演示天地初开的景象。众弟子观之大悟，各自突破。

**老子化胡**：老子西出函谷关时，曾将一缕先天灵气赠予尹喜。尹喜凭借这缕先天灵气，最终证道成仙，成为了文始真人。
