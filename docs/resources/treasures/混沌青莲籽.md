# 混沌青莲籽

> 品阶：神级九品 · 混沌至宝

## 诞生条件

混沌青莲籽，乃天地未分、混沌未开之际，一株自虚无中诞生的青莲所结。此莲生于混沌，长于太初，历经三万个元会方开一次花，再经三万个元会结一次籽。每一次花开籽成，不过三五之数，故自盘古开天以来，世间所存混沌青莲籽屈指可数。

其诞生无特定地域，唯在混沌深处、时空未定之处方可得见。寻常世界之中，纵有通天彻地之能，亦无法培育此物——盖因混沌之气不存，青莲便无生根之所。

## 外观特征

混沌青莲籽大如鸡卵，形似莲子而略扁，通体呈混沌之色。所谓混沌之色，非青非白非黑，目光所及，似有万千色彩流转其中，却又无一色可名状。

其表有天然道纹，纹路如龙蛇蜿蜒，细看之下，竟演化出日月星辰、山河大地之相。每隔片刻，纹路自行变幻，重演一次开天辟地之景象。籽中隐约可见一株微缩青莲，莲叶九片，每一叶上各托一界，诸天万象尽在其中。

持此籽于手，可感一股苍茫浩瀚之气自掌心渗入，仿佛触摸到了天地的源头。若以神识探入，更可见混沌翻涌、地水火风奔涌不息的奇景。

## 功效

混沌青莲籽蕴含的并非寻常灵气，而是最为本源的混沌之气。此气乃万气之母，可化为任何属性的灵力，亦可直接滋养大道根基。

**修炼之助**：炼化一枚混沌青莲籽，可让修士在丹田中开辟一片混沌海。混沌海中自行演化清浊二气，清气上升为天、浊气下沉为地，最终在体内自成一方小天地。有此天地为根基，修士对大道法则的领悟远超常人，突破境界时几乎不受天地法则的压制。

**悟道之宝**：持混沌青莲籽入定，可观想开天辟地之景，亲眼见证大道从无到有的全过程。此法对合体期以上修士冲击大乘、渡劫境界有不可思议的助益。

**本源修复**：混沌青莲籽能修复受损的大道根基。若是修士在突破时走火入魔、道基崩毁，或是在天劫中被毁去修为，只需一枚混沌青莲籽，便可重塑根基，且更胜从前。

## 获取方式

混沌青莲籽不存在于任何已知的洞天福地，亦非人力可寻。其来源有三：

其一，混沌秘境开启时，若有缘人误入混沌深处，或可在时空中发现漂浮的青莲籽。然混沌秘境亿万年方现一次，且非大机缘者不可入。

其二，上古大能遗留下的洞府中或有珍藏。传说当年道祖鸿钧讲道于紫霄宫，曾以三枚混沌青莲籽作为讲道之资，分赠门下弟子。此三枚青莲籽随诸圣隐去，再无踪迹。

其三，以无上大法力重塑混沌，自虚无中孕育。然此法需至少大罗金仙修为，且需耗费数个元会的法力，若非万不得已，无人愿行此道。

**守护**：混沌青莲籽本身便有无上威能，其周围的混沌之气可侵蚀万物，化有形为无形。更有传说，每一枚混沌青莲籽周围都有一条混沌真龙守护，此龙乃青莲所化，实力堪比天道圣人。

## 使用方法

**直接炼化**：将混沌青莲籽纳入丹田，以自身真火慢慢炼化。此法耗时极长，少则千年，多则万年。然一旦炼化成功，所获好处最为彻底，丹田中开辟的混沌海也最为广阔。

**入药炼丹**：混沌青莲籽是炼制"混沌造化丹"的唯一主药。此丹服下后可立地飞升，且根基之稳固远超寻常飞升者。辅以九天息壤、三光神水等至宝，可炼出传说中的"开天丹"，服之直证混元。

**炼器**：以混沌青莲籽为器胚，辅以万千星辰之精，可炼制先天至宝。传说盘古大神的开天斧，其斧柄便是以混沌青莲的一截莲茎所制。

**布阵**：混沌青莲籽可作为混沌级大阵的阵眼。以上古阵法"混沌五行归元阵"为例，以混沌青莲籽为中枢，可镇压一方天地，使阵内自成一界，万法不侵。

## 相关传说

**开天遗物**：相传盘古大神开天辟地之时，混沌青莲有感于大道之变，结下最后一枚种子便化为虚无。此籽在开天的大破灭中幸存，随天地碎片漂流，最终落入洪荒大陆。

**鸿钧赠籽**：道祖鸿钧于紫霄宫讲道时，曾取出一枚混沌青莲籽，言此物乃天地间最古老之物，蕴含大道之始。他以这枚青莲籽为六圣演示开天之道，后不知所踪。

**女娲补天余料**：另有一说，女娲补天之时，曾以混沌青莲籽炼化成五色石浆，填补苍天裂痕。余下的一枚青莲籽被女娲藏于不周山遗址之下，待有缘人取之。

**青莲至尊**：传说上古时期有一散修，偶得一枚混沌青莲籽，炼化后功力大进，自号"青莲至尊"。此人以一己之力独战三圣而不败，后不知所终。有人言他已将青莲籽完全炼化，在体内开辟了一方真正的大千世界，超脱此界而去。
