# 龙脉石

> 品阶：天级六品 · 地脉至宝

## 诞生条件

龙脉石非寻常矿石，亦非简单的地气凝结之物。它的诞生，需天时地利与漫长岁月的共同作用。

大地之下，有无数灵气流动的通道，如同人体的经脉一般密布于地壳深处。其中最为粗壮、灵气最充沛的几条主要通道，便被修真者称为"龙脉"。龙脉是天地灵气的主动脉，承载着一方世界的气运流转。

龙脉石的诞生，便是在这些龙脉的关键节点之处。在地底灵气最为集中的龙脉交汇点上，灵气的浓度高到了一个临界值，长年累月的冲刷与沉淀，使得灵气逐渐从气态转为液态，再从液态慢慢凝固，最终化为固体的晶体——这便是龙脉石的雏形。

这个过程极为漫长，至少需要十万年的时间。而且在这十万年间，龙脉不能有任何的移动或变化，否则正在凝结的龙脉石便会崩解消散。正因如此，修真界现存的龙脉石极为稀少，每一块都是经历了十万年以上岁月沉淀的至宝。

龙脉石的品级也并非一成不变。龙脉石会随着时间不断成长，吸收龙脉之气提升自己的品质。最早的龙脉石呈灰色，每过万年颜色便加深一分，从灰到青，从青到碧，最终化为最上乘的"帝王绿"——通体翠绿欲滴，没有一丝杂质。

## 外观特征

龙脉石形无定状，有的如卵石般圆润光滑，有的如山峰般峻峭嶙峋，甚至有的如同一条约三寸长的游龙，蜿蜒盘曲、栩栩如生。它们的共同点是表面光滑如镜，无一丝棱角——这是经过十万年灵气冲刷才形成的质感。

其色以翠绿为上品，碧绿为次之，青绿再次之，灰色为下品。最顶级的帝王绿龙脉石，通体翠绿通透，宛如一块上好的翡翠，但其内部蕴含的灵气量，远非翡翠可比。

以神识探入龙脉石中，可见其内部有无数细密的纹路，如同树木的年轮一般层层叠叠。每一层纹路代表了一万年的岁月沉淀。若是十层以上的龙脉石，便是十万年级别的至宝，价值连城。

龙脉石握于手中，温润如玉，却比玉石更加沉重，小小的一块便有百斤之重。这并非因为它的密度大，而是因为其内部压缩了极为庞大的灵气，这些灵气的质量远超一般物质。

最奇特的异象是，将龙脉石贴耳于上，可以听到地下深处传来的低沉轰鸣之声，仿佛有一条巨龙在岩石间穿行。这并非错觉——那是龙脉在地底流动的声音，龙脉石便像是一个留声筒，将地脉深处的声音忠实地传递出来。

## 功效

龙脉石被誉为"大地之心"，其功效与大地、龙脉、气运密切相关。

**修炼加速**：龙脉石中封存的是经过十万年以上压缩的龙脉灵气，浓度之高、品质之纯，远非普通灵石可比。修士以龙脉石辅助修炼，吸收的灵气不仅量多质纯，还蕴含一丝地脉法则，对修炼土属性功法的修士有极大的助益。传说持龙脉石修炼，速度是吸收普通灵石的十倍以上，且几乎没有任何副作用。

**气运加持**：龙脉石与一方天地的气运紧密相连。将龙脉石置于宗门之中，可镇压宗门气运，使宗门子弟修炼顺利、机缘不断。很多超级大宗都会花费巨大代价寻找龙脉石，放在宗门地脉的节点上，以巩固宗门的气运根基。

**镇压灵脉**：龙脉石可以稳定和强化地下的灵脉。若有一处灵脉即将枯竭，将龙脉石埋入灵脉的关键节点，可以使灵脉重新焕发生机，甚至变得更加强大。很多传承悠久的大宗，其山门之下的灵脉之所以能千年不衰，便是因为有龙脉石在维持。

## 获取方式

龙脉石藏于大地深处，获取方法不多，每一种都极为艰难。

**地脉勘探**：最直接的方法，就是在大地龙脉的关键节点处挖掘。但这需要有极为精湛的地脉勘探术，能够准确找到龙脉交汇的位置。而且挖掘深度通常在地底万丈之下，非大神通者不可为。

**龙脉变迁**：在发生大地震或地壳变动时，一些深埋地底的龙脉石可能会被翻到地表。这是获取龙脉石最省力的方法，但也是可遇不可求。历史上每次大的地壳变动后，都会有大量修真者涌入地变区域，希望能捡到一两块龙脉石。

**上古遗迹**：许多上古大能的洞府中，都会在修炼室中埋设龙脉石来聚集灵气。这些遗迹中的龙脉石虽然可能已经被用去了大半灵气，但仍然是难得的宝物。

**守护妖兽**：龙脉石周围必有强大的妖兽守护。因为这些石头散发的龙脉气息对一些妖兽有极大的吸引力——特别是龙裔妖兽，如蛟龙、地龙、龙蟒等。这些妖兽以龙脉之气为食，会盘踞在龙脉石周围，将其视为禁脔。击败一条守护蛟龙，往往就能在它的巢穴中发现龙脉石。

## 使用方法

**直接修炼**：将龙脉石握于手中或置于丹田，直接吸收其中蕴含的龙脉精气，是最直接的用法。但龙脉石中的灵气极为精纯厚重，吸收速度不宜过快，否则容易撑破经脉。化神期以下的修士每次修炼只能吸收一丝，需要数百年的时间才能耗尽一块龙脉石。

**布设聚灵阵**：龙脉石是聚灵阵的最佳阵眼材料。以龙脉石为阵眼布置的聚灵阵，效果是普通灵石阵法的十倍以上。普通的聚灵阵聚拢的是周围百里的灵气，而以龙脉石为阵眼的聚灵阵，则可以引动地脉之气，将大地的灵气也纳入阵中。

**炼制法宝**：龙脉石是炼制山门、洞府类法宝的核心材料。将龙脉石炼入一方印玺中，制成的"镇山印"可镇压一方山脉的气运。龙脉石也可炼入飞剑，使飞剑重量大增，威力更加刚猛。

**入药炼丹**：龙脉石粉末是炼制"地灵丹""厚土丹"等土属性丹药的主要辅料。地灵丹服用后可强化骨骼经脉，使肉身更加坚韧。

## 相关传说

**大禹铸鼎**：相传大禹平定洪水后，收集天下九州之金，铸成九鼎以镇压天下气运。而这九鼎的核心，便是九块从各州龙脉中取出的龙脉石。九鼎因此具备了镇压天下龙脉的无上威能，成为了华夏文明的象征。据说只要九鼎还在，天下便有定数，不会大乱。

**秦始皇寻龙脉**：秦始皇统一六国后，听信方士之言，认为秦朝的龙脉不够稳固，需要找到天下龙脉的源头，以龙脉石重新加固。他派遣徐福率领三千童男童女出海，名为寻仙药，实为寻龙脉。但徐福一去不返，秦始皇至死也未能得到他想要的龙脉石。

**和氏璧之秘**：历史上的和氏璧，表面看是一块美玉，但修真界深知其本质——那其实是一块顶级的帝王绿龙脉石，被雕琢成了玉璧的形状。赵惠文王当年得到和氏璧后，赵国的气运大盛，一度成为战国七雄中的强国。后秦灭赵，和氏璧落入秦始皇之手，被制成传国玉玺，以镇压大秦的气运。
