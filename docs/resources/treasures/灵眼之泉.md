# 灵眼之泉

> 品阶：天级四品 · 灵脉之眼

## 诞生条件

灵眼之泉诞生于灵脉与地表的交汇之处。

灵脉是大地灵气的通道，灵气在灵脉中流动。在某些地方，灵脉靠近地表，灵气会从地表的裂缝中喷涌而出，形成泉水——这便是灵眼之泉。

灵眼之泉与普通灵泉的区别在于：灵眼之泉直接连接灵脉，泉水中的灵气浓度是普通灵泉的百倍以上。

灵眼之泉的形成需要三个条件：其一，灵脉必须靠近地表；其二，地表必须有裂缝或通道，让灵气得以溢出；其三，必须有水源，让灵气与水融合。

灵眼之泉的形成没有固定的时间，可能数千年，也可能数万年。

灵眼之泉形成之时，地表会涌出清澈的泉水，泉水散发着浓郁的灵雾。

## 外观特征

灵眼之泉的泉水清澈见底，散发着浓郁的灵雾。泉眼周围的灵气浓度远超普通区域，是建立山门、开辟药园的理想之地。

灵眼之泉的泉水入口甘甜，如同琼浆玉液。一口灵眼之泉入腹，会感到一股温暖的气息在体内流转。

灵眼之泉有一个奇特的特性：它会自行调节温度。冬天温暖，夏天清凉，四季不变。

## 功效

**立宗建派**：灵眼之泉是建立山门的核心资源。在灵眼之泉旁建立宗门，可让宗门弟子修炼速度大幅提升。

**药园灌溉**：灵眼之泉可灌溉灵药，加速灵药的生长。以灵眼之泉浇灌的灵药，品质远超普通灵药。

**日常饮用**：灵眼之泉可日常饮用，补充灵气。长期饮用灵眼之泉，可改善体质，提升修炼资质。

**炼丹用水**：灵眼之泉是炼丹的最佳用水。以灵眼之泉炼丹，可让丹药的品质大幅提升。

## 获取方式

灵眼之泉是天然形成的灵脉节点，无法人为制造。

**地脉勘探**：通过地脉勘探术找到灵脉的位置，然后寻找灵眼之泉。

**风水望气**：风水师可通过观察山川地势来推测灵眼之泉的位置。

**机缘巧合**：有些灵眼之泉会因为地震或地壳变动而暴露在地表，被有缘人发现。

## 使用方法

**立宗建派**：在灵眼之泉旁建立山门，可让宗门弟子修炼速度大幅提升。

**药园灌溉**：以灵眼之泉灌溉灵药，可加速灵药的生长。

**日常饮用**：直接饮用灵眼之泉，可补充灵气。

**炼丹用水**：以灵眼之泉炼丹，可让丹药的品质大幅提升。

## 相关传说

**瑶池**：西王母的瑶池，据说便是一口巨大的灵眼之泉。瑶池中的灵泉蕴含仙气，饮用后可长生不老。

**灵眼之泉化形**：传说灵眼之泉积累到一定程度，会诞生灵智，化为"灵眼精灵"。灵眼精灵形如少女，通体透明，可操控水流。

**龙泉**：传说龙族在灵眼之泉中沐浴，可让龙鳞更加坚硬。因此，灵眼之泉又被称为"龙泉"。
