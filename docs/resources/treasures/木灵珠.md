# 木灵珠

> 品阶：天级四品 · 生命之珠

## 诞生条件

木灵珠的诞生，与上古万木之祖"大椿"有关。

大椿者，以八千岁为春、八千岁为秋的神木也。上古时期，大椿的一截枯枝从九天坠落，落入大地。这截枯枝虽已死去，却仍蕴含大椿遗留的一丝生机。

枯枝入土之后，并未腐烂，反而扎根大地，与周围的草木根系相连。它以自身残存的生机为引子，吸纳万木之精华，将方圆万里所有草木的生命力汇聚于一点。经过数万年的凝聚，枯枝化为一颗浑圆的木灵珠。

木灵珠的形成需要特殊的地理条件：必须是从未被开垦的原始森林深处，地脉生机旺盛，且周围需有至少万种以上的草木共生。唯有如此，木灵珠才能汲取足够的万木精华。

木灵珠成型之时，方圆万里的草木会在一瞬间同时开花结果，然后枯萎，将全部生命力注入珠中。

## 外观特征

木灵珠大如鸡蛋，通体翠绿欲滴，表面有天然的树纹，如同一截微缩的古木截面。珠体温润，触之如肤，散发着清新的草木香气。

将木灵珠置于暗处，可见珠内有无数细小的光点在流动，如同一片微缩的森林在珠中生长。春生夏长，秋收冬藏，珠内的景象随季节流转而变化。

木灵珠有一个奇特的特性：将它放在枯木旁，枯木会重新发芽；放在死水中，水中会生出苔藓。即便将它放在沙漠中，珠周围也会渐渐长出青草。

## 功效

**生机无尽**：木灵珠蕴含的生命力极为庞大，修士重伤垂危时，以木灵珠贴在伤口上，可让伤势以肉眼可见的速度愈合。即便是断肢，在木灵珠的滋养下也能重新生长出来。

**延年益寿**：长期佩戴木灵珠，可让肉身保持在巅峰状态，大幅延缓衰老。一枚木灵珠可使修士的寿元延长五百年，且不会有服用延寿丹药的抗药性问题。

**催生灵药**：将木灵珠埋入灵田，可让灵药的生长速度提升百倍。一株需要千年方可成熟的灵药，在木灵珠的催生下，十年便可收获。

**点化草木**：木灵珠可让草木诞生灵智。将木灵珠放在一棵古树旁百年，古树便可化妖，开启修行之路。

## 获取方式

木灵珠只存在于最古老的原始森林深处。已知的产出地有四处：一是建木遗迹周围的"万木之森"，由建木残根滋养；二是神农架最深处的"不死林"，据说神农氏曾在此种植仙草；三是东海蓬莱岛上的"长生林"，由蓬莱仙派守护；四是南荒的"万妖林"，妖族禁地。

木灵珠周围必有"树祖守护"——那是一棵吸收了木灵珠气息而诞生灵智的万年古树，实力堪比渡劫期修士。树祖与木灵珠共生共存，以木灵珠的生机延续生命，同时守护木灵珠不被外人夺走。

## 使用方法

**贴身佩戴**：将木灵珠以丝线穿系，贴身佩戴。木灵珠的生机会缓缓渗入体内，潜移默化地改善体质、延缓衰老。这是最温和的用法。

**炼化入体**：将木灵珠纳入丹田，以木属性功法炼化。炼化后，修士的恢复能力大幅提升，且可修炼木属性神通"万木回春"，一念之间让枯木逢春。

**炼丹入药**：木灵珠是炼制"长生丹"的主药。长生丹服下后可延寿千年，且无任何副作用。配方为：木灵珠粉末一钱，配以万年人参一株、九叶灵芝三片、九天息壤二两，以文火炼四十九日。

## 相关传说

**大椿遗珠**：庄子《逍遥游》有云："上古有大椿者，以八千岁为春，八千岁为秋。"传说大椿死后，其身躯化为万木，其精血化为九颗木灵珠散落人间。得到木灵珠的修士，可获得大椿的一部分寿元。

**神农种药**：神农氏尝百草时，曾以木灵珠点化万千草木，让它们诞生灵智，化为药灵。这些药灵后来成为了修真界最早的灵药来源。

**建木之心**：传说沟通天地的建木被砍伐后，其树心化为一颗木灵珠，被天帝收藏于天庭宝库。这颗木灵珠是唯一能沟通天地的钥匙，得之者可自由往返天人两界。
