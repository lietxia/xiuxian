# 业火红莲

> 品阶：神级七品 · 因果业火

## 诞生条件

业火红莲诞生于佛教圣地的九品莲台之中。

佛教修士修行积累功德，功德凝聚到一定程度，会在九品莲台中凝聚出一朵红莲。这朵红莲并非实体，而是功德的具象化形态。

当佛教修士坐化时，其一生的因果之力会转化为红莲业火，将红莲从虚转实，最终化为业火红莲。

业火红莲的形成需要三个条件：其一，必须有佛教修士坐化；其二，修士一生必须积累大量功德；其三，修士必须在九品莲台中坐化。

业火红莲每万年才能诞生一朵，因此极为珍贵。

业火红莲成型之时，天地间会响起梵音，天降花雨，地涌金莲。

## 外观特征

业火红莲呈莲花状，花瓣如火焰般跳动，呈深红色，散发炽热气息。每一朵红莲都蕴含完整的因果法则，是佛门至宝。

将业火红莲放在掌心，会感到一股温暖的气息从莲中透出。业火红莲的温度并不高，却能焚烧一切业障。

业火红莲有一个奇特的特性：它会根据持有者的业障多少而改变颜色。业障深重者，红莲颜色偏黑；业障轻微者，红莲颜色偏红；无业障者，红莲颜色偏金。

## 功效

**焚烧业障**：业火红莲蕴含因果法则，可焚烧修士身上的业障。业障是修士修行的障碍，焚烧业障后，修士的修行之路会更加顺畅。

**净化因果**：业火红莲可净化修士身上的因果。无论是善因还是恶因，业火红莲都可将其净化，让修士不受因果束缚。

**炼制法宝**：业火红莲是炼制佛门法宝的极品材料。以业火红莲为核心炼制的法宝，蕴含因果法则，可攻击敌人的因果。

**悟道辅助**：业火红莲蕴含因果法则，修士以神识探入其中，可感悟因果之道。

## 获取方式

业火红莲只存在于佛教圣地的九品莲台中。

**九品莲台**：佛教圣地的九品莲台中，偶尔能发现业火红莲。但九品莲台是佛教至宝，外人无法靠近。

**高僧坐化之地**：一些高僧坐化的洞府中，可能存有业火红莲。

**守护**：业火红莲周围必有佛门护法守护。最著名的当属八部天龙，实力堪比大罗金仙。

## 使用方法

**焚烧业障**：将业火红莲放在身前，以神识催动，可焚烧身上的业障。

**净化因果**：将业火红莲放在身前，以神识催动，可净化身上的因果。

**炼器**：以业火红莲为核心，辅以其他材料，可炼制佛门法宝。

**悟道**：以神识探入业火红莲中，可感悟因果之道。

## 相关传说

**佛祖拈花**：佛祖释迦牟尼拈花一笑，手中的花便是一朵业火红莲。迦叶尊者见之开悟，成为了禅宗初祖。

**红莲业火**：传说红莲业火是天地间最强大的火焰之一，可焚烧一切因果。佛祖以红莲业火洗涤一身因果，方才成就无上佛果。

**业火红莲化形**：传说业火红莲积累到一定程度，会诞生灵智，化为"业火精灵"。业火精灵形如火焰，通体深红，可操控因果。
