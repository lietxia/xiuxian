# 功德金光

> 品阶：天级三品 · 天道赐福之光

## 诞生条件

功德金光并非天地自然孕育之物，而是天道对善行的奖赏。

天道运转，赏善罚恶。当修士行善积德、济世度人时，天道会降下功德，汇聚于修士体内。功德积累到一定程度，便会化为金色的光芒——这便是功德金光。

功德金光的形成需要大量的善行。救一人可得一丝功德，济一城可得一缕功德，度一国可得一片功德。要将功德凝聚为可见的金光，至少需要救万人以上的大功德。

功德金光的形成没有固定的地点和时间，它只与修士的行为有关。只要善行足够，功德金光便会自然凝聚。

功德金光凝聚之时，修士脑后会浮现一轮金色光轮，如同佛陀的背光。光轮的亮度与功德的深厚程度成正比。

## 外观特征

功德金光呈金色光芒状，温暖祥和，不刺目却可照亮黑暗。它没有固定的形态，时而化为光轮悬浮于脑后，时而化为金光笼罩全身。

功德金光的气息极为独特——吸入一口，便觉心中充满慈悲与喜悦，一切负面情绪都会消散。在功德金光的照耀下，周围的生灵都会感到安宁与舒适。

功德金光有一个奇特的特性：它会排斥一切邪恶之物。在功德金光的照耀下，鬼修、邪修、魔物都会感到极度不适，实力骤降。

## 功效

**抵御心魔**：功德金光是一切心魔的克星。在闭关突破的关键时刻，功德金光可帮助修士抵御心魔入侵，保持心神清明。

**化解灾劫**：功德金光可化解天劫。在渡劫时，功德金光可削弱天雷的威力，让修士更容易渡过天劫。功德越深厚，天雷削弱的幅度越大。

**加持福报**：功德金光可提升修士的运势。持有功德金光的修士，机缘不断，逢凶化吉，事半功倍。

**超度亡魂**：功德金光可超度亡魂，让飘荡的魂魄得以安息。在战场上，功德金光可超度战死者的怨念，化解煞气。

## 获取方式

功德金光无法通过杀戮或掠夺获取，只能通过行善积德自然积累。

**济世度人**：最常见的获取方式是济世度人。救治病人、庇护百姓、平息战乱，皆可积累功德。

**传道授业**：传授功法、指点后辈，也可积累功德。功德的大小与受助者的成就相关。

**护生惜命**：保护生灵、珍惜万物，也可积累功德。放生、植树、保护环境，皆是功德。

**天降机缘**：在某些特殊情况下，天道会降下功德作为奖赏。如修补天地裂缝、镇压凶兽、守护一方平安等。

## 使用方法

**护体**：功德金光会自动护体，无需刻意催动。在遇到危险时，功德金光会自动爆发，抵御攻击。

**加持法宝**：将功德金光注入法宝中，可让法宝附带"破邪"之能，对邪修和魔物有极强的克制作用。

**超度亡魂**：将功德金光照射在亡魂上，可让亡魂得以安息，化解怨念。

**炼丹**：功德金光是炼制"功德丹"的主药。功德丹服下后，可让修士在短时间内获得大量功德，抵御心魔。

## 相关传说

**女娲补天**：女娲补天拯救了苍生，天道降下无量功德，化为金色光轮悬浮于女娲脑后。女娲凭借这份功德，最终证道成圣。

**后土化六道**：后土身化六道轮回，为亡魂开辟往生之路，天道降下无量功德。后土凭借这份功德，成为了与天道平齐的存在。

**如来成佛**：如来佛祖在菩提树下悟道时，脑后浮现一轮巨大的金色光轮。这轮光轮便是功德金光的极致体现，照耀三千世界。
