# 灵粉

> 品阶：地级三品 · 灵气之粉

## 诞生条件

灵粉诞生于灵气泉眼等灵气外溢之处。

灵气泉眼是灵脉灵气外溢至地表形成的出口，灵气从泉眼中喷涌而出。当灵气喷涌到空气中，会与空气中的微尘结合，经过漫长岁月的沉淀，形成微小的颗粒——灵尘。灵尘再经过数万年的进一步凝聚，形成更为细腻的灵粉。

灵粉的形成需要三个条件：其一，必须有灵气泉眼；其二，泉眼周围的灵气浓度必须足够高；其三，必须有足够的沉淀时间。

灵粉每万年才能沉积薄一层，因此极为珍贵。

灵粉沉积之时，泉眼周围会形成一层淡淡的灵雾，灵雾中的微尘便是灵粉。

## 外观特征

灵粉呈银白色粉末状，手感如丝绸般顺滑。高品质的灵粉在光线下会折射出微弱的七彩光芒。

将灵粉放在掌心，会感到一股清凉的气息从粉中透出。灵粉的细腻程度远超灵尘，可直接被身体吸收。

灵粉有一个奇特的特性：它会自行飘浮。灵粉不受重力影响，会一直悬浮在空气中，随风飘动。

## 功效

**炼丹辅料**：灵粉是炼丹的常用辅料。在炼丹时加入灵粉，可让丹药成形更加紧密。

**灵墨原料**：灵粉是调制灵墨的核心材料。以灵粉调制的灵墨，可绘制出蕴含灵气的符箓。

**炼丹炉铺设**：灵粉可铺设在炼丹炉底部，提升温度均匀度。

**灵植促进**：灵粉可撒在灵植根部，促进灵植生长。

## 获取方式

灵粉可由灵尘进一步提纯而来，也可从灵气泉眼、灵脉裂隙中直接收集。

**灵尘提纯**：以特殊手法将灵尘进一步提纯，可获得灵粉。

**灵气泉眼收集**：在灵气泉眼周围放置特制的收集器具，可收集飘浮的灵粉。

**灵植枯萎**：某些特殊的灵植枯萎后也会析出灵粉。

## 使用方法

**炼丹辅料**：在炼丹时加入灵粉，可让丹药成形更加紧密。

**灵墨原料**：以灵粉调制灵墨，可绘制出蕴含灵气的符箓。

**炼丹炉铺设**：将灵粉铺设在炼丹炉底部，可提升温度均匀度。

**灵植促进**：将灵粉撒在灵植根部，可促进灵植生长。

## 相关传说

**灵粉化蝶**：传说灵粉积累到一定程度，会化为一只灵蝶。灵蝶通体银白，翅膀如丝绸般顺滑，可操控灵气。

**撒粉成雪**：传说上古大能将灵粉撒向天空，灵粉化为漫天大雪，覆盖了整个大地。

**灵粉之路**：传说灵脉深处有一条由灵粉铺成的小路，沿着小路行走，可直达灵脉核心。
