# 凤凰胆

> 品阶：神级七品 · 涅槃至宝

## 诞生条件

凤凰胆的诞生，与凤凰一族最神秘的天赋神通——涅槃——息息相关。

凤凰乃百鸟之王，天生掌握火之法则与重生法则。每一只凤凰在寿命将尽或遭受致命重创时，会自行激发体内的涅槃之力，化作熊熊烈火，将自身焚为灰烬。在火焰中，凤凰的魂魄会凝聚不散，以毕生修为为燃料，在灰烬中重新孕育出新的生命。

然而并非每一次涅槃都能成功。若凤凰在涅槃时心有挂碍、修为不足，又或者是受到了不可逆转的本源创伤，那么涅槃便会失败。失败的涅槃不会产生新的凤凰，却会在凤凰燃烧后的灰烬中留下一样东西——便是凤凰胆。

更准确地说，凤凰胆是凤凰涅槃失败时，其毕生血脉精华与未散尽的涅槃之力在绝境中凝固而成的结晶。它是一只凤凰生命与修为的最终凝结，是死亡与重生在极限对抗中产生的奇异物质。

因此，每一颗凤凰胆都是一只凤凰的墓志铭。它的数量绝不会很多——凤凰一族本就数量稀少，能够成功涅槃的百不存一，而涅槃失败的更是少之又少。

## 外观特征

凤凰胆呈卵圆形，大如鹅卵，通体赤红如玛瑙。它的红色并非寻常之红，而是一种流动的、仿佛有生命的红——如同被封印的火焰在薄薄的玉壳下不断翻滚燃烧。

仔细看去，凤凰胆内部仿佛有一团永不熄灭的火焰在跳动。火焰的中心，隐约可见一只微缩的凤凰虚影，优雅地展开双翅，昂首向天。那凤凰的姿态栩栩如生，双眸闪烁着金色的光芒，仿佛随时要破壳而出，翱翔九天。

凤凰胆握在手中，会感到一阵温暖却不灼手的温度，如同握着一颗跳动的心脏。每隔一段时间，凤凰胆会发出微弱的光晕，以某种奇异的频率闪烁，宛如活物的呼吸。有修为高深的修士曾言，将神识探入凤凰胆中，能够感受到一股强烈的生命意志——那是一只凤凰对重生的执念，即便化为结晶，依然不灭。

当凤凰胆置于黑暗之中时，它会散发出柔和的火光，将周围照亮。若遇水则水为之沸，遇木则木为之燃，遇金则金为之熔。唯有以千年寒玉制成的盒子，才能妥善存放此物。

## 功效

凤凰胆最核心的功效，便是它蕴含的重生之力。

**浴火重生**：持有凤凰胆的修士，在遭受致命伤害时，可主动激发凤凰胆中的重生之力。其效果与凤凰涅槃类似——身体会化作一团火焰，在火焰中重塑肉身，重新归来。虽然过程极为痛苦，但确确实实是一条命。一枚凤凰胆可供一次"伪涅槃"重生，虽不如真凤凰涅槃后那般实力大增，但保住一条命却是绰绰有余。

有传说一位化神巅峰的修士，在渡劫时被天劫劈得肉身崩毁，元神即将消散。他在最后一刻捏碎了随身携带的凤凰胆，火焰将他包裹，三日后他从灰烬中走出，不仅伤势痊愈，还借助这次"涅槃"成功突破到了炼虚期。

**火属性增益**：凤凰胆中蕴含的南明离火精华，对修炼火属性功法的修士有极大的助益。持之修炼，可让火灵根的纯度不断提升，对火之法则的领悟也更加容易。将凤凰胆置于丹田处炼化，可让修士的真火渐渐转化为南明离火，威力提升数倍。

**疗伤圣品**：凤凰胆散发的阳气对疗伤有奇效。即使是重伤濒危之人，将凤凰胆放在胸口，以阳气滋养心脉，也能稳住伤势、延长生机。凤凰胆还能克制一切阴寒毒物——被冰蚕寒毒所伤的修士，以凤凰胆的热力驱毒，立竿见影。

## 获取方式

凤凰胆极难获取，因为它的出处只有凤凰栖息之地。

**凤凰巢穴**：凤凰多筑巢于极阳之地，如火山口、地心熔岩之湖，或传说中的"梧桐神木"之上。已知的凤凰巢穴有南明火山深处的凤凰谷、昆仑山脉中的朱焰崖，以及东海扶桑岛上的梧桐神木。但这些地方都有凤凰或其血脉后裔守护，擅入者死。

**涅槃之地**：凤凰在涅槃失败后，其遗骸所在之地会留下凤凰胆。但凤凰涅槃时会引燃周围的一切，因此很难准确找到涅槃之地。而且涅槃之地往往被强大的火焰禁制包围，以凤凰的本命真火构成屏障，修为不足者根本无法靠近。

**守护妖兽**：凤凰胆周围必有凤凰一族的守护者。最直接的可能是一只活着的凤凰——若被发现偷取死去同族的遗物，凤凰的怒火可不是一般人能承受的。另一种可能是由凤凰的近亲——青鸾或火凤——守护。这些神鸟虽然不是纯血凤凰，却也具备凤凰血脉，修为极高。

传说中有一只活了十万年的九彩孔雀，受凤凰族的嘱托守护着历代凤凰涅槃失败的遗物。它藏身于南明火山的深处，常年沉睡，但一旦有人靠近凤凰胆的存放之处，便会立即苏醒。

## 使用方法

**炼化融合**：将凤凰胆以真火熔炼，与自身血脉融合，是最彻底的利用方式。融合成功后，修士将获得凤凰的一部分特性——肉身恢复能力大幅提升，对火属性攻击的耐性极强，甚至可以在火中自由穿行。最顶尖的是，修士将获得一次"伪涅槃"的能力，相当于多了一条命。但融合时需承受凤凰真火灼烧之痛，非意志坚定者不可为。

**炼丹入药**：凤凰胆是炼制"涅槃丹"与"火神丹"的核心材料。涅槃丹服用后可让修士获得一次浴火重生的机会，与炼化凤凰胆的效果类似，但温和得多。火神丹则能大幅提升火属性修为，让修士的火焰蜕变为南明离火，威力大增。

**炼器**：以凤凰胆为主材炼制的法宝，蕴含南明离火之力。可炼成"凤凰火羽扇"，扇动一次便有无边火海降世；也可炼成"赤凤剑"，剑出如凤凰展翅，焚尽万物。传说上古时期的南明离火剑，便是以一颗凤凰胆为主体炼制而成。

**布阵**：凤凰胆可作为阳属性大阵的阵眼。以凤凰胆为核心布置的"大日焚天阵"，可将方圆千里化为火海，威力无穷。若是布置较小的"浴火重生阵"，则可让阵中受伤的人快速恢复。

## 相关传说

**凤凰泣血**：传说上古时期有一只七彩凤凰，为救心爱之人，强行逆转了涅槃的法则，在还未该涅槃时自焚肉身，留下了一颗凤凰胆。她的爱人以这颗凤凰胆保住了性命，而那只凤凰却再也无法重生。后来，这颗凤凰胆被制成了一条项链，流传于世，被称为"凤凰泣血"。据说佩戴这条项链的人，会梦见一只七彩凤凰在对他低语，讲述一个关于爱与牺牲的故事。

**九天玄女**：传说九天玄女在与妖魔大战时身负重伤，形神即将崩解。凤凰族感念玄女的恩德，赠予她一颗凤凰胆。玄女以凤凰胆重塑肉身，不仅完全恢复，还突破到了更高的境界。此后玄女与凤凰族结下不解之缘，她的道号"九天玄女"中的"玄"字，便取自凤凰的玄火之色。

**百鸟朝凤**：上古时期有一颗凤凰胆被供奉在百鸟谷中，周围百里内的鸟类都会被它所吸引，日夜围着那颗凤凰胆啼鸣。这便是"百鸟朝凤"典故的由来。后来这颗凤凰胆被一个路过的散修盗走，百鸟谷日渐凋零，百鸟朝凤的奇景不再重现。
