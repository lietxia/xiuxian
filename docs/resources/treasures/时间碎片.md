# 时间碎片

> 品阶：神级七品 · 时间之屑

## 诞生条件

时间碎片诞生于时间长河。

天地间有一条无形的河流，名为"时间长河"。时间长河中流淌的不是水，而是过去、现在、未来的一切事件。每一个生灵的生死、每一个世界的兴衰，都在时间长河中留下痕迹。

时间长河的河床上，偶尔会有一些碎片脱落。这些碎片是时间长河在冲刷过程中自然剥落的，它们蕴含着时间法则的力量——这便是时间碎片。

时间碎片的形成需要特殊的机缘：只有当时间长河发生"漩涡"时，才会有碎片脱落。时间漩涡的形成与天地大劫相关，每一次量劫都会引发时间漩涡。

时间碎片脱落之时，周围的时间会发生紊乱——有的地方时间加速，有的地方时间减速，有的地方时间静止。

## 外观特征

时间碎片呈不规则形状，大小不一，小如指甲盖，大如拳头。碎片表面有流动的时间纹路，纹路的流动方向代表时间的方向——向前流动代表未来，向后流动代表过去。

将时间碎片放在掌心，会感到一阵奇异的感觉——有时觉得时间过得飞快，有时觉得时间慢如蜗牛。这是时间碎片在影响周围的时间流速。

以神识探入碎片中，可看到时间长河的景象——过去的事件如倒影般闪过，未来的事件如幻影般浮现。

## 功效

**加速时间**：时间碎片可加速局部时间流逝。在加速的区域内，修士的修炼速度大幅提升，但寿元消耗也会加速。

**减速时间**：时间碎片可减速局部时间流逝。在减速的区域内，敌人的动作会变得迟缓，如同慢动作。

**时间静止**：时间碎片可让局部时间静止。在静止的区域内，一切物体都会停止运动，只有持有者可以自由活动。

**时间倒流**：时间碎片最为逆天的功效，是它可以让局部时间倒流。将时间倒流作用于伤口，可让伤口恢复到受伤前的状态。但时间倒流的消耗极大，且只能倒流极短的时间。

## 获取方式

时间碎片只存在于时间长河的河畔或时间漩涡之中。

**时间长河河畔**：最直接的方式是找到时间长河的入口，在河畔寻找脱落的时间碎片。时间长河的入口位于"时间神殿"的禁地，由时间守护者世代守护。

**时间漩涡**：量劫爆发时，会产生时间漩涡。时间漩涡中会脱落大量时间碎片。但时间漩涡极为危险，稍有不慎便会被卷入时间长河，永远迷失。

**大能遗物**：一些修炼时间大道的上古大能，其遗物中可能藏有时间碎片。如烛龙的"时间之眼"、羲和的"日晷"等。

## 使用方法

**加速时间**：将时间碎片握于手中，以神识催动，可加速局部时间流逝。加速的幅度与碎片的品质成正比。

**减速时间**：将时间碎片对准目标，以神识催动，可减速目标周围的时间流速。

**时间静止**：将时间碎片激发到极限，可让局部时间静止。静止的时间越长，消耗越大。

**时间倒流**：将时间碎片贴在伤口上，以神识催动，可让时间倒流，恢复伤势。此法消耗极大，非关键时刻不可使用。

## 相关传说

**烛龙睁眼**：上古神兽烛龙，睁眼为白昼，闭眼为黑夜。传说烛龙的眼睛便是一颗巨大的时间碎片，可操控昼夜交替。

**羲和浴日**：羲和是太阳之母，她每天驾车载着太阳从东飞到西。她车上的日晷便是一件时间碎片法宝，可操控太阳的运行速度。

**时间神殿**：传说天地间有一座时间神殿，神殿中供奉着时间长河的源头。时间神殿的守护者是一位活了无数纪元的古老存在，他守护着时间长河的秘密。
