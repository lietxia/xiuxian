# 空间石

> 品阶：天级五品 · 空间之晶

## 诞生条件

空间石诞生于空间裂缝之中。

天地间的空间并非绝对稳定。在某些特殊条件下，空间会产生裂缝，连接着不同的世界或维度。空间裂缝中充斥着狂暴的空间之力，这些空间之力在裂缝中不断碰撞、挤压，经过数万年的凝聚，最终化为结晶——这便是空间石。

空间石的形成需要三个条件：其一，必须有稳定的空间裂缝；其二，裂缝中的空间之力必须足够浓郁；其三，裂缝必须存在足够长的时间（至少数万年）。

空间石成型之时，空间裂缝会短暂扩大，释放出大量的空间之力。这股空间之力会扭曲周围的空间，产生"空间折叠"的奇观。

## 外观特征

空间石呈不规则多面体形状，通体呈银白色，表面有流动的空间纹路。珠体半透明，内部似乎有另一个空间在流转。

将空间石放在掌心，会感到一阵微微的失重感，如同站在悬崖边缘。珠体周围的空间会微微扭曲，光线在穿过空间石时会发生折射，产生彩虹般的光晕。

以神识探入空间石中，可看到一片空旷的虚无——那是空间石内部的"亚空间"。亚空间的大小与空间石的品质成正比。

## 功效

**开辟储物空间**：空间石是开辟储物空间的核心材料。以空间石为主材炼制的储物法宝，内部空间极为稳定，不会崩塌。

**空间传送**：空间石可用于制作传送阵。以空间石为阵眼的传送阵，传送距离远超普通传送阵。

**空间切割**：空间石可释放空间之力，形成"空间刃"。空间刃锋利无比，可切割一切物质，无视物理防御。

**空间感知**：空间石可让持有者感知周围空间的波动，发现隐藏的空间裂缝或空间法宝。

## 获取方式

空间石只存在于空间裂缝附近。

**空间裂缝**：最直接的方式是进入空间裂缝，寻找凝聚的空间石。但空间裂缝极为危险，空间之力可撕裂一切。

**虚空遗迹**：一些上古大能撕裂空间后留下的遗迹中，偶尔能发现空间石。

**空间兽体内**：一些以空间之力为食的空间兽，其体内会凝聚空间石。击杀空间兽后，可从其体内获取。

## 使用方法

**开辟储物空间**：以空间石为主材，辅以其他材料，可炼制储物法宝。空间石的品质越高，储物空间越大越稳定。

**制作传送阵**：以空间石为阵眼，可制作传送阵。传送阵的传送距离与空间石的品质成正比。

**空间切割**：以空间石释放空间之力，可形成空间刃。空间刃可用于攻击或切割物品。

**炼丹**：空间石是炼制"空间丹"的主药。空间丹服下后，修士可在短时间内获得空间穿梭的能力。

## 相关传说

**袖里乾坤**：地仙之祖镇元子的"袖里乾坤"之术，便是以一块巨大的空间石为核心施展的。镇元子将空间石炼入袖中，袖子内藏一方小世界，可装天地。

**乾坤袋**：太上老君的乾坤袋，便是以空间石为主材炼制而成。乾坤袋内藏乾坤，可装万物。

**空间隧道**：传说天地间有一条连接各个世界的"空间隧道"，隧道的墙壁上镶嵌着无数空间石。找到空间隧道，便可自由往返各个世界。
