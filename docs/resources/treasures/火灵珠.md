# 火灵珠

> 品阶：天级四品 · 火之精核

## 诞生条件

火灵珠的诞生，与上古"十日并出"的浩劫有关。

上古时期，天帝帝俊的十个儿子——十只三足金乌，同时飞上天空，十日并出，焦禾稼，杀草木，民无所食。大地被烤得干裂，河水蒸发，山石融化。

后羿奉帝俊之命，射落九只金乌。被射落的金乌坠地之时，体内的太阳真火与地心烈焰相遇，两种至阳之火相互融合，产生了不可思议的变化。太阳真火至刚，地心烈焰至烈，二者交融后，经过数万年的凝聚，最终化为火灵珠。

火灵珠的形成需要"太阳真火"与"地心烈焰"同时存在，因此只诞生于金乌坠落之地。后羿射落九只金乌，分散于九处，因此天地间最多只形成了九颗火灵珠。

火灵珠成型之时，坠落之地会化为一片永不熄灭的火焰山，方圆千里寸草不生，地表化为熔岩。

## 外观特征

火灵珠大如鸡卵，通体呈金红色，表面有火焰纹路在不断流转，如同一颗微缩的太阳。珠体温度极高，寻常修士根本无法徒手触碰，需以寒玉或玄冰包裹方能拿取。

将火灵珠置于暗处，它会散发出耀眼的光芒，将周围照得如同白昼。珠内隐约可见一只微缩的三足金乌在振翅飞翔，口中喷出炽烈的火焰。

火灵珠有一个奇特的特性：它会自行吸收周围的热量。在火灵珠附近，温度会急剧下降，因为热量都被它吸收了。但若将火灵珠投入水中，它释放的热量可让整条河流沸腾蒸发。

## 功效

**太阳真火**：火灵珠蕴含太阳真火之力，修炼火属性功法的修士持之修炼，可将自身真火提升为太阳真火，威力提升十倍以上。太阳真火可焚烧万物，连仙人之体都可灼伤。

**火遁之术**：持有火灵珠的修士，可修炼"火遁之术"——化身火焰，瞬息千里。火遁之术的速度在所有遁术中排名第一。

**熔炼万物**：火灵珠释放的火焰可熔炼天下一切物质，是炼器师梦寐以求的至宝。以火灵珠为主火炼制的法宝，品质远超普通真火所炼者。

**驱散阴邪**：火灵珠的太阳真火是一切阴邪之物的克星。鬼修、邪修、魔物在火灵珠的光芒下都会受到极大压制，实力骤降。

## 获取方式

火灵珠只存在于上古金乌坠落之地。已知的产出地有九处，对应后羿射落的九只金乌：

一是"火焰山"，位于西牛贺洲，是规模最大的金乌坠落之地，火焰燃烧万年不灭。二是"炎帝谷"，位于南瞻部洲，传说神农氏曾在此采集火灵珠炼丹。三是"九阳潭"，位于东胜神洲，潭水被火灵珠煮沸，常年蒸汽缭绕。

其余六处坠落之地大多已被上古大能占据或封印。

火灵珠周围必有"金乌残魂"守护。金乌虽死，残魂不散，化为火焰精灵，实力堪比大乘期修士。金乌残魂性情暴烈，会主动攻击一切靠近火灵珠的活物。

## 使用方法

**炼化入体**：以火属性功法将火灵珠纳入丹田，慢慢炼化。炼化后，修士的火焰可提升为太阳真火，且可在体内形成一颗"真火种子"，源源不断地产生火焰。但火灵珠的火力极为霸道，炼化过程如同置身熔炉，非肉身强横者不可为。

**镶嵌法宝**：将火灵珠镶嵌在火属性法宝上，可让法宝品质提升一个品阶，且附带"太阳真火"之能，攻击时可释放金乌火焰。

**炼丹**：火灵珠是炼制"九阳丹"的主药。九阳丹服下后，修士可在短时间内获得太阳真火之力，实力暴增。但药效过后会陷入虚弱期。

## 相关传说

**后羿射日**：后羿射落九只金乌后，曾收集金乌坠落之地的火灵珠。他将八颗火灵珠封印于八方，一颗留作己用。后羿凭借这颗火灵珠的太阳真火之力，成为了上古第一神射手。

**十日焚天**：传说若将九颗火灵珠聚在一起，可重现"十日并出"的浩劫。上古时期，曾有一位邪修集齐了九颗火灵珠，试图以此焚毁天地。最终是女娲娘娘出手，以九天息壤扑灭了大火，重新封印了火灵珠。

**夸父逐日**：夸父追赶太阳时，曾路过一处金乌坠落之地，被火灵珠的火焰灼伤。夸父虽然力大无穷，却无法承受太阳真火的力量，最终渴死于追逐太阳的路上。
