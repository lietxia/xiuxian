# 灵珠

> 品阶：地级三品 · 灵气之珠

## 诞生条件

灵珠诞生于灵脉深处的特殊环境。

灵脉深处的灵气浓度极高，在某些特殊的地质构造中，灵气会围绕一个核心点不断旋转，形成一个"灵气漩涡"。灵气漩涡经过数万年的旋转，逐渐凝聚成一颗浑圆的珠子——这便是灵珠。

灵珠的形成需要三个条件：其一，必须有稳定的灵气漩涡；其二，漩涡的核心必须有一个"凝结核"（如一块小石子或一滴灵液）；其三，必须经过数万年的旋转凝聚。

灵珠每万年才能形成一颗，因此极为珍贵。

灵珠成型之时，灵气漩涡会突然停止旋转，所有的灵气在瞬间凝聚成珠。

## 外观特征

灵珠呈圆珠状，直径约一寸，通体半透明，内含流动的光晕。高品质的灵珠内部可见清晰的灵气漩涡。

将灵珠放在掌心，会感到一股清凉的气息从珠中透出。灵珠无需炼化，可直接吸收其中的灵气。

灵珠有一个奇特的特性：它会自行吸收周围的灵气。将灵珠放在灵气充沛的地方，它的体积会缓慢增长。

## 功效

**直接吸收**：灵珠可直接吸收，补充灵气。一颗灵珠蕴含的灵气，可供筑基期修士修炼百日。

**炼丹核心**：灵珠是炼制丹药的灵气核心。以灵珠为核心炼制的丹药，灵气充沛，品质极高。

**镶嵌法宝**：灵珠可镶嵌在法宝上，提升法宝的灵性。

**阵法阵眼**：灵珠可作为阵法的阵眼，提供能量。

## 获取方式

灵珠多产于灵脉核心地带，需深入地下开采。

**灵脉开采**：通过地脉勘探术找到灵脉核心，然后挖掘进入。

**灵兽体内**：某些特殊的灵兽体内也会孕育灵珠，击杀后可获取。

**上古遗迹**：一些上古遗迹的灵脉中可能存有灵珠。

## 使用方法

**直接吸收**：将灵珠握于手中，可直接吸收其中的灵气。

**炼丹核心**：以灵珠为核心，辅以其他材料，可炼制丹药。

**镶嵌法宝**：将灵珠镶嵌在法宝上，可提升法宝的灵性。

**阵法阵眼**：以灵珠为阵眼，可布置阵法。

## 相关传说

**灵珠化形**：传说灵珠积累到一定程度，会诞生灵智，化为"灵珠精灵"。灵珠精灵形如婴儿，通体透明，可操控灵气。

**龙珠**：传说龙族体内的内丹便是一种特殊的灵珠。龙族以内丹储存灵气，内丹的品质与龙的修为成正比。

**灵珠献瑞**：传说灵珠现世之时，会引发天地异象——天降祥瑞，地涌灵泉，万物复苏。
