# 灵眼之树

> 品阶：天级四品 · 聚灵宝树

## 诞生条件

灵眼之树诞生于灵眼之泉旁。

灵眼之泉是灵脉灵气外溢至地表形成的泉眼，泉水蕴含浓郁灵气。在灵眼之泉旁，偶尔会生长出一种特殊的灵木——灵眼之树。

灵眼之树的种子极为特殊，它不是从其他树木传承而来，而是由灵眼之泉的泉水孕育而成。当灵眼之泉的泉水喷涌到空气中，水汽凝结成一颗晶莹的种子，落入土壤中，便会生根发芽，长成灵眼之树。

灵眼之树的形成需要三个条件：其一，必须有灵眼之泉；其二，泉水必须喷涌到空气中凝结成种子；其三，种子必须落入肥沃的土壤中。

灵眼之树每万年才能诞生一棵，因此极为珍贵。

灵眼之树成型之时，灵眼之泉会喷涌出大量的泉水，泉水在空中凝结成一颗晶莹的种子，落入土壤中。

## 外观特征

灵眼之树树干粗壮，枝叶常青，能自动汇聚周围的灵气。树叶呈翠绿色，在光线下闪烁微光，果实为红色小珠，蕴含浓郁灵气。

灵眼之树的高度与树龄成正比。百年的灵眼之树高丈许，千年的高数丈，万年的高达数十丈。

灵眼之树有一个奇特的特性：它会自行汇聚周围的灵气。在灵眼之树周围，灵气浓度是普通地方的十倍以上。

## 功效

**树叶炼丹**：灵眼之树的树叶是炼制聚气丹、回灵丹的珍贵材料。

**果实炼丹**：灵眼之树的果实是炼制筑基丹、结丹辅助的珍贵材料。

**树干炼器**：灵眼之树的树干是制作法器手柄的上佳材料。

**树下修炼**：在灵眼之树下修炼，吸收的灵气量是普通地方的十倍以上。

## 获取方式

灵眼之树只在灵眼之泉旁自然生长，无法移植。

**寻找灵眼之泉**：通过地脉勘探术找到灵眼之泉，然后观察周围是否有灵眼之树生长。

**上古遗迹**：一些上古遗迹中可能存有灵眼之树。

**守护妖兽**：灵眼之树周围必有妖兽守护。最常见的是"灵眼蟒"，此蟒以灵眼之树的果实为食，修为可达元婴期。

## 使用方法

**采摘树叶**：采摘灵眼之树的树叶，可炼制聚气丹、回灵丹。

**采摘果实**：采摘灵眼之树的果实，可炼制筑基丹、结丹辅助。

**砍伐树干**：砍伐灵眼之树的树干，可制作法器手柄。

**树下修炼**：在灵眼之树下修炼，可大幅提升修炼速度。

## 相关传说

**灵眼之树化形**：传说灵眼之树积累到一定程度，会诞生灵智，化为"灵眼精灵"。灵眼精灵形如少女，通体翠绿，可操控树木。

**建木**：传说沟通天地的建木，便是一棵巨大的灵眼之树。建木的根系扎入九幽，枝叶覆盖九天，是天地间最大的灵木。

**灵眼之树的眼泪**：传说灵眼之树在悲伤时会流出树脂，树脂化为灵珀，封存了灵眼之树的悲伤。
