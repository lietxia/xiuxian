# 九天玄铁

> 品阶：神级六品 · 九天坠落之铁

## 诞生条件

九天玄铁诞生于九天之上。

九重天之上，有一片名为"九天虚空"的区域。九天虚空中充斥着狂暴的九天罡风和虚空乱流，普通物质根本无法存在。

然而，在九天虚空的某些特殊区域，九天罡风会携带大量的金属微粒，这些微粒在虚空中不断碰撞、融合，经过数十万年的凝聚，最终化为一块块玄铁——这便是九天玄铁。

九天玄铁的形成需要三个条件：其一，必须有九天罡风携带金属微粒；其二，必须在九天虚空中凝聚数十万年；其三，必须恰好坠入凡间，不被九天罡风摧毁。

九天玄铁每数十万年才能形成一块，因此极为珍贵。

九天玄铁坠落之时，会引发一场流星雨，天空中出现一道耀眼的光芒。

## 外观特征

九天玄铁呈深黑色，表面有流动的九天纹，散发着神秘的气息。每一块九天玄铁都蕴含浓郁的九天灵气。

将九天玄铁放在掌心，会感到一股冰冷的气息从铁中透出。九天玄铁的密度极高，一块拳头大小的九天玄铁重达万斤。

九天玄铁有一个奇特的特性：它会自行吸收周围的灵气。将九天玄铁放在灵气充沛的地方，它的品质会缓慢提升。

## 功效

**炼器材料**：九天玄铁是炼制顶级法宝的珍稀材料。以九天玄铁为核心炼制的法宝，蕴含九天灵气，威力远超普通法宝。

**药引**：极少数顶级丹药需要九天玄铁作为药引，以激发药性。

**布阵**：九天玄铁是布置顶级阵法的阵眼材料。以九天玄铁为阵眼的阵法，威力远超普通阵法。

**镇派之宝**：九天玄铁可作为镇派之宝，镇压宗门气运。

## 获取方式

九天玄铁只产于九天之上，需流星坠落时方可获取。

**流星坠落**：最常见的方式是在流星雨后，到流星坠落的区域寻找。但流星雨后能找到的九天玄铁数量极少，一次大型流星雨能收获的也不过数块。

**上古遗迹**：一些上古遗迹中可能存有九天玄铁。

**守护妖兽**：九天玄铁周围必有强大的妖兽守护。最常见的是"玄铁蟒"，此蟒以九天玄铁为食，修为可达化神期。

## 使用方法

**炼器材料**：以九天玄铁为核心，辅以其他材料，可炼制顶级法宝。

**药引**：在炼丹时加入九天玄铁粉末，可激发药性。

**布阵**：以九天玄铁为阵眼，可布置顶级阵法。

**镇派之宝**：将九天玄铁供奉于宗门的核心，可镇压宗门气运。

## 相关传说

**女娲炼石**：女娲补天时，曾以九天玄铁为材料，炼制成五色石。五色石蕴含九天灵气，可修补苍天。

**轩辕剑**：黄帝的轩辕剑，据说便是以九天玄铁为主材炼制而成。轩辕剑蕴含九天灵气，可斩妖除魔。

**九天玄女**：传说九天玄女曾将一块九天玄铁赠予黄帝，帮助他击败了蚩尤。这块九天玄铁后来成为了黄帝的镇国之宝。
