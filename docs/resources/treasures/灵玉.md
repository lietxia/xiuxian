# 灵玉

> 品阶：地级五品 · 灵气蕴玉

## 诞生条件

灵玉诞生于灵脉附近的玉矿中。

天然玉石在地底形成后，若恰好位于灵脉附近，会被灵脉散发的灵气长期浸润。经过数万年的浸润，灵气逐渐渗入玉石内部，将普通的玉石转化为灵玉。

灵玉的形成需要三个条件：其一，必须有高品质的天然玉石；其二，玉石必须位于灵脉附近；其三，必须经过数万年的灵气浸润。

灵玉的形成没有固定的时间，取决于灵气的浓度和浸润的时间。

灵玉成型之时，玉石会发出微弱的光芒，如同一颗星星在地下闪烁。

## 外观特征

灵玉质地细腻温润，表面有淡淡的光晕流转。高品质的灵玉通体通透，内部可见云雾状的灵气流转。

将灵玉握于手中，会感到一股温润的气息从玉中透出。灵玉的温度恒定，冬暖夏凉。

灵玉有一个奇特的特性：它会自行吸收周围的灵气。将灵玉放在灵气充沛的地方，它的品质会缓慢提升。

## 功效

**制作玉简**：灵玉是制作玉简的最佳材料。以灵玉制作的玉简，可储存大量的信息，且万年不损。

**制作玉符**：灵玉是制作玉符的上佳材料。以灵玉制作的玉符，威力远超普通符箓。

**炼制防御法宝**：灵玉是炼制防御法宝的绝佳材料。以灵玉炼制的防御法宝，坚不可摧。

**身份象征**：灵玉是修士身份的象征。高品质的灵玉饰品，只有高阶修士才能拥有。

## 获取方式

灵玉多产于灵脉附近的玉矿中。

**玉矿开采**：通过勘探找到灵脉附近的玉矿，然后开采。但玉矿通常位于地底深处，开采难度极大。

**上古遗迹**：一些上古遗迹中可能存有高品质的灵玉。

**河床捡拾**：一些灵玉会从玉矿中被水流冲刷到河床上，被有缘人捡拾。

## 使用方法

**制作玉简**：以灵玉制作玉简，可储存功法、信息。

**制作玉符**：以灵玉制作玉符，可释放强大的法术。

**炼制防御法宝**：以灵玉炼制防御法宝，坚不可摧。

**随身佩戴**：将灵玉贴身佩戴，可缓慢吸收其中的灵气，改善体质。

## 相关传说

**和氏璧**：历史上的和氏璧，据说便是一块顶级的灵玉。和氏璧的价值连城，不仅因为它的美丽，更因为它蕴含的灵气。

**玉皇大帝**：传说玉皇大帝的玉玺，便是以一块巨大的灵玉雕刻而成。玉玺蕴含天道之力，可号令三界。

**灵玉化形**：传说灵玉积累到一定程度，会诞生灵智，化为"灵玉精灵"。灵玉精灵形如美玉，温润可爱，可操控玉石。
