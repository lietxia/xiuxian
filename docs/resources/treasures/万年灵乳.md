# 万年灵乳

> 品阶：天级五品 · 万年凝聚之宝

## 诞生条件

万年灵乳是灵乳历经万年进一步浓缩而成的至宝。

灵脉核心处，灵乳缓慢凝结。普通的灵乳经过万年的进一步浓缩，灵气浓度提升百倍，最终化为万年灵乳。

万年灵乳的形成需要三个条件：其一，灵脉必须足够古老（至少百万年）；其二，灵脉核心必须处于完全密封的状态；其三，必须经过万年的缓慢浓缩。

万年灵乳每万年才能凝结一滴，因此极为珍贵。一条百万年的灵脉，核心处也不过积攒了百余滴万年灵乳。

万年灵乳凝结之时，灵脉会发出低沉的嗡鸣之声，如同一颗心脏在跳动。灵脉周围的灵气浓度会短暂提升数倍。

## 外观特征

万年灵乳呈银白色，质地如珍珠般圆润，在光照下散发柔和的银光。一滴万年灵乳蕴含的灵气堪比数万块灵石。

万年灵乳入口有浓郁的甘甜，如同琼浆玉液。一滴万年灵乳入腹，会感到一股温暖的气息在体内流转，滋养着四肢百骸。

万年灵乳有一个奇特的特性：它会自行发出柔和的光芒。在黑暗中，万年灵乳如同一颗微缩的月亮，将周围照亮。

## 功效

**起死回生**：万年灵乳有起死回生之效。无论伤势多严重，只要还有一口气在，服用一滴万年灵乳便可保住性命。

**逆天改命**：万年灵乳可逆天改命，重塑修士的根基。无论修士的根基有多差，只要服用足够的万年灵乳，便可将根基重塑为完美状态。

**突破辅助**：万年灵乳是突破的绝佳辅助材料。在突破时服用一滴万年灵乳，可大幅提升突破的成功率。

**延寿续命**：万年灵乳可延长寿元。服用一滴万年灵乳，可延长寿元数百载。

## 获取方式

万年灵乳只产于最古老的灵脉核心，需深入地下万丈方可寻得。

**灵脉勘探**：通过地脉勘探术找到灵脉的核心位置，然后挖掘进入。但灵脉核心的温度和压力极高，非元婴期修士无法承受。

**上古遗迹**：一些上古遗迹的灵泉中可能存有万年灵乳。

**守护妖兽**：万年灵乳周围必有强大的妖兽守护。最常见的是"万年灵蟒"，此蟒以万年灵乳为食，修为可达化神期。

## 使用方法

**直接服用**：直接服用万年灵乳是最简单的方法。但不可贪多，普通修士一次一滴足矣，多了肉身承受不住。

**炼丹入药**：万年灵乳是炼制"万年丹""逆天丹"等顶级丹药的必备材料。以万年灵乳为辅，可让药效提升数倍。

**浸泡沐浴**：将万年灵乳滴入灵泉中，以灵泉沐浴，可让万年灵乳的精华渗入体内，脱胎换骨。

## 相关传说

**万年灵乳化形**：传说万年灵乳积累到程度，会诞生灵智，化为"万年灵乳精灵"。万年灵乳精灵形如婴儿，通体雪白，是天地间最纯净的生命。

**王母万年灵乳**：西王母的蟠桃园中，有一口灵泉，泉中便含有万年灵乳。蟠桃树以灵泉浇灌，才能结出蟠桃这等奇珍。

**万年灵乳之争**：传说上古时期，两位大能为了一滴万年灵乳展开了一场惊天动地的大战。最终，两位大能同归于尽，万年灵乳也随之消失在天地之间。
