# 灵珀

> 品阶：地级四品 · 灵气琥珀

## 诞生条件

灵珀诞生于远古灵木森林中。

远古时期，天地间生长着无数灵木。这些灵木在受伤后会分泌树脂，树脂流淌到地面上，将周围的灵气封存其中。经过数万年的地质变化，树脂逐渐硬化，最终化为琥珀——这便是灵珀。

灵珀的形成需要三个条件：其一，必须有灵木分泌的树脂；其二，树脂必须封存足够的灵气；其三，必须经过数万年的地质变化。

灵珀的形成没有固定的时间，取决于树脂的体积和灵气的浓度。

灵珀成型之时，树脂会发出微弱的光芒，如同一颗星星在地下闪烁。

## 外观特征

灵珀呈金黄色或橙红色，通透度不一。高品质的灵珀内部可见远古灵气形成的气泡，甚至封存着远古昆虫或植物碎片。

将灵珀放在掌心，会感到一股温暖的气息从珀中透出。灵珀的温度恒定，冬暖夏凉。

灵珀有一个奇特的特性：它会自行吸收周围的灵气。将灵珀放在灵气充沛的地方，它的品质会缓慢提升。

## 功效

**封存灵药**：灵珀是封存灵药的最佳材料。以灵珀制成的容器，可让灵药万年不腐，灵气不流失。

**保护法宝**：灵珀可作为法宝的保护层，防止法宝受损。

**考古研究**：灵珀中封存的远古昆虫或植物碎片，是研究远古灵植的珍贵材料。

**装饰饰品**：灵珀可制作成修士的饰品，既美观又实用。

## 获取方式

灵珀多产于远古灵木森林的遗迹中。

**挖掘矿层**：通过勘探找到远古灵木森林的遗迹，然后挖掘地下矿层寻找灵珀。

**河床捡拾**：一些灵珀会从矿层中被水流冲刷到河床上，被有缘人捡拾。

**上古遗迹**：一些上古遗迹中可能存有高品质的灵珀。

## 使用方法

**封存灵药**：以灵珀制成的容器，可让灵药万年不腐。

**保护法宝**：以灵珀作为法宝的保护层，可防止法宝受损。

**考古研究**：研究灵珀中封存的远古昆虫或植物碎片，可了解远古灵植。

**装饰饰品**：以灵珀制作成修士的饰品，既美观又实用。

## 相关传说

**琥珀藏蜂**：传说灵珀中封存着一只远古灵蜂。这只灵蜂是远古时期最强大的蜂类，其蜂蜜可生死人肉白骨。

**灵珀化形**：传说灵珀积累到一定程度，会诞生灵智，化为"灵珀精灵"。灵珀精灵形如琥珀，通体金黄，可操控树脂。

**树脂落泪**：传说灵木在悲伤时会分泌大量的树脂，这些树脂化为灵珀，封存了灵木的悲伤。得到灵珀的修士，会在梦中听到灵木的哭泣。
