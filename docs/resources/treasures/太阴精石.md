# 太阴精石

> 品阶：天级五品 · 月华之魄

## 诞生条件

太阴精石，本是太阴星（月亮）表面的一部分。

太阴星与太阳星相对，主掌夜间的光明与天地间的阴气。在漫长的岁月中，太阴星表面偶尔会被陨石撞击，产生碎片。这些碎片脱离太阴星后，在虚空中飞行，最终被地球引力捕获，坠入凡间。

碎片在穿越九重天层时，会被月华浸染，吸收太阴星的至阴之气，最终化为陨石坠落地面。这便是太阴精石。

太阴精石的形成条件极为苛刻：碎片必须恰好坠入阴气充沛的区域，才能保住灵性；碎片坠落后必须被深埋地底，才能避免阴气散失；碎片必须在月圆之夜坠落，才能吸收足够的月华。

太阴精石坠落之时，会引发一场"月华潮汐"——方圆千里的阴气会在一瞬间暴涨，温度骤降，万物凋零。

## 外观特征

太阴精石呈不规则形状，通体呈银白色，表面有淡淡的月华流转。珠体触感冰凉，如同触摸一块寒冰。

将太阴精石置于暗处，它会散发出柔和的银光，如同一轮微缩的月亮。以神识探入珠中，可看到一片清冷的月宫，桂树婆娑，玉兔捣药。

太阴精石有一个奇特的特性：它会自行吸收月光。在月圆之夜，它的亮度和寒气会大幅提升；在月食之夜，它的光芒会完全消失。

## 功效

**太阴之力**：太阴精石蕴含纯粹的太阴之力，修炼太阴功法的修士持之修炼，可将自身灵力提升为太阴之力，威力提升十倍以上。

**月华淬体**：以太阴精石散发的月华淬炼肉身，可让肉身变得清冷如玉，大幅提升法术抗性。月华淬炼后的肉身，对火属性攻击有极强的抵抗力。

**滋养神魂**：太阴精石的月华可滋养神魂，修复神魂损伤。对于神魂受损的修士，太阴精石是无上的疗伤至宝。

**召唤月华**：太阴精石可在夜间召唤月华，形成一片"月华领域"。在月华领域内，太阴属性修士的实力大幅提升，太阳属性修士则被大幅削弱。

## 获取方式

太阴精石散落在世界各地的陨石坑中。已知的产出地有三处：

一是广寒宫遗迹，位于昆仑山巅，是太阴精石最集中的坠落之地。遗迹中太阴精石随处可见，但周围寒气极重，非太阴属性修士无法靠近。

二是月桂谷，位于西牛贺洲，传说月桂树的种子坠落于此。谷中太阴精石散落在月桂树下，但月桂树有树精守护。

三是玉兔洞，位于东胜神洲，传说玉兔曾在此捣药。洞中太阴精石被玉兔用来炼制丹药，至今仍有残留。

## 使用方法

**炼化入体**：以太阴功法将太阴精石纳入丹田，慢慢炼化。炼化后，修士可操控太阴之力，且神魂大幅增强。但太阴之力极为阴寒，需以火属性灵物调和。

**镶嵌法宝**：将太阴精石镶嵌在太阴属性法宝上，可让法宝品质提升一个品阶，且附带"月华"之能。

**炼丹**：太阴精石是炼制"太阴丹"的主药。太阴丹服下后，修士可在短时间内获得太阴之力，神魂强度暴增。

## 相关传说

**嫦娥奔月**：嫦娥奔月时，曾带走一块太阴精石。这块太阴精石后来被吴刚用来砍伐月桂树，每一斧下去，都会释放出一道月华。

**玉兔捣药**：月宫中的玉兔以太阴精石为臼，以月桂树枝为杵，炼制长生不老药。据说玉兔炼制的丹药，一颗可延寿万年。

**天狗食月**：传说天狗食月时，会咬下太阴星的一块碎片。这块碎片坠落凡间，便化为太阴精石。因此，太阴精石又被称为"天狗之食"。
