# 灵砂

> 品阶：地级三品 · 灵气之砂

## 诞生条件

灵砂诞生于灵脉深处的特殊环境。

灵脉深处的灵气浓度极高，在某些特殊的地质构造中，灵气会围绕一个微小的核心（如一颗微尘）不断沉积，经过数万年，形成一颗坚硬的颗粒——这便是灵砂。

灵砂的形成需要三个条件：其一，必须有稳定的灵气来源；其二，必须有一个微小的核心；其三，必须经过数万年的沉积。

灵砂每千年才能形成一颗，因此极为珍贵。

灵砂成型之时，灵脉深处会发出微弱的嗡鸣之声。

## 外观特征

灵砂呈淡金色半透明颗粒，质地坚硬，触感温润。每粒灵砂约芝麻大小，在光照下会闪烁微弱的金光。

将灵砂放在掌心，会感到一股温暖的气息从砂中透出。灵砂的硬度远超普通砂石，但比灵晶软。

灵砂有一个奇特的特性：它会自行吸收周围的灵气。将灵砂放在灵气充沛的地方，它的品质会缓慢提升。

## 功效

**炼器材料**：灵砂是炼制灵器的常用材料。在炼器时加入灵砂，可提升法宝的灵气传导性。

**阵法基石**：灵砂是布置阵法的基石材料。以灵砂为阵基的阵法，威力远超普通阵法。

**炼丹药引**：某些特殊丹药需要灵砂作为药引，以激发药性。

**制符填充**：灵砂可作为符箓的填充材料，提升符箓的灵气含量。

## 获取方式

灵砂多产于灵脉深处，需挖掘灵脉矿石后提炼而来。

**灵脉开采**：通过地脉勘探术找到灵脉深处，然后挖掘开采。

**灵矿提炼**：某些古老的灵矿中天然存在灵砂矿层，可直接开采。

**河床捡拾**：一些灵砂会从矿层中被水流冲刷到河床上，被有缘人捡拾。

## 使用方法

**炼器材料**：在炼器时加入灵砂，可提升法宝的灵气传导性。

**阵法基石**：以灵砂为阵基，可布置阵法。

**炼丹药引**：在炼丹时加入灵砂粉末，可激发药性。

**制符填充**：以灵砂作为符箓的填充材料，可提升符箓的灵气含量。

## 相关传说

**灵砂化形**：传说灵砂积累到一定程度，会诞生灵智，化为"灵砂精灵"。灵砂精灵形如沙粒，通体金黄，可操控砂石。

**撒砂成兵**：传说上古大能将灵砂撒向空中，灵砂化为千军万马，与敌人厮杀。

**灵砂之路**：传说灵脉深处有一条由灵砂铺成的小路，沿着小路行走，可直达灵脉核心。
