# 土灵珠

> 品阶：天级四品 · 厚德之珠

## 诞生条件

土灵珠的诞生，源于地母后土的慈悲。

上古时期，共工怒触不周山，天柱折断，天塌地陷，无数生灵陨落。死后魂魄无所归依，在天地间飘荡哀嚎。后土娘娘心生悲悯，以身化六道轮回，为亡魂开辟往生之路。

在化道之际，后土娘娘望着满目疮痍的大地，流下了一滴眼泪。这滴眼泪蕴含后土对苍生的悲悯与对大地的眷恋，落入大地深处，与黄土之精融合。

黄土者，大地之本色，承载万物、孕育生灵的根基。后土之泪与黄土之精融合后，经过数万年的沉淀，最终化为土灵珠。

土灵珠的形成需要"后土之泪"与"黄土之精"两个条件，因此天地间只形成了六颗土灵珠，对应六道轮回。

土灵珠成型之时，大地会微微震颤，如同母亲在叹息。珠周围的土壤会变得异常肥沃，万物生长速度提升百倍。

## 外观特征

土灵珠大如鹅卵，通体呈土黄色，表面粗糙如普通泥土，毫不起眼。但仔细看去，珠体表面有无数细密的纹路，如同大地的脉络。

将土灵珠托于掌心，会感到一股厚重而温暖的气息，如同站在广袤的大地上。珠体极为沉重，看似不过鹅卵大小，却重达万斤。

土灵珠有一个奇特的特性：将它放在任何地方，它都会与脚下的土地产生共鸣。通过土灵珠，持有者可以感知方圆千里内的一切动静——无论是地下的矿脉、地表的行走，还是地中的根系生长。

## 功效

**大地之力**：土灵珠蕴含后土的大地法则，持有者可操控大地。无论是移山倒海、裂地穿石，还是凝聚土墙、召唤石人，皆可随心而动。

**厚德载物**：土灵珠可大幅提升防御力。以土灵珠加持的防御法术，坚不可摧。修炼土属性功法的修士持之修炼，可在体表形成一层"大地护甲"，可抵挡同阶修士的全力攻击。

**滋养万物**：土灵珠散发的气息可滋养大地。将土灵珠埋入贫瘠的土地，可让荒地变为沃土。将土灵珠置于灵田，可让灵药的品质大幅提升。

**沟通地脉**：土灵珠可让持有者感知天下地脉的走向，是寻找矿脉、灵脉、龙脉的最佳法器。

## 获取方式

土灵珠散落于大地深处，与地脉融为一体，极难寻找。

**后土祠**：传闻在昆仑山之巅，有一座后土娘娘的祠堂。祠堂的地基中，埋藏着一颗土灵珠。但祠堂周围有后土残魂守护，非大慈悲者不可入。

**六道轮回**：后土身化六道时，六颗土灵珠分别对应六道。其中一颗留在人间道，其余五颗散落于天道、阿修罗道、畜生道、饿鬼道、地狱道。要集齐六颗土灵珠，需遍历六界。

**地脉节点**：在一些地脉交汇的关键节点，偶尔也能发现土灵珠的踪迹。但这些节点通常位于地底万丈深处，非大神通者不可达。

## 使用方法

**炼化入体**：将土灵珠纳入丹田，以土属性功法炼化。炼化后，修士可操控大地，且肉身与大地相连，只要站在地上，就拥有无穷无尽的力量。

**布阵**：以土灵珠为阵眼布置的"大地守护阵"，可引动地脉之气，形成一层坚不可摧的防御。阵中修士的防御力提升十倍。

**炼丹**：土灵珠是炼制"地母丹"的主药。地母丹服下后，修士可在短时间内获得后土的一部分大地之力，防御力暴增，且能感知方圆千里的一切动静。

## 相关传说

**后土化六道**：后土娘娘身化六道时，她的眼泪化为土灵珠，散落于六界之中。传说集齐六颗土灵珠，可重现后土娘娘的一部分神力，甚至能打开六道轮回之门。

**地母赐珠**：上古时期，大地崩裂，生灵涂炭。后土娘娘显灵，将一颗土灵珠赐予一位善良的修士。这位修士凭借土灵珠的大地之力，修补了裂缝，拯救了苍生。后来这位修士成为了第一代地仙之祖。

**镇元子**：地仙之祖镇元子的人参果树下，据说就埋着一颗土灵珠。正是因为土灵珠的滋养，人参果树才能结出人参果这等奇珍。
