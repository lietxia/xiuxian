# 九天息壤

> 品阶：神级七品 · 神土至宝

## 诞生条件

九天息壤，非人间凡土，亦非寻常灵壤可比。此土生于九重天之上的虚空之中，是天道运转时洒落的神土碎屑，经无穷岁月吸纳诸天星辰精华，最终凝为微尘大小的一粒。每一粒九天息壤，都需要经历至少十万年以上的凝练，方能成型。

其形成之地必定是九天之上灵气最为精纯之处，且必须同时满足三个条件：其一，处于天界罡风层与虚空乱流的交界处，有天地交泰之气滋润；其二，周围有至少九条天脉灵泉汇聚，以泉养土；其三，需在九九八十一次天劫雷火中淬炼而不毁，方得圆满。

正因条件如此苛刻，九天息壤的数量极为稀少，整个天地间也不过百粒之数。且每取一粒便少一粒，天道短时间内不会再生。

## 外观特征

九天息壤看似为土，实则已超出凡土之相。每一粒不过米粒大小，通体呈现璀璨的金黄色，在黑暗中能自行发光，光芒柔和温润，不刺目却可照亮十丈方圆。

其质极为奇特，看似坚实，握于手中却如无物，轻盈若空。用力捏时，息壤会自行凹陷，却永远不会被压碎。撒入水中不沉不化，遇火不焚不焦，落入地面则会自行渗入，与大地融为一体再无迹可寻。

以神识细观，可见息壤表面有无数先天符文流转不息。这些符文细小如尘埃，却是天地间最为古老的文字，记载着大地生长万物的法则。每一个符文都在不断演化，时而化为草木之形，时而化为山川之相，生生不息。

## 功效

九天息壤最神奇之处在于"生生不息"四字。一粒息壤，若置于合适的环境中，可自行生长繁衍，百年后变为一碗，千年后化为一方，万年后可成一片沃土。

**培植灵药**：以九天息壤种植灵草灵药，有不可思议的奇效。寻常需千年方能成熟的灵药，在息壤中百年便可收获。且所生灵药的品质远超自然生长者，药效至少提升三成。更珍贵的是，一些已经绝迹的上古灵药，若将种子植入息壤，有极大可能重新萌发。

**扩容空间**：九天息壤是炼制空间法宝的核心材料。以息壤为主料炼制的储物法宝，内部空间可随主人心意无限扩展。传说上古大能的袖里乾坤之术，便是以九天息壤炼制的一粒微尘，展开后内藏一方小世界。

**修复大地**：九天息壤可修复受损的山川灵脉。若有一处灵脉被毁、灵气枯竭，只需将一粒息壤埋入地脉深处，百年之内灵脉便可自行修复，且比从前更加旺盛。

## 获取方式

九天息壤产自九重天之上的虚空裂缝中，凡人根本无法到达。便是化神期的修士，若无至宝护身，也挡不住九天罡风的侵蚀。

**天界掉落**：每隔万年左右，会有一些九天息壤碎粒被罡风吹落，散落在天界与人间的交界处。这些碎粒虽小，却是人间修真者最有可能获得的息壤来源。

**天劫余烬**：有极小的概率，在修为极高的修士渡天劫时，天劫之力会击穿九天罡风层，使得少量息壤随劫雷坠落。这便是所谓"天劫余烬"，可遇而不可求。

**守护妖兽**：息壤周围必有守护之物。因息壤蕴含大地本源之力，最吸引土属性的神兽。最常见的是"玄土麒麟"，此兽通体如黄玉，形似麒麟而略小，平日沉睡于地脉深处，以息壤散发的气息为食。若有修士靠近息壤，玄土麒麟便会苏醒，其战力堪比合体期修士。

另有传说，每一块成熟的九天息壤周围，都有一条"地脉龙魂"守护。此龙魂乃大地意志的化身，非实体，却能调动整片山脉的地气为己用，极难对付。

## 使用方法

**培植灵根**：将息壤铺于灵田底部，上覆普通灵土，可大幅提升整片灵田的品质。此法最适合宗门种植稀有灵药。

**炼制法宝**：以九天息壤为主材，可炼制"乾坤袋""纳虚戒"等空间法宝。若辅以星辰砂、龙脉石等材料，甚至可炼制出内含洞天的镇派至宝。炼器时需将息壤以真火熔炼，再以神识刻入空间阵法，息壤的灵性会自行与阵法融合。

**入药炼丹**：九天息壤味甘性平，可直接服用，但药效发挥极慢，需千年才能完全吸收。更常用的方法是以息壤为辅料炼制"培元固本丹"，可大幅提升修士的体质。

**布阵**：九天息壤是地属性大阵的最佳阵基材料。以息壤为阵眼布置的防御大阵，可引动大地之气，阵法运转时如同与整片大地连为一体，极难攻破。

## 相关传说

**女娲补天**：最著名的九天息壤传说，当属女娲补天。远古时期天柱折断、苍天破裂，女娲斩巨龟之足以立四极，又炼五色石以补苍天。然五色石虽好，却缺少一种能将天幕紧密粘连的材料。女娲于是登上九天，采集九天息壤，以神火将五色石与息壤熔炼为一体，终将苍天补全。

**大禹治水**：传说大禹治水时，曾得天帝赐下一粒九天息壤。大禹将此土投入洪水中，息壤见水而长，化为一道千里长堤，将洪水挡于堤外。这便是典故"息壤止洪"的由来。

**不死之土**：《山海经》有载："鲧窃帝之息壤以堙洪水。"传说鲧从天帝处偷走九天息壤，欲以此堵塞洪水。不料息壤落入人间后，自行生长繁衍，化作漫天神土，反将更多河道堵塞。天帝一怒之下收走息壤，鲧也因此获罪。
