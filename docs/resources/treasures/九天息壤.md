# 九天息壤

> 品阶：神级七品 · 神土至宝

## 诞生条件

九天息壤，非人间凡土，亦非寻常灵壤可比。此土生于九重天之上的虚空之中，是天道运转时洒落的神土碎屑，经无穷岁月吸纳诸天星辰精华，最终凝为微尘大小的一粒。每一粒九天息壤，都需要经历至少十万年以上的凝练，方能成型。

其形成之地必定是九天之上灵气最为精纯之处，且必须同时满足三个条件：其一，处于天界罡风层与虚空乱流的交界处，有天地交泰之气滋润；其二，周围有至少九条天脉灵泉汇聚，以泉养土；其三，需在九九八十一次天劫雷火中淬炼而不毁，方得圆满。

天地异象方面，九天息壤成型之际，九天之上会出现一片金色祥云，笼罩万里。祥云中隐隐有龙吟凤鸣之声，天降金色花雨，每一朵花落地即化为泥土——这便是"天女散花，化作息壤"的奇景。同时，方圆万里的所有草木会在一瞬间疯长，原本需要千年方能长成的灵木，在这短短数息间便可拔地而起，直达云霄。有缘人若此时恰好身处九天，甚至能闻到一股浓郁的泥土芬芳——那是万物生机的极致，闻之可延寿百年。

正因条件如此苛刻，九天息壤的数量极为稀少，整个天地间也不过百粒之数。且每取一粒便少一粒，天道短时间内不会再生。

## 外观特征

九天息壤看似为土，实则已超出凡土之相。每一粒不过米粒大小，通体呈现璀璨的金黄色，在黑暗中能自行发光，光芒柔和温润，不刺目却可照亮十丈方圆。

其质极为奇特，看似坚实，握于手中却如无物，轻盈若空。用力捏时，息壤会自行凹陷，却永远不会被压碎。撒入水中不沉不化，遇火不焚不焦，落入地面则会自行渗入，与大地融为一体再无迹可寻。

以神识细观，可见息壤表面有无数先天符文流转不息。这些符文细小如尘埃，却是天地间最为古老的文字，记载着大地生长万物的法则。每一个符文都在不断演化，时而化为草木之形，时而化为山川之相，生生不息。

九天息壤散发的气息极为独特——那是一种混合了雨后泥土的清新、春日百花的芬芳、秋日谷物的醇香的气息。此气息可安神魂、定心神，长期闻之可使人身强体健，百病不侵。更有一种奇异的特性：九天息壤的气息会吸引周围的草木向其靠拢，故凡在息壤附近生长的植物，都会不自觉地朝向息壤的方向弯曲生长。

## 功效详解

九天息壤最神奇之处在于"生生不息"四字。一粒息壤，若置于合适的环境中，可自行生长繁衍，百年后变为一碗，千年后化为一方，万年后可成一片沃土。

**培植灵药**：以九天息壤种植灵草灵药，有不可思议的奇效。寻常需千年方能成熟的灵药，在息壤中百年便可收获。且所生灵药的品质远超自然生长者，药效至少提升三成。更珍贵的是，一些已经绝迹的上古灵药，若将种子植入息壤，有极大可能重新萌发。据《神农百草经》记载，以息壤培育的万年灵芝，药效等同于自然生长三万年的古灵芝；以息壤培育的九叶玄参，其药力可媲美自然生长的十二叶玄参。

**扩容空间**：九天息壤是炼制空间法宝的核心材料。以息壤为主料炼制的储物法宝，内部空间可随主人心意无限扩展。标准配比如下：炼制一枚乾坤戒以一粒息壤为底，可开辟十丈见方的初始空间，之后每融入一粒息壤，空间可扩大十倍。传说上古大能的袖里乾坤之术，便是以九粒九天息壤炼制的一粒微尘，展开后内藏一方小世界，方圆足有百万里之广。

**修复大地**：九天息壤可修复受损的山川灵脉。若有一处灵脉被毁、灵气枯竭，只需将一粒息壤埋入地脉深处，百年之内灵脉便可自行修复，且比从前更加旺盛。若灵脉断裂，则以三粒息壤布成三才阵埋入断口，可在十年内使断脉重连。上古时期，不周山断裂导致天地倾覆，女娲便曾以九天息壤填补天柱根基，可见其修复大地之力何等惊人。

**镇压气运**：鲜有人知的是，九天息壤还具备镇压气运的功效。将息壤供奉于宗门的镇运大阵中，可安抚地脉、稳固根基，使宗门气运不轻易流失。一个拥有九粒息壤镇压气运的宗门，至少可保万年气运不衰。

## 获取方式

九天息壤产自九重天之上的虚空裂缝中，凡人根本无法到达。便是化神期的修士，若无至宝护身，也挡不住九天罡风的侵蚀。

**天界掉落**：每隔万年左右，会有一些九天息壤碎粒被罡风吹落，散落在天界与人间的交界处。这些碎粒虽小，却是人间修真者最有可能获得的息壤来源。历史上数次大规模的天界之风，都曾在人间留下了息壤的踪迹，如三千年前的昆仑山息壤雨——一夜之间，昆仑山方圆千里落下了上百粒息壤，引发了修真界的一场血雨腥风。

**天劫余烬**：有极小的概率，在修为极高的修士渡天劫时，天劫之力会击穿九天罡风层，使得少量息壤随劫雷坠落。这便是所谓"天劫余烬"，可遇而不可求。据记载，一万年来只有七次天劫出现了息壤随劫雷坠落的情况，七位渡劫者中有五位在渡劫后成功飞升。

**深渊倒悬**：在极少数情况下，地渊深处的逆流会将息壤从九天之下卷入九幽之地。冥界的某些区域偶尔会发现九天息壤的踪迹——这便是所谓的"深渊倒悬"。然而冥界凶险异常，非大能者不可轻入。

**守护妖兽**：息壤周围必有守护之物。因息壤蕴含大地本源之力，最吸引土属性的神兽。最常见的是"玄土麒麟"，此兽通体如黄玉，形似麒麟而略小，平日沉睡于地脉深处，以息壤散发的气息为食。若有修士靠近息壤，玄土麒麟便会苏醒，其战力堪比合体期修士，且能调动周围千里的地气为己用，在地脉范围内几乎不可战胜。

另有传说，每一块成熟的九天息壤周围，都有一条"地脉龙魂"守护。此龙魂乃大地意志的化身，非实体，却能调动整片山脉的地气为己用，极难对付。地脉龙魂不出手则已，一出手便是山崩地裂，飞沙走石。

## 使用方法

**培植灵根**：将息壤铺于灵田底部，上覆三寸普通灵土，可大幅提升整片灵田的品质。每一粒息壤可改造三丈方圆的灵田。此法最适合宗门种植稀有灵药。若将息壤直接埋入灵根植物的根部，可让灵根的品质在三年内提升一品——从下品升中品、中品升上品。

**炼制法宝**：以九天息壤为主材，可炼制"乾坤袋""纳虚戒"等空间法宝。若辅以星辰砂、龙脉石等材料，甚至可炼制出内含洞天的镇派至宝。炼器时需将息壤以真火熔炼，再以神识刻入空间阵法，息壤的灵性会自行与阵法融合。最佳配比为：一粒息壤配三两星辰砂、一块龙脉石，以三昧真火炼七七四十九日。

**入药炼丹**：九天息壤味甘性平，可直接服用，但药效发挥极慢，需千年才能完全吸收。更常用的方法是以息壤为辅料炼制"培元固本丹"，可大幅提升修士的体质，使肉身坚韧如大地。具体配方为一粒息壤配以百年黄精五两、千年首乌三两、地髓芝两株，以文火炼九日九夜，可得培元固本丹十二枚。

**布阵**：九天息壤是地属性大阵的最佳阵基材料。以息壤为阵眼布置的防御大阵，可引动大地之气，阵法运转时如同与整片大地连为一体，极难攻破。布置护山大阵时，以九粒息壤分镇九宫方位，可使阵法的防御力提升十倍以上。

## 相关传说

**女娲补天**：最著名的九天息壤传说，当属女娲补天。远古时期天柱折断、苍天破裂，女娲斩巨龟之足以立四极，又炼五色石以补苍天。然五色石虽好，却缺少一种能将天幕紧密粘连的材料。女娲于是登上九天，采集九天息壤，以神火将五色石与息壤熔炼为一体，终将苍天补全。据说女娲补天共用了九万九千九百九十九粒九天息壤，此数量恰好暗合天道之数。

**大禹治水**：传说大禹治水时，曾得天帝赐下一粒九天息壤。大禹将此土投入洪水中，息壤见水而长，初始不过微尘大小，转瞬之间化为一道千里长堤，高百丈、厚十丈，将洪水挡于堤外。这便是典故"息壤止洪"的由来。大禹用毕后将息壤归还天帝，天帝以大禹不贪宝物、一心为民，又赐下三粒息壤，大禹以此疏通九河，终成大业。

**不死之土**：《山海经》有载："鲧窃帝之息壤以堙洪水。"传说鲧从天帝处偷走九天息壤，欲以此堵塞洪水。不料息壤落入人间后，自行生长繁衍，化作漫天神土，反将更多河道堵塞。天帝一怒之下收走息壤，鲧也因此获罪，死于羽山。三日后鲧的尸体不腐，剖之而生禹——这便是大禹出生的来历。

**佛国净土**：佛教传说中，西方极乐世界的黄金铺地，其实便是以九天息壤为底。阿弥陀佛发四十八大愿，以大法力将息壤铺满整个极乐世界，故净土之中寸寸皆是黄金，步步可生莲花。

## 同类对比

九天息壤位列神级七品，在土属性至宝中独占鳌头。

**与五色息壤相比**：五色息壤乃是息壤中掺杂了五行精气的变种，各具五行属性——青色主木、红色主火、黄色主土、白色主金、黑色主水。五色息壤在培育特定属性的灵药时效果更好，但论及生生不息、自行繁衍这一根本特性，远不及纯正的九天息壤。一粒五色息壤只能繁衍百倍，而九天息壤可繁衍万倍不止。

**与玄黄之精相比**：玄黄之精是天地的精华，重逾山岳，是炼制防御至宝的绝佳材料。玄黄之精更为坚实厚重，防御力无双；九天息壤则贵在生机与繁衍。若论镇压气运，玄黄之精更为直接；若论长久经营、培育人才，九天息壤更胜一筹。两者搭配，以玄黄之精炼制护甲、以九天息壤培育灵药，是完美的资源互补。

**与三光神水相比**：三光神水是日月星三光精华凝结而成，主滋润、复苏，与九天息壤的培育之能相辅相成。以九天息壤为土、三光神水浇灌，可使灵药的生长速度再提升一倍。许多绝迹的上古灵根，便是用这种土水配合的方式重新培育出来的。两者常被并列称为"天地双宝"。

**阴性克制**：九天息壤对冥界死气、怨气和阴煞之气有天然的克制作用。若将息壤撒在鬼域或阴煞之地，可净化地气、化解怨念。但需注意，息壤不可与玄冥真水接触——水土相克，两者相遇会互相抵消灵性，造成不可挽回的损失。
