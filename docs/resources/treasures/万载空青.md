# 万载空青

> 品阶：天级五品 · 空间奇珍

## 诞生条件

万载空青，非寻常草木之精，而是天地间罕见的空间属性灵物。其形成需要一株至少存活了万年以上的古木——此木须生于空间裂缝附近，常年受虚空之力的侵蚀与滋养。

古木的根系扎入大地，汲取地脉灵气；树干支撑天地，承接日月精华；而最关键的是，其枝叶须伸入空间裂缝之中，以叶片吸纳虚空中的空间之力和混沌之气。如此，此木便不再是一棵普通的树，而成了勾连现实与虚空通道的媒介。

经过万年以上的漫长岁月，树心会逐渐液化，最终凝结成一种半透明青色的树液精华——这便是万载空青。树液每千年才会凝出一滴，故而整棵万年古木的木心之中，也不过十滴左右。

由于需要空间裂缝这一苛刻条件，修真界中能产出万载空青的地方屈指可数。而且古木一旦被取走空青，生机便会断绝，所以不可持续获取。

## 外观特征

万载空青呈液体状，色如青空之碧，清透澄澈。其最为奇特之处在于颜色并非固定不变——正如天空之色会随时间变化一般，万载空青也会随着时辰流转而呈现出不同的色泽：

清晨时分呈淡青色，如初晓之空；正午时分化为深碧色，如晴空万里；黄昏时分转为橙青色，如晚霞映天；子夜时分则透明近无色，如深邃夜空。

用目光注视万载空青时，会发现它的内部似乎有无数细小的空间在不断地生灭。每一个空间都如同一粒微尘，其中却有山有水，别有洞天。偶尔还能在空青中看到一些异象——一片飘落的树叶在空间中旋转，一朵不知名的花在其中绽放又凋谢，甚至有一只蝴蝶在其中翩然飞舞，恍如隔世。

装盛万载空青的容器不能是普通的玉瓶，因为空间之力会侵蚀容器，使之崩裂。通常需以空冥石或虚空水晶制成的瓶子来保存，这两种材料的空间属性稳固，不会与空青产生排斥。

## 功效

万载空青最为珍贵的功效，在于它蕴含的空间之力。这种力量是领悟空间法则、修炼空间术法的绝佳媒介。

**领悟空间**：修士以神识探入万载空青之中，可以亲身体验空间法则的运转。不需自己费心推演，只需沉浸于空青中不断生灭的空间碎片，便能在心中逐渐明悟空间的本质。这比单纯参悟功法典籍的效果好了百倍不止。

**凝固虚空**：万载空青具备凝固虚空的能力。在战斗中使用一滴万载空青，可以在瞬间冻结周围的空间，将敌人困在凝固的空间中。修为低于施术者的敌人，至少要三个呼吸才能挣脱，这在强者对决中足以决定胜负。

**开辟储物空间**：将万载空青炼入材料中，可以开辟出稳定的储物空间。即使是一滴万载空青，也能开辟出一间屋子大小的储物空间，且随着空青的品质提升，空间也会扩大。用万载空青炼制的储物法宝，空间极为稳定，不会像其他空间法宝那样有崩塌之虞。

## 获取方式

万载空青的获取难度极大，远在寻常天材地宝之上。

**空间裂缝古木**：最正统的获取方式，是在空间裂缝附近寻找被虚空之力滋养的古木。修真界已知的有三处：一是苍梧山深处的一棵万年古榕，二是昆仑山虚空崖边的一株苍松，三是东海归墟附近的一棵扶桑古木。这三处的空青都已有主，由隐世宗门守护，外人无法染指。

**随机形成的空青矿脉**：在一些经历了空间大崩塌的遗迹中，偶有万载空青形成的矿脉。这些矿脉并非来自古木，而是空间碎片在地底经过千万年的沉淀后，逐渐合并凝聚，最终形成的空青矿。这种空青矿的品质不如古木所出者，但胜在数量较多。已知的矿脉仅有两条，一条在上古战场遗址的地下千丈处，另一条在虚空裂缝深处的浮空岛上。

**守护妖兽**：产万载空青的古木周围，必有以空青为食的"空灵兽"守护。此兽形如白猿，通体透明，能在空间中自由穿梭。空灵兽极为机敏，一旦感知到有人在打空青的主意，便会遁入空间深处，或从意想不到的角度发起攻击。

更为可怕的是，一些古木中甚至寄宿着"虚空古魂"——那是上古时期陨落在空间裂缝中的强大修士留下的残魂，被古木吸收后与之融为一体。此魂可在虚实之间切换，攻击手段诡异莫测。

## 使用方法

**炼化入体**：将万载空青纳入丹田炼化，可使修士的空间感知力大幅提升。炼化后的修士能够更加敏锐地感知空间的波动，从而在战斗中做出更快的反应。长期持有空青的修士，甚至能够自行领悟一些简单的空间术法。

**炼器**：万载空青是炼制空间类法宝的最佳材料之一。在炼制储物法宝时加入一滴空青，可让储物空间扩大数倍且更加稳定。炼制飞剑时加入一滴空青，可让飞剑具备穿梭虚空的特性，在战斗中出其不意地出现在敌人背后。

**布阵**：以万载空青为阵眼布置的空间阵法，可以在一定的范围内扭曲空间，使人误入歧途。高阶的幻阵就是以空青为核心，在阵中造出层层叠叠的空间，让入阵者永远找不到出口。

**入药炼丹**：万载空青也是炼制"虚空丹"的主药。虚空丹可以帮助修士在突破瓶颈时更好地理解空间法则，对于合体期修士突破到大乘期有极为显著的助益。

## 相关传说

**青帝化木**：传说上古青帝为领悟空间法则的真谛，曾将自己化作一棵古木，扎根于虚空裂缝之中。他这一化便是三万年。三万年后，青帝从树中走出，其木心之处便留下了一池万载空青。后世有人寻得此木，将空青取走，凭此领悟了空间法则的真谛，成为一代空间大能。

**空青祖木**：修真界一直流传着一个故事——在天地初开之时，有一棵"虚空祖木"，这棵树的根须扎入三千世界，枝叶覆盖诸天万界。祖木每百万年凝出一滴万载空青，这一滴空青便可开辟一个中千世界。后祖木在量劫中被毁，其残骸化为万千碎片散落各界的空间裂缝之中。如今修真界的那些产空青的古木，据说都是祖木碎片所化。

**空青剑仙**：三千年前，散修凌云子得一滴万载空青。他将空青炼入自己的飞剑中，使得飞剑具备了穿梭虚空之能。凌云子凭此剑纵横修真界，无人能挡。后来有人问他成功的秘诀，他笑而不语，只留下一句话："剑出空青，万法皆空。"
