# 因果丝

> 品阶：神级六品 · 因果之丝

## 诞生条件

因果丝诞生于因果法则的运转之中。

天地间有因果法则，掌管万事万物的因果报应。有因必有果，有果必有因。因果法则在运转时，会产生一种名为"因果之力"的能量。

当因果之力积累到一定程度，便会凝聚成丝线状的物质——这便是因果丝。因果丝是因果法则的具象化，每一根因果丝都代表着一种因果关系。

因果丝的形成需要大量的因果积累。一个凡人的一生，不过产生数十根因果丝；一个修士的一生，可产生数千根因果丝；而一场大战、一次量劫，可产生数以百万计的因果丝。

因果丝凝聚之时，天地间会响起一种奇异的声响——如同琴弦被拨动，清脆而悠远。

## 外观特征

因果丝呈金色或银色，细如蛛丝，却坚韧无比。金色的因果丝代表善因善果，银色的因果丝代表恶因恶果。

将因果丝放在掌心，会感到一阵温热（善因）或冰凉（恶因）。因果丝会自行颤动，颤动的频率与因果的强弱成正比。

以神识探入因果丝中，可看到因果的全貌——从因到果，从果到因，循环往复，无穷无尽。

## 功效

**感知因果**：因果丝可让持有者感知事物之间的因果联系。只需将因果丝放在目标上，便可看到此人与周围一切事物的因果关系。

**斩断恶缘**：因果丝可以斩断。斩断一根恶因因果丝，可以化解一段恶缘，避免因果报应。但斩断因果丝会遭受因果反噬，反噬的大小与斩断的因果强度成正比。

**加强善缘**：因果丝可以加强。将一根善因因果丝缠绕在目标上，可以加强一段善缘，提升福报。

**因果攻击**：因果丝可用于攻击。将一根恶因因果丝植入敌人体内，可让恶果加速降临，使敌人遭受因果报应。

## 获取方式

因果丝只存在于因果法则运转剧烈之地。

**量劫遗迹**：量劫爆发时，无数因果纠缠，会产生大量因果丝。量劫结束后，这些因果丝会残留在战场遗迹中。

**佛门圣地**：佛门修士修炼因果大道，其圣地中常有因果丝凝聚。如大雷音寺、灵山等地。

**轮回之地**：六道轮回是因果法则运转的核心之地，轮回入口处常有因果丝飘落。

## 使用方法

**感知因果**：将因果丝放在目标上，以神识探入，可感知此人与周围一切事物的因果关系。

**斩断恶缘**：以特殊手法斩断恶因因果丝，可化解恶缘。但斩断因果丝会遭受因果反噬。

**加强善缘**：将善因因果丝缠绕在目标上，可加强善缘，提升福报。

**因果攻击**：将恶因因果丝植入敌人体内，可让恶果加速降临。此法极为阴毒，使用者会遭受天道惩罚。

## 相关传说

**佛祖拈花**：佛祖释迦牟尼拈花一笑，以因果丝连接了与迦叶尊者的师徒之缘。这段善缘后来成就了禅宗一脉。

**封神大战**：封神大战是天地量劫，无数因果纠缠。大战结束后，战场上残留的因果丝化为了"封神榜"，记载了三百六十五位正神的因果。

**六道轮回**：后土身化六道轮回时，以因果丝编织了轮回法则。每一个亡魂的轮回转世，都是由因果丝牵引的。
