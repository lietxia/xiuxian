# 雷灵珠

> 品阶：天级四品 · 雷之精魄

## 诞生条件

雷灵珠的诞生，与天劫息息相关。

修士渡劫时，天雷从天而降，劈在大地上。大多数天雷的威力会在劈中目标后消散，但有极小概率，天雷会劈入地底深处，与地脉中天然存在的"地雷电脉"相遇。

地雷电脉是大地中天然存在的电流通道，由地底金属矿脉与地下水脉摩擦产生。当天雷与地雷电脉交汇，天上的雷之法则与地下的雷电之力相互融合，经过数万年的凝聚，最终化为雷灵珠。

雷灵珠的形成需要"天雷"与"地雷电脉"两个条件，且天雷必须是九九重劫级别的天雷方可。因此，雷灵珠的数量极为稀少——每一次九九重劫，最多只形成一颗雷灵珠。

雷灵珠成型之处，会形成一片"雷域"——天空中雷电交加，地面上游走着电弧，寻常生灵无法靠近。

## 外观特征

雷灵珠大如鸡蛋，通体呈紫金色，表面有电弧在不断跳跃。珠体周围始终笼罩着一层淡淡的雷光，发出"噼啪"的声响。

将雷灵珠托于掌心，会感到一阵麻痹感从珠中传来。修为不足者，手臂会被电得失去知觉。珠体看似光滑，触摸时却有微微的刺痛感，如同被针扎。

以神识探入珠中，可看到一片雷电交织的天空中，无数雷龙在翻腾咆哮。珠内蕴含的雷电之力极为狂暴，稍有不慎便会被雷电反噬。

## 功效

**天雷之力**：雷灵珠蕴含天雷法则，修炼雷属性功法的修士持之修炼，可将自身雷电提升为"天雷"，威力提升十倍以上。天雷可破一切邪祟，是鬼修和魔修的克星。

**雷遁之术**：持有雷灵珠的修士，可修炼"雷遁之术"——化身雷电，瞬息万里。雷遁之术的速度仅次于火遁，但破坏力更强。

**淬炼肉身**：以雷灵珠释放的雷电淬炼肉身，可让肉身强度大幅提升。雷电淬炼后的肉身，不仅坚硬如铁，还能免疫大部分雷电攻击。

**引动天雷**：持有雷灵珠的修士，可在战斗中引动天雷轰击敌人。引动的天雷威力与修士的修为相关，高深者可引下九九重劫级别的天雷。

## 获取方式

雷灵珠只存在于"雷域"之中。已知的产出地有三处：

一是渡劫谷，位于西牛贺洲，是上古时期修士渡劫的专用之地。谷中雷域密布，雷灵珠散落在雷域深处。但谷中雷电终年不息，非渡劫期修士无法深入。

二是雷泽，位于东胜神洲，是上古雷神"雷泽"的居所。雷泽中雷电之力极为浓郁，据说藏有大量雷灵珠。但雷神虽已离去，其残魂仍守护着雷泽。

三是天劫遗迹，一些修士渡劫失败后，天雷之力残留在渡劫之地，经过漫长岁月后形成雷灵珠。这些遗迹通常位于荒僻之地，难以寻找。

## 使用方法

**炼化入体**：以雷属性功法将雷灵珠纳入丹田，慢慢炼化。炼化后，修士可操控天雷，且肉身免疫雷电攻击。但雷电极为狂暴，炼化过程如同遭受天劫，非肉身强横者不可为。

**镶嵌法宝**：将雷灵珠镶嵌在雷属性法宝上，可让法宝品质提升一个品阶，且附带"天雷"之能，攻击时可释放雷电轰击敌人。

**炼丹**：雷灵珠是炼制"雷劫丹"的主药。雷劫丹服下后，修士可在短时间内获得天雷之力，实力暴增。但药效过后会陷入虚弱期。

## 相关传说

**雷神鼓**：传说上古雷神雷泽曾将一颗雷灵珠嵌入自己的战鼓中。每次敲击战鼓，都会引动天雷轰击敌人。后来这颗雷灵珠随雷神一同消失，至今下落不明。

**雷震子**：封神大战中的雷震子，据说便是吞食了一颗雷灵珠后，生出了风雷双翅，获得了操控天雷的能力。

**渡劫之秘**：修真界流传着一个秘密——若能在渡劫时将雷灵珠含在口中，可将天雷之力吸收，化为己用。这样不仅能顺利渡劫，还能大幅提升修为。但雷灵珠极为稀少，能得此机缘者万中无一。
