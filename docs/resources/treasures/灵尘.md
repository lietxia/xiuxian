# 灵尘

> 品阶：地级二品 · 灵气微尘

## 诞生条件

灵尘诞生于灵气泉眼等灵气外溢之处。

灵气泉眼是灵脉灵气外溢至地表形成的出口，灵气从泉眼中喷涌而出，如同泉水。当灵气喷涌到空气中，会与空气中的微尘结合，经过漫长岁月的沉淀，形成微小的颗粒——这便是灵尘。

灵尘的形成需要三个条件：其一，必须有灵气泉眼；其二，泉眼周围的灵气浓度必须足够高；其三，必须有足够的沉淀时间。

灵尘每十年才能沉积薄薄一层，因此产量极低。

灵尘沉积之时，泉眼周围会形成一层淡淡的灵雾，灵雾中的微尘便是灵尘。

## 外观特征

灵尘呈淡蓝色粉末状，触感细腻。灵气浓度极高的环境中，灵尘会如尘埃般悬浮于空气中，形成淡淡的灵雾。

灵尘的气息极为清淡——吸入一口，便觉神清气爽。灵尘可直接被身体吸收，但效果微弱，不如灵液。

灵尘有一个奇特的特性：它会自行飘浮。灵尘不受重力影响，会一直悬浮在空气中，随风飘动。

## 功效

**培育灵田**：灵尘可撒入灵田，提升土壤肥力。以灵尘培育的灵田，灵药生长速度提升三倍。

**炼制低阶丹药**：灵尘是炼制低阶丹药的灵气基底。在炼丹时加入灵尘，可让丹药蕴含灵气。

**调制符墨**：灵尘是调制符墨的基础材料。以灵尘调制的符墨，可绘制出蕴含灵气的符箓。

**制符填充**：灵尘可作为符箓的填充材料，提升符箓的灵气含量。

## 获取方式

灵尘主要产自灵脉节点、灵气泉眼等灵气外溢之处。

**灵气泉眼收集**：在灵气泉眼周围放置特制的收集器具，可收集飘浮的灵尘。但收集效率极低，一天只能收集到薄薄一层。

**灵矿沉积**：大型矿脉附近常有灵尘沉积，以特殊器具收集即可获得。

**聚灵阵**：以聚灵阵将灵气压缩，可人工制造灵尘。但此法成本极高，不如天然灵尘划算。

## 使用方法

**培育灵田**：将灵尘撒入灵田，可提升土壤肥力。

**炼丹**：在炼丹时加入灵尘，可让丹药蕴含灵气。

**调制符墨**：以灵尘调制符墨，可绘制出蕴含灵气的符箓。

**制符填充**：以灵尘作为符箓的填充材料，可提升符箓的灵气含量。

## 相关传说

**灵气微尘**：传说灵尘是天地灵气的"种子"。每一粒灵尘都蕴含着一丝灵气，落在合适的环境中，便会生长成灵脉。

**灵尘暴**：在一些灵气极度浓郁的地方，灵尘会形成"灵尘暴"——大量的灵尘被风暴卷起，形成一道巨大的灵雾。灵尘暴所过之处，灵气浓度大幅提升，草木疯长。

**仙人撒尘**：传说仙人路过凡间时，会撒下灵尘，让荒芜之地变为沃土。这些灵尘落地后，会逐渐形成灵脉，滋养一方生灵。
