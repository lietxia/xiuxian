# 灵膏

> 品阶：地级四品 · 灵气草木精华

## 诞生条件

灵膏诞生于灵气充沛的森林深处。

在灵气充沛的森林中，灵木会分泌树脂，树脂与空气中的灵气混合，经过漫长岁月的发酵，形成一种膏状物质——这便是灵膏。

灵膏的形成需要三个条件：其一，必须有灵木分泌的树脂；其二，树脂必须与足够的灵气混合；其三，必须经过数万年的发酵。

灵膏每万年才能形成一小块，因此极为珍贵。

灵膏成型之时，灵木会散发出浓郁的草木香气，吸引周围的生灵前来。

## 外观特征

灵膏呈淡绿色或乳白色，质地粘稠如蜂蜜，散发着清新的草木香气。高品质的灵膏在光照下会呈现半透明状态。

将灵膏放在掌心，会感到一股温暖的气息从膏中透出。灵膏入口有浓郁的甘甜，如同琼浆玉液。

灵膏有一个奇特的特性：它会自行吸收周围的灵气。将灵膏放在灵气充沛的地方，它的品质会缓慢提升。

## 功效

**炼丹主材**：灵膏是炼制疗伤丹药的主材料。以灵膏为核心炼制的疗伤丹药，药效远超普通丹药。

**外伤治疗**：灵膏可直接涂抹在伤口上，加速伤口愈合。

**美容驻颜**：灵膏是修士驻颜的护肤品。以灵膏涂抹肌肤，可让肌肤保持青春。

**药引调和**：灵膏可中和丹药的药性冲突，是炼丹的常用辅料。

## 获取方式

灵膏多产于灵气充沛的森林深处。

**灵木采集**：在灵气充沛的森林中，寻找古老的灵木，采集树洞中自然凝结的灵膏。

**人工合成**：采集灵露草、灵芝等灵木的汁液，可人工合成低阶灵膏。

**上古遗迹**：一些上古遗迹中可能存有高品质的灵膏。

## 使用方法

**炼丹主材**：以灵膏为核心，辅以其他材料，可炼制疗伤丹药。

**外伤治疗**：将灵膏直接涂抹在伤口上，可加速伤口愈合。

**美容驻颜**：将灵膏涂抹在肌肤上，可让肌肤保持青春。

**药引调和**：在炼丹时加入灵膏，可中和丹药的药性冲突。

## 相关传说

**灵膏化形**：传说灵膏积累到一定程度，会诞生灵智，化为"灵膏精灵"。灵膏精灵形如少女，通体翠绿，可操控草木。

**神农膏**：神农氏尝百草时，曾以灵膏解毒。无论中了什么毒，只需涂抹灵膏，便可化解。

**灵膏之路**：传说灵脉深处有一条由灵膏铺成的小路，沿着小路行走，可直达灵脉核心。
