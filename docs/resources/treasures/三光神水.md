# 三光神水

> 品阶：仙级六品 · 水系至宝

## 诞生条件

三光神水的形成，需集齐天时、地利、机缘三者方可。

所谓天时，须在日月同辉、星辰列张的特殊天象之下。通常在某个百年难得一遇的日子——日食或月食之时，日之精、月之华、星之芒三者交汇于一条无形的线，天地间的光之法则在这一刻被压缩到极致。

所谓地利，须有一方灵泉池或天池，水质须至纯至净，不可有任何杂质。此泉须处于天地灵气汇聚之处，且上方空旷无遮挡，能直接承接日月星光。修真界仅有寥寥几处这样的所在，如昆仑山天池、东海扶桑岛，以及传说中漂浮于虚空中的"悬空灵泉"。

所谓机缘，则是即便前两者皆备，三光神水也未必会形成。因为日月星三光的交汇不仅需要特定的天象，还需要天地间冥冥中的契机。所以有时候，万年也未必能凝成一滴三光神水。

## 外观特征

三光神水并非寻常的水，而是一种介于液态与光之间的奇异存在。

平日里，它呈现出清澈透明的寻常水状，看不出任何特别之处。但若在日光下细看，水中有无数细微的光点在流转，每一粒光点都如同一颗微缩的星辰。若在月光下观赏，则水色转为银白，表面浮着一层淡淡的霜华。若在星光下凝视，水中会出现一幅浩瀚的星空图，万千星辰在其中缓缓旋转。

最奇特的异象在于，当三种光芒同时照在水面上时，三光神水会散发出三种颜色的霞光——金色为日芒，银色为月华，紫色为星光。三种霞光交织缠绕，如同一匹华丽的锦缎在水面飘荡。

将一滴三光神水滴在掌心，它不会像普通水一样四散流开，而是凝聚成圆润的球形，在掌心中微微滚动，散发着温润的光泽。放在耳边倾听，可以听到若有若无的天籁之声，仿佛是日月星辰在低语。

## 功效

三光神水的功效之神奇，冠绝天下万水，乃是天地间排名前三的至宝神水。

**起死回生**：三光神水最著名的功效就是起死回生。无论伤势多严重，只要魂魄尚未完全消散，一滴三光神水便可吊住性命。若是肉身受损，以三光神水浸泡，可令伤处迅速愈合，甚至断肢也能重新生长出来。传说有修士被仇家打得形神俱灭，只剩一丝残魂，其师门以九滴三光神水施救，竟将此人从死亡边缘拉了回来。

**净化万物**：三光神水蕴含太阳真火的正阳之力、太阴月华的清冷之气以及周天星辰的浩瀚之威，三种力量完美融合，使得它对一切阴邪、毒瘴、魔气都有极佳的净化效果。一滴三光神水可净化方圆百里的魔气。上古时期的万魔大战后，仙界便是以三光神水清洗战场，才将漫天魔气尽数化解。

**增进修为**：修士服用三光神水后，可洗涤体内的杂质，净化灵根，提升修炼资质。更珍贵的是，三光神水中蕴含的星辰之力能够帮助修士感应周天星辰，领悟星辰之道。对于修炼星象类功法的修士而言，三光神水是无价之宝。

## 获取方式

三光神水无法人为炼制，只能依靠天地机缘自然形成。获取它的唯一方法就是在特定的时间、特定的地点守候。

**昆仑天池**：修真界中，已知最有可能产出三光神水的地方是昆仑山天池。每三百年的中秋之夜，日月星三光交汇于昆仑之巅，天池中便有可能凝结出三光神水。每次不过三五滴，且并非每个三百年都会出现。

**东海扶桑岛**：传言东海扶桑岛是太阳栖息的地方，那里的日出时刻，第一缕阳光与最后一缕月光交汇时，偶尔也会凝出三光神水。但扶桑岛周围有上古禁制，寻常修士无法靠近。

**守护妖兽**：三光神水凝聚之处，必有强大的守护者。最常见的是身具三种神兽血脉的"三光灵蛟"。此蛟并非凡种，而是传说中龙与凤、麒麟交配后产生的异种，通体透明如水晶，能操控光之力。三光灵蛟以三光神水为食，修为可达炼虚期，极为难缠。

另有一种名为"幻光蝶"的奇异灵虫，体长不过三寸，翅膀如水晶般透明，散落在三光神水周围。数量极多，一旦群起攻击，便是化神期修士也难以招架。

## 使用方法

**直接服用**：直接服用三光神水是最简单的方法。但不可贪多，普通修士一次一滴足矣，多了肉身承受不住光之法则的冲击。服用时需以灵力包裹，慢慢引入丹田，让身体逐渐吸收。

**炼丹入药**：三光神水是炼制"九转还魂丹""造化生息丹"等顶级疗伤丹药的必备材料。炼丹时以三光神水化药，可让药效提升数倍。尤其是九转还魂丹，有了三光神水，才真正有了让死者复生的功效。

**炼器淬火**：炼器时若以三光神水淬火，可大幅提升法宝的灵性与品质。特别是炼制光属性或星辰属性的法宝时，三光神水是无可替代的淬火材料。以此水淬炼的法宝，通体流转三色霞光，灵性十足，甚至有极小概率诞生器灵。

**布阵**：以三光神水为阵眼布置的"三光神水大阵"，可引日月星三光之力，形成一方修炼圣地。阵中修士修炼速度是外界的数倍。

## 相关传说

**观音玉净瓶**：传说观音菩萨的玉净瓶中装的便是三光神水。当年孙悟空大闹天宫时推倒了镇元大仙的人参果树，观音菩萨以玉净瓶中之水洒在树上，枯木便立即复活，枝叶繁茂如初。此水便是三光神水。

**瑶池琼浆**：西王母瑶池中的琼浆玉液，据说便是以三光神水为基酿制而成。每年蟠桃盛会上，众仙饮用的便是此酒，一杯可增千年修为。

**后羿射日**：传说后羿射落九只金乌后，金乌的残骸坠落大地，引燃无边大火。女娲于是从天池中取来三光神水，洒向凡间，大火遂灭。那些被三光神水浇过的地方，后来都变成了灵泉，成为修真界的一处处洞天福地。
