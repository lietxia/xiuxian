# 混沌石

> 品阶：神级八品 · 混沌之遗

## 诞生条件

混沌石诞生于天地初开之际。

盘古开天辟地，混沌初开，清阳之气上升为天，浊阴之气下沉为地。然而，并非所有的混沌之气都成功转化。有极少数混沌之气因为密度过高、质地过重，未能上升或下沉，而是凝结为固体——这便是混沌石。

混沌石是混沌的"遗骸"，是天地未能完全消化的残余物质。它蕴含最原始的混沌法则，是天地间最接近"道"的物质。

混沌石的形成条件极为苛刻：必须在天地初开时，混沌之气恰好凝结；凝结后必须被封存于混沌深处，不被后天灵气侵蚀。

混沌石成型之时，周围的空间会微微扭曲，如同一面镜子被弯曲。

## 外观特征

混沌石呈不规则形状，大小不一，小如拳头，大如磨盘。通体呈混沌之色——非青非白非黑，目光所及，似有万千色彩流转其中，却又无一色可名状。

混沌石的表面有天然的道纹，纹路如龙蛇蜿蜒，细看之下，竟演化出日月星辰、山河大地之相。每隔片刻，纹路自行变幻，重演一次开天辟地之景象。

将混沌石握于手中，会感到一股苍茫浩瀚之气自掌心渗入，仿佛触摸到了天地的源头。混沌石的重量极为奇特——有时轻如鸿毛，有时重逾山岳，取决于持有者与混沌石的"缘分"。

## 功效

**感悟混沌**：混沌石蕴含最原始的混沌法则，修士以神识探入其中，可感悟混沌从无到有的过程。此法对冲击最高境界有不可思议的助益。

**混沌之力**：混沌石可释放混沌之气，将一切物质回归到最原始的混沌状态。在战斗中，混沌石可化解一切法术攻击，将其化为虚无。

**开辟世界**：混沌石是开辟世界的核心材料。以混沌石为根基，可在体内或体外开辟一方小世界。

**返璞归真**：混沌石可让修士的灵力回归到最原始的混沌状态，不受任何属性限制，可化为任何属性的灵力。

## 获取方式

混沌石只存在于混沌深处或天地初开时的遗迹中。

**混沌秘境**：混沌秘境是天地初开时残留的混沌空间碎片，其中混沌石最为常见。但混沌秘境极为危险，混沌之气可侵蚀万物。

**盘古遗迹**：盘古开天辟地之处，据说藏有大量混沌石。但盘古遗迹的位置无人知晓，只有大机缘者才能找到。

**上古战场**：一些上古大能战斗时，会撕裂空间，露出混沌深处的混沌石。这些混沌石散落在战场遗迹中。

## 使用方法

**感悟混沌**：以神识探入混沌石中，感悟混沌从无到有的过程。此法对冲击最高境界有极大助益。

**炼化入体**：将混沌石纳入丹田，以混沌功法炼化。炼化后，修士可操控混沌之气，将一切物质回归混沌。

**开辟世界**：以混沌石为根基，可在体内或体外开辟一方小世界。此法需要极高的修为和大量的混沌石。

**炼器**：混沌石是炼制混沌级法宝的核心材料。以混沌石为主材炼制的法宝，蕴含混沌法则，威力无穷。

## 相关传说

**盘古开天**：盘古开天时，混沌初开，残余的混沌之气凝结为混沌石。盘古将最大的混沌石留在不周山，作为天柱的根基。

**鸿钧讲道**：道祖鸿钧在紫霄宫讲道时，曾以混沌石为媒介，向三千弟子演示混沌初开的景象。众弟子观之大悟，各自突破。

**混沌珠**：传说混沌珠便是以一块巨大的混沌石为核心炼制而成。混沌珠内蕴含三千世界，是混沌级法宝的巅峰之作。
