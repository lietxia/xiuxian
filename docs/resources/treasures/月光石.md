# 月光石

> 品阶：地级六品 · 映心之石

## 诞生条件

月光石诞生于月宫桂树的落叶。

广寒宫中有一棵万年月桂树，吴刚日日砍伐，桂树日日生长。桂树每隔百年会落下一片叶子，这些叶子从月宫飘落，坠入凡间。

桂叶在坠落过程中，吸收了沿途的月华，落地后又经万年月华浸润，最终化为一块晶莹剔透的奇石——这便是月光石。

月光石的形成需要三个条件：其一，必须是月宫桂树的落叶；其二，必须坠入灵气充沛之地；其三，必须经万年月华浸润方可成型。

月光石成型之时，坠落之地会被一片银色的月华笼罩，持续三天三夜。在此期间，月光石周围的生灵会陷入沉睡，做一场关于月亮的梦。

## 外观特征

月光石呈椭圆形，大如巴掌，通体呈乳白色，内部有一团流动的银色光晕。那光晕如同月亮的缩影，在石中缓缓流转，忽明忽暗。

将月光石对准月亮，石中的光晕会与天上的月亮产生共鸣，发出柔和的银光。此时若以神识探入石中，可看到月宫的景象——桂树、玉兔、嫦娥，历历在目。

月光石有一个奇特的特性：它能映照出持有者内心深处的情感。喜悦时石中光晕明亮，悲伤时光晕暗淡，愤怒时光晕泛红，恐惧时光晕泛紫。

## 功效

**映照人心**：月光石能映照出他人的真实意图。在谈判或对峙时，以月光石观察对方，可判断其言语是否真诚。

**照破虚妄**：月光石的光芒可照破一切幻术和伪装。在幻阵中，月光石的光芒可让阵中幻象烟消云散。

**宁神安眠**：月光石散发的月华可安抚神魂，帮助修士快速入定。在失眠或焦虑时，将月光石放在枕边，可安然入睡。

**滋养神魂**：月光石的月华可缓慢滋养神魂，长期佩戴可让神魂强度稳步提升。

## 获取方式

月光石散落在月宫桂树落叶的坠落之地。已知的产出地有三处：

一是广寒宫投影，位于昆仑山巅，是月宫在人间的投影。每逢月圆之夜，投影中偶尔会落下桂叶化成的月光石。

二是月桂谷，位于西牛贺洲，谷中生长着一棵月桂树的分支。这棵分支偶尔也会落叶，化为月光石。

三是嫦娥遗迹，位于南瞻部洲，传说嫦娥奔月前的居所。遗迹中散落着一些月光石，是嫦娥当年的收藏。

## 使用方法

**随身佩戴**：将月光石穿绳佩戴，可时刻保持神魂清明，抵御幻术侵扰。

**布阵**：以月光石为阵眼布置的"月华幻阵"，可制造逼真的幻象，迷惑入阵者。

**炼丹**：月光石是炼制"宁神丹"的主药。宁神丹可安抚神魂，帮助修士突破瓶颈时抵御心魔。

## 相关传说

**吴刚伐桂**：吴刚砍伐月桂树时，桂树的落叶偶尔会飘落凡间。这些落叶化为月光石，成为人间修士的至宝。

**嫦娥思念**：嫦娥奔月时，曾将一块月光石留给丈夫后羿。后羿思念嫦娥时，便对月饮酒，将月光石贴在胸口。月光石映照出后羿对嫦娥的思念，化作一道月光射向月宫。嫦娥在月宫中看到这道月光，也流下了眼泪。

**玉兔传书**：传说玉兔曾将一块月光石送给凡间的挚友，作为传信的媒介。只要在月光石上写字，字迹便会出现在月宫中的玉兔面前。
