# 风灵珠

> 品阶：天级四品 · 轻盈之珠

## 诞生条件

风灵珠的诞生，与九天罡风层中的风之精灵"巽风"有关。

九天之上，有一层永不停歇的罡风层。罡风层中生活着一种名为"巽风"的风之精灵。巽风无形无相，以罡风为食，以云精为饮，寿命长达万年。

当巽风寿终正寝时，其精魄会从九天坠落。在坠落过程中，精魄与沿途的云精融合，经过九天罡风的反复淬炼，最终凝结为一颗风灵珠。

风灵珠的形成需要"巽风精魄"与"云精"两个条件，且必须在九天罡风中淬炼万年方可成型。因此，风灵珠的数量极为稀少——每一万年，最多只形成数颗。

风灵珠成型之时，九天罡风层会短暂平息，形成一个"无风区"。这是罡风层中唯一平静的时刻，也是收集风灵珠的最佳时机。

## 外观特征

风灵珠大如龙眼，通体呈淡青色，近乎透明。珠体轻盈无比，几乎没有重量，放在掌心如同一缕微风。

风灵珠最为奇特之处在于它的形态并非固定不变。它会随着周围气流的流动而不断变化——有时呈球形，有时呈梭形，有时甚至化为一道细小的旋风在掌心旋转。

将风灵珠放在耳边，可听到风声呼啸，如同站在高山之巅。以神识探入珠中，可看到一片无边无际的天空，狂风在其中呼啸，云卷云舒。

## 功效

**御风之术**：风灵珠蕴含风之法则，持有者可操控风力。无论是召唤狂风、制造龙卷，还是御风飞行，皆可随心而动。修炼风属性功法的修士持之修炼，御风之术可提升十倍。

**风遁之术**：持有风灵珠的修士，可修炼"风遁之术"——化身清风，无形无相，瞬息千里。风遁之术在所有遁术中最为隐蔽，难以追踪。

**轻盈之体**：风灵珠可让修士的身体变得轻盈如风。持之修炼，身法速度大幅提升，且可在空中自由飞行，无需借助法宝。

**感知气流**：风灵珠可让持有者感知气流的细微变化。在战斗中，可通过感知气流的变化来预判敌人的攻击方向，从而提前闪避。

## 获取方式

风灵珠散落在九天罡风层中，极难收集。

**九天罡风层**：最直接的方式是飞上九天，进入罡风层寻找。但九天罡风凛冽无比，寻常修士根本无法承受。只有渡劫期以上的强者，才能在罡风层中短暂停留。

**巽风巢穴**：巽风在罡风层中筑巢，巢穴中偶尔能发现风灵珠。但巽风极为警觉，一旦感知到外人靠近，便会召唤罡风攻击。

**坠落之地**：风灵珠成型后，会从九天坠落。若能在风灵珠落地前接住，便可获得。但风灵珠的坠落毫无规律，且落地时会引发一场风暴，极难预测。

## 使用方法

**炼化入体**：以风属性功法将风灵珠纳入丹田，慢慢炼化。炼化后，修士可操控风力，且身体轻盈如风，可在空中自由飞行。

**镶嵌法宝**：将风灵珠镶嵌在风属性法宝上，可让法宝速度大幅提升，且附带"风刃"之能，攻击时可释放锋利的风刃。

**炼丹**：风灵珠是炼制"风行丹"的主药。风行丹服下后，修士可在短时间内获得极致的速度，甚至能化身清风，免疫物理攻击。

## 相关传说

**列子御风**：传说上古仙人列子御风而行，便是因为体内炼化了一颗风灵珠。列子凭借风灵珠的风之法则，可在空中自由飞行数月不落。

**风伯飞廉**：上古风伯飞廉的骨骼，据说便是由风灵珠凝聚而成。风伯死后，其骨骼化为无数风灵珠散落人间。

**鲲鹏展翅**：鲲鹏从北冥飞往南冥时，曾卷起无数风灵珠。这些风灵珠随鲲鹏一同飞行，最终散落在天地之间。传说得到鲲鹏散落的风灵珠，可获得鲲鹏的一部分飞行能力。
