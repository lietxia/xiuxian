# 灵液

> 品阶：地级四品 · 液态灵石

## 诞生条件

灵液诞生于灵脉深处的特殊环境。

灵脉深处的灵气浓度极高，在高压环境下，气态的灵气会液化形成灵液。这个过程类似于自然界中水蒸气凝结成水滴。

灵液的形成需要三个条件：其一，灵脉深处的灵气浓度必须达到临界值；其二，环境温度必须足够低；其三，必须有密封的空间，防止灵液蒸发。

灵液每百年才能凝结一小碗，因此比灵乳更为常见，但仍属珍贵。

灵液凝结之时，灵脉深处会传来"滴答"之声，如同水滴落入潭中。

## 外观特征

灵液呈无色透明，略带粘稠感，入口有淡淡的甘甜。高品质的灵液在光照下会折射出微弱的蓝光。

灵液的气息极为纯净——吸入一口，便觉神清气爽，疲劳尽消。灵液无需炼化，可直接被身体吸收，转化为灵力。

灵液有一个奇特的特性：它会自行挥发。在开放环境中，灵液会缓慢蒸发，重新化为气态灵气。因此，灵液必须密封保存。

## 功效

**快速补充灵气**：灵液可快速补充消耗的灵气。服用一滴灵液，可让筑基期修士的灵力瞬间恢复三成。

**炼丹溶剂**：灵液是炼丹的最佳溶剂。以灵液溶解灵药，可让药效充分释放，大幅提升丹药的品质。

**淬火介质**：灵液是炼器的最佳淬火介质。以灵液淬火，可让法宝的灵性大幅提升。

**浇灌灵植**：灵液可浇灌灵植，加速灵药的生长。以灵液浇灌的灵药，生长速度提升十倍。

## 获取方式

灵液多产于灵脉深处的灵泉中。

**灵泉采集**：灵泉是灵脉灵气外溢至地表形成的水泉，泉水中含有灵液。但灵泉中的灵液浓度极低，需要大量提纯才能获得纯净的灵液。

**聚灵阵压缩**：以聚灵阵将气态灵气压缩为液态，可人工制造灵液。但此法消耗极大，得不偿失。

**上古遗迹**：一些上古遗迹的灵泉中，可能存有高浓度的灵液。

## 使用方法

**直接服用**：直接服用灵液是最简单的方法。一次服用一滴，可快速补充灵气。

**炼丹溶剂**：以灵液溶解灵药，可让药效充分释放。

**淬火介质**：以灵液淬火，可让法宝的灵性大幅提升。

**浇灌灵植**：以灵液浇灌灵植，可加速灵药的生长。

## 相关传说

**瑶池琼浆**：西王母瑶池中的琼浆玉液，据说便是以灵液为基酿制而成。每年蟠桃盛会上，众仙饮用的便是此酒，一杯可增千年修为。

**灵液化泉**：传说灵液积累到一定程度，会化为灵泉。灵泉是灵脉灵气外溢至地表形成的水泉，泉水蕴含浓郁灵气。

**仙人之泪**：传说仙人流下的眼泪便是灵液。仙人悲悯苍生，流下的眼泪落地化为灵泉，滋养万物。
