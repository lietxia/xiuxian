# 太阳精石

> 品阶：天级五品 · 日华之精

## 诞生条件

太阳精石，本是太阳星表面的一部分。

太阳星并非永恒不灭。在漫长的岁月中，太阳星表面偶尔会爆发"日冕风暴"，将表面的碎片抛射到宇宙中。这些碎片在虚空中飞行，绝大多数会在宇宙射线中消融，但极少数碎片会被地球的引力捕获，坠入凡间。

碎片在穿越九重天层时，会与九天罡风摩擦，被天火淬炼，最终化为拳头大小的陨石坠落地面。这便是太阳精石。

太阳精石的形成需要极为苛刻的条件：碎片必须足够大，才能在穿越九重天时不被烧毁；碎片必须恰好坠入有灵气的区域，才能保住灵性；碎片坠落后必须被深埋地底，才能避免灵气散失。

太阳精石坠落之时，会引发一场大火，焚烧方圆百里。火熄之后，坠落之地会形成一个巨大的陨石坑，坑中便是太阳精石。

## 外观特征

太阳精石呈不规则形状，通体呈金黄色，表面有无数细密的裂纹，裂纹中透出暗红色的光芒。珠体温度极高，方圆十丈内的空气都会被烤得扭曲变形。

将太阳精石置于暗处，它会散发出耀眼的金色光芒，如同一颗微落的小太阳。以神识探入珠中，可看到一片火海，火焰的中心隐约可见一只三足金乌的虚影。

太阳精石有一个奇特的特性：它会自行吸收日光。在白天，它的温度和亮度会大幅提升；在夜晚，它的光芒会减弱，但温度不变。

## 功效

**太阳真火**：太阳精石蕴含纯粹的太阳真火之力，修炼火属性功法的修士持之修炼，可将自身真火提升为太阳真火，威力提升十倍以上。

**日华淬体**：以太阳精石散发的日光淬炼肉身，可让肉身强度大幅提升。日华淬炼后的肉身，不仅坚硬如铁，还能免疫大部分火焰攻击。

**驱散阴邪**：太阳精石的日光是一切阴邪之物的克星。鬼修、邪修、魔物在日光下都会受到极大压制。

**光合作用**：太阳精石的日光可促进灵药生长。将太阳精石放在灵田上方，可让灵药吸收日华精华，品质大幅提升。

## 获取方式

太阳精石散落在世界各地的陨石坑中。已知的产出地有三处：

一是火焰山，位于西牛贺洲，是规模最大的太阳精石坠落之地。山中有数十块太阳精石，但周围火焰终年不息，非火属性修士无法靠近。

二是炎帝谷，位于南瞻部洲，传说神农氏曾在此采集太阳精石炼丹。谷中太阳精石已被采集殆尽，但偶尔还能发现小块碎片。

三是日蚀沙漠，位于北俱芦洲，是太阳精石最密集的坠落之地。沙漠中太阳精石随处可见，但沙漠温度极高，寻常修士根本无法生存。

## 使用方法

**炼化入体**：以火属性功法将太阳精石纳入丹田，慢慢炼化。炼化后，修士可操控太阳真火，且肉身免疫火焰攻击。但太阳真火极为霸道，需以水属性灵物调和。

**镶嵌法宝**：将太阳精石镶嵌在火属性法宝上，可让法宝品质提升一个品阶，且附带"太阳真火"之能。

**炼丹**：太阳精石是炼制"太阳丹"的主药。太阳丹服下后，修士可在短时间内获得太阳真火之力，实力暴增。

## 相关传说

**后羿射日**：后羿射落九只金乌后，金乌的残骸坠落大地，化为无数太阳精石。后羿将这些太阳精石收集起来，炼制了九支"落日神箭"。

**夸父逐日**：夸父追赶太阳时，曾捡起一块太阳精石。太阳精石的热量让夸父口渴难耐，他喝干了黄河和渭河的水，仍不解渴，最终渴死于途中。

**十日并出**：传说太阳精石是太阳星的碎片，蕴含着太阳的一部分力量。若将十块太阳精石聚在一起，可重现"十日并出"的浩劫。
