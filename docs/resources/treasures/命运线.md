# 命运线

> 品阶：神级六品 · 天机之丝

## 诞生条件

命运线诞生于命运长河。

天地间有一条无形的河流，名为"命运长河"。命运长河中流淌的不是水，而是万事万物的命运轨迹。每一个生灵、每一件物品、每一个事件，都在命运长河中有一条对应的"线"。

命运长河的河面上，偶尔会飘落一些丝线。这些丝线是从命运长河中自然脱落的，它们脱离了长河的束缚，化为独立的个体——这便是命运线。

命运线的形成需要特殊的机缘：只有当命运长河发生"涨潮"时，才会有丝线飘落。命运长河涨潮的时机不定，可能数万年一次，也可能数千年一次。

命运线飘落之时，天地间会响起一种奇异的声响——非风非雷，而是一种低沉的嗡鸣，如同命运在低语。

## 外观特征

命运线呈半透明状，细如发丝，若隐若现，常人难以察觉。只有修炼命运大道的修士，才能以"命运之眼"看到命运线的存在。

命运线的颜色并非固定不变——它会随着所连接的事物的命运变化而变化。连接好运者呈金色，连接厄运者呈黑色，连接平凡者呈灰色。

将命运线握在手中，会感到一阵微微的颤动，如同握住一条活物。命运线会自行颤动，颤动的频率与所连接事物的命运变化速度成正比。

## 功效

**窥探天机**：命运线可让持有者窥探天机，预知未来。将命运线贴在眉心，以神识探入，可看到命运长河中的景象，从而预知即将发生的事情。

**推演命运**：命运线可帮助修士推演他人的命运。只需取他人的一滴血或一根头发，与命运线接触，便可看到此人未来的命运轨迹。

**改变命运**：命运线最为逆天的功效，是它可以改变命运。通过拨动命运线，可以改变事物的发展方向。但改变命运会遭受天道的反噬，反噬的大小与改变的幅度成正比。

**斩断命运**：命运线可以斩断。斩断一个人的命运线，可以让此人从命运长河中消失——天道将不再关注此人，此人将不受命运约束。但斩断命运线的代价极大，需要消耗大量的寿元。

## 获取方式

命运线只存在于命运长河的河畔。

**命运长河河畔**：最直接的方式是找到命运长河的入口，在河畔等待命运线飘落。命运长河的入口位于"天机阁"的禁地，由天机阁世代守护。

**命运潮汐**：命运长河涨潮时，会有大量命运线飘落在天地各处。此时是收集命运线的最佳时机。

**大能遗物**：一些修炼命运大道的上古大能，其遗物中可能藏有命运线。如天机子的"天机盘"、袁天罡的"推背图"等。

## 使用方法

**窥探天机**：将命运线贴在眉心，以神识探入，可看到命运长河中的景象。此法消耗极大，每次窥探都会消耗寿元。

**推演命运**：取他人的血或头发，与命运线接触，可推演此人未来的命运轨迹。推演越详细，消耗越大。

**改变命运**：以命运线连接目标，拨动命运线，可改变事物的发展方向。但改变命运会遭受天道反噬。

**斩断命运**：以特殊手法斩断命运线，可让目标从命运长河中消失。此法代价极大，非万不得已不可使用。

## 相关传说

**天机阁**：天机阁是修炼命运大道的第一宗门，其镇宗之宝"天机盘"中藏有三千条命运线。天机阁凭借这些命运线，可推演天下大势，预知未来。

**袁天罡推背图**：唐代袁天罡以命运线推演天下大势，写下了《推背图》。书中预言了后世数千年的兴衰更替，无一不验。

**命运三女神**：上古时期有三位命运女神，分别掌管过去、现在、未来。她们以命运线编织众生的命运，无人能逃脱她们的掌控。
