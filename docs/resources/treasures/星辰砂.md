# 星辰砂

> 品阶：天级五品 · 星辰至宝

## 诞生条件

星辰砂的诞生，与天上的星辰息息相关。

茫茫宇宙之中，有无数星辰在虚空中运行。这些星辰并非死寂的岩石，而是蕴含了天地法则的载体。每一颗星辰都拥有自己的生命与意志，它们在虚空中按照天道轨迹运行，吐纳宇宙能量，散发出星光与星力。

然而星辰也有寿命。当一颗星辰走到生命的尽头时，它会崩溃、碎裂，化作无数碎屑散落在宇宙中。这些碎屑在虚空中漂浮，被星光照耀、被星力浸染，经历数万年的淬炼，最终化为细小的沙粒——这便是星辰砂的雏形。

并非所有星辰碎裂后的碎屑都能成为星辰砂。只有那些蕴含了最纯星辰之力的核心碎屑，才能够在漫长岁月的淬炼中保留下来。而更多的碎屑则会在虚空中渐渐失去灵性，最终化为普通的宇宙尘埃。

星辰砂形成之后，会在虚空中漂浮，随着星辰运行的方向不断移动。只有当它恰好落入一颗有生命的世界，被世界的大气层捕获，才会坠落到地面上。这个过程同样需要极深的机缘——绝大多数星辰砂会在穿越大气层时被焚烧殆尽，只有其中最坚韧的那一部分才能坠落到地面。

## 外观特征

星辰砂的形态极为独特，与凡间的一切沙土都有着天壤之别。

每一粒星辰砂不过米粒大小，却重逾金石。普通的沙粒轻如鸿毛，而一粒星辰砂却有三五斤之重——这是因为它的内部凝聚了极其庞大的星力，密度远超寻常物质。

星辰砂的表面并不光滑，而是布满了无数细小的切面，如同经过精心切割的钻石一般。这些切面在光线照射下，会反射出璀璨的星芒，每一道星芒的颜色各不相同——有的呈蓝色，有的呈金色，有的呈紫色，甚至有的呈黑色。

放在掌中细看，星辰砂的内部似乎有无数星光在流动，如同一片微缩的星海。如果将星辰砂放在黑暗处，它会自行发光，光芒清冷而明亮，如同夜空中的星星。数十粒星辰砂聚在一起，发出的光芒足以照亮一间屋子。

最有意思的是，星辰砂对天上的星辰有一种天然的感应。在有星星的夜晚，将星辰砂放在露天之处，它会与天上的某颗星辰产生共鸣，发出忽明忽暗的闪烁，频率与那颗星辰的光芒闪烁完全一致。有修士据此推测，每一粒星辰砂都与天上的一颗星辰有着千丝万缕的联系。

## 功效

星辰砂最珍贵的，是其蕴含的纯正星辰之力。

**引动星力**：星辰砂可以引动周天星辰的星力为己用。修炼星辰类功法的修士，以星辰砂为媒介，可以更轻松地沟通天上的星辰，借星光来淬炼己身。一颗星辰砂在手，吸收星力的效率提升数倍。传说上古时期的周天星斗大阵，其阵基便是以万千星辰砂铺就的星台。

**淬炼肉身**：星辰之力不仅可用于修炼，还可用于淬炼肉身。将星辰砂以真火熔炼，化为星尘之露，涂抹于体表，星光会渗透入骨髓经脉，淬炼筋骨。此法类似于佛门的金刚不坏体，炼至大成，肉身坚硬如星辰陨铁，普通法宝难以伤之分毫。

**布阵之宝**：星辰砂是布置星辰类大阵的绝佳材料。无论是周天星斗大阵、北斗七星阵，还是二十八宿大阵，都离不开星辰砂作为阵基。以星辰砂布置的阵法，可以引动天上的星辰之力加持，威力远非普通阵法可比。

**占星卜卦**：星辰砂对天机推演有奇效。高阶占星师在推演天机时，会在星盘上洒下一把星辰砂。星辰砂的分布与闪烁，能够反映出天道运转的轨迹，帮助占星师更准确地预知未来。

## 获取方式

星辰砂的获取，不外乎以下几种途径：

**流星坠落**：最常见的方式是在流星雨后，到流星坠落的区域寻找。流星在穿越大气层时虽然大部分被烧毁，但有时会有一些核心碎屑残留下来。不过流星雨后能找到的星辰砂数量极少，一次大型流星雨能收获的也不过一小撮。

**星空秘境**：一些连接着域外星空的秘境中，漂浮着大量的星辰砂。这些秘境是宇宙碎屑的汇聚之地，星辰砂在其中如同沙尘一般常见。但星空秘境通常位于空间裂缝的深处，需大虚空术方能进入。且秘境中危险重重，有虚空生物出没。

**上古大能遗物**：许多上古大能在修行星辰大道时，会收集大量的星辰砂。他们的洞府或墓葬中，往往存有成罐的星辰砂。找到这些遗迹，便等于发现了宝藏。

**守护妖兽**：星辰砂对星兽类的妖兽有致命的吸引力。最常见的是"星鳞兽"，此兽通体覆盖着如同星辰般闪烁的鳞甲，以吞食星辰砂为生。星鳞兽体内会有未消化的星辰砂，击杀后可从其腹中取出数量可观的星辰砂。然而星鳞兽实力极强，成年星鳞兽的战力堪比合体期修士。

还有一种名为"虚空星蝶"的灵虫，它们以星辰砂筑巢，巢穴往往建在星空秘境的深处。找到虚空星蝶的巢穴，就意味着找到了大量星辰砂。但此虫群起攻击时，便是大能修士也要退避三舍。

## 使用方法

**直接吸收**：将星辰砂握于手中，运转功法，吸收其中的星力。这是最基础也最简单的用法。一粒星辰砂中蕴含的星力，可供金丹期修士修炼百日。但直接吸收的效率并不高，会浪费三成以上的星力。

**炼入法宝**：星辰砂是炼制星辰属性法宝的最佳材料。将星辰砂熔入飞剑中，可让飞剑带上星辰之力，攻击时带有星芒附加伤害。炼入法衣中，可使法衣在星光下自行恢复灵性。最上乘的用法是以星辰砂炼制"星辰道袍"，穿上此袍可在夜间引动星光入体，无时无刻不在淬炼肉身。

**炼丹入药**：星辰砂难以直接入药——因为其质地坚硬，难以消化。通常的方法是先以真火将星辰砂熔炼为星辰液，再与其他灵药配伍。星辰液是炼制"星元丹"的主药，星元丹服后可壮大元神，让修士对星辰法则的感悟更加敏锐。

**布阵**：星辰砂是布阵的最佳辅助材料。布置护山大阵时，在阵基中埋入一把星辰砂，可在夜间引动星光为阵法补充能量。一些超级大宗的护山大阵，阵基中埋了不下千斤星辰砂，每至夜晚，整个宗门便被星光笼罩，宛如仙境。

## 相关传说

**天罡地煞**：相传上古时期，天庭曾以一百零八颗星辰砂为核心，炼制成了一百零八面星辰幡。三十六面天罡幡对应天罡星，七十二面地煞幡对应地煞星。此幡布下天罡地煞大阵，可困住大罗金仙。后此阵在封神大战中使用过一次，令敌方数百万大军全军覆没，从此星辰砂的名声威震三界。

**星泪传说**：传说有一对相爱的修士，妻子修炼星辰大道飞升天界，丈夫却因资质所限滞留人间。妻子在天上思念丈夫，她的眼泪化作星光照耀人间。后来妻子自碎星辰，化作漫天星辰砂洒向人间。丈夫以这些星辰砂炼成一件法宝，日夜对着法宝呼唤妻子的名字。百年后法宝化作人形，正是妻子的模样——星辰有灵，竟以这种方式让一对有情人重逢。

**紫微帝星**：相传紫微帝星坠落时，曾洒下九粒紫色的星辰砂。这九粒紫星砂被九位有缘人得到，后来这九人无一例外都成为了三界中的顶级存在。其中一人以紫星砂炼成紫微剑，一剑可斩断星辰；另一人以紫星砂炼成紫微帝袍，穿上后万法不侵。这九粒紫星砂至今仍有四粒不知下落，成为修真界中津津乐道的话题。
