# 冰灵珠

> 品阶：天级四品 · 极寒之珠

## 诞生条件

冰灵珠诞生于北海最深处的"玄冥深渊"。

北海之底，有一处深达十万丈的海沟，名为玄冥深渊。此处终年不见阳光，海水温度低到极致，连灵气都会被冻结。在深渊最底部，有一层万年不化的玄冰，名为"冰魄"。

冰魄并非普通的冰，而是水之法则在极寒条件下凝聚而成的结晶体。它每千年生长一丝，经过亿万年的积累，才形成数丈大小的冰魄矿脉。

当冰魄矿脉生长到一定程度，会与从海面渗透下来的月华之精相遇。月华至阴至柔，冰魄至寒至坚，二者融合后，经过数万年的孕育，最终凝结为冰灵珠。

冰灵珠的形成需要"冰魄"与"月华"两个条件，且必须在绝对黑暗、绝对寒冷的环境中方可成型。因此，天地间的冰灵珠极为稀少。

冰灵珠成型之时，玄冥深渊会爆发一场"寒潮"，寒气从深渊涌出，将方圆千里的海域冻结成冰。

## 外观特征

冰灵珠大如鸽卵，通体呈冰蓝色，近乎透明。珠体表面覆盖着一层薄薄的霜花，霜花的形状随时间不断变化，永不停歇。

将冰灵珠托于掌心，会感到一股刺骨的寒气从珠中透出。修为不足者，手掌会瞬间被冻伤。珠体坚硬无比，却有一个奇特的特性：它会吸收周围的热量。在冰灵珠附近，温度会骤降到冰点以下。

以神识探入珠中，可看到一片冰封的天地——雪花飘落，冰川连绵，万物寂静。珠内隐约可见一只微缩的"冰魄精灵"在翩翩起舞。

## 功效

**极寒之力**：冰灵珠蕴含至极的寒气，修炼冰属性功法的修士持之修炼，可将自身灵力提升为"玄冥寒气"，温度可低至绝对零度，可冻结一切物质。

**冰封之术**：持有冰灵珠的修士，可施展"冰封之术"——将敌人冻结在冰块中，使其无法动弹。冰封的强度与修士的修为相关，高深者可冻结一方天地。

**静心凝神**：冰灵珠的寒气可让修士保持绝对的冷静。在闭关突破的关键时刻，冰灵珠可帮助修士压制心魔、保持心神清明。

**防腐保鲜**：冰灵珠可让一切物质保持在新鲜状态。将灵药放在冰灵珠旁，可万年不腐。

## 获取方式

冰灵珠只存在于极寒之地。已知的产出地有三处：

一是北海玄冥深渊，由上古冰龙"玄冥"守护。玄冥龙修为已达渡劫期，且在海中实力倍增。

二是北冥天池，位于昆仑山巅的万年寒潭底部。天池周围有上古冰阵守护，非冰属性修士无法靠近。

三是广寒宫的"冰魄园"，嫦娥仙子种植的各种冰属性灵植，其土壤中偶尔能发现冰灵珠。

## 使用方法

**炼化入体**：以冰属性功法将冰灵珠纳入丹田，慢慢炼化。炼化后，修士的灵力自带极寒属性，且可在体内形成一颗"冰魄种子"，源源不断地产生寒气。但冰灵珠的寒气极为霸道，需以火属性灵物调和，否则会冻伤经脉。

**镶嵌法宝**：将冰灵珠镶嵌在冰属性法宝上，可让法宝品质提升一个品阶，且附带"玄冥寒气"之能，攻击时可冻结敌人。

**炼丹**：冰灵珠是炼制"冰魄丹"的主药。冰魄丹服下后，修士可在短时间内获得极寒之力，甚至能冻结一条河流。

## 相关传说

**玄冥镇海**：传说北海之中有一条上古玄冥龙，它守护着玄冥深渊中的冰魄矿脉。玄冥龙每万年才会苏醒一次，苏醒时会引发一场席卷北海的寒潮。

**嫦娥奔月**：嫦娥奔月时，曾带走一颗冰灵珠。月宫之所以终年寒冷，就是因为冰灵珠的寒气所致。嫦娥以冰灵珠的寒气炼制"广寒丹"，服之可保持容颜不老。

**冰雪精灵**：传说冰灵珠中封印着一只冰雪精灵。这只精灵是冰之法则的化身，只有心地纯净之人才能唤醒它。被唤醒的冰雪精灵会成为修士的灵宠，操控冰雪，威力无穷。
