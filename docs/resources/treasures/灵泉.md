# 灵泉

> 品阶：地级四品 · 灵脉之眼

## 诞生条件

灵泉诞生于灵脉与地表的交汇之处。

灵脉是大地灵气的通道，灵气在灵脉中流动。在某些地方，灵脉靠近地表，灵气会从地表的裂缝中喷涌而出，形成泉水——这便是灵泉。

灵泉的形成需要三个条件：其一，灵脉必须靠近地表；其二，地表必须有裂缝或通道，让灵气得以溢出；其三，必须有水源，让灵气与水融合。

灵泉的形成没有固定的时间，可能数千年，也可能数万年。

灵泉形成之时，地表会涌出清澈的泉水，泉水散发着淡淡的灵雾。

## 外观特征

灵泉的泉水清澈见底，散发着淡淡的灵雾。泉眼周围的灵气浓度远超普通区域，是建立山门、开辟药园的理想之地。

灵泉的泉水入口甘甜，如同琼浆玉液。一口灵泉入腹，会感到一股温暖的气息在体内流转。

灵泉有一个奇特的特性：它会自行调节温度。冬天温暖，夏天清凉，四季不变。

## 功效

**日常饮用**：灵泉可日常饮用，补充灵气。长期饮用灵泉，可改善体质，提升修炼资质。

**药灌溉**：灵泉可灌溉灵药，加速灵药的生长。以灵泉浇灌的灵药，品质远超普通灵药。

**炼丹用水**：灵泉是炼丹的最佳用水。以灵泉炼丹，可让丹药的品质大幅提升。

**沐浴洗髓**：以灵泉沐浴，可洗髓伐毛，改善体质。

## 获取方式

灵泉是天然形成的灵脉节点，无法人为制造。

**地脉勘探**：通过地脉勘探术找到灵脉的位置，然后寻找灵泉。

**风水望气**：风水师可通过观察山川地势来推测灵泉的位置。

**机缘巧合**：有些灵泉会因为地震或地壳变动而暴露在地表，被有缘人发现。

## 使用方法

**日常饮用**：直接饮用灵泉水，可补充灵气。

**药园灌溉**：以灵泉灌溉灵药，可加速灵药的生长。

**炼丹用水**：以灵泉炼丹，可让丹药的品质大幅提升。

**沐浴洗髓**：以灵泉沐浴，可洗髓伐毛。

## 相关传说

**瑶池**：西王母的瑶池，据说便是一口巨大的灵泉。瑶池中的灵泉蕴含仙气，饮用后可长生不老。

**桃花源**：陶渊明笔下的桃花源，据说便是一处被灵泉滋养的世外桃源。桃花源中的居民长期饮用灵泉，人人长寿，无病无灾。

**灵泉化形**：传说灵泉积累到一定程度，会诞生灵智，化为"灵泉精灵"。灵泉精灵形如少女，通体透明，可操控水流。
