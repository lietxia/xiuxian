# 灵晶

> 品阶：地级五品 · 灵气之晶

## 诞生条件

灵晶诞生于灵脉核心处。

灵脉核心的灵气浓度极高，在高压环境下，气态的灵气会直接跳过液态阶段，凝华成固态的晶体——这便是灵晶。

灵晶的形成需要三个条件：其一，灵脉核心的灵气浓度必须达到极致；其二，环境温度必须极低；其三，必须有足够的结晶时间。

灵晶每千年才能生长一寸，因此极为珍贵。一条十万年的灵脉，核心处也不过生长出数尺长的灵晶。

灵晶生长之时，灵脉核心会发出微弱的光芒，如同一颗心脏在跳动。

## 外观特征

灵晶呈六棱柱状，通体透明，内含流动的光晕。高品质的灵晶内部可见清晰的灵气漩涡，光芒璀璨。

将灵晶放在掌心，会感到一股清凉的气息从晶中透出。灵晶无需炼化，可直接吸收其中的灵气。

灵晶有一个奇特的特性：它会自行吸收周围的灵气。将灵晶放在灵气充沛的地方，它的体积会缓慢增长。

## 功效

**法宝核心**：灵晶是炼制法宝的能量核心。以灵晶为核心炼制的法宝，灵气充沛，威力强大。

**阵法阵眼**：灵晶是大型护山大阵的阵眼材料。以灵晶为阵眼的阵法，威力远超普通阵法。

**突破辅助**：灵晶蕴含的灵气极为纯净，可辅助高阶修士突破瓶颈。

**炼丹药引**：极少数顶级丹药需要灵晶作为药引，以激发药性。

## 获取方式

灵晶多产于灵脉核心地带，需深入地下开采。

**灵脉开采**：通过地脉勘探术找到灵脉核心，然后挖掘进入。但灵脉核心的温度和压力极高，非金丹期修士无法承受。

**灵矿开采**：某些特殊的灵矿中天然存在灵晶矿层，可直接开采。

**上古遗迹**：一些上古遗迹的灵脉中可能存有灵晶。

## 使用方法

**法宝核心**：以灵晶为核心，辅以其他材料，可炼制法宝。

**阵法阵眼**：以灵晶为阵眼，可布置大型护山大阵。

**直接吸收**：将灵晶握于手中，可直接吸收其中的灵气。

**炼丹药引**：在炼丹时加入灵晶粉末，可激发药性。

## 相关传说

**灵晶之心**：传说每一条灵脉的核心处，都有一颗"灵晶之心"。灵晶之心是灵脉的灵魂，掌控着灵脉的灵气流动。得到灵晶之心，便可控制整条灵脉。

**水晶宫**：东海龙宫的水晶宫，据说便是以灵晶为主材建造而成。水晶宫的墙壁和柱子上镶嵌着无数灵晶，将龙宫照得如同白昼。

**灵晶化形**：传说灵晶积累到一定程度，会诞生灵智，化为"灵晶精灵"。灵晶精灵通体透明，如同一尊水晶雕像，可操控灵气。
