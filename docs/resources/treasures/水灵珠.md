# 水灵珠

> 品阶：天级四品 · 水之精魄

## 诞生条件

水灵珠的诞生，源于上古水神共工的悲歌。

上古时期，共工与颛顼争帝失败，怒而触不周山。天柱折，地维绝，天倾西北，地陷东南。共工在撞击中身负重伤，一滴神血从伤口飞出，落入天河之中。

这滴神血蕴含共工对天道的愤怒与不甘，与天河之水融合后，产生了不可思议的变化。神血中的水之法则与天河的至柔之水相互激荡，经过数万年的凝聚，最终化为一颗水灵珠。

水灵珠的形成需要"神血"与"天河水"两个条件，因此天地间的水灵珠极为稀少。据《上古神器志》记载，自共工触山以来，只形成了三颗水灵珠。

水灵珠成型之时，天河之水会倒灌人间，引发一场大洪水。同时，水灵珠周围会形成一片"弱水领域"——任何物体落入其中都会沉没，连羽毛都不浮。

## 外观特征

水灵珠大如龙眼，通体呈深蓝色，内部似有海水在翻涌。珠体表面不断有水珠凝结又消散，循环往复，永不停歇。

将水灵珠托于掌心，会感到一股清凉的气息渗入体内，如同浸泡在清泉之中。珠体看似坚硬，按压时却有弹性，如同水球。

水灵珠最为奇特之处在于它的重量会随环境变化：在干燥处轻如鸿毛，在水中则重逾万斤。以神识探入珠中，可听到海浪拍岸的声音，以及共工愤怒的咆哮。

## 功效

**控水之术**：水灵珠蕴含共工的水之法则，持有者可操控天下万水。无论是江河湖海，还是雨水霜雪，皆可随心而动。修炼水属性功法的修士持之修炼，控水之术可提升十倍。

**弱水护身**：水灵珠可在修士身周形成一层"弱水护盾"。这层护盾无形无质，却能化解一切攻击——无论是法术还是物理攻击，落入弱水护盾中都会被消解于无形。

**净化之能**：水灵珠蕴含天河至柔之水，可净化一切污秽与毒素。无论是魔气、瘴气还是剧毒，以水灵珠浸泡后的清水洗涤，皆可化解。

**感应水脉**：水灵珠能感应天下水脉的走向。持有者可轻易找到地下暗河、灵泉、水脉节点，是寻找水属性资源的最佳法器。

## 获取方式

水灵珠散落于天下水脉之中，极难寻找。

**天河遗迹**：传闻在昆仑山之巅，有一处通往天河的遗迹。天河干涸后，其中一颗水灵珠便留在了遗迹深处。但遗迹周围有共工残魂守护，实力堪比大罗金仙。

**东海海眼**：东海最深处的"归墟海眼"中，据说藏有一颗水灵珠。海眼是天下万水之归处，水压极强，寻常修士根本无法靠近。

**共工之墓**：共工陨落后，其陵墓建在水底深处。最后一颗水灵珠便陪葬于墓中。但共工之墓的位置无人知晓，只有水灵珠之间才能相互感应。

## 使用方法

**炼化入体**：将水灵珠纳入丹田，以水属性功法炼化。炼化后，修士可操控天下万水，且肉身化为"水体"，受到物理攻击时身体会化为水流散开，不受伤害。

**布阵**：以水灵珠为阵眼布置的"天河倒悬阵"，可引天河之水从天而降，将方圆百里化为泽国。阵中水属性修士实力倍增，火属性修士则被大幅削弱。

**炼丹**：水灵珠是炼制"水神丹"的主药。水神丹服下后，修士可在短时间内获得共工的一部分控水之力，甚至能召唤天河之水对敌。

## 相关传说

**共工遗恨**：传说共工触山后，其神血化为水灵珠，其中蕴含了他对天道的不甘。得到水灵珠的修士，会在梦中听到共工的悲歌，感受到那股怒触天柱的决绝。

**大禹治水**：大禹治水时，曾得到一颗水灵珠。他凭借水灵珠的控水之力，疏导九河，平定水患。治水成功后，大禹将水灵珠归还天河，以示不贪神力。

**精卫填海**：炎帝之女女娃溺于东海，化为精卫鸟。传说精卫鸟衔石填海时，曾得到水灵珠的助力。水灵珠被精卫的执念感动，助她将海水一寸寸填平。
