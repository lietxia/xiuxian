# 金灵珠

> 品阶：天级四品 · 杀伐之珠

## 诞生条件

金灵珠非天地自然孕育，而是后天杀伐之气的产物。

太古时期，神魔大战，无数神兵利刃在战场上崩毁碎裂。那些饮过神血、染过仙魂的兵刃碎片，其金之精华渗入大地，与战场上弥漫的杀伐之气、战死者的执念相互纠缠。经过数十万年的沉淀，金气与执念逐渐凝聚，最终化为一颗浑圆的金灵珠。

金灵珠的形成条件极为苛刻：其一，战场必须足够惨烈，陨落者至少百万以上；其二，战场中必须有大量金属性神兵崩毁；其三，战场遗迹须被深埋地底，不受风雨侵蚀，方能保住金气不散。

金灵珠成型之时，天地间会响起金铁交鸣之声，方圆千里的金属器物都会微微颤鸣，如同在朝拜君王。

## 外观特征

金灵珠大如鸽卵，通体呈暗金色，表面布满细密的裂纹。那些裂纹并非瑕疵，而是当年兵刃碎裂时留下的痕迹，每一道裂纹都对应一柄崩毁的神兵。

将金灵珠置于掌心，会感到一股刺骨的锋锐之气从珠中透出，修为不足者，手掌会被割出血痕。珠体沉重异常，看似不过鸽卵大小，却重达千斤。

以神识探入珠中，可听到无数金铁交鸣与喊杀之声，那是太古战场残留的回响。珠内隐约可见无数兵刃虚影在厮杀碰撞，永不停歇。

## 功效

**杀伐之力**：金灵珠蕴含纯粹的杀伐之气，修炼金属性功法的修士持之修炼，可将杀伐之气融入灵力，使攻击威力倍增。普通金属性法术在金灵珠加持下，锋锐程度可提升三到五倍。

**兵魂共鸣**：金灵珠能与天下金属性法宝产生共鸣。持有金灵珠的修士，可同时操控的金属性法宝数量是常人的十倍，且每一件法宝的威力都会得到增幅。

**淬炼锋刃**：将金灵珠浸泡在水中，以溶液擦拭兵刃，可让凡铁化为神兵。以金灵珠溶液淬炼法宝，可使法宝的锋锐度大幅提升，甚至能在法宝表面形成一层"金煞"，触之即伤。

## 获取方式

金灵珠只存在于太古战场遗迹深处。已知的产出地有三处：一是涿鹿之野的蚩尤战冢，深埋地底三千丈；二是封神战场的牧野遗迹，被阐教以阵法封印；三是天庭与阿修罗的远古战场，漂浮在虚空乱流中。

金灵珠周围必有"兵煞守护"——那是战死者的怨念与金气融合而成的煞灵，形如披甲武士，手持残兵，战力堪比大乘期修士。兵煞没有灵智，只有战斗本能，会攻击一切靠近金灵珠的活物。

## 使用方法

**炼化入体**：以真火熔炼金灵珠，将金之精华纳入丹田。炼化后，修士的灵力自带锋锐属性，举手投足间可发出金煞之气。但金煞过于霸道，需以木属性灵物调和，否则会损伤经脉。

**镶嵌法宝**：将金灵珠镶嵌在金属性法宝上，可让法宝品质提升一个品阶，且附带"破甲"之能，可穿透同阶防御法宝。

**布阵**：以金灵珠为阵眼布置的"金煞杀阵"，阵中金气化为无数兵刃虚影，可绞杀阵内一切生灵。

## 相关传说

**蚩尤遗珠**：传说蚩尤被黄帝斩杀后，其体内飞出九颗金灵珠，每一颗都蕴含蚩尤的一部分战意。黄帝将其中八颗封印于八方，一颗赐予麾下大将。后来得到那颗金灵珠的大将，成为了兵家之祖。

**诛仙剑灵**：通天教主的诛仙剑阵中，四柄诛仙剑的剑灵据说便是以金灵珠为核心凝聚而成。这也是诛仙剑阵杀伐无匹的根本原因。
