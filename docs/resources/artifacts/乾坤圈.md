# 乾坤圈

**品阶：** 仙器（上品）

**外观：**

一金色圆环，直径一尺，环身刻乾坤二卦。环体金光灿灿，隐隐有风雷之声。可大可小，大则百丈，小则寸许。祭起时金光万道，乾坤之力弥漫。

**炼制材料：**

- 乾坤精英三两
- 风雷灵木心一枚
- 先天金精一斤
- 太乙真人三昧真火淬炼

**特性：**

乾坤圈一经祭起，乾坤之力锁定敌身。圈落之处，敌人被禁锢其中，动弹不得。圈中自成乾坤，内外隔绝，任人宰割。更可砸人，一砸之下如山压顶。

**神通：**

- 乾坤之力锁定敌身
- 圈落禁锢，动弹不得
- 可砸人，如山压顶
- 可大可小，变化随心

**使用限制：**

需金仙以上修为方可催动。若对方有乾坤类法宝，可破此圈。修为差距过大时，禁锢效果减弱。

**持有者/典故：**

太乙真人镇洞之宝，后传于哪吒。哪吒以此圈砸杀石矶娘娘门下，又于万仙阵中禁锢多名截教弟子。封神后哪吒成圣，此圈留于天庭武库。

**传承脉络：**

此宝乃太乙真人于乾元山金光洞炼制，为镇洞之宝。后传于哪吒，哪吒封神后成圣，此圈留于天庭武库。后赐予哪吒三太子，为天庭镇妖之宝。

**克制关系：**

翻天印可破此圈，以硬碰硬。太极图以阴阳之力化解乾坤之力。其余禁锢类法宝，多半被此圈砸碎。

**历史战绩：**

哪吒以此圈砸杀石矶娘娘门下碧云童子，又于万仙阵中禁锢截教金光仙、灵牙仙，使其动弹不得，再一一击杀。封神后哪吒成圣，此圈留于天庭武库。

**同类对比：**

与混天绫同为哪吒法宝，然乾坤圈主禁锢，混天绫主控水。论禁锢能力，乾坤圈更强；论控制范围，混天绫更广。乾坤圈一落，敌人动弹不得；混天绫一展，江海皆听号令。

**法宝评价：**

乾坤圈乃仙器中禁锢第一宝。乾坤之力锁定敌身，圈落之处，敌人动弹不得。此宝位列仙器上品，为哪吒标志性法宝之一。
