# 覆海神珠

**品阶：** 先天灵宝

**外观：**

二十四颗神珠，每颗鸽蛋大小，通体湛蓝如深海。珠内隐隐有海浪翻涌，似藏一方海域。二十四颗神珠串联成串，蓝光流转，海浪之声不绝于耳。

**炼制材料：**

此珠乃先天水精所化，二十四颗合一，可覆四海。每颗珠内藏一方海域之力，二十四颗齐出，四海倾覆。

**特性：**

覆海神珠一砸之下，如四海倾覆。每一颗珠重如泰山，二十四颗齐出，便是二十四座泰山压顶。无论金刚不坏之体，一砸之下皆成肉泥。

**神通：**

- 二十四颗齐出，四海倾覆
- 每颗珠重如泰山，砸人无敌
- 珠内海域化形，困敌于海
- 可操控四海之水

**使用限制：**

需大罗金仙以上修为方可催动二十四颗齐出。若修为不足，仅能催动数珠，威力大减。

**持有者/典故：**

原为赵公明所有，封神之战中以此宝砸伤阐教多名金仙。后燃灯道人夺此宝，化为二十四诸天。

**传承脉络：**

此珠乃先天灵宝，为鸿钧道祖于紫霄宫分宝时赐通天教主。通天教主赐赵公明，封神后归燃灯道人。燃灯道人以此宝化为二十四诸天，为佛教镇教之宝。

**克制关系：**

杏黄旗可挡此珠，金花万朵护体，珠不能落。翻天印可与此珠对砸，以硬碰硬。其余防御法宝，遇此珠多半被砸碎。

**历史战绩：**

赵公明以此珠砸伤阐教五名金仙，广成子、赤精子、玉鼎真人皆被砸伤。后燃灯道人夺此宝，化为二十四诸天，为佛教镇教之宝。

**同类对比：**

与定海珠同出一源，然定海珠主定海，覆海神珠主砸人。论攻击威力，覆海神珠更胜；论控制能力，定海珠更强。覆海神珠一砸如四海倾覆，定海珠一定则风平浪静，一攻一控，各有妙用。

**法宝评价：**

覆海神珠乃先天灵宝，二十四颗齐出，四海倾覆。此宝位列先天灵宝前二十，为水系攻击之宝第一。封神后此宝归燃灯道人，燃灯以此宝化为二十四诸天，为佛教镇教之宝。二十四诸天一出，佛光万丈，为佛教无上神通。

**后世影响：**

覆海神珠之名，已成为"水系攻击"的代名词。后世修士仿此珠炼制众多仿品，如"覆海珠"、"镇海珠"等，然仿品威力十不存一。此宝之四海倾覆，更是后世水系攻击法宝之典范。
