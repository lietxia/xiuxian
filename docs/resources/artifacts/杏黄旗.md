# 杏黄旗

**品阶：** 先天灵宝

**外观：**

旗面一尺见方，杏黄色，旗边绣金色云纹。旗面中央绘一朵金莲，金莲绽放，金光万道。旗杆以先天灵木所制，长三尺。展旗时，金莲化形，万朵金花护体。

**炼制材料：**

先天五方旗之一，乃先天土精所化。旗面以先天杏黄锦织就，旗杆取自中央黄精之木，金莲乃先天土灵凝聚。

**特性：**

杏黄旗展开，万法不侵。无论神通法术、法宝兵器，遇金花纷纷坠落。旗主立于旗下，万邪不侵，诸魔退避。乃天下第一防御之宝。

**神通：**

- 万朵金花护体，万法不侵
- 金莲绽放，金光所照诸邪退散
- 旗展自成空间，隔绝外力
- 可护一方天地，挡天劫

**使用限制：**

需大罗金仙以上修为方可完全展开。若修为不足，金花数量有限，防御有缺。先天至宝可破此旗。

**持有者/典故：**

原为元始天尊所有，后赐姜子牙护身。姜子牙持此旗入万仙阵，诸般神通皆不能伤。封神后此旗归玉虚宫。

**传承脉络：**

此旗乃先天五方旗之一，为鸿钧道祖于紫霄宫分宝时赐予元始天尊。元始天尊赐姜子牙护身，封神后归玉虚宫。后元始天尊将此旗赐广成子，为阐教镇教之宝。

**克制关系：**

盘古幡可破杏黄旗，以混沌之力击碎金花。混沌钟以混沌之气隔绝金光。其余先天至宝，旗可挡之。

**历史战绩：**

姜子牙持此旗入万仙阵，通天教主诛仙四剑皆不能伤。后元始天尊以此旗护体，入诛仙阵如入无人之境。封神后此旗为玉虚宫镇宫之宝，非大劫不出。

**同类对比：**

与其余四面五方旗各主一方防御。杏黄旗居中，防御最全面；离地焰光旗主火防；素色云界旗主云防；青莲宝色旗主佛防；玄元控水旗主水控。五旗合一，可布先天五行大阵，防御之强仅次于天地玄玲珑宝塔。

**法宝评价：**

杏黄旗乃先天五方旗之首，万法不侵，为天下第一防御之宝。此宝位列先天灵宝前十，为阐教镇教之宝。后世修士仿此旗炼制众多仿品，然无一能及原品之金花万朵。封神后此旗为阐教镇教之宝，非掌教不得轻用。此旗一出，万法辟易，为阐教护道之根本。

**后世影响：**

杏黄旗之名，已成为"万法不侵"的代名词。后世修士仿此旗炼制众多仿品，如"杏黄旗"、"金莲旗"等，然仿品威力十不存一。此宝之金花万朵，更是后世防御法宝之典范。
