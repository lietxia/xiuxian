# 斩仙飞刀

**品阶：** 先天灵宝

**外观：**

一柄小小飞刀，长三寸七分，刀身如秋水，寒光凛冽。刀体透明，似有似无，仿佛由纯粹杀气凝聚。刀柄系一缕红绸，飘动时隐现"斩仙"二字。平时藏于红葫芦之中。

**炼制材料：**

此宝非人力所炼，乃混沌中一缕先天杀气，经无量量劫凝聚成形。后天无人能仿，亦无人能毁。

**特性：**

斩仙飞刀，刀出必杀人。一经祭起，锁定敌身，无论对方修为多高、遁术多快，一刀之下皆难逃。刀光一闪，肉身崩解，元神湮灭，连转世重修的机会都不留。

**神通：**

- 祭刀时需口诵"请宝贝转身"
- 刀光锁定，无可遁逃
- 斩仙灭神，形神俱灭
- 可斩大罗金仙，可灭准圣

**使用限制：**

需大罗金仙以上修为方可驾驭。每次施展需消耗海量法力，且需诵咒锁定，若对方有替死之法或至宝护身，可避一刀。

**持有者/典故：**

陆压道君镇斩飞刀。封神之战中，陆压以此刀斩余元、杀袁洪、诛妲己，刀刀不落空。陆压曾言："此刀无形无迹，大罗金仙亦难逃。"

**传承脉络：**

此宝乃陆压道君于西昆仑修炼时所炼。陆压道君乃离火之精，生于混沌初开之时。封神之战后，陆压归隐，此刀留于西昆仑。后此刀下落不明，传闻为西昆仑镇山之宝。

**克制关系：**

太极图可挡斩仙飞刀，以太极阴阳之力化解刀光。天地玄玲珑宝塔以功德金光护体，刀不能入。替死法（如莲花化身）可避一刀，然第二刀难逃。

**历史战绩：**

陆压以此刀斩余元，余元金刚不坏之身一刀两段。杀袁洪，袁洪七十二变亦难逃一刀。诛妲己，妲己九尾妖狐之体一刀毙命。封神之战中，此刀共斩七人，皆是一刀毙命，从无例外。

**同类对比：**

与金蛟剪同为先天杀伐之宝。金蛟剪以锋锐取胜，斩仙飞刀以锁定见长。金蛟剪可躲可挡，斩仙飞刀一出必杀。论杀伐之利，斩仙飞刀为最。金蛟剪杀人见血，斩仙飞刀杀人无形，更显诡异。

**法宝评价：**

斩仙飞刀乃先天杀伐之宝，刀出必杀人，一刀之下形神俱灭。此宝位列先天灵宝前十五，为封神第一凶刀。后世修士仿此刀炼制众多仿品，然无一能及原品之锁定神通。封神后此宝归隐西昆仑，为陆压道君随身之宝。此刀不出则已，一出必取人性命，从无例外。

**后世影响：**

斩仙飞刀之名，已成为"一击必杀"的代名词。后世修士仿此刀炼制众多仿品，如"斩仙刀"、"灭神刀"等，然仿品威力十不存一。此刀之锁定神通，更是后世修士争相研究的对象。
