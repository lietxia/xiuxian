# 五火七禽扇

**品阶：** 仙器（上品）

**外观：**

扇面一尺五寸，以五根神禽翎羽为骨，七种灵禽羽毛交织为面。扇面绘五朵火焰，色分赤橙黄白青。扇柄以凤凰梧桐木所制，温润如玉。轻摇扇面，五火齐出，热浪滔天。

**炼制材料：**

- 凤凰翎一根
- 青鸾翅羽三根
- 大鹏金翅鸟背翎二根
- 火鸦顶翎五根
- 朱雀尾羽一根
- 先天五火之精各一缕

**特性：**

五火七禽扇内含五火：天火、地火、人火、三昧火、南明离火。七禽之灵各掌一火，扇动则五火齐发。火势铺天盖地，可焚山煮海，所过之处尽成焦土。

**神通：**

- 五火齐出，焚天煮海
- 七禽之灵化形助战
- 南明离火专破邪祟
- 三昧火焚元神，灭之难复

**使用限制：**

需金仙以上修为方可施展。五火齐出消耗法力极巨，连扇三次则力竭。若修为不足，火反噬身，自焚而亡。

**持有者/典故：**

原为云中子所炼，后传于杨任。杨任以扇破瘟癀阵，扇杀吕岳，又于万仙阵中连扇数扇，焚灭截教数名金仙。封神后此扇留于人间道统。

**传承脉络：**

此宝乃云中子于终南山玉柱洞炼制，后传于杨任。杨任封神后，此扇留于人间道统，为阐教三代弟子所掌。后此扇失踪，传闻落入散仙之手，下落不明。

**克制关系：**

玄元控水旗可克此扇，以玄冥真水灭五火。定海珠定住风势，扇不得展。其余水系法宝，威力不足则反被火克。

**历史战绩：**

杨任以此扇破瘟癀阵，一扇焚尽吕岳所放瘟毒，二扇将吕岳本人化为灰烬。万仙阵中，杨任连扇三扇，焚灭截教三名金仙、十二名天仙，火势蔓延百里，截教弟子见此扇无不退避三舍。

**同类对比：**

与九龙神火罩同为火系上品仙器。九龙神火罩擅困杀一人，五火七禽扇擅群攻。论范围杀伤，五火七禽扇更胜；论单体炼化，九龙神火罩更强。五火七禽扇一扇焚百里，九龙神火罩一罩炼一人，各有妙用。

**法宝评价：**

五火七禽扇乃仙器中群攻第一宝。五火齐出，焚天煮海，所过之处尽成焦土。此宝位列仙器上品，为火系群攻法宝之冠。后世修士仿此扇炼制众多仿品，然五火难齐，仿品威力十不存一。
