# 九龙神火罩

**品阶：** 仙器（上品）

**外观：**

罩体通红如琉璃，透明可见罩内九龙游动。罩口直径一尺，展开可达三丈。九条火龙浮雕盘绕罩身，龙首朝内，口吐烈焰。罩顶一颗火灵珠，红光灼灼。

**炼制材料：**

- 先天火精三两
- 九条火蛟心头血
- 南明离火晶一枚
- 赤铜精英千斤
- 太阴真火一缕（阴阳相济）

**特性：**

九龙神火罩一经落下，将敌人罩于其中。九条火龙同时喷吐三昧真火，从九方位焚烧。罩内温度可融金化石，便是金刚不坏之身，一时三刻亦化为灰烬。

**神通：**

- 九龙齐出，喷三昧真火
- 罩内自成火海，无路可逃
- 火龙有灵性，可追敌缠绕
- 火灵珠增幅火力，越烧越旺

**使用限制：**

需金仙以上修为催动。罩内火力无差别攻击，若罩住同伴亦同遭焚毁。水属性法宝可稍克之，然三昧真水方能灭三昧真火。

**持有者/典故：**

太乙真人镇洞之宝，后传于哪吒。哪吒以此罩杀石矶娘娘门下，又于万仙阵中屡建奇功。封神后哪吒成圣，此罩留于天庭武库。

**传承脉络：**

此宝乃太乙真人于乾元山金光洞炼制，为镇洞之宝。后传于哪吒，哪吒封神后成圣，此罩留于天庭武库。后赐予火德星君，为天庭火部镇部之宝。

**克制关系：**

玄元控水旗可克此罩，以玄冥真水灭三昧真火。八宝琉璃瓶中杨柳枝洒水，亦可灭火。其余水系法宝，威力不足则反被火克。

**历史战绩：**

哪吒以此罩杀石矶娘娘门下碧云童子，又于万仙阵中罩住截教金光仙，三刻化为灰烬。封神后此罩留于天庭，玉帝曾以此罩炼杀花果山妖猴，猴群见此罩无不胆寒。

**同类对比：**

与五火七禽扇同为火系法宝，然五火七禽扇主范围焚烧，九龙神火罩主困杀。罩住之后慢慢炼化，比扇之横扫更令人绝望。五火七禽扇一扇而过，九龙神火罩则是慢慢煎熬，论折磨程度更胜一筹。

**法宝评价：**

九龙神火罩乃仙器中困杀第一宝。罩住之后，九条火龙慢慢炼化，敌人只能眼睁睁看着自己被烧死，比一刀毙命更折磨人。此宝位列仙器上品，为火系法宝之翘楚。
