# 金刚伏魔杵

> 金刚怒目，伏魔除妖。此杵乃佛门至宝，专克邪魔外道，对魔道修士有克制之效。

---

## 品阶

| 项目 | 内容 |
|------|------|
| 品阶 | 极品灵器 |
| 类型 | 攻击型法宝 |
| 器灵 | 金刚罗汉（需以佛门功法温养） |

## 外观

金刚伏魔杵长约一尺八寸，通体呈暗金色，杵身刻有密密麻麻的金刚伏魔符文，在佛光下会发出耀眼的金光。杵的两端呈莲花状，莲花中心各镶嵌一颗舍利子，散发着柔和的佛光。杵身中间握持处刻有防滑纹路，以千年沉香木包裹，握在手中沉稳有力。整件法宝重约三十六斤，但在佛门修士手中轻如鸿毛。

## 炼制材料

- **主材**：金刚精铁一斤、舍利子两颗
- **辅材**：千年沉香木一段、佛门金漆三两
- **符文**：金刚伏魔符文一百零八道、镇邪符文三十六道

## 法宝特性

- **攻击力**：对正道修士攻击力一般，但对魔道修士攻击力翻倍，对鬼道修士攻击力翻三倍
- **特殊能力**：祭起后可化为一条金龙，缠绕敌人并将其镇压，持续约三息时间
- **佛光普照**：杵身的舍利子可散发佛光，净化周围的阴邪之气

## 使用限制

- 需以佛门功法驱动，非佛门修士使用会遭到反噬
- 每次使用需诵念金刚伏魔咒，否则威力大减
- 不可杀生，否则会损耗杵身的佛光，严重时会导致法宝品阶下降

## 相关典故

传说上古时期，有一位名为金刚罗汉的佛门大能，为镇压一头为祸人间的万年魔兽，以自身舍利子和金刚精铁炼制了此杵。经过九九八十一天的激战，终于将魔兽镇压于杵中。后世佛门修士感念金刚罗汉的功德，将此杵奉为佛门至宝，代代相传。

## 同类对比

与**降魔杵**相比，金刚伏魔杵威力更大，但限制也更多。与**紫金铃**相比，金刚伏魔杵专克邪魔，但对付正道修士效果一般。金刚伏魔杵的优势在于对魔道的克制作用，是佛门修士降妖伏魔的首选法宝。
