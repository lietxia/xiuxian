# 玄元控水旗

**品阶：** 先天灵宝

**外观：**

旗面一尺见方，玄黑色，旗边绣水纹。旗面中央绘一朵玄冥真水，水波荡漾，寒气逼人。旗杆以水灵木所制，长三尺。展旗时，玄冥真水化形，万里波涛护体。

**炼制材料：**

先天五方旗之一，乃先天水精所化。旗面以先天玄锦织就，旗杆取自北方水之灵木，玄冥真水乃先天水灵凝聚。

**特性：**

玄元控水旗展开，玄冥真水化形，可控天下万水。一切水系神通、法宝，遇此旗尽被控制。旗主可操控江海湖泊，翻江倒海，无所不能。

**神通：**

- 控天下万水，江海听令
- 玄冥真水护体，万法不侵
- 旗展自成水域，隔绝外力
- 可增幅水系神通威力

**使用限制：**

需大罗金仙以上修为方可完全展开。土属性先天之宝可克此旗。若修为不足，控水范围有限。

**持有者/典故：**

原为玄武圣兽所有，后赐截教门下。封神之战中，此旗控水之术令阐教弟子吃尽苦头。后此旗归北冥海眼。

**传承脉络：**

此旗乃先天五方旗之一，为鸿钧道祖于紫霄宫分宝时赐玄武圣兽。玄武圣兽赐截教门下，封神后归北冥海眼。后此旗为玄武圣兽所掌，护持北冥海域。

**克制关系：**

盘古幡可破此旗，以混沌之力击碎玄冥真水。混沌钟以混沌之气隔绝水气。土属性先天之宝可克此旗，以土克水。

**历史战绩：**

截教弟子持此旗入万仙阵，控水之术令阐教弟子吃尽苦头。后此旗归北冥海眼，玄武圣兽以此旗护持北冥海域，水族皆听号令。

**同类对比：**

与杏黄旗同为五方旗，然杏黄旗主全面防御，玄元控水旗主水控。论防御全面性，杏黄旗胜；论水系控制，玄元控水旗为最。玄元控水旗不仅防御，更可操控天下万水，攻守兼备。

**法宝评价：**

玄元控水旗乃先天五方旗之水旗，玄冥真水化形，可控天下万水。此宝位列先天灵宝前二十五，为水系控制之宝第一。封神后此旗归北冥海眼，玄武圣兽凭此旗护持北冥海域，水族皆听号令。此旗一出，万水朝宗，天下水族莫敢不从。

**后世影响：**

玄元控水旗之名，已成为"水系控制"的代名词。后世修士仿此旗炼制众多仿品，如"控水旗"、"玄冥旗"等，然仿品威力十不存一。此宝之玄冥真水，更是后世水系法宝之典范。
