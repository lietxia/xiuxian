# 混元金斗

**品阶：** 先天灵宝

**外观：**

斗口直径三尺三寸，通体呈混沌之色，非金非玉非石。斗内深不见底，隐隐有星云流转，似藏一方天地。斗身刻先天道纹，无人能识，观之目眩。

**炼制材料：**

此宝乃天地自然生成，非人力可炼。取鸿蒙初判时一缕先天混元之气，经无量量劫孕育而成。后天无人能仿。

**特性：**

混元金斗最凶之处在于"削三花、闭五气"。三花者，天地人三花，乃修士顶上精气神所聚；五气者，胸中五行之气。一旦被此斗照住，顶上三花纷纷坠落，胸中五气尽数闭塞，万年修为毁于一旦，沦为凡夫。

**神通：**

- 一照削三花，破人顶上庆云
- 一闭五气，锁修士胸中五行
- 斗内自成空间，可收万物
- 祭起时混沌之光笼罩万丈，无可遁逃

**使用限制：**

需大罗金仙以上修为方可催动。每次施展消耗法力极巨，非底蕴深厚者不可轻用。若修为不足，反噬自身，三花亦损。

**持有者/典故：**

原为通天教主座下三霄娘娘（云霄、碧霄、琼霄）所得。九曲黄河阵中，三霄以此宝削去阐教十二金仙顶上三花，一战震动三界。后元始天尊亲至，收此宝。

**传承脉络：**

此宝乃鸿钧道祖于紫霄宫分宝时赐予通天教主，通天教主又赐三霄娘娘。九曲黄河阵后，元始天尊收此宝，封神后归天庭宝库。后天庭将此宝封存于凌霄殿深处，非三界大劫不出。

**克制关系：**

太极图可破混元金斗，以太极阴阳之力化解混沌之光。天地玄玲珑宝塔亦可抵挡，以功德金光护住三花五气。其余防御法宝，遇此斗皆如纸糊。

**历史战绩：**

九曲黄河阵一战，三霄娘娘以此宝削去广成子、赤精子、太乙真人等十二金仙顶上三花，尽废万年修为。元始天尊亲至，亦不敢硬接，先以言语稳住三霄，再趁机收宝。此战之后，混元金斗被列为禁宝，非封神大劫不可轻用。

**同类对比：**

与斩仙飞刀同属先天灵宝，然斩仙飞刀主杀伐，一击毙命；混元金斗主废人修为，生不如死。论凶残，混元金斗更胜一筹。斩仙飞刀杀人痛快，混元金斗则让人生不如死，万年苦修化为流水，比死更难受。

**法宝评价：**

混元金斗位列先天灵宝前十，乃封神第一凶宝。此宝不杀人，却比杀人更可怕。修士苦修万年，一朝被削三花闭五气，沦为凡夫，比死更痛苦。此宝出世，三界皆惊，被列为禁宝，非大劫不可轻用。后世修士闻此宝名，无不胆寒。封神之后，此宝被列为三界禁宝，封存于凌霄殿深处，非无量量劫不得出世。每逢此宝出世，必伴随三界大劫，生灵涂炭。

**后世影响：**

混元金斗虽被封印，其威名却永传三界。后世修士炼制众多仿品，如"化功散"、"闭气符"等，皆为此宝之仿效。然仿品威力十不存一，且多有后遗症。此宝之名，已成为"废人修为"的代名词，闻者色变。
