# 素色云界旗

**品阶：** 先天灵宝

**外观：**

旗面一尺见方，素白色，旗边绣云纹。旗面中央绘一朵祥云，祥云缭绕，仙气飘飘。旗杆以云灵木所制，长三尺。展旗时，祥云化形，万里云海护体。

**炼制材料：**

先天五方旗之一，乃先天云精所化。旗面以先天素锦织就，旗杆取自东方云灵之木，祥云乃先天云灵凝聚。

**特性：**

素色云界旗展开，祥云万里，诸邪不侵。一切攻击入云海如泥牛入海，消弭于无形。云中生云，无穷无尽，攻击越强，云海越厚。立于旗下，万法不侵。

**神通：**

- 祥云护体，万法不侵
- 云海无穷，攻击越强防御越厚
- 旗展自成云海，隔绝外力
- 可增幅遁术速度

**使用限制：**

需大罗金仙以上修为方可完全展开。风属性先天之宝可吹散云海。若修为不足，云海稀薄。

**持有者/典故：**

原为西王母所有，后赐龙吉公主。龙吉公主持此旗入万仙阵，云海护体，诸般攻击皆不能伤。封神后此旗归瑶池。

**传承脉络：**

此旗乃先天五方旗之一，为鸿钧道祖于紫霄宫分宝时赐西王母。西王母赐龙吉公主，封神后归瑶池。后此旗为西王母所掌，为瑶池仙境护境之宝。

**克制关系：**

盘古幡可破此旗，以混沌之力击碎云海。混沌钟以混沌之气隔绝祥云。风属性先天之宝可吹散云海，然需极强风力。

**历史战绩：**

龙吉公主持此旗入万仙阵，截教弟子诸般攻击入云海皆消弭于无形。后此旗归瑶池，西王母以此旗护持瑶池仙境，诸魔不敢犯。

**同类对比：**

与杏黄旗同为五方旗，然杏黄旗主金防，素色云界旗主云防。论防御刚性，杏黄旗胜；论防御韧性，素色云界旗为最。素色云界旗以柔克刚，攻击越强防御越厚，论持久防御无出其右。

**法宝评价：**

素色云界旗乃先天五方旗之云旗，祥云万里，诸邪不侵。此宝位列先天灵宝前二十五，为云系防御之宝第一。封神后此旗为瑶池护境之宝，西王母凭此旗护持瑶池仙境，诸魔不敢犯。此旗一出，云海万里，瑶池固若金汤。

**后世影响：**

素色云界旗之名，已成为"云系防御"的代名词。后世修士仿此旗炼制众多仿品，如"云界旗"、"祥云旗"等，然仿品威力十不存一。此宝之云海无穷，更是后世云系法宝之典范。
