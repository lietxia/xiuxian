# 阴阳镜

> 正面照生，反面照死。此镜乃生死至宝，可定人生死，是上古大能的禁忌之物。

---

## 品阶

| 项目 | 内容 |
|------|------|
| 品阶 | 先天灵宝 |
| 类型 | 生死型法宝 |
| 器灵 | 阴阳灵（需以生死功法温养） |

## 外观

阴阳镜直径约六寸，呈圆形，正反两面颜色分明。正面呈白色，光滑如镜，可照出人的生机；反面呈黑色，幽深如渊，可照出人的死气。镜身以混沌石打造，边缘刻有阴阳鱼图案，黑白相间，缓缓流转。镜柄以万年阴沉木制成，握在手中冰凉刺骨。整件法宝散发着淡淡的生死气息，令人不寒而栗。

## 炼制材料

- **主材**：混沌石一块、万年阴沉木一段
- **辅材**：阴阳石三颗、生死水一瓶
- **符文**：生符文三十六道、死符文三十六道、阴阳符文十二道

## 法宝特性

- **攻击力**：正面照射可恢复生机，反面照射可剥夺生机，对元婴期以下修士一击必杀
- **特殊能力**：可同时照射多人，范围约百丈，但威力会随人数增加而减弱
- **生死平衡**：每次使用需消耗使用者自身寿元，正面照射消耗一年，反面照射消耗十年

## 使用限制

- 需以生死功法驱动，非生死灵根修士使用会遭到反噬
- 每次使用需消耗大量法力和寿元
- 对高于使用者一个大境界的敌人无效
- 不可对凡人使用，否则会遭天谴

## 相关典故

传说上古时期，有一位名为阴阳真人的大能，在参悟生死之道时，以自身精血和混沌石炼制了此镜。凭借此镜，他连败魔道十余名化神期修士，威震修真界。后来，他因过度使用此镜，寿元耗尽，最终坐化。后世修士将此镜列为禁忌之物，轻易不敢使用。

## 同类对比

与**生死簿**相比，阴阳镜更加灵活，但威力稍逊。与**判官笔**相比，阴阳镜攻守兼备，但限制更多。阴阳镜的优势在于生死一体，攻守兼备，是生死法宝中的极品。
