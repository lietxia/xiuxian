# 定风珠

> 风来我定，万法不侵。此珠乃风系法宝的克星，可定住一切风属性攻击。

---

## 品阶

| 项目 | 内容 |
|------|------|
| 品阶 | 中品灵器 |
| 类型 | 防御型法宝 |
| 器灵 | 无（需以特殊手法驱动） |

## 外观

定风珠直径约一寸，通体呈淡蓝色，晶莹剔透，内有蓝色光华流转。珠身表面有天然形成的纹路，似风又似云，在阳光下会泛出幽幽蓝光。珠内封印着一缕上古风灵的精魂，在珠内缓缓游动，仿佛有生命一般。整件法宝小巧玲珑，可挂在腰间或收入袖中。

## 炼制材料

- **主材**：定风石一颗、万年寒玉二两
- **辅材**：风灵精魂一缕、寒铁精金三两
- **符文**：定风符文二十四道、镇风符文十二道

## 法宝特性

- **防御力**：可定住金丹期以下修士的风属性攻击，元婴期修士的风属性攻击也可削弱五成
- **特殊能力**：祭起后可形成一个定风领域，领域内所有风属性法术都会失效，持续约一炷香时间
- **灵气消耗**：持续消耗灵气，筑基期修士可维持约半个时辰

## 使用限制

- 只对风属性攻击有效，对其他属性攻击无效
- 每次使用需消耗约一成法力
- 对高于使用者一个大境界的敌人效果大减
- 珠身破损后需以定风石修补，普通材料无法修复

## 相关典故

传说上古时期，有一位名为定风真人的大能，在渡劫时被天风劈中肉身，魂魄即将消散。他以最后一丝法力将一缕风灵精魂封印在定风石中，成功保住魂魄，最终转修散仙。后世修士感念此珠的救命之恩，将其列为防御法宝中的中品。

## 同类对比

与**芭蕉扇**相比，定风珠防御力更强，但攻击力不足。与**天地防护罩**相比，定风珠更加灵活便携，但防御范围较小。定风珠的优势在于对风属性的克制作用，是风系法宝的克星。
