# 定海珠

**品阶：** 先天灵宝

**外观：**

二十四颗神珠，每颗鸽蛋大小，通体湛蓝如深海。珠内隐隐有海浪翻涌，似藏一方海域。二十四颗神珠串联成串，蓝光流转，海浪之声不绝于耳。

**炼制材料：**

此珠乃先天水精所化，二十四颗合一，可定四海。每颗珠内藏一方海域之力，二十四颗齐出，四海皆定。

**特性：**

定海珠一出，四海皆定。无论海浪滔天、洪水泛滥，一珠定之，风平浪静。更可定住敌人身形，使其动弹不得。定住之后，任人宰割。

**神通：**

- 定住四海，风平浪静
- 定住敌人身形，动弹不得
- 珠内海域化形，困敌于海
- 可操控四海之水

**使用限制：**

需大罗金仙以上修为方可催动二十四颗齐出。若修为不足，仅能催动数珠，定住范围有限。

**持有者/典故：**

原为赵公明所有，封神之战中以此宝定住阐教多名金仙。后燃灯道人夺此宝，化为二十四诸天。

**传承脉络：**

此珠乃先天灵宝，为鸿钧道祖于紫霄宫分宝时赐通天教主。通天教主赐赵公明，封神后归燃灯道人。燃灯道人以此宝化为二十四诸天，为佛教镇教之宝。

**克制关系：**

杏黄旗可挡此珠，金花万朵护体，珠不能落。翻天印可破此珠，以硬碰硬。其余防御法宝，遇此珠多半被定住。

**历史战绩：**

赵公明以此珠定住阐教五名金仙，使其动弹不得，再一一斩杀。后燃灯道人夺此宝，化为二十四诸天，为佛教镇教之宝。

**同类对比：**

与覆海神珠同出一源，然定海珠主定海，覆海神珠主砸人。论控制能力，定海珠更强；论攻击威力，覆海神珠更胜。定海珠一定之下，敌人动弹不得，任人宰割，比死更可怕。

**法宝评价：**

定海珠乃先天灵宝，二十四颗齐出，四海皆定。此宝位列先天灵宝前二十，为水系控制之宝第一。封神后此宝归燃灯道人，燃灯以此宝化为二十四诸天，为佛教镇教之宝。二十四诸天一出，佛光万丈，为佛教无上神通。

**后世影响：**

定海珠之名，已成为"水系控制"的代名词。后世修士仿此珠炼制众多仿品，如"定海珠"、"镇海珠"等，然仿品威力十不存一。此宝之四海皆定，更是后世水系控制法宝之典范。
