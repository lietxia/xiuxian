# 阴阳剑

**品阶：** 仙器（上品）

**外观：**

双剑合璧，一阴一阳。阴剑通体漆黑，寒气逼人；阳剑通体赤红，热浪滚滚。双剑合璧时，阴阳交汇，剑气纵横。可分可合，分则各主一方，合则威力倍增。

**炼制材料：**

- 太阴精英三两
- 太阳精英三两
- 阴阳调和玉液一瓶
- 太乙真人三昧真火淬炼

**特性：**

阴阳剑双剑合璧，阴阳交汇，剑气纵横。阴剑主杀，阳剑主生，一杀一生，循环不息。双剑合璧时，威力倍增，可斩金断玉。

**神通：**

- 双剑合璧，阴阳交汇
- 阴剑主杀，阳剑主生
- 剑气纵横，可斩金断玉
- 可分可合，变化随心

**使用限制：**

需金仙以上修为方可催动。若对方有阴阳类法宝，可破此剑。修为差距过大时，威力减弱。

**持有者/典故：**

太乙真人镇洞之宝，后传于哪吒。哪吒以此剑杀石矶娘娘门下，又于万仙阵中屡建奇功。封神后哪吒成圣，此剑留于天庭武库。

**传承脉络：**

此宝乃太乙真人于乾元山金光洞炼制，为镇洞之宝。后传于哪吒，哪吒封神后成圣，此剑留于天庭武库。后赐予哪吒三太子，为天庭镇妖之宝。

**克制关系：**

太极图可破此剑，以太极阴阳之力化解剑气。混沌钟以混沌之气隔绝剑气。其余阴阳类法宝，多半被此剑压制。

**历史战绩：**

哪吒以此剑杀石矶娘娘门下碧云童子，又于万仙阵中刺伤截教多名金仙。封神后哪吒成圣，此剑留于天庭武库。

**同类对比：**

与同为双剑法宝的青紫双剑相比，阴阳剑更重阴阳之道。论阴阳玄妙，阴阳剑胜；论锋锐程度，青紫双剑更强。阴阳剑双剑合璧，阴阳交汇，剑气纵横；青紫双剑则锋锐无匹，一刺即入。

**法宝评价：**

阴阳剑乃仙器中阴阳第一宝。双剑合璧，阴阳交汇，剑气纵横。此宝位列仙器上品，为哪吒标志性法宝之一。
