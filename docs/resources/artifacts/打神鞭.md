# 打神鞭

**品阶：** 先天灵宝

**外观：**

鞭长三尺六寸五分，共二十一节，每节四道符印，共八十四道符印。鞭体呈玄黄色，似金非金，似木非木。挥动时风雷交作，符印亮起，金光万道。

**炼制材料：**

此鞭乃封神榜伴生之宝，以天道之力凝成。鞭体取自建木神树枝条，符印乃天道铭文，非人力可书。

**特性：**

打神鞭专打封神榜上有名之人。榜上有名者，被此鞭一打，轻则重伤，重则魂飞魄散。若榜上无名，此鞭威力大减，与寻常鞭类无异。

**神通：**

- 专打封神榜上有名者
- 一鞭打落，封神榜上有名者无可抵抗
- 符印亮起，封印敌身
- 可打落修为，削去仙籍

**使用限制：**

仅对封神榜上有名之人有效。若对方不在榜上，威力十不存一。需金仙以上修为方可催动。

**持有者/典故：**

姜子牙持此鞭封神。封神之战中，姜子牙以此鞭打截教众多上榜之人，无人能挡。封神后此鞭归天庭，为封神台镇台之宝。

**传承脉络：**

此鞭乃封神榜伴生之宝，为天道所赐。姜子牙持此鞭封神，封神后此鞭归天庭，为封神台镇台之宝。后此鞭为玉皇大帝所掌，为天庭节制众神之器。

**克制关系：**

封神榜上有名者，打神鞭方能发挥威力。若对方不在榜上，此鞭威力十不存一。杏黄旗可挡此鞭，金花护体，鞭不能入。

**历史战绩：**

姜子牙以此鞭打截教众多上榜之人，马元、余化龙、邓婵玉等皆被此鞭打落马下。封神之战中，此鞭共打三百六十五人，皆为封神榜上有名者，无一落空。

**同类对比：**

与斩仙飞刀同为先天灵宝，然斩仙飞刀无差别杀人，打神鞭专打榜上有名者。论通用性，斩仙飞刀更广；论针对性，打神鞭更专。打神鞭如天规，榜上有名者不可逃；斩仙飞刀如天谴，一刀之下无活口。

**法宝评价：**

打神鞭乃封神榜伴生之宝，专打封神榜上有名者。此宝如天规，榜上有名者不可逃。封神后此宝为天庭节制众神之器，位列先天灵宝前三十。后天庭以此鞭节制众神，违令者鞭打不饶，为天庭刑律之象征。众神见此鞭如见天规，莫敢不从。

**后世影响：**

打神鞭之名，已成为"天规律条"的代名词。后世天庭仿此鞭炼制众多刑律之器，如"天刑鞭"、"律令鞭"等，然仿品威力十不存一。此宝之专打榜上神通，更是后世天庭节制众神之根本。
