# 离地焰光旗

**品阶：** 先天灵宝

**外观：**

旗面一尺见方，赤红色，旗边绣火焰纹。旗面中央绘一朵南明离火，火焰腾腾，热浪滚滚。旗杆以火灵木所制，长三尺。展旗时，南明离火化形，万丈火焰护体。

**炼制材料：**

先天五方旗之一，乃先天火精所化。旗面以先天赤锦织就，旗杆取自南方火灵之木，离火乃先天火灵凝聚。

**特性：**

离地焰光旗展开，离火万丈，诸邪不侵。一切阴邪鬼魅、魔功邪法，遇离火尽消。火中至阳，专克阴邪。立于旗下，万火不侵，诸邪退避。

**神通：**

- 南明离火护体，万邪不侵
- 离火所照，阴邪尽消
- 旗展自成火海，隔绝外力
- 可增幅火系神通威力

**使用限制：**

需大罗金仙以上修为方可完全展开。水属性先天之宝可克此旗。若修为不足，离火反噬。

**持有者/典故：**

原为通天教主所有，后赐火灵圣母。火灵圣母持此旗入万仙阵，火系神通威力倍增。封神后此旗归天庭。

**传承脉络：**

此旗乃先天五方旗之一，为鸿钧道祖于紫霄宫分宝时赐予通天教主。通天教主赐火灵圣母，封神后归天庭。后此旗为火德星君所掌，为天庭火部镇部之宝。

**克制关系：**

玄元控水旗可克此旗，以玄冥真水灭南明离火。定海珠定住火势，旗不得展。其余水系法宝，威力不足则反被火克。

**历史战绩：**

火灵圣母持此旗入万仙阵，阐教弟子火系神通皆不能伤，反被离火反弹，烧伤数人。后广成子以翻天印破旗，方才击杀火灵圣母。

**同类对比：**

与杏黄旗同为五方旗，然杏黄旗主全面防御，离地焰光旗主火防。论防御全面性，杏黄旗胜；论火系防御，离地焰光旗为最。离地焰光旗不仅防御，更可反弹火攻，攻守兼备。

**法宝评价：**

离地焰光旗乃先天五方旗之火旗，南明离火护体，万邪不侵。此宝位列先天灵宝前二十五，为火系防御之宝第一。封神后此旗为天庭火部镇部之宝，火德星君凭此旗掌管三界火政。此旗一出，万火朝宗，火部众神皆听号令。

**后世影响：**

离地焰光旗之名，已成为"火系防御"的代名词。后世修士仿此旗炼制众多仿品，如"离火旗"、"焰光旗"等，然仿品威力十不存一。此宝之南明离火，更是后世火系法宝之典范。
