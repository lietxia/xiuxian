# 金砖

**品阶：** 仙器（上品）

**外观：**

一块金砖，长六寸，宽三寸，厚一寸。砖体金光灿灿，先天道纹隐隐。可大可小，大则如山，小则寸许。祭起时金光万道，如山压顶。

**炼制材料：**

- 先天金精三斤
- 太乙真人三昧真火淬炼
- 先天道纹铭刻

**特性：**

金砖一经祭起，如山压顶。一砖砸下，无论金刚不坏之体，皆成肉泥。更兼金光万道，晃人眼目，防不胜防。

**神通：**

- 如山压顶，砸人无敌
- 金光万道，晃人眼目
- 可大可小，变化随心
- 一砖砸下，防不胜防

**使用限制：**

需金仙以上修为方可催动。若对方有土属性法宝，可挡此砖。修为差距过大时，威力减弱。

**持有者/典故：**

太乙真人镇洞之宝，后传于哪吒。哪吒以此砖砸杀石矶娘娘门下，又于万仙阵中屡建奇功。封神后哪吒成圣，此砖留于天庭武库。

**传承脉络：**

此宝乃太乙真人于乾元山金光洞炼制，为镇洞之宝。后传于哪吒，哪吒封神后成圣，此砖留于天庭武库。后赐予哪吒三太子，为天庭镇妖之宝。

**克制关系：**

杏黄旗可挡此砖，金花万朵护体，砖不能落。翻天印可与此砖对砸，以硬碰硬。其余防御法宝，遇此砖多半被砸碎。

**历史战绩：**

哪吒以此砖砸杀石矶娘娘门下碧云童子，又于万仙阵中砸伤截教多名金仙。封神后哪吒成圣，此砖留于天庭武库。

**同类对比：**

与同为砸人法宝的覆海神珠相比，金砖更灵活但威力更小。论灵活性，金砖胜；论威力，覆海神珠更强。金砖一砖砸下，覆海神珠二十四珠齐出，论威势覆海神珠更胜。

**法宝评价：**

金砖乃仙器中砸人第一宝。一砖砸下，如山压顶，防不胜防。此宝位列仙器上品，为哪吒标志性法宝之一。封神后此宝为天庭镇妖之宝，哪吒凭此砖降妖伏魔，屡建奇功。此砖一出，金光万道，妖邪辟易，为天庭征伐之利器。

**后世影响：**

金砖之名，已成为"砸人法宝"的代名词。后世修士仿此砖炼制众多仿品，如"金砖"、"金印"等，然仿品威力十不存一。此宝之如山压顶，更是后世砸人法宝之典范。
