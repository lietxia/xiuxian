# 降魔杵

> 金龙一出，万魔伏首。此杵乃佛门降魔利器，祭起后可化为金龙镇压邪魔。

---

## 品阶

| 项目 | 内容 |
|------|------|
| 品阶 | 中品灵器 |
| 类型 | 攻击型法宝 |
| 器灵 | 无（需以佛门功法驱动） |

## 外观

降魔杵长约一尺二寸，通体呈金黄色，杵身刻有降魔符文，在阳光下会泛出金属光泽。杵的一端呈三棱锥形，锋利无比，可刺穿金丹期修士的护体灵光。另一端呈圆球状，刻有莲花图案，可作为钝器使用。杵身中间握持处以牛皮包裹，防滑且舒适。整件法宝重约十八斤，比普通法宝轻便许多。

## 炼制材料

- **主材**：黄金精铁八斤、玄铁二斤
- **辅材**：牛皮一张、佛门金漆二两
- **符文**：降魔符文七十二道、镇邪符文二十四道

## 法宝特性

- **攻击力**：对正道修士攻击力一般，但对鬼道和妖道攻击力提升五成
- **特殊能力**：祭起后可化为一条金龙，缠绕敌人并将其镇压，持续约两息时间
- **破邪**：杵身的降魔符文可破除低阶幻术和隐身术

## 使用限制

- 需以佛门功法驱动，非佛门修士使用效果减半
- 每次使用需消耗约一成法力
- 对高于使用者一个大境界的敌人效果大减

## 相关典故

传说上古时期，有一位名为降龙尊者的佛门大能，在云游四方时遇到一头为祸乡里的妖龙。降龙尊者以自身佛法和降魔杵与妖龙激战三天三夜，最终将其镇压。后世佛门修士将此杵奉为降魔利器，常用于镇压妖邪。

## 同类对比

与**金刚伏魔杵**相比，降魔杵威力较小，但使用限制也少。与**紫金铃**相比，降魔杵更加灵活，可近身作战也可远程攻击。降魔杵的优势在于攻守兼备，是佛门修士常用的降魔法宝。
