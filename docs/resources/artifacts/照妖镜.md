# 照妖镜

> 镜一照，妖邪现形。此镜乃辅助至宝，可照破一切幻术和隐身，是妖邪的克星。

---

## 品阶

| 项目 | 内容 |
|------|------|
| 品阶 | 中品灵器 |
| 类型 | 辅助型法宝 |
| 器灵 | 无（需以特殊手法驱动） |

## 外观

照妖镜直径约四寸，呈圆形，镜面以水晶打磨而成，光滑如镜。镜背以青铜打造，刻有上古符文和妖兽图案，在月光下会泛出幽幽青光。镜柄以桃木制成，握在手中舒适舒适。镜身周围有一圈铜边，铜边上有十二个凹槽，可嵌入灵石供能。整件法宝小巧玲珑，可挂在腰间或收入袖中。

## 炼制材料

- **主材**：水晶石一块、青铜三斤
- **辅材**：桃木一段、照妖石一颗
- **符文**：照妖符文三十六道、破幻符文二十四道

## 法宝特性

- **破幻能力**：可照破金丹期以下修士的幻术和隐身，元婴期修士的幻术也可削弱五成
- **特殊能力**：照射到妖邪之物时，镜面会发出红光示警，同时照出妖邪的原形
- **范围**：镜面照射范围约百丈，范围内所有妖邪都会现形

## 使用限制

- 需以特殊手法驱动，非特殊灵根修士使用效果减半
- 每次使用需消耗约一成法力
- 对高于使用者一个大境界的敌人效果大减
- 镜面破损后需以水晶石修补，普通材料无法修复

## 相关典故

传说上古时期，有一位名为照妖真人的大能，在云游四方时遇到一头为祸乡里的妖兽。照妖真人以自身精血和水晶石炼制了此镜，经过三天三夜的激战，终于照出妖兽的原形并将其斩杀。后世修士将此镜奉为辅助法宝，常用于探查妖邪。

## 同类对比

与**破幻符**相比，照妖镜可以重复使用，但威力稍逊。与**天眼通**相比，照妖镜更加灵活便携，但需要消耗法力。照妖镜的优势在于破幻和照妖的双重作用，是辅助法宝中的中品。
