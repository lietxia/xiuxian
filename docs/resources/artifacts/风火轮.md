# 风火轮

**品阶：** 仙器（上品）

**外观：**

两只火轮，直径一尺，轮身刻风火二纹。轮体赤红如火，风纹缠绕。轮转时风火齐作，烈焰腾腾，风声呼啸。踏轮飞行，快如闪电。

**炼制材料：**

- 风灵精英三两
- 火灵精英三两
- 先天风火灵木心一枚
- 太乙真人三昧真火淬炼

**特性：**

风火轮一经踏起，风火齐作，快如闪电。轮转时风助火势，火助风威，速度倍增。一日可行百万里，追敌逃命皆可用。

**神通：**

- 风火齐作，快如闪电
- 一日百万里
- 轮转时喷风火，攻敌
- 可大可小，变化随心

**使用限制：**

需金仙以上修为方可催动。若对方有风火类法宝，可破此轮。修为差距过大时，速度优势减弱。

**持有者/典故：**

太乙真人镇洞之宝，后传于哪吒。哪吒以此轮追敌逃命，屡建奇功。封神后哪吒成圣，此轮留于天庭武库。

**传承脉络：**

此宝乃太乙真人于乾元山金光洞炼制，为镇洞之宝。后传于哪吒，哪吒封神后成圣，此轮留于天庭武库。后赐予哪吒三太子，为其专属座驾。

**克制关系：**

定海珠可定住风火轮，使其动弹不得。玄元控水旗可灭风火。其余飞行法宝，速度皆不及此轮。

**历史战绩：**

哪吒以此轮追敌逃命，屡建奇功。封神后哪吒成圣，此轮留于天庭武库，为哪吒三太子专属座驾。

**同类对比：**

与同为飞行法宝的筋斗云相比，风火轮更快但消耗更大。论速度，风火轮胜；论持久，筋斗云更强。风火轮一日百万里，筋斗云一筋斗十万八千里，论爆发速度风火轮更胜。

**法宝评价：**

风火轮乃仙器中飞行第一宝。风火齐作，快如闪电，一日可行百万里。此宝位列仙器上品，为哪吒专属座驾。
