# 火尖枪

**品阶：** 仙器（上品）

**外观：**

一杆长枪，长一丈二尺，枪尖赤红如火焰。枪身刻火焰纹，隐隐有火灵涌动。枪尖一点火焰，永不熄灭。舞动时火焰腾腾，热浪滚滚。

**炼制材料：**

- 火尖精英三两
- 先天火灵木心一枚
- 赤铜精英一斤
- 太乙真人三昧真火淬炼

**特性：**

火尖枪一经舞动，火焰腾腾，热浪滚滚。枪尖一点火焰，专破护体神光。刺中敌人，火焰入体，焚烧经脉，痛苦难忍。

**神通：**

- 火焰腾腾，热浪滚滚
- 枪尖破护体神光
- 火焰入体，焚烧经脉
- 可大可小，变化随心

**使用限制：**

需金仙以上修为方可催动。若对方有水系法宝，可克此枪。修为差距过大时，火焰威力减弱。

**持有者/典故：**

太乙真人镇洞之宝，后传于哪吒。哪吒以此枪杀石矶娘娘门下，又于万仙阵中屡建奇功。封神后哪吒成圣，此枪留于天庭武库。

**传承脉络：**

此宝乃太乙真人于乾元山金光洞炼制，为镇洞之宝。后传于哪吒，哪吒封神后成圣，此枪留于天庭武库。后赐予火德星君，为天庭火部镇部之宝。

**克制关系：**

玄元控水旗可克此枪，以玄冥真水灭枪尖火焰。定海珠定住火势，枪不得舞。其余水系法宝，威力不足则反被火克。

**历史战绩：**

哪吒以此枪杀石矶娘娘门下碧云童子，又于万仙阵中刺伤截教多名金仙。封神后哪吒成圣，此枪留于天庭武库。

**同类对比：**

与同为火系法宝的九龙神火罩相比，火尖枪更灵活但范围更小。论灵活性，火尖枪胜；论范围杀伤，九龙神火罩更强。火尖枪一枪刺出，九龙神火罩一罩炼杀，各有妙用。

**法宝评价：**

火尖枪乃仙器中火系攻击第一宝。枪尖一点火焰，专破护体神光。此宝位列仙器上品，为哪吒标志性法宝之一。
