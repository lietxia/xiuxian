# 捆仙绳

> 绳一出，仙难逃。此绳乃束缚至宝，可自动捆绑敌人，越挣扎越紧，是擒拿敌人的利器。

---

## 品阶

| 项目 | 内容 |
|------|------|
| 品阶 | 上品灵器 |
| 类型 | 束缚型法宝 |
| 器灵 | 缚神灵（需以特殊手法收服） |

## 外观

捆仙绳长约一丈二寸，通体呈金黄色，由天蚕丝和龙筋编织而成，柔软如丝却坚韧无比。绳身上刻有密密麻麻的束缚符文，在阳光下会泛出金光。绳的两端各有一颗金色铃铛，在捆绑敌人时会发出清脆的铃声。整件法宝小巧玲珑，可缠绕在腰间或收入袖中。

## 炼制材料

- **主材**：天蚕丝一匹、龙筋三条
- **辅材**：金铃铛两颗、束缚石三颗
- **符文**：束缚符文七十二道、紧缚符文三十六道

## 法宝特性

- **束缚力**：可捆绑金丹期以下修士，元婴期修士也可束缚约三息时间
- **特殊能力**：绳子会自动追踪敌人并将其捆绑，越挣扎越紧，最终令敌人无法动弹
- **范围**：绳子可延伸至十丈长，范围内所有敌人都会被追踪

## 使用限制

- 每次使用需消耗约两成法力
- 对高于使用者一个大境界的敌人效果大减
- 绳子被挣脱后需以灵气温养三日方可再次使用
- 不可对凡人使用，否则会伤及无辜

## 相关典故

传说上古时期，有一位名为缚仙真人的大能，在云游四方时遇到一头为祸乡里的妖龙。缚仙真人以自身精血和天蚕丝炼制了此绳，经过三天三夜的激战，终于将妖龙捆绑。后世修士将此绳奉为束缚法宝，常用于擒拿敌人。

## 同类对比

与**缚妖索**相比，捆仙绳威力更大，但限制也更多。与**定身符**相比，捆仙绳更加灵活，但需要持续消耗法力。捆仙绳的优势在于自动追踪和越挣越紧的特性，是束缚法宝中的上品。
