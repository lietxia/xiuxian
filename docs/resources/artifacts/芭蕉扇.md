# 芭蕉扇

> 一扇生风，二扇起火，三扇风火交加。此扇乃风火至宝，一扇之下可令天地变色。

---

## 品阶

| 项目 | 内容 |
|------|------|
| 品阶 | 极品灵器 |
| 类型 | 风火型法宝 |
| 器灵 | 风火灵（需以风火功法温养） |

## 外观

芭蕉扇展开时直径约二尺四寸，形似芭蕉叶，扇面呈翠绿色，叶脉清晰可见。扇面以千年芭蕉叶炼制而成，轻薄如纸却坚韧无比。扇骨以凤凰木制成，共有十二根，每根上都刻有一道风火符文。扇柄以万年寒玉制成，握在手中清凉舒适，可抵御扇面传来的高温。收拢时不过一尺长，可收入袖中。

## 炼制材料

- **主材**：千年芭蕉叶一片、凤凰木十二根
- **辅材**：万年寒玉一块、风火石三颗
- **符文**：风符文十二道、火符文十二道、聚灵符文一道

## 法宝特性

- **攻击力**：一扇生风，可吹出罡风，将敌人吹飞百丈；二扇起火，可喷出三昧真火，焚烧一切；三扇风火交加，威力翻倍
- **特殊能力**：扇出的风火可融为一体，形成风火轮，持续攻击敌人约一盏茶时间
- **范围**：扇面覆盖范围约三百丈，范围内所有敌人都会受到风火侵袭

## 使用限制

- 需以风火功法驱动，非风火灵根修士使用效果减半
- 每次使用需消耗约三成法力
- 不可在密闭空间使用，否则会伤及自身
- 扇面破损后需以千年芭蕉叶修补，普通材料无法修复

## 相关典故

传说上古时期，有一位名为铁扇仙子的女修，在火焰山修炼千年，以自身精血和千年芭蕉叶炼制了此扇。凭借此扇，她连败魔道十余名化神期修士，威震修真界。后来，她将此扇传给弟子，代代相传，成为风火法宝中的极品。

## 同类对比

与**五火七禽扇**相比，芭蕉扇更加灵活，但威力稍逊。与**定风珠**相比，芭蕉扇攻守兼备，但防御力不如定风珠。芭蕉扇的优势在于风火一体，攻守兼备，是风火法宝中的极品。
