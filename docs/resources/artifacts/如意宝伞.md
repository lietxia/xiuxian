# 如意宝伞

> 撑开如意伞，万法不侵身。此伞乃上古大能仿照天地初开时的混沌屏障所炼，撑开后可抵御万法侵袭。

---

## 品阶

| 项目 | 内容 |
|------|------|
| 品阶 | 上品灵器 |
| 类型 | 防御型法宝 |
| 器灵 | 无（需主人神识驱动） |

## 外观

如意宝伞撑开时直径约三尺，伞面呈淡金色，由千年天蚕丝编织而成，轻薄如蝉翼却坚韧无比。伞面上绣有云纹图案，在阳光下会泛出七彩光晕。伞骨以寒铁精金打造，共有二十四根，每根上都刻有一道防御符文。伞柄以万年温玉制成，握在手中温润舒适，可安抚心神。收拢时不过一尺长，可收入袖中。

## 炼制材料

- **主材**：千年天蚕丝一匹、寒铁精金二十四斤
- **辅材**：万年温玉一块、云纹金丝三两
- **符文**：防御符文二十四道、聚灵符文一道

## 法宝特性

- **防御力**：撑开后可抵挡金丹期以下修士的全力攻击，元婴期修士的攻击也可削弱三成
- **特殊能力**：伞面上的云纹可幻化出云雾，遮蔽主人身形，持续约一炷香时间
- **灵气消耗**：撑开时持续消耗灵气，筑基期修士可维持约一个时辰

## 使用限制

- 每使用一次需以灵气温养三日，否则伞面会逐渐老化
- 不可在雷雨天使用，否则会引雷上身
- 伞面破损后需以天蚕丝修补，普通材料无法修复

## 相关典故

传说上古时期，有一位名为云游子的大能，在渡劫时被天雷劈中肉身，魂魄即将消散。他以最后一件法宝——如意宝伞撑开，挡住了致命一击，虽然法宝被毁，但成功保住魂魄，最终转修散仙。后世修士感念此伞的救命之恩，将其列为防御法宝中的上品。

## 同类对比

与**天地防护罩**相比，如意宝伞防御力稍逊，但更加灵活便携。与**金刚不坏体**相比，如意宝伞无需修炼，任何人皆可使用，但防御力远不如金刚不坏体。如意宝伞的优势在于攻防一体，撑开时可防御，收拢时可作兵器使用。
