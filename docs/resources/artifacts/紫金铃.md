# 紫金铃

> 铃声一响，魂魄飞扬。此铃乃音攻至宝，摇动时可发出摄魂之音，扰乱敌人心神。

---

## 品阶

| 项目 | 内容 |
|------|------|
| 品阶 | 上品灵器 |
| 类型 | 音攻型法宝 |
| 器灵 | 摄魂灵（需以特殊手法收服） |

## 外观

紫金铃高约三寸，通体呈紫金色，由紫金打造而成，表面光滑如镜。铃身上刻有上古符文，在月光下会泛出幽幽紫光。铃舌以万年寒铁制成，碰撞铃身时会发出清脆悦耳的铃声。铃柄以紫玉制成，握在手中温润舒适。整件法宝小巧玲珑，可挂在腰间或收入袖中。

## 炼制材料

- **主材**：紫金一斤、万年寒铁二两
- **辅材**：紫玉一块、摄魂石一颗
- **符文**：摄魂符文三十六道、迷音符文二十四道

## 法宝特性

- **攻击力**：铃声可直接攻击敌人神魂，筑基期修士闻之会陷入昏迷，金丹期修士也会心神不宁
- **特殊能力**：连续摇动三下可发出摄魂神音，直接攻击敌人元神，对元婴期以下修士有效
- **范围**：铃声覆盖范围约百丈，范围内所有敌人都会受到影响

## 使用限制

- 每次使用需消耗约两成法力
- 对高于使用者一个大境界的敌人效果大减
- 不可对凡人使用，否则会伤及无辜
- 长期使用会在使用者体内积累魂力，需定期化解

## 相关典故

传说上古时期，有一位名为摄魂仙子的魔门大能，以自身精血和紫金炼制了此铃。凭借此铃，她连败正道十余名元婴期修士，威震修真界。后来，一位佛门大能以佛法收服了摄魂仙子，将此铃改造为正道法宝，用于震慑邪魔。

## 同类对比

与**清心铃**相比，紫金铃攻击力更强，但副作用也更大。与**天雷钟**相比，紫金铃更加灵活，但威力稍逊。紫金铃的优势在于音攻无形，敌人难以防御，是音攻法宝中的上品。
