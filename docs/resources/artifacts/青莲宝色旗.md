# 青莲宝色旗

**品阶：** 先天灵宝

**外观：**

旗面一尺见方，青莲花色，旗边绣莲纹。旗面中央绘一朵青莲，青莲绽放，佛光万道。旗杆以菩提灵木所制，长三尺。展旗时，青莲化形，万朵青莲护体。

**炼制材料：**

先天五方旗之一，乃先天木精所化。旗面以先天青锦织就，旗杆取自西方菩提之木，青莲乃先天佛灵凝聚。

**特性：**

青莲宝色旗展开，青莲万朵，诸邪不侵。一切魔功邪法、外道神通，遇佛光尽消。佛光普照，专克魔道。立于旗下，万邪不侵，诸魔退避。

**神通：**

- 青莲护体，万邪不侵
- 佛光所照，魔道尽消
- 旗展自成佛国，隔绝外力
- 可增幅佛门神通威力

**使用限制：**

需大罗金仙以上修为方可完全展开。魔道先天之宝可污此旗。若修为不足，佛光暗淡。

**持有者/典故：**

原为接引道人所有，后赐门下弟子。封神之战中，此旗护持西方教弟子，魔道神通皆不能伤。后此旗归西方极乐世界。

**传承脉络：**

此旗乃先天五方旗之一，为鸿钧道祖于紫霄宫分宝时赐接引道人。接引道人赐门下弟子，封神后归西方极乐世界。后此旗为西方教镇教之宝，护持西方净土。

**克制关系：**

盘古幡可破此旗，以混沌之力击碎青莲。混沌钟以混沌之气隔绝佛光。魔道先天之宝（如诛仙四剑）可污此旗，以煞气破佛光。

**历史战绩：**

西方教弟子持此旗入万仙阵，截教魔功邪法皆不能伤。后此旗归西方极乐世界，接引道人以此旗护持西方净土，魔道修士不敢近。

**同类对比：**

与杏黄旗同为五方旗，然杏黄旗主全面防御，青莲宝色旗主佛防。论防御全面性，杏黄旗胜；论对魔道防御，青莲宝色旗为最。青莲宝色旗佛光普照，专克魔道，论对魔防御无出其右。

**法宝评价：**

青莲宝色旗乃先天五方旗之佛旗，青莲万朵，佛光普照。此宝位列先天灵宝前二十五，为佛门防御之宝第一。封神后此旗为西方极乐世界镇教之宝，护持西方净土，魔道修士不敢近。此旗一出，佛光普照，魔道修士如遇天敌。

**后世影响：**

青莲宝色旗之名，已成为"佛门防御"的代名词。后世佛门仿此旗炼制众多仿品，如"青莲旗"、"佛光旗"等，然仿品威力十不存一。此宝之佛光普照，更是后世佛门法宝之典范。
