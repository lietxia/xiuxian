# 混天绫

**品阶：** 仙器（上品）

**外观：**

一匹红绫，长一丈二尺，宽一尺。绫面绣金色云纹，隐隐有水波荡漾。红绫飘动时，水声潺潺，似有江海藏于其中。可大可小，大则百丈，小则寸许。

**炼制材料：**

- 天绫之水三两
- 云灵丝一斤
- 先天水精一缕
- 太乙真人三昧真火淬炼

**特性：**

混天绫一经展开，可翻江倒海。绫中藏江海之力，一展之下，江海倾覆。更可缠绕敌身，使其动弹不得。绫中水灵，可操控天下万水。

**神通：**

- 翻江倒海，江海倾覆
- 缠绕敌身，动弹不得
- 操控天下万水
- 可大可小，变化随心

**使用限制：**

需金仙以上修为方可催动。若对方有土属性法宝，可克此绫。修为差距过大时，控制效果减弱。

**持有者/典故：**

太乙真人镇洞之宝，后传于哪吒。哪吒以此绫翻江倒海，震动龙宫。封神后哪吒成圣，此绫留于天庭武库。

**传承脉络：**

此宝乃太乙真人于乾元山金光洞炼制，为镇洞之宝。后传于哪吒，哪吒封神后成圣，此绫留于天庭武库。后赐予水德星君，为天庭水部镇部之宝。

**克制关系：**

玄元控水旗可克此绫，以玄冥真水控天绫之水。定海珠定住水势，绫不得展。其余水系法宝，多半被此绫压制。

**历史战绩：**

哪吒以此绫翻江倒海，震动龙宫，龙王亦不敢犯。封神后哪吒成圣，此绫留于天庭武库，为水德星君所掌。

**同类对比：**

与乾坤圈同为哪吒法宝，然乾坤圈主禁锢，混天绫主控水。论控制范围，混天绫更广；论禁锢能力，乾坤圈更强。混天绫一展，江海皆听号令；乾坤圈一落，敌人动弹不得。

**法宝评价：**

混天绫乃仙器中水系控制第一宝。绫中藏江海之力，一展之下，翻江倒海。此宝位列仙器上品，为哪吒标志性法宝之一。
