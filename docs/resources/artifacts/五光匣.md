# 五光匣

**品阶：** 仙器（极品）

**外观：**

一匣长八寸，宽四寸，通体五色流转。匣盖开合间，青黄赤白黑五道神光迸射而出。匣身刻五行相生相克之图，隐隐有龙吟虎啸之声。五光所照，万物消融。

**炼制材料：**

- 先天木精（东方青华木心）
- 先天金精（西方太白精金）
- 先天火精（南方离火之精）
- 先天水精（北方玄冥真水）
- 先天土精（中央黄壤之精）
- 五行调和玉液一瓶

**特性：**

五光匣内藏五色神光，乃先天五行之精所化。五色神光一刷，无物不落。无论法宝兵器、神通法术，被神光一刷便失去灵性，化为凡铁。五行之内，无物可逃。

**神通：**

- 五色神光刷落万物
- 青光收木、白光收火、赤光收土、黑光收水、黄光收金
- 五光合一，刷人元神
- 匣内自成五行空间，可困敌

**使用限制：**

需太乙金仙以上修为方可催动。五色神光消耗法力极巨，每刷一次便去一成法力。若遇先天至宝（如太极图），神光亦不能落。

**持有者/典故：**

传说为孔宣本命神光所化。孔宣乃上古凤凰之后，背生五色神光，无物不落。后孔宣入佛门，五色神光凝为此匣，留于世间。

**传承脉络：**

此宝乃孔宣五色神光所化。孔宣乃上古凤凰之后，生于混沌初开之时。后孔宣入佛门，为孔雀大明王菩萨，五色神光凝为此匣，留于世间。后此匣归西方极乐世界，为佛教镇教之宝。

**克制关系：**

太极图可破五色神光，以太极阴阳之力化解五行。混沌钟以混沌之气隔绝神光。其余先天至宝，神光亦不能落。

**历史战绩：**

孔宣以此光刷落阐教众多法宝，韦护的降魔杵、雷震子的黄金棍、木遁公明的定海珠，皆被神光刷落。后准提道人亲至，以七宝妙树破五色神光，方才收服孔宣。

**同类对比：**

与混元金斗同为"落宝"类法宝。混元金斗削修为，五光匣落法宝。论对敌手段，五光匣更灵活；论凶残程度，混元金斗更甚。五光匣刷人法宝，混元金斗废人修为，一为夺人依仗，一为断人根基。

**法宝评价：**

五光匣乃仙器中落宝第一宝。五色神光一刷，无物不落，五行之内无物可逃。此宝位列仙器极品，为孔宣本命神光所化，后世无人能仿。
