# 金蛟剪

**品阶：** 先天灵宝

**外观：**

一柄金色剪刀，长一尺二寸。剪身乃两条蛟龙交尾而成，蛟首为刃，蛟尾为柄。开合之间，龙吟阵阵，金光灿灿。双刃相交，有风雷之声。

**炼制材料：**

取两条上古金蛟精魄，以三昧真火淬炼九九八十一日，将蛟魂炼入先天金精之中。需蛟龙自愿献魂，否则炼成亦无灵性。

**特性：**

金蛟剪一剪两段，无物可挡。剪口乃先天金精所凝，锋锐无匹。无论金刚不坏之体、炼体大能，一剪之下皆成两段。更兼蛟魂噬魄，肉身一断，元神亦难逃脱。

**神通：**

- 一剪两段，肉身元神同时断绝
- 祭起时化两条金蛟缠绕敌身
- 蛟口喷金光，中者形神俱灭
- 可大可小，大则百丈，小则寸许

**使用限制：**

需太乙金仙以上修为方可驾驭。剪出必见血，无血不归。若心慈手软、杀意不坚，蛟魂反噬其主。

**持有者/典故：**

三霄娘娘所持，与混元金斗配合使用。赵公明借宝以此剪威震昆仑，后被燃灯道人设计夺去。封神后归天庭宝库。

**传承脉络：**

此宝乃通天教主于碧游宫炼制，赐赵公明。赵公明死后，此宝归三霄娘娘。九曲黄河阵后，元始天尊收此宝，封神后归天庭宝库。后赐予托塔李天王，为天庭镇妖之宝。

**克制关系：**

杏黄旗可挡金蛟剪，金花万朵护体，剪不能入。太极图以阴阳之力化解蛟魂杀意。其余防御法宝，遇此剪多半被一剪两段。

**历史战绩：**

三霄娘娘以此剪对战燃灯道人，燃灯座下梅花鹿被一剪两段，燃灯本人亦险些断臂。赵公明借宝后，一剪将慈航道人金身剪出裂痕，威震昆仑。封神之战中，此剪共剪杀十二人，皆为金仙以上修为。

**同类对比：**

与斩仙飞刀皆为先天杀伐之宝。斩仙飞刀以咒语锁定，金蛟剪以锋锐取胜。斩仙飞刀可杀大罗，金蛟剪更擅破肉身。各有千秋。斩仙飞刀杀人于无形，金蛟剪则血肉横飞，视觉冲击更甚。

**法宝评价：**

金蛟剪乃先天杀伐之宝，锋锐无匹，一剪两段。此宝不锁不定，纯以锋锐取胜，最是简单直接。论杀伐之利，此剪位列先天灵宝前二十。后世炼器师仿此剪炼制众多仿品，然无一能及原品之万一。封神后此宝为天庭镇妖之宝，为托塔李天王所掌。此剪一出，群妖辟易，为天庭征伐之利器。

**后世影响：**

金蛟剪之名，已成为"锋锐无匹"的代名词。后世炼器师仿此剪炼制众多仿品，如"金蛟剪"、"蛟龙剪"等，然仿品威力十不存一。此宝之蛟魂噬魄之能，更是后世邪道修士争相模仿的对象。
