# 虚空炼体丹

**品阶：** 六阶中品

## 外观

银灰色，大如龙眼。丹身半透明，内有银色光雾流转，如云雾缭绕。丹面有空间波纹状纹路，层层叠叠，名曰"虚空纹"。丹香清幽，似远山薄雾与月光混合之气。上品虚空炼体丹置于暗处，可见丹身散发银灰色光晕，空间波纹在光晕中缓缓荡漾。

## 炼制材料

- **主药：** 虚空晶石一块（宇宙深处飘来的神秘晶体，蕴含空间本源之力）
- **辅药：** 混沌灵水一盏（天地初开时的原始之水）、星辰陨铁三两、不灭龙鳞一片
- **药引：** 空间法则碎片（需取自曾经存在过的空间裂缝残迹，蕴含空间法则痕迹）

## 炼制难度

- **丹炉：** 以空间石打造的"虚空炉"为最佳
- **丹火：** 虚空之火炼制，火焰温度忽高忽低
- **成功率：** 一成

六阶中品，虚空晶石极难寻觅，且空间法则碎片更是百年难遇。主炉者须对空间之道有一定理解，否则无法驾驭材料中的空间之力。

## 功效

虚空炼体丹是专攻肉身成圣之路的绝世丹药，其核心理念在于以虚空之力锤炼肉身，令修士之躯脱胎换骨，向着不死之身的方向蜕变。此丹服用后，会在修士体内构建一个"虚空微域"——一个肉眼不可见、却真实存在的微型空间。

- **具体效果：** 肉身不朽、力能扛鼎、空间亲和、疾速自愈
- **服用感受：** 在这个空间内，时间流速与外界不同，修士的肉身会被缓慢而持续地拉伸、挤压、撕裂、重塑。每一次痛苦都会转化为肉身强度的提升，每一次撕裂都会在愈合后变得更为坚韧
- **持续时间：** 锤炼过程持续七日七夜

## 服用禁忌

- 锤炼过程极其痛苦，肉身被虚空反复撕裂重组，往往持续七日七夜，中途不可中断
- 服用后肉身处于极度虚弱状态，约需三十日方能完全恢复
- 锤炼期间神识极度敏锐，感知到的痛苦比常人强烈十倍
- 服用前须完全排空体内灵力，以免空间之力与灵力冲突
- 每名修士一生最多服用三枚，第三枚后效果大减
