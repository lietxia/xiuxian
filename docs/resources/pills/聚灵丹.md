# 聚灵丹

## 丹药概述

**丹药名称：** 聚灵丹
**品级：** 三阶上品
**类型：** 加速修炼类丹药

## 丹药外观

聚灵丹呈清透的淡青色，丹身约小指尖大小，质地晶莹如冰晶，恍若一滴凝固的青色露珠。丹面光滑如镜，丹纹极为细密，呈一圈圈螺旋状由丹心向外发散，如同水波扩散的纹路，被修士形象地称为"灵波纹"。

丹香清冽而空灵，带着淡淡的草木清香之气，仿佛雨后初晴时森林中的气息。若将丹药置于掌心，片刻后掌心会感到温热的跳动感——那是丹中灵旋在自行运转。上品聚灵丹丹身会泛出淡淡的青光，在暗处看去如同一颗微型的青色星辰。极品者丹中可见一道细如发丝的银色光丝缓缓流转，正是"聚灵之核"已然成型的标志。

将一枚上品聚灵丹含入口中，舌尖会感到清凉甘甜，丹力尚未入腹，已有灵气在口腔中弥漫开来。

## 主治/效果

聚灵丹为筑基期修士梦寐以求的修炼加速丹药，其核心功效在于大幅提升灵力吸纳效率。正常修炼时，修士需吐纳天地灵气纳入丹田，而聚灵丹服用后，可在丹田内形成一层"灵旋"，犹如漩涡一般主动吸附周遭灵气，使吸纳速度提升两到三倍。

此丹特别适合以下场景：**闭关冲刺突破**——在冲击筑基中期、后期等关键节点时，灵气需求量剧增，单纯靠自然吸纳往往力有不逮；**灵气稀薄之地修炼**——如荒漠、深海、秘境深处等灵气匮乏之处；**争分夺秒的比斗间隙**——短暂服药即可快速恢复灵力。

服用聚灵丹后，修士周身会浮现淡青色灵光，持续约一个时辰。在此期间打坐修炼，相当于平时三日的功效。连续服用三日配合闭关，效果尤为显著。

突破几率的提升方面，若在冲击筑基中期前连续服用聚灵丹三日，再辅以破境丹冲击瓶颈，成功率可从五成提升至八成左右。但须注意，聚灵丹只提供灵气量上的辅助，真正的境界突破仍需修士自身的感悟与积累。

## 炼制材料

**主药：** 灵芝孢子三钱（须取百年灵芝所产，活性充足者，以紫芝为佳）
**辅药：** 聚灵石粉一钱、五行土（取灵矿脉深处之土）二钱、青木精华一滴、灵泉晶半钱
**药引：** 聚灵草汁液三滴（此草极难培育，为丹药命名之源，需以灵泉日日浇灌三年方可入药）
**药炉：** 青木属性丹炉为佳，木属性温和可控，利于聚灵
**丹火：** 以木属性真火为主，火势须稳而不烈，缓缓逼出药力精华

此丹需以五行相生之理炼制，土生金、金生水、水生木，三种辅药须按特定顺序依次投入。若顺序颠倒，药性相克则丹毁炉废。

## 炼制难度

三阶上品丹药，对炼丹师五行理论基础要求较高。材料搭配顺序、火候五行对应皆有严格讲究。成功率约为三成，资深炼丹师（十年以上）可达六成。由于炼制难度较高，市面流通量较少，每炉最多成丹三枚。

## 服用禁忌与副作用

1. **药效期间切忌中断修炼**——灵旋一旦启动便不可强行中止，否则灵气反噬会导致经脉剧痛。
2. 不可连续服用超过三日，否则体内灵气淤积过重，轻则经脉肿胀，重则走火入魔。
3. 体质虚弱者慎用，气血不足者可能承受不住灵旋高速运转带来的负担。
4. 不可在渡劫前后服用，雷劫余威未消时服用此丹风险极大。
5. 服用后应多饮灵泉水，帮助灵气疏导。
6. 服用期间不可与人斗法，灵旋专注于吸纳灵气，无法兼顾防御。

## 丹方渊源

聚灵丹丹方最早见于三千年前炼丹奇才"灵虚子"之手笔。此人一生痴迷于灵气运转之道，曾闭关四十年只为研究灵气在丹田中的流动规律。出关后创出聚灵丹方，以"外力设旋、以内力养旋"为核心理念，令天下修士的修炼速度迈上一个新台阶。

据《灵虚子丹经》记载，灵虚子本人曾以聚灵丹配合自创功法，仅用六十三年便从筑基修至化神，其速度之快震惊修真界。后人多效仿其法，但无人能企及其成就，盖因聚灵丹虽好，终究只是辅助，天赋与毅力才是根本。
