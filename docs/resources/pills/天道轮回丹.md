# 天道轮回丹

**品阶：** 八阶极品

## 外观

天道轮回丹呈混沌之色，丹身约龙眼大小，质地如混沌般不可捉摸。丹面有无数细密的轮回纹路，仿佛一张微缩的轮回之网，名曰"轮回纹"。丹香极为玄妙，似有似无，闻之令人对轮回有所感悟。上品天道轮回丹置于暗处，可见丹身散发混沌色光晕，轮回纹在光晕中缓缓流动。

## 炼制材料

- **主药：** 天道本源碎片一枚（天地诞生之初，天道第一次显化时遗留的本源碎片）
- **辅药：** 轮回法则结晶、因果法则结晶、命运法则结晶各一份
- **药引：** 天道意志的一缕投影（需以无上秘法，在天道显化之时收取其投影）

## 炼制难度

- **丹炉：** 以天道石打造的天道炉为最佳
- **丹火：** 须在天道显化的特殊时刻进行，整个炼制过程可能跨越数个纪元
- **成功率：** 极低，且无人知晓具体概率

八阶极品，材料几乎不可能收集齐全。天道本源碎片自天地诞生以来只出现一次，且被谁获得已不可考证。

## 功效

天道轮回丹位列八阶丹药之巅，是令无数合道境大能趋之若鹜的绝世神丹。其核心理念在于令服用者窥见天道的终极奥义，在轮回与永恒之间找到那条通往至高境界的道路。

- **具体效果：** 窥见天机、轮回感悟、因果通明、天道共鸣、证道契机
- **服用感受：** 此丹并非直接助人突破，而是给予服用者一次"窥见天道本原"的机会。天道轮回丹服用后，修士将进入一种前所未有的悟道状态——时间、空间、因果、命运、生死，一切法则在眼前交织成一幅完整的画卷
- **持续时间：** 悟道状态可能持续数百年乃至数千年

## 服用禁忌

- 服用此丹后的状态无法预测——每个人的悟道体验都不相同，有人收获颇丰，有人一无所获
- 窥见天道后，服用者可能会陷入长时间的悟道状态，可能长达数百年乃至数千年
- 服用后若无法承受天道的威压，神魂可能崩溃
- 天道意志并非善意——窥见天道本身可能招来天道的"注视"，日后可能面临天道的考验
- 每名修士仅有一次服用机会，第二次服用将毫无效果

## 著名丹师/典故

天道轮回丹位列八阶丹药之巅，是令无数合道境大能趋之若鹜的绝世神丹。此丹只存在于传说中，世间从未有人亲眼见过实物。历史上曾有一位合道境大能尝试炼制此丹，结果引发天道反噬，整个宗门被天罚夷为平地。
