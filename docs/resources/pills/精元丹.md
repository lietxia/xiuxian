# 精元丹

**品阶：** 四品下阶

## 外观

银白色，小如莲子。丹身银光熠熠，仿佛一颗微缩的月亮。丹面光滑如镜，细看之下有无数微小晶面，折射出七彩光芒，名曰"精元晶纹"。丹香清冷，似冰雪与薄荷混合之气。上品精元丹置于暗处，可见丹身散发淡淡的银色光晕，晶面折射出七彩光华。

## 炼制材料

- **主药：** 八百年雪莲子一枚、冰玉髓三两
- **辅药：** 凝霜花五朵、寒露草七株、月华石粉三钱
- **药引：** 月华灵乳九滴（须月圆之夜采集）

## 炼制难度

- **丹炉：** 紫金丹炉（需保温极佳）
- **丹火：** 极低温的冷火炼制，又称"阴火炼"
- **成功率：** 一成

精元丹须以阴火炼制，这对丹师的控火能力提出了极高要求。天下能掌握阴火之法的丹师不过百人。

## 功效

将修士体内的真元反复淬炼、压缩、提纯，去除其中的杂质，使真元更加精纯。真元的精纯度直接影响结丹的成功率和金丹的品质。

- **具体效果：** 极大提升真元精纯度，为结丹做准备
- **服用感受：** 全身清凉舒爽，真元仿佛被冰水洗涤，杂质被一点点挤出体外
- **持续时间：** 药效持续炼化四十九日

## 服用禁忌

- 筑基后期以下服用会被冻伤经脉
- 火灵根修士服用需辅以火属性灵药中和
- 服用期间不可接触火属性灵气
- 每年至多一粒

## 著名丹师/典故

精元丹乃北极冰宫的不传之秘。冰宫坐落在极北冰原深处，宫主为一女性修士，传闻已修炼数千年。她所创的精元丹以极寒灵材入药，辅以极光灵乳，效果远超普通提纯丹药。冰宫弟子结丹率高达七成，远超外界，精元丹功不可没。

## 同类对比

精元丹与归元丹都有提纯净化之意，但归元丹是将杂乱归为一统，精元丹是将现有真元提纯去杂。归元丹如整理杂物间，精元丹如打磨玉石。筑基后期修士若想结丹，精元丹几乎是必备之物。
