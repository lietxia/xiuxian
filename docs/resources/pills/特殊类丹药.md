# 特殊类丹药

特殊类丹药不直接用于战斗或修炼突破，却在修仙生活中扮演着不可或缺的角色。从日常辟谷到改变灵根属性，从驻颜不老到延寿续命，特殊类丹药覆盖了修士生活的方方面面。

---

## 一、避毒丹

避毒丹与解毒丹不同，它并非清除已有的毒素，而是在服用后的一段时间内使修士对毒物免疫。

| 属性 | 详情 |
|------|------|
| **品阶** | 一至五阶（对应免疫同阶以下毒素） |
| **有效时间** | 一阶：一个时辰；三阶：半日；五阶：三日 |
| **免疫机制** | 在体表与经脉外层形成药力屏障，毒素接触即被分解 |
| **限制** | 不可与解毒丹同时服用（药力冲突）；对已中毒者无效 |
| **常见用途** | 探索毒沼秘境、闯荡瘴气之地、对抗毒修 |
| **三阶避毒丹材料** | 百毒草×3、清灵花×2、三阶蛇胆×1、灵泉液 |

---

## 二、辟谷丹

修士闭关修炼时，肉身仍需基本的水谷精气维持。辟谷丹可替代食物与饮水，让修士安心闭关。

| 属性 | 详情 |
|------|------|
| **品阶** | 一阶（无境界限制） |
| **有效时间** | 一枚辟谷七日 |
| **药理** | 丹中蕴含浓缩的天地精气，可直接被肉身吸收，替代食物消化产生的能量 |
| **限制** | 长期服用可能导致肠胃功能退化 |
| **常见用途** | 闭关修炼、长途历练、资源匮乏时 |
| **市场价格** | 5~20灵石/枚 |

---

## 三、驻颜丹/定颜丹

驻颜丹与定颜丹都能永驻容貌，但侧重点不同。

| 属性 | 驻颜丹 | 定颜丹 |
|------|--------|--------|
| **品阶** | 三品中阶 | 二品 |
| **功效** | 永驻容貌，有美容效果 | 永驻容貌，单纯定格 |
| **适用人群** | 女修首选 | 男修首选 |
| **限制** | 每人仅第一枚有效 | 每人仅第一枚有效 |
| **市场价格** | 50~200灵石 | 20~80灵石 |

---

## 四、延寿丹

延寿丹能延长修士的寿元，是寿元将尽者的最后希望。

| 属性 | 详情 |
|------|------|
| **品阶** | 四品至九品（延寿效果递增） |
| **延寿效果** | 四品：三十到五十年；六品：五十到一百年；九品：万年 |
| **限制** | 每人一生仅能服用三到四枚，之后会产生完全抗性 |
| **市场价格** | 四品：5000~10000中品灵石；六品：10000~20000上品灵石；九品：有价无市 |

---

## 五、清虚丹

清虚丹是专为灵兽炼制的特殊丹药，能护住灵兽的神魂，使其在突破时保持清醒。

| 属性 | 详情 |
|------|------|
| **品阶** | 六品上阶 |
| **功效** | 保护灵兽神智，防止突破时走火入魔 |
| **适用人群** | 驭兽师、拥有灵兽的修士 |
| **限制** | 凡兽服之无效；仅对化神期以下的灵兽有效 |
| **市场价格** | 5000~8000上品灵石 |

---

## 六、万兽归元丹

万兽归元丹能令修士与灵兽之间建立心灵链接。

| 属性 | 详情 |
|------|------|
| **品阶** | 五阶上品 |
| **功效** | 建立心灵链接、提升灵智 |
| **适用人群** | 驭兽师、灵兽师 |
| **限制** | 服用前须与灵兽完成契约 |
| **市场价格** | 12000~18000中品灵石 |

---

## 七、特殊类丹药的市场价值

特殊类丹药的市场价值往往远超同品阶的其他丹药，原因在于：

1. **需求特殊**：针对特定人群，需求刚性
2. **材料珍稀**：许多特殊材料可遇不可求
3. **炼制难度高**：炼制手法独特，成丹率低
4. **不可替代性**：许多特殊丹药的功效无法被其他丹药替代

---

*特殊类丹药是修仙生活中不可或缺的一部分。它们可能不直接提升战力，却在某些关键时刻发挥不可替代的作用。*
