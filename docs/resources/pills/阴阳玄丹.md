# 阴阳玄丹

## 丹药概述

**丹药名称：** 阴阳玄丹
**品级：** 五阶中品
**类型：** 阴阳调和类丹药

## 丹药外观

阴阳玄丹是修仙界中最具辨识度的丹药之一——丹身一半纯黑、一半纯白，黑白之间界限分明却又浑然一体，宛如一枚微缩的太极图。丹身约龙眼大小，质地细腻如羊脂玉，黑白两面各自光滑，触手时会有一种奇特的温凉交替之感——白色一面温热，黑色一面清凉。

丹香极为玄妙，并非单一气息，而是冷香与暖香交织——白色半边的丹香清甜如春日百花，黑色半边的丹香幽冷如深冬寒梅。两种截然不同的香气从同一枚丹药上散发，交汇融合后形成一种令人心醉又清醒的独特气息。

上品阴阳玄丹的黑白界限更加分明，且丹身会自行缓慢旋转，仿佛被无形之力推动。极品者丹中的阴阳二气会自行流转，在丹腹内形成微型的阴阳鱼图案，首尾相衔、生生不息。传说将极品阴阳玄丹置于掌心，凝视片刻可感受到一股道韵直入神魂，令人对阴阳之道有所明悟。

## 主治/效果

阴阳玄丹专为体内阴阳失调的修士而设，其核心功效在于**调和体内阴阳二气，化解属性冲突，令灵力运转趋于极致平衡**。

在修仙界中，不少修士因修炼阴阳属性相克的功法，或因服用属性极端的丹药，导致体内阴阳失调——或阴气过盛、手足冰冷、法力阴寒；或阳气过旺、性情暴烈、功法失控。阴阳失调轻则修行受阻，重则走火入魔、灵力逆行。

阴阳玄丹服用后，会在丹田内形成一枚微型的"阴阳鱼眼"，左阴右阳、互抱互融。丹力会引导失调的阴阳二气各归其位、各司其职，原本混乱的灵力运转将重归有序。

此丹的另一重功效鲜为人知：**服用后，修士对阴阳两种属性的法术皆有了一定程度的抗性**，阴寒与烈阳之术加于其身，皆会被体内阴阳之力部分化解。此外，阴阳平衡的修士更容易领悟"太极"之意境，对阴阳类功法的修炼有极大裨益。

服用感受方面，丹药入腹后会兵分两路——清凉之气沿左侧经脉下行，温热之气沿右侧经脉下行，两股药力在丹田处交汇，既不冲突也不融合，而是如同两条首尾相接的鱼，在丹田内缓缓游动。修士会感到一种前所未有的和谐与安定。

## 炼制材料

**主药：** 阴阳玄石一块（天然形成一半黑一半白的灵石，极为罕见，往往在阴阳灵脉交汇处方可得见）
**辅药：** 太阳真火精一滴、太阴月华露三滴、阴阳交泰草一株、两仪花一朵
**药引：** 阴阳交汇之地的地脉灵气（须在每月十五子时，于阴阳山交汇处采集，以玉瓶盛装，须在一炷香内投入炉中，否则灵气消散）
**药炉：** 以黑白双色玄铁铸就的阴阳炉为最佳，普通丹炉难以同时承载两种极致属性
**丹火：** 须在丹炉中同时点燃太阳真火与太阴冷焰，两簇火焰在炉中互不侵犯，以阴阳交泰之力令药性融合

## 炼制难度

五阶中品，炼制过程极为精细，稍有偏差便导致阴阳失衡、丹毁炉亡。主炉者须对阴阳之道有深刻理解，同时掌控冷热两种截然不同的火焰，难度之大非寻常炼丹师可想象。成功率约二成，每炉得丹二至四枚。

## 服用禁忌与副作用

1. **体质极度偏阴或极度偏阳的修士服用后**，初期可能出现剧烈的阴阳对冲反应，如忽冷忽热、情绪大起大落等，约持续三日方能平复。
2. 服用期间忌食极端属性食物，如万年寒冰所化之水、烈阳真火所炙之肉。
3. 不可与任何丹药同服，两种药力之间的冲突可能产生未知后果。
4. 服用后半年内不可修炼性质极端的功法，以免打破刚建立的阴阳平衡。
5. 孕妇及胎儿禁止服用。
6. 心性偏激、易走极端者服用效果大打折扣——阴阳玄丹需以"中正平和"之心承接，心有偏执则药力难行。

## 丹方渊源

阴阳玄丹的丹方传自上古时期的"阴阳宗"，此宗以阴阳大道为立宗之本，门中弟子皆修炼阴阳相济之法。据《阴阳道藏》记载，阴阳宗的创派祖师"太易真人"在阴阳山闭关千年，悟出"孤阴不生、独阳不长"之理，遂以阴阳玄石为基础创出此丹。

阴阳宗覆灭后，其丹方流入魔道，被一位名为"阴阳魔君"的化神修士所得。此魔君以阴阳玄丹为基础，创出了一套阴狠毒辣的阴阳采补之法，令此丹蒙上了一层邪名。直到千年后正道修士重新夺回丹方，洗去其中邪术，方使阴阳玄丹重归正道。
