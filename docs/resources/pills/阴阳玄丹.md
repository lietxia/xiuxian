# 阴阳玄丹

**品阶：** 五阶中品

## 外观

阴阳玄丹是修仙界中最具辨识度的丹药之一——丹身一半纯黑、一半纯白，黑白之间界限分明却又浑然一体，宛如一枚微缩的太极图。丹身约龙眼大小，质地细腻如羊脂玉，黑白两面各自光滑，触手时会有一种奇特的温凉交替之感——白色一面温热，黑色一面清凉。

## 炼制材料

- **主药：** 阴阳玄石一块（天然形成一半黑一半白的灵石，极为罕见，往往在阴阳灵脉交汇处方可得见）
- **辅药：** 太阳真火精一滴、太阴月华露三滴、阴阳交泰草一株、两仪花一朵
- **药引：** 阴阳交汇之地的地脉灵气（须在每月十五子时，于阴阳山交汇处采集，以玉瓶盛装，须在一炷香内投入炉中，否则灵气消散）

## 炼制难度

- **药炉：** 以黑白双色玄铁铸就的阴阳炉为最佳，普通丹炉难以同时承载两种极致属性
- **丹火：** 须在丹炉中同时点燃太阳真火与太阴冷焰，两簇火焰在炉中互不侵犯，以阴阳交泰之力令药性融合
- **成功率：** 二成

五阶中品，炼制过程极为精细，稍有偏差便导致阴阳失衡、丹毁炉亡。主炉者须对阴阳之道有深刻理解，同时掌控冷热两种截然不同的火焰。

## 功效

阴阳玄丹专为体内阴阳失调的修士而设，其核心功效在于调和体内阴阳二气，化解属性冲突，令灵力运转趋于极致平衡。服用后，会在丹田内形成一枚微型的"阴阳鱼眼"，左阴右阳、互抱互融。

- **具体效果：** 调和阴阳、化解属性冲突
- **服用感受：** 丹药入腹后会兵分两路——清凉之气沿左侧经脉下行，温热之气沿右侧经脉下行，两股药力在丹田处交汇，既不冲突也不融合，而是如同两条首尾相接的鱼，在丹田内缓缓游动
- **持续时间：** 药效持续炼化六十日

## 服用禁忌

- 体质极度偏阴或极度偏阳的修士服用后，初期可能出现剧烈的阴阳对冲反应，如忽冷忽热、情绪大起大落等，约持续三日方能平复
- 服用期间忌食极端属性食物
- 不可与任何丹药同服
- 服用后半年内不可修炼性质极端的功法
- 心性偏激、易走极端者服用效果大打折扣

## 著名丹师/典故

阴阳玄丹的丹方传自上古时期的"阴阳宗"，此宗以阴阳大道为立宗之本，门中弟子皆修炼阴阳相济之法。据《阴阳道藏》记载，阴阳宗的创派祖师"太易真人"在阴阳山闭关千年，悟出"孤阴不生、独阳不长"之理，遂以阴阳玄石为基础创出此丹。阴阳宗覆灭后，其丹方流入魔道，被一位名为"阴阳魔君"的化神修士所得。

## 同类对比

阴阳玄丹调理的是"气"的平衡，五行元灵丹构建的是"行"的圆满，两者各有侧重。若修士同时存在阴阳失调与五行不全的问题，应先用阴阳玄丹调和阴阳，再服用五行元灵丹构建五行，先后有序不可颠倒。
