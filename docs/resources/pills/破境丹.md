# 破境丹

**品阶：** 三阶极品

## 外观

破境丹呈赤金之色，丹身约拇指大小，是筑基期丹药中最大的一种。丹面并非光滑，而是布满细密的凸起纹路，如同龟甲上的裂纹，被修士称为"破甲纹"——寓意打破境界壁垒如破盔甲。丹香浓烈而霸道，带着一丝辛辣之气，闻之令人口舌生津、心跳加速。

## 炼制材料

- **主药：** 千年何首乌王（须取九须之首乌，根部有九道灵纹者，缺一道则药力不足）
- **辅药：** 破障石粉二钱（取自雷劫残壁之石，蕴含天雷余威）、龙涎香一钱、麒麟角粉半钱、赤焰草一株
- **药引：** 渡劫失败者遗留的一缕残魂（需在丹成前七日封入炉中，以残魂之执念引动破境之力）

## 炼制难度

- **丹炉：** 以赤铜丹炉为佳，赤铜导热均匀且能承受破障石粉中的天雷余威
- **丹火：** 须以烈阳真火为主导，火势猛而不暴，保持高温煅烧
- **成功率：** 二成

三阶极品，炼制难度极高。需金丹期炼丹师亲自主炉。此丹炼制过程极为凶险——辅药中的破障石粉含有天雷余威，与药引残魂结合时，稍有不慎便引发炸炉。历史上曾有炼丹师因此丹炸炉而丧命。

## 功效

破境丹乃三阶丹药中的翘楚，专为筑基期修士突破瓶颈而设。此丹尤其针对以下情形：筑基初期冲击筑基中期、筑基中期冲击筑基后期、经脉淤堵长期无法精进、修炼停滞不前等。

- **具体效果：** 强行冲开壁垒、打通淤塞经脉
- **服用感受：** 丹力入腹后先是一阵温和的暖意，约一炷香后暖意骤然转为炽热，仿佛有一股火焰从丹田喷涌而出，沿经脉冲向全身。此时修士会感到经脉被猛烈扩张，疼痛与畅快交织
- **持续时间：** 药力持续三个时辰

## 服用禁忌

- 服用此丹后若突破失败，境界壁垒会更为坚固，下次突破难度翻倍，不可轻易尝试
- 体质虚弱、气血不足者强行服用可能导致经脉寸断，终身无缘仙道
- 服用后一个时辰内须全神贯注感应体内变化，切忌与他人交谈或分心他用
- 服用后三日内不可与人斗法，体内药力尚未完全吸收，易被对手引动导致失控
- 同一修士一生服用不可超过三枚，否则会产生耐药性，彻底失效
- 服用前三个月内须保持心境平和，若心浮气躁或心有执念，强行破境易生心魔

## 著名丹师/典故

破境丹的丹方由万年前的丹道大宗师"破虚真人"所创。据《破虚丹录》记载，破虚真人年少时天资平平，修炼至筑基后期便停滞三十年而不得寸进。后他另辟蹊径，以渡劫失败者留下的雷劫残石为引，结合多种烈性药材，终创出破境丹方。破虚真人以自己为试验对象，服下第一枚破境丹后经脉寸断，险些丧命。但他不甘失败，养伤三年后又服下第二枚，这一次终于成功破境。

## 同类对比

破境丹为"攻"，金丹筑基丹为"守"，洗髓丹为"本"。三者之中，洗髓丹从根本上解决问题，但价格昂贵且难以获取；破境丹最直接有效，但也最为凶险。明智的做法是：先以金丹筑基丹稳固根基，再以培元丹温养数月，最后以破境丹一鼓作气破关。
