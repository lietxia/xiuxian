# 炼气散

**品阶：** 四品中阶（散剂）

## 外观

并非丹丸，而是淡金色的细腻粉末，盛于玉瓶之中。粉末在光线下闪烁着细碎金光，如星尘一般。散剂有一种独特的药香，似炒熟的芝麻与蜂蜜混合之味。

## 炼制材料

- **主药：** 六百年金精芝两朵、玉髓参一支
- **辅药：** 金石斛五钱、地脉精三份、乾元花七朵
- **药引：** 无根水化开服用

## 炼制难度

- **丹炉：** 普通丹炉即可（实则不需成丹）
- **丹火：** 文火焙干，不可过火
- **成功率：** 三成

炼气散并非丹药而是散剂，不需要成丹步骤。将药材炼化、焙干、研磨成粉即可。但这反而更难——粉末的细腻程度直接影响药效吸收。

## 功效

筑基期修士以灵泉水调服，粉末入腹即化，药力迅速扩散至四肢百骸。每日一服，可代替三个时辰的打坐修炼。

- **具体效果：** 持续滋养经脉，加速筑基期修炼
- **服用感受：** 温和而持久，如春风拂体，并无明显冲击感，但日积月累效果显著
- **持续时间：** 每服效果持续六个时辰

## 服用禁忌

- 不可直接吞服干粉，否则会灼伤食道
- 须以灵泉水调服，普通水效果减半
- 炼气期修士承受不住药力
- 开瓶后须在七日内用完，否则药效流失
- 孕妇禁用

## 著名丹师/典故

炼气散在散修中极受欢迎。散修大多囊中羞涩，买不起完整的丹药，而散剂价格仅为同品丹药的三分之一，效果却有七成。且散剂便于分次服用，对精打细算的散修来说是上上之选。有散修笑言："一粒丹够买三瓶散，省下的灵石买肉吃不香吗？"

## 同类对比

炼气散与聚灵丹虽皆可辅助修炼，但炼气散是持续滋养型，如同喝补汤；聚灵丹是爆发加速型，如同猛火快炒。炼气散适合日常修炼，聚灵丹适合突破瓶颈。散修多选炼气散，宗门弟子则二者兼备。
