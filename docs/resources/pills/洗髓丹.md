# 洗髓丹

## 丹药概述

**丹药名称：** 洗髓丹
**品级：** 五阶下品
**类型：** 脱胎换骨类丹药

## 丹药外观

洗髓丹成丹后，通体呈深玉之色，丹身约龙眼大小，圆润如珠。丹面遍布细密的金色丹纹，纹路如经络般纵横交织，细看之下仿佛有微光在纹路中流转。若置于日光下，丹身会折射出一种介于碧绿与幽蓝之间的奇特光泽，恍若万年古玉浸于深潭。

丹香极为独特——非花非木，而是一股清冽如冰雪融化后混合着淡淡药草的气息。闻之令人神清气爽，但不可久嗅，否则神思过度活跃，竟有经脉微微发痒之感，正是丹力已在悄然影响肉身之兆。

上品洗髓丹丹面可生九道金纹，合称"九龙洗髓纹"，丹身温润如玉，触手生温。极品者丹中会生出一滴灵液，在丹腹内自行流转，如同微型灵泉藏于丹中，映日可见液光摇曳。

## 主治/效果

洗髓丹乃金丹期修士梦寐以求的蜕变之丹，其功效在于**从根本上洗净修士骨髓经脉中的杂质污垢，完成一次彻彻底底的脱胎换骨**。

此丹与低阶的培元丹有本质区别——培元丹只是温养经脉，而洗髓丹则是将经脉、骨骼、骨髓全部重新塑造。服用后，修士体内的每一滴血液、每一根骨骼、每一条经脉都会被丹力冲刷，那些因服用劣质丹药、接触邪气、斗法受伤而残留体内的淤毒杂质，都会在丹力的涤荡下化为黑烟从周身毛孔排出。

洗髓丹最惊人的效果在于**提升灵根品质**。部分修士灵根驳杂，修炼资质平平，服用此丹后，丹力会如清泉冲刷泥沙一般，将灵根中的杂质剥离，令原本浑浊的灵根趋于纯净。灵根品质的提升，意味着修行上限的拔高，更意味着寿元的隐性延长。

此外，经洗髓后的肉身对天地灵气的亲和度大幅提升，修炼速度可在原基础上提升五成以上，且日后服用高阶丹药时，吸收效率也将显著提高。

## 炼制材料

**主药：** 洗骨花一朵（仅生长于万年古战场遗址，花开时香气可令枯骨生肌）
**辅药：** 天蚕丝精三钱、玉髓泉水一盏、九幽寒铁粉半钱、万年石钟乳两滴
**药引：** 修士一缕本命精元（须在服药前分离出，与丹力共同作用于肉身）
**药炉：** 以九幽寒铁铸造的丹炉为底，压制洗骨花的燥烈之气，使药性归于温和
**丹火：** 须以地心熔火为源，辅以修士自身金丹之火，交替煅烧七日七夜

## 炼制难度

五阶下品，需要金丹期以上的炼丹师方可炼制，且对药材年份要求极为苛刻——洗骨花须开满九九八十一日方可入药，否则药性不足。成功率约为二成，每炉得丹一至三枚。

## 服用禁忌与副作用

1. **洗髓过程极为痛苦**，仿佛有万蚁噬骨、千火焚身，意志不坚者可能痛晕过去，但切不可中断药力运转，否则前功尽弃且损伤更大。
2. 服用前须排空体内灵力，否则丹力与灵力相冲可能导致经脉寸断。
3. 洗髓期间会排出大量黑色污垢与恶臭气体，需在密闭空间且有人护法方可服用。
4. 洗髓后三日内身体极度虚弱，须由他人照顾。
5. 每人一生服用不可超过两枚，第三枚将产生严重排异反应。
6. 孕妇及胎儿禁止服用。
7. 天生气血两虚或先天体弱之人，服用前须以温补丹药调理三月，否则洗髓之力过猛，恐伤根本。

## 丹方渊源

洗髓丹之丹方相传出自上古时期一位名为"骨道人"的散修。此人天资驽钝，灵根驳杂不堪，修行百年仍困于筑基后期。后因偶然坠入万年古战场遗址，于白骨累累中发现一株奇异之花——洗骨花。骨道人以此花为主药，穷尽三十年光阴反复尝试，终在寿元将尽之际创出洗髓丹方，服用后一举洗去灵根杂质，三年内凝成金丹。

后世多位传奇人物皆受益于此丹。三千年前的天剑宗宗主柳白眉，便是以一枚极品洗髓丹洗去双属性驳杂灵根，化为纯金灵根，终成一代剑仙。其事迹至今仍在修士间传颂，洗髓丹亦因此被冠以"换骨丹"之美名。
