## 四、炼丹术特色设定

### 4.1 丹雷体系（斗破苍穹）

| 丹药等级 | 丹雷类型 | 说明 |
|----------|---------|------|
| 七品低阶~中阶 | 普通天地异象 | 无丹雷 |
| 七品高阶 | 普通丹雷 | 丹药开始有灵智会逃跑 |
| 八品 | 二色~九色丹雷 | 颜色数越多品质越高 |
| 九品宝丹 | 黑魔雷 | 威力在九色丹雷之上 |
| 九品玄丹 | 丹雨异象 | 需凝聚天地之力 |
| 九品金丹 | 九玄金雷 | 最高阶雷劫 |
| 帝品 | 无 | 已超脱丹雷范畴 |

### 4.2 丹毒体系

丹毒是丹药中残留的杂质，在体内淤积会导致：
- 瓶颈提升（更难突破）
- 灵气运转不顺
- 境界与寿命逐渐下降

**抗性机制**：同种丹药服用越多，效果越差。高品质（极品/无垢）可避免或减少抗性。

### 4.3 炼丹成功率影响因素

| 因素 | 影响 |
|------|------|
| 炼药师等级 | 必须≥丹药等级 |
| 灵魂境界 | 凡境→一品至七品；灵境→八品；天境→九品；帝境→帝品 |
| 异火/丹火品质 | 异火大幅提升成丹率与药力 |
| 药鼎品质 | 影响温度控制和稳定性 |
| 灵脉等级 | 高灵脉环境提升丹药品质上限 |
| 材料年份 | 年份越高药力越强 |
| 丹方完整度 | 缺少关键步骤可能导致失败 |

### 4.4 丹方构成要素

一个完整的丹方通常包括：
1. **主药**（1~3种）— 决定丹药的核心功效
2. **辅药**（3~10种）— 调和药性、辅助药效
3. **药引**（0~1种）— 引导药力融合
4. **魔核/妖丹**（0~1枚）— 提供能量核心
5. **特殊材料**（依丹而定）— 如异火、丹雷、灵泉等

## 六、创作参考建议

1. **境界匹配原则**：丹药等级应略高于修士当前境界才有突破效果。筑基丹对应炼气大圆满，结金丹对应筑基大圆满。
2. **丹毒设定**：合理的丹毒设定增加真实感，如"每人最多服三枚筑基丹，之后无效"。
3. **产业链逻辑**：高品丹药需要大量低品丹药做基础，形成资源金字塔。
4. **稀缺性控制**：筑基丹主药不可人工种植→导致筑基丹产量受限→引发宗门争夺→推进剧情。
5. **年份与药效**：灵药年份决定药力上限，年份差距呈指数增长（百年→千年→万年→十万年）。
6. **特色创新**：丹纹、丹雷、丹兽、丹雨、丹劫等异象增加丹药出现的仪式感和剧情张力。
