## 一、丹药等级体系对照

不同小说的丹药等级体系有所差异，下表展示主流体系对照：

### 1.1 通用品阶体系（凡人流/传统修仙）

| 品阶 | 特征 | 对应修士等级 | 代表丹药 |
|------|------|-------------|---------|
| 一品（下/中/上/极品） | 药味稀薄，基础效果 | 炼气期 | 培元丹、聚气丹 |
| 二品 | 药效显著提升 | 炼气后期~筑基初期 | 筑基丹、真元丹 |
| 三品 | 药力充沛，价格高昂 | 筑基期 | 降尘丹、昊元丹 |
| 四品 | 丹香四溢，附带能量波动 | 筑基后期~金丹 | 结金丹、增元丹 |
| 五品 | 成形时产生能量涟漪 | 金丹期 | 培婴丹、皇极丹 |
| 六品 | 炼制耗时极长，引发天地异变 | 元婴期 | 化神丹、绛云丹 |
| 七品 | 引来丹雷，丹药具初步灵智 | 化神~炼虚 | 菩提丹、生骨融血丹 |
| 八品 | 极强灵智，可与人拼斗，多色丹雷 | 炼虚~合体 | 一始丹、九阴黄泉丹 |
| 九品（宝丹/玄丹/金丹） | 可化人形/兽形，黑魔雷/九玄金雷 | 大乘~渡劫 | 雷劫丹、帝品雏丹 |
| 帝品/神丹 | 传说级，含位面源气，可助成帝 | 仙人以上 | 帝品雏丹 |

### 1.2 本体系特色设定

本丹药体系在传统修仙体系基础上，增加了以下特色设定：

1. **丹纹系统**：丹纹越多，丹药品质越高，最高九纹
2. **丹象系统**：高品阶丹药出炉时会产生天地异象
3. **丹劫系统**：五品以上丹药成丹时会引发天劫
4. **超品丹药**：九品之上更有灵丹、天丹、仙丹、神丹四重天
5. **丹毒系统**：所有丹药都含有丹毒，需定期排毒

## 四、丹药命名规则

### 4.1 命名规律

1. **品阶越高，名字越长**：一品丹多为两字（如聚气丹），九品丹多为五字以上（如宇宙创世丹）
2. **功效决定名字**：名字通常直接反映丹药的主要功效
3. **材料决定前缀**：部分丹药以主药命名（如九曲灵参丹）
4. **意境决定后缀**：部分丹药以意境命名（如大道归真丹）

### 4.2 常见命名前缀

| 前缀 | 含义 | 示例 |
|------|------|------|
| 九转 | 需九次炼制 | 九转还魂丹、九转生死丹 |
| 五行 | 涉及五行之力 | 五行元灵丹 |
| 万 | 数量极多 | 万法归一丹、万兽归元丹 |
| 天 | 涉及天道之力 | 天罚雷劫丹、天道轮回丹 |
| 大 | 涉及大道之力 | 大道归真丹 |

## 五、丹药服用注意事项

### 5.1 服用时机

- **修炼丹**：最好在每日打坐修炼前服用，药效可持续两个时辰
- **突破丹**：须在突破瓶颈的关键时刻服用，过早过晚皆无效
- **疗伤丹**：受伤后越早服用越好
- **解毒丹**：中毒后立即服用，毒素扩散到丹田后再吃，药力就赶不上了

### 5.2 服用剂量

- 修炼丹：一日之内不宜超过三颗，否则丹毒积累反而拖慢修行
- 突破丹：一生仅能服用一到三次，再多则产生耐药性
- 疗伤丹：根据伤势轻重，每日一到三枚
- 解毒丹：根据中毒程度，每日一到两枚

### 5.3 服用禁忌

- 不同丹药不可随意搭配服用，药性冲突可能导致严重后果
- 服用丹药后须运功炼化，否则药力散逸，浪费丹药
- 服用丹药期间忌食与药性相克的食物
- 孕妇及特殊体质者服用前须咨询炼丹师
