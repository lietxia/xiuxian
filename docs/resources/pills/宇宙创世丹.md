# 宇宙创世丹

**品阶：** 九阶中品

## 外观

宇宙创世丹呈混沌之色，丹身约龙眼大小，质地如混沌般不可捉摸。丹面有无数细密的创世纹路，仿佛一张微缩的创世之网，名曰"创世纹"。丹香极为玄妙，似有似无，闻之令人对创世有所感悟。上品宇宙创世丹置于暗处，可见丹身散发混沌色光晕，创世纹在光晕中缓缓流动。

## 炼制材料

- **主药：** 创世神晶一块（传说中盘古开天辟地时遗留的神晶，蕴含创世之初的力量）
- **辅药：** 混沌五太精华各一份（太易、太初、太始、太素、太极）、三千大道法则本源各一丝
- **药引：** 一缕创世神念（需取自以创世证道的至高存在遗留的神念印记）

## 炼制难度

- **丹炉：** 以创世石打造的创世炉为最佳
- **丹火：** 须在天地初开之地进行，且需至少九九八十一位合道境大能同时护法
- **成功率：** 从未有过记录

九阶中品，炼制难度超越想象。创世神晶只存在于传说中，混沌五太精华更是只在天地初开时短暂出现。炼制可能横跨数个纪元。

## 功效

宇宙创世丹是超越凡人想象的绝世神丹，专为欲以"创世"之道突破至高境界的至强者而设。其核心理念在于在服用者体内种下一颗"创世之种"，令服用者具备开天辟地、创造世界的无上潜能。

- **具体效果：** 一念宇宙、内宇宙加持、创世法则、宇宙同寿、宇宙轮回
- **服用感受：** 服用此丹后，修士体内会诞生一个微型宇宙。这个宇宙虽然渺小，却五脏俱全——有日月星辰、有山川河流、有天地法则。修士的一举一动、一呼一吸，都能影响这个内宇宙的运转
- **持续时间：** 永久性效果

## 服用禁忌

- 内宇宙的形成需要漫长岁月——丹药只是种下种子，真正构建宇宙需要服用者数千乃至数万年的培育
- 服用后，服用者将背负创世之责——内宇宙中若诞生智慧生命，服用者便是他们的"天道"
- 创世之责不可推卸，内宇宙若毁灭，服用者将承受反噬
- 服用后，服用者的修为将与内宇宙共同成长，内宇宙越强大，服用者越强大
- 服用后，服用者可能变得孤独——宇宙的创造者，与宇宙中的生命终究是两个世界的存在

## 著名丹师/典故

宇宙创世丹是超越凡人想象的绝世神丹。此丹为传说中最强丹药之一，世间从未炼制成功过，仅存在于理论之中。历史上曾有一位至高存在尝试炼制此丹，结果引发了时空乱流，差点毁灭整个修真界。

## 同类对比

宇宙创世丹与本源归一丹皆有窥见宇宙本源之效，但本源归一丹是"窥见宇宙本源"，宇宙创世丹是"在体内创造宇宙"。本源归一丹如观画，宇宙创世丹如作画。前者更玄妙，后者更逆天。
