## 三、炼丹步骤详解

### 第一步：备料

将主药、辅药、药引按照丹方要求进行预处理。有的需要研磨成粉，有的需要榨取汁液，有的需要浸泡灵泉。备料的质量直接决定炼丹的下限。

**备料要点**：
- 药材需在特定时间采集（如清晨露水、子时露水）
- 药材需以特定方式保存（如玉盒、蜡封）
- 药材需以特定工具处理（如玉石臼、不可沾铁器）

### 第二步：温炉

以文火慢慢加热丹炉，使炉内温度均匀，激活炉壁上的聚灵阵法。温炉不充分，炼丹时容易受热不均。

**温炉要点**：
- 温炉时间：一品丹半个时辰，九品丹七日七夜
- 温炉温度：略高于体温
- 温炉火候：文火，不可急躁

### 第三步：融药

按顺序投入药材，先放难以融化的矿物类材料，再放草木类材料，最后放最娇贵的药引。每一步都需要精确的温度控制和时机把握。

**融药要点**：
- 投药顺序：先矿物，后草木，最后药引
- 投药时机：前一种药材完全融化后再投下一种
- 搅拌手法：以灵力或神识引导药力融合

### 第四步：凝丹

所有药材在丹炉中完全融合后，以特殊手法催动药力凝聚成丹。这是最关键的一步，需要炼丹师以神识细致入微地观察炉内变化，随时调整火候。

**凝丹要点**：
- 凝丹时机：药液转为特定颜色时
- 凝丹火候：根据丹药种类调整
- 凝丹手法：以神识引导药力凝聚

### 第五步：收丹

丹药成型后，在最佳时机开炉取丹。收丹过早则丹药未成，药效不足；过迟则丹药被火气侵蚀，品质下降。

**收丹要点**：
- 收丹时机：丹炉冒出特定颜色烟气时
- 收丹手法：以灵力包裹丹药，防止药力散逸
- 收丹容器：玉瓶、玉盒等不易导热的容器

### 第六步：养丹

高阶丹药往往需要出炉后的"养丹"过程。将丹药放置在灵气充沛之处，让其自然吸收灵气，进一步稳固药力。

**养丹要点**：
- 养丹环境：灵气充沛的洞府或灵脉
- 养丹时间：一品丹无需养丹，九品丹需养丹数年
- 养丹效果：可提升丹药品级

## 五、炼丹禁忌与注意事项

### 5.1 炼丹禁忌

1. **忌杂念**：炼丹时不可有一丝杂念，否则丹力不纯
2. **忌急躁**：火候不可急躁，否则丹毁炉炸
3. **忌污秽**：炼丹环境必须洁净，否则丹力受污
4. **忌相克**：药材不可随意搭配，药性相克会导致炸炉

### 5.2 炼丹注意事项

1. **环境要求**：炼丹需在灵气充沛、环境稳定的地方进行
2. **时辰选择**：不同丹药有不同的最佳炼制时辰
3. **火候控制**：火候是炼丹的核心，差之毫厘谬以千里
4. **丹毒处理**：炼制过程中产生的丹毒需及时清除
