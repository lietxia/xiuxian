# 腾龙丹

**品阶：** 六品中阶（妖族专属）

## 外观

金红色，大如鸽卵。丹身金红交织，隐隐有龙鳞状纹路浮现。丹面有龙形虚影游动，时隐时现，名曰"腾龙纹"。丹香霸道浓烈，似龙血与烈焰混合之气，闻之令妖兽血脉沸腾。上品腾龙丹置于暗处，可见丹身散发金红色光晕，龙形虚影在光晕中游动。

## 炼制材料

- **主药：** 化龙草三株、龙血芝一朵
- **辅药：** 蛟龙鳞粉三钱、凤凰羽一根、万年石钟乳一盏
- **药引：** 真龙精血一滴（或以五阶蛟龙精血替代）

## 炼制难度

- **丹炉：** 龙纹赤铜炉
- **丹火：** 龙炎之火炼制，需持续高温
- **成功率：** 不足半成

腾龙丹的药材举世难寻——化龙草只生长在真龙出没之地，龙血芝需以龙血浇灌万年方可成材。整个修真界能凑齐材料的势力不超过三家。

## 功效

此丹专为妖族设计，服下后可大幅提升化形成功率，纯化血脉，甚至帮助蛟龙化龙。

- **具体效果：** 辅助妖族化形、纯化血脉、提升化形成功率
- **服用感受：** 体内血脉如沸腾，骨骼肌肉重组，痛苦但充满力量
- **持续时间：** 药效持续炼化三月，化形过程不可中断

## 服用禁忌

- 非妖族服用无效，反而会血脉逆流
- 化形期间需大量吸收灵气，最好在灵脉上闭关
- 一生仅能服用一次，第二次无效
- 化形失败将修为倒退，严重者爆体而亡

## 著名丹师/典故

腾龙丹乃龙族所创。上古时期，龙族为帮助蛟龙族后裔化龙，以本族精血配合化龙草创出此丹。龙族隐世后，腾龙丹的丹方流入妖族各大势力，成为妖族至宝。每一次腾龙丹在拍卖会上出现，都会引起妖族各大势力的疯狂争夺。

## 同类对比

腾龙丹与化形丹皆为妖族丹药，但化形丹是基础化形辅助，腾龙丹是高级血脉纯化。化形丹如开门，腾龙丹如登堂入室。妖族通常先服化形丹完成初步化形，再服腾龙丹纯化血脉。
