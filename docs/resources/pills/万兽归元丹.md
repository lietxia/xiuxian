# 万兽归元丹

## 丹药概述

**丹药名称：** 万兽归元丹
**品级：** 五阶上品
**类型：** 御兽增益类丹药

## 丹药外观

万兽归元丹呈暗赤之色，丹身约龙眼大小，质地并不光滑，而是布满细密的鳞甲状纹路，如同某种妖兽的皮肤纹理，被修士称为"万兽鳞纹"。丹身敦实沉重，远超同体积的其他丹药，仿佛里面封存的不是药力，而是一头沉睡的猛兽。

丹香极为霸道，带有一股浓烈的血腥之气与野性的腥膻之味交织而成的复杂气息。初次嗅到者可能会本能地感到心悸——这是修士体内的灵性在感知到万兽之力的本能反应。但对于驭兽师而言，此香如同醇酒，闻之令人血脉偾张、与灵兽的心灵联系仿佛更加紧密了。

上品万兽归元丹丹身会散发出淡淡的血光，置于暗处可见丹中仿佛有无数细小的兽影在奔突。极品者丹中十种妖兽精血各据一方，在丹腹内化为十道微型的妖兽虚影，绕着丹心缓缓追逐，发出只有驭兽师才能感知到的微弱灵魂波动。这种极品丹被称为"万兽朝宗"，是整个御兽界梦寐以求的至宝。

## 主治/效果

万兽归元丹乃驭兽师一脉的无上珍宝，其核心功效在于**令修士与灵兽之间的灵魂联系发生质的飞跃，从主从关系进化为"心意相通"**。

服用此丹后，修士眉心会生出一枚"万兽印记"，从此与契约灵兽之间建立了心灵层面的直接连接。无论相隔多远，修士都能感知灵兽的位置、状态、情绪甚至是模糊的想法；而灵兽也能在更深层次上理解主人的意图，无需言语命令即可默契配合。

此丹最令人称道的效果，是它能**大幅提升灵兽的灵智与成长潜力**。许多野生灵兽因灵智未开，修炼到一定程度后便再难寸进。服用万兽归元丹后，灵兽的灵智仿佛被开启了一扇窗户，能理解更复杂的道理、学习更精妙的法术、突破原本的血脉桎梏。

对于拥有多只灵兽的驭兽师而言，此丹更是必备之物——丹中的"万兽归元"之意，能令多只灵兽之间也建立心灵链接，从此协同作战如同一个整体，进退有度、配合天衣无缝。

服用感受极其独特：丹力入腹后，修士会感到眉心一阵刺痛，仿佛有什么东西在烙印。随后大量杂乱无章的兽性意念涌入脑海——这是丹中十种妖兽精血中残留的本能记忆。修士必须用自身意志压制这些兽性意念，将其驯服、归化，最终化为己用。若能成功度过这一关，眉心的万兽印记便会成形，与灵兽的心灵链接也将正式建立。

## 炼制材料

**主药：** 万兽精血一份（须取自十种不同妖兽，各取其精血三滴，融合而成。十种妖兽中须涵盖走兽、飞禽、鳞甲、虫豸四类，缺一则不可称为"万兽"）
**辅药：** 通灵神木屑二钱、兽魂晶一枚（取自即将突破的妖兽，死后魂魄凝聚而成）、百草甘露半盏、血菩提三颗
**药引：** 驭兽师与灵兽各一滴精血（须在服药时同时滴入，以血为桥连接彼此灵魂）
**药炉：** 以兽骨熔铸的"兽骨鼎"为最佳，普通丹炉无法承载万兽精血的暴烈之气
**丹火：** 须以妖兽内丹之火为源——以一枚火属性妖兽内丹投入炉底，燃烧释放的兽火与丹中药性同源，可大幅提升融合度

炼丹时需将十种妖兽精血依次注入，每种间隔一个时辰，以特定顺序引导药性归元。顺序稍有错乱，轻则药性冲突丹毁，重则万兽反噬炸炉。

## 炼制难度

五阶上品，炼制难度极高。辅药中的通灵神木屑极难获取——此木只生长于灵兽埋骨之地，百年方长一寸。且主药中十种妖兽精血的融合顺序不得有丝毫差错。成功率约一成半，每炉得丹一至二枚。

## 服用禁忌与副作用

1. **服用前须与灵兽完成契约**，否则印记无法落地，药力消散。
2. 服用后三日内，修士与灵兽之间会出现短暂的心灵过载期，双方都可能出现头痛、幻觉等症状，属正常现象。
3. 印记一旦生成便不可消除，修士若欲更换契约灵兽，将付出巨大代价。
4. 若灵兽死亡，印记会反噬修士神识，造成严重创伤，轻则神识受损三月，重则修为倒退。
5. 服用后修士身上会残留淡淡的妖兽气息，低阶妖兽可能将其视为同类或敌人。
6. 不可在灵兽怀孕或受伤期间服用。
7. 心性懦弱者慎用——驯服万兽印记需要强大的意志力，否则会被兽性意念反噬，导致性情大变。

## 丹方渊源

万兽归元丹的丹方由万年前的驭兽大宗师"兽皇"所创。据《万兽真经》记载，兽皇年轻时曾驯服过九十九头妖兽，却始终无法与它们建立真正的心灵连接。后来他在一次深入蛮荒的历练中，无意间发现了一处天然形成的"万兽坑"——那是无数妖兽死后精血渗入土壤，历经万年形成的奇特地貌。

兽皇在万兽坑中闭关十年，以自身精血为引，与万兽坑中的妖兽残魂沟通，终于悟出了"万兽归元"之理。出关后他走遍天下，寻找十种最强妖兽的精血，历经百年方集齐材料，炼成了第一枚万兽归元丹。服用后，他与自己的九十九头灵兽同时建立了心灵链接，成为修仙史上第一位真正意义上的"万兽之主"。
