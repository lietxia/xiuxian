# 天机神算丹

**品阶：** 六阶上品

## 外观

天机神算丹呈银蓝色，丹身约拇指大小，质地如水晶般通透。丹面有细密的星图纹路，仿佛一张微缩的周天星辰图，名曰"天机星纹"。丹香清幽，似夜空中传来的淡淡星辉气息。上品天机神算丹置于暗处，可见丹身散发银蓝色光晕，星图纹在光晕中缓缓旋转。

## 炼制材料

- **主药：** 天机石一块（天界坠落的神秘灵石，蕴含天道运转的部分规律）
- **辅药：** 悟道茶叶三片（悟道茶树所产，服之可短暂提升悟性）、智慧树汁三滴（传说中通天建木的一滴汁液所化）、周天星图残片一份
- **药引：** 一缕天机阁历代传承的天机烙印（以此为引，使丹力与天道相合）

## 炼制难度

- **丹炉：** 以星辰石打造的"星图炉"为最佳
- **丹火：** 须在夜观星象之时，以星辉为火、月华为引，令药性与天机相融
- **成功率：** 半成

六阶上品，天机石极为珍稀，且周天星图残片百年难遇。整个炼制过程需耗时一年，每炉得丹仅为一枚。

## 功效

天机神算丹乃天机阁历代相传的秘炼神丹，专为欲窥探天机、推演未来的高阶修士而设。其核心功效在于大幅提升修士的神识推演能力与智慧领悟力，令服用者在一定时限内具备"料事如神"的能力。

- **具体效果：** 推演未来、洞察人心、阵法速成、万法归一
- **服用感受：** 修士眉心泥丸宫会生出一枚"天机符印"，与天道冥冥之中的联系骤然增强。在此状态下，修士的思维将变得无比清晰敏锐
- **持续时间：** 药效持续七日

## 服用禁忌

- 药效仅持续七日，届时天机符印消散，神识可能短暂空虚，约需三日方能恢复
- 药效期间若过度使用推演能力，可能导致天机反噬，出现头痛欲裂、流鼻血等症状
- 服用后不可妄言天机——将自己推演之事告知他人，会削弱推演准确性
- 每人一生服用不可超过两枚，第二枚后效果减半
- 不可在服用期间修炼魔道功法，天机与魔气相冲

## 著名丹师/典故

天机神算丹乃天机阁历代相传的秘炼神丹。此丹最令修士心动的用途，是在渡天劫之时。天劫降临时若有天机神算丹相助，修士往往能在电光火石之间做出最正确的判断，大幅提升渡劫成功率。天机阁将此丹列为最高机密，从不外流，市面上流通的皆为仿制品或走私之物。

## 同类对比

天机神算丹与凝神丹皆有增强神识之效，但凝神丹是"扩张感知范围"，天机神算丹是"提升推演智慧"。凝神丹如望远镜，看得更远；天机神算丹如算盘，算得更准。二者可搭配使用，先服凝神丹扩大感知，再服天机神算丹推演天机。
