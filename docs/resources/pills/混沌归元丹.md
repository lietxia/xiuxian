# 混沌归元丹

**品阶：** 八阶中品

## 外观

混沌归元丹呈混沌之色，丹身约龙眼大小，质地如混沌般不可捉摸。丹面有无数细密的混沌纹路，仿佛一张微缩的混沌之网，名曰"混沌纹"。丹香极为玄妙，似有似无，闻之令人对混沌有所感悟。上品混沌归元丹置于暗处，可见丹身散发混沌色光晕，混沌纹在光晕中缓缓流动。

## 炼制材料

- **主药：** 混沌原石一块（宇宙诞生之初的第一块混沌物质，蕴含开天辟地的原始力量）
- **辅药：** 盘古精血三滴（取自盘古陨落后遗留的精血，亿万年来仅发现数滴）、鸿蒙紫气一道
- **药引：** 大道法则碎片一份（需取自陨落的合道境大能遗留的法则烙印）

## 炼制难度

- **丹炉：** 以混沌石打造的"混沌炉"为最佳
- **丹火：** 须在天地初开之地进行，模拟混沌初分的场景
- **成功率：** 一成

八阶中品，混沌原石亿万年来只发现数块，且大小不超过拳头。炼制需在混沌灵气弥漫之地，且需数名合道境大能协助护法。

## 功效

混沌归元丹是令修士蜕变为"混沌体"的绝世丹药，混沌体乃世间最完美的体质之一，与天生道体、先天道体并列。服用此丹后，修士将开启体内沉睡的"混沌血脉"，从此以混沌为名、以天地为炉。

- **具体效果：** 万法不侵、混沌化身、天地同寿、一念成法、诸天万界
- **服用感受：** 混沌体的核心在于混沌包容万有。无论修士原本是何种灵根、何种体质，混沌化之后都将归于"混沌"——一种超越五行、不在三界内的特殊存在
- **持续时间：** 永久性效果

## 服用禁忌

- 服用风险极高——混沌之力极为狂暴，若服用者意志不坚，可能被混沌同化，化为虚无
- 服用后混沌体质开启过程可持续数年，期间修士将经历多次生死考验
- 混沌体修士与天道关系微妙——既受天道庇护，又被天道忌惮
- 混沌体质一旦激活便不可逆转，修士将永远无法离开混沌之道
- 服用后体内灵力将逐渐混沌化，原本修炼的功法可能失效

## 著名丹师/典故

混沌归元丹是令修士蜕变为"混沌体"的绝世丹药，混沌体乃世间最完美的体质之一，与天生道体、先天道体并列。此丹只存在于传说中，世间从未有过成功炼制的记录。历史上曾有一位修士偶然获得一块混沌原石，尝试炼制此丹，结果被混沌同化，化为虚无。
