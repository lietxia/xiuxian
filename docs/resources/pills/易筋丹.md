# 易筋丹

**品阶：** 四品中阶（体修辅助类）

## 外观

暗金色，大如鸽卵。丹身沉重，触手如握精铁。丹面有筋脉状纹路，纵横交错如人体经络图，名曰"易筋络"。丹香浓烈，似铁锈与药酒混合之气，闻之令人筋骨发热。上品易筋丹置于暗处，可见丹身散发淡淡的金色光晕，筋脉纹路在光晕中若隐若现。

## 炼制材料

- **主药：** 四百年龙筋藤一段、虎骨草三株
- **辅药：** 续断花五朵、牛膝根三两、金狗脊二钱
- **药引：** 筑基期妖兽筋腱一条（以形补形）

## 炼制难度

- **丹炉：** 玄铁丹炉
- **丹火：** 武火猛炼三个时辰，后转文火温养
- **成功率：** 四成

此丹最难在药引——妖兽筋腱必须新鲜，且需与服用者修为匹配。筋腱品阶太低则药力不足，太高则经脉承受不住。

## 功效

药力如锤，反复敲打筋骨，疏通经脉淤塞。体修服用后可大幅强化筋骨强度，非体修服用亦可改善体质。

- **具体效果：** 疏通经脉、强健筋骨、提升肉身强度
- **服用感受：** 全身筋骨如被锤击，酸麻胀痛，但过后浑身舒畅、力量倍增
- **持续时间：** 药效持续炼化四十九日，每日皆有改善

## 服用禁忌

- 炼气期修士筋骨太弱，服用有断裂之险
- 服用期间不可剧烈运动，需静养配合
- 每月不超过两粒，多则筋骨过度劳损
- 骨折未愈者禁用

## 著名丹师/典故

易筋丹由佛门达摩院首座所创。达摩院以体修闻名，首座发现弟子们虽法力高深，但肉身强度跟不上，斗法中常因肉身脆弱而吃亏。他遂以龙筋藤为主药，结合佛门锻体之法，创出此丹。达摩院弟子服用易筋丹后，肉身强度提升一个台阶，从此体修与法修并重的理念在佛门扎根。

## 同类对比

易筋丹与锻体丹皆可强化肉身，但易筋丹偏重"疏通经脉、强筋健骨"，适合体修打基础；锻体丹偏重"淬炼皮膜、强化肌肉"，适合外功修炼者。二者可搭配使用，先易筋丹疏通经脉，再锻体丹强化肌肉，内外兼修。
