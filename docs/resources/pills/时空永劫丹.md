# 时空永劫丹

**品阶：** 八阶上品

## 外观

时空永劫丹呈银蓝交织之色，丹身约龙眼大小，质地如时空般不可捉摸。丹面有无数细密的时空纹路，仿佛一张微缩的时空之网，名曰"时空纹"。丹香极为玄妙，似有似无，闻之令人对时空有所感悟。上品时空永劫丹置于暗处，可见丹身散发银蓝交织的光晕，时空纹在光晕中缓缓流动。

## 炼制材料

- **主药：** 时间长河源头之水一份、空间维度夹缝中的神秘物质一份
- **辅药：** 永恒法则结晶三块、时空乱流核心一份、因果锁链三条
- **药引：** 时空大道烙印一枚（需取自以时空证道的合道境大能陨落后遗留的本源烙印）

## 炼制难度

- **丹炉：** 以时空石打造的时空炉为最佳
- **丹火：** 须同时存在于时间与空间两条维度线上，对炼丹师的要求极高
- **成功率：** 半成

八阶上品，炼制材料收集难度极大，且炼制过程需同时操控时间与空间，稍有不慎便会引发时空乱流反噬。

## 功效

时空永劫丹是时空一道的至高丹药，专为欲以时空证道、超越永恒的绝世强者而设。其核心理念在于将时间法则与空间法则在修士体内彻底融合，令修士成为超越时空限制的永恒存在。

- **具体效果：** 时空永恒、时空主宰、时空挪移、时空囚笼、时空轮回
- **服用感受：** 服用此丹后，修士体内的时空法则将发生质的蜕变。原本只是感悟的时空法则，将被丹力催化成"时空法则本源"，成为修士生命的一部分
- **持续时间：** 永久性效果

## 服用禁忌

- 服用后若无法承受时空法则的反噬，修士将被时空乱流撕碎，魂飞魄散
- 时空修士因超脱于常规时空之外，故而天道对其"不兼容"——修炼任何其他法则都极为困难
- 服用后，修士将与时空长河产生联系，可能被卷入时空因果之中，无法脱身
- 时空修士死亡后虽可重生，但每次重生都将遗忘部分记忆，永劫之后可能忘记自己是谁

## 著名丹师/典故

时空永劫丹是时空一道的至高丹药，专为欲以时空证道、超越永恒的绝世强者而设。此丹为传说级丹药，炼制之法早已失传，现存于世的可能不超过三枚。历史上曾有一位时空修士服用此丹后，成为超越时空限制的永恒存在，但也因此失去了所有记忆，忘记了自己是谁。
