# 化神丹

**品阶：** 七阶下品

## 外观

化神丹呈温润的乳白色，丹身约拇指大小，质地柔和如凝脂。丹面有无数细密的神识纹路，仿佛一张微缩的神识之网，名曰"化神纹"。丹香柔和而深远，如同母亲怀抱中的温暖气息。上品化神丹置于暗处，可见丹身散发柔和的白色光晕，神识纹在光晕中缓缓流动。

## 炼制材料

- **主药：** 化神果一枚（天地初开时诞生的神树所结，全界不超过三棵，每年仅结九果）
- **辅药：** 法则结晶三份（取自渡劫成功的化神期大能陨落后遗留的法则碎片）、混沌原石一块
- **药引：** 化神期大能的一缕神识（以已成就化神者的神识为引，为服用者指明方向）

## 炼制难度

- **丹炉：** 以法则石打造的法则炉为最佳
- **丹火：** 须在天地灵气最为浓郁的"洞天福地"炼制，且须每百年中灵气最浓的三日内完成
- **成功率：** 半成

七阶下品，整个修仙界能炼制此丹的炼丹师不超过五人。化神果需等待数十年方能采撷，法则结晶更是可遇不可求。

## 功效

化神丹（七阶）与四阶的化神丹同名，实则天差地别。四阶化神丹仅助神识蜕变，而七阶化神丹则是元婴向化神跨越的根本性阶梯，唯有元婴期大圆满的绝世强者方有资格触碰此丹。

- **具体效果：** 元神出窍、法则感悟、寿元大增、神通自生、天地共鸣
- **服用感受：** 服用此丹后，元婴期修士体内将经历一场从"婴"到"神"的根本性蜕变。元婴会逐渐解化，原本与肉身紧密相连的元婴将变得虚淡透明、几乎与天地融为一体
- **持续时间：** 蜕变期可持续数月

## 服用禁忌

- 服用风险极大——化神之路需依靠自身悟性，丹药只能辅助引路，若服用者悟性不足，可能在蜕变过程中神魂溃散
- 服用前须在天地法则浓厚之地静心悟道至少三年，否则仓促服用必败无疑
- 服用后蜕变期可持续数月，期间不可被打扰，否则前功尽弃且神魂重创
- 蜕变失败后，修士元婴将受损严重，需要数十年方能恢复，且二次冲击化神难度倍增

## 著名丹师/典故

化神丹（七阶）被各大圣地视为镇派之宝，任何一颗的出现都会引发腥风血雨。化神是一道分水岭，化神之下皆为蝼蚁。历史上曾有一位元婴大圆满修士服用此丹后，历经数月蜕变，最终成功化神，成为一代传奇。

## 同类对比

化神丹与元婴塑魂丹皆有辅助突破之效，但元婴塑魂丹辅助金丹到元婴的突破，化神丹辅助元婴到化神的突破。元婴塑魂丹如筑基，化神丹如登天。前者更实用，后者更逆天。
