# 九曲灵参丹

**品阶：** 六品下阶

## 外观

紫金色，大如核桃。丹身紫金流光，华贵非凡。丹面上有九道弯曲回环的金色纹路，宛如九条小龙盘绕，名曰"九曲龙纹"。丹香极为浓郁，似千年灵芝与龙涎香混合之味，开瓶则满室生香，久久不散。上品九曲灵参丹置于暗处，可见丹身散发紫金色光晕，九条龙纹在光晕中游动。

## 炼制材料

- **主药：** 五千年九曲灵参一支（此参天生九曲，每一曲代表千年）
- **辅药：** 万年灵芝一朵、九龙草三株、七彩玉髓五钱、星辰砂三钱
- **药引：** 真龙之血三滴（或以蛟龙精血替代）

## 炼制难度

- **丹炉：** 天龙八部炉或上古遗炉
- **丹火：** 九阳真火炼制，九九八十一日
- **成功率：** 半成以下

九曲灵参丹的主药——五千年九曲灵参——就已是世间难寻之物。此参生长在人迹罕至的灵脉深处，每千年长一曲，五千年方成。再加上真龙之血为引，几乎只有传说中才能凑齐材料。

## 功效

金丹大圆满修士冲击元婴时服下此丹，可感悟天道、沟通天地，结婴成功率提升三至五成。

- **具体效果：** 大幅提升结婴成功率，感悟天道法则
- **服用感受：** 吞下后仿佛灵魂出窍，看到了天地的脉络、法则的运行，对道的理解瞬间深了一层
- **持续时间：** 药效在结婴期间持续

## 服用禁忌

- 金丹中期以下服用无效
- 一生仅能生效一次
- 心性不够者服后可能被天地法则冲垮神智
- 须配合元婴功法使用

## 著名丹师/典故

此丹方传说乃真龙一族所传。上古时期，龙族与人族交好，龙族丹师见人族修士结婴艰难，便以本族精血配合九曲灵参创出此方。后龙族隐世，九曲灵参丹日渐稀少。现今偶尔在拍卖会上出现一粒，必是天价，引得无数金丹大圆满修士倾尽家财争夺。

## 同类对比

九曲灵参丹与降尘丹虽都是增加突破几率的丹药，但针对的境界不同——降尘丹助结丹，九曲灵参丹助结婴。结婴比结丹艰难百倍，因此九曲灵参丹的价值也远在降尘丹之上。
