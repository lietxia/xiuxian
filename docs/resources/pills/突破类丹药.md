# 突破类丹药

突破类丹药是丹药体系中最珍贵的品类。修士每逢境界瓶颈，自行突破的成功率往往不足三成，而服用对症的突破丹药可将成功率提升至六到九成。正因如此，一枚高阶突破丹足以引发宗门大战。

## 二、突破类丹药的获取途径

### 2.1 宗门赐予

各大宗门往往将突破丹药作为核心弟子的奖励。内门弟子突破筑基时可获得一枚筑基丹，核心弟子突破金丹时可获得一枚结婴丹。

### 2.2 坊市购买

大型坊市偶有突破丹药出售，但价格高昂，且往往需要以物易物。

### 2.3 遗迹探险

上古遗迹中往往藏有上古大能留下的突破丹药，但此类地方通常危险重重。

### 2.4 炼丹师定制

找到掌握突破丹丹方的炼丹师，提供材料，委托炼制。但炼丹师往往需要天价报酬。

## 三、突破类丹药的副作用与注意事项

### 3.1 常见副作用

1. **丹毒积累**：突破类丹药往往丹毒含量较高
2. **根基不稳**：借助丹药突破的修士，根基往往不如自行突破的修士稳固
3. **耐药性**：同一种突破丹药多次服用会产生耐药性
4. **天道反噬**：部分突破类丹药会引来天道反噬

### 3.2 使用建议

1. **谨慎使用**：突破类丹药应在万不得已时使用
2. **配合修炼**：服用突破类丹药前应做好充分的修炼准备
3. **注意排毒**：服用突破类丹药后应配合排毒丹药
4. **避免依赖**：过度依赖突破类丹药会导致根基不稳

---

*突破类丹药是修士突破瓶颈的重要助力，但过度依赖反而会损害根基。明智的修士懂得在享受丹药带来的便利的同时，时刻保持对自身修炼的重视。*
