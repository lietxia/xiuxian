# 结续丹

**品阶：** 五品中阶

## 外观

青碧色，大如鸽卵。丹身呈半透明状，内有无数细如发丝的绿色丝线交织缠绕，仿佛活的经络。丹面有网状纹路，密密麻麻如血脉分布，名曰"结续脉络"。丹香清鲜，似雨后青草与新鲜竹叶之气，闻之令人伤口发痒。

## 炼制材料

- **主药：** 两千年玉骨参一支、续命草三株
- **辅药：** 生肌花七朵、接骨藤九段、万年钟乳髓五钱
- **药引：** 同等修为妖兽的骨血精华一份

## 炼制难度

- **丹炉：** 天蚕丝纹丹炉
- **丹火：** 三昧真火炼制百日
- **成功率：** 半成以下

结续丹对原材料品质要求极高。主药玉骨参若不足两千年，药效无法催生断骨；药引的妖兽骨血须与服用者修为相当。

## 功效

断肢者服下此丹，断口处会生出肉芽，经脉、骨骼、血肉依次重生，一月之内断肢可恢复如初。若非断肢而是重伤，则可修复体内残破经脉。

- **具体效果：** 断肢重生，经脉重塑，肉身修复
- **服用感受：** 断口处如万蚁啃噬，麻痒难忍，但可见骨肉以肉眼可见速度生长
- **持续时间：** 药效持续一月，期间不得中断

## 服用禁忌

- 头颈以上的断伤无法恢复（头颅不可再生）
- 内脏破碎者需先服其他丹药稳住伤势
- 服用期间须大量补充气血，否则身体会被丹药抽干
- 一生仅能对同一肢体生效一次

## 著名丹师/典故

上古时期有一名修士在与妖兽搏斗中失去一臂，他本是剑修，断臂后剑法威力大减，几近崩溃。他不甘心就此沉沦，转而钻研丹道，耗时百年终于创出结续丹方。服下后断臂重生，他大喜过望，提剑再战江湖，终成一代剑仙。此人名为"续断子"，他的故事至今激励着无数断肢修士。

## 同类对比

离殒丹救的是"命"，结续丹救的是"身"。离殒丹让濒死者活过来，结续丹让残缺者恢复完整。二者常搭配使用——先用离殒丹救命，再用结续丹修复伤残。
