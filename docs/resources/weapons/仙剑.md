# 九阶仙剑

## 八阶仙剑（大乘期）

八阶仙剑是大乘期剑修使用的玄天之宝，接近道器级别。

| 名称 | 本源 | 特殊能力 |
|------|------|----------|
| 问道剑 | 大道 | 问道苍穹，剑出则大道共鸣 |
| 仙道剑 | 仙道 | 飞升之剑，可破开虚空 |
| 无上剑 | 无上 | 无上剑道，剑出无敌 |
| 造化剑 | 造化 | 造化万物，一剑生世界 |
| 时空剑 | 时空 | 操控时空，剑出无形 |

## 九阶仙剑（渡劫期）

九阶仙剑是渡劫期剑修使用的玄天之宝巅峰，半步道器。

| 名称 | 本源 | 特殊能力 |
|------|------|----------|
| 大道剑 | 大道本源 | 斩道破法，一剑破万法 |
| 永恒仙剑 | 永恒本源 | 永恒不灭，剑出永恒 |
| 起源之剑 | 起源本源 | 万剑之祖，剑道起源 |
| 混沌剑 | 本源 | 混沌之力，开天辟地 |
| 天道剑 | 天道本源 | 天道之剑，代天行道 |
