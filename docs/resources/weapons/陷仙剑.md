# 陷仙剑

## 品阶
神器·天道杀器（诛仙四剑之一）

## 外观
陷仙剑长三尺五寸，剑身玄黑如墨，隐有银光流转如星河流淌。剑脊略厚，刃口呈淡紫色，乃九天紫雷淬炼而成。剑柄末端悬一缕黑缨，乃混沌之气凝结为丝。舞动时剑光如银河倒泻，银紫交错，美则美矣，实则杀机暗藏。

## 炼制材料
- **主材**：星辰玄铁（取九天陨铁经千年雷火淬炼）
- **辅材**：紫霄神雷雷核、天河弱水三滴
- **药引**：青龙逆鳞一片、白虎利齿一对

## 武器特性
- **攻击力**：中等，以困敌为主
- **特效**：剑气化网，陷入者如坠泥沼，行动艰难
- **器灵**：上古神兽白泽，擅布阵困敌

## 招式/神通
- **天罗地网**：剑气交织成网，困住一方天地
- **陷仙阵眼**：作为诛仙剑阵阵眼之一，演化无穷杀机
- **虚空禁锢**：剑意锁住周遭空间，令对手无法遁逃

## 使用限制
- **修为要求**：大罗金仙以上
- **副作用**：困敌同时亦会消耗持剑者大量法力

## 著名持有者
- **通天教主**：用以布设诛仙剑阵，陷仙剑镇守阵眼东南方

## 同类对比
陷仙剑不及诛仙剑之凌厉，亦不如戮仙剑之破防，然其困敌之能乃四剑之最。与绝仙剑配合，一困一追，令对手无处可逃。单独使用威力一般，但在剑阵中不可或缺。
