### 2.3 丹方构成

一副完整的丹方包含：

```
┌─────────────────────────────────────────┐
│              完整丹方结构                │
├─────────────────────────────────────────┤
│  主药（君药）  — 决定丹药核心功效（1-3味）│
│  臣药          — 辅助主药发挥功效（2-5味）│
│  佐药          — 中和副作用（1-3味）     │
│  药引          — 引导药力直达病灶（1味）  │
│  丹炉          — 影响成丹率              │
│  丹火          — 影响药效纯度            │
│  火候          — 决定成败关键            │
│  收丹手法      — 影响丹纹数量            │
└─────────────────────────────────────────┘
```

### 2.4 火候控制

| 阶段 | 火候 | 时间 | 作用 |
|:---:|:---|:---:|:---|
| **温炉** | 文火 | 1-3时辰 | 预热丹炉，去除杂质 |
| **融药** | 文→武 | 3-12时辰 | 药材融化、混合 |
| **凝丹** | 武→文 | 1-3时辰 | 药液凝聚成丹 |
| **收丹** | 文火 | 1时辰 | 稳定丹形、生成丹纹 |
| **养丹** | 文火 | 3-7日 | 丹药品级稳定 |

**火候要诀**：
- "文火温养，武火淬炼"
- "进火为阳，退符为阴"
- "卯酉周天，进退有度"
- "水火既济，铅汞归真"

## 三、著名丹药丹方

### 3.1 筑基丹（一品~二阶）

**功效**：辅助炼气期突破筑基期，成功率约70%

**材料**：
- 主药：玉髓芝、紫猴花、天灵果
- 辅药：七星草、龙涎草
- 药引：灵兽血一滴

**炼制**：
1. 温炉三时辰，以地脉灵火预热
2. 依次投入主药，文火融炼六时辰
3. 投入辅药，武火淬炼三时辰
4. 滴入药引，凝丹收丹

**品质判定**：
- 下品：丹纹1-2道，成功率50%
- 中品：丹纹3-4道，成功率70%
- 上品：丹纹5-6道，成功率85%
- 极品：丹纹7-9道，成功率95%

### 3.2 结婴丹（四品~五阶）

**功效**：辅助元婴期突破，增加结婴几率30-50%

**材料**：
- 主药：九曲灵参、玛瑙角、千叶露
- 辅药：龙鳞果、霓裳草
- 药引：万年灵乳一滴

**注意**：炼制时需以元婴灵火温养，天劫降临时需及时收丹
