# 特殊灵符

> 特殊灵符是具有特殊效果的灵符，功能多样，效果独特。其外形为一张特殊符纸，上画特殊咒文。传说特殊灵符乃上古时期一位大能模仿天地法则所创，每张灵符都蕴含一种独特的法则之力。

---

## 品阶

| 项目 | 内容 |
|------|------|
| 初始品阶 | 三阶·符箓 |
| 最高品阶 | 九阶·仙符 |
| 所属类别 | 特殊类·多功能符箓 |
| 稀有程度 | 罕见 |

## 外形描写

特殊灵符外形为一张特殊符纸，上画特殊咒文。符纸由各种珍稀材料制成，散发着淡淡的灵光。不同品阶的特殊灵符大小不同——低阶仅手掌大小，高阶可达一尺见方。

## 功能与效果

- **特殊效果**：每张特殊灵符都有独特的特殊效果，如隐身、瞬移、分身等
- **效果强度**：每升一品，效果强度翻倍
- **持续时间**：低阶约一炷香，高阶可达一个时辰

## 炼制方法

- **主要材料**：特殊符纸、灵墨、各种珍稀材料
- **炼制条件**：需金丹期以上修为，掌握特殊符箓术
- **炼制时间**：低阶七日，高阶需数月

## 使用限制

- 特殊灵符为一次性消耗品
- 特殊灵符效果不可叠加
- 特殊灵符对品阶高于本身的目标无效

## 著名典故

上古时期，有一位名为"灵符子"的大能，在昆仑山发现了一张特殊灵符。他将其带出，用以施展特殊效果，成为修真界最强的符修。

## 同类对比

与**辅助灵符**相比，特殊灵符效果更加多样。与**攻击灵符**相比，特殊灵符更加灵活。
