# 冰锥符

**品阶：** 一阶下品（初级符箓）

## 符体描述

符纸以寒玉纸为上品，以寒潭玉竹浆制成，色白质冷、触手生凉，日光下隐现冰晶光泽。
若以寻常黄纸替代，需先以冰泉浸泡三日方可使墨不泄。
符墨乃冰蟾血调玄冰粉，研磨时须在寒玉臼中进行，否则冰气消散、墨效大减。
符文呈冰棱交错之状，主纹六角如雪花，名曰"六出冰晶纹"，纹理繁复精细如窗花。
成符后触手生凉，盛夏不化，置于烈日下半个时辰方渐温。

## 制作方法

**材料：** 寒玉纸一张（或以黄纸替代）、冰蟾血三滴、玄冰粉一钱、寒泉水调和、玉镇尺一方。
**步骤：** 玄冰粉入寒泉水调匀，再入冰蟾血，以玉勺朝同一方向轻搅四十九圈至墨色泛青、冰气隐然。符纸铺于寒玉台上，以冰蚕丝笔蘸墨勾勒。先点符胆为核，再以符胆为中心引六出冰纹，每出一角须注入一缕水灵力。运笔须轻灵迅捷如蜻蜓点水，不可重按，重则冰纹融化成团、符文模糊。完符后以玉镇尺压符，置于背阴处待墨自干，不可见阳光。
**成功率：** 五成左右。关键在于冰蟾血的新鲜程度，血放三日则冰气散半。玄冰粉的研磨细度亦至关重要，粗则墨涩不畅、笔画生涩。

## 功效

激发后化为一支三尺冰锥，尖端锐利如针，通体寒气缭绕、白雾蒸腾。
可刺穿寻常铁甲，中者伤口冰封、血流立止，然寒气入骨、痛彻心扉且伤处冻伤难愈。
对火系妖兽有克制之效，可熄灭其护体火焰。
若击中要害，寒气直侵丹田可短暂阻滞对方灵力运转。
**持续时间：** 冰锥飞出三十丈后碎裂消散。击中目标则碎裂为冰屑嵌入伤口，寒气持续侵蚀一炷香。若被闪避，冰锥落地处可冻结三尺方圆地面。

## 使用方式

指捏符角，注入水系灵力，向目标一指。
冰锥自符中激射而出，势如劲弩，快似流星。
口诀曰"玄冰凝形，去"。
亦可贴于暗器上掷出，使暗器附带冰寒之效。
更可将冰锥符置于水源中待敌饮水时激发，冰锥自水中爆射而出，防不胜防。

## 使用限制

**次数：** 一次性。
**修为要求：** 炼气三层以上，水系灵根为佳。火灵根修士使用此符，灵力冲突可使符箓威力减半，甚或冰锥自爆伤己。
**反噬：** 炎热地带使用时威力递减，四十度以上时仅余三成威力。若在火山口使用，冰锥尚未成形即蒸发殆尽。

## 著名制符师/典故

北域冰宫有制符师名寒玉子，所制冰锥符可于三伏天维持七日不化。
其秘在于符墨中加入一滴本命冰元，但此法耗损修为，故每年仅制十张、万金难求。
寒玉子晚年冰法大成，创出"九幽冰瀑"之法，一枚冰锥符可化九支齐发，覆盖丈许方圆，同阶修士无人能挡。
北域至今仍传其名。

## 同类对比

冰锥符与火球符同为初级攻击符之双壁，一冰一火各擅胜场。
冰锥符穿透力强于火球之爆破力，可击穿铁甲而火球只能灼烧表面。
然范围不及火球符广，对密集敌群效果不佳。
若敌手修炼火系功法，冰锥符有五行克制之奇效；若对水系修行者使用，则效果大减、寒气或被吸收。
与风刃符相比，冰锥符有形有质，不惧大风干扰。
