# 水牢符

**品阶：** 二阶中品（中级符箓）

## 符体描述

符纸以水纹蓝纸为上品，纸中织入水蚕丝，纸面隐现波光纹理如湖面涟漪。
入手湿润柔软如浸过水，以火烤之则冒水汽而不燃，甚是奇特。
符墨乃蛟龙涎调玄水精华——蛟龙涎取自三阶以上水蛟，色蓝透如深海之水，在光下折射出水影。
以鼻近闻有淡淡海腥味，如站在礁石上远眺大海。
符文呈水波连环之状，主纹外圆内旋、层层如漩涡盘绕，名曰"九曲困水纹"——九圈水纹各有变化，如九曲黄河蜿蜒。
成符后触之冰凉，以指弹之声如滴水入潭，清脆而悠远。

## 制作方法

**材料：** 水纹蓝纸一张、蛟龙涎三钱（或以水蟒唾液代替）、玄水精华两滴、玉制镇尺一把。
**步骤：** 蛟龙涎以玉碗盛装——不可用铁器，铁腥气会污染水灵。滴入玄水精华以一缕水灵力搅拌至墨色透蓝。以白玉笔蘸墨，画圆为牢基，再自外而内旋笔九圈，每旋一圈注入一分水灵力。九圈水纹圈圈相扣，每圈灵力均匀分布。收笔时以水气封符胆，玉镇尺压符待自然阴干。
**成功率：** 约四成。水牢符难在九圈水纹须灵力均匀，一圈偏弱则牢壁不固，困敌即破。

## 功效

激发后目标周身水汽骤聚，化为一圆形水牢将其包裹。
水牢壁柔韧异常，刀砍不入、火烧不透，攻击落在壁上如击棉絮被卸去力道。
被困者如坠深海，呼吸艰难、行动迟滞，每动一分须耗费数倍力气。
水汽弥漫亦会模糊视线和神念感应。
**持续时间：** 一炷香。若在干旱沙漠之地使用则缩短为半炷香。若在江河湖海之畔，可延长至一个时辰。

## 使用方式

以水系灵力激发符箓掷符向目标上空，朗喝"壬癸借法，五行为牢，困！"
水牢自天而降，罩住方圆两丈范围。
亦可贴于水域表面诱敌靠近时从水面暴起发动。
多张水牢符可叠加使用增厚牢壁。

## 使用限制

**次数：** 一次性。
**修为要求：** 筑基期以上。水灵根修士使用牢壁更厚、困敌更久。
**反噬：** 火灵根修士使用此符，水火灵力冲突可致水牢提前崩溃。若对方修炼土系功法，可筑土坝引流将水牢泄掉。

## 著名制符师/典故

东海散修碧波仙子，擅制各类水符。
其水牢符中加入一滴海心泉——海心泉乃万丈海底灵泉之眼，水压倍增如山岳。
被困者如沉万丈深渊、骨节欲裂、呼吸困难。
据传她曾以此符困住一头元婴期蛟龙，虽只困得五息便已足够脱身远遁千里，由此声名大噪。
碧波仙子后来创立"水符宗"，水牢符成为镇宗三宝之一。

## 同类对比

水牢符与土牢符齐名于世，一刚一柔各有妙用。
水牢符柔韧可卸力，适合困持重型兵器或擅长蛮力的对手；土牢符坚硬稳固，适合困持术法修士。
水牢符在近水之地威力倍增，若在沙漠中使用则大减。
水牢对修炼火系功法的修士有奇效，然土系修士可掘地破牢而出。
