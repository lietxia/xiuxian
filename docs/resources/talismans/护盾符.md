# 护盾符

**品阶：** 二阶中品（中级符箓）

## 符体描述

符纸以灵纹纸为上品，纸中织入细微灵蚕丝增强灵力传导，色莹白而有微光。
符墨乃灵石粉末调灵泉水，墨色莹白透光内含点点灵力微光如夜空星辰。
符文如龟甲之形，主纹层层叠叠如龟背鳞片，曰"玄武灵甲纹"，每层鳞片代表一层防护。
成符后触之温润如玉，隐有灵力波动如脉搏轻跳。

## 制作方法

**材料：** 灵纹纸一张、中品灵石粉三钱、灵泉水五滴、灵蚕丝一缕织入纸中、鹤毛笔一支。
**步骤：** 灵石粉以灵泉水调至稀稠适中。以鹤毛笔蘸墨，先画外层大圆为护盾轮廓奠基础，再由外向内层层堆叠鳞片纹。每层鳞片注入等量灵力不可多不可少，共九层如龟甲堆叠。完符后以灵石压符七日吸收灵气充分饱和，方为成品。
**成功率：** 约四成。护盾符难度在于九层鳞片的灵力须均衡，层次分明方为上品，某层偏弱则护盾有缺口。

## 功效

激发后一道半透明的灵力护盾在周身成形，呈球形笼罩上下左右无死角。
可抵挡法术攻击和灵力冲击如流水卸力，对火球术、冰锥术等远程法术尤其有效。
护盾受击时表面荡开涟漪如水面落石，将冲击力分散至整个护盾面。
**持续时间：** 一炷香，或承受相当于筑基后期全力三击的能量后碎裂消散。护盾碎裂前会有密集裂纹预警。

## 使用方式

以灵力激发符箓掷向头顶上空，口诀曰"玄武护体，万法不沾，起"。
护盾自头顶降下如倒扣玉碗笼罩全身。
亦可缩小护盾至数尺集中防御正面，牺牲覆盖面换取局部增强。
群战中可同时激发多张护盾符重叠防御。

## 使用限制

**次数：** 一次性。
**修为要求：** 筑基期以上。炼气期使用护盾范围仅三尺且一触即碎。
**反噬：** 护盾碎裂时会产生灵力震荡波纹，近距离可将施符者推开数丈，在悬崖边使用需防被震落。护盾对物理穿刺类攻击（如飞箭、金剑符）的防御力不如金刚符，可能被刺穿。

## 著名制符师/典故

玄龟岛岛主"龟灵子"，身具玄武血脉以制护盾符闻名四海。
其符以玄龟甲壳碎末入墨，激发的护盾隐有玄武虚影盘踞于顶，防御力倍增加持。
传闻他曾凭一枚护盾符在海底火山爆发中护住整船三十名弟子，岩浆洪流冲在护盾上如浪击礁石、船行其中毫发无伤。
龟灵子因此被弟子尊为"玄武护法"。


## 注意事项

护盾符碎裂时会产生灵力震荡波，在悬崖或高处使用需防被震落。多层护盾符叠加使用效果不如一层高品质护盾符。护盾符对物理穿刺类攻击的防御力较弱，需配合金刚符使用。

## 同类对比

护盾符与金刚符一柔一刚相得益彰。
护盾符更擅化解法术冲击如水流卸力，金刚符专精硬抗物理攻击如铁壁阻挡。
护盾符的优势在于全方位覆盖无死角（包括头顶和脚下均可挡住），劣势是单点防御力不及金刚符易被穿透。
高阶修士常将两者叠加使用—外层护盾挡法术、内层金刚挡物理，多一层保障多一条命。
