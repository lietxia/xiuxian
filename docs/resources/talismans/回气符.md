# 回气符

**品阶：** 二阶中品（中级符箓）

## 符体描述

符纸以空灵纸为上品，纸质薄而透光利于灵力穿透流通。
入手如握一片薄冰，对着光看可透过符纸看清手指纹路，隐隐有灵气氤氲其上如薄雾浮于水面。
符墨乃聚灵草汁调灵石髓液——聚灵草汁取自三阶聚灵草，灵石髓液取自中品灵石核心。
墨色淡蓝如晴空万里，隐约有灵气氤氲其上，以鼻近闻有淡淡矿石清冷气息。
符文如漩涡盘旋收缩之形，主纹一圆中旋纹向内收敛如龙卷风眼，名曰"聚灵旋气纹"——圈圈收拢直达核心。
成符后周围灵气缓缓汇聚，持符修炼可略增吐纳炼化效率。

## 制作方法

**材料：** 空灵纸一张、聚灵草汁五钱、灵石髓液三滴、灵泉水和墨、鹤毛笔一支。
**步骤：** 聚灵草汁与灵石髓液以灵泉水调匀于玉碗中。以鹤毛笔蘸墨，先画外圆引聚四方灵气为界，再画内旋纹引导灵气走向。旋纹由外向内共七圈，每圈缩小一圈、灵气浓度递增一层。完符后置于灵脉出口处吸纳灵气七日，待符纸灵力饱和微光流转方为成品。
**成功率：** 约五成。回气符制作难度适中，要做出高品质回气符则需要优质的灵石髓液。下品灵石髓液制成的回气符恢复效果不足上品三成。

## 功效

激发后符中储存的高浓度灵气团涌入施符者丹田，快速补充消耗灵力。
可恢复筑基期修士约三成灵力，金丹期约一成。
恢复过程中灵力运转加速三成，亦可略微提升后续施法速度和法术威力。
**持续时间：** 灵气灌注过程约十息连绵不断。之后符纸灵力耗尽化灰飘散。

## 使用方式

以神念激发符箓贴于丹田处或握于掌心，心念"气归元海"即可。
一股温热灵气自符中涌入丹田，自行沿经脉运转周天归入气海，如久旱逢甘霖。
无需口诀，心念一动即发。

## 使用限制

**次数：** 一次性。
**修为要求：** 炼气期即可使用，但炼气修士经脉宽度有限，使用回气符时可能因灵气冲击而经脉胀痛不适，需缓慢引导吸收。
**反噬：** 短时间内连续使用多张回气符可导致灵力不纯、气息紊乱。回气符恢复的灵力较为驳杂精炼度不足，不如自身修炼所得精纯，需以功法重新炼化后方可继续使用。一日之内最多使用三张，过多则事倍功半。

## 著名制符师/典故

灵宝宗制符大师号"聚灵子"，其回气符使用上品灵石髓液和五百年份聚灵草，一张可恢复金丹期修士两成灵力，品质冠绝灵宝宗。
曾在正魔大战前线一次供给三千张回气符，守城修士灵力耗尽便换符续力，硬生生将攻城战拖了三天三夜等来援军，一举扭转战局。
战后回气符被正式列为各宗战略储备物资。

## 同类对比

回气符与回春符并称战场双符，一补灵力一治伤。
回气符较丹药的优势在于吸收速度极快，十息即可恢复大量灵力，危急时刻可以边战边用不耽误作战。
但丹药恢复的灵力更精纯温和且可配合修炼增长修为，回气符则只能应急恢复。
三阶以上的高阶修士更倾向于服用丹药而非使用回气符，因回气符恢复量对他们而言杯水车薪。
