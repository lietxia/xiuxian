# 六甲符

**品阶：** 三阶中品（高级符箓）

## 符体描述

符纸以六种灵蚕丝交织而成——金丝、银丝、火蚕丝、冰蚕丝、紫蚕丝、墨蚕丝各取其长，坚韧异常灵光交织如彩虹织就。
入手温润而有弹性，如握一块活玉，六色灵光在纸面流转不息。
符墨乃六种妖兽精血调和——青龙、白虎、朱雀、玄武、螣蛇、勾陈各一滴，墨色变幻不定如霓虹流转。
以鼻近闻有六种气息交替：龙腥、虎啸、雀鸣、龟息、蛇信、勾陈之香，玄妙非常。
符文由六个小型符阵嵌套而成，层层相套环环相扣，名曰"六丁六甲护身阵纹"。
成符后六色灵光流转不息，威压隐现令人肃然，低阶修士不敢直视。

## 制作方法

**材料：** 六合纸一张、六种妖兽精血各一滴、六色灵石粉末各少许、万年灵泉水调和、六支符笔各配一种墨。
**步骤：** 六种妖兽血分别以六色灵石粉调匀于六个玉碟中，各配一支专用符笔不可混用。以六支符笔轮流蘸取六种符墨，先画甲子层为青色，再画甲戌层为白色，依序至甲寅层为金色。每画一层须引一种妖兽气息注入符中，六层嵌套互不干扰却彼此呼应。完符后以六角阵盘温养四十九日方可使用。
**成功率：** 不足两成。六甲符制作极为繁复，六层嵌套中任何一层出错则全符报废。制符时哪怕一丝气息紊乱亦会导致前功尽弃。

## 功效

激发后六层颜色各异的护罩依次张开：青龙青、白虎白、朱雀红、玄武黑、螣蛇紫、勾陈金，六色流转美不胜收。
每层护罩可抵挡一次金丹期全力攻击，六层全开可硬抗元婴初期一击而不破。
六层之间灵力联动流转，一层被破后其剩余灵力自动分摊至余下五层加固防御。
**持续时间：** 一个时辰自然消散，或六层护罩全部被击破后提前消失。

## 使用方式

以大量灵力激发符箓掷向头顶，朗喝"六甲护体，万邪不侵，开！"
六层护罩自顶至踵层层罩下如孔雀开屏。
每破一层剩余层数护罩会更加凝实坚韧。
亦可贴于洞府大门化为守护禁制，六甲符镇门元婴亦难破入。

## 使用限制

**次数：** 一次性。
**修为要求：** 金丹期以上方可完全激发全部六层护罩。筑基期强用只能激发两层。
**反噬：** 若六层全部被击破，剩余符力会反冲施符者短暂造成灵力紊乱三息——这三息内无法施法防御。不过六层全部被破的情况极为罕见，六甲符本身就是修仙界最顶级的保命符箓之一。

## 著名制符师/典故

神符宗太上长老六甲真人，以六甲符闻名整个修真界无人不知。
他早年游历时偶得上古符仙遗刻于无名山洞中，参悟十年得六丁六甲护身大道。
传闻他曾面对三名元婴修士围攻力战不退，凭一道六甲符硬抗一炷香攻击——六层护罩被破了五层但始终未全部碎裂，等来了宗门援军反败为胜。
六甲真人一战成名后著《六甲符经》三卷，为神符宗镇宗典籍传承至今。

## 同类对比

六甲符为三阶防御符箓之冠，远超金刚符和护盾符不止一个层次。
金刚符仅一重金身防护，六甲符六重嵌套防御，每层独立又彼此联动，防御能力和战术价值天差地别。
然六甲符制作成本高昂到令人瞠目，耗时长达数十日，非大宗门核心弟子不可拥有。
较之单纯护盾，六甲符的优势在于多层递进防御，每一层被破都会给施符者发出预警和反应时间。
