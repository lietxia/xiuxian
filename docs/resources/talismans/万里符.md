# 万里符

**品阶：** 三阶中品（高级符箓）

## 符体描述

符纸以传音纸为上品，纸薄而韧至极，折叠后可缩小至指甲大小便于携带。
入手如握一片蝉翼，对着光看可透过符纸看清手指纹路，两符之间隐有灵力丝线相连如蛛丝。
符墨乃回音螺粉调空音鸟喉液——回音螺粉取自三阶回音螺，空音鸟喉液取自二阶空音鸟。
墨色银白如月光流淌，以鼻近闻有淡淡海螺与鸟鸣混合的清越气息。
符文如声波扩散之形，主纹一圆中心一点，波纹层层向外扩散如水面投石，名曰"千山传音纹"。
一对万里符之间有神秘感应联系，持一对者可以心念传讯无视距离。成符后两符之间隐有灵力丝线相连，以灵视可观之。

## 制作方法

**材料：** 传音纸两张需同炉所造方有默契感应、回音螺粉一钱、空音鸟喉液两滴、月华露水调和。
**步骤：** 回音螺粉入月华露调匀于玉碟，加入空音鸟喉液搅拌至银光微泛。以鹤毛笔在两符上同时画相同的传音纹，须两符并列一气呵成、笔势同步如镜像。每画一圈波纹须心念相通冥想万里传音之意、两符同振。两符完成后以月光浸润七日七夜，使两符的灵力频率完全同调。
**成功率：** 不过两成。万里符须两符同制，笔势同步极难掌握，稍有偏差则传音不畅或距离大幅缩短。

## 功效

一对万里符之间可无视距离即时传讯，只要在同一界域之内皆可通联。
持符者以神念对符说话，另一符便会震动发光提醒，对方以神念探入即可听取留言。
亦可传递简单影像画面和情绪感受，文字亦可。
**持续时间：** 每张万里符可使用三次传讯，之后符力耗尽化为普通纸张。每次传讯最长可达百字、持续数息。

## 使用方式

以神念激活符箓轻抚符面，开口说话声音即化为灵力波动传至另一符。
对方以神念探入符中即可听取如对面语。
无需口诀，心念"传"字即可。
接收时符纸发热震动如蝴蝶扑翼，手探入符中读取消息如水映月。
跨区传讯亦可留言。

## 使用限制

**次数：** 每张可使用三次传讯，每次传讯至多百字。三次用完符力耗尽。
**修为要求：** 筑基期以上需有基础神念修为方可操控收发。
**反噬：** 若跨越界域传讯无效，如从修真界传至凡间界则万里符沉寂如凡纸。若在禁制重重的秘境中使用传讯距离大幅缩减，可能在百里之内即失效。曾有修士在酒后对符大骂宗门长老，不知符未关闭声音实时传至对方耳中，隔日被罚面壁思过三月，一时传为笑谈。此后再无人酒后玩万里符。

## 著名制符师/典故

天机阁两位阁主"千里眼"和"顺风耳"，以散仙之尊联手创制了万里符。
千里眼精研空间之道可窥万里之外，顺风耳精通音律之术可听九天之音，两人合力将声音化为灵力波纹跨越空间距离，开创了修仙界即时通讯的新纪元。
如今各大宗门皆有仿制版本，但原版万里符仍以天机阁所制为正宗、通联最稳。

## 同类对比

万里符与破界符同为空间类高阶符箓，但万里符仅传递信息而不撕裂空间，安稳便捷远胜破界符之凶险。
较之普通传音符的百里限制，万里符距离无上限且可传递情绪影像。
传音符仅限百里之内且只能传递文字信息甚为不便。
万里符是宗门精英弟子在外行走的必备联络工具，大宗门核心弟子人手一对以应急需。
