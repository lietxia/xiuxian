# 飞天符

**品阶：** 二阶中品（中级符箓）

## 符体描述

符纸以轻云纸为上品，以云蚕丝浆制，纸质轻薄如蝉翼、色白透光似晴空浮云。
符墨乃青鸾羽灰调浮空石粉，墨色淡青如晨空之色，研磨细致如脂。
符文如飞鸟展翅翱翔之形，主纹一弧托双翼，曰"青云飞翼纹"，弧为气流、翼为升力。
成符后几乎无重量，放手则飘悬空中不坠，以口吹气便可飘移。

## 制作方法

**材料：** 轻云纸一张、青鸾羽灰一钱、浮空石粉三钱、朝露水调和、鹤毛笔一支。
**步骤：** 青鸾羽灰与浮空石粉混合均匀，以朝露水徐徐调入制成墨，墨色淡青空灵。以极轻之鹤毛笔蘸墨，先画左翼再画右翼，左右对称展翅，最后以弧线连接双翼。每一笔须注入风灵力并冥想腾空之感，运笔轻灵如风拂面。完符后以檀香熏之，令符之轻灵之气纯化升腾。
**成功率：** 约四成。飞天符最忌笔重，一笔过重则符失轻灵、难以腾空。心情沉重之日制符成功率必低。

## 功效

激发后一道清风自符中涌出托住施符者，使其可御风飞行翱翔天际。
飞行高度可达百丈，速度如飞鸟疾驰，日行千里不在话下。
可携一人同飞但速度减半、消耗加倍。
飞行时风拂面庞，衣袂飘飘。
**持续时间：** 半个时辰。若逆风飞行则缩短为一刻钟。顺风时可持续近一个时辰。

## 使用方式

将符贴于胸前或后背，注入风灵力即可腾空而起。
以神念控制飞行方向和高度，如鸟儿振翅般自如。
口诀曰"风起青云，御空而行，起"。
亦可贴于器物上令器物飞行。
飞剑贴飞天符可剑遁合一速度倍增。
注意起飞和降落时速度须缓，避免冲撞。

## 使用限制

**次数：** 一次性。
**修为要求：** 筑基期以上方可稳定操控方向和高度。炼气期使用虽可飞行但容易头重脚轻难以把控。
**反噬：** 飞行途中若符箓受潮则飞行能力逐渐减弱，若完全湿透则符力失效坠落。遇狂风暴雨天气可能失控偏离方向。曾有修士在雷雨天使用飞天符被雷电误击，幸有护身法器保得性命，但飞天符从此有了"雷雨天勿用"的警示。高空飞行时亦需注意罡风，筑基期肉身不强可能被罡风吹伤。

## 著名制符师/典故

风灵门掌门"青云散人"，年少时偶遇青鸾翱翔九天之姿，观其御风之道悟得飞符真谛。
他的飞天符以青鸾本命羽入墨，飞行时隐有青鸾虚影相随，速度之快冠绝同阶。
然青鸾难寻，故其真品飞天符市价万金有价无市。
青云散人曾凭一枚飞天符载着受伤的道侣连夜飞越三千里赶回宗门救治，传为修仙界佳话。

## 同类对比

飞天符乃筑基修士必备逃命符箓，与遁地符一上一下并称双绝。
遁地符入土逃遁无声无息但速度慢，飞天符升空远遁速度快如飞鸟但暴露无遗易被远程攻击。
飞天符的优势在于视野开阔可观察全局，劣势是空中无遮蔽物如靶子一般。
较之金丹以上修士的御空飞行术，飞天符即用即走不耗本命精元，胜在便利和性价比。
飞天符在高空飞行时需注意罡风侵体，筑基期修士肉身不强，建议以护体灵力覆盖全身。遇到雷雨天气应尽快降落，以免被天雷误击。
