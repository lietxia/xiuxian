# 金丝符

**品阶：** 二阶中品（中级符箓）

## 符体描述

符纸以金蚕丝浆制成，色淡黄如旧绢帛而坚韧异常。
入手光滑如丝绢，手指轻触有丝滑柔顺之感，隐隐有金光流转。
符墨乃金精粉调天蚕丝液——金精粉取自金矿之精，天蚕丝液取自三阶天蚕吐丝。
墨色如熔化的黄金在纸上流淌，拉丝极长不断，以鼻近闻有金属与蚕丝混合的奇异气味。
符文如丝线盘绕成团，主纹一团丝线缠绕成漩涡状如乱丝，名曰"千丝困金纹"——看似杂乱实则暗含束缚之道。
成符后符面光滑如镜，以指弹之声如拨弦，清脆而绵长。

## 制作方法

**材料：** 金蚕丝纸一张、金精粉三钱、天蚕丝液五滴、灵泉水调和、金针一支为笔。
**步骤：** 金精粉入灵泉水调匀于瓷碗中，加入天蚕丝液搅拌至黏稠拉丝如蜜。以金针为笔——不能用毛笔因毛笔太软难以拉丝。蘸墨后先画圆心一点为核心，再以螺旋方式向外缠绕拉丝，每圈丝线须保持等距不可重叠亦不可断开，共缠绕三十六圈方成。完符后以玉镇压平待干。
**成功率：** 约四成。金丝符最难在三十六圈丝线须一气呵成不断，一断则符力全失从头再来。拉丝时手须极稳，一抖则丝乱。

## 功效

激发后符中飞出无数金色丝线铺天盖地向目标缠绕而去，如天罗地网无处可逃。
金丝坚韧异常，寻常刀剑斩之不断、凡火烧之不熔。
被困者如被蛛网缚住越挣扎缠得越紧，丝线会勒入衣物皮肉，挣扎越猛勒得越深。
**持续时间：** 半个时辰，之后金丝中的灵力消散化为凡金丝线松脱落地。期间可以灵力不断加固延长持续时间。

## 使用方式

以灵力激发符箓掷向目标，朗喝"金丝缠身，缚！"
金丝自符中爆射而出如无数金蛇飞舞罩向目标。
亦可预埋于地面作陷阱，触发后从下而上缠绕将人裹成金茧。
金丝符亦可覆盖较大范围，对群敌有奇效。

## 使用限制

**次数：** 一次性。
**修为要求：** 筑基期以上。
**反噬：** 金丝不畏寻常水火，但遇三昧真火则熔化为金水滴落。若目标修炼了金系遁术可能化身金气从丝缝中逸出逃走。金丝困敌不分敌我，若自己不慎踏入金丝范围亦会被缠住，需小心站位。金丝不可在金属矿山附近使用，会被地磁干扰乱飞。

## 著名制符师/典故

天蚕宗女修号"金丝娘子"，以金丝符和天蚕丝织术闻名于世。
她所制的金丝符中掺入天蚕本命丝，金丝柔韧度倍增且带有微弱麻痹毒素——被困者时间一久便四肢麻痹失去反抗之力。
一名金丹修士曾赞誉："此金丝可困蛟龙。"
金丝娘子后来创出"金丝符阵"——三十六张金丝符布下天罗地网，同阶修士入阵者无人能破，天蚕宗因此名声大噪。

## 同类对比

金丝符与土牢符同为困敌符箓但各有侧重。
金丝符更为灵活精准——可缠绕可束缚可远程缠敌，不像土牢符只能固定位置大范围困敌。
金丝符可针对单个目标精准控制，而土牢符范围大但不分敌我。
然而金丝符的控制力不如土牢符稳固，遇到克制金属性的火系法术特别是三昧真火容易失效，土牢符则无此弱点。
