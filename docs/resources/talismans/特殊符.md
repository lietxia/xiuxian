# 特殊符

## 四阶特殊符（元婴期）

四阶特殊符是元婴期修士使用的特殊功能符箓，拥有封印、替身、破界等独特能力。

| 名称 | 功效 | 材料 | 参考价格 |
|------|------|------|----------|
| 封印符 | 封印修士修为，使其无法运转灵力 | 千年符纸、封印石 | 2万灵石 |
| 解封符 | 解除四阶以下封印 | 千年符纸、解封石 | 2万灵石 |
| 替身符 | 可替死一次，代替主人承受致命攻击 | 千年符纸、替身草 | 5万灵石 |
| 破界符 | 破开界面屏障，可短暂穿越空间裂缝 | 千年符纸、空间石 | 有价无市 |
| 锁魂符 | 暂时束缚神魂，压制敌人神识冲击 | 千年符纸、冥魂墨 | 3万灵石 |
| 追踪符 | 追踪目标气息，五百里内可定位 | 千年符纸、追踪蝶粉 | 1.5万灵石 |
