# 天戈符

**品阶：** 三阶上品（高级符箓）

## 符体描述

符纸以天罡纸为上品，以天罡星力淬炼过三百日的银丝纸制成，色银白泛星辉如银河碎屑。
入手有微微星辰之力透体，如握一块来自天外的陨铁，冰凉而沉重。
符墨乃星陨铁精调天外陨石液——星陨铁精取自坠落陨石之核心，天外陨石液取自天外飞来的陨石。
墨色银亮如熔化的星河在纸上流淌，以鼻近闻有淡淡金属与焦石混合的气息。
符文如戈矛之形古拙刚猛，主纹一笔通天彻地直贯符首符尾，两侧附两道弧刃如戈锋，名曰"天戈破军纹"。
成符后锋锐之气逼人刺骨，修为低者不敢直视、视之则双目如被针刺。

## 制作方法

**材料：** 天罡纸一张、星陨铁精三钱、天外陨石液一滴、玄铁笔一支、剑形铜镇纸一方。
**步骤：** 铁精以陨石液调和于铁臼中研磨百日至细腻如脂。需在星夜之中以星光淬墨七七四十九夜，每夜吸收星力后方可使用。以玄铁笔蘸墨，先书笔直主纹如戈柄贯通天地，再勾两侧弧刃如戈锋斜劈。每画一笔须引一丝星辰之力注入笔端，笔势如真正挥戈劈斩般凌厉。完符后以剑匣封存，不可与钝器同置，以免钝气污了锋锐。
**成功率：** 不过一成。天戈符乃三阶攻击符中至强之列，非制符大宗师不可为。星力引注入墨最难掌握，多一丝则纸裂、少一丝则无力。

## 功效

激发后化为一柄银白色天戈虚影悬于头顶，长约丈许光芒璀璨，内含破军星力肃杀万物。
天戈挥出可斩断下品法宝、击破金丹期护盾如切豆腐。
一击之下方圆十丈内生灵尽感冰寒肃杀之气，心生恐惧。
**持续时间：** 天戈凝形持续五息，可发出一记全力劈斩或三次快速刺击。全力一击后天戈消散化星辉归天。

## 使用方式

以金丹之力注入符胆激发，掷符向天以神念锁定目标，暴喝"天戈所指，星辰为锋，落！"
天戈自九天而降携星辰光辉宛如流星坠地直击目标。
亦可贴于飞剑上使飞剑的一击蕴含天戈之力、威力倍增。

## 使用限制

**次数：** 一次性。
**修为要求：** 金丹期以上方可驾驭天戈之力。筑基期使用会被天戈的锋锐之气反伤经脉，重则残废。
**反噬：** 天戈符威力巨大，若在人群密集处使用可能误伤友军，甚至将友方法器一并斩断。天戈之气不可收回，一击不中则符力白白浪费轰在空处。曾有修士在天戈符激发瞬间被对头闪开，天戈轰入山中，削平半座山头、泥石滚落如天崩地裂。

## 著名制符师/典故

星剑宗宗主"天戈上人"，以天戈符和星辰剑法并称双绝名动天下。
传说他制符时以星辰为墨、天幕为纸、引北斗星光为笔，在万丈高空以天地为符室引星力入符。
他的天戈符可与元婴期修士一较高下，曾一符击退魔道巨擘"血煞老祖"，救星剑宗上下三千弟子于水火。
天戈上人享寿四百二十岁坐化于星剑宗观星台，留下天戈符秘法于藏经阁顶层，非宗主不可阅。

## 同类对比

天戈符乃三阶攻击符箓中的顶尖存在，与金剑符的差距犹如金丹比筑基——不可同日而语。
金剑符为二阶可斩筑基，天戈符为三阶可伤元婴。
与水龙符相比，天戈符威力集中、单体爆发力极强、适合斩首行动；水龙符则范围更广、持续更久、适合战场压制。
一张天戈符的造价可购百张金剑符。
