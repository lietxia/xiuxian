# 降灵符

**品阶：** 三阶上品（高级符箓）

## 符体描述

符纸以兽皮符纸为上品，以七级以上妖兽皮鞣制而成，质韧而充满凶煞妖气，触手粗粝如砂纸。
入手有微微凶威压迫，低阶修士不敢久持，仿佛手中握着一块嗜血的兽尸。
符墨乃八级妖兽真灵之血调魂晶粉末——真灵之血须活取方才有效，墨色赤中泛紫如凝固的妖血。
以灵视观之隐有妖魂咆哮之影在墨中挣扎，令人不寒而栗。
符文如兽魂咆哮怒号之形，主纹一张巨口大张獠牙毕露，周围环绕束缚妖魂的锁链纹困住凶兽，名曰"镇魂降灵纹"。
成符后煞气逼人凶威凛凛，低阶修士不敢近前三尺之内。

## 制作方法

**材料：** 七阶妖兽皮一张、八级妖魂精血三滴（须活取方才有效）、魂晶粉末二钱、镇魂锁链一条仪式用。
**步骤：** 妖魂精血入魂晶粉调匀于镇魂钵中，以妖骨笔蘸墨。先画镇魂锁链重重困住妖魂之形，再画兽魂之形释放其威压。每画一笔须以镇魂咒压制妖魂的反抗意志，笔势刚猛中带着封印之力。完符后以镇魂符阵封印多层加固，防止妖魂反噬制符师。取血过程最为凶险，须猎杀八级妖兽后即刻取血，拖过一炷香则真灵消散。
**成功率：** 不过一成。降灵符因需活取妖魂精血而凶险万分，制符师本身须有至少金丹后期修为才可压制妖魂反抗。

## 功效

激发后封印在符中的八级妖魂被释放出来，化为一头巨大的妖兽虚影，咆哮着扑向敌人。
妖魂保留生前部分神通和战斗本能可自主攻击，会使用妖兽天赋法术。
八级妖魂战力堪比金丹后期修士，与同阶人类修士对战不落下风。
妖魂被击散前会持续追击目标，不会疲倦不会恐惧。
**持续时间：** 一炷香，或妖魂被对手击散后提前消散。妖魂消散时有凄厉的魂啸波及周围数丈。

## 使用方式

以大量灵力注入符胆激发，掷符向目标方向，暴喝"妖魂听令，为我所用，亟！"
妖魂虚影自符中冲出仰天咆哮、声震四野，以神念指引攻击目标，妖魂会自动追击不死不休。
释放后施符者可以腾出手来做其他事，妖魂会自行战斗。

## 使用限制

**次数：** 一次性。
**修为要求：** 金丹期以上方可驾驭八级妖魂。筑基期使用必被妖魂反噬，魂魄被妖魂吞食、身死道消。
**反噬：** 降灵符风险极高，若妖魂意志过强可能挣脱符中禁制反噬施符者——妖魂会先把施符者当成第一个猎物吞噬。妖魂被击杀后其怨念会冲击施符者神念，轻则头痛数日重则神念受创修为退步。制符时的镇魂环节若出差错，符成之日即为制符师丧命之时。

## 著名制符师/典故

万妖谷谷主"妖符天尊"，以猎妖制符闻名天下。
他一生猎杀了不下千头妖兽取其精血魂魄制成降灵符，万妖谷中妖骨堆积如山。
其中最著名的一张"九尾天狐降灵符"封印了一头九级天狐妖魂，在正魔大战中放出——九尾天狐虚影遮天蔽日，以一己之力撕碎了魔道三尊的护身魔器，为正道赢得了关键一战。
妖符天尊自此被尊为"万妖之祖"，其降灵符制作方法被列为万妖谷最高秘传。

## 同类对比

降灵符与傀儡符同属召唤类符箓但方向迥异。
降灵符召唤的是强大妖魂力量霸道但风险极高，随时可能反噬主人。
傀儡符召唤的是影傀儡忠诚可控安心可靠但力量有限。
降灵符是一场豪赌——赌封印够强、妖魂够听话；傀儡符是一步稳棋——虽不强但绝不会出事。
较之火鸟符和水龙符的五行化形攻击，降灵符召唤真实妖魂具有自主战斗能力，灵活性和战术价值远高于元素化形。
