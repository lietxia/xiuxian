# 遁形符

**品阶：** 三阶上品（高级符箓）

## 符体描述

符纸以影蚕丝纸为上品，以暗影蚕吐丝织成，黑如浓墨、薄如夜雾，拿在手中几乎感觉不到重量。
符墨乃暗影豹心头之血调幽冥泉水，墨色漆黑如虚空缺口，落笔处仿佛吞噬周围光线、令人目眩。
符文如暗影流动无常形无定势，主纹一道裂痕状曲线若隐若现，曰"虚空裂影纹"。
成符后置于暗处则完全消失于视野中，唯有以神念方可勉强感知其存在。

## 制作方法

**材料：** 影蚕丝纸一张、暗影豹精血三滴、幽冥泉水五滴、月影石粉末少许、陨铁笔一支。
**步骤：** 暗影豹血入幽冥泉调和以陨铁笔研磨至墨色完全吸光不反光。须在子时阴气最浓时于无光暗室中制符，不可点灯亦不可有月光透入。以神念感知笔尖、凭意勾勒裂影纹，笔在纸上游走如蛇行暗影。每画一笔须冥想"化入虚空、成为虚无"之意。完符后以月影石粉轻洒封灵，石粉落在符上即融入不见。
**成功率：** 不过两成。三阶符箓难度相较二阶陡增数倍，对制符师的神念和暗影之道领悟要求极高。

## 功效

激发后施符者彻底消失在视觉和灵觉之中。
不仅身形完全不可见，气息、体温、心跳、呼吸声亦全部收敛至无。
移动无声、踏雪无痕，与周遭天地融为一体。
元婴期以下极难察觉破绽。
若施符者屏息不动，化神期修士不经细查亦未必能发现。
**持续时间：** 一个时辰。也可提前主动解除。期间可缓慢移动和观察外界。

## 使用方式

以大量灵力注入符胆，符箓化为一道黑影融入施符者背心。
无需口诀手印，心念一动即入遁形状态。
在此状态下可缓慢移动，亦可施展低威力法术而不暴露。
如欲解除，心念再动黑影自背后脱离消散。
口诀可默念"化影归虚"四字以助入定。

## 使用限制

**次数：** 一次性。
**修为要求：** 金丹期以上方可完全发挥遁形之妙。筑基期使用隐匿效果减半且持续时间缩短至一刻钟。
**反噬：** 若在隐匿期间施展大威力法术或受到直接攻击，遁形状态立刻解除且会在解除时产生短暂灵力波动暴露位置。对修炼天眼通或有破虚法器的元婴修士，仍有可能被识破。若遁形时被大范围禁制覆盖，可能被逼出。

## 著名制符师/典故

暗影阁阁主"夜影老人"，制遁形符之法传自上古影杀宗，距今已传承三千年。
其符以千年影蚕丝为纸、九幽暗影豹心头血为墨，一张可藏身三日、化神难察。
他曾凭一枚遁形符闯入化神修士的道场，在书架间翻阅典籍三日后从容离去，对方浑然不知。
夜影老人制符从不示人，制符时以影幕遮蔽周身、外人只见一团黑影，留下无尽传说。

## 同类对比

遁形符乃隐身符的进阶版，两者差距如萤火比皓月。
隐身符仅遮蔽视觉和部分气息，高手可用灵觉识破；遁形符则近乎从天地间抹去存在感，是潜行暗杀的至高符箓之一。
较之空明符专攻气息隐匿、身形仍在，遁形符更为全面、身形气息一并隐匿。
然遁形符制造成本高出空明符数倍，非大宗门核心弟子不可拥有。
遁形符为暗影阁不传之秘，仿制者虽多但真品难得。市面所见遁形符多为下品仿制，隐匿效果远不及真品。购买时需认准暗影阁的暗影印记。
