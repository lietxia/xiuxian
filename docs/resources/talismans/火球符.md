# 火球符

**品阶：** 一阶下品（初级符箓）

## 符体描述

符纸以赤焰草浆掺朱砂碾压而成，色如凝血，纸面细看有暗纹如岩浆龟裂。
入手微温，若握得久了，掌心会生出一层薄汗，仿佛纸中封印着一团随时可能爆开的暴烈之力。
符墨乃朱砂融合火蜥蜴心头血调制，墨色暗红近黑，以玉杵研磨时隐隐有硫磺气味刺鼻。
符文走势如烈焰腾空，主纹一圆三弧——圆为火核，三弧为焰舌外舔，名曰"三焰聚火纹"。
三弧长短不一：天弧最长上冲，地弧最短下沉，人弧居中缠绕，暗合三才火运之理。
成符后置于阴凉处，若以指弹符面，声如裂帛，清脆中带着一丝沉闷的爆响。

## 制作方法

**材料：** 赤焰朱砂纸一张、朱砂三钱、火蜥蜴心头血三滴（须活取）、灵泉水五滴、阳燧石一方。
**步骤：** 朱砂入石臼以玉杵研磨百圈至细腻无渣，滴入火蜥蜴血后顺时针搅动八十一圈，墨色由朱转绛即火性已活。静置一炷香待墨面浮起一层薄薄赤油——此为火精外溢之兆。提笔蘸墨，先点符胆为火核，再三笔勾勒焰舌，笔势须一气呵成，中途不可顿笔。收笔时以真火注入符胆封灵，阳燧石压符半日令火气内敛。
**成功率：** 初习者二三成，熟手七八成。火蜥蜴血死后半个时辰火性散半，隔日则墨成废品。

## 功效

激发后化一枚人头大小火球，赤红中泛着橙黄焰芒，携滚滚热浪轰向目标。
命中时轰然爆开，烈焰四溅覆盖方圆丈许，温度足以熔金化铁。
火球飞过时空气扭曲，发出尖锐呼啸如鬼哭，令人闻之胆寒。
对阴寒毒瘴之物有天然克制，火焰所过之处瘴气如雪遇沸油。
**持续时间：** 火球离符后飞行三十丈自行消散。命中目标则爆燃三息，若未命中落地燃起一簇火焰持续片刻。

## 使用方式

以灵力注入符胆，振腕掷出，低喝"疾"字。
火球离手三丈即自燃成形，拖曳一条灼热尾焰直扑敌手。
可贴于箭矢射出一并激发，箭到火到。
亦可卷于飞刀之上掷出，中敌后符燃火起，刀火双伤。
夜间使用火光冲天，兼具震慑之效。

## 使用限制

**次数：** 一次性，激发即焚。
**修为要求：** 炼气三层以上。凡人强行激发必遭火灵力反噬，经脉如焚。
**反噬：** 水灵根修士使用灵力相克，威力仅余六成且火球可能半途熄灭。火灵力注入过猛则符纸自燃伤手。符墨未干透使用则火焰方向失控，可能误烧己身。

## 著名制符师/典故

南疆散修张火云，早年以制火球符闻名坊市，人称"三成张"——其符威力较寻常火球符高出三成。
他每制符前必饮三碗烈酒，以酒气激火性，笔势方得狂放不羁之韵。
据传他曾在妖兽潮中以百张火球符布下"火雨阵"，百符齐发如流星坠地，将一群二阶火鸦焚为焦羽，从此名震南疆。
晚年著《火符三昧》三卷传世，开篇第一句便是："画火符如驭烈马，心手相合方能驾驭。"

## 同类对比

火球符乃五行基础攻击符中销量之冠，每年修真界消耗以百万计。
威力不及雷符刚猛，不如金剑符锋锐，然制作简单、成本低廉，乃散修行走江湖必备。
较之火鸟符，火球符灵力集中、精准更胜，但缺乏自主追击之能。
百张火球符造价不及一张雷符三分之一，性价比无出其右。
