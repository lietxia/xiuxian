# 风刃符

**品阶：** 一阶下品（初级符箓）

## 符体描述

符纸以青桑树皮经九蒸九晒去粗取精制成，质薄如蝉翼而坚韧似牛皮，色青灰如将雨未雨的天空。
入手轻若无物，指尖捻之如拈一片羽毛，遇风则微颤有声如春蚕食叶。
符墨乃青风鸟羽灰调疾风露——青风鸟乃风系一阶灵兽，其羽灰入墨后有轻盈飘逸之性。
墨色青灰如阴云密布，以鼻近闻有淡淡青草清香，乃疾风露特有的山野气息。
符文如风旋之形，主纹三道弧线交缠于一点，名曰"三旋风刃纹"——纹理看似凌乱实则暗合风向变化之理。
成符后以指弹之声脆而清越，如风铃轻响。

## 制作方法

**材料：** 青桑纸一张、青风鸟羽灰二钱、疾风露五滴、灵泉水少许、风灵石碎屑一撮。
**步骤：** 羽灰研至极细过罗筛三次至触手如脂粉。入疾风露调成糊状，再以灵泉水稀释至墨稠适度，加入风灵石碎屑以增风性。取青桑纸以玉镇压平，鹤毛笔蘸风墨自外而内旋笔入符胆。运笔须快如疾风以意驭笔，不可有片刻迟疑——一顿则风散气泄。完符后置于风口处自然风干，以风养风，不可曝晒烈日。
**成功率：** 约四成。风系符箓最重笔意连贯，一顿则前功尽弃。制符之日若有微风拂面则天时相助，成功率可增一成。

## 功效

激发后化一枚无形风刃，半月之形，高速旋飞而出。
可切割皮革藤甲，对无甲目标尤为致命——风刃过处切口平整光滑，敌手往往中招后方知被袭。
风刃破空之声极微，如蚊虫振翅，耳目灵敏者仅能捕捉一丝尖啸。
可随施符者意念小幅变向追敌，如猎鹰俯冲。
**持续时间：** 风刃飞出约四十丈后消散于风中。遇障碍则切割后消散，薄木板布甲可一切而过。

## 使用方式

双指夹符注入风灵力，振腕一挥，风刃即循挥动方向无声飞出。
口诀曰"风起刃生，无形无影"。
可置符于折扇之中，谈笑间挥扇暗发风刃，杀人于无形。
更高明者将风刃符贴于飞针之上，以针引风刃穿透力倍增且轨迹更难捉摸。

## 使用限制

**次数：** 一次性。
**修为要求：** 炼气三层以上。
**反噬：** 风刃无形无质，狭小空间使用可能因回风反弹误伤己方。曾有修士对敌时误判风向，风刃折返削断自身发髻，沦为坊间笑柄。大风天气使用风刃轨迹可能随风偏转，需以神念额外校准。

## 著名制符师/典故

风灵门女修柳依依，制风刃符以轻灵著称。
其符激发后风刃可于空中变向三次追袭逃敌，号称"三折风刃"。
此法乃她在悬崖边观旋风穿林悟得——叶片遇风则转向借力，遂将风刃亦炼出折向追击之能。
同门叹服，尊其为"风符仙子"。
她后来将此法写入《风符要诀》，成为风灵门不传之秘。据传她晚年坐化时，周身环绕三道清风百日不散。

## 同类对比

风刃符威力在三初级符中垫底，单次伤害不及火球符之爆裂、冰锥符之穿透。
然其无形无声之特性使其成为偷袭首选，敌手至死不知攻击从何而来。
与火球符正面强攻不同，风刃符更适合作战辅攻或扰敌——可切割对手兵器带、暗器袋等。
制作成本亦是三符中最低，青风鸟羽灰易得，疾风露虽稀但用量甚微。
然遇重甲或石肤术等物理防御，风刃符几乎无效。
