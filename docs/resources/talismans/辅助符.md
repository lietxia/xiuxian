# 辅助符

## 四阶辅助符（元婴期）

四阶辅助符是元婴期修士使用的辅助符箓，功能强大，涵盖挪移、隐匿、破阵、传音等方面。

| 名称 | 功效 | 材料 | 参考价格 |
|------|------|------|----------|
| 瞬移符 | 瞬间移动百里，用于逃命或突袭 | 千年符纸、虚空砂 | 2万灵石 |
| 隐匿符 | 完全隐匿气息，元婴期以下无法察觉 | 千年符纸、隐匿石 | 1万灵石 |
| 破阵符 | 破除四阶以下阵法禁制 | 千年符纸、破阵石 | 1.5万灵石 |
| 传音符 | 万里传音，可跨越山脉传递信息 | 千年符纸、天音石 | 3000灵石 |
| 疗伤符 | 加速骨骼与皮肉愈合，一日内愈合轻伤 | 千年符纸、血藤汁 | 5000灵石 |
| 回气符 | 恢复元婴期修士三成灵力 | 千年符纸、回气石 | 8000灵石 |
