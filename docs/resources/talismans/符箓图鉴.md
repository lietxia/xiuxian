# 符箓体系

## 符箓的等级

符箓根据其威力和制作难度，通常分为以下几个等级：

### 低级符箓
- **等级**：一阶、二阶
- **威力**：适合炼气期和筑基期修仙者使用
- **制作难度**：较低，需要掌握基本的符文绘制技巧
- **代表符箓**：火球符、风刃符、防御符、治疗符

### 中级符箓
- **等级**：三阶、四阶
- **威力**：适合金丹期和元婴期修仙者使用
- **制作难度**：中等，需要熟练掌握符文绘制技巧和阵法知识
- **代表符箓**：雷暴符、冰锥符、隐身符、飞行符

### 高级符箓
- **等级**：五阶、六阶
- **威力**：适合化神期和炼虚期修仙者使用
- **制作难度**：较高，需要精通符文绘制技巧和阵法知识，还需要强大的神识
- **代表符箓**：空间禁锢符、时间减速符、大挪移符、自爆符

### 顶级符箓
- **等级**：七阶、八阶
- **威力**：适合合体期和大乘期修仙者使用
- **制作难度**：极高，需要对天地规则有深刻的理解，还需要特殊的材料和环境
- **代表符箓**：灭世雷符、混沌符、生死符、轮回符

### 仙符
- **等级**：九阶及以上
- **威力**：适合仙人使用，拥有毁天灭地的力量
- **制作难度**：无法想象，只有仙人才有能力制作
- **代表符箓**：仙雷符、仙火符、仙风符、仙水符

## 符箓的分类

### 攻击类符箓

#### 单体攻击符箓
- **火球符**：一阶符箓，释放一个炽热的火球，攻击单个目标，适合炼气期修仙者使用
  - **等级**：一阶
  - **适用修为**：炼气期
  - **效果**：释放直径约1米的火球，造成火焰伤害，有一定的灼烧效果
  - **制作材料**：黄纸、朱砂墨、火属性灵草

- **风刃符**：一阶符箓，释放一道锋利的风刃，切割目标，适合炼气期修仙者使用
  - **等级**：一阶
  - **适用修为**：炼气期
  - **效果**：释放长约2米的风刃，造成切割伤害，有一定的穿透效果
  - **制作材料**：黄纸、普通墨汁、风属性灵草

- **雷暴符**：二阶符箓，释放一道强大的雷电，攻击目标，适合筑基期修仙者使用
  - **等级**：二阶
  - **适用修为**：筑基期
  - **效果**：释放一道闪电，造成雷电伤害，有一定的麻痹效果
  - **制作材料**：灵纸、灵墨、雷属性灵草

- **冰锥符**：二阶符箓，释放一支尖锐的冰锥，刺穿目标，适合筑基期修仙者使用
  - **等级**：二阶
  - **适用修为**：筑基期
  - **效果**：释放长约3米的冰锥，造成穿刺伤害，有一定的冰冻效果
  - **制作材料**：灵纸、灵墨、冰属性灵草

- **飞剑符**：三阶符箓，召唤一把锋利的飞剑，攻击目标，适合金丹期修仙者使用
  - **等级**：三阶
  - **适用修为**：金丹期
  - **效果**：召唤一把由灵气凝聚的飞剑，自动追踪目标，造成切割伤害
  - **制作材料**：玉符纸、金墨、剑形灵草

- **破甲符**：三阶符箓，释放一道破甲能量，穿透目标的防御，适合金丹期修仙者使用
  - **等级**：三阶
  - **适用修为**：金丹期
  - **效果**：释放一道破甲能量，无视目标三成防御，造成真实伤害
  - **制作材料**：玉符纸、金墨、穿山甲鳞片

- **五行灭杀符**：四阶符箓，释放五行之力，灭杀目标，适合元婴期修仙者使用
  - **等级**：四阶
  - **适用修为**：元婴期
  - **效果**：释放金、木、水、火、土五行之力，形成五行剑阵，全方位攻击目标
  - **制作材料**：金符纸、金墨、五行灵草

  - **效果**：产生剧烈爆炸，攻击直径约8米范围内的所有目标，造成冲击波伤害

- **万箭齐发符**：四阶符箓，释放无数箭矢，攻击范围内的所有目标，适合元婴期修仙者使用

  - **等级**：二阶

  - **制作材料**：灵纸、灵墨、毒属性灵草

  - **等级**：三阶

- **诅咒符**：三阶符箓，对目标施加诅咒，使其运势下降，适合金丹期修仙者使用
  - **等级**：三阶
  - **适用修为**：金丹期
  - **效果**：对目标施加诅咒，使其修炼速度大减，战斗中屡屡失手
  - **制作材料**：玉符纸、金墨、诅咒属性灵草

  - **制作材料**：金符纸、金墨、神魂属性灵草

- **自爆符**：五阶符箓，与目标同归于尽，产生巨大爆炸，适合化神期修仙者使用
  - **等级**：五阶
  - **适用修为**：化神期
  - **效果**：使用者引爆自身神魂，产生巨大爆炸，攻击直径约100米范围内的所有目标，使用者自身死亡

  - **适用修为**：炼虚期

  - **制作材料**：仙符纸、仙墨、因果属性灵草

  - **适用修为**：合体期

  - **制作材料**：神符纸、神墨、时间属性灵草

## 符箓之道

符箓之道，博大精深。从一阶到九品，从凡符到仙符，每一步都是对天地法则的更深理解。

符箓之术，最易入门却最难精通。低阶符箓可依样画葫芦，高阶符箓则需符箓师对天地法则有深刻的领悟。一张极品符箓的诞生，往往是符箓师心血的结晶。
