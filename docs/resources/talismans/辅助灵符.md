# 辅助灵符

> 辅助灵符是辅助修士的灵符，可增幅各种属性。其外形为一张灵符，上画辅助咒文。传说辅助灵符乃上古时期一位大能模仿天地法则所创，每张灵符都蕴含一种辅助之力。

---

## 品阶

| 项目 | 内容 |
|------|------|
| 初始品阶 | 一阶·符箓 |
| 最高品阶 | 七阶·灵符 |
| 所属类别 | 辅助类·增幅符箓 |
| 稀有程度 | 常见 |

## 外形描写

辅助灵符外形为一张灵符，上画辅助咒文。符纸由各种灵木制成，散发着淡淡的清香。不同品阶的辅助灵符大小不同——低阶仅手掌大小，高阶可达一尺见方。

## 功能与效果

- **增幅属性**：可增幅各种属性，如攻击、防御、速度等
- **增幅幅度**：每升一品，增幅幅度翻倍
- **持续时间**：低阶约一炷香，高阶可达一个时辰

## 炼制方法

- **主要材料**：灵符纸、灵墨、各种灵木
- **炼制条件**：需筑基期以上修为，掌握基础符箓术
- **炼制时间**：低阶一日，高阶需数日

## 使用限制

- 辅助灵符为一次性消耗品
- 辅助灵符效果不可叠加
- 辅助灵符对品阶高于本身的目标无效

## 著名典故

上古时期，有一位名为"辅助子"的大能，在昆仑山发现了一张辅助灵符。他将其带出，用以增幅各种属性，成为修真界最强的符修。

## 同类对比

与**特殊灵符**相比，辅助灵符效果更加单一。与**攻击灵符**相比，辅助灵符更加温和。
