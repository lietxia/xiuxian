# 追星赶月

## 基本信息
- **功法名称**：追星赶月
- **品级**：三阶（地级）
- **类型**：身法功法
- **适用境界**：金丹期
- **修习难度**：★★★☆☆

## 功法介绍

《追星赶月》的创造者是一位性格极为张扬的修士——"逐日真人"。此人行事狂妄，但天资纵横，金丹期时就敢挑战元婴修士。他最出名的事迹不是斗法取胜，而是他曾做过一件让整个修真界瞠目结舌的事——追逐太阳。

逐日真人年轻时曾听闻一个传说：在天地尽头有一棵扶桑神树，太阳每晚都在那里休息。他好奇心起，决定亲眼去看看。于是他从东海岸出发，一路向西追逐落日。他用遁术狂奔了七天七夜，跨越了十万里山河，最终在第八天的黄昏时看到了一个奇景——太阳真的在西方地平线上"停留"了一会儿，仿佛在等他。

当然，他并没有真的追到太阳——那只是一个光学幻象。但这次经历让他领悟到了一个关于速度和追逐的深刻道理："你追的是太阳，但你永远追不上。可当你不再追的时候，太阳反而会停下来等你——不是太阳停了，是你的心停了。"

他从中悟出了一套独特的身法理念——追逐的最高境界不是"追"，而是让目标自己"靠近"你。他以此创立了《追星赶月》，一门以"势"和"意"驱动的身法。修炼此术的修士不需要拼命奔跑，而是在移动中蓄势，在蓄势中等待，在等待中爆发——如同射出的箭矢在离弦之前的那一瞬间积蓄的力量。

逐日真人晚年曾对弟子总结此功法的精髓："天下万物的移动，都遵循着一个规律——欲速则不达。你越想追到的东西，你越追不到；你越放松，目标反而离你越近。追星赶月教的不是怎么跑，而是怎么等。"

## 功法特点

**优点：**
- 爆发力极强——在短距离内的瞬间加速能力是同阶身法中数一数二的
- 适合追击和拦截——对移动中的目标有着天然的压制效果
- 可以"借势"加速——从对手的攻击中借力，以彼之道还施彼身
- 在追逐战中越战越勇——追逐目标的过程中，速度和气势会不断提升
- 练成后对距离和时机的感知极为敏锐——能精准判断最佳出手时机

**缺点：**
- 长途奔袭效果一般——追星赶月擅长的是短距离爆发而非长距离巡航
- 在被追击时效果大减——此功法是为"追逐者"设计的，逃跑时反而施展不开
- 极度依赖"目标"的存在——如果没有明确的追逐目标，此功法的威力会大打折扣
- 容易陷入"追逐执念"——修炼者在追逐目标时容易忽视周围环境，被伏击的风险极高
- 对心性要求极高——追逐时需保持"既迫切又从容"的矛盾心态，一般人很难掌握

## 功法等级

**望星**：学会锁定目标并感知目标的移动轨迹。此阶段修炼者在追逐时会自动预判目标的下一个位置——不是靠计算，而是靠一种近似本能的"感觉"。此阶段速度提升有限，但追击的精准度大幅提高。

**追星**：初步掌握追逐的"势"。在追逐目标时，速度和气势会越来越强，如同滚雪球一般。此阶段修士可以在追逐过程中逐步加速，在追上目标的瞬间达到速度的峰值。此阶段被称为"追星"——因为你追逐的已经不是目标本身，而是目标留下的"轨迹"。

**赶月**：达到"以势压人"的境界。在追逐目标的过程中，修炼者的气势会形成一种无形的压迫感，让被追逐者感到窒息和恐慌——如同被一头猎豹盯上的羚羊，心理防线会先于身体崩溃。此阶段修士的目光在追逐时会产生一种奇异的"锁定感"，被盯上的人会感觉怎么跑都跑不掉。

**星月同辉**：追与赶合二为一的最高境界。修炼者不再需要刻意去追逐——一个眼神、一个念头，目标就会自动进入攻击范围。这不是目标在靠近你，而是你在不知不觉中已经站在了目标必经之路上。逐日真人当年达到此境后，曾说过一句极为狂妄的话："我要追的人，从未逃掉过。"

## 功法招式

1. **星锁**：以神识锁定目标，在目标身上留下一道无形的"星痕"。只要星痕不灭，无论目标逃到哪里，修炼者都能感知到其大致方位。星痕可持续十二个时辰，但对神识消耗不小，一次最多同时锁定三人。

2. **踏星步**：每一步踏出都在地面上留下一道星芒脚印——不要误会，这不是为了好看。星芒脚印实际上是灵力的凝聚点，修炼者可以在踩到这些脚印时获得二次加速。此招的核心是在战场上提前布置"加速点"，形成一条属于你自己的加速路径。

3. **逐风式**：锁定目标后，以意念引导身体以最短路径接近目标。在此状态下，修炼者的眼中除了目标以外的所有事物都会变得模糊——这是一种高度专注的状态，可以让你排除一切干扰。但同时也意味着你很容易忽略周围的伏击。

4. **月影步**：利用高速移动在目标周围留下多个残影，让目标无法判断你的真实位置。与普通残影不同——月影步的残影会模仿你的下一个动作，让目标产生"预判错误"。此招是追星赶月中最精妙的惑敌之术。

5. **星坠**：将所有积蓄的"势"在一瞬间全部释放，化作一次雷霆万钧的冲击。此招的速度是正常情况下的三倍，但使用后会有短暂的气力真空期——因为所有的势都在一瞬间用尽了。星坠的精髓不在于速度，而在于时机的把握——在目标最松懈的那一刻发动。

6. **星月交辉**：传说之招。修炼者与目标之间会产生一种奇异的"牵引感"——仿佛有一条无形的锁链连接着两人。此时修炼者的每一个动作都会"引导"目标的行动——你向左，目标也会不自觉地向左；你加速，目标也会不自觉地加速。最终目标是"带着"目标跑，而不是"追着"目标跑。据说此招修炼到最高境界时，可以让目标主动走向你——因为他会认为那是他自己的意愿。

## 修炼条件

- **前置功法**：需将《基础遁术》和《瞬息千里》都练至大成——追星赶月对速度和爆发力都有较高的要求
- **灵根要求**：以火属性和雷属性灵根为佳——这两种灵根的爆发力最强。水木属性修士修炼时需要在爆发力上多下功夫
- **性格要求**：需要有极强的求胜欲和行动力——安于现状、与世无争的修士无法领悟追逐的真谛
- **特殊心态**：需要经历过"求而不得"的痛苦——只有真正体验过追逐的渴望与失落，才能理解"追"与"等"之间的微妙平衡
- **修炼方式**：最好通过与人对练来修炼——对着死物练习永远无法掌握追逐的精髓

## 使用限制/副作用

- **执念反噬**：追星赶月在追逐目标时会产生一种精神上的"锁定效应"。如果目标最终逃脱，修炼者会遭到强烈的精神反噬——表现为狂躁、抑郁甚至自残倾向。历史上有多位追星赶月的修炼者在追丢目标后走火入魔。
- **视觉疲劳**：长时间处于高度专注的追逐状态，眼睛会承受极大的负担。表现为视力模糊、眼压升高、眼球充血。许多修炼此术的老修士都有严重的眼疾。
- **体力透支**：积蓄的"势"在爆发后会留下一段虚弱期。这段虚弱期的长度与爆发强度成正比——如果以星坠全力一击，之后可能虚脱长达半个时辰。
- **社交影响**：修炼追星赶月的修士在日常生活中也会不自觉地带上"追逐"的习惯——和人说话时目光过于专注，让对方感到压迫感；走路时会不自觉地跟在别人后面，让人毛骨悚然。

## 相关典故

**典故一：逐日真人追太阳**
逐日真人追逐太阳的故事在修真界流传甚广。传说他出发时背着一壶水、一柄剑，从东海之滨一路向西。他白天追着太阳跑，夜里在山野中露宿。他的事迹引起了沿途许多修士的注意，有人笑他痴傻，有人佩服他的勇气。

第八天的黄昏，逐日真人站在西极的万仞高峰上，望着即将沉入地平线的落日。他忽然大笑三声，声震四野："我追的不是太阳，我追的是我自己的极限！太阳落下了明天还会升起，但若我今天停下了，我的道心就永远追不上了。"

他转身下山，从此闭关于一座无名山谷，一年后出关时，手中多了一卷功法——正是《追星赶月》。他对前来迎接的故友说了这样一句话："我追上了太阳——不，我追上了我自己。"

**典故二：千里追杀——三日三夜的无悔追踪**
七百年前，一位追星赶月的修炼者"流星剑"楚南，为了追杀杀害他全家的仇人，横跨了三个大洲，追了三天三夜。他的仇人是一个金丹巅峰的魔修，狡猾异常，不断变换方向、布置陷阱、雇佣替身。

但楚南的星锁一旦锁定目标，就绝不会松开。他追了三天三夜不眠不休，眼睛布满血丝，嘴角溢出血沫。第三天的落日时分，他在一处荒原上终于追上了那个魔修。此时他的灵力已经见底，双腿颤抖不止，但他眼中的"锁定"光芒让那魔修吓得瘫软在地。

楚南一剑斩下仇人的头颅，然后仰天倒下——他力竭昏迷了整整七天。醒来后有人问他何必这么拼命，他答道："我不是为了报仇而追，我是为了给我死去的家人一个交代。追星赶月教会我的不是如何追上别人，而是如何不辜负自己的承诺。"

## 修炼进度

**初学期（约三至六个月）**：学会锁定目标——以神识感知目标的移动并预判其轨迹。此阶段修炼者会在追逐时不由自主地模仿目标的动作，看起来有些滑稽。需要刻意练习才能摆脱这种"镜像效应"。

**成长期（约一至二年）**：掌握星锁和踏星步。可以在追逐中保持稳定的加速曲线，并在锁定目标的同时保持对周围环境的感知。此阶段的修炼者最大的进步是"追得不那么累了"——之前的追逐靠蛮力，现在开始学会借力。

**精进期（约五至十年）**：掌握逐风式和月影步。可在追逐战中同时使用惑敌技巧，不再是一味地直线追击。此阶段的修炼者开始理解"追逐的节奏"——知道什么时候该加速，什么时候该减速，什么时候该停下来等一等。

**大成期（约二十至三十年）**：掌握星坠，达到赶月境界。此阶段的修炼者一旦锁定一个目标，就会给目标造成极大的心理压力——被追星赶月的修士盯上的人，往往会因为心理崩溃而犯错。此阶段的标志是你已经不再需要用眼睛去看目标——你能"感觉"到他在哪里。

**化境（机缘所至）**：星月同辉。据逐日真人留下的手札记载，此境界已经不是修炼能至——"当你不再为了追而追，当你真正理解了静与动的统一，你自然会达到。"古往今来，据说只有逐日真人和他的大弟子达到了这一境界。
