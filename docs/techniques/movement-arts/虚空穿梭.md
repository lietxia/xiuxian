# 虚空穿梭

## 基本信息
- **功法名称**：虚空穿梭
- **品级**：八阶（帝级）
- **类型**：身法功法
- **适用境界**：大乘期
- **修习难度**：★★★★★

## 功法介绍

《虚空穿梭》乃八阶帝级身法，放眼整个修真界，能够与之比肩的身法寥寥无几。此功法由太古时代一位被称作"虚空大帝"的无上存在所创，据传此帝非人非妖非魔，而是诞生于虚空乱流中的一道先天元灵，天生便精通空间法则。

虚空大帝在混沌中游历了百万年，将虚空法则参悟到了极致，最终创造出了这门可以自由穿梭于诸天万界的身法。与其他空间类身法不同，虚空穿梭不是在"主世界"的表面上移动，而是直接潜入更深层的虚空层面——那里是主世界之下的阴影，是空间与空间的夹缝。在虚空层面中，主世界的距离、障碍、法则都不复存在，修士可以在其中自由穿行，然后从任意一个位置破开虚空回到主世界。

传说虚空大帝曾以此术在眨眼之间横跨九界，从凡间界一步踏入仙界。他飞升神界之前，将此功法封印于九枚虚空玉简之中，散落在天地各处。后世修士若有机缘得到其中一枚，便可参悟虚空穿梭的奥秘。但九枚玉简至今只被发现四枚，余下五枚仍隐藏在未知的虚空深处。

## 功法特点

**优点：**
- 可以在诸天万界之间自由穿梭，无视界面壁垒
- 移动速度堪称天下无双——从启动到抵达，几乎不需要时间
- 潜入虚空层面后可躲避几乎所有攻击——物理、法术、神魂攻击均无法触及虚空层面
- 可以在战斗中频繁出入虚空，形成神出鬼没的战术优势
- 不受任何地形和禁制的限制——因为直接从空间层面绕过

**缺点：**
- 修炼难度极高——需要对空间法则有极深的理解，非大乘期修士无法驾驭
- 在虚空层面中会持续受到虚空之力的侵蚀——停留时间越长，身体和神魂受损越严重
- 定位精度随距离增加而下降——远距离穿梭时可能出现数百里的偏差
- 若在穿梭过程中被空间风暴卷入，可能被抛入未知的时空乱流中，永远找不到归路
- 在法则稳固的上界（如神界）中使用时，消耗是下界的十倍以上

## 功法等级

**虚空感应**：能感知到主世界之下的虚空层面存在，如同隔着水面看到水下的世界。此阶段修士尚无法进入虚空，但可以在战斗中利用虚空气息制造空间波动来干扰对手。

**虚空入微**：能将身体的一部分（如一只手臂）短暂地送入虚空层面，从另一个位置穿出。此招用于出其不意的攻击——你的拳头可能从敌人的背后打出来。但这极其危险，因为收回肢体时若被空间夹断，便永久失去了那一部分。

**虚空行走**：整个人可以潜入虚空层面，在虚空中行走。每次潜入最多持续十息时间——超过此限，虚空之力会开始侵蚀肉身。此阶段的修士可以在战斗中频繁穿梭虚空，来去如鬼魅。

**虚空跨越**：可以在虚空层面中快速穿行较长的距离，实现真正意义上的空间跨越——从一座大陆直接传送到另一座大陆。此阶段修士在虚空中停留的时间延长至一炷香。

**万界随心**：传说之境。可以在诸天万界之间随意穿梭，无视一切空间法则的束缚。到达此境的修士已经将虚空法则融入了自身的存在——他们自身便是一个移动的空间通道。据说虚空大帝本人在创造出此功法的同时便达到了这一境界。

## 功法招式

1. **虚空裂隙**：以指尖划开一道细小的空间裂隙，身体化为一道流光钻入裂隙中，从数丈外的另一道裂隙中钻出。此招消耗极小，是虚空穿梭最基本的运用，可用于短距离闪避和变位。

2. **暗影潜行**：潜入虚空层面并在其中移动，在主世界不留任何痕迹。此招用于潜行、侦察和逃脱。在虚空层面中观察主世界，如同隔着一层薄纱看世界——一切景物都模糊而遥远。此期间修士可以看到主世界的一切，但主世界的生物无法感知到修士的存在。

3. **虚空之刃**：在钻出虚空的一瞬间，以空间裂隙的边缘为刃，切割目标。此招极难防御——因为空间裂隙本身就是最锋利的刀刃，可以切断几乎任何物质。但此招对灵力的消耗极大，且需要极其精准的空间掌控，稍有偏差就会切到自己。

4. **空间锚定**：在主世界的一个位置留下一个"空间锚"，之后可以在任意位置撕开虚空直接回到锚点位置。此招是虚空穿梭中最实用的旅行手段。但空间锚会散发微弱的虚空波动，高阶修士可以感知到并被追踪。

5. **虚空风暴**：强行撕裂一大片空间，制造出小范围的虚空风暴，将周围的一切都卷入空间乱流中。此招是威力极大的范围攻击，但极其危险——若施术者自身也被卷入风暴，可能永远迷失在虚空中。此招被认为是虚空穿梭中最接近禁术的存在。

6. **万界之门**：传说之招。以自身为媒介，在任意两个位置之间打开一道永久性的空间之门。此门一旦建立，可以反复使用，成为一条固定的空间通道。虚空大帝曾以此招在九界之间建立了九座虚空之门，至今仍有一些处于运转之中。

## 修炼条件

- **前置功法**：必须将《咫尺天涯》或同类空间身法修至大成，对空间法则有深刻的理解
- **境界要求**：最低要求为大乘期——不到大乘期，肉身和神魂都无法承受虚空层面的压力
- **灵根要求**：空间异灵根为最佳，次之为虚空灵根、混沌灵根。不具备空间类灵根的修士几乎不可能练成
- **神魂强度**：必须达到大乘期的神魂修为——在虚空层面中，若神魂强度不够，会被虚空中的混沌意志同化
- **特殊机缘**：必须找到一枚虚空玉简——因为此功法的核心口诀无法用语言传授，只能通过玉简中的神魂印记来领悟。没有虚空玉简，即便天资再高也无法入门
- **禁忌**：心性不正、贪念过重者不可修——在虚空中，心魔会被无限放大，一念之差便是万劫不复

## 使用限制/副作用

- **虚空侵蚀**：每一次进入虚空层面，身体和神魂都会受到不可逆的虚空侵蚀。表现为皮肤上出现黑色的虚空纹路——被称为"虚空痕"。虚空痕越多，说明被侵蚀越严重。当虚空痕布满全身时，修士会被虚空彻底吞噬，化为虚空的一部分。
- **时空迷失**：在虚空层面中，时间和空间的感知会被严重扭曲。修士可能在虚空中感觉只待了一炷香，但主世界已经过去了百年。历史上有一位虚空穿梭的修炼者，在虚空中追踪敌人时感觉只过了半个时辰，出来后发现自己的宗门已经灭亡了三千年。
- **记忆错乱**：频繁穿梭虚空会使修士的记忆出现断层和错乱——因为他们的大脑无法适应在不同空间之间跳跃的体验。很多修炼虚空穿梭的大能最后都会变得疯疯癫癫，分不清哪里是现实、哪里是虚空。
- **法则排斥**：每次进出虚空都会对主世界的空间法则造成微小的扰动。天道会逐渐将频繁穿梭虚空的修士标记为"不稳定因素"，在渡劫时降下更强的天劫来"清理"这个扰动源。

## 相关典故

**典故一：虚空玉简的传说**
九枚虚空玉简，传说每一枚都封存着虚空穿梭的一部分传承。第一枚玉简被发现于三万年前的虚空深渊——一位偶然坠入深渊的修士在临死前抓到了一枚发光的玉简，他临死前将玉简抛出深渊，被路过的修士捡到。这位修士后来成为了第一位修炼虚空穿梭的人族大能。

第二枚玉简出现在一处上古遗迹中，被封印在一块巨大的虚空水晶中。第三枚玉简则更为离奇——它是在一个凡人的梦境中被发现的。那个凡人连续七天做同一个梦，梦中有无数的空间碎片在飞舞，他醒来后发现自己枕边多了一枚玉简。第四枚玉简至今下落不明，据说被某个神秘势力收藏。

剩余五枚玉简，有人说它们隐藏在虚空中最危险的禁地，有人说它们就在我们身边但肉眼无法看见，也有人说它们根本不存在——因为这些玉简本身就是虚空法则的一部分，只有被选中的人才能感知到它们的存在。

**典故二：虚空大帝的最后一步**
虚空大帝在创造出虚空穿梭的第十万年，忽然消失了。他留下的最后一句话被刻在他的道场遗址上："我去了虚空的最深处，那里有诸天万界的源头。不必寻我。"

有人说他去了天道之上的地方，有人说他迷失在了虚空乱流中，也有人说他其实从未离开——他的意识已经化入虚空，成为了虚空本身。因为自此之后，修炼虚空穿梭的修士们发现了一件诡异的事：当他们在虚空中遇到无法解决的危机时，总会有一种冥冥中的力量将他们推回主世界，仿佛是有人在虚空中守护着他们。

## 修炼进度

**感应期（取决于机缘）**：获得虚空玉简，与其中的神魂印记产生共鸣。这个过程有的修士花了一辈子也做不到——他们即便手握玉简，也无法感知到其中的传承。而有些人只需一夜便能与玉简共鸣。这与资质无关，全凭缘分。

**入门期（约百年）**：能够感知虚空层面并打开微小的空间裂隙，进行短距离虚空穿梭。此阶段修士身上开始出现第一道虚空痕——通常出现在指尖或眼角。

**稳固期（约三百年）**：掌握虚空行走，可以在虚空层面中短暂停留并进行长距离跨越。此阶段修士的虚空痕已经蔓延到手臂和面部，需要用特殊的衣物或法器来遮掩。

**精进期（约千年）**：达到虚空跨越境界，可以在不同大陆甚至不同界面之间穿梭。此阶段的修士已被虚空之力深度改造——他们的身体会自然地散发出空间波动，弱小的修士仅凭气息就会被压制得无法动弹。

**超越之境（不可预测）**：万界随心。自虚空大帝之后，据说只有两位存在达到过这一境界——一位是太古时期的虚空神龙，另一位是某位不愿透露姓名的神秘大能。此境界已经超越了功法的范畴，进入了"道"的领域。
