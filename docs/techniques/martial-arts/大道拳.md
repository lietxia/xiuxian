# 大道拳

## 基本信息
- **功法名称**：大道拳
- **品级**：七阶（圣级）（圣级）
- **类型**：武技功法
- **适用境界**：合体期
- **修习难度**：★★★★★

## 功法介绍

大道拳传自太上道祖的一道神念化身。那化身名为"道一"，游历诸天万界，在人间讲道三千载。一日道一在讲道时，一武夫问道："道可道，非常道，那道能用拳头打出来吗？"道一大笑，随手打出一拳。那一拳没有任何花哨技巧，却让在场三千修士同时看到了自己的道——有人看到了天地初开、有人看到了轮回六道、有人看到了自己的本心。道一说："道不在经文里，在万物之中。拳也是道，道也是拳。"大道拳由此而生。此拳法不教招式、不教运气，只教一个"悟"字。

## 功法特点

**优点：**
- 一拳蕴含大道法则，无视物理防御
- 修的不是拳法而是对道的领悟，道行越深拳越强
- 每个修炼者领悟的"大道拳"都不相同，因人而异
- 可辅助悟道，修炼此拳法有助于突破境界瓶颈

**缺点：**
- 修炼方式抽象，全靠悟性，无法言传
- 没有固定招式，实战中需要临场发挥
- 悟性不足者修炼百年不得入门
- 对道心的要求极高，心有杂念则拳意不纯

## 功法等级

**入门**：打出的拳蕴含一丝道韵，令人心有所感

**小成**：拳出大道共鸣，天道法则加身

**大成**：一拳可引动天地法则，言出法随

**圆满**：拳即大道，一拳可改写局部规则

## 功法招式

大道拳无固定招式，以下为历代前人曾打出的代表性拳法形式（仅供参考，非必学）：

1. **太极式**：以柔克刚，拳出阴阳鱼旋转，化解万法
2. **无极式**：无形无相，拳出无迹可寻
3. **因果式**：拳劲穿越因果链，直接攻击过去或未来的敌人
4. **时空式**：一拳同时攻击多个时间点的敌人
5. **造化式**：拳出可创造或改变事物性质
6. **归一式**：万法归一的一拳，破尽万法
7. **道一式**：打出的不是拳而是一个问题"你的道是什么？"

## 修炼条件

- **前置功法**：不需要前置功法，但基础越深厚越好
- **体质要求**：无特殊要求
- **心性要求**：须有大智慧、大悟性，不钻牛角尖
- **修炼地点**：任何地方都可修炼，山河大川、人潮闹市皆可
- **所需资源**：不需要外物，需要的是阅历与思考

## 使用限制/副作用

- 过于追求大道可能导致超脱世俗、不食人间烟火
- 拳法威力全在悟性，面对资质愚钝的对手反而威力有限
- 无法传给悟性不足的人
- 斗战中顿悟可能导致短暂的失神

## 相关典故

道一打出的那一拳被后世称为"问道第一拳"。当时在场的三千修士中，有一人被打醒了道心，当场突破到大乘期；有一人被打出了心魔，当场走火入魔；还有一个农夫看了那一拳，回家种地去了，后来成为了一代"农道"宗师。道一事后说："每个人的道不同，同一拳在他们眼中自然不同。大道拳不是杀人技，是问心拳。"

## 修炼进度

- **悟**：可能一瞬间，也可能一辈子。有人当场入门，有人百年不得
- **证**：将所悟之道理印证于拳，形成自己的大道拳雏形
- **融**：道与拳合一，举手投足皆在道中
- **超**：超脱拳法的桎梏，以道御拳、以拳证道
