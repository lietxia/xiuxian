# 混沌拳

## 基本信息
- **功法名称**：混沌拳
- **品级**：九阶（混沌级）
- **类型**：武技功法
- **适用境界**：渡劫期
- **修习难度**：★★★★★

## 功法介绍

混沌拳乃开天辟地之初，混沌神魔"盘武"遗留于世的本能战斗之法。盘武是混沌孕育的第一批神魔之一，在天地未分之际便已存在。他经历了混沌初开、天地分离、万物诞生的全过程，见证了宇宙从无到有的演化。盘武没有学过任何功法，他的拳法就是混沌本身的律动——每一拳都是混沌的呼吸、每一次出拳都是宇宙的脉动。后盘武陨落于神魔大战，其遗体化为一片混沌禁区。一位名为"元始"的修士深入禁区，在盘武骸骨旁枯坐万年，终从其骨骼中残留的混沌气息中领悟出了这套混沌拳。

## 功法特点

**优点：**
- 蕴含混沌法则，可破万法而不被万法所破
- 混沌之力可同化一切能量攻击为己用
- 拳出如宇宙初开，混沌之气弥漫可腐蚀一切
- 拳法没有固定形态，随心所欲无迹可寻

**缺点：**
- 修炼者必须承受混沌之力对身体的改造，极其痛苦
- 每次出拳都有引发空间崩塌的风险
- 混沌之气会污染周围环境，不可在城市或宗门中使用
- 修炼者会逐渐失去人形，向混沌形态转化

## 功法等级

**入门**：拳中带混沌之气，可化解一切属性灵力攻击

**小成**：拳出混沌领域，领域内一切法则崩坏，唯有混沌

**大成**：一拳可开辟小世界，也可一拳毁灭小世界

**圆满**：化身混沌，拳即宇宙本源

## 功法招式

混沌拳本无招式，以下为后人根据盘武骸骨上的混沌痕迹推演出的七种可能性：

1. **混沌初开式**：双手缓缓分开，模拟天地初开的创世之力
2. **鸿蒙演化式**：拳中演化万物生灭变化
3. **混沌吞噬式**：拳化为黑洞，吞噬一切物质与能量
4. **无极归元式**：将一切归为混沌虚无
5. **混沌造化式**：从混沌中创造出新的物质
6. **混沌湮灭式**：以混沌之力湮灭目标的存在痕迹
7. **盘武开天式**：重现盘武开天辟地的终极一拳

## 修炼条件

- **前置功法**：至少将一门九阶以下功法修炼至圆满
- **体质要求**：必须是混沌之体或无属性之体
- **灵根要求**：混沌灵根或变异无属性灵根（唯一可能）
- **修炼地点**：混沌禁区或天地初开时的遗迹
- **所需资源**：混沌石、盘古精血、天地本源碎片

## 使用限制/副作用

- 修炼者的肉身会逐渐混沌化，最终失去人形
- 每施展一次都对周围环境造成不可逆的破坏
- 混沌之力会影响修炼者的心智，逐渐失去自我意识
- 若控制不当会被混沌同化，化为混沌的一部分
- 此功法有意识，它会选择宿主而不接受强行修炼

## 相关典故

元始修士在盘武骸骨旁枯坐万年后站起身，打出第一记混沌拳。那一拳让整个混沌禁区震荡，浓稠的混沌之气向四面八方奔腾。元始的身影在混沌中若隐若现，他每一次出拳都在混沌中开辟出一片新天地。打到第九千九百九十九拳时，整个混沌禁区被他一拳打穿，露出了一片从未有人见过的全新世界。元始回头看了一眼修真界，踏入那片新世界中消失了。后人猜测他可能成为了第二个盘武。

## 修炼进度

- **万年入门**：与混沌共鸣，初步掌握混沌之气
- **三万年小成**：混沌领域初成
- **六万年大成**：开辟小世界
- **十万年圆满**：化身混沌，重开天地
