# 仙腿无双

## 基本信息
- **功法名称**：仙腿无双
- **品级**：六阶（神级）（神级）
- **类型**：武技功法
- **适用境界**：炼虚期
- **修习难度**：★★★★★

## 功法介绍

仙腿无双乃上古仙兽鹤祖所创的绝世腿法。太古年间，天地初分，第一只仙鹤自混沌中诞生，其双腿修长优美，踏云而行、穿空而渡，速度冠绝万族。鹤祖观日月东升西落、观沧海桑田变迁，将亿万年岁月感悟融入腿部动作——每一次踢击都是一次日升、每一步踏出都是一次沧海变迁。后鹤祖将此腿法传于其唯一人族弟子"云中君"，云中君以此腿法横行仙界，被封为"踏云仙君"。仙腿无双讲究"快、准、美"三者合一，不似凡间腿法那般蛮横刚猛，而是以优雅的步伐和致命的精准取胜。

## 功法特点

**优点：**
- 速度冠绝同阶，出腿如仙鹤掠影，肉眼难辨
- 腿部动作优雅潇洒，令人防不胜防
- 可凌空踏虚而行，无需任何飞行法宝
- 修炼有成者可短暂停驻虚空

**缺点：**
- 对腿部柔韧性和协调性要求极高
- 力量不如刚猛类腿法，需以技巧取胜
- 修炼者需身材修长、比例匀称，否则难以达到圆满
- 须在开阔空间才能发挥全部威力

## 功法等级

**入门**：腿部柔韧达到极致，可凌空连踢七次

**小成**：出腿有仙鹤虚影，速度提升三倍，可踏水而行

**大成**：一腿幻化七道残影，敌人不知哪道是真

**圆满**：人腿合一如仙鹤展翅，凌空虚渡万里，一脚踏出日月倒转

## 功法招式

1. **鹤踏式**：轻点地面腾空，以脚尖攻击敌人穴位，精确致命
2. **凌云式**：凌空回旋踢，身体旋转三百六十度借力
3. **掠影式**：高速移动中出腿，留下七道残影迷惑敌人
4. **穿云式**：直线冲刺踢击，速度快到撕裂空气
5. **踏虚式**：在空中借力变向，连续踢击如仙鹤舞空
6. **逐日式**：追逐太阳轨迹的踢法，正面强攻
7. **无双式**：化身仙鹤真身虚影，一腿裂空，空间为之震荡

## 修炼条件

- **前置功法**：基础腿法圆满、雷属性或风属性腿法大成
- **体质要求**：身材修长、双腿比例超过身长六成者最佳
- **灵根要求**：风灵根或水灵根，雷灵根亦可
- **修炼地点**：高山之巅或云海之上
- **所需资源**：仙鹤灵羽七根、风灵石、天风玉髓

## 使用限制/副作用

- 狭隘空间（洞穴、巷道）中施展不開
- 穿重型护甲或负重过大时速度大减
- 女子修炼效果优于男子
- 若腿部受伤未愈强行运功，会导致经脉永久损伤

## 相关典故

云中君飞升仙界后，曾在蟠桃盛会上与仙界一位以腿法闻名的金仙切磋。那金仙双腿如铁柱，一脚可踢碎星辰。云中君却脚踏凌云式，轻飘飘地闪避了金仙所有攻击，忽然一记鹤踏式点在金仙膝盖穴道上，金仙整条腿一麻跪倒在地。之后云中君又以掠影式化出七道残影，那金仙眼花缭乱，被连续踢中三十六脚而毫无还手之力。西王母见状赞叹："此腿只应天上有，人间能得几回见？"遂赐号"仙腿无双"。

## 修炼进度

- **五年入门**：腿柔如无骨，可凌空七连踢
- **十二年小成**：踏水而行，出腿三倍速
- **二十五年大成**：七道残影惑敌
- **四十年圆满**：凌空虚渡，一脚日月倒转
