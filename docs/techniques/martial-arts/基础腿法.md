# 基础腿法

## 基本信息
- **功法名称**：基础腿法
- **品级**：一阶（黄级）
- **类型**：武技功法
- **适用境界**：聚气期
- **修习难度**：★☆☆☆☆

## 功法介绍

基础腿法由散修联盟初代盟主"风无痕"于四千年前归纳成册。风无痕年轻时曾游历九州，发现各地散修虽然功法各异，但腿功普遍薄弱，往往顾上不顾下。于是他集百家腿法之长，去芜存菁，整理出七式基础腿法，刊印成册散于天下散修。这部腿法口诀简单、动作朴实，却包含了踢、扫、绊、蹬、踹、勾、摆所有基本腿功技法，是下盘功夫的奠基之作。

## 功法特点

**优点：**
- 修炼下盘稳定，走桩站马效果极佳
- 腿长力大，踢击威力约为拳击的三倍
- 与拳法掌法配合，可做到拳脚并用、上下齐攻
- 修炼过程中极好地锻炼了平衡感和核心力量

**缺点：**
- 起腿半边空，出腿后重心不稳易被反击
- 需极好的柔韧性，韧带拉开过程痛苦漫长
- 穿窄袍或地形狭窄时施展受限
- 单腿站立时下盘防守空虚

## 功法等级

**入门**：能稳定踢出七式，踢断两指粗的木桩

**熟练**：一腿可连环踢出三式，踢碎半尺厚石板

**精通**：出腿无声，快如残影，可凌空连踢

**圆满**：腿即是手，灵活自如，高踢过顶、低扫入地，攻防一体

## 功法招式

1. **正蹬式**：提膝正蹬，攻敌胸腹，势大力沉
2. **鞭扫式**：侧身摆腿横扫，专攻敌膝弯与腰肋
3. **勾绊式**：低腿勾踢敌脚踝，使其失去平衡摔倒
4. **侧踹式**：侧身高踹，攻击距离最长，可拒敌于丈外
5. **后撩式**：背身反撩，攻其不备，专踢敌下巴
6. **踏压式**：抬腿猛踏，如巨象踩踏，可碎敌兵器
7. **旋风式**：腾空旋转扫踢，威力最大，但破绽也最大

## 修炼条件

- **体质要求**：无特殊要求，但柔韧性好者修炼更快
- **前置基础**：无需前置功法
- **修炼地点**：平坦宽敞之地，以沙滩软地最佳
- **所需资源**：绑腿沙袋一副，木桩若干

## 使用限制/副作用

- 初学阶段韧带撕裂风险极高，须循序渐进
- 高踢动作在湿滑地面容易滑倒
- 长期高强度踢击会导致膝盖磨损，需用药油养护
- 女子修炼过度会使大腿变粗，影响体态

## 相关典故

风无痕晚年曾以基础腿法与一位金丹期的邪修对战。那邪修嘲笑他"堂堂散修盟主只会这等粗浅功夫"。风无痕笑而不语，只以正蹬式起手，一记鞭扫式破敌下盘，紧接着侧踹式正中胸口，三式连环将那金丹邪修踢飞三丈有余。邪修败后心服口服，叹道："七式基础腿法在你脚下，不输任何高阶功法。"

## 修炼进度

- **百日开胯**：每日压腿拉筋，百日可一字马，韧带初开
- **一年入门**：七式纯熟，可单腿站立一炷香不倒，踢断木桩
- **三载小成**：连环踢击可达五式，凌空踢碎飞石
- **六年圆满**：七式化为本能，出腿无需思考，风吹草动即出腿相应，至此可修习更高阶腿法
