# 归一掌

## 基本信息
- **功法名称**：归一掌
- **品级**：七阶（圣级）
- **类型**：武技功法
- **适用境界**：合体期
- **修习难度**：★★★★★

## 功法介绍

归一掌为万法归宗门的上古创派祖师"归一道人"所创。归一道人年轻时曾遍访九州，习得百家掌法——佛门金刚掌、道家太极掌、魔教蚀骨掌、妖族的妖皇掌……他学得越多越迷茫，因为百家掌法各有道理、互相冲突，根本不可能同时使用。苦恼了五百年后，归一道人在一座破庙中看到一个小沙弥在扫地。小沙弥将满地的落叶扫成一堆，又全部倒入垃圾桶中。归一道人豁然开朗——万法归一，不在于学会所有法，而在于将所有法化为一法！他回去后将百家掌法全部打碎，取其精髓融为一炉，创出了这部归一掌。

## 功法特点

**优点：**
- 融合百家之长，可针对不同敌人切换不同掌意
- 掌法变化莫测，前一招至刚后一招至柔
- 对百家掌法的招式都有破解之法
- 修炼此掌法有助于理解其他功法的本质

**缺点：**
- 需要对百家掌法都有涉猎，修炼周期极长
- 贪多嚼不烂，若未真正融会贯通则威力不如专精一门
- 对修炼者的悟性和融会贯通能力要求极高
- 极易走上"学而不精"的歧路

## 功法等级

**入门**：能勉強融合三家门派的掌法精髓

**小成**：能融合十家掌法，自如切换

**大成**：百家掌法信手拈来，一掌兼具数家之长

**圆满**：万法归一，再多的掌法在手中也不过是一掌

## 功法招式

1. **佛魔一念式**：融合佛门慈悲与魔道狠辣，一掌两重天
2. **阴阳相济式**：道家的阴柔与刚猛合为一体
3. **正反相生式**：正派功法的浩然正气与邪派功法的诡诈并行
4. **刚柔并济式**：金刚掌的刚猛与绵掌的阴柔在同一掌中
5. **虚实相生式**：虚招与实招在同一招中不断切换
6. **万法归宗式**：瞬间调用所学的全部掌法精髓
7. **归一式**：终极一掌，攻击中包含百家掌法的所有变化

## 修炼条件

- **前置功法**：至少精通三门不同流派的三阶以上掌法
- **体质要求**：经脉容量极大，能同时运转多种不同属性的灵力
- **心性要求**：海纳百川，有包容万物的胸怀
- **修炼地点**：游历天下，四处拜师学艺
- **所需资源**：百家功法典籍、各流派宗师指点

## 使用限制/副作用

- 若未真正融会贯通，强行归一会导致经脉错乱
- 学的功法越多越杂，归一越难
- 遇到从未见过的流派掌法时可能被克制
- 修炼者容易陷入"收集癖"，沉迷收集功法而忽略本质

## 相关典故

归一道人创出归一掌后，用此掌法与当时修真界十大宗师逐一交手。他用佛魔一念式击败了佛门金刚；用阴阳相济式击败了道门太极；用正反相生式击败了魔教教主。十大宗师全部败在他一掌之下，却不觉得自己输了——因为归一道人每一战用的都是他们最熟悉的功法的影子却又完全不同。最后归一道人说："你们的功法我都学过，你们的优点我都了解，你们的缺点我也一清二楚。这就是归一。"

## 修炼进度

- **十年融三门**：初步融合三家门派掌法
- **三十年融十家**：自如切换十家掌意
- **六十年融百家**：百家掌法信手拈来
- **百年归一**：万法归于一掌
