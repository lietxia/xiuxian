# 神拳通神

## 基本信息
- **功法名称**：神拳通神
- **品级**：六阶（神级）
- **类型**：武技功法
- **适用境界**：炼虚期
- **修习难度**：★★★★★

## 功法介绍

神拳通神是一部传奇色彩极浓的功法——它的创造者"拳痴"武无敌并非天赋异禀的修士，而是一个资质平平的凡人。武无敌年少时被测出无灵根，被宗门拒之门外。但他不服天命，立誓"以拳通神、以武证道"。之后三百年，他以凡人之躯日夜苦练拳法，将基础拳法练了百万遍、开山拳练了十万遍、大道拳练了万遍，硬生生以拳入道。在四百八十岁那年，武无敌打出贯通天地的一拳，以武破碎虚空飞升。他飞升前将毕生领悟刻于石壁之上，后人将其整理为这部《神拳通神》。此功法的核心理念是——灵根不是一切，意志才是最强的道。

## 功法特点

**优点：**
- 无灵根者亦可修炼至圆满，是凡人逆袭的最佳功法
- 每一拳都蕴含创作者的武道意志，越战越勇
- 不依赖灵气，以气血和意志为动力
- 修炼到极致可以拳意沟通天道，以武证道

**缺点：**
- 修炼过程极为艰苦，需要远超常人的毅力
- 前期进境缓慢，积累期漫长
- 无灵根者修炼需花费有灵根者三倍以上的时间
- 对炼体要求极高，体魄不够者强行修炼会身体崩溃

## 功法等级

**入门**：拳意初成，意念加持拳劲，威力提升三成

**小成**：拳意化形，出拳时有武者虚影相随

**大成**：拳通天地，一拳可引动天地灵气共鸣

**圆满**：神拳无敌，一拳出有破碎虚空之威

## 功法招式

1. **问心式**：以拳问心，坚定武道意志，起手蓄势
2. **破障式**：一拳破万法，以意志粉碎一切阻碍
3. **忘我式**：忘却生死荣辱，拳法进入天人合一之境
4. **通神式**：引天地之力加持拳劲，神威凛凛
5. **不灭式**：战意不灭则拳劲不绝，越战越强
6. **碎虚式**：以拳意锁定空间，一拳打碎虚空
7. **证道式**：终极一拳，燃烧全部意志与气血，以武证道

## 修炼条件

- **前置功法**：基础拳法圆满、开山拳大成
- **体质要求**：最严格——最好是"无灵根"或废灵根
- **特殊要求**：须有大毅力、大智慧、大勇气
- **修炼地点**：无限制，任何地方皆可修炼
- **所需资源**：不需要灵石丹药，只需要对手与战斗

## 使用限制/副作用

- 无灵根者每次突破需经历肉身的极限痛苦
- 每一次被击败都会对武道意志造成重创
- 此功法不可传承，非自悟者无法发挥十分之一的威力
- 修炼此功法者一生不能放弃，放弃则心血来潮走火入魔

## 相关典故

武无敌飞升时，整个修真界都看到了那震撼的一幕——一个白发苍苍的老者站在山巅，对着天空缓缓打出最后一拳。那一拳击碎了虚空，打开了通往仙界的通道。天地间回荡着他的声音："我武无敌，无灵根、无背景、无资源，唯有一颗拳拳之心。三百年苦练，今日以拳证道！"直至今日，无数无灵根的少年仍以武无敌为榜样，以神拳通神为目标。

## 修炼进度

- **十年入门**：意志初凝，拳意小成（无灵根需十五年）
- **三十年小成**：拳意化形，武神虚影相随
- **六十年大成**：拳通天地，引灵气共鸣
- **百年圆满**：神拳破碎虚空，以武证道飞升
