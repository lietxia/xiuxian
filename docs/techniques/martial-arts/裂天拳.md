# 裂天拳

## 基本信息
- **功法名称**：裂天拳
- **品级**：四阶（天级）
- **类型**：武技功法
- **适用境界**：元婴期
- **修习难度**：★★★★☆

## 功法介绍

裂天拳源自上古凶兽"裂天兕"的血脉神通。裂天兕乃是远古时期纵横九州的顶级凶兽，以一对能够撕裂天空的巨角闻名。兕本为独角犀牛状，但裂天兕的双角却呈拳状，一撞之下连天穹都可撕裂。人族体修大能"武烈"在猎杀一头裂天兕后，以秘法将妖兽血脉中的神通符文剥离，融合人族拳理，创出了这部旨在撕裂一切的霸道拳法。裂天拳的核心理念是"无不可破之物"，以旋转撕裂之力破坏一切。

## 功法特点

**优点：**
- 旋转撕裂劲力可破开绝大多数防御
- 对能量护盾的破坏效果尤佳，可将护盾撕开缺口
- 拳劲具有极强的穿透力，可隔物伤敌
- 出拳带尖啸声，可干扰敌人心神

**缺点：**
- 刚猛有余而柔韧不足，遇太极类借力打力功法则被克制
- 撕扯之力对自身手臂经脉亦有损伤
- 每次出拳需旋转腰身蓄力，出拳轨迹易被预判
- 消耗巨大，元婴期修士最多连续出十拳

## 功法等级

**入门**：拳劲带旋转之力，可撕裂精铁铠甲

**小成**：一拳可将中品防御法器撕成碎片，拳风可裂石

**大成**：拳劲破空形成真空旋涡，可撕碎上品灵器

**圆满**：一记裂天拳可撕裂空间，短暂形成空间裂缝

## 功法招式

1. **撕风式**：扭腰出拳，拳劲旋转如钻，破风而行
2. **裂甲式**：专攻敌人防御法宝，以旋转劲撕裂护甲
3. **破罡式**：拳劲穿透护体罡气后旋转扩散，撕裂内部
4. **旋龙式**：双拳交替旋转出击，如双龙绞杀，连续撕裂
5. **碎空式**：全力一拳，拳劲在空中形成肉眼可见的螺旋波纹
6. **裂天式**：跃起后自上而下出拳，拳劲撕裂大地
7. **大裂天式**：燃烧精血，一拳打出空间裂缝，终极杀招

## 修炼条件

- **前置功法**：开山拳大成或金属性拳法圆满
- **体质要求**：金灵根三品以上，经脉宽大坚韧者
- **灵根要求**：金灵根最佳，火金双灵根次之
- **修炼地点**：风穴或罡风层中修炼，借风之力感悟撕裂之意
- **所需资源**：裂天兕精血一滴（必备）、万年玄铁拳套

## 使用限制/副作用

- 旋转劲对手臂筋骨扭转极大，每月须以灵药浸泡手臂
- 裂天式大裂天式有撕裂空间的风险，控制不当会引来空间乱流
- 过度使用会导致手臂经脉永久性扭转错位
- 需配合顶级炼体功法强化双臂，否则骨骼承受不住旋转力

## 相关典故

武烈猎杀裂天兕的过程本身就是一段传奇。那头裂天兕身长十丈，独角一顶便可撕裂山岳。武烈与之搏杀七七四十九天，从南域打到北域，跨越三州之地。最后武烈以自身右臂为代价，将裂天兕的双角折断。后以此双角炼制出两柄神兵，又以兕血悟出裂天拳。后人评价："兕可裂天，武烈裂兕，拳名裂天，实至名归。"

## 修炼进度

- **一年入门**：拳带旋转劲，撕裂精铁铠甲
- **三年小成**：一拳碎中品防御法器
- **七年大成**：真空旋涡现，上品灵器亦碎
- **十二年圆满**：空间裂缝隐现，可威胁化神修士
