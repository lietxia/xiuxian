# 天拳降世

## 基本信息
- **功法名称**：天拳降世
- **品级**：八阶（帝级）
- **类型**：武技功法
- **适用境界**：大乘期
- **修习难度**：★★★★★

## 功法介绍

天拳降世乃是天界"战神"刑天被贬谪人间后所创的无上拳法。刑天本是天帝座下第一战将，因在天庭演武时失手打死了一位星君，被天帝贬下凡间历劫三千年。刑天在人间化为一个普通铁匠，每日打铁铸剑，将一身神力压抑在平凡的肉身之中。他花了千年时间领悟到——真正的力量不在于神体，而在于对力量的掌控。他将在天庭学到的神级战技与凡间打铁的手法融合，创造出这部以"重"为核心的天拳降世。此拳法看似缓慢，实则每一拳都重如星辰，一拳之下万物臣服。

## 功法特点

**优点：**
- 一拳之重堪比星辰，力大无穷者也无法正面接下
- 气势磅礴，出拳时犹如天神下凡，震慑众生
- 以拙破巧，再精妙的技巧在绝对的力量面前都不堪一击
- 拳势自成领域，范围内重力增加十倍

**缺点：**
- 出拳速度较慢，容易被敏捷型对手躲避
- 消耗极为恐怖，大乘期最多出三拳
- 对修炼者的肉身强度要求达到变态级别
- 施展时自身也承受同等重力压迫

## 功法等级

**入门**：一拳打出有如山压，重力增加三倍

**小成**：拳出天象变，乌云压顶，重力五倍

**大成**：拳如星辰坠地，重力十倍，百丈内一切压为齑粉

**圆满**：一拳开天，可打碎空间通道

## 功法招式

1. **镇山式**：自上而下的压拳，犹如山岳镇压
2. **覆海式**：横拳扫出，犹如海啸扑面
3. **破天式**：冲天一拳，可击碎九天罡风
4. **降世式**：跃起后以拳下击，如天神自九天而降
5. **压狱式**：拳劲向下扩散，范围内的敌人被重力压制无法动弹
6. **碎星式**：凝聚全部力量于一拳，可打碎小型星辰
7. **天怒式**：引动天象之力，雷霆风暴随拳而至

## 修炼条件

- **前置功法**：任意七阶以上拳法圆满
- **体质要求**：极品炼体修士，肉身强度至少达到极品灵器级别
- **灵根要求**：土灵根或金灵根
- **修炼地点**：重力异常之地或星核深处
- **所需资源**：星辰铁、重力石、万年地髓

## 使用限制/副作用

- 肉身体魄不够强行施展会导致肉身崩溃
- 每施展一次碎星式需休养一月
- 修炼此功法的修士体重会不断增加
- 出拳时重力场不分敌我，队友也会被压制

## 相关典故

刑天在人间时，一名大乘期妖帝前来挑战。那妖帝速度快如闪电，自诩同阶无敌。刑天只是缓缓举起右拳。妖帝嘲笑："这么慢的拳头，连我的影子都打不到。"说罢化作一道流光冲向刑天。刑天看也不看，一拳砸下——降世式。那一拳落下的瞬间，方圆千丈内的空气仿佛凝固了，妖帝的速度骤降百倍，如同陷入泥沼。刑天的拳头精准地砸在妖帝头顶，妖帝被一拳从天空砸入地下百丈，在地底形成一个巨大的拳印深坑。妖帝败后心服口服，尊刑天为"拳帝"。

## 修炼进度

- **十年入门**：三倍重力拳
- **三十年小成**：天象变色，五倍重力
- **六十年大成**：十倍重力域
- **百年圆满**：一拳开天
