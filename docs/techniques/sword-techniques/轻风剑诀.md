# 轻风剑诀

## 基本信息
- **功法名称**：轻风剑诀
- **品级**：二阶（玄级）
- **类型**：剑法功法
- **适用境界**：筑基期
- **修习难度**：★★☆☆☆

## 功法介绍

轻风剑诀源自东海风灵岛的"轻风仙子"柳如烟。柳如烟天生风灵体，对风的感知远超常人。她年少时曾在东海悬崖边闭关十二年，每日感受海风的千变万化——时而温柔如母亲的手，时而狂暴如怒龙咆哮，时而轻柔如羽毛拂面，时而凛冽如刀割肌肤。

她将风的十二种形态融入剑法之中，创出了这套以轻灵迅捷见长的剑诀。轻风剑诀讲究"剑随心动、身随意走"，出剑时无声无息，如清风拂面，待敌人察觉时剑锋已及咽喉。柳如烟以此剑法独步东海三百年，从未有人能在速度上胜过她。

## 功法特点

**优点：**
- 出剑速度极快，同阶中鲜有能及者
- 身法轻盈飘逸，可借风力大幅提升移动速度
- 剑招消耗真气极少，可持续作战
- 风声、剑声极小，适合潜行刺杀

**缺点：**
- 威力偏弱，正面硬拼不占优势
- 对体魄要求较高，需要极强的心肺功能
- 害怕封闭的无风环境
- 剑招过于轻盈，难以破开重甲或护体真气

## 功法等级

**风起青萍**：能在微风中感知气流变化，出剑时借风势增加速度

**御风而行**：可借助风力让身法更加迅捷，战斗时如风中柳絮般飘忽不定

**风过无痕**：出剑不留痕迹，敌人只觉一阵风吹过便已中剑，伤口微不可察

**风雷相生**：轻极生刚，快极生猛，在极致速度下可斩出风雷之声，威力倍增

## 功法招式

1. **微风拂面**：看似随意的一剑，剑身几乎不带动空气流动，无声无息地刺向敌人面门。

2. **清风徐来**：连续三剑呈扇形展开，如同清风徐来般轻柔，实则封锁了敌人所有闪避路线。

3. **旋风斩**：以身带剑旋转一周，剑势如旋风般席卷四周，是突围和反包围的妙招。

4. **风卷残云**：剑尖急速抖动幻化出数十道剑影，如狂风席卷残云般将敌人笼罩其中。

5. **轻风托叶**：以剑身的侧面轻轻拍击敌人的剑身，四两拨千斤，借力打力卸掉对方的攻势。

6. **风过苍穹**：剑势冲天而起，身形也随之跃起，居高临下的一记轻斩，如风过天空不着痕迹。

## 修炼条件

**前置功法**：基础剑诀大成，具备一定的速度和身法基础

**灵根要求**：风属性变异灵根最佳，木属性灵根次之

**修炼地点**：海边悬崖、高山风口、开阔平原等风大的地方

**所需资源**：极轻的软剑，重量不超过两斤，剑身薄而韧

## 使用限制/副作用

- 在无风或密闭环境中实力下降三成
- 因追求速度而牺牲力量，面对重甲或护体真气强大的对手极其吃力
- 长期修炼此剑法可能导致根基不稳，需辅以力量训练
- 过度追求轻灵容易产生"轻敌冒进"的战斗习惯

## 相关典故

**柳如烟的羽毛剑**：柳如烟的本命飞剑名为"青羽"，乃是一根青色羽毛所化，轻若鸿毛却可斩断玄铁。相传有一日她在海边舞剑，一只海鸥的羽毛被风吹落，恰好落在她的剑刃上竟被切成两半。柳如烟由此悟出了"轻若羽毛亦可杀人"的道理。

## 修炼进度

**乘风期**：掌握以气感风的基本功，能在有风的环境下借力加速，约需半年

**御风期**：身法可与风同步，在风中战斗如鱼得水，速度提升五成，约需一到二年

**化风期**：出剑如同风的一部分，对手无法通过风声判断攻击方向，约需三到五年

**无风期**：即便在无风环境中也能凭空生出风势，以自身剑意带动气流，已达大成之境
