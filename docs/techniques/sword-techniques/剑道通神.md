# 剑道通神

## 基本信息
- **功法名称**：剑道通神
- **品级**：七阶（圣级）
- **类型**：剑法功法
- **适用境界**：合体期
- **修习难度**：★★★★★

## 功法介绍

剑道通神由"通神剑尊"段天涯所创。段天涯出生于一个没落的剑道世家，自幼被断言"剑道天赋平庸、终生无望高阶"。但他偏偏不信命，以凡人资质硬是凭着一股执念修炼到了合体期。在这个过程中他发现了一件事——所谓的天赋不过是对"人剑合一"的感知能力，而更高的境界是"以神御剑"——以神识和意念直接操控剑，不再经过肉身这个中介。

他创出了剑道通神的核心法门：将元神与剑彻底融合，让剑成为元神的延伸。修习者不再需要用手握剑，一念之间飞剑便可跨越千里取人性命。段天涯的元神出窍后甚至可以直接附在剑上飞行，以剑为身周游天地。这已超越了普通的剑法范畴，进入了"以神御剑、以剑通神"的道境。

## 功法特点

**优点：**
- 元神御剑，范围可达千里之外
- 肉身与剑分离，极大降低了肉身的风险
- 剑速极快——意念的速度远超肉身反应
- 可同时操控多柄飞剑从不同角度攻击

**缺点：**
- 元神出窍御剑时肉身毫无防备
- 若飞剑被毁，附着在上面的元神会受重创
- 需要极为强大的神识和元神修为
- 初期修炼时元神离体极容易迷失

## 功法等级

**神与剑合**：元神开始与剑融合，初次体验到以神御剑的感觉

**元神御剑**：可在百丈范围内以元神操控飞剑攻击，无需用手持剑

**千里飞剑**：飞剑出鞘后可飞行千里取敌首级，元神通过剑感知远处的情况

**剑即神体**：元神可直接以剑为载体出游，剑在人在、剑毁人亡

## 功法招式

1. **飞剑取首**：最简单的应用——飞剑出鞘化作一道流光，千里之外取敌首级。

2. **分光化影**：一剑化为数道剑光，从不同方向同时攻击，敌人难以判断真身。

3. **神游天外**：元神出窍附在飞剑上，以剑为身周游天地，一日可行万里。

4. **万剑穿心**：以神识同时操控多柄飞剑，形成密集的剑雨覆盖目标区域。

5. **剑心领域**：以自身为中心展开神识领域，领域内一切皆可为剑——草木竹石皆在神识操控之下飞起攻击。

6. **通神一剑**：元神与剑完全融合，人与剑化为一道贯穿天地的神光——在这一剑面前，任何防御都如同虚设。

## 修炼条件

**前置功法**：需要具备化神期以上的元神修为，且神识强度远超同阶

**灵根要求**：以神识强大的精神属性变异灵根为佳，剑道天赋反而不那么重要

**修炼地点**：神识安全的环境——最好在有护山大阵保护的闭关室中

**所需资源**：需要与本命元神绑定的一柄本命飞剑，以天外陨铁锻造最佳

## 使用限制/副作用

- 元神出窍御剑时肉身若被毁则万劫不复
- 飞剑与元神绑定，若剑受损则元神受损，剑毁则人亡
- 过度使用元神御剑会导致神识疲劳，严重时会神识崩溃
- 若被更高阶的修士捕捉到飞剑，可将元神禁锢在剑中

## 相关典故

**段天涯的万里追魂**：段天涯的仇家为了躲避他的追杀，逃到了海外一座被上古禁制保护的岛屿上。段天涯站在大陆的东海岸，闭目感应了一炷香的时间，然后飞剑出鞘。飞剑穿过万里海域，穿透了岛屿的九重禁制，在仇家的眉心留下了一个血洞，然后又飞回了段天涯的手中。全程不过盏茶时间。

## 修炼进度

**合剑期**：元神开始与剑建立联系，能以微弱的神识操控飞剑在空中做简单的移动，约需十到二十年

**御剑期**：神识可操控飞剑在一里范围内自由攻击，剑速快如闪电，约需三十到五十年

**神游期**：元神可附剑出游，以剑为身周游天地，神识覆盖范围可达百里，约需百年

**通神期**：一念之间飞剑可至千里之外取人性命，剑心领域展开后万物皆可为剑
