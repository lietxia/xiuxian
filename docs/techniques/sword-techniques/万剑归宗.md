# 万剑归宗

## 基本信息
- **功法名称**：万剑归宗
- **品级**：六阶（神级）
- **类型**：剑法功法
- **适用境界**：炼虚期
- **修习难度**：★★★★★

## 功法介绍

万剑归宗乃万剑山庄第二代庄主——"剑藏"司徒无量所创。司徒无量一生痴迷于收集天下名剑，万剑山庄藏剑楼中收藏了九千九百九十九柄名剑，只差一柄便可满万。为了寻得最后一柄剑，司徒无量走遍天下，与各路剑修交手，观摩了上万种剑法。

他从万剑中找到了一个共同的规律——天下剑法万变不离其宗，无论外表多么不同，剑道的本源只有一个。他将这一领悟化为万剑归宗大法：以自身剑心为枢纽，御使万剑齐飞，如同号令万剑的君王。司徒无量创出此剑法的那一日，万剑山庄的九千九百九十九柄剑同时出鞘，在天空中排列成剑阵，方圆千里皆可看见。他最终没有找到最后一柄剑——因为他自己化为了那第一万柄剑。

## 功法特点

**优点：**
- 可同时御使多柄飞剑，数量越多威力越大
- 万剑大阵攻防一体，几乎无懈可击
- 对低于自身境界的敌人有碾压性的优势
- 每一柄剑都可以独立攻击不同目标

**缺点：**
- 修炼成本极高，需要收集大量名剑
- 神识消耗巨大，御剑数量受神识强度限制
- 若剑被毁，会对主人的神识造成反噬
- 对剑的品级有要求，凡铁剑无法承受剑意

## 功法等级

**百剑齐鸣**：可同时御使百柄飞剑，初步形成剑阵，百剑齐飞蔚为壮观

**千剑如雨**：可御使千柄飞剑，剑如雨落覆盖战场，每一剑皆有独立的攻击轨迹

**万剑归宗**：万剑齐出遮天蔽日，剑阵流转如同一个完整的剑道世界

**剑道之主**：自身化为万剑之源，一念之间万剑生灭，天地万物皆可为剑

## 功法招式

1. **万剑齐发**：所有飞剑同时射出，如同暴雨般覆盖整个战场，不留任何死角。

2. **剑阵·周天**：万剑按照周天星斗排列，形成一个巨大的困杀剑阵，入阵者如同陷入剑之宇宙。

3. **万剑归一**：万剑聚合成一柄巨剑，集中所有剑的威力于一击，可越阶斩杀强敌。

4. **剑海沉浮**：万剑如海潮般层层叠叠涌向敌人，一波未平一波又起，直至将敌人淹没。

5. **剑冢囚笼**：以万剑构筑一个封闭的剑之牢笼，笼中万剑穿梭形成死亡空间。

6. **万物皆剑**：达到最高境界后，草木竹石皆可为剑，不再需要实体飞剑。

## 修炼条件

**前置功法**：需要至少掌握三种不同属性的五阶剑法，且神识强度需达标

**灵根要求**：以金属性灵根最佳（金主杀伐、号令兵器），剑道天赋为主

**修炼地点**：万剑山庄的藏剑楼是最佳修炼场所，其次为剑意浓厚的古战场

**所需资源**：需要至少百柄以上品级不低于四阶的灵剑，数量越多越好

## 使用限制/副作用

- 飞剑被毁会反噬神识，可能导致神识永久性损伤
- 御剑数量过多时若遇神识攻击，可能被敌人趁虚而入
- 万剑大阵一旦展开消耗极大，长时间维持会力竭而亡
- 收集万剑需要极大的财力和机缘

## 相关典故

**藏剑楼的万剑之约**：司徒无量临终前立下规矩——万剑山庄的每一任庄主都要寻找一柄足以与历代名剑并列的绝世好剑，放入藏剑楼第九层。千年过去了，藏剑楼中已有九千九百九十九柄剑，每一柄都有一段传奇故事。传闻当藏剑楼满万剑之日，便是万剑归宗重现人间之时。

## 修炼进度

**识剑期**：熟悉每一柄剑的特性，与剑建立初步的灵性联系，约需十年

**御剑期**：能够同时御使百剑，初步形成剑阵攻防一体，约需二十到五十年

**剑阵期**：可御千剑布置周天大阵，一人之力可敌一宗，约需百年

**归宗期**：万剑随心而动，意念所至万剑相随，天下万剑皆为其所用
