# 天剑诀

## 基本信息
- **功法名称**：天剑诀
- **品级**：五阶（仙级）
- **类型**：剑法功法
- **适用境界**：化神期
- **修习难度**：★★★★★

## 功法介绍

天剑诀出自上古剑道圣地——天剑宫。天剑宫开派祖师"天剑真人"于三千年前游历域外星空时，在一块天外陨石上发现了数十道深不见底的剑痕。这些剑痕并非人为雕刻，而是在陨石穿越大气层时，被天道之力自然铭刻而成。

天剑真人在陨石前参悟三十年，将这些天然剑痕中蕴含的天地至理融入剑道，创出了这套引动天道之力为己用的天剑诀。天剑诀的核心在于"代天行剑"——修习者以自身剑心沟通天地意志，让天道之力加持于剑身之上，每一剑都带着天地之威。天剑宫凭借此剑诀成为天下剑修圣地，天剑真人也因此飞升上界。

## 功法特点

**优点：**
- 引动天道之力加持，每一剑都有天地之威
- 对低于施剑者境界的敌人有天然的威压效果
- 剑气中蕴含天道法则，克制一切逆天邪术
- 可借用天地灵气续航，持久战能力强

**缺点：**
- 对剑心要求极高，心性不正者无法引动天道
- 在禁法之地或天道不全的空间中无法施展
- 修炼过程需与天地共鸣，对环境要求苛刻
- 有违天道之事不可为，否则会被天道反噬

## 功法等级

**天道共鸣**：剑心与天地初步沟通，出剑时可引动微弱的天地灵气加持

**代天行剑**：剑势引动天地异象，剑出则风云变色，一剑之威如同天罚

**天人合一**：身、剑、天三者合一，每招每式皆是天道意志的体现

**以己代天**：自身化为天道化身，言出法随，剑出天从，堪比真正的仙人之威

## 功法招式

1. **天道无情**：横剑一挥，剑气不带任何感情色彩，如同天道运转般冰冷无情，精准致命。

2. **天网恢恢**：剑尖画出一个巨大的天道法网，将敌人笼罩其中，法网中的天道法则会压制敌人的所有能力。

3. **替天行道**：一剑指出，引动天道之力锁定敌人，避无可避、挡无可挡，如同命中注定般必中。

4. **天罚之剑**：沟通天道降下天罚，一道巨大的光剑从天而降，携带天劫之威轰击敌人。

5. **天命难违**：以剑沟通命运法则，斩出一剑可短暂预知并改变未来三息内的因果走向。

6. **天剑开天**：终极一式——引动天道本源之力，一剑斩开天地间的任何屏障，包括空间壁垒和法则禁制。

## 修炼条件

**前置功法**：需修习过至少一种五阶以上的剑法，剑道造诣需达到化神期水准

**灵根要求**：以天灵根最佳，任何一种单属性天灵根皆可，杂灵根无法感应天道

**修炼地点**：天道法则最为清晰之地——如天剑宫的剑道崖、上古飞升台、天道碑林等

**所需资源**：以天道玉石锻造的本命飞剑，可与天道共鸣

## 使用限制/副作用

- 心性若不正，天道反噬会在瞬间将修习者抹杀
- 每次引动天道之力后会有一段天道沉寂期，期间无法再次沟通
- 此剑诀不可用于违背自身道心的行为，否则剑心崩碎
- 天剑诀的修炼者会受到天道的关注，行事需谨慎

## 相关典故

**陨石上的剑痕**：天剑宫的天外陨石至今仍供奉在宗门圣地中。据说石头上的剑痕共有九十九道，天剑真人当年只参悟了七十二道便已飞升。天剑宫历代宫主都会去参悟剩余的剑痕，据说每参悟一道便可创出一招新的天剑式。至今已参悟到第九十七道，最后两道始终无人能解。

## 修炼进度

**感天期**：能在练剑时感受到天地意志的回应，剑招得到天地灵气的自然加持，约需十年

**通天期**：出剑可引动风云变色，一剑引动方圆百丈的天地灵气为己用，约需三十到五十年

**代天期**：可代天行罚，一剑之威堪比真正的天劫，对魔修有绝对的压制力，约需百年

**化天期**：以身为天、以剑为道，自身即是天道化身，一剑可断因果、改命运
