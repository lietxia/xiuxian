# 流云剑诀

## 基本信息
- **功法名称**：流云剑诀
- **品级**：二阶（玄级）
- **类型**：剑法功法
- **适用境界**：筑基期
- **修习难度**：★★☆☆☆

## 功法介绍

流云剑诀由云梦泽的散修奇人——"流云剑仙"云中鹤所创。云中鹤少年时不过是个在云梦泽打渔的渔夫，一日在湖上泛舟时，偶然看到天边流云变幻、聚散无常，心中忽然有所触动。他弃舟登岸，以船桨为剑，模仿云的气象万千——时而如白云舒卷般轻柔，时而如乌云压顶般沉重，时而如朝霞破晓般绚烂，时而如残阳如血般苍凉。

他在云梦泽畔观云三十载，终创出这套以云为魂、以水为骨的流云剑诀。此剑法如行云流水一般连绵不绝，一旦展开便如同云海翻涌，让敌人陷入无穷无尽的剑势之中无法脱身。云中鹤后来凭借此剑法纵横修真界三百载，被誉为"云中之仙"。

## 功法特点

**优点：**
- 剑势连绵不绝，后招叠前招，令敌人防不胜防
- 身法飘逸灵动，配合轻功可大幅提升闪避能力
- 剑招变化无穷，可根据战况灵活变通
- 对水属性灵根修士有额外加成

**缺点：**
- 缺乏一击必杀的爆发招式
- 需要较大的战斗空间才能发挥全部威力
- 修炼需要"观云悟道"的天赋悟性
- 在封闭空间（洞穴、密室内）威力大打折扣

## 功法等级

**云影初现**：掌握了基本剑式的连贯变化，出剑时已有流水般的流畅感

**行云流水**：九式剑招环环相扣，一气呵成，视觉上已呈现流云般的连绵美感

**云海翻腾**：剑势展开如云海翻涌，身法飘忽不定，对手难以捕捉攻击方向

**云卷云舒**：收放自如，进攻时如乌云压顶般猛烈，防守时如白云轻拂般从容

## 功法招式

1. **白云出岫**：剑势轻柔展开，剑尖微颤如白云从山间缓缓飘出，看似漫不经心，实则暗藏杀机。

2. **流云断水**：手腕急转，剑身在空中划出S形弧线，如流云掠过水面，可截断敌人的攻势。

3. **云卷风残**：身形旋转带动剑身画圆，剑势如漩涡般将周围的一切卷入其中，适合以寡敌众。

4. **飞云逐月**：身剑合一向前突刺，剑势迅疾如飞云追月，是流云剑诀中速度最快的杀招。

5. **云海幻影**：剑尖幻化出数道剑影，如同云海中的海市蜃楼，虚虚实实令敌人无法判断真身所在。

6. **残云归西**：收剑式也是杀招——剑势由极动转为极静，在敌人以为攻击结束时突然一剑封喉。

## 修炼条件

**前置功法**：基础剑诀或入门剑式，需具备一定的剑法基础

**灵根要求**：水属性灵根或变异冰灵根最佳，风属性灵根亦可

**修炼地点**：云梦泽、大江大湖之畔，或常年有云雾缭绕的山顶

**所需资源**：一柄柔韧性好的软剑，三尺左右，重约两斤半

## 使用限制/副作用

- 此剑法需要较大的闪转腾挪空间，在狭窄场地中威力减半
- 连续施展超过一炷香时间会大量消耗真气体力
- 对悟性要求较高，死记硬背招式者难有大成
- 若遇快剑流高手，容易被以快破巧

## 相关典故

**云中鹤悟道**：云中鹤曾为领悟"云的重压感"，在暴雨天站在瀑布下练剑整整一年，让万吨水流的冲击力融入剑势中。出关之日，他一剑劈开了云梦泽中的一座小岛，水面分开三息才重新合拢。

## 修炼进度

**初窥门径**：九式剑招能连贯使出，身法步伐初步配合，约需半年

**渐入佳境**：剑势不再断断续续，行剑如流水，能在对战中持续施压，约需一至二年

**炉火纯青**：云海剑势展开后可同时困住三到五名同阶对手，约需三至五年

**出神入化**：剑势收发自如，可变幻九种不同形态的云势，接近当年云中鹤的境界
