# 雷霆剑诀

## 基本信息
- **功法名称**：雷霆剑诀
- **品级**：四阶（天级）（天级）
- **类型**：剑法功法
- **适用境界**：元婴期
- **修习难度**：★★★★☆

## 功法介绍

雷霆剑诀由上古雷修大宗——"九天雷帝"雷震子所创。雷震子本是金丹期的普通雷修，有一次渡金丹劫时，天雷过于猛烈，竟然将他的金丹劈出了一道裂纹。但他并未陨落，反而在生死之际从天雷中感悟到了一丝雷霆的本源真意。

从此他痴迷于追逐天雷，每逢雷雨天气便飞上高空，以肉身承受天雷轰击，在雷击中感悟雷霆的律动。他在九重天上的雷池中闭关千年，将雷霆的毁灭与新生之力融入剑道，创出了这雷霆剑诀。此剑法以雷霆的速度和毁灭力著称，出剑时如电光石火，剑气中蕴含着天劫般的毁灭意志。雷震子后来以雷霆剑诀度过了九重天劫，飞升上界，被后世尊为"九天雷帝"。

## 功法特点

**优点：**
- 速度极快，出剑如闪电般肉眼难以捕捉
- 破坏力惊人，对邪祟和魔道有极强的克制效果
- 剑气附带的雷霆之威可麻痹敌人
- 引动天雷时威力可跨越一个大境界对敌

**缺点：**
- 极难控制，容易误伤或失控
- 引天雷入体时极度危险，稍有不慎便灰飞烟灭
- 消耗巨大，尤其是引天雷时可能耗尽所有真气
- 对雷灵根资质要求极高，一般人无法修习

## 功法等级

**电光初闪**：剑身附着银色电弧，剑速提升三成，击中敌人可造成轻微的麻痹

**雷蛇缠身**：剑气化为雷蛇缠绕攻击，击中后可令敌人全身麻痹数息之久

**雷劫降世**：引动天雷入剑，每一剑都如同天劫降临般带着毁灭气息

**万雷之主**：以自身为雷源，一念之间可召万雷齐发，如同掌控雷霆的君王

## 功法招式

1. **电光火石**：以雷霆般的速度拔剑、出剑、收剑，整个过程快到对手连剑光都看不见便已中招。

2. **五雷正法**：剑尖凝聚五道不同属性的天雷，依次轰向敌人，第一道破防、第二道伤体、第三道损神、第四道断魂、第五道灭迹。

3. **狂雷天牢**：以剑气构筑一个由雷电组成的牢笼，将敌人困在其中持续承受雷电灼烧。

4. **雷霆万钧**：双手握剑举过头顶，引动天雷灌注剑身，然后以万钧之势劈下，威力可劈开山岳。

5. **雷神降世**：将雷霆之力遍布全身，以身为剑撞向敌人，所过之处一切化为焦土。

6. **九天雷动**：引九道天雷落下融入剑中，人与剑化为一道贯穿天地的雷柱，将范围内的所有敌人化为灰烬。

## 修炼条件

**前置功法**：惊雷剑诀大成或有同等级的雷系功法基础

**灵根要求**：雷属性变异灵根（必须），雷灵根纯度需在七成以上

**修炼地点**：九天雷池、雷暴频发之地、高山之巅等引雷容易之处

**所需资源**：以天外雷陨铁锻造的灵剑，可承受天雷不毁

## 使用限制/副作用

- 引天雷入体时若经脉强度不足，会被雷霆之力炸成焦炭
- 每次引天雷后身体会极度虚弱，需休养数日
- 雷灵根纯度不足者强行修炼会导致灵根崩溃
- 雷霆剑诀杀气太重，长期修炼会影响心性变得暴戾

## 相关典故

**雷震子的九道疤痕**：雷震子身上有九道触目惊心的疤痕，每一道都是被天雷劈出来的。第一道在他金丹期，最后一道在他大乘期。他说："每一道疤痕都是一次顿悟，我身上的伤痕就是我的剑谱。"他的弟子们曾说，雷震子每次出剑时，身上的疤痕会发出雷光。

## 修炼进度

**感雷期**：能以剑引动空中的雷电之力，剑身附着电弧，约需一年

**御雷期**：可自主控制和引导雷电的方向和强度，在雷雨天战力倍增，约需三到五年

**化雷期**：可将自身部分化为雷电，实现短距离的雷遁位移，约需五到十年

**掌雷期**：无需引雷，自身便是雷霆之源，举手投足皆有天雷相随，可驾驭九天神雷
