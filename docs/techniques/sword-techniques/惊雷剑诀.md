# 惊雷剑诀

## 基本信息
- **功法名称**：惊雷剑诀
- **品级**：三阶（地级）
- **类型**：剑法功法
- **适用境界**：金丹期
- **修习难度**：★★★☆☆

## 功法介绍

惊雷剑诀源自佛门雷音寺的护法神功。雷音寺第三代伏魔金刚——"雷吼"慧明禅师，天生暴脾气与佛门清规格格不入，但他却有极高的雷法天赋。慧明禅师在一次闭关中，听到山门外雷鸣震天，忽然领悟到——雷霆本身就是天地间最强的伏魔之力，何不将雷音融入剑法之中？

他穷尽三十年光阴，将佛门狮子吼、雷音禅唱与雷法符箓融为一体，创出了这套刚猛无铸的惊雷剑诀。出剑时伴随雷鸣之音，不仅以剑气伤人，更以雷音震慑心魄。慧明禅师后来凭此剑法镇压了魔道七宗的三次进攻，被尊为"雷音降魔尊者"。

## 功法特点

**优点：**
- 爆发力极强，瞬间伤害在金丹期功法中名列前茅
- 雷音震荡可破邪祟、震碎阴魂鬼物
- 剑势刚猛霸道，气势上先声夺人
- 蕴含雷法奥义，对魔道功法有克制效果

**缺点：**
- 消耗巨大，全力出剑三到五次便会真气枯竭
- 雷音震耳，不分敌我，组队作战时易误伤队友
- 速度较慢，大开大合容易被灵活型对手躲避
- 对水属性灵根修士有天然的属性克制

## 功法等级

**雷音初动**：出剑时能发出轻微的雷鸣声，剑气中带有微弱的雷电之力

**雷光乍现**：剑身泛起银白色雷光，出剑时可见电弧跳跃，攻击附带麻痹效果

**雷动九天**：剑势如同九天惊雷，每一剑都伴随震耳欲聋的雷音，可震慑对手心神

**万雷归宗**：剑气化为万千雷蛇，铺天盖地笼罩战场，每一道雷蛇皆有独立的攻击意识

## 功法招式

1. **春雷惊蛰**：蓄势许久后猛然爆发的一剑，如同春雷炸响惊醒万物，快如闪电直取咽喉。

2. **雷音贯耳**：剑身高速震颤发出刺耳雷音，在击中目标之前先用声波冲击对手的耳膜和神识。

3. **雷霆万钧**：高举长剑引动天雷之力灌注剑身，然后以万钧之势劈下，可一剑劈开山石。

4. **电闪雷鸣**：连续快速斩出七剑，每一剑都伴随一道闪电，形成密集的雷电网笼罩敌人。

5. **五雷轰顶**：以剑尖引动五道天雷从天而降，封锁敌人的五个方位，避无可避。

6. **九天雷动**：引动九道天雷灌注剑身，人与剑化为一道巨大的雷霆光柱直冲云霄，然后以毁天灭地之势落下。

## 修炼条件

**前置功法**：需修习过基础雷法或金雷属性功法，体内有雷属性真气基础

**灵根要求**：雷属性变异灵根最佳，金属性灵根亦可，火属性灵根次之

**修炼地点**：雷雨天气的山顶最佳，平时可在布置了雷属性聚灵阵的密室中修炼

**所需资源**：雷击木剑或掺有天外陨铁的金属剑，能承受雷电之力不毁

## 使用限制/副作用

- 反噬风险极高，若经脉强度不够，雷属性真气会灼伤经脉
- 每次施展后需要较长时间恢复，连续作战能力差
- 雷音对自身听力也有损伤，长期修炼会导致听力下降
- 雷雨天修炼虽有加成但极易引来真正的天雷，风险极大

## 相关典故

**雷音寺镇魔钟**：慧明禅师晚年将惊雷剑诀的奥义刻在了雷音寺的镇魔钟上。每当魔道来犯，钟声响起时伴随着雷鸣剑意，方圆百里的魔修都会感到神魂刺痛。至今雷音寺的钟声仍然被魔道修士称为"催命梵音"。

## 修炼进度

**感雷期**：学会引动空气中的雷属性灵力附着剑身，能在木桩上留下焦痕，约需半年

**御雷期**：可自主控制雷电之力在剑身上的流转，出剑时附带麻痹效果，约需一到二年

**化雷期**：剑势可引动小天雷，一剑之威堪比小型天劫雷罚，约需三到五年

**雷心境**：心如雷霆而身如止水，能以意御雷不以形拘雷，已达惊雷剑诀最高境界
