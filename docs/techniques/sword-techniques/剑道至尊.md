# 剑道至尊

## 基本信息
- **功法名称**：剑道至尊
- **品级**：八阶（帝级）
- **类型**：剑法功法
- **适用境界**：大乘期
- **修习难度**：★★★★★

## 功法介绍

剑道至尊由上古剑道皇朝的缔造者——"至尊剑帝"轩辕无极所创。轩辕无极以一介剑修之身建立了横跨三界的剑道皇朝，自号"剑道至尊"。他不仅是天下第一剑修，更是剑道的立法者和执行者——他定下了天下剑法的品级标准，裁决了剑道宗门之间的纷争，数千年间无人敢违逆他的意志。

他所创的剑道至尊之法，核心在于一个"统"字——统御万剑、统领天下剑修。此剑法修炼的不是剑术，而是"帝王的胸怀和威仪"。出剑时带着九五之尊的威压，让低阶剑修不由自主地想要跪伏。剑道至尊的剑意中蕴含着"号令天下"的规则之力——不是用剑去战斗，而是用剑去统治。轩辕无极曾以一柄帝剑号令万宗，不服者只需看他一眼便失去了战意。

## 功法特点

**优点：**
- 蕴含帝王威压，对低境界修士有绝对的统治力
- 可号令万剑为己用，非本命剑也可临时操控
- 剑道规则之力可压制和修改小范围内的剑道法则
- 气势磅礴，群战中可以一当万

**缺点：**
- 需要有帝王般的心性和格局，普通人无法修炼
- 若遇同样心高气傲之辈，剑意会互相排斥
- 一旦失去权势和地位，剑心会同步衰败
- 过于依赖气势碾压，对上不吃这套的对手会很难

## 功法等级

**剑中称王**：剑意中已具备王者之气，出剑时有号令群剑的气势，低阶剑的灵性会被压制

**万剑来朝**：一声令下方圆千丈内的剑器都会朝拜，敌人的剑会受到召唤而偏离方向

**统御万道**：不仅能号令剑，还能号令与剑相关的所有法则——剑气、剑意、剑心皆可操控

**至尊无上**：自身即是剑道至高规则，言出法随——说谁的剑不能用，谁的剑就真的不能用

## 功法招式

1. **王剑出鞘**：拔剑的动作本身就带着不容违抗的威严，震慑对手的心神。

2. **号令天下**：剑指前方，身后幻化出万剑虚影，如同帝王检阅军队一般气势恢宏。

3. **君临天下**：以剑画圆，剑气形成一个王座般的存在，端坐其上者俯瞰众生万物。

4. **指鹿为马**：以剑改写局部规则——将对手的剑定义为"非剑"，使对方的剑无法发挥功效。

5. **一言九鼎**：口含天宪——说话的同时剑随声动，言出剑至，一言可定生死。

6. **帝剑·统御万界**：将所有力量凝聚为一道帝皇剑气，所过之处一切剑器皆向其臣服。

## 修炼条件

**前置功法**：需至少掌握三门不同属性的七阶剑法，且具备领袖气质

**灵根要求**：以帝王气运加身的特殊命格为佳，灵根反而是次要条件

**修炼地点**：剑道皇朝的帝宫遗址、万剑朝拜的剑冢圣地

**所需资源**：需要一柄承载过帝王之气的帝剑——历代王朝的镇国神剑为佳

## 使用限制/副作用

- 若失去了霸业或遭受了重大失败，剑心会随之崩溃
- 此剑法对队友也有威压效果，不适合团队作战
- 过于追求"统御"会导致忽视剑道本身的纯粹性
- 若遇上真正不敬天不畏地的狂人，帝皇威压会失效

## 相关典故

**轩辕无极的万剑朝拜**：轩辕无极登基之日，下令天下剑修前来朝拜。有人不服，带着自己的本命剑站在千里之外，拒绝臣服。轩辕无极只是朝着那个方向看了一眼——那人手中的剑便自行飞向了帝都，插在了轩辕无极面前的剑台上。那人惊恐地发现，自己与本命剑的联系竟然被切断了。从此再无人敢违抗剑道至尊的号令。

## 修炼进度

**立威期**：培养帝王心态和威仪，出剑时已有王者之气，约需十年

**驭剑期**：可短暂号令周围的剑器，让对手的剑在战斗中偏离准头，约需三十到五十年

**统御期**：一念之间可令万剑来朝，敌人的本命剑会被强行压制，约需百年

**至尊期**：自身即为剑道最高法则，一言可改剑道规则，万剑皆臣服于脚下
