# 太极剑诀

## 基本信息
- **功法名称**：太极剑诀
- **品级**：五阶（仙级）
- **类型**：剑法功法
- **适用境界**：化神期
- **修习难度**：★★★★★

## 功法介绍

太极剑诀由阴阳道宗的开派祖师——"太极道尊"所创。太极道尊本是一位参悟宇宙至理的哲学家，并非纯粹的剑修。他在观悟天地运行之道时发现，世间万物皆有阴阳两面——刚柔、快慢、进退、生死，相生相克又相互转化。

他将这一哲理化为剑法，创出了以阴阳平衡为核心的太极剑诀。此剑法的精髓不在于杀伐，而在于"调和"——以柔克刚、以静制动、以慢打快、以退为进。太极道尊曾以这一剑法与天下十大剑修交手，不伤一人而胜十人，因为他的剑法根本不是为了伤害对手，而是引导对手的力量走向自我抵消。太极剑诀一出，天下剑道格局为之一变。

## 功法特点

**优点：**
- 以柔克刚，专克刚猛型功法
- 借力打力，对手越强反噬越重
- 真气消耗极少，可持续战斗数日
- 养生效果极佳，可延年益寿

**缺点：**
- 进攻性弱，缺乏一击必杀的手段
- 修炼进度缓慢，讲究水到渠成
- 对悟性要求极高，需要理解阴阳大道
- 面对极速或极诡的攻击时应对困难

## 功法等级

**阴阳初分**：剑势初步分出阴阳变化，可做到刚柔并济，攻守平衡

**四象相生**：在阴阳基础上分化出四象变化，剑招之间可互相转化不留痕迹

**八卦周流**：剑势在八卦方位之间流动，循环往复生生不息，形成完整的剑域

**无极归真**：阴阳融合归于一，有无极而太极、太极而归无的境界，一剑生出万法

## 功法招式

1. **起手式·无极**：剑尖指地，双手自然下垂，全身放松，看似毫无防备却暗藏阴阳变化之机。

2. **太极初开**：双手持剑画出一个完整的圆，剑气形成一个太极图将敌人包裹其中，慢慢绞杀。

3. **四两拨千斤**：以剑身的旋转带动敌人的攻击偏离方向，用最小的力量化解最强的攻击。

4. **阴阳绞杀**：两道剑气一阴一阳交织成螺旋状向前推进，阴阳之力相生相克产生巨大的绞杀力。

5. **八卦游身**：脚踏八卦方位快速游走，每走一位便留下一道剑气，八位走完剑气组成八卦阵困杀敌人。

6. **太极归元**：将所有阴阳剑气收回剑中，凝聚成一团灰蒙蒙的无极剑气——既不是阴也不是阳，而是混沌本源，一剑出则万法归虚。

## 修炼条件

**前置功法**：需具备一定的阴阳道基础修为，或修习过道家经典

**灵根要求**：以阴阳属性变异灵根最佳，其次为水土双灵根（阴阳平衡）

**修炼地点**：日出日落之时的山巅、阴阳交汇的灵脉节点等天地阴阳平衡之处

**所需资源**：以阴阳玄铁锻造的佩剑，剑身黑白分明可承载阴阳二气

## 使用限制/副作用

- 若心性偏激、阴阳失衡者修炼此剑诀反而会走火入魔
- 太极剑诀讲究防守反击，不适合主动进攻的场合
- 对距离控制要求极高，贴身后容易被压制
- 若遇上同样精通阴阳之道的对手，会陷入无尽的缠斗

## 相关典故

**太极道尊的十战**：太极道尊曾与十位化神期剑修约战于天都峰。十位剑修轮番上阵，太极道尊只用了一招——太极图。十位剑修的攻击打在图上都如同泥牛入海，反倒被自己的力道震伤。十人打了一天一夜，太极道尊的太极图越转越快，而十位剑修越来越疲惫。最后十人主动认输，拜太极道尊为师。

## 修炼进度

**入门期**：理解阴阳基本概念，能画出完整的太极剑气图，约需三到五年

**四象期**：分化四象变化，可在战斗中自由转换刚柔快慢，约需十到二十年

**八卦期**：剑势可布设八卦剑阵，一人之力困住数名同阶对手，约需三十到五十年

**无极期**：阴阳合一归于无极，一剑可消融万法，不战而屈人之兵
