# 寒冰剑诀

## 基本信息
- **功法名称**：寒冰剑诀
- **品级**：四阶（天级）（天级）
- **类型**：剑法功法
- **适用境界**：元婴期
- **修习难度**：★★★★☆

## 功法介绍

寒冰剑诀由极北冰原的传奇女修——"冰魄仙子"冷凝霜所创。冷凝霜本是一位温婉如水的女剑修，因道侣被仇家所害，心死如灰之下孤身前往极北冰原。她在万年寒冰之下发现了上古冰凤的遗骸，从冰凤羽翼的纹路中参悟出了寒冰剑道的真谛。

她在极北冰原闭关百年，将心中的悲愤化为彻骨寒意，融入了剑法之中。此剑诀出剑时寒气逼人，剑气所过之处万物冰封，连空气中的水分都会凝结成冰晶。冷凝霜百年后出关，以一剑冰封了仇家满门三千里的领地，而后将那柄剑刺入冰原最深处，飘然而去。后人称她为"冰中之魄"，寒冰剑诀也由此流传开来。

## 功法特点

**优点：**
- 剑气附带极寒之力，可冻结敌人的血液和真气
- 大范围冰封能力，在群战中极具优势
- 冰层可作为临时防御壁垒
- 在水中或潮湿环境中威力倍增

**缺点：**
- 在炎热环境（火山、沙漠）中威力大幅下降
- 出剑速度会因寒气凝聚而略显迟缓
- 对自身经脉也有冻伤风险
- 修炼之地极为苛刻，温暖之地无法修炼

## 功法等级

**寒气初生**：剑身表面凝结一层薄霜，出剑时能感受到刺骨的寒意

**冰霜附刃**：剑气化为肉眼可见的白色寒气，可在击中目标时冻结伤口周围的血肉

**千里冰封**：一剑斩出可冰封方圆数十丈的地面和水面，范围类控制能力大增

**绝对零度**：剑气温度降至极致，可以冻结空间中的灵气流动，甚至冻结低阶法术

## 功法招式

1. **寒霜初降**：横剑一挥，白色的寒气如晨霜般弥漫开来，降低周围温度，减缓敌人的行动速度。

2. **冰封三尺**：剑尖点地，以剑为中心方圆三丈内的地面瞬间结冰，冰刺从地面刺出攻击敌人。

3. **霜雪纷飞**：急速挥剑，无数细碎的冰晶剑气如同暴风雪般向敌人席卷而去，覆盖范围极广。

4. **冰魄寒光**：剑身凝聚出深蓝色的寒光，一记直刺将极寒之力凝聚于一点，洞穿敌人的护体真气和防御法宝。

5. **万载冰封**：以剑引动天地寒气，将自身周围百丈范围内的所有事物（包括空气）全部冻结，形成一座巨大的冰牢。

6. **冰凤展翅**：终极招式——以自身元婴之力催动，剑气化为冰凤之形展翅高飞，所过之处万物冰封、生机断绝。

## 修炼条件

**前置功法**：需修习过水属性或冰属性基础功法，能够御寒

**灵根要求**：冰属性变异灵根最佳，水属性灵根次之

**修炼地点**：极北冰原、万年冰川、雪山之巅等极寒之地

**所需资源**：以千年寒铁或冰晶玉髓锻造的剑器，剑身能储存和传导寒气

## 使用限制/副作用

- 长期修炼会导致寒气侵入脏腑，需要火属性丹药调和
- 在温暖环境中施展会消耗额外的真气维持寒冰剑气
- 此剑诀对周边环境有不可逆的影响，会永久改变当地的气候
- 寒气反噬时经脉会如针刺般疼痛，严重时可能导致经脉永久性损伤

## 相关典故

**冰原上的剑痕**：在极北冰原深处有一道长达百里的剑痕，因为寒气经久不散，百年来从未融化。据说这是冷凝霜出关时随手一挥留下的。许多冰系修士专程前去参悟这道剑痕，有人在剑痕旁枯坐十年才领悟其中一分寒意。

## 修炼进度

**凝霜期**：能在剑身表面凝结寒霜，攻击时可冻伤敌人表皮，约需一年

**冰晶期**：剑气化为实质性的冰晶，可冻结敌人的兵器和法术，约需三到五年

**暴雪期**：一剑可引动小范围的暴风雪，持续冰封敌人并消耗对方的体温和真气，约需五到十年

**冰封期**：一念之间可冰封千丈，万物冻结连时间都仿佛停滞，已达寒冰剑诀之最高境界
