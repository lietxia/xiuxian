# 狂风剑诀

## 基本信息
- **功法名称**：狂风剑诀
- **品级**：四阶（天级）
- **类型**：剑法功法
- **适用境界**：元婴期
- **修习难度**：★★★★☆

## 功法介绍

狂风剑诀出自北漠狂刀客"铁骨"萧烈之手。萧烈本是北漠第一刀客，纵横大漠三十载未逢敌手。然而在一次秘境探险中，他的爱刀被一位剑修以精妙剑法击碎。萧烈深受刺激，决定弃刀学剑。但以他的性格，根本学不来那些优雅精妙的剑招。

他另辟蹊径，将刀法中的狂猛霸道融入剑中，又结合了北漠沙暴的狂暴之势，创出了这套不讲章法、只求痛快、狂放不羁的狂风剑诀。此剑法如同暴风过境，每一剑都带着毁天灭地的狂暴力量，没有固定的招式套路，全凭一股摧枯拉朽的气势碾压敌人。萧烈后来以狂风剑诀横扫北漠，当年击败他的那位剑修主动前来拜服，称他的剑"已经不是剑，是道"。

## 功法特点

**优点：**
- 攻击范围极大，剑势覆盖方圆数十丈
- 气势磅礴，对心志不坚的敌人有震慑效果
- 破坏力惊人，对建筑、阵法、法宝有额外的破坏加成
- 狂风附体可提升移动和攻击速度

**缺点：**
- 真气消耗极大，全力战斗半柱香即需休息
- 精度不足，容易误伤友军
- 防御薄弱，狂风剑诀只攻不守
- 对体力要求极高，修习者需有强壮的体魄

## 功法等级

**风起大漠**：初具狂风之势，出剑带动呼啸风声，每一剑都有风沙相随

**狂风呼啸**：剑势如狂风般不可阻挡，每一剑都带着摧枯拉朽的力道，风声如鬼哭狼嚎

**风卷残云**：剑势展开如同一场真正的沙暴，飞沙走石遮蔽视线，敌人无法睁眼

**飓风灭世**：以身化风，每一剑都是一道飓风，剑气旋转绞碎一切，可摧毁一座城池

## 功法招式

1. **大漠风沙**：横向挥剑带起漫天风沙，遮蔽敌人视线，同时在风沙中隐藏数道致命剑气。

2. **狂风扫叶**：以身带剑高速旋转，剑气呈螺旋状扩散开来，将周围的一切绞碎扫荡。

3. **暴风骤雨**：一口气斩出数十道剑气，如同暴风骤雨般砸向敌人，密集到无法闪避。

4. **风卷残云**：剑势凝聚成一个巨大的龙卷风，将敌人吸扯到风眼中心承受无尽切割。

5. **狂沙百裂**：剑气中夹杂着被风沙打磨了千年的尖锐沙砾，击中目标后可造成百道细小伤口。

6. **天地一怒**：将全身真气引爆，以剑引动天地狂风，形成一道连接天地的飓风柱，将范围内的万物绞成粉末。

## 修炼条件

**前置功法**：轻风剑诀或狂风类基础功法，具备一定的风系造诣

**灵根要求**：风属性变异灵根最佳，火属性灵根亦可（火借风势）

**修炼地点**：大漠戈壁、荒原旷野等开阔且风大的地方

**所需资源**：宽刃重剑，剑身厚重以承受狂猛的力道，重量不低于十斤

## 使用限制/副作用

- 在密闭空间中威力大减且容易伤及自身
- 对剑器损耗极大，普通剑用不了多久就会崩裂
- 体力和真气消耗双高，不适合持久战
- 战斗风格狂暴，容易激怒对手导致不死不休的局面

## 相关典故

**一刀一剑一座城**：萧烈曾受邀到北漠最大的城市"金沙城"做客。城中恶霸欺压百姓，萧烈一人一剑站在城门口，以狂风剑诀卷起了十里黄沙，将整座金沙城笼罩在沙暴中三天三夜。城中恶霸出来投降时，萧烈只说了两个字："够了。"从此北漠再无恶霸敢横行。

## 修炼进度

**扬沙期**：出剑可扬起地面沙尘形成简易的遮蔽效果，剑气附带风刃，约需一年

**卷风期**：能以剑势卷起小型的旋风，将敌人卷入其中连续切割，约需三到五年

**暴风期**：剑势可化为覆盖百丈的暴风区域，飞沙走石日月无光，约需五到十年

**天怒期**：一剑可引动天象变化，方圆百里内狂风大作如同天怒，从此举手投足皆是狂风
