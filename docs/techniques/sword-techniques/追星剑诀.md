# 追星剑诀

## 基本信息
- **功法名称**：追星剑诀
- **品级**：二阶（玄级）
- **类型**：剑法功法
- **适用境界**：筑基期
- **修习难度**：★★☆☆☆

## 功法介绍

追星剑诀为天星宗第三代宗主——"观星老人"北辰子所创。北辰子一生痴迷于星辰之道，每逢晴朗夜晚必在天星宗最高的观星台上观测星象，风雨无阻。他花了六十年时间绘制了完整的周天星图，却发现星辰运行的轨迹之中蕴含着某种玄妙的规律。

某一夜，一颗流星划破天际，北辰子福至心灵，将流星划过的轨迹一剑斩出——剑气竟然在星空中留下了一道经久不散的剑痕。他由此悟出，将剑法融入星辰运行的轨迹之中，便可借星辰之力施展威力倍增的剑招。追星剑诀由此诞生。天星宗也因此剑诀从一个二流宗门一跃成为北斗域的名门大派。

## 功法特点

**优点：**
- 剑招轨迹诡异难测，如同星辰运行般难以预判
- 在夜晚或星空下有额外的威力加成
- 蕴含星辰之力，可克制阴邪鬼魅类敌人
- 身法步法暗合北斗七星阵位，进退有据

**缺点：**
- 白天或阴天时威力有所下降
- 需要一定的天文星象知识才能领悟精髓
- 剑招复杂，修炼难度高于同阶功法
- 对目力要求极高，近视或有眼疾者难以修习

## 功法等级

**星痕初现**：剑招能隐约带出星光轨迹，在夜间能看到淡淡的剑光残影

**斗转星移**：身法步法可对应北斗七星的变化，在七星阵位之间快速切换

**追星逐月**：出剑速度大幅提升，如同追逐流星般迅疾，剑光可跨越数丈距离

**星耀九天**：剑招之中蕴含真正的星辰之力，每一剑斩出都如同星辉洒落，威力惊人

## 功法招式

1. **北辰一剑**：剑指北方，凝聚北斗第一星之力，一记笔直的突刺，是所有招式中最沉稳的一剑。

2. **流星赶月**：身形向前冲刺的同时连刺七剑，剑光如流星雨般连绵不绝，速度一次快过一次。

3. **七星伴月**：以自身为中心画出一个圆弧，七道剑气依次射出，呈北斗七星状排列封锁敌人退路。

4. **星罗棋布**：剑尖点出数十点星芒，如同夜空繁星散布在敌人周身，每一道星芒都是一记杀招。

5. **斗转星移**：以剑身画出一个大圆，引动周围天地灵气旋转，可将敌人的攻击力道转向反弹。

6. **星河倒悬**：跃起后自上而下挥出一剑，剑光如银河倾泻般笼罩大片区域，是追星剑诀的最强范围攻击。

## 修炼条件

**前置功法**：基础剑诀或入门剑式大成，有一定的天文星象基础为佳

**灵根要求**：金属性或雷属性灵根最佳，光属性变异灵根亦可

**修炼地点**：视野开阔的露天之地，最好是山顶或高台，夜晚修炼效果最佳

**所需资源**：一柄能够反光的亮银色长剑，剑身需抛光如镜以反射星光

## 使用限制/副作用

- 过度观星修炼会导致视力受损，需配合明目丹药调理
- 长期依赖星光之力，在无光环境下战斗力锐减
- 剑招对精度要求极高，毫厘之差便会从杀招变成破绽
- 容易被阵法或遮蔽天机的手段克制

## 相关典故

**观星老人的最后一剑**：北辰子临终前，弟子们将他抬到观星台上。那一夜天降流星雨，北辰子用最后的力气挥出了一剑——这一剑引动了流星雨中的一颗陨石改变了轨迹，砸落在了天星宗的后山，形成了如今的"陨剑湖"。他含笑而逝，手中的剑化为了星光点点消散在夜空中。

## 修炼进度

**识星期**：学会辨认三十六颗主星的位置和运行规律，能在出剑时对应星辰方位，约需半年

**引星期**：能够在出剑时引动微弱的星辰之力，剑身泛起淡淡星光，约需一到二年

**化星期**：剑招可幻化出星光残影，夜间战斗如同操纵星光般华丽致命，约需三到五年

**掌星期**：可引动周天星辰之力为己用，一剑出而星光随行，已达此剑诀的最高境界
