# 剑开天门

## 基本信息
- **功法名称**：剑开天门
- **品级**：六阶（神级）
- **类型**：剑法功法
- **适用境界**：炼虚期
- **修习难度**：★★★★★

## 功法介绍

剑开天门由上古天门宗的飞升传奇——"天门剑圣"李淳风所创。李淳风修炼至大乘期圆满后，发现天地法则有缺，飞升之门关闭已久，世间已万年无人飞升。他不甘止步于此，携剑登上世界最高峰——"不周山巅"，以自身剑道强行劈开通往仙界的通道。

他在不周山巅挥出了九剑。第一剑劈开了天幕，第二剑斩断了法则枷锁，第三剑击溃了天道压制……到第九剑时，一道金色的天门在虚空中缓缓打开。李淳风迈入天门之前，将这九剑的精髓刻在了不周山巅的石壁上，命名为"剑开天门"。后世修士参悟这九道剑痕，逐渐完善了这套以力破道、以剑开天的绝世剑法。剑开天门的核心是"以有限之力破无限之天"——只要剑心够坚，连天道法则都可一剑斩断。

## 功法特点

**优点：**
- 蕴含飞升之秘，可感应天道法则的薄弱之处
- 每剑皆可破开法则禁制，专破各种封印和结界
- 剑气中蕴含飞升之意，对大乘期修士有极大的启发
- 可短暂打通天界与凡间的通道，引仙气灌体

**缺点：**
- 消耗极为巨大，九剑全部出完会耗尽修为
- 每出一剑都会受到天道反噬，可能折损寿命
- 若剑心不坚，会被天道反噬之力击碎道心
- 此剑法过于霸道，容易引动天地灾变

## 功法等级

**裂天**：剑气可斩裂天空，在苍穹上留下一道剑痕，可在一定程度上干扰天象

**破法**：剑气可斩断天地法则的束缚，破除阵法、禁制、封印等皆不在话下

**开天**：剑气可暂时打通界面壁垒，在虚空中打开一道通往另一界的通道

**天门永驻**：无需出剑，自身的存在就相当于一座永固的天门，可随时引动天道之力

## 功法招式

1. **一剑裂天**：竖劈一剑，剑气直冲云霄将天空划开一道裂痕，天幕如同布帛般被撕裂。

2. **二剑断法**：横斩一剑，斩断周围的所有法术和禁制，一切人为设立的限制在这一剑面前尽皆失效。

3. **三剑破障**：以剑尖点在虚空某处，精确地击碎空间屏障最脆弱的那一点，打通通道。

4. **四剑逆流**：逆着天地灵气的流动方向斩出一剑，短暂逆转局部区域的法则运行。

5. **五剑通天**：剑尖指向天际，一道剑气冲天而起，穿透层层天幕直达仙界，引仙气降临。

6. **九剑天门**：九剑叠加——前五剑积蓄的力量在第九剑时全部释放，一剑斩开通往仙界的真正天门。

## 修炼条件

**前置功法**：需至少达到炼虚期且已将一门五阶剑法修炼至圆满

**灵根要求**：以天灵根为佳，需要具备极强的天道感应能力

**修炼地点**：不周山巅的天门剑痕处最佳，其次为世界最高峰或天道法则稀薄之处

**所需资源**：需要一柄能够承受天道反噬的本命神剑，最好是经历过天劫的剑

## 使用限制/副作用

- 每施展一次高阶剑招都会折损寿元，不可轻用
- 天道反噬会在身上留下法则伤痕，极难愈合
- 若强行施展超出自身承受能力的剑式，可能当场道消身殒
- 此剑法在天道不全的小世界或秘境中无法使用

## 相关典故

**不周山巅的九道剑痕**：不周山巅至今仍留有李淳风当年的九道剑痕。每一道剑痕都有不同的颜色和气息——第一道金色、第二道紫色、第三道青色……据说化神期以下的修士靠近剑痕就会感到神魂被撕裂。曾有魔道大乘期修士试图毁掉剑痕，结果被剑痕中残存的剑意一击斩杀。

## 修炼进度

**感天期**：能够感知天地法则的脉络，找到法则的薄弱之处，约需十到二十年

**裂空期**：一剑可在天空留下剑痕，破除大多数阵法禁制，约需三十到五十年

**破界期**：可短暂打开界面通道，进行短距离的跨界传送，约需百年

**开天门期**：九剑齐出可真正打开飞升天门，自身剑心与天道共鸣，随时可飞升
