# 养气剑诀

## 基本信息
- **功法名称**：养气剑诀
- **品级**：一阶（黄级）
- **类型**：剑法功法
- **适用境界**：聚气期
- **修习难度**：★☆☆☆☆

## 功法介绍

养气剑诀出自道家剑修门派"养剑宗"的入门心法。养剑宗祖师青云真人发现，寻常修士炼气时真气散乱难以凝聚，若是将呼吸吐纳与剑式结合，以剑势引导真气运转，则事半功倍。于是他创出了这一套以剑养气、以气御剑的独特法门。

此功法的核心在于"剑是气的延伸，气是剑的灵魂"。修习者通过特定的剑式引导体内真气流转，每一个剑招对应一条经脉路线，在练剑的同时完成真气的积累和提纯。养剑宗弟子入门第一课不是学剑，而是"以剑呼吸"——将剑视为身体的一部分，通过剑身感知天地灵气的脉动。青云真人凭借此功法从一介散修修炼至元婴期，开创了养剑宗五百年的基业。

## 功法特点

**优点：**
- 炼气与练剑同时进行，效率倍增
- 真气凝练度远超同阶功法
- 为日后御剑飞行、剑气外放打下坚实基础
- 温和绵长，几乎没有走火入魔的风险

**缺点：**
- 修炼速度较慢，讲究水到渠成
- 剑招威力平庸，缺乏爆发力
- 需每日坚持不可中断，否则真气会溃散
- 只适合性情温和、有耐心的修士

## 功法等级

**气随剑走**：剑式引导真气在经脉中初步运行，练剑时能感受到真气在剑柄与掌心之间流转

**剑随气动**：真气充盈后反哺剑式，出剑时带有淡淡的剑气附着，削铁如泥

**气剑合一**：真气和剑式完全同步，每招每式皆有真气加持，剑未至而气先到

**剑气如丝**：从剑尖吐出三寸剑芒，可隔空伤敌，是日后御剑术的雏形

## 功法招式

1. **抱元守一式**：双脚与肩同宽，双手持剑于胸前，剑尖朝天。配合"吸—停—呼"三拍呼吸，引真气沉入丹田，是养气的根本式。

2. **青龙汲水式**：剑尖斜向下刺，身体前倾，如龙吸水。配合吸气，引真气从脚底涌泉沿督脉上行至丹田。

3. **白鹤亮翅式**：剑身横展如白鹤展翅，真气由丹田向双手劳宫穴扩散，经剑身释放出体外，然后再收回。

4. **苍松迎客式**：剑尖斜向上挑，身体后仰，配合呼气将浊气逼出体外，同时将新鲜的天地灵气吸入体内。

5. **回风拂柳式**：剑身画弧旋转，带动体内真气沿任督二脉小周天运转，每转一圈真气便凝练一分。

6. **归元藏剑式**：剑收于鞘中或背后，双手结剑印，将全身真气收敛回丹田，是收功的招式。

## 修炼条件

**前置功法**：需已完成聚气期的基础炼气，体内有微弱的真气感应

**灵根要求**：以木属性灵根最佳，水土灵根次之，火金灵根也可修习但效率稍低

**修炼地点**：灵气充沛的山林溪涧之畔为最佳，早晚时分效果最好

**所需资源**：需要一柄能传导真气的法器级长剑，凡铁剑无法承载剑气

## 使用限制/副作用

- 每日必须完成一整套剑式才能巩固真气，若有中断则前功尽弃
- 修炼时需绝对专注，分心会导致真气岔道，轻则经脉受损，重则吐血受伤
- 此功法以养为主、以战为辅，实战能力较弱，需搭配其他攻伐剑法
- 若长期只练养气剑诀而不对敌实战，会造成"纸上谈兵"的困境

## 相关典故

**青云真人的三百年一剑**：相传青云真人晚年收了一个资质驽钝的弟子，教了他三十年养气剑诀。弟子始终无法突破剑气外放的境界。青云真人临终前对弟子说："你今日刺我一剑。"弟子含泪出剑，三十年凝聚的剑气在这一刻喷薄而出，将洞府石壁刺穿三丈。青云真人含笑而逝——原来他一直在等弟子将"气"养够。

## 修炼进度

**感应期**：掌握抱元守一式，能在练剑时感受到真气随剑式流动，耗时一到三个月

**运行期**：六式连贯练完，真气可完成一个小周天循环，面色红润精力充沛，耗时半年

**凝气期**：剑尖吐出寸许剑气，能在木桩上留下焦痕，真气积累已达一定厚度，耗时一至二年

**养成期**：剑气外放可达三尺，为日后修习御剑术和高阶剑法做好了充分准备
