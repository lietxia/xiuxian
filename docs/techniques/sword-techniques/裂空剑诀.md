# 裂空剑诀

## 基本信息
- **功法名称**：裂空剑诀
- **品级**：三阶（地级）（地级）
- **类型**：剑法功法
- **适用境界**：金丹期
- **修习难度**：★★★☆☆

## 功法介绍

裂空剑诀源于上古"虚空剑尊"——凌虚子的一次奇遇。凌虚子在金丹期时误入一处空间裂缝，被困在虚空乱流中整整十年。在这十年里，他每日面对刀刃般锋利的空间裂隙，发现虚空裂隙本身就是天地间最完美的"剑痕"——无形无质，却可切裂万物。

他以手指为剑，模仿空间裂隙的轨迹和韵律，慢慢创出了一套能在虚空中斩出裂缝的剑法。十年后，他从空间裂缝中走出时，一剑便将守护裂缝的上古禁制斩成了两半。裂空剑诀的核心在于"以剑裂空"，斩出的剑气能在空间中留下短暂的空间裂隙，这些裂隙不仅难以愈合，还会持续切割陷入其中的一切物体。凌虚子后来以此剑法跻身大乘期，被誉为"虚空第一剑"。

## 功法特点

**优点：**
- 剑气附带空间切割特性，无视大部分物理和法术防御
- 造成的伤口极难愈合，空间之力会阻止创口恢复
- 可以斩开低级禁制和阵法
- 对空间类法术有天然的破解效果

**缺点：**
- 修炼过程极其危险，稍有不慎便会在修炼时割裂空间伤到自己
- 对真气的质量和操控精度要求极高
- 剑气消耗是普通剑法的三倍以上
- 修炼此剑法需具备一定的空间感知天赋

## 功法等级

**裂痕初现**：剑气能在空气中斩出肉眼可见的白色裂痕，转瞬即逝

**裂帛之声**：出剑时空间发出撕裂般的声响，剑气所过之处空气如布帛般裂开

**虚空留痕**：剑气斩出的空间裂隙可持续三到五息时间，裂隙边缘锋利如刀

**裂空碎虚**：可一剑斩出长宽数尺的空间裂缝，将敌人或攻击吞入虚空乱流之中

## 功法招式

1. **一线天**：横斩一剑，剑气化为一条细如发丝的空间裂缝，无声无息地切向敌人，极难察觉。

2. **虚空斩**：竖直劈下，剑气撕裂空间形成一个短暂的缺口，可将敌人的攻击引入虚空之中化解。

3. **碎空刺**：剑尖凝聚空间之力，一刺之下前方三尺的空间寸寸碎裂，形成一片空间碎片风暴。

4. **裂天斩**：横竖交叉的两剑斩出十字形空间裂缝，将敌人的防御或法宝直接撕裂。

5. **虚空漩涡**：以剑尖搅动空间，形成一个微小的空间漩涡，将周围的一切吸扯进去绞碎。

6. **乾坤一裂**：聚集全部力量一剑斩出，剑过之处空间如镜子般裂开，万物在这一剑面前尽皆两断。

## 修炼条件

**前置功法**：需修习过空间类基础法术或拥有空间感知能力

**灵根要求**：空间属性变异灵根最佳（极其罕见），其次为金属性灵根

**修炼地点**：空间壁垒薄弱处，如空间裂缝附近、上古传送阵遗址等

**所需资源**：掺有虚空石的灵剑，否则普通剑无法承受空间之力的反噬

## 使用限制/副作用

- 修炼时必须在空间壁垒稳固的地方进行，否则可能引发不可控的空间崩塌
- 每次施展高阶招式后会感到强烈的空间眩晕感，需调息恢复
- 若使用过度，施展者自身可能被空间裂缝反噬，躯体出现不可愈合的裂痕
- 裂空剑诀对环境的破坏较大，在宗门内或城市中使用会受到严厉制裁

## 相关典故

**凌虚子出关**：凌虚子从空间裂缝中走出时，天衍宗的宗主感应到了空间波动前来查看。他看到衣衫褴褛的凌虚子从裂隙中走出，正要出手试探，凌虚子只是轻轻挥了一下手指——天衍宗宗主身后十里外的一座山峰无声无息地滑落了一半。切口光滑如镜。天衍宗宗主当场跪拜，称其为"虚空真仙"。

## 修炼进度

**感空期**：能感知到空间的微弱波动，初步尝试在剑身上凝聚空间之力，约需一年

**破壁期**：能在空气中斩出短暂的空间裂隙，持续一息左右，约需二到三年

**裂空期**：一剑可斩出可容纳一人通过的空间裂缝，用于战斗或短暂位移，约需五到十年

**碎虚期**：方圆百丈内的空间皆可为剑，一念之间可裂空碎虚，已达裂空剑诀之巅
