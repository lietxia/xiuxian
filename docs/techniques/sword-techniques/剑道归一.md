# 剑道归一

## 基本信息
- **功法名称**：剑道归一
- **品级**：九阶（混沌级）
- **类型**：剑法功法
- **适用境界**：渡劫期
- **修习难度**：★★★★★

## 功法介绍

剑道归一源自混沌初开时的第一位剑修——「混沌剑主」。传说天地未分、鸿蒙未判之际，混沌中诞生了一缕先天剑意。那剑意没有形体，没有意识，它只是纯粹的「斩」——是天地间第一个被定义的法则。盘古挥斧开天之时，这缕剑意受到感召，化为天地间第一柄剑——「归一」。

混沌剑主得此古剑，穷尽一生参悟其中先天剑理，终于勘破了一层至理——天下万剑、万般变化、无穷招式，说到底不过是「一斩」的延伸。一斩之前的起手、蓄势、周旋，皆是虚妄；一斩之后的余波、剑痕、胜负，亦归空无。剑道的尽头，便是回归这一「斩」的本源。

他所创的剑法，实则是一门「反剑法」——要破除一切剑法的形与式，回归剑的本源：斩。

## 功法特点

**优点：**
- 天下剑法的终点——没有什么剑法能超出归一的范畴
- 一斩之力可破万法、开天地、断因果
- 不需要任何招式变化——因为所有变化都包含在这一斩之中
- 超越一切剑道规则，不受天道法则约束

**缺点：**
- 根本无法传授——因为"归一"只能意会不能言传
- 修炼者必须先穷尽万剑，然后才能舍弃万剑
- 一旦出剑无法收回——这一斩没有"收回"的概念
- 修炼此剑法意味着要否定自己之前所有学过的剑法，极为痛苦

## 功法等级

**知万剑**：参透天下万般剑法的本质，理解了所有剑法的共同本源

**忘万剑**：将学过的所有剑法全部忘记——不是遗忘，而是超越

**得一斩**：心中再无任何剑招剑式，只剩一个纯粹"斩"的意念

**归一境**：自身与斩合一——我就是斩、斩就是我，一剑可开天亦可灭世

## 功法招式

剑道归一没有固定的招式——因为它本身就是所有招式的本源。若勉强要描述，只有"一斩"二字。

1. **一斩·开天**：横斩——取盘古开天辟地第一斩之意，剑出则空间裂、时间长河断、法则崩碎如齑粉。

2. **一斩·断法**：竖劈——斩断天地间一切法则与规则，万法不存，唯有此剑独真。

3. **一斩·灭因**：斜削——直斩因果之线。剑过处，「因」消「果」散，敌人的杀招失去了来处，自然溃散于无形。

4. **一斩·归虚**：点刺——将毕生力量凝于剑尖一点，刺中之物从存在层面被彻底抹除——不剩残骸，不余波动，仿佛从未存在过。

5. **一斩·永恒**：回旋——这一剑没有起点亦没有终点，剑意永存于斩痕之中，形成一道永恒不灭的剑伤——即便岁月流逝、天地崩塌，剑痕依旧。

6. **归一·终焉**：万法归一，万物终焉——这不是攻击，而是「定义」。此剑出，便定义了万物的终结，不可逆转，不可违抗。

## 修炼条件

**前置功法**：需要将至少三门九阶以下的剑法修炼至圆满，且穷尽剑道变化

**灵根要求**：无任何灵根要求——归一超越灵根和资质，只看剑心是否纯粹

**修炼地点**：混沌未开的边缘地带、天地初开的遗迹、归一古剑的沉睡之地

**所需资源**：归一古剑——或者任何一柄剑都可以，因为归一境中"万物皆是剑"

## 使用限制/副作用

- 出剑即决生死——没有试探和留手的余地
- 若未能真正理解"归一"，这一剑可能连鸡都杀不了
- 修炼此剑法后无法再使用其他剑法——因为其他剑法在归一面前都是"多余"
- 归一的力量过于本源，可能引起天地法则的排斥

## 相关典故

**混沌剑主与盘古**：传说混沌剑主曾与盘古有过一番对话。盘古问他：「你为何持剑？」混沌剑主答：「为斩。」盘古笑曰：「我开天是为生，你持剑是为灭——你我何异？」混沌剑主沉默良久，忽然挥出一剑——那一剑没有斩向任何事物，只在虚空中留下了一道横贯天地的剑痕。他淡淡道：「斩，也可以是创造。这一剑，便为你的开天助一臂之力。」盘古大笑，取下开天斧斧刃上的一道寒光赠予混沌剑主——那寒光便是归一古剑的雏形。

## 修炼进度

**参万期**：穷尽天下剑法，参透所有剑道的本质和本源，约需百年以上

**忘剑期**：将一切剑法从心中抹去——这个过程比学习更痛苦，约需数十年

**悟斩期**：心中只剩一个"斩"字，万物皆可一斩而破，约需百年

**归一期**：自身化为「斩」的化身——世间万物无不可斩，却也不会轻出此剑。盖因一斩即永恒，出剑便是终局。
