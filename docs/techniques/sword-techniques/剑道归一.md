# 剑道归一

## 基本信息
- **功法名称**：剑道归一
- **品级**：九阶（混沌级）
- **类型**：剑法功法
- **适用境界**：渡劫期
- **修习难度**：★★★★★

## 功法介绍

剑道归一源自混沌初开时的第一位剑修——"混沌剑主"。传说天地未分、混沌一片时，有一缕先天剑意在混沌中诞生。这缕剑意没有形体、没有意识，它只是纯粹的"斩"的法则本身。当盘古开天辟地时，这缕剑意也随之苏醒，化为了天地间第一柄剑——"归一"。

混沌剑主是第一个得到这柄剑的生灵，他穷尽一生参悟归一古剑中蕴含的先天剑理，最终发现了一个真理：天下万剑、万般变化、无穷招式，归根结底都只是"一斩"——一斩之前的准备、一斩之后的余韵，皆是虚妄。剑道的终极就是回归到这一"斩"的本源。他创出了剑道归一这一剑法，实际上是"反剑法"——它要破除所有剑法的形和式，回归到剑的本源：斩。

## 功法特点

**优点：**
- 天下剑法的终点——没有什么剑法能超出归一的范畴
- 一斩之力可破万法、开天地、断因果
- 不需要任何招式变化——因为所有变化都包含在这一斩之中
- 超越一切剑道规则，不受天道法则约束

**缺点：**
- 根本无法传授——因为"归一"只能意会不能言传
- 修炼者必须先穷尽万剑，然后才能舍弃万剑
- 一旦出剑无法收回——这一斩没有"收回"的概念
- 修炼此剑法意味着要否定自己之前所有学过的剑法，极为痛苦

## 功法等级

**知万剑**：参透天下万般剑法的本质，理解了所有剑法的共同本源

**忘万剑**：将学过的所有剑法全部忘记——不是遗忘，而是超越

**得一斩**：心中再无任何剑招剑式，只剩一个纯粹"斩"的意念

**归一境**：自身与斩合一——我就是斩、斩就是我，一剑可开天亦可灭世

## 功法招式

剑道归一没有固定的招式——因为它本身就是所有招式的本源。若勉强要描述，只有"一斩"二字。

1. **一斩·开天**：横斩——这一剑模仿了盘古开天辟地的第一斩，可切开空间、时间、法则。

2. **一斩·断法**：竖劈——这一剑斩断一切法则和规则，让万法在这一剑面前失效。

3. **一斩·灭因**：斜削——这一剑斩断因果，让攻击失去了"因"，直接落到"果"上。

4. **一斩·归虚**：点刺——这一剑将所有力量凝聚于一点，将刺中之物从存在层面抹除。

5. **一斩·永恒**：回旋——这一剑没有起点也没有终点，永远在斩的过程中，形成永恒不灭的剑痕。

6. **归一·终焉**：所有力量归于这一斩——不是攻击，而是"定义"。这一剑定义了万物的终结。

## 修炼条件

**前置功法**：需要将至少三门九阶以下的剑法修炼至圆满，且穷尽剑道变化

**灵根要求**：无任何灵根要求——归一超越灵根和资质，只看剑心是否纯粹

**修炼地点**：混沌未开的边缘地带、天地初开的遗迹、归一古剑的沉睡之地

**所需资源**：归一古剑——或者任何一柄剑都可以，因为归一境中"万物皆是剑"

## 使用限制/副作用

- 出剑即决生死——没有试探和留手的余地
- 若未能真正理解"归一"，这一剑可能连鸡都杀不了
- 修炼此剑法后无法再使用其他剑法——因为其他剑法在归一面前都是"多余"
- 归一的力量过于本源，可能引起天地法则的排斥

## 相关典故

**混沌剑主与盘古**：传说混沌剑主曾与盘古见过一面。盘古问他："你为何持剑？"混沌剑主说："为斩。"盘古说："我开天是为了生，你持剑是为了灭，你我何异？"混沌剑主沉默良久，然后挥出了一剑——这一剑没有斩向任何东西，只是在虚空中留下了一道剑痕。他说："斩，也可以是创造。这一剑便是为你开天助力的。"盘古大笑，将开天斧的斧刃上的一道寒光赠予了混沌剑主，那便是归一古剑的雏形。

## 修炼进度

**参万期**：穷尽天下剑法，参透所有剑道的本质和本源，约需百年以上

**忘剑期**：将一切剑法从心中抹去——这个过程比学习更痛苦，约需数十年

**悟斩期**：心中只剩一个"斩"字，万物皆可一斩而破，约需百年

**归一期**：自身化为"斩"的化身，从此世间万物在面前无不可斩——但也不会轻易出剑，因为一斩即永恒
