# 剑心通明

## 基本信息
- **功法名称**：剑心通明
- **品级**：七阶（圣级）
- **类型**：剑法功法
- **适用境界**：合体期
- **修习难度**：★★★★★

## 功法介绍

剑心通明源自佛门剑道高僧——"明心剑佛"慧觉大师。慧觉大师本是佛门天骄，却因一次下山历练时误入心魔幻境，在幻境中经历了百世轮回。他在每一世中都持剑而行，历经爱恨情仇、生离死别。百世轮回之后，他在最后一世中忽然觉悟——剑是心、心即剑，万法皆空、剑心如明。

他回到寺中，以佛门"明心见性"之法融合剑道，创出了这套以心御剑的法门。剑心通明的核心不是练剑，而是"修心"——只有剑心如明镜般澄澈无尘，才能照见万物的本来面目，才能在敌人的剑招出手之前就洞察其意图。慧觉大师在明心见性之后，看天下一切剑法都如同透明——因为任何剑法都是人心的映射，看透了人心就看透了剑法。

## 功法特点

**优点：**
- 洞察力极强，可提前预判敌人的所有动作
- 不为幻象所惑，一切幻术在心镜面前都是透明的
- 心剑合一，无需出鞘即可以心御剑伤敌
- 剑心澄澈则万邪不侵

**缺点：**
- 战斗力完全取决于心境的澄澈程度
- 若心有杂念或情绪波动，剑心会蒙尘而威力大减
- 修炼过程极为痛苦，需要直面内心所有的阴暗面
- 重悟不重力，对上蛮横型对手时可能力不从心

## 功法等级

**心如明镜**：剑心如镜可照见自身——清晰看到自己的优缺点和剑道上的不足

**洞若观火**：剑心可照见他人——在与对手对决之前就能看穿对方的剑路和心理

**明察秋毫**：剑心可照见天地——能感知到周围天地灵气的流动变化，洞察一切风吹草动

**心剑通明**：剑心与天道相合——不再需要观察和分析，一切尽在直觉之中，心意所动即剑之所至

## 功法招式

1. **心剑式**：不以目视、不以耳听，全凭剑心感知——心中映出敌人的全貌，剑随意动先发制人。

2. **明镜止水**：心如止水不起波澜，剑气如镜面般光滑澄澈——可反射和看穿一切攻击。

3. **照妖一剑**：剑心通明可照见一切虚妄——幻术也好、隐身也罢，在这一剑面前无所遁形。

4. **慧剑斩心魔**：这是一招专门针对神识和心灵的攻击——不是斩肉身，而是直斩心魔。

5. **万法皆明**：以剑心观察天地法则的运转规律，一瞬间洞察对方功法的所有奥秘和破绽。

6. **剑心通明·大圆满**：剑心如明月当空，照彻天地万物——在这一状态下，一切攻击都如同在慢动作中发生，洞察即闪避、预判即可破。

## 修炼条件

**前置功法**：需要具备一定的佛门心法基础或禅定功夫

**灵根要求**：无特殊灵根要求，但需要剑道天赋极高且心性纯良

**修炼地点**：古刹、清静之地、远离尘嚣的深山幽谷

**所需资源**：不需要特定的神剑——任意一柄剑都可以，因为剑心通明重在心而非剑

## 使用限制/副作用

- 情绪波动时剑心会蒙尘，越愤怒越弱
- 若做了违背本心之事，剑心上会留下裂痕，极难修复
- 修习者需持守清规戒律，纵情声色会导致剑心蒙昧
- 看透人心后容易对人性和世界感到失望，滋生避世之心

## 相关典故

**慧觉辨剑**：有一日，天下十大剑修齐聚灵山，请慧觉大师品评他们的剑道。慧觉大师让他们依次出剑，然后闭目不语。十人问其故，慧觉说："你们十人剑法各异，但剑心中的心魔却大同小异——无非是贪嗔痴三毒。"十人震惊，跪求开示。慧觉以剑心通明之法为他们各自指出了心魔所在，十人中后来有五人达到了更高的剑道境界。

## 修炼进度

**净心期**：通过禅定和反省，清理剑心中的杂念和尘埃，让剑心逐渐恢复澄明，约需十年

**明心期**：剑心明亮如镜，可照见自身一切不足，约需二十到三十年

**照心期**：剑心可照见他人之心，在对决前便可知对方深浅，约需五十到百年

**通明期**：剑心与天道相通，万物皆在心中明澈如画，剑未出而胜负已定
