# 一剑永恒

## 基本信息
- **功法名称**：一剑永恒
- **品级**：七阶（圣级）（圣级）
- **类型**：剑法功法
- **适用境界**：合体期
- **修习难度**：★★★★★

## 功法介绍

一剑永恒来自时间长河尽头的神秘剑修——"永恒剑主"。永恒剑主并非此界生灵，他来自未来，是末法时代最后一位剑修。在那个时代，天道崩塌、灵气枯竭，万物走向终结。永恒剑主在时间长河的尽头，用最后的力气挥出了最后一剑——这一剑不是为了杀敌，而是为了将剑道的火种送回过去，让它在灵气充沛的时代继续燃烧。

这一剑穿越了时间长河，落在了此界的一座无名山峰上，在石壁上留下了一道蕴含时间法则的剑痕。后世有缘人参悟此剑痕，逐渐复原出了"一剑永恒"这套蕴含时间之力的剑法。此剑法的核心是"凝刹那为永恒"——在一剑之中凝聚时间的力量，让这一剑的威力凝固在时间中永远不灭。正是因为这个原因，一剑永恒修炼到极致时，剑出之后不会消失，而是化作永恒存在的剑意。

## 功法特点

**优点：**
- 剑意永恒不灭，一剑可留存千年万年
- 蕴含时间之力，可短暂影响时间流速
- 剑出无悔，威力固定不可削减
- 可在空间中留下永恒剑痕用于守护

**缺点：**
- 修炼条件极端苛刻，需理解时间法则
- 出剑极慢（为了凝聚时间之力）
- 一剑之后需要很长时间恢复
- 对剑心的要求极高，不够纯粹者无法凝聚永恒剑意

## 功法等级

**刹那永恒**：能将一瞬间的剑意凝固在空中持续片刻，剑气不会消散

**时光凝固**：出剑时可令小范围的时间流速变慢，敌人陷入慢动作而自身不受影响

**永恒剑痕**：斩出的剑气化为永恒剑痕，可永久留在某处作为守护手段

**时间之主**：可在一定范围内自由操控时间流速，一剑可跨越过去未来

## 功法招式

1. **刹那芳华**：将一剑的威力压缩到一瞬间爆发，这一瞬的威力是正常状态下的十倍。

2. **时光逆流**：以剑斩开时间线，让小范围内的时间回到三息之前——可用于躲避必中的攻击。

3. **永恒枷锁**：剑气化为时间枷锁将敌人禁锢在原地，让敌人的时间停止流动。

4. **千载一剑**：凝聚千年功力于这一剑中——剑出之后在虚空中穿行千年，而后从过去的时间点斩向敌人。

5. **轮回之剑**：让敌人在一瞬间经历千百次生死轮回，耗尽对方的心神和寿元。

6. **永夜·永恒**：将自身化为永恒的存在，一剑出后剑意永存不灭，自身进入与天地同寿的状态。

## 修炼条件

**前置功法**：需要修习过时间类法术或有时间灵根的资质

**灵根要求**：时间属性变异灵根（极其罕见），或拥有剑心通明的剑道天赋

**修炼地点**：时间长河的分支节点、上古遗迹中时间流速异常的区域

**所需资源**：以时间之砂锻造的神剑，或承载过万年时光的古剑

## 使用限制/副作用

- 时间反噬极为可怕，一次失误可能导致自身时间线紊乱
- 使用时会在宿主的寿命中扣除相应的时间损耗
- 永恒剑意无法收回，一旦斩出便会永久存在于天地之间
- 此剑法有悖于时间法则的自然运行，天道会降下惩罚

## 相关典故

**无名山峰的剑痕**：传说在那座无名山峰上，有一道从远古就存在的剑痕。这道剑痕至今仍然散发着凛冽的剑意，任何靠近它的生灵都会看到自己过去的记忆。有人说道剑痕中封印着一剑——那是来自未来的永恒一剑，在等待着有一天它的主人回来取走。

## 修炼进度

**悟时期**：开始感知时间的流动，能在练剑时感受到时间的重量，约需十到二十年

**凝时期**：能将剑意凝固在时间中，一剑出后剑气不散，约需五十到百年

**控时期**：可短暂操控小范围的时间流速，加速自身或减速敌人，约需百年以上

**永恒期**：一剑永恒、万古不灭，自身与剑意共同化为时间长河中永不磨灭的存在
