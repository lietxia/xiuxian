# 基础剑诀

## 基本信息
- **功法名称**：基础剑诀
- **品级**：一阶（黄级）
- **类型**：剑法功法
- **适用境界**：聚气期
- **修习难度**：★☆☆☆☆

## 功法介绍

基础剑诀源自上古凡人剑修村落"青石村"的狩猎剑术。相传三千年前，青石村有一位名叫石破天的猎户，常年与山中凶兽搏斗，将日常劈柴、刺鱼、扫尘等动作化为剑式，代代相传，逐渐形成了一套质朴而实用的剑法。

此功法不讲花哨，不重招式变化，而是强调最根本的"劈、刺、扫、撩、点、崩"六大基本剑式。每一式都是千锤百炼的生存之道，是通往更高剑道的必由之路。青石村虽已湮灭在历史长河中，但基础剑诀却流传下来，成为无数剑修的启蒙功课。

## 功法特点

**优点：**
- 根基稳固，极难走火入魔
- 简单易学，对灵根资质要求极低
- 可融入任何高阶剑法作为根基
- 对体魄有显著的淬炼效果

**缺点：**
- 几乎没有远程攻击手段
- 威力有限，只适合近身搏杀
- 缺乏灵气运转法门，对高阶修士用处不大
- 招式朴素，容易被看破路数

## 功法等级

**剑形初成**：能够正确做出六大基本剑式，动作规范但不流畅，需刻意控制

**剑势渐生**：六大剑式收发自如，出剑时已具备一定的力道和气势

**剑意自生**：每一剑都蕴含质朴的剑意，返璞归真，简单的招式有了灵魂

**化繁为简**：将六大剑式融会贯通，任意变化皆在方寸之间，一劈一刺皆有千钧之力

## 功法招式

1. **劈山式**：自上而下的一记重劈，全身力道凝于剑刃一线，可劈开寻常巨石。看似简单，实则讲究腰马合一、力从地起。

2. **穿心刺**：直来直去的一记突刺，是最快的杀招。要求手腕稳定、身步合一，刺出的瞬间全身力量凝聚于剑尖一点。

3. **扫叶式**：横向挥扫，攻守兼备。扫剑之时以腰为轴，带动全身旋转，可同时攻击多个敌人。

4. **撩阴式**：自下而上的反撩，专攻下盘。此招出自猎户剖鱼的动作，角度刁钻，防不胜防。

5. **点星式**：以剑尖快速点击，精准打击敌人要害。讲究眼疾手快，腕力精准。

6. **崩剑式**：以剑身崩弹之力震开敌人兵器或暗器。是防守反击的妙招，需要极强的腕部爆发力。

## 修炼条件

**前置功法**：无，此乃剑道入门之根本

**灵根要求**：无任何灵根要求，凡人亦可修习

**修炼地点**：任意开阔场地，以山林野地为佳

**所需资源**：一柄普通铁剑即可，无需消耗灵石

## 使用限制/副作用

- 长期单独修习此功可能导致剑路僵化，需配合其他剑法灵活变通
- 过度追求力量而忽视技巧，容易损伤手腕和腰部筋骨
- 此剑诀注重外功，未曾涉及内息运转，需配合炼气功法一同修习

## 相关典故

**青石村剑祭**：相传每年秋收后，青石村都会举行"剑祭"仪式——全村剑士以基础剑式演练"百人同剑"，千人一同出剑时的气势足以惊退山中妖兽。此习俗一直延续到村落覆灭，至今仍有剑修在故地凭吊。

## 修炼进度

**启蒙期**：初握铁剑，学习六大基本剑式的动作要领，每日挥剑千次，耗时三至六个月

**磨砺期**：剑式熟练，开始在山林中与野兽实战，在实战中打磨剑法，耗时约一年

**贯通期**：六大剑式融会贯通，不再拘泥于固定招式，能以基础剑式应对大多数战斗情况

**大成期**：返璞归真，一劈一刺皆有剑意，为修习更高阶剑法打下最坚实的基础
