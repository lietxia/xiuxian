# 八卦阵

## 名称品阶

**八卦阵**，五阶高级阵法，属综合类。此阵以乾、坤、震、巽、坎、离、艮、兑八卦为基础，演化无穷变化。阵道有云："八卦之要，在于'变'字，变化无穷，困杀由心。"

## 阵法构成

- **阵眼**：太极石一枚（阴阳相济）
- **阵纹**：八卦纹各十二道，共九十六道
- **阵基**：八枚卦符，分镇八卦方位
- **辅助材料**：阴阳土二两，太极水三滴

## 布置方法

八枚卦符按方位布置：乾南、坤北、离东、坎西、兑东南、震东北、巽西南、艮西北。太极石置于正中，阴阳土调和绘制八卦纹。激活后八卦轮转，可演化六十四卦，变化无穷。布阵者需精通易理，否则难以驾驭诸多变化。

## 威力效果

- 八卦轮转，可演化六十四种变化
- 困、杀、幻、防四效兼备
- 可根据入阵者特性自动调整
- 覆盖范围：方圆百丈至千丈
- 持续时间：视布阵者易理修为而定

## 使用限制

- 布阵者需精通八卦易理，门槛极高
- 太极石难得，阴阳失衡则阵溃
- 变化多端但单项威力有限
- 对不通易理者效果更佳
- 维护复杂，需定期校准卦位

## 著名使用者/典故

传闻太上传人曾以八卦阵困住十万天兵，不伤一人却使其无法越雷池一步。又有阵道宗师诸葛武侯，以八卦阵为基础推演出八阵图，成为阵道经典。
