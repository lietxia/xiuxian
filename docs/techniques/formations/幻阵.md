# 幻阵

## 名称品阶

**幻阵**，五阶高级阵法，属辅助类。此阵不伤肉身，专攻心神，入阵者五感皆被蒙蔽，所见所闻皆为幻象。阵道有云："幻阵之要，在于'真'字，以假乱真方为大成。"

## 阵法构成

- **阵眼**：幻心玉一枚（需千年以上）
- **阵纹**：迷神纹二十四道，乱心纹十六道，虚实纹八道
- **阵基**：五枚幻灵幡，分镇五行方位
- **辅助材料**：迷魂香灰一两，蜃珠粉三钱

## 布置方法

幻阵之难，在于虚实相生。布阵者需先以幻心玉为核心，五枚幻灵幡按五行方位布置。阵纹绘制时需灌注神识，使纹路具有迷幻之效。激活后阵内自成幻境，入阵者深陷其中而不自知。高深者可将自身神识融入幻阵，实时调整幻象内容，使破绽全无。

## 威力效果

- 蒙蔽五感，制造以假乱真的幻境
- 可读取入阵者记忆，生成针对性幻象
- 心神不坚者永困幻境，直至神识枯竭
- 覆盖范围：方圆百丈至千丈
- 持续时间：视布阵者神识强度而定

## 使用限制

- 对神识强于布阵者之人效果大减
- 幻心玉极为珍贵，损毁后难以替代
- 布阵者需持续消耗神识维持
- 佛门修士因修心功法，对幻阵有天然抗性
- 阵眼暴露则幻境自破

## 著名使用者/典故

幻心宗曾以幻阵困住一位化神期大能长达三月，期间该大能浑然不知，直至神识耗尽方被擒获。又有幻道散修柳如烟，以幻阵幻化整座城池，骗过追兵耳目，传为佳话。
