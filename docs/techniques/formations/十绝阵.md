# 十绝阵

## 名称品阶

**十绝阵**，仙阵下品，属攻击类。此阵由十座小阵组成，座座绝命：天绝、地烈、风吼、寒冰、金光、化血、烈焰、落魂、红水、红砂。阵道有云："十绝之要，在于'绝'字，入阵绝路，十死无生。"

## 阵法构成

- **阵眼**：十绝珠一枚（十种天劫之力凝聚）
- **阵纹**：十绝纹各三十六道，共三百六十道
- **阵基**：十座阵台，各承一绝
- **辅助材料**：天劫液十滴，绝灵土三斤

## 布置方法

十绝阵需十位布阵者各主一阵，或一人精通十绝之术。十座阵台按特定方位布置，十绝珠置于中央枢纽。每座小阵需单独激活，最终合为一体，形成绝杀之局。布阵耗时极长，通常需七日方可完成。

## 威力效果

- 天绝阵：灭绝生机
- 地烈阵：地火焚身
- 风吼阵：罡风裂体
- 寒冰阵：冰封万物
- 金光阵：金光万道
- 化血阵：血肉消融
- 烈焰阵：三昧真火
- 落魂阵：魂魄离散
- 红水阵：腐骨消形
- 红砂阵：砂蚀元神
- 十阵合一，金仙难挡

## 使用限制

- 需十位布阵者或一人精通十绝
- 布阵耗时七日，期间不可中断
- 十绝珠需天劫之力凝聚，极难获取
- 每座小阵被破则威力递减
- 消耗资源巨大，非大战不可轻用

## 著名使用者/典故

截教十天君各主一阵，曾以十绝阵困杀阐教多位金仙，震动三界。燃灯道人率十二金仙齐出，方破十绝阵，可见其威。此战之后，十绝阵被列为截教十大杀阵之一。
