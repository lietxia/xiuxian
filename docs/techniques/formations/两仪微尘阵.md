# 两仪微尘阵

## 名称品阶

**两仪微尘阵**，仙阵中品，属综合类。此阵以两仪之气为基，生死幻灭尽在微尘之间。阵道有云："两仪之要，在于'生'字，生死轮转，一念之间。"

## 阵法构成

- **阵眼**：两仪珠一枚（阴阳相济）
- **阵纹**：两仪纹三十六道，微尘纹七十二道
- **阵基**：两枚生死符，分镇阴阳两极
- **辅助材料**：阴阳土二两，微尘砂三钱

## 布置方法

两枚生死符分镇阴阳，两仪珠置于正中。阴阳土调和绘制两仪纹，微尘砂撒于阵纹之上。激活后两仪之气轮转，阵内自成微尘世界，生死幻灭皆在布阵者一念之间。

## 威力效果

- 两仪之气轮转，可困可杀可幻
- 入阵者如入微尘世界，空间无限
- 生死轮转，可将生者转死，死者转生
- 覆盖范围：方圆百丈至千里
- 持续时间：视两仪珠品质而定

## 使用限制

- 两仪珠需阴阳平衡，失衡则阵溃
- 布阵者需精通阴阳之道
- 对纯阳或纯阴属性修士效果略减
- 微尘砂难得，需特殊炼制
- 生死轮转消耗极大，难以长时间维持

## 著名使用者/典故

蜀山派曾以两仪微尘阵镇压一头万年蛇妖，将其困于微尘世界之中，生生炼化。又有蜀山长老以两仪微尘阵困住一位大乘期魔修，生死轮转之下，魔修修为尽废。
