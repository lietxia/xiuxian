# 复合阵

## 名称品阶

**复合阵**，五阶高级阵法，属综合类。此阵将多种功能融于一体，攻防一体，妙用无穷。阵道有云："复合之要，在于'衡'字，五行相生，万法归一。"

## 阵法构成

- **阵眼**：五行灵珠各一枚（金木水火土）
- **阵纹**：基础聚灵纹、攻防纹、迷踪纹各若干
- **阵基**：九枚多功能阵桩，按九宫分布
- **辅助材料**：五行灵液各一滴，万法土三两

## 布置方法

复合阵之难，在于平衡。布阵者需精通多种阵法原理，将聚灵、攻击、防御、迷幻等纹路巧妙融合，不可有丝毫冲突。五行灵珠需按相生顺序布置，万法土调和诸纹。激活时需同时灌注五行真元，使诸阵同时运转而不互相干扰。

## 威力效果

- 聚灵效果：提升灵气浓度五成
- 攻击效果：可释放五行术法
- 防御效果：形成五行护盾
- 迷幻效果：扰乱入阵者方向感
- 可根据需要切换主攻方向
- 覆盖范围：方圆百丈至五百丈

## 使用限制

- 布阵者需精通多种阵法，门槛极高
- 五行灵珠缺一不可，损毁任何一颗则全阵崩溃
- 功能多但单项不如专精阵法
- 真元消耗巨大，难以长时间维持
- 维护复杂，需定期检查五行平衡

## 著名使用者/典故

万法宗宗主曾以复合阵独战三位同阶修士，攻防转换间游刃有余，最终耗死对手。此战之后，复合阵被列为万法宗核心传承，非真传弟子不得修习。
