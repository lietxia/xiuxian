# 传送阵

## 名称品阶

**传送阵**，五阶高级阵法，属空间类。此阵可撕裂虚空，将生灵瞬间传送至万里之外。阵道有云："传送之要，在于'定'字，坐标差之毫厘，谬以千里。"

## 阵法构成

- **阵眼**：空冥石一枚（品质决定传送距离）
- **阵纹**：空间纹三十六道，定位纹十二道，稳固纹八道
- **阵基**：两枚定界碑，分置起点与终点
- **辅助材料**：虚空液三滴，星砂一两
- **可选增幅**：破空晶石八枚（可稳定空间通道）

## 布置方法

传送阵需成对布置，起点终点各一座。先以定界碑确定坐标，再以空冥石为眼，绘制空间纹。虚空液需均匀涂抹于阵纹之上，激活时需大量真元撕裂空间壁障。两座传送阵需事先校准坐标，稍有偏差便可能将人送入虚空乱流，尸骨无存。布阵完成后须先以灵兽试传送数次，确认通道稳定方可载人。

## 威力效果

- 瞬间传送生灵至万里之外
- 高品质空冥石可传送十万里
- 传送过程约三息，期间有轻微眩晕感
- 可传送活物、死物，但活物需有修为护体
- 每次传送后需冷却一炷香方可再次使用
- 高阶传送阵一次可传送百人，且传送过程平稳

## 使用限制

- 需成对布置，单座无法使用
- 空冥石珍贵，品质参差不齐
- 空间不稳定区域（如秘境）无法使用
- 传送过程中若阵被破坏，可能坠入虚空
- 每次传送消耗大量灵石
- 对传送者修为有最低要求（筑基以上）
- 传送者落地后有短暂眩晕期，修为越低眩晕越长

## 破阵之法

传送阵本身无攻防之能，破坏定界碑或空冥石即可使其失效。若在传送过程中攻击阵台，空间通道可能崩塌，届时阵中所有人将被卷入空间乱流，尸骨无存。故传送阵通常建在宗门深处，重兵把守。

## 著名使用者/典故

空间殿以传送阵网络闻名修真界，其遍布各地的传送阵极大促进了修士间的交流。传闻上古时期，传送阵网络覆盖整个修真界，后因大战损毁大半，如今仅存寥寥数座完好。天机阁曾建立覆盖整个修真界的传送网络，设有传送节点三千六百处，修士只需支付灵石即可穿行天下。
