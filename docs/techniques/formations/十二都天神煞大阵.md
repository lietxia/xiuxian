# 十二都天神煞大阵

## 名称品阶

**十二都天神煞大阵**，神级阵法，乃巫族护族大阵。此阵以十二祖巫精血为引，凝聚盘古真身，力可开天。阵道有云："都天之要，在于'力'字，以力破法，一力降十会。"

## 阵法构成

- **阵眼**：盘古之心（或十二祖巫精血替代）
- **阵纹**：都天纹十二道，各应一位祖巫
- **阵基**：十二杆都天神煞幡，各承一祖巫之力
- **辅助材料**：祖巫精血各一滴，混沌土三斤
- **可选增幅**：盘古精血一滴（可大幅提升真身凝聚度）

## 布置方法

十二杆都天神煞幡按十二祖巫方位布置：帝江（空间）、句芒（木）、祝融（火）、蓐收（金）、共工（水）、玄冥（雨）、强良（雷）、烛九阴（时间）、天吴（风）、翕兹（电）、奢比尸（土）、后土（土）。布阵者需以祖巫精血激活各幡，十二幡共鸣，凝聚盘古真身。

## 威力效果

- 凝聚盘古真身，力可开天
- 一击之下，圣人亦需退避
- 可撕裂虚空，破碎法则
- 覆盖范围：方圆万里至一界
- 持续时间：视祖巫精血品质而定
- 以力破法，一力降十会，无物可挡

## 使用限制

- 需十二祖巫精血，极难获取
- 布阵者需有巫族血脉，否则无法激活
- 盘古真身凝聚后难以控制，易伤己方
- 每次使用后神煞幡需温养千年
- 祖巫精血有限，不可再生
- 对使用者肉身要求极高，否则反噬身亡

## 破阵之法

破十二都天神煞大阵需打断十二幡的共鸣，使盘古真身无法凝聚。或以圣人之力对抗盘古真身，但亦需付出代价。若十二祖巫中有人陨落，其所主之幡失效，阵法威力大减。

## 著名使用者/典故

巫妖大战中，十二祖巫布都天神煞大阵，凝聚盘古真身，与妖族周天星斗大阵对撞。那一战天崩地裂，十二祖巫陨落其六，妖族亦元气大伤。此后巫族衰落，此阵几近失传，后世再无人能复现。
