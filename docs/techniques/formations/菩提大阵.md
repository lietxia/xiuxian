# 菩提大阵

## 名称品阶

**菩提大阵**，仙阵上品，属辅助类。此阵以菩提心为引，佛光普照，可度化众生，亦可降魔伏妖。阵道有云："菩提之要，在于'度'字，普度众生，回头是岸。"

## 阵法构成

- **阵眼**：菩提子一颗（万年菩提树所结）
- **阵纹**：菩提纹三十六道，佛光纹二十四道
- **阵基**：八枚金刚桩，分镇八方
- **辅助材料**：佛光砂二两，菩提露三滴
- **可选增幅**：舍利子一枚（可大幅增强佛光威力）

## 布置方法

八枚金刚桩按八方布置，菩提子置于中央。佛光砂沿菩提纹铺设，菩提露滴于菩提子之上。激活后佛光普照，菩提之力弥漫，入阵者如沐春风，戾气渐消。布阵者需有菩提心，心存慈悲，否则阵法反噬。若得舍利子加持，佛光威力倍增。

## 威力效果

- 佛光普照，普度众生
- 可消除入阵者戾气、执念
- 对魔修有天然克制，可净化魔气
- 可治愈心神创伤，修复神魂
- 覆盖范围：方圆千里至万里
- 持续时间：视菩提子品质而定
- 普度众生，回头是岸，魔气消散

## 使用限制

- 需万年菩提树所结菩提子，极难获取
- 布阵者需心存慈悲，杀心重者无法布阵
- 对心志坚定者效果有限
- 魔修可抵抗佛光净化
- 菩提子每用一次便损耗一分
- 需持续消耗佛力维持

## 破阵之法

菩提大阵以慈悲为念，若布阵者心存慈悲，阵法便无破绽可寻。若以杀心入阵，佛光反噬，布阵者先受其害。魔修可以魔力对抗佛光，但需付出极大代价。若菩提子被夺，阵法自溃。

## 著名使用者/典故

西方佛教圣人曾以菩提大阵度化十万天魔，使其弃恶从善，传为佳话。又有佛门高僧以菩提大阵净化一方魔土，使其重归净土，功德无量。此阵成为佛门标志性阵法，高僧出行常布此阵以度化众生。
