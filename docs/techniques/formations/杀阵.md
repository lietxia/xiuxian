# 杀阵

## 名称品阶

**杀阵**，五阶高级阵法，乃攻击类阵法之正宗。此阵以天地杀伐之气为引，凝聚庚金之芒，入阵者如千刀万剐，不死不休。阵道有云："杀阵之要，在于'绝'字，绝其生路，断其退路。"

## 阵法构成

- **阵眼**：杀伐石一枚（需饮血开锋）
- **阵纹**：庚金纹三十六道，绝杀纹十二道
- **阵基**：七枚杀剑桩，按北斗方位排列
- **辅助材料**：庚金粉末三两，煞气凝液五滴
- **可选增幅**：杀道本源一滴（可大幅提升杀伤力）

## 布置方法

杀阵凶险，布阵时需先以自身精血点化杀伐石，使其认主。七枚杀剑桩需以庚金粉末淬炼后打入地下。阵纹绘制时需灌注杀意，心慈手软者阵必不成。激活后阵内庚金之气凝聚为无形剑芒，绞杀一切生灵。战时布阵可省略杀剑桩，直接以阵旗代桩，虽威力降三成，但布阵速度极快。

## 威力效果

- 凝聚庚金剑芒，无形无质却锋利无匹
- 剑芒密度随时间递增，越久越凶
- 金丹期以下修士入阵，百息之内必死
- 元婴期修士可支撑一炷香，但持续消耗下亦难逃
- 覆盖范围：方圆五十丈至两百丈
- 攻击密度随时间推移越来越强，直至灵石耗尽

## 使用限制

- 布阵者需有杀意，心性纯善者难以发挥威力
- 杀伐石每用一次便损耗一分，十次后碎裂
- 阵成之后敌我不分，己方人员亦会遭殃
- 对体修效果略逊，强横肉身可部分抵御
- 煞气反噬风险：长期使用易影响心性
- 消耗之巨冠绝各类阵法，非富家不可轻用

## 破阵之法

破杀阵需从外部攻击阵眼杀伐石，或以防御类法宝抵挡剑芒，寻机破坏杀剑桩。若已入阵，需以最快的速度找到阵眼并摧毁之。杀阵一旦启动不可逆转，必须等灵石耗尽或阵基被毁方可停止。

## 著名使用者/典故

杀神殿殿主曾以杀阵困杀四位同阶仇敌，一战成名。然其晚年杀阵反噬，走火入魔，令人唏嘘。又有剑修白眉，将杀阵融入剑域，创"剑杀阵"一脉，攻伐之力更胜原版。散修血杀老祖以杀阵纵横修真界五百年，其成名绝技"血海滔天阵"曾在一夜间屠尽三个中型宗门。
