# 七星阵

## 名称品阶

**七星阵**，三阶中级阵法，属攻击类。此阵引动北斗七星之力，天枢、天璇、天玑、天权、玉衡、开阳、摇光各司其位，星辰之力灌注阵中。阵道有云："七星之要，在于'引'字，借天之力，伐不敬。"

## 阵法构成

- **阵眼**：星陨石一枚（需夜间采取）
- **阵纹**：七星纹各七道，共四十九道
- **阵基**：七枚星桩，按北斗方位排列
- **辅助材料**：星砂二两，夜光石粉末一钱

## 布置方法

需于晴朗夜空下布阵，七枚星桩按北斗七星方位打入地下。星陨石置于天枢位为眼，星砂绘制七星纹。布阵时需感应星辰之力，于子时激活，引星光入阵。若逢阴雨或星辰隐没，阵法威力大减。

## 威力效果

- 引动北斗星辰之力，凝聚星芒杀敌
- 七星依次亮起，威力递增
- 第七星摇光激活时，威力达到顶峰
- 对邪祟、魔修有额外克制
- 覆盖范围：方圆五十丈至三百丈

## 使用限制

- 需夜间布阵，白天威力减半
- 阴雨天气几乎无法使用
- 星陨石难得，品质参差不齐
- 布阵者需有星辰感应天赋
- 每次使用后星桩需重新淬炼

## 著名使用者/典故

星宫弟子以七星阵闻名，夜间作战几近无敌。传闻星宫长老曾以七星阵轰杀一位同阶魔修，星光贯穿其躯，形神俱灭。又有散修观北斗悟道，自创七星步法，与七星阵配合，攻防一体。
