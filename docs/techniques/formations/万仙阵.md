# 万仙阵

## 名称品阶

**万仙阵**，仙阵上品，属综合类。此阵需万仙合力布成，汇聚万仙之力，攻防一体，妙用无穷。阵道有云："万仙之要，在于'合'字，万众一心，其利断金。"

## 阵法构成

- **阵眼**：万仙旗一面（凝聚万仙意志）
- **阵纹**：万仙纹三百六十五道，对应周天
- **阵基**：万仙桩一万枚，各承一仙之力
- **辅助材料**：万灵血一两，聚仙土三斤

## 布置方法

万仙阵需万名修士同时布阵，各据一位，将真元注入万仙桩。万仙旗居中调度，汇聚万仙之力。布阵时需万众一心，心有杂念者反遭阵力反噬。布阵耗时约一个时辰，需提前演练配合。

## 威力效果

- 汇聚万仙之力，攻防一体
- 攻击时可释放万仙合力一击
- 防御时可分担伤害至万仙
- 阵中修士可互相支援，真元共享
- 覆盖范围：方圆十里至百里
- 持续时间：视万仙真元总量而定

## 使用限制

- 需万名修士同时布阵，极难组织
- 万仙旗为核心，损毁则全阵崩溃
- 布阵者需配合默契，临时拼凑难以发挥
- 心有异念者会扰乱阵力
- 消耗真元巨大，难以长时间维持
- 万仙伤亡过半则阵法威力大减

## 著名使用者/典故

截教教主通天教主曾布万仙阵迎战阐教，万仙齐聚，气势惊天。然阐教请来西方二圣，四圣合力方破万仙阵。此战截教元气大伤，万仙阵成为绝响。
