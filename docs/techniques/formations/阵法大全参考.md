## 八、阵法体系说明

### 阵法品阶（《二次封仙》体系）
| 品阶 | 对应能力 | 说明 |
|------|---------|------|
| 法阵 | 阵道入门 | 基础阵法，如流沙阵、灵盾阵 |
| 灵阵 | 阵道小成 | 引动天地灵气，如五行惊雷灵阵 |
| 宝阵 | 阵道大成 | 蕴含宝物之力，如七杀护宝大阵 |
| 道阵 | 阵道宗师 | 蕴含大道法则，如护宗大阵级别 |
| 仙阵 | 阵道仙师 | 传说级别，蕴含仙界法则 |

### 阵法四大分类
1. **杀阵**：以击杀敌人为主，煞气极重，通常留有一处生门。威力最大但最好破
2. **困阵**：以困住敌人为目的，内含无数禁制，可吸收闯阵者灵气削弱其实力
3. **幻阵**：以迷惑敌人为主，制造幻象让人沉沦迷失
4. **辅阵**：辅助功能，如聚灵阵、传送阵、浮空阵等

### 炼阵师体系
- 炼阵师 = 阵法师 + 炼器师结合体
- 将阵法融合在炼器之中，炼制出**布阵器具**
- 布阵器具包含：**阵盘**（灵魂/心脏）+ **阵旗**（按方位布置）+ **玉简**（使用说明）
- 高级布阵器具极为稀有，可遇不可求

### 上古 vs 今世阵法差异（《仙路之险》设定）
- **上古阵法**：删繁就简、依势而行，依赖天然地势与灵气脉动，无需外物
- **今世阵法**：仰仗外物、步骤繁复，高度依赖演阵盘、布阵旗等器物
