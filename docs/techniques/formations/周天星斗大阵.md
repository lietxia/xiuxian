# 周天星斗大阵

## 名称品阶

**周天星斗大阵**，神级阵法，乃上古妖族天庭护族大阵。此阵引动周天三百六十五颗主星之力，星辰之力倾泻而下，毁天灭地。阵道有云："星斗之要，在于'天'字，借天之威，行天之道。"

## 阵法构成

- **阵眼**：混沌钟（先天至宝）
- **阵纹**：星辰纹三百六十五道，对应周天主星
- **阵基**：三百六十五杆星辰幡，各应一星
- **辅助材料**：星辰之精三两，混沌土一斤

## 布置方法

三百六十五杆星辰幡按周天星位布置，混沌钟居中调度。布阵者需感应周天星力，于特定时辰激活对应星辰幡。每杆星辰幡需提前温养，与对应星辰建立联系。阵成之时，周天星辰之力倾泻而下，如银河倒悬。

## 威力效果

- 引动周天三百六十五颗主星之力
- 星辰之力凝聚为星光、星芒、星剑
- 一击可灭一界，圣人亦需退避
- 可封锁空间，使敌人无处可逃
- 覆盖范围：方圆万里至一界
- 持续时间：视星辰幡温养程度而定

## 使用限制

- 需混沌钟为阵眼，否则无法引动星辰
- 三百六十五杆星辰幡缺一不可
- 布阵者需有妖族血脉，否则难以感应星辰
- 每次使用后星辰幡需重新温养百年
- 星辰之力狂暴，布阵者易遭反噬
- 需特定天时，非随时可用

## 著名使用者/典故

上古妖帝帝俊与东皇太一布周天星斗大阵，守护天庭，威震洪荒。巫妖大战中，此阵与十二都天神煞大阵对撞，天崩地裂，两败俱伤。此后周天星斗大阵失传，仅存残篇。
