# 九宫阵

## 名称品阶

**九宫阵**，五阶高级阵法，属控制类。此阵依河图洛书之理，戴九履一，左三右七，二四为肩，六八为足，五居中央。阵道有云："九宫之要，在于'位'字，各得其位，天地有序。"

## 阵法构成

- **阵眼**：洛书石一枚（刻有洛书图案）
- **阵纹**：九宫纹各九道，共八十一道
- **阵基**：九枚宫位符，按九宫分布
- **辅助材料**：河图土二两，定位砂三钱
- **可选增幅**：河图残片（可增强空间分割效果）

## 布置方法

九枚宫位符按洛书数理布置：一居北，二居西南，三居东，四居东南，五居中，六居西北，七居西，八居东北，九居南。洛书石置于中央五之位，河图土调和绘制九宫纹。激活后九宫自成空间，入阵者如入迷宫，方位全乱。布阵者需精通河图洛书数理，否则难以驾驭。

## 威力效果

- 九宫空间自成，入阵者方位感全失
- 可将敌人分割至不同宫位，各个击破
- 中央五之位为阵眼所在，控制全局
- 覆盖范围：方圆百丈至五百丈
- 持续时间：视洛书石品质而定
- 九宫轮转，入阵者如陷无尽迷宫

## 使用限制

- 洛书石需与河图土配合，缺一不可
- 布阵者需精通河图洛书数理
- 对空间天赋高者效果略减
- 九宫需同时激活，有一宫不成则全阵不稳
- 中央五之位最脆弱，需重点保护
- 布阵耗时较长，不适合临时应战

## 破阵之法

破九宫阵需找到中央五之位，此为阵眼所在。或以蛮力同时攻击多处宫位符，使其首尾难顾。若布阵者修为不足，九宫转换间有破绽，可趁此时机突入阵眼。精通河图洛书者可推算宫位变化规律，找到生门。

## 著名使用者/典故

河图洛书一脉传人曾以九宫阵困住一位化神期修士，将其分割于九宫之中，逐个击破其分身。此战之后，九宫阵被列为河图洛书一脉核心传承。后世阵法师参悟九宫之理者，无不获益良多。
