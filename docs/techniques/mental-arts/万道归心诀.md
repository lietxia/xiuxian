# 万道归心诀

## 基本信息
- **功法名称**：万道归心诀
- **品级**：九阶（混沌级）
- **类型**：心法功法
- **适用境界**：渡劫期
- **修习难度**：★★★★★

## 功法介绍

万道归心诀，乃上古混沌纪元之初，第一位以力证道之人——"元始心帝"坐化前所留。传闻元始心帝观天地万道运转，见日月星辰各循其轨，草木枯荣各有其时，遂悟得"万法不离其宗，万道终归一心"之理。此功法非以术胜，乃以心御万道，将天地间一切法则、道韵、元气尽数炼入一颗道心之中。

元始心帝曾言："天地虽大，道虽万千，若能归于一念，则一念可破万法。"万道归心诀的修行，便是将这"一念"不断淬炼，直至心力足以撼动天道本身。此法传出后，历代仅有七人修至大成，每一人都曾是一方主宰，但至今无人真正修至圆满——因其圆满之境，需以心代天，那已非修士所能及。

## 功法特点

**优点：**
- 万法归宗：修至深处，可将敌方法术化为己用，一法破万法
- 心化天地：道心之坚韧远超同阶，心魔不侵，幻术不惑
- 道韵共鸣：举手投足间引动天地道韵，修行效率惊人
- 一念改命：道心足够强大时，可窥见命运长河，甚至拨动因果

**缺点：**
- 入门极难：需先废去自身所有功法根基，从零开始，九成九修士不敢尝试
- 孤寂无比：修行此诀者须斩断尘缘，独坐枯禅百年方有小成
- 心性考验：每日需直面自身最深的恐惧与欲望，稍有动摇便道心崩碎
- 天地所忌：此功法太过逆天，修行者每突破一境便会引来天道反噬

## 功法等级

**观道境**：以道心感知天地万道，如盲人摸象，一日仅能观一瞬道韵，此境修士常常呆坐数月不动，看似痴傻，实则神游道海。

**融道境**：将所观之道与自身神魂融合，体内开始凝聚"心之道种"，此时修士一言一行皆有道意，行走间草木俯首，鸟兽噤声。

**御道境**：以心御道，天地法则开始听从号令，可一念令江河倒流，一念让花开顷刻。但每用一次，道心便承受天地反噬。

**归心境**：万道归一，心即天道。此境之下，修士自身便是一方天地的法则本身。举手投足皆为道，开口闭口皆成法。

## 功法招式

1. **归心引**：将周身逸散的真元尽数收回心窍，化作一枚"心印"。心印一成，方圆百里的灵气皆受牵引，如百川归海般涌入体内。修道者修行一日，等于常人百日之功。

2. **万道化一**：以道心感应敌方功法的"道根"，将其分解为最基本的道韵碎片，再以自身心意重新编织，化为己用。传说修至极致，连天道降下的劫雷都能被化去。

3. **心剑无痕**：以心意凝练一道无形无质之剑，不以灵力催动，不以神识锁定，杀念起时，剑已在敌人体内。此剑无视任何护体罡气、法宝防御，唯以心防心。

4. **道心种念**：将自身一缕道念种入他人心湖之中，被种念者浑然不觉，但从此一言一行皆受种念者影响。此念无声无形，连搜魂大法也无法察觉。

5. **归元大寂灭**：将道心压缩至极限，化作一颗微型奇点，再猛然爆发。此招一出，方圆千里一切法则崩坏，灵气化为虚无，敌人在法则真空中如鱼失水，任人宰割。但此招之后，施术者道心碎裂，百年内无法动用任何神识。

## 修炼条件

**前置要求**：必须曾经达到合体期以上境界，拥有完整的道心根基，否则无法承载万道归一的冲击。

**心性要求**：需经历过至少三次情劫、杀劫或魔劫，且未在心魔面前崩溃——只有千锤百炼的道心，才配承载万道。

**灵根要求**：天灵根为佳，但万道归心诀不挑灵根属性，因其化万道为己用，任何灵根都可修行。然而废灵根修行速度极慢，通常需要千年以上。

**修炼地点**：混沌虚空边缘的"归道崖"，那里天道法则最为薄弱，便于修士以心取而代之。若在凡间修行，每突破一阶便会引发天崩地裂。

**所需资源**：至少三枚"混沌道果"、一壶"鸿蒙初水"，以及一件先天灵宝作为心印的载体。这些资源任何一件都足以让大乘期修士拼命争夺。

## 使用限制/副作用

- **每次动用"御道"之力后，道心会碎裂出一道裂痕，最多碎裂九次，第十次便是道心彻底崩毁之日。**
- **修至"归心境"后，修士将逐渐失去"人"的情感。七情六欲如观画中烟云，再真实也与己无关。曾有高僧修此法千年，见爱子死于眼前，竟微笑曰"生死如梦，何须挂怀"。**
- **若在突破时被外力打断，修士的"心"会在瞬间失去与天地的联系，从此沦为活死人——肉身不死，神魂永困虚无。**
- **道心一旦种下"万道之基"，便无法再修行任何其他功法。若废功重来，必遭万道反噬，形神俱灭。**

## 相关典故

**典故一·元始心帝坐化**：元始心帝创此功法后，于归道崖上坐化。坐化前，他将自身道心化作一块石碑，碑上无字，唯有心念可感。据说那石碑至今仍在归道崖顶，每万年显化一次，能引动石碑共鸣者，便是下一任万道归心诀的传承者。

**典故二·七心渡劫**：太古年间，七位修行万道归心诀的大能同时渡劫，天道降下九九天劫，天雷化作九条紫龙围攻七人。七人以心相连，化作一座"七星归心阵"，硬生生将九天劫雷炼化为己用，最终七人同时飞升。此事震惊三界，从此万道归心诀被尊为"万法之祖"。

**典故三·疯帝**：三千年前，一位名为"李太虚"的修士修至"御道境"后走火入魔，道心扭曲，将自身一万八千道心念散入凡间，附身于凡人身上。从此天下多了一万八千个"李太虚"，每一个都以为自己才是本体。至今仍有修士声称在某处见过"李太虚"——他们可能是凡人、可能是妖兽、甚至可能是一块石头。

## 修炼进度

**入门·心开一窍**：感应到道心的存在，能在须臾间进入"空灵之境"。此时修士会发现自己能听到花草的"心声"，但每次倾听都会头痛欲裂。此阶段通常需要三到五年。

**初窥·心窍九转**：道心初成，能将九条天地道韵纳入心窍。修士会在梦中看到天地初开的景象，醒来后浑身毛孔渗出黑色杂质——那是道心排出的"凡念"。此阶段约需三十年。

**小成·心湖初成**：道心化作一汪心湖，可映照天地方圆。修士从此无需肉眼视物——心湖所映，比肉眼所见更真实。但心湖中也会映出修士心中最深的恐惧，日日相伴。此阶段约需百年。

**大成·心海无涯**：心湖化作无边心海，一念可覆盖一界。修士此时已能窥见命运长河的碎影，但看到的越多，越是明白自身的渺小。此阶段约需五百年。

**圆满·心即天道**：万道归心，心代天道。至此修士已与天地同寿，但也不再是"人"。自元始心帝以来，无一人真正修至圆满——或许"圆满"本身，便是一个不能抵达的境界。
