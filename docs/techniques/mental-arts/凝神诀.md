# 凝神诀

## 基本信息
- **功法名称**：凝神诀
- **品级**：二阶（玄级）
- **类型**：心法功法
- **适用境界**：筑基期
- **修习难度**：★★☆☆☆

## 功法介绍

凝神诀，源自上古器修宗门"天工宗"的镇派心法之一。天工宗以炼器闻名于世，门中弟子日夜对着炉火，一坐便是数月甚至数年。淬炼法器时心神稍有涣散，便前功尽弃。为了让弟子在长时间的炼器过程中保持专注，天工宗第三代宗主"凝铁真人"融汇了佛门禅定与道门守一之法，创立了这部凝神诀。

凝铁真人年轻时是个性急如火的人，炼器百炼百败，气得他砸了九十九个炼器炉。第一百个炉子砸碎之后，他坐在废墟中突然悟了——不是炉子不对，不是材料不好，是他的心太躁。于是他跑到后山悬崖上，对着瀑布一坐三年，任水花溅身纹丝不动。三年后他下山，随手捡起一块废铁炼了三日，炼出一柄灵器——便是后来名震修真界的"凝铁剑"。

凝神诀的核心思想是"将散乱的心神凝聚成一根针"。普通修士的神识像一盆水，泼出去就是一片，看似覆盖范围广，实则力量分散。而凝神诀将神识反复压缩、千锤百炼，最终化作一根无形之针——刺得又准又狠又深。这一针，可以刺穿同阶修士的神识防御，可以看穿阵法的最薄弱节点，甚至可以在炼器时将杂质从法宝内部一针一针地挑出来。

## 功法特点

**优点：**
- 专注力暴增：修至小成后，修士可以在任何事情上保持极致的专注，效率远超同阶
- 神识精炼：虽不增加神识总量，但神识的"质"远胜常人，如同铁与钢的区别
- 破幻破阵：凝神诀练出的"凝神之针"天然克制幻阵迷阵，可以在万花筒中找到唯一的真实
- 炼器炼丹加成：修炼此诀后再炼器炼丹，对火候和时机的掌控精细入微，成品率大幅提升

**缺点：**
- 视野变窄：长期保持高度专注会让修士习惯性地忽略周围环境，容易被人偷袭
- 难以分心：无法同时处理多件事情，战斗时会因为太过专注于一个目标而露出破绽
- 精神疲惫：极度专注后会有强烈的精神疲惫感，如同连跑三天三夜一样
- 容易钻牛角尖：遇到解不开的问题时会死磕到底，不知变通，曾有人为了解锁一个初级阵法困了自己整整七十年

## 功法等级

**针芒境**：神识初步凝聚成形，如同一根细针。此时修士可以清晰感知到周围环境中微弱的灵力波动，如同盲人戴上了眼镜。此境修士最明显的变化是——看书一目十行且过目不忘。

**淬火境**：对凝练后的神识进行"淬火"强化，如同将锻打的铁器浸入冷水中。此过程极其痛苦，如同用烧红的针在识海中搅动。熬过此境，神识之针便有了"钢性"，不易折断。

**千丝境**：将一根神识之针分裂成千丝万缕，每一缕都保持同样的精炼度。此境大成者，可以同时操控上千根神识之丝，织成一张大网，覆盖百里方圆。天工宗的顶级炼器师便是用这种方法来同时监控几十个炼器炉的。

**归元境**：千丝归元，万法归一。神识不再分为千万缕，而是在需要时瞬间凝聚成一束，不需要时自然散开回归常态。至此境界，凝神诀才算真正圆满。

## 功法招式

1. **闭门造车**：在识海中构建一个封闭的"精神工坊"，将全部心神封锁其中，外界一切声响、气味、干扰都被隔绝在外。此状态下修士对外界完全失去感知，但精神力高度集中，可以思考最复杂的问题。初学时只能维持一炷香时间，大成后可连续数月不出。

2. **悬丝诊脉**：将一缕凝练过的神识探入他人体内，如丝线般游走经脉丹田，感知对方的灵气运行状态。此法可用于探查暗伤、诊断经脉堵塞，甚至可以用来追踪对手的真元波动——只要被探过的人，千年之内都逃不过你的神识追踪。

3. **天眼微视**：将凝神之力汇聚于双目，可以看到微观层面的东西。比如看到法器内部的阵纹走向、看到丹药内部的药力融合状态、看到灵脉中灵气流动的精确轨迹。这是炼器师和炼丹师最梦寐以求的能力。

4. **穿心针**：将神识之针迅猛射出，直刺敌方识海。这一招无声无息，无视物理防御，专破神魂防御罩。若对方神识强度不如你，中者会瞬间失神三息——高手对决中，三息足以定生死。

5. **千丝缚魂**：上千根神识之丝同时射出，将对方的神魂牢牢缠住。被缚者会感到如同被蜘蛛网粘住一般，神识无法外放，念头难以转动。此招消耗极大，通常作为底牌使用。

## 修炼条件

**前置功法**：需要先修炼任意一门基础心法至圆满，确保识海稳固。因为凝神诀对识海的冲击极大，识海不稳者强行修炼，会把脑子变成一锅粥。

**心性要求**：需要有极强的耐心和定力。凝神诀的修炼过程极其枯燥——就是反复地凝聚、分散、再凝聚、再分散，如同在磨刀石上来回磨同一把刀，连续磨上十年。

**灵根要求**：金属性或水属性灵根为佳，因为这两类灵根天然具有"凝聚"和"柔韧"的特性。火属性灵根修士修炼此法会事倍功半——火性发散，与凝神之道相悖。

**修炼地点**：安静的密室为最佳。凝神诀最忌讳被打断——若在凝聚神识之针时受到惊吓，针会断在识海中，轻则头痛三月，重则识海受损。因此有经验的凝神诀修士都会在自己的修炼密室周围布置隔音阵法。

**所需资源**：需要一些安神定魂的丹药辅助，如"定神丹""凝魂香"等。另外需要一件"精神容器"类法器——比如天工宗特制的"玄铁护额"，可以帮助修士在识海中固定神识之针的位置。

## 使用限制/副作用

- **识海疲劳**：过度使用凝神诀会导致识海干涸，修士会觉得头痛欲裂、眼前发黑、耳鸣不止。严重时会导致暂时性失明或失聪。通常每使用两个时辰就需要休息一个时辰。
- **性格偏执**：长期修炼凝神诀会让修士变得固执、偏执、听不进劝。这是因为神识长期处于高度凝聚状态，性格也会随之变得"尖锐"。天工宗的炼器师个个都是出了名的倔脾气，十头牛都拉不回来。
- **钻牛角尖症**：此功法的典型后遗症——遇到难题时不会变通，只会死磕到底。历史上曾有凝神诀修士为了参悟一道阵法的解法，把自己关在密室中七十年没出来，最后饿死在里面（金丹期修士也需要进食）。
- **情感迟钝**：神识被过度训练后，修士对情感的感知会变得迟钝。大笑时笑不出声，大哭时流不出泪——并非无情，而是情感被神识的"精准控制"压抑了。凝铁真人晚年时，连自己的儿子站在面前都认不出来，因为他已经习惯了"看"而不"看"。

## 相关典故

**典故一·凝铁真人的瀑布**：凝铁真人当年坐于瀑布之下修炼凝神诀，三年间一动不动，青苔爬满了他的身体，小鸟在他头顶筑巢。三年后他睁眼的瞬间，瀑布竟然停滞了三息——这不是什么法术，而是他的凝神之力太过强大，连天地都为之凝滞了一瞬。

**典故二·天工宗的"睁眼瞎"**：天工宗历史上曾有七位长老因为修炼凝神诀过度，神识变得空前强大，肉眼的视力却彻底退化了。他们行走时需要以神识探路，但在神识无法穿透的地方（比如有禁神阵法的地方），他们就会像瞎子一样跌跌撞撞。宗内的弟子暗地里叫他们"睁眼瞎长老"。

**典故三·穿心针的传说**：两千年前，天工宗一位金丹期修士遭遇化神期妖兽追杀。他自知必死，将全身所有神识灌入一根穿心针中，拼死射出。那根穿心针洞穿了妖兽的护体妖气，刺入了它的识海深处——那化神妖兽当场昏迷了整整三天。虽然后来那修士还是被妖兽的肉身本能拍死了，但"金丹杀化神"的传奇至今仍在修真界流传。

## 修炼进度

**入门·识海凝丝（三月）**：能够在识海中凝聚出一缕细细的神识之丝，维持时间从一息逐渐延长到一炷香。此阶段修士会感到头疼欲裂，因为识海正在被重塑。

**初窥·一眼看穿（一年）**：可以透过一块灵石的表面看到内部杂质分布。此时修士再去炼器坊看师傅们炼器，便能看出很多以前看不懂的门道。

**小成·千丝齐发（五年）**：可以同时操控上百根神识之丝，布置简单的神识网络。修士此时已经可以轻松地一心二用，一边炼丹一边看书。

**大成·凝神化针（二十年）**：神识彻底凝聚成一枚无形之针，收发由心，快如闪电。此时修士的神识已可刺穿三阶以下的阵法，视野中一切物品都呈现出"内部结构"的轮廓。

**圆满·万法归针（五十年）**：千丝万缕聚散自如，一念之间可化为大网也可化为细针。修士的识海中悬浮着一枚金色的"神针"，那是凝神诀的实体化象征。至此，修士的专注力已经达到非人的程度——可以一边处理千件琐事，一边思考一道最复杂的炼器难题。不过此时的修士往往已经不像"人"了。
