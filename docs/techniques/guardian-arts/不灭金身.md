# 不灭金身

## 基本信息
- **功法名称**：不灭金身
- **品级**：八阶（帝级）
- **类型**：护法功法
- **适用境界**：大乘期
- **修习难度**：★★★★★

## 功法介绍

不灭金身并非正统修仙法门，其源头可追溯至远古魔神战争时期。当时一尊名为"荒"的上古魔神被诸天仙帝联手斩杀，但其肉身历经万年不腐，反而吸收天地煞气自行进化。一位胆大包天的散修以此魔躯为蓝本，创出了这门以"血肉不灭"为核心的惊世功法。

此功法的修炼理念与传统防御功法截然相反——不求"不被击中"，而求"击中后瞬间复原"。修士将自身血肉炼化成类似魔神的"不灭元胞"，每个元胞都蕴含独立生命力。即便肉身被打成血雾，只要有一个元胞存活，便可在一息之间重塑肉身。传说当年创功者被仇家追杀，肉身被毁九十九次，却每次都浴血重生，最终反杀所有仇敌。

## 功法特点

**优点：**
- 堪称修真界最强恢复力，断肢重生、血肉重塑如同喝水
- 战斗中几乎不死，以命换命的打法无人敢接
- 肉身强度随恢复次数增加而提升，越战越强
- 对毒、咒、蛊等阴损手段有极强抗性

**缺点：**
- 每次重生会消耗大量寿元，多次重生可能耗尽寿命
- 恢复过程极其痛苦，精神不坚者会崩溃
- 功法煞气极重，修习者易被煞气侵蚀心智，走火入魔
- 佛门功法与正道雷法对此功有克制效果

## 功法等级

**血肉活化**：全身血肉开始拥有独立意识，小伤口瞬间愈合，断指可再生。此阶段煞气初显，需以道心压制。

**元胞分裂**：体内百分之三十的普通细胞转化为"不灭元胞"，被斩断的手臂可在三息内重新长出，消耗寿元十年。

**百劫不灭**：元胞转化率过半，要害被毁仍可肉身重塑。曾在战斗中被人一剑穿心，却随手拔出长剑，伤口眨眼愈合。

**魔神真躯**：全身尽数化为不灭元胞，理论上只要剩一个细胞便可重生。至此方为"不灭金身"大成。

## 功法招式

1. **血肉屏障**：将手臂血肉化为一面不断蠕动的血肉巨盾，被击穿后立即自我修复。盾面上布满尖刺，近身者会被血肉吞噬。

2. **不灭战意**：以煞气激发全身元胞活性，使恢复速度提升十倍。此招持续期间修士状若疯魔，失去痛觉，不知退怯。

3. **血影分身**：撕下自身一块血肉，投入空中化为一个完全相同但实力减半的分身。分身同样拥有不灭特性，可为主体争取时间。

4. **万劫归元**：主动引爆肉身，化为漫天血雨覆盖方圆百丈。血雨中的每个血滴都是一个不灭元胞，可在半息内重聚主体，同时血雨具有强烈腐蚀性。

5. **不死魔轮**：在身后凝出一轮暗金色魔轮，轮上铭刻魔神的"不灭咒印"。魔轮每转动一圈，修复全身伤势，同时抽取天地煞气补充消耗。

6. **荒古魔躯**：化为万丈魔神真身，皮肤呈暗紫色，布满远古魔纹。此形态下每被击中一次，便吸收对方部分力量化为己用，越战越强。持续一炷香后需休养三日。

## 修炼条件

**前置功法**：需将一门六阶以上炼体功法修至大成，且肉身需经历九次碎体重塑

**灵根要求**：无特殊要求，但雷灵根和佛门弟子不宜修炼

**特殊要求**：需获得一滴上古魔神的精血作为引子，并以此改造自身体质

**修炼地点**：煞气浓烈的古战场或深渊魔窟，普通灵地无法修炼

**所需资源**：万年魔髓一块、九幽玄铁百斤、幽冥泉水千滴、活祭血肉无数

## 使用限制/副作用

- **寿元燃烧**：每次肉身重塑消耗寿元——断肢十年、半毁五十年、全毁三百年。修炼者通常活不过千年
- **煞气噬心**：煞气会逐渐侵蚀神智，若不及时以天雷淬体净化，终将沦为只知杀戮的魔头
- **天雷重劫**：不灭金身的逆天恢复力为天道所不容，天劫威力大幅提升，且每次渡劫都伴有九重天雷专门毁坏元胞
- **佛光灼伤**：遇到佛门高僧的净化佛光，不灭元胞会被大面积灼烧坏死

## 相关典故

当年创功者"血散人"曾以一己之力对抗三大宗门围攻。三大宗门出动合体期长老七人，元婴修士数十人，布下天罗地网。战斗中血散人被轰碎四十三次，却每次都在漫天血雨中重塑肉身，反而趁机击杀了三名合体期长老。最后血散人仰天长笑："尔等杀我一次，我便强一分！我看你们有多少命来填！"三大宗门无奈退走，从此无人敢招惹这位"打不死的老魔"。但经此一战后，血散人寿元耗尽，一夜之间化为枯骨——不灭之身，也难逃天道法则。

## 修炼进度

**血肉初醒**：服下魔神精血后，全身血肉开始产生意识的"觉醒感"，伤口愈合速度提升一倍。需以煞气锻体百日。

**元胞化生**：第一次经历肉身被打碎重塑的剧痛，成功后将诞生第一批不灭元胞。此后恢复力大幅提升，但也寿元消耗百年。

**百死不悔**：累计经历百次以上的肉身重塑，道心已被煞气侵蚀过半，需寻找天雷或佛门净化之力保持清醒。

**魔神临世**：完全掌控不灭元胞，可在瞬息之间完成全身重塑。但此时距离彻底魔化也不远了——历代修炼者中，十人有九人在此阶段堕入魔道。
