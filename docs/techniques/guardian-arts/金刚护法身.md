# 金刚护法身

## 基本信息
- **功法名称**：金刚护法身
- **品级**：六阶（神级）（神级）
- **类型**：护法功法
- **适用境界**：炼虚期
- **修习难度**：★★★★★

## 功法介绍

金刚护法身是佛门防御功法中少有的"攻防一体"绝学。它不同于其他佛门功法只专注防守，而是将金刚法相塑造成一个独立的"护法分身"——既有强大的防御力，又能主动出击。

此功法由西天佛国的一位护法金刚尊者所创。这位尊者在镇守佛国边疆时发现，单纯的防御太过被动——敌人打不破你的防御，你也奈何不了敌人，最终只会陷入消耗战。他于是创出了这门功法：将金刚法力从体内分离出去，凝聚成一个独立存在的"金刚护法身"。这个护法身既是修炼者的铠甲，又是一个可以独立行动的战士。当敌人攻击修炼者时，护法身会自动挡下；当修炼者需要进攻时，护法身又可冲出去战斗。护法身不破，本尊不伤。

## 功法特点

**优点：**
- 攻防一体——护法身既能防御又能主动攻击
- 护法身拥有一定的自主意识，可以自动护主
- 护法身被击破后可以重新凝聚，不伤及本尊
- 护法身的存在会对妖魔产生强烈的威慑

**缺点：**
- 护法身需要消耗大量的佛门愿力来维持
- 护法身被击碎后需要较长时间重新凝聚
- 护法身的战斗能力受限于修炼者的佛门修为
- 修炼者需要分心操控护法身，一心二用

## 功法等级

**护法虚影**：在身边凝聚一道半透明的金刚虚影，轮廓模糊，只能看到一个金色的人形光影。虚影可以自动挡下攻击，但效果有限。

**护法法身**：虚影凝实为一个金身罗汉形象，面目清晰可见，身穿金色铠甲。法身可以独立行动，施展简单的佛门拳法。

**护法金身**：法身进一步凝实，高度达到三丈，不再是罗汉形象而是怒目金刚的形象——手持降魔杵、脚踏莲台。法身的攻击力大幅提升。

**护法本尊**：法身与本尊融为一体，本尊即是护法、护法即是本尊。可瞬间分出法身攻敌，也可瞬间收回法身护体。此境界又名"金刚不坏护法身"。

## 功法招式

1. **护法凝聚**：将金刚法力外放，在身边凝聚出一个护法分身。初时只有模糊轮廓，随着注入的愿力增多而逐渐清晰。

2. **金刚护体**：命令护法身缠绕在修炼者身上，化为一件金色的金刚战甲。护法身化甲时防御力最强，但失去攻击能力。

3. **护法出击**：命令护法身离开修炼者，冲向敌人进行攻击。护法身可以使用降魔杵、金刚拳等佛门招式。本尊此时防御空虚，需注意保护自己。

4. **金刚法界**：护法身化为一道金光扩散开来，形成一个方圆百丈的金刚结界。结界内妖魔被压制，正道修士获得防御和恢复加成。

5. **护法合体**：将护法身收回本尊体内，本尊全身金光大放，进入"护法附体"状态。此状态下修炼者同时拥有人形和法身双重防御，近乎无敌。持续一炷香。

6. **护法涅槃**：当护法身被敌人击碎时，引爆碎片化为一场金色的佛光风暴。佛光风暴可净化范围内的妖魔，同时碎片会寻找机会在风暴中心重新凝聚。这是护法身最强的反击姿态——破而后立。

## 修炼条件

**前置功法**：需将金刚不坏体修至金身初成以上，且佛门愿力积累深厚

**灵根要求**：金灵根或光灵根最佳，佛门弟子以舍利子代替灵根

**特殊要求**：需炼化一枚金刚舍利作为护法身的核心——舍利等级越高，护法身越强

**修炼地点**：佛门圣地或愿力浓郁的佛寺，愿力不足处无法凝聚护法身

**所需资源**：金刚舍利一枚（核心）、降魔杵一柄（法身武器）、金精百斤（注入法身增强装甲）

## 使用限制/副作用

- **愿力枯竭**：护法身被打碎后需要大量愿力重新凝聚，愿力不足时无法召唤
- **本尊脆弱**：护法身离体后，本尊防御力大幅下降，需注意保护真身
- **法身反噬**：如果护法身被魔气污染，可能会反噬本尊——曾有高僧因此堕入魔道
- **一心二用**：操控护法身战斗需要分心，容易顾此失彼

## 相关典故

佛国边疆曾有一位护法金刚尊者，他奉命镇守边境千年。某日魔界大军压境，尊者一人独战七位魔王。他唤出金刚护法身，护法身化为降魔金刚与三位魔王缠斗，本尊则与另外四位魔王周旋。战斗中护法身被一位魔王偷袭击碎，尊者非但不慌，反而引爆了护法身碎片。佛光风暴将七位魔王全部笼罩，风暴中心护法身重新凝聚——这一次法身比之前更加凝实。魔王们惊恐地发现，这位尊者的护法身越打越强，仿佛永远也杀不死。最终魔王们被护法金身一一镇压。此事被载入佛经，成为镇守佛国边疆的经典战例。

## 修炼进度

**虚影显形**：在身侧凝聚出护法虚影，可维持一炷香时间。虚影只能做简单的挡格动作，没有攻击能力。需数年积累愿力。

**法身初凝**：虚影凝实为罗汉形象，可施展基础佛门拳法。护法身离体后可在百丈范围内自由活动。需数十年。

**金身大成**：法身化为怒目金刚形象，手持降魔杵。已可独战一尊魔王。需三百年以上积累。

**护法合一**：本尊与法身融合，一念之间可分可合。至此金刚护法身大成——修炼者本身已相当于一尊行走的护法金刚。
