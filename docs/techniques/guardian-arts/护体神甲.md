# 护体神甲

## 基本信息
- **功法名称**：护体神甲
- **品级**：七阶（圣级）
- **类型**：护法功法
- **适用境界**：合体期
- **修习难度**：★★★★★

## 功法介绍

护体神甲是修真界最负盛名的星象系防御功法，由万年前的星象大宗师"天魁星君"所创。天魁星君毕生研究周天星斗的运行规律，他发现天上每一颗星辰都蕴含着独特的力量，而人体内的窍穴正好与诸天星辰一一对应。若能以星辰之力淬炼窍穴，便可在体表凝聚一副无坚不摧的星辉神甲。

此功法的修炼过程极为壮丽——修士须在无月之夜盘坐于高山之巅，以神识沟通天上星辰，引星光入体。每一颗星辰的光芒都是一种独特的力量属性：北斗七星主"死"，南斗六星主"生"，二十八宿各有司职。当星光在修士体内凝聚成形，会在体表显现出一副由星辉编织而成的神甲。神甲上星光流转如银河，每颗闪烁的星点都是一个窍穴的投影。

## 功法特点

**优点：**
- 星辉神甲硬度堪比圣器，合体期修士难以破防
- 星光对阴邪鬼物有净化效果，魔修攻击威力大减
- 星甲自带"星辰引力"，可吸附偏转金属类法宝
- 修炼过程中会不断拓宽经脉，提升修为上限

**缺点：**
- 极度依赖星象环境，白昼和阴天时威力大减
- 引星光入体的过程极其痛苦，如万针刺穴
- 星辰之力过于霸道，会逐渐改变修士的体质和性情——变得孤高冷漠
- 在不见天日的地下秘境中完全失效

## 功法等级

**星辉初显**：引北斗七星之光入体，在左臂上凝出一小块星光甲片。甲片呈银白色，上有北斗七星排列的图案。可抵挡化神期一击。

**星甲初成**：星光甲片覆盖双臂和双肩，二十八宿的星光逐一被引下。甲片上的星图越来越完整，防御力稳步提升。

**群星护体**：星光甲片覆盖躯干和头部，全身大半部位被星甲覆盖。背后可见淡淡的银河虚影，星甲上的星点闪烁如活物。

**周天神甲**：全身被一副完整的星辉神甲覆盖，头盔、胸甲、肩甲、裙甲、护胫、战靴一应俱全。甲上诸天星辰运转，如同披着一片银河。

## 功法招式

1. **星光壁垒**：在身前凝聚一面星光屏障，呈半透明银白色，上有星辰图案闪烁。可抵挡法术攻击，同时星光会吸收法术中的灵力补充自身。

2. **星辉流转**：控制星辉神甲缓慢流动，使甲片的排列始终处于最优防御角度。流动的星光会让敌人难以锁定具体部位。

3. **天罡护体**：引三十六天罡星之力灌注神甲，使甲片竖起如龙鳞，防御力暴增三倍。但此招只能维持三十息，过后需休养。

4. **北斗反弹**：以北斗七星的"死"之力在星甲表面形成一层反震光膜。敌人攻击命中时会触发北斗死气反噬，攻击力越强反噬越重。

5. **星陨降世**：召唤一颗流星虚影包裹自身，如同一枚陨石从天而降。此招既是防御也是位移——可以流星之势砸向敌人，冲击力极大。

6. **银河倒悬**：以自身为中心引动一片小型银河虚影，星辉流转间将所有攻击吸入银河中分解为星光。银河持续期间修士无敌，但结束后会因灵力透支昏迷三日。

## 修炼条件

**前置功法**：需将一门六阶以上星辰类功法修至大成（如周天星斗功），且自身需有星象天赋

**灵根要求**：异灵根中的星灵根最佳，无星灵根者需以星光草炼体三年改造体质

**特殊要求**：需在无月之夜于高山之巅连续观星七七四十九天，以神识标记每一颗与自身对应的星辰

**修炼地点**：高原或高山之巅，空气稀薄、观星条件极佳之处

**所需资源**：星辰铁百斤（炼入星甲可提升硬度）、星辉石一颗（辅助引星光）、万年寒玉床一张（压制星光灼体之苦）

## 使用限制/副作用

- **环境影响**：白昼威力降至五成，阴雨天降至三成，地下秘境完全失效
- **星辰反噬**：强行引动超出自身承受范围的星辰之力，会导致经脉被星光撕裂，修为倒退
- **性格变化**：长期受星辰之力影响，修炼者会变得越来越孤高冷漠，不近人情
- **星命纠缠**：修炼者的命运会与对应的星辰绑定——星陨则人亡，星黯则人衰

## 相关典故

天魁星君晚年时曾遭遇三位同阶魔修围攻。魔修们选择在无月的阴天出手，以为这样护体神甲的威力会大打折扣。天魁星君冷笑一声，全身星光大放——他早已修至"周天神甲"境界，即使阴天也能引动星空深处的远古星光。三位魔修的攻击打在星辉神甲上，如同石沉大海。天魁星君反手一挥，银河倒悬之术发动，一片银河虚影将三位魔修卷入其中。魔修们在星光中化为三座星辉雕塑，直至今日仍矗立在星象宗的山门前，警示后人莫要与星辰为敌。

## 修炼进度

**引星入体**：选取北斗七星中与自己命格对应的一颗星，引其星光入左臂窍穴。首次引星光时经脉有被撕裂之感，需以星辉石镇压。需百日。

**七星连甲**：引齐北斗七星之力，左臂上出现七块星甲片呈北斗排列。可挡下化神巅峰攻击。需三年。

**二十八宿归位**：逐一引二十八宿星光入体，铠甲覆盖双臂、肩甲、胸背。需十年以上，且需在不同季节引不同的星宿。

**周天圆满**：引三百六十五颗周天正星对应全身窍穴，星甲覆盖全身无死角。需耗费数百年苦功，天魁星君本人也用了三百年。
