# 灵气护盾

## 基本信息
- **功法名称**：灵气护盾
- **品级**：一阶（黄级）
- **类型**：护法功法
- **适用境界**：聚气期
- **修习难度**：★☆☆☆☆

## 功法介绍

灵气护盾是修真界最基础、最原始的防御法术。它没有华丽的来头，没有传奇的创造者——几乎可以认为是第一位修士在修炼过程中自然而然领悟出来的技巧。当修士体内有了灵力之后，自然而然会想要用灵力保护自己，而最直接的方式就是在体表形成一层灵力屏障。

灵气护盾的原理极其简单：将体内的灵力外放到体表，以一定的密度排列成一层无形的屏障。屏障可以缓冲冲击、偏折攻击、隔绝水火。虽然防御力极其有限，但对于刚刚踏入修仙之路的聚气期修士来说，这层薄薄的灵气护盾往往就是保命的最后一道防线。几乎所有的宗门都将灵气护盾作为入门弟子的必修课。

## 功法特点

**优点：**
- 上手极快——几乎所有修士都能在几天内掌握
- 消耗极低——只需要维持一层薄薄的灵力膜
- 用途广泛——可以防尘、防水、防寒、隔热
- 与其他防御功法不冲突，可作为底层基础

**缺点：**
- 防御力极其有限，凡人中的大力士都能击穿
- 对法术攻击几乎没有效果
- 面对利器穿刺时效果很差
- 在灵气稀薄的地方难以维持

## 功法等级

**灵气薄膜**：在体表附着一层薄薄的灵力膜，看不见摸不着，可感应到。可防灰尘蚊虫、微弱寒风、小雨滴。几乎不消耗灵力。

**灵气气墙**：灵力膜增厚到肉眼隐约可见的程度，如同在体表覆盖了一层透明气墙。可挡住普通飞石、箭矢。持续消耗灵力。

**灵气壁垒**：灵力墙进一步增厚，形成半透明的壁垒。可挡住普通的刀剑劈砍。灵力消耗明显增加。

**灵气坚壁**：壁垒呈淡白色，硬度堪比薄铁板。可挡住低阶妖兽的爪击。聚气期修士维持此形态超过一炷香就会灵力耗尽。

## 功法招式

1. **基础护盾**：将灵力均匀分布在体表形成一层薄膜。这是最基础的用法，也是所有护盾技巧的起点。

2. **局部加厚**：将灵力集中在某一部位加厚护盾，比如在胸口加厚以抵挡正面攻击。同一时间只能加厚一个部位。

3. **护盾爆发**：在遭受攻击的瞬间，将护盾上的灵力向外猛烈释放，形成一股冲击波弹开攻击。爆发后护盾暂时消失。

4. **灵力滑流**：使护盾表面的灵力呈流动状态，让来袭的物理攻击沿着护盾表面滑开，减少正面冲击。

5. **护盾共鸣**：两人或多人同时展开灵气护盾并调整到相同频率，使护盾之间产生共鸣叠加效果。多人叠加的护盾防御力远超单人。

6. **护盾充能**：将护盾与周围的灵气环境连接，从外界吸收灵气补充护盾消耗。在有灵脉的地方可持续很久，枯竭之地则失效。

## 修炼条件

**前置功法**：不需要——只要能够感应灵气并将灵气引出体外即可

**灵根要求**：任何灵根都可修炼，没有限制

**修炼地点**：任何有灵气的地方都可以练习

**所需资源**：不需要特殊资源

## 使用限制/副作用

- **灵力耗尽即破**：灵力耗尽后护盾自动消失，需要打坐恢复灵力后才能再次展开
- **穿透攻击难防**：尖锐的穿刺类攻击（飞针、剑气）很容易突破护盾
- **神识压制**：遇到神识强大的对手，护盾可能被对方的神识直接击穿
- **脱力后遗症**：长时间维持护盾导致灵力透支，会伴随头晕乏力等症状

## 相关典故

据说在修真界的远古时期，第一名学会灵气护盾的修士其实是个意外。当时一名初学者正在打坐运气，突然有一只毒蛇咬向他的小腿。他本能地想要用灵力阻挡——奇迹发生了，毒牙在离皮肤一寸处被一层无形的力量挡住了。这名初学者又惊又喜，反复试验后发现确实可以用灵力在体外形成屏障。他将这个发现告诉了师兄弟们，从此灵气护盾这门最基础的防御法术便流传开来。直到今天，每一位踏入修仙之路的修士，学的第一个防御法术都是灵气护盾。

## 修炼进度

**初见成效**：在体表形成一层可以感知的灵力膜，持续一刻钟。初学者一两天即可掌握。

**稳定维持**：灵力膜可以持续一整天而不消散。日常走路、干活时都可以保持着。需一周至一月的练习。

**实战应用**：在战斗中可以熟练地展开和维持护盾，并且学会局部加厚和滑流技巧。需三至六个月。

**随心所欲**：护盾如同身体的一部分，心念一动即可展开。同时可以维持护盾做其他事情而不分心。这也是聚气期大圆满的标志之一。
