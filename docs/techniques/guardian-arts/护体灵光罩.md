# 护体灵光罩

## 基本信息
- **功法名称**：护体灵光罩
- **品级**：四阶（天级）（天级）
- **类型**：护法功法
- **适用境界**：元婴期
- **修习难度**：★★★★☆

## 功法介绍

护体灵光罩乃护体灵光的进阶演化版本，由上古器修宗门"天光宗"的宗主所创。相传天光宗宗主在炼制一件防御法宝时，发现七种不同属性的珍贵宝石在灵力共鸣下会形成一道坚不可摧的光罩，由此悟出以七窍灵力凝聚护罩之法。

与二阶护体灵光不同，护体灵光罩的灵力不再只是附着体表，而是在体外一尺处凝聚成一个立体的"蛋壳状"光罩。这个罩子共有七层，每层对应人体七窍之一——目、耳、鼻、口、前阴、后阴等窍穴皆有灵光覆盖。七层灵光罩每一层被击破后都有不同的效果，或是吸纳攻击威力、或是反弹部分伤害、或是自动修复。

## 功法特点

**优点：**
- 七层灵光罩层层防护，攻破一层还有一层，安全性极高
- 每层灵光罩有独立的属性防御侧重，几乎无短板
- 罩破警报——当第一层被击破时修士会立即警觉
- 可同时保护周围三尺范围内的同伴

**缺点：**
- 消耗灵力极大，元婴初期修士只能维持一炷香
- 七窍对应的灵光罩受损会反噬到对应的感官器官
- 需要大量稀有宝石辅助修炼，花费不菲
- 移动速度会受到灵光罩的拖累

## 功法等级

**一窍光起**：在体外凝聚一层薄薄的光罩，对应眼窍。光罩透明无色，可抵御金丹期攻击，但容易被神识穿透。

**三窍光成**：三窍对应的三层光罩相互嵌套，防御力大幅提升。敌方的神识探查会被外层光罩阻挡，无法看清修士真实修为。

**五窍光固**：五层光罩覆盖上半身，每次被击破一层都会发出不一样的光效和声音作为预警。

**七窍圆满**：七层灵光罩完整嵌套，形成七彩琉璃罩。每一层都有独立的灵力循环，被击破一层后其余六层会加速运转补位。据说修至圆满者可在元婴期内无敌手。

## 功法招式

1. **虹光护罩**：在体外一尺处凝结出一道七彩光罩，以目窍灵光为主。光罩表面如流水般波动，可将来袭的攻击滑走卸力。

2. **灵光共鸣**：以自身灵力震动七层光罩，发出特定的频率共鸣。身处共鸣范围内的同伴可共享一层光罩庇护，但消耗加倍。

3. **罩破反击**：当某一层灵光罩被击碎时，碎裂的灵力会化为万千光针射向攻击者。光针中蕴含该层对应的属性之力，防不胜防。

4. **七窍轮转**：主动调整七层光罩的排列顺序，将防御力集中到最受攻击的一面。例如受到火系攻击时，将水系光罩调到外层。

5. **光罩涅槃**：当七层光罩全部被击碎时，引爆全部灵力碎片形成一个短暂的"光罩涅槃"区域。区域内一切攻击都被灵力碎片风暴搅碎，为修士争取撤退或反攻的时机。

6. **七彩琉璃界**：将七层光罩极速旋转融为一体，形成一颗直径丈许的七彩琉璃球。修士位于球心，琉璃球外壳坚不可摧。但持续期间修士无法攻击和移动，只能全力维持。琉璃球破碎后修士灵力耗尽，任人宰割。

## 修炼条件

**前置功法**：需将护体灵光修至五色圆满，且自身修为达到元婴期

**灵根要求**：天灵根最佳，三灵根以上也可修炼但进度缓慢

**特殊要求**：需以七种属性不同的稀世珍宝（如五行宝石、光暗晶石等）为引子，炼化入七窍之中

**修炼地点**：宝光充沛的矿脉深处，或天光宗的传承秘境

**所需资源**：七彩宝珠七颗、万年温玉一块、天光宗修行手札一本

## 使用限制/副作用

- **感官反噬**：某一窍对应的光罩破碎时，对应的感官会暂时失灵——眼罩破则目盲、耳罩破则失聪，需一昼夜恢复
- **宝石依赖**：七种宝石缺一不可，若其中一颗碎裂则整层功法威力大减，需重新寻找同属性的宝石替换
- **灵力枯竭**：七层光罩持续运转消耗极大，一旦灵力耗尽罩体消散，修士会陷入极度虚弱状态
- **神识负担**：同时操控七层光罩对神识要求极高，长期使用会导致神识疲劳，反应变慢

## 相关典故

天光宗曾有一名长老在探索上古遗迹时遭遇封印万年的魔头。魔头脱困后第一击便击碎了长老的五层灵光罩，长老虽然心惊但并不慌乱。当魔头准备发动致命一击时，长老引爆了剩余两层光罩，七彩琉璃碎片刺入魔头体内，其中蕴含的天光宗传承灵力正好克制魔头的魔气。魔头惨叫一声，被碎片中的净化之光封印了修为。长老趁机逃出遗迹，此后天光宗将此案例写入功法传承中，作为"光罩涅槃"招式的经典实战案例。

## 修炼进度

**开窍引光**：选择第一个窍穴（通常为目窍），将对应属性的宝石灵力引入窍穴中，在体外凝出第一层光罩。需百日炼化宝石。

**三窍稳固**：完成目、耳、鼻三窍的光罩凝聚，三罩相互嵌套。此时光罩防御力初见雏形，可抵御元婴初期攻击。需三至五年。

**五窍大成**：口窍和前阴窍也凝聚光罩，五层光罩覆盖上半身重要部位。光罩颜色五彩斑斓，极为醒目。需十余年苦修。

**七窍圆满**：七窍全部完成，七层光罩浑然一体。此时光罩色泽转为温润的琉璃色，不再刺眼——返璞归真。需数十年积累，非大毅力者不可成。
