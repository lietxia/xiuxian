# 护身天罗地网

## 基本信息
- **功法名称**：护身天罗地网
- **品级**：六阶（神级）（神级）
- **类型**：护法功法
- **适用境界**：炼虚期
- **修习难度**：★★★★★

## 功法介绍

护身天罗地网是由护身天罗和地网缚灵两种功法融合而成的复合型防御绝学。万年前，天罗宗的宗主"罗天道人"和地网宗的宗主"网罗仙子"是一对道侣，两人各自专精一门织物系防御功法。在大道双修的过程中，他们发现天罗（上层的丝网防御）和地网（地面的阵法防御）如果同时施展，可以形成一个天地之间无死角的完美防御体系。

此功法的精妙之处在于"天地交织"——天罗从头顶垂下无数灵力丝线，地网从脚下升起无数阵法符文，两者在半空中交织融合，形成一个完整的球状防御网络。攻击从上方来会被天罗层层拦截，从下方来会被地网重重阻挡，从侧面来则会被天罗地网交织的界面切碎。两位创功者联手时，曾以天罗地网困住一头上古凶兽三日三夜，凶兽无论如何冲撞都无法破网而出。

## 功法特点

**优点：**
- 天地交织，没有防御死角
- 天罗负责拦截攻击，地网负责束缚敌人，攻防兼备
- 天罗地网可困敌——敌人陷入网中后越挣扎越紧
- 多了一层地网防御，不怕土遁或地下突袭

**缺点：**
- 需要同时操控天罗和地网两套系统，神识负担极重
- 地上需要有可布置地网的场地（岩石或水面效果差）
- 合击版本需要双人配合，一人修炼时效果减半
- 地网一旦被破坏，整个体系失衡

## 功法等级

**天罗初布**：能同时展开天罗和地网的雏形——头顶一层透明丝网，脚下一层淡淡的阵光。两网尚未连接，防御范围有限。

**天地交织**：天罗的丝线下垂与地网的阵光相连，形成一个半闭合的球体。防御范围和强度大幅提升，可困住化神期妖兽。

**周天罗网**：天罗地网完全闭合为一个球体，将修士包裹其中。球体内外完全隔绝，攻击来则被层层过滤，敌人入则被重重束缚。

**网罗天地**：天罗地网的范围扩大到覆盖百丈方圆。网中每一根丝线都铭刻阵法符文，每一条阵纹都可以化为丝线。天地一体，攻防合一。

## 功法招式

1. **天罗垂丝**：从头顶释放出无数灵丝垂落悬浮，如同天上垂下的一道道丝帘。这层天罗可拦截上方来的攻击，丝线有粘性可缠住飞行法宝。

2. **地网升纹**：地面浮现一圈圈阵法纹路，向上升起形成地网。地网可阻挡来自地下的攻击，同时阵纹可限制敌人移动。

3. **天地缝合**：将天罗的丝线与地网的阵纹一一对接，形成一个完整的空间网络。此时天罗地网正式成型，防御力倍增。

4. **网中捕鱼**：当敌人进入天罗地网范围时，操控四周的丝线和阵纹向敌人收缩，将其困在网中央。越挣扎丝线勒得越紧，直至动弹不得。

5. **罗网绞杀**：将天罗地网急剧收缩，网中的丝线和阵纹如同利刃一般切割网内的所有物体。这一招极其残忍但极为有效——被困的敌人会被切成碎片。

6. **天地归网**：终极招式——将天罗地网压缩成一个拳头大小的光球，然后引爆。光球的爆炸之力相当于天罗地网全部能量的释放，威力足以夷平一座山头。但释放后修士需休养三个月以恢复损耗的神识和灵力。

## 修炼条件

**前置功法**：需将护身天罗修至大成，同时精通至少一门阵法类功法

**灵根要求**：木土双灵根最佳（木化丝、土布阵），或拥有天罗和地网双系天赋

**特殊要求**：需有一件本命法宝作为天罗地网的核心阵眼，通常是一枚"罗网珠"

**修炼地点**：适合同时修炼天罗和地网的地方——上有开阔天空、下有平坦土地

**所需资源**：天蚕丝千缕、地脉灵石百块、罗网珠一枚（核心阵眼）、天罗地网秘籍全本

## 使用限制/副作用

- **双倍消耗**：同时维持天罗和地网消耗是单一功法的两倍
- **场地限制**：在水面、流沙、岩石等地势上地网效果大打折扣
- **阵眼脆弱**：作为核心的罗网珠如果被击碎，整个天罗地网瞬间崩溃
- **双人默契**：若两人配合施展，需要极高的默契——心意相通才能发挥最大威力

## 相关典故

罗天道人和网罗仙子这对道侣最著名的一战是对抗魔道巨擘"破天老魔"。破天老魔以一身蛮力闻名，曾徒手撕裂过上品法宝。他放出狂言要将天罗地网撕成碎片。罗天道人和网罗仙子相视一笑，同时展开天罗地网。破天老魔一拳轰在天罗上，天罗丝线被拉长到极致，但就是不碎；他一脚踩在地网上，地网阵纹闪烁，反而将他的脚黏住了。破天老魔越挣扎陷得越深，最后被丝线和阵纹裹成了一个茧。罗天道人笑道："你再大的力，也破不了这天罗地网——因为你越用力，网收得越紧。"从此天罗地网威名远扬。

## 修炼进度

**分修天罗地网**：需要分别掌握天罗和地网。天罗方面要学会灵丝化网，地网方面要学会阵纹布设。这一步需数年。

**初次交织**：尝试将天罗的丝线连接地网的阵纹，形成初步的天地联动。此阶段极容易出现连接不稳、一方崩溃的情况。需三至五年。

**天地一体**：天罗地网可在一息之内完全展开，覆盖方圆十丈。天地之间的丝线和阵纹浑然一体，如同一个独立的结界。需数十年。

**网罗大成**：心念一动便可在百丈范围内布下天罗地网，网中每一根丝线都蕴含阵纹之力。至此护身天罗地网大成——修真界能破此网者屈指可数。
