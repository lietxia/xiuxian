# 护体天道

## 基本信息
- **功法名称**：护体天道
- **品级**：八阶（帝级）
- **类型**：护法功法
- **适用境界**：大乘期
- **修习难度**：★★★★★

## 功法介绍

护体天道乃九天仙域流传下来的至高防御法门，其核心在于"借天之力以为己用"。普通防御功法依靠灵力或肉身硬抗，而护体天道则是让修士与天道法则建立共鸣，使天道本身成为最坚固的屏障。

此功法由万年前一位名为"天道子"的仙帝所创。天道子曾在上古时代以一己之力对抗域外天魔入侵，在战斗中悟出"天之道，损有余而补不足"的至理，创下此功。据说天道子施展护体天道时，周身环绕天地万象——日月星辰、山河大地、风雨雷电尽皆虚影浮现，任何攻击落在其上，便如同攻击整个世界一般，被天地之力自然化解。

## 功法特点

**优点：**
- 防御力与天道共鸣深度成正比，极致时可引一界之力加身
- 自动识别天道因果，对含有业力、怨气的攻击有额外消解效果
- 无需主动运转，天道护体自动生效，不易被偷袭
- 修炼者可在护体状态下感悟天道运转规律，辅助悟道

**缺点：**
- 修炼门槛极高，需对大道的理解达到极深境界
- 心境不稳时天道共鸣会中断，护体效果归零
- 每用一次都会加深与天道的因果纠缠，不利超脱飞升
- 在规则不完整的秘境或小世界中威力大打折扣

## 功法等级

**天道初闻**：初步感知天道法则的存在，体表浮现淡淡天地虚影，可抵挡元婴期攻击。此阶段护体需主动催动。

**天地共鸣**：与天道建立稳定共鸣，护体效果自动生效。受到攻击时周身会有山河虚影闪烁，将攻击力分散到天地之间。

**道我合一**：修士与天道短暂合一，周身演化日月星辰运转之象。合体期全力一击落在身上，如同沧海一粟，无足轻重。

**天道化身**：修士身化天道的一部分，一念之间可调动方圆千里的天地之力。至此护体天道方为大成。

## 功法招式

1. **天道屏障**：在身前凝聚一面无形天道之壁，任何攻击穿过此壁时都会被天道法则削弱。法术攻击会被分解为最原始的灵气消散，物理攻击会被空间之力偏折。

2. **因果消解**：以天道因果之理化解攻击。敌方施展含怨气的魔功时，此招可直接将怨气引向天道因果循环，使攻击在命中前便自行崩解。

3. **天地借法**：暂时借用一方天地的法则之力强化护体。在群山之中借山岳之稳重，在大海之上借沧海之浩瀚，在沙漠之中借大漠之苍茫。

4. **天罚反噬**：将所受攻击的因果扭转，使攻击者承担天道反噬。曾有魔尊全力一击打在护体天道之上，结果三成威力被天道反噬加于己身，自己吐血倒退。

5. **周天星斗**：引动周天星斗之力笼罩全身，防御力达到极致。星斗运转间可形成天然阵法，任何攻击都将面对周天星辰的碾压。

6. **天道轮回**：终极秘术——以自身为媒介，短暂召唤天道轮回虚影。身处虚影之中，一切攻击都会被卷入轮回，返还于天地。此术只能维持三息，使用后修为跌落一个小境界，需百年恢复。

## 修炼条件

**前置功法**：需将一门七阶以上土系或雷系防御功法修至大成，且对大道的感悟达到"化道"境界

**灵根要求**：天灵根或异灵根（雷、风、冰、光），普通灵根无法感知天道法则

**心境要求**：需达到"天人合一"心境，心魔滋生时不可修炼

**修炼地点**：天道法则最为完整的天界或仙界，人间界法则残缺难以修至大成

**所需资源**：天道碎片一枚（需在天劫中领悟凝聚）、天地本源之气一缕、道果一枚

## 使用限制/副作用

- **天道因果缠绕**：每次使用护体天道都会加深与天道的因果纠缠，使得飞升时遭遇的天道束缚更强，渡劫更难
- **小世界失效**：在储物空间、秘境洞天等法则不全的小世界中，护体天道威力暴跌至一两成
- **心境依赖**：若心绪波动剧烈（如愤怒、恐惧、悲伤），天道共鸣会瞬间中断，护体消失
- **天机遮蔽**：使用此功时会剧烈扰动天机，极易被天机推演类的法宝锁定位置

## 相关典故

万年前天道子与域外天魔皇大战于天外天。天魔皇以吞天魔功吞噬了半个仙界，天道子施展护体天道，化身为一轮天道大日悬于虚空。天魔皇的每一次吞噬之力都被天道法则消解，反而被反噬之力伤了本源。天魔皇怒道："你非与我为敌，是与整片天地为敌！"天道子淡然回应："我即天道，天道即我。你吞天噬地，便是与己为敌。"最终天魔皇被天道反噬之力绞杀。但天道子也因为与天道纠缠过深，再也无法超脱飞升，永世镇守天外天。

## 修炼进度

**天道初感**：首次在天劫或天地异变中感知到天道法则的存在，需在特定天象下方可入门。快则数年，慢则终生无望。

**共鸣建立**：通过漫长悟道与天道建立共鸣，期间需保持心境纯净如镜，任何杂念都会导致共鸣断裂。通常需百年以上。

**道体同化**：身体开始部分"天道化"，寿元大幅延长，可隐约感知一界之内的天地异动。至此方算小成，而修炼者往往已容颜苍老。

**法身大成**：彻底与天道法则融为一体，一念可引天地之力。但代价是自身的存在感越来越淡，逐渐被天道同化——历代修炼者中，最终都化为了天地法则的一部分，以另一种方式"永生"。
