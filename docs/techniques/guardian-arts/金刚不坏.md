# 金刚不坏

## 基本信息
- **功法名称**：金刚不坏
- **品级**：三阶（地级）
- **类型**：护法功法
- **适用境界**：金丹期
- **修习难度**：★★★☆☆

## 功法介绍

金刚不坏源自佛门，是佛家护法金刚一脉的锻体基础功法。传说佛陀座下有八大金刚护法，每一个都有降妖伏魔的神力。他们将佛门金身的修炼之法简化后传于世间，便有了这门"金刚不坏"功。

不同于其他佛门防御功法的"修心养性"路线，金刚不坏是一门纯粹的"炼体"功法。它的理念很简单——把身体炼成金刚石一般的存在。修炼者需要不断以佛门真火淬炼皮肉筋骨，如同炼钢一般反复锻打。每一次淬炼都会使肉身更加坚硬，最终达到"筋骨如钢、皮如铁甲"的境界。金刚不坏虽然品级不高，但它是一切高阶佛门金身功法的根基——所有佛门大能的防御之道，都是从这门基础功法开始的。

## 功法特点

**优点：**
- 纯物理防御极强，刀砍斧劈如挠痒
- 习成后身体硬如金石，徒手可碎凡兵
- 修炼入门门槛低，佛门弟子皆可修习
- 作为基础锻体功法，可向高阶金身进化

**缺点：**
- 对法术攻击的防御力几乎为零
- 修炼过程极为痛苦——需要承受真火焚身之痛
- 敏捷性下降，身体变得沉重笨拙
- 需要配合佛门清规戒律才能修炼，破戒则功力倒退

## 功法等级

**皮如革**：皮肤变得粗糙厚实，如同老牛皮。普通刀剑划过只能留下白痕，不易破皮。此阶段需以真火灼烧全身皮肤七七四十九次。

**肉如筋**：肌肉变得坚韧如老牛筋，弹性十足且紧致。钝器击打如同打在橡胶上，冲击力被肌肉吸收分散。

**骨如铁**：骨骼呈灰黑色，硬度堪比凡铁。断骨处愈合后会更加坚硬——如同钢铁折叠锻打一样，越折越强。

**金刚体**：全身皮肤呈古铜色，闪现金属光泽。寻常法器砍在身上发出金铁交击之声，火星四溅。

## 功法招式

1. **金刚体肤**：将佛门真火遍布皮肤表面，皮肤在真火淬炼中逐渐变为古铜色。此状态下的皮肤硬度堪比薄铁甲。

2. **铁骨硬功**：将真火之力集中于骨骼，使骨骼硬度短时间内大幅提升。施展时关节发出咔咔声响，全身骨骼进入"铁化"状态。

3. **铜皮铁骨**：同时激活皮肤和骨骼的硬化状态，全身皮骨硬如铜铁。普通筑基修士的飞剑砍在身上只能留下一道浅痕。

4. **金刚霸体**：将全身肌肉紧绷如钢铁，身高膨胀三分，青筋暴起如老树根。此状态下免疫一切物理控制（推、撞、抓），如同生根于大地。

5. **金刚吼**：以金刚之力发出怒吼，声波中蕴含佛门真力。可震碎低阶法器，还可震慑妖魔心魂。

6. **不坏金身（伪）**：将全身真火凝聚于体表，化为一层金色火焰战衣。此状态下皮肤短暂进入"金刚化"，可硬抗金丹巅峰一击。但时间极短，只能用一次。

## 修炼条件

**前置功法**：需将一门基础佛门心法修至入门，并且在寺庙中受过三皈五戒

**灵根要求**：金灵根最佳（金对应坚固），土灵根亦可

**体质要求**：需有"金刚骨"体质者修炼最佳，普通体质也能修炼但进度缓慢

**修炼地点**：佛门寺庙中的金刚堂，或地火旺盛的火山口附近（以地火代替佛门真火）

**所需资源**：金刚砂十斤（淬体时加入可增加硬度）、佛门真火种子一枚、铜汁铁水各百斤（用于炼体沐浴）

## 使用限制/副作用

- **真火焚身之苦**：每次修炼都要承受真火灼烧肉身的剧痛，非心志坚毅者难以承受
- **酒肉破功**：饮酒食肉会破坏金刚体的修炼成果，须严守斋戒
- **女色戒忌**：犯色戒会导致金刚体境界倒退，严重者功力尽废
- **水浸软化**：在极寒之水或弱水中浸泡太久，金刚体会暂时软化

## 相关典故

佛门中曾有一位著名的"铜头铁罗汉"，他修炼金刚不坏达到了大成境界。有一次他路过一座被山贼肆虐的村庄，山贼头目见他是个和尚，挥刀就砍。铜头铁罗汉不闪不避，任由大刀砍在头顶——只听"铛"的一声，大刀崩出一个大口子，他的头上连个白印都没有。山贼头目吓傻了，又连砍数刀，刀刀崩口。铜头铁罗汉摸了摸光溜溜的脑袋，笑道："施主，你再砍下去，刀就要废了。"山贼头目跪地求饶，从此弃恶从善。铜头铁罗汉用他的"铁头"度化了一方恶人。

## 修炼进度

**淬皮**：以佛门真火灼烧全身皮肤，每日一次，每次一炷香。皮肤从白皙变红、再变为古铜色。需百日方可完成。

**炼肉**：真火深入肌肉层，将肌肉中的杂质烧尽。此阶段需忍受肌肉痉挛之痛。需半年。

**锻骨**：真火入骨，将骨髓中的杂质蒸发。此阶段最为痛苦——骨头如同被铁锤反复敲打。需一至三年。

**金刚大成**：皮、肉、骨全部淬炼完毕，全身呈现古铜色，在阳光下闪现金属光泽。至此金刚不坏大成，可向下一个境界"金刚不坏体"进发。
