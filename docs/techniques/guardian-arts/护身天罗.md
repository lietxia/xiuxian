# 护身天罗

## 基本信息
- **功法名称**：护身天罗
- **品级**：四阶（天级）
- **类型**：护法功法
- **适用境界**：元婴期
- **修习难度**：★★★★☆

## 功法介绍

护身天罗源自天蚕族的传承秘法。天蚕是一种极其罕见的灵兽，它们吐出的丝线坚韧无比，且蕴含灵力。上古时期，一位名叫"织罗仙子"的女修在天蚕谷中修行时，发现天蚕结茧的过程蕴含着天然的防御至理——茧丝层层缠绕，形成一个完美的防护结构。

织罗仙子以天蚕吐丝为灵感，创造出一门以灵力化丝、以丝织罗的防御功法。不同于普通的护罩将灵力外放形成屏障，护身天罗将灵力凝成一根根细如毫发、透明无色的丝线，在体表编织成一张精密的天罗网。这些丝线有极强的粘性和韧性，攻击落在网上如同飞虫落入蛛网，被层层缠绕、分解、吸收，最终消散于无形。

## 功法特点

**优点：**
- 灵力丝线极细极韧，寻常刀剑砍不断
- 丝线有粘性，可缠绕困住近身的敌人
- 天罗网透明无影，不易被敌人察觉
- 可同时兼顾防御和束缚两种功能

**缺点：**
- 火系功法克制此功——火烧丝断，天罗瓦解
- 编织天罗需要极高的神识操控精度
- 丝线编织需要时间，面对突袭来不及展开
- 对范围型攻击（如爆炸）的防御效果较差

## 功法等级

**灵丝初凝**：从指尖凝出一根灵力丝线，细如蛛丝但韧如牛筋。可缠绕在手指上备用，但还不足以编织成网。

**丝线织网**：学会将多根灵丝编织成一张小网，覆盖面积约一尺见方。可用于遮挡要害部位，但覆盖不全。

**天罗披身**：灵丝编织出一件完整的"天罗衣"披在身上，覆盖全身。天罗衣透明轻薄，不影响行动，防御力已相当可观。

**天罗万象**：天罗不再是固定形状，而是随心变化——可化为一面罗盾、一件罗甲、一张罗网。甚至可编织出多层罗网叠加防御。

## 功法招式

1. **灵丝缠绕**：从十指各射出一根灵丝，在身前快速编织成一道丝网。丝网透明且极有弹性，攻击撞在网上会被弹回或缠绕住。

2. **天罗衣**：将灵丝编织成一件紧贴身体的罗衣，覆盖全身。罗衣不影响活动，却能让偷袭的利器滑开，如同在冰面上滑行。

3. **天罗盾**：将灵丝编织成一面半透明的圆形罗盾，盾面丝线纵横交错。可挡住正面攻击，同时丝线可突然延伸出去缠绕敌人武器。

4. **千丝万缕**：一瞬间释放出上千根灵丝，在周身形成一张密不透风的天罗网。网丝极细，肉眼几乎不可见，敌人往往撞到网上才能察觉。

5. **罗网收束**：将编织好的天罗网突然收紧，将网内的敌人或攻击紧紧包裹。这招适合对付近身的敌人——网住后敌人如同被蛛丝缠住动弹不得。

6. **天罗结界**：以自身为中心编织一个直径丈许的球形天罗结界。结界内布满灵丝，敌人进入结界如同走入蜘蛛巢穴——每动一下都会被更多的丝线缠住。

## 修炼条件

**前置功法**：需将护体灵光修至三色以上，神识强度需达到元婴期水平

**灵根要求**：木灵根最佳（木属性有延展性，适合化丝），水灵根次之

**特殊要求**：需取得天蚕丝一缕作为引子，以天蚕丝的灵力运转规律激发自身灵力化丝的能力

**修炼地点**：天蚕谷或有大量天蚕的地方，通过观察天蚕结茧领悟化丝之法

**所需资源**：天蚕丝百缕、柔丝泉水一瓶（浸泡灵丝可增加韧性）、织罗针一枚（辅助精确控制丝线）

## 使用限制/副作用

- **火克之**：遇到火系功法或火属性法宝，灵丝会被烧断，天罗崩溃。火盾克星。
- **锋刃割裂**：遇到极为锋利的神兵利器（如飞剑），灵丝会被切断
- **神识疲劳**：同时操控大量丝线编织复杂网络对神识消耗极大
- **湿气影响**：暴雨或潮湿环境下，灵丝会吸水变重，灵活性下降

## 相关典故

织罗仙子年轻时曾在天蚕谷中修炼，一日遇到一头四阶妖兽"赤焰蟒"袭击。赤焰蟒喷出的烈火恰好克制她的天罗网。织罗仙子急中生智，一边后退一边加速编织天罗网。她用灵丝编织了足足九九八十一层罗网挡在身前，赤焰蟒冲破一层还有一层，冲破一层又来一层。最终赤焰蟒被累得精疲力竭，而织罗仙子趁机以灵丝将蟒蛇缠绕捆住。她后来在《织罗心得》中写道："天罗一门，胜在韧性——一缕不够便十缕，十缕不够便百缕。只要丝线不断，敌人终将被缠住。"

## 修炼进度

**吐丝入门**：在指尖凝出第一根灵丝，细如发丝、长约三尺。需反复练习控制丝线的方向和粗细。初学者需三月。

**织网初成**：用十根灵丝编织出一张面盆大小的网，可捉住低阶飞剑。需一年。

**罗衣罩体**：编织一件覆盖全身的透明罗衣，日夜穿着以培养人与丝的默契。需五年。

**天罗万象**：丝线随心所欲变化形态——可做衣、做盾、做网、做绳。战斗时可在一息之内完成布防。至此护身天罗大成，需数十年苦练。
