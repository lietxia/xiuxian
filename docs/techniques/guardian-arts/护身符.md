# 护身符

## 基本信息
- **功法名称**：护身符
- **品级**：一阶（黄级）
- **类型**：护法功法
- **适用境界**：聚气期
- **修习难度**：★☆☆☆☆

## 功法介绍

护身符并非传统意义上的修炼功法，而是一种"符箓类防御术"——将符文铭刻在符纸上，注入灵力后贴在身上，形成一层保护性的符力屏障。这是修真界最基础、最普及的防御手段，几乎每个入门修士都会制作和使用。

护身符的历史可以追溯到符箓之道的源头。相传在上古时期，一位名叫"符祖"的大能在观察龟甲裂纹时领悟了天地符文之理。他发现用朱砂在黄纸上画出特定的符文，可以引动天地之力。后来他的弟子们将这种力量用于防御，创出了护身符。一枚好的护身符可以在危急时刻救你一命——虽然它只能挡住一次攻击，但在低阶修士的战斗中，一次阻挡往往就是生与死的区别。

## 功法特点

**优点：**
- 制作简单，材料便宜，人人都可掌握
- 使用方便——往身上一拍即可激活
- 可批量制作，随身携带多枚备用
- 不占用手部，不影响其他法术施展

**缺点：**
- 一次性使用，用后即废
- 防御力有限，只能挡住聚气期到筑基初期的攻击
- 遇水则失效——被雨淋湿后符文会化开
- 需要提前准备，紧急情况下可能来不及使用

## 功法等级

**黄纸符**：用普通黄纸和朱砂绘制，防御力最弱，可抵挡一次聚气中期攻击。成本最低，散修最爱。

**灵纸符**：用蕴含灵气的灵纸绘制，防御力中等，可抵挡一次聚气巅峰攻击。中型宗门弟子标配。

**玉符**：不再用纸，而是将符文刻在玉石上。可反复充能使用，防御力相当于筑基初期一击。价格昂贵但性价比高。

**金符**：以金箔为载体，用特殊灵墨绘制。防御力极强，可抵挡筑基中期全力一击。通常作为保命底牌使用。

## 功法招式

1. **聚气符**：最基础的护身符，用朱砂在黄纸上画出聚气符文。激活后在体表形成一层薄薄的气墙，可偏折暗器和小型法术。

2. **金刚符**：在符纸上绘制金刚符文，激活后体表浮现一层金色光晕，短时间内大幅提升物理防御力。适合近战时使用。

3. **避水符**：绘制避水符文，激活后可在体表形成一层隔水膜。不仅防水，在水中还可获得一定的防御加成。

4. **御风符**：绘制御风符文，激活后在周身形成一层气旋屏障，可偏折远程攻击。同时能小幅提升移动速度。

5. **五行护身符**：用五种颜色的灵墨绘制五行符文，每色对应一行的防御。红色防火、蓝色防水、绿色防木、金色防金、黄色防土。

6. **复合符阵**：将多张不同功能的护身符组合使用，形成一个符阵。比如身上同时贴着金刚符、避水符、御风符，三种效果同时生效。但复合符阵对神识控制要求较高。

## 修炼条件

**前置功法**：需掌握最基础的符箓绘制技巧，以及基本灵力运转

**灵根要求**：任何灵根皆可，但火灵根在画符时有天然优势（朱砂需以灵力加热）

**特殊要求**：需有一支符笔（普通毛笔也可，但效果差）、朱砂、符纸

**修炼地点**：安静的书房或工坊即可，无需特定环境

**所需资源**：黄纸千张（练习用）、朱砂一斤、灵墨一瓶、符笔一支

## 使用限制/副作用

- **一次性消耗**：绝大多数护身符只能用一次，用后即化为灰烬
- **湿气失效**：护身符怕水怕潮，雨雪天气效果大减，浸泡后完全失效
- **符力冲突**：不同种类的护身符不能同时叠太多，否则符力冲突会爆炸
- **材质限制**：护身符的防御上限受限于载体材质——黄纸不可能挡住金丹期攻击

## 相关典故

据说符祖年轻时曾用一枚护身符救了自己一命。那时他还在研究符文，一次实验中引发了灵力爆炸，眼看就要被炸死——贴身的那枚护身符突然金光大放，挡住了爆炸冲击。符祖愣了半天，发现这枚符是他随手画坏的废品，没想到反而救了他一命。他由此悟出一个道理："符文之道的精髓不在于完美的技巧，而在于那一丝灵性。"从此他不再追求符文的完美对称，转而追求注入其中的灵性。这也是为什么有些看似粗糙的护身符反而效果极佳。

## 修炼进度

**画符入门**：学会画最简单的聚气符，十张中能有一张成功即可。初学者需七日打好基础。

**成功提率**：成功率提升到五成以上，可画出金刚符、避水符等初级符。需三月练习。

**精通多种符**：掌握五种以上的护身符绘制方法，成功率八成以上。需一年。

**符师境界**：一笔成符、符成即灵。画出的护身符灵气饱满，效果上佳。至此可称为符师，需三年以上的积累。
