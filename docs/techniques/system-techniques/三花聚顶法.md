# 三花聚顶法

## 基本信息
- **功法名称**：三花聚顶法
- **品级**：三阶（地级）（地级）
- **类型**：体系功法
- **适用境界**：金丹期
- **修习难度**：★★★☆☆

## 功法介绍

三花聚顶法源自上古一位名为"青莲道人"的妖修。青莲道人本是一株生于昆仑山巅的千年青莲，在吸收了无数年的日月精华后开启了灵智，化形为人。她的本体是一株三花并蒂的异种青莲——同一根茎上开出三朵不同颜色的莲花：一朵纯白如雪（精之华）、一朵赤红如血（气之华）、一朵金黄如阳（神之华）。

青莲道人在化形后游历人间百年，发现人族修士虽然修炼速度远胜妖修，但大多"精、气、神"三者失衡——偏重修气者体质虚弱，偏重炼体者神识薄弱，偏重养神者真气不济。她结合自身三花同根的经历，创出了这套同时修炼精、气、神的法门，取名为三花聚顶法。所谓"三花"，即精花、气花、神花；"聚顶"，即三花在头顶泥丸宫汇聚，象征着精气神三者合一、圆满无缺。

## 功法特点

**优点：**
- 精气神三者同步提升，不会有偏科之虞。修炼者的体质、真气储量与神识强度均衡发展
- 三花聚顶后，修炼者的生命力、法力与精神力三者可相互转化——真气不足时可燃烧精神力补充，精神力不足时可消耗生命力恢复
- 对心魔有极强的抵御能力，因为精气神三者稳固，外邪难侵
- 达到圆满境界后，头顶会隐现三色光晕，万法不侵

**缺点：**
- 同时修炼三条路线，进度自然比单一路线的功法慢得多
- 修炼时需要同时保持三种不同的意念状态，极为耗神，修炼一次后需要休息更长时间
- 三花之中若有一花凋零（精亏、气虚或神损），则会拖累另外两花，整体修为大幅下跌
- 此功法品阶虽为三阶，但修炼难度堪比四阶功法

## 功法等级

**精花初绽**：精花对应的是肉身精血。此阶段修炼者通过特殊的炼体法门，将全身精血提炼凝聚，在下丹田处形成一朵能量态的白色莲花花苞。精花绽放后，修炼者的肉身强度大幅提升，寿元延长

**气花含苞**：气花对应的是真气修为。在中丹田（膻中穴）凝聚第二朵能量态红色花苞，以真气日夜灌溉。气花绽放时，修炼者的真气储量会成倍增长，且真气中带上了花的生机属性

**神花盛开**：神花对应的是神识灵魂。在上丹田（泥丸宫）凝聚第三朵能量态金色花苞，以精神力日夜温养。神花绽放时，修炼者的神识范围会大幅扩展，可覆盖方圆数十里

**三花聚顶**：下中上三个丹田的三朵花同时盛开，三花的光芒连成一线，在头顶泥丸宫上方汇聚成一朵巨大的三色莲花虚影。此时精气神三者互为根基、互相转化，修炼者进入了一个全新的境界

## 功法招式

1. **精血凝花法**：以特殊的手法按摩全身大穴，配合呼吸法将全身精血引导向下丹田。双手结"莲花印"，观想下丹田处有一朵白色莲花花苞在精血的灌溉下缓缓生长。每日修炼一个时辰，七七四十九日后可见花苞雏形。

2. **真气灌花法**：在运转周天积累真气的同时，将真气有意地引导到中丹田的气花花苞上。每次真气经过中丹田时，留下一丝真气滋养花苞，如同以露水浇灌花卉。切记不可过量，否则花苞会因"养分过剩"而萎缩。

3. **神识养花法**：以神识观想之法——闭上双目，想象自己看到一朵金色的花苞悬浮在泥丸宫中。用全部精神去感受它、温暖它、呵护它。神花对精神力的敏感度极高，修炼者情绪的细微波动都会影响其生长，因此修炼时需时刻保持平和喜悦的心境。

4. **三花贯气诀**：三朵花苞同时绽放后，以意念引导三花之间的真气流通。气花的真气上行至神花滋养神魂，神花的神识下行至精花强化肉身，精花的精血扩散至气花补充真气。从此三花一体，源源不绝。

5. **漫天花雨术**：三花聚顶后，可将三花之力外放，在周身范围内形成一片绚烂的花瓣光雨。光雨范围内的友方会感到精力充沛、伤势恢复加快；敌方则会感到昏昏欲睡、真气运转滞涩。此招是三花聚顶法唯一的范围性辅助招式，战场上极为实用。

## 修炼条件

**前置功法**：任意二阶功法修炼至大成以上。三花聚顶法对修炼者的根基要求较高，根基不牢者强行修炼会导致精气神三者全部崩溃

**灵根要求**：至少一条中品灵根，灵根数量越多越好。因为三花修炼需要大量灵气支撑，单一灵根的灵气吸收速度可能跟不上消耗

**修炼地点**：灵气充沛且环境优美宁静之处为佳。花海之中、灵果园内、瀑布旁的花谷都是理想选择。若环境太差，则会影响"花"的品质

**所需资源**：以木属性灵石为主，辅以各类灵花精华炼制的"百花丹"。条件允许的话，可在修炼室周围种植灵花灵草，形成一个小型花阵，对修炼有裨益

## 使用限制/副作用

- 三花中任何一朵受到重创都会导致整体失衡。例如精花受损则身体虚弱，气花受损则真气溃散，神花受损则神识混乱。修复受损的花比其他功法修复同等伤害困难三倍
- 修炼此功法者不可过度纵欲（损精花）、不可过度劳累（损气花）、不可过度用脑（损神花），日常生活需极为自律
- 三花聚顶后修炼者身上会散发出一股淡淡的花香，这种气味极易吸引妖兽和灵虫的注意。修为低微时，可能会引来不必要的麻烦
- 每个月圆之夜，三花会进入"满月期"——此时三花会变得异常活跃，修炼者会精气神过剩，辗转难眠，需要通过修炼来消耗多余的能量

## 相关典故

- **青莲道人的传说**：青莲道人最终修炼到了大乘期，在渡劫飞升时，她的三花本体化作了三道光柱直冲云霄，在天空中形成了一朵覆盖千里的三色莲花虚影。方圆千里的修士都闻到了奇异的莲香，据说闻到香气者都在修炼上有所突破。青莲道人飞升后，她生长的那株青莲根茎至今仍在昆仑山巅，每千年开一次花，每次开花都会引来无数修士朝圣。

- **三花婆婆**：五百年前有一位散修老妪，修炼三花聚顶法达到了三花聚顶后，容貌逆生长——从八旬老妪变回了二八少女。她自称"三花婆婆"，以驻颜之术闻名修真界。无数女修前来求教，但她留下"三花聚顶自然返老还童，没有捷径可走"一句话后便云游四方，再无踪迹。

## 修炼进度

**炼精化气**（约3-7年）：下丹田精花绽放。修炼者肉身显著强化，力量、速度、耐力全面提升，容貌开始变得年轻，白发转黑、皱纹淡化

**炼气化神**（约7-15年）：中丹田气花绽放。真气储量暴增，可以连续战斗数日不歇。头顶开始隐现淡淡红光（气花之光），修为高深者可见

**炼神还虚**（约15-25年）：上丹田神花绽放。神识范围扩展到数十里，可以同时监控多个目标。双目炯炯有神，目光如电，普通人不敢直视

**三花聚顶**（约25-50年）：三花在头顶汇聚，精气神三者合一。修炼者举手投足间都有一种自然的韵律，仿佛与天地融为一体。此时已在金丹期中走到了极致，可准备冲击元婴
