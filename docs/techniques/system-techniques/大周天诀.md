# 大周天诀

## 基本信息
- **功法名称**：大周天诀
- **品级**：四阶（天级）
- **类型**：体系功法
- **适用境界**：元婴期
- **修习难度**：★★★★☆

## 功法介绍

大周天诀是小周天诀的进阶版。小周天诀打通任督二脉，建立的是人体主干道的气血循环；而大周天诀则要将全身十二条正经、奇经八脉全部贯通，建立一个覆盖全身每一个角落的完整气网。

创造大周天诀的是汉代的"魏伯阳"，他是道教丹鼎派的鼻祖，也是《周易参同契》的作者。魏伯阳在研究炼丹术时发现，炼丹炉中的药材在高温下会沿着炉壁的管道循环流动，不断精炼提纯。他灵光一闪——人体不就是一座炼丹炉吗？经脉就是炉壁的管道，真气就是炉中的药液。如果能让真气像炼丹炉中的药液一样在全身上下循环流动，不是也能不断精炼提纯吗？于是他结合小周天诀的理论，创出了大周天诀——将全身经脉全部纳入循环系统，让真气在体内进行"大循环"。

## 功法特点

**优点：**
- 全身经脉打通后，真气可以到达身体的任何一个角落，任何一个部位的伤势都可以得到真气的滋养修复
- 大周天建立后，修炼效率比小周天时期提升数倍，因为全身的毛孔、窍穴都在参与灵气交换
- 对身体的控制达到入微级别，可以精确控制身体的每一条肌肉、每一根骨骼、甚至每一滴血液的流动
- 为元婴期的"身外化身"和"分神术"打下坚实基础

**缺点：**
- 修炼难度极高，需要打通全身数百个穴位和数十条经脉，每一条都需要花费大量时间和精力
- 冲击经脉时的痛苦是小周天修炼的数倍，越到后期越痛苦
- 大周天建立后，身体对灵气的需求暴增，需要更多的资源来维持运转
- 修炼过程中可能出现"全身剧痛"的排异反应——身体某些部位不适应真气的流经

## 功法等级

**正经贯通**：打通手三阴、手三阳、足三阴、足三阳共十二条正经，真气可以沿着这十二条经脉完成全身性循环

**奇经贯通**：打通任脉、督脉、冲脉、带脉、阴跷脉、阳跷脉、阴维脉、阳维脉八条奇经，使真气可以在正经与奇经之间自由切换

**大周天成**：正经与奇经全部贯通且形成完整的循环网络，真气在体内如同一个球形的网状结构，覆盖全身每一个部位

**天人感应**：大周天与天地的灵气循环相呼应，修炼者能清晰感知到天地灵气的潮汐涨落，并将自身的大周天与天地的大周天同步

## 功法招式

1. **十二正经连环法**：从手太阴肺经开始，依次贯通手阳明大肠经、足阳明胃经、足太阴脾经、手少阴心经、手太阳小肠经、足太阳膀胱经、足少阴肾经、手厥阴心包经、手少阳三焦经、足少阳胆经、足厥阴肝经。每打通一条经脉，就在该经脉的起点和终点处留下一道真气印记，作为后续连接的锚点。

2. **奇经八脉开天法**：在正经贯通的基础上，逐一打通奇经八脉。冲脉如江河之冲——从丹田直冲胸腹；带脉如束带——环绕腰部一周；阴跷脉从足走腹，阳跷脉从足走背；阴维脉维系诸阴经，阳维脉维系诸阳经。每条奇经的功能各不相同，打通的方法也各异。

3. **大周天循环术**：全部经脉打通后，引导真气按照最优路线进行大周天循环——从丹田出发，依次经过所有经脉，每一处都要到达，最后回到丹田。一个完整的大周天循环约需一个时辰，每日至少运转三个大周天。

4. **天人合一大法**：在深夜子时或正午午时，盘坐于天地之气最为通畅之处（山顶或开阔地），将自身的大周天循环频率调整到与天地灵气潮汐完全一致。当两者同步时，修炼者会感到自己与天地融为一体，天地灵气如同潮水般涌入体内，修炼效率可提升十倍。但此招极为凶险，若在同步过程中被打断，会导致体内真气与天地灵气剧烈冲突，后果不堪设想。

5. **经脉重构术**：大周天的最高奥义——在完全掌握经脉走向后，可以用真气对经脉进行"微调"，拓宽狭窄的经脉、修复受损的经脉、甚至开辟新的经脉路线。此招式需要对人体经脉结构有极为透彻的了解，稍有不慎就会导致经脉错乱。

## 修炼条件

**前置功法**：小周天诀达到圆满境界，任督二脉完全打通且运转流畅。这是修炼大周天诀的硬性前提，不可跳过

**灵根要求**：至少一条上品灵根，或两条中品灵根。因为大周天对灵气质量和数量都有极高的要求

**修炼地点**：最好的地点是大地灵脉的分支节点处。大周天修炼者需要大量的灵气支撑经脉打通和维持

**所需资源**：护脉丹、扩脉丹、补天丹等各种经脉类丹药大量。还需要至少一条灵脉作为修炼基地的能源支撑

## 使用限制/副作用

- 大周天建立后，身体对外界灵气的敏感度大幅提升。好处是修炼效率提高，坏处是在灵气稀薄或充满煞气的地方会感到极度的不适，如同鱼离开水般窒息
- 经脉全部打通后，身体的防御能力在短期内反而会下降——因为真气在经脉中高速流动，经脉壁被撑薄了，更容易受到外力的损伤
- 大周天的运转虽然大部分由身体自动完成，但仍需消耗一部分精神力来维持运转秩序。如果精气神不足，大周天的运转可能会紊乱
- 在战斗中如果大周天的运转节律被敌人的攻击打乱，可能会引发"真气逆行"——全身的真气在同一时间往反方向流动，导致剧烈的痛楚和短暂的失去战斗力

## 相关典故

- **魏伯阳与炼丹炉**：据《周易参同契》记载，魏伯阳在观察炼丹炉时发现，炉中的水银蒸汽沿着导气管上升，遇到冷后凝结成液滴，又顺着管壁流回炉底，如此循环往复。他由此悟出"人体如炉、经脉如管、真气如水银"的道理。魏伯阳后来在青城山闭关十年，将大周天诀完善后，在丹炉旁留下偈语："炉中火炼丹，体中气修仙。火候到时丹自转，功夫到处道自成。"然后不知所踪。

- **黄石公的考验**：传说张良年轻时在下邳桥上遇到一位老人（黄石公），老人故意将鞋踢到桥下，让张良捡回来穿上，反复三次，考验张良的耐心。张良通过了考验，黄石公便授予他《素书》一卷。但少有人知的是，黄石公真正传授给张良的其实是《大周天诀》的缩略版，张良靠着这套功法活了两百余岁，最后在留侯祠中安详坐化。

## 修炼进度

**正经期**（约5-15年）：逐一打通十二条正经。每打通一条，对应的器官和区域就会得到大幅强化——肺经通则呼吸深沉有力，心经通则血脉通畅精神饱满，胃经通则消化吸收能力大增

**奇经期**（约10-25年）：打通八条奇经。奇经如同江河的蓄水池，对正经的真气起到调节作用。奇经贯通后，修炼者的真气储备量会成倍增长

**大同期**（约20-40年）：正经奇经全部打通，形成完整的大周天网络。此时修炼者举手投足间都有真气相伴，体内的真气如同一个永不停歇的潮汐，往复循环

**感应期**（约30-50年）：大周天与天地同步，达到天人合一的境界。修炼者可感知天地灵气的流向，预知天气变化，甚至可以借助天地之势来提升自己的实力
