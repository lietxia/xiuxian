# 聚气诀

## 基本信息
- **功法名称**：聚气诀
- **品级**：一阶（黄级）（黄级）
- **类型**：体系功法
- **适用境界**：聚气期
- **修习难度**：★☆☆☆☆

## 功法介绍

聚气诀乃修真界流传最广、传承最久的入门功法之一。相传在万年之前，修真界尚处于蛮荒时代，人族修士各自摸索修炼之法，走火入魔者十之八九。此时一位自称"天灵散人"的游方修士，游历百国、观摩千种吐纳法门，去芜存菁，最终在东海之滨的一块礁石上闭关三年，创出了这部聚气诀。天灵散人将此法刻于七十二块玉简上，掷向四面八方，任人拾取修习，故聚气诀亦称"天授七十二法"之一。

聚气诀的核心要义在于一个"聚"字——天地灵气弥漫宇宙，但凡人无法直接利用，必须通过特定的方法将涣散的灵气收束、压缩、提炼，使之化为己用。聚气诀就像修建一座水库，先将四散的溪流汇聚成池，再筑堤蓄水，最终化为可发电灌溉的能源。正是这种"引而不发、聚而不散"的理念，使得聚气诀成为修真界公认的"万功之母"。

## 功法特点

**优点：**
- 真气凝聚效率在同阶功法中出类拔萃，比基础吐纳法的灵气转化率高出一倍
- 上手极快，资质上佳者三月可入门，一年可见效
- 真气性质温和中正，不偏属任何属性，后期转修任何功法都不会产生排斥
- 对环境的适应性极强，即便在灵气稀薄之地也能缓慢聚气

**缺点：**
- 纯粹的真气积累法门，不包含任何应用技巧，毫无战斗能力
- 修炼过程枯燥至极，需要日复一日地重复聚气-散气-再聚气的循环
- 过度依赖聚气诀会导致真气"惰性"——习惯了温和的聚气方式，后期修炼刚猛功法时经脉难以适应
- 聚气速度受限于个人体质，体弱多病者聚气效率大打折扣

## 功法等级

**引气**：感应到周围灵气存在，能以意念牵引一丝灵气进入体内，但无法留住，灵气会在数息内逸散，如手握流沙

**聚气**：成功将灵气引入丹田并留住，丹田内形成微弱的"气旋"，可主动吸附周围灵气。气旋稳定后，修炼者可感受到丹田处温热的"气感"

**凝气**：丹田气旋由虚转实，形成一团密度极高的真气团。此时真气已可外放于体表，形成一层若有若无的护体气罩，可抵御普通刀剑劈砍

**液化**：真气由气态压缩至液态，丹田内真气如汞浆般沉重粘稠，数量虽少但质量天差地别。液化是聚气诀的最高境界，达到此境后便可向筑基期发起冲击

## 功法招式

1. **丹田旋吸法**：盘坐闭目，意念集中于丹田，想象丹田处有一漏斗状漩涡。吸气时漩涡扩张，将周围灵气吸入；呼气时漩涡收缩，将吸入的灵气压缩在丹田底部。此招乃聚气诀之基本功，需反复练习直至形成肌肉记忆。

2. **周天聚气法**：待丹田真气充盈后，引导真气沿任督二脉做小周天循环。每运转一周天，真气在途经丹田时就会吸附一部分新吸入的灵气，如同滚雪球般越滚越大。一个完整的小周天约需一盏茶时间，每日至少运转三十六周天。

3. **毛孔聚气阵**：以意念引导丹田真气散至全身经脉网络，在体表形成一张无形的"真气网"，如同蜘蛛网捕捉飞虫般捕捉空气中游离的灵气粒子。此招需配合专门的呼吸节奏——吸气时网张，呼气时网收，将捕捉到的灵气顺着经脉拉回丹田。

4. **三田聚鼎法**：上丹田（眉心泥丸宫）、中丹田（胸口膻中穴）、下丹田（脐下三寸）同时打开，形成三个气旋，三者构成一个三角形气鼎。上丹田聚天地之清气，中丹田聚自身之元气，下丹田聚五谷之精气，三气合一，化作最纯粹的本源真气。

5. **归元归一诀**：聚气诀的终极奥义——将全身各处积蓄的真气全部收回丹田，以意念强力压缩，使真气液化。此招极为凶险，压缩过程中经脉会承受巨大压力，稍有不慎便会导致经脉破裂。但一旦成功，便意味着踏入聚气诀的极致，可冲击筑基。

## 修炼条件

**前置功法**：建议先修习基础吐纳法至少一年，使经脉适应气的存在。但资质卓绝者可直接修炼聚气诀

**灵根要求**：至少有一条下品灵根。无灵根者虽可习得引气，但无法聚气，永远停留在第一阶段

**修炼地点**：灵气浓度越高越好。最佳地点为灵脉支脉附近、灵石矿坑边缘、古木参天的原始森林。切忌在阴气、煞气、死气浓重的地方修炼，易导致真气污染

**所需资源**：黄品聚气丹（可提升30%聚气速度）、下品灵石（手握灵石修炼可加速灵气吸收）

## 使用限制/副作用

- 聚气过度会导致"气满为患"——丹田内真气过多无处疏导，出现腹胀、胸闷、头晕等症状，严重时丹田可能胀裂，需以推宫过血之法将多余真气导入四肢百骸
- 聚气诀修炼出的真气纯净但缺乏"活性"，若长时间只聚气而不应用，真气会变得死板呆滞，后期需要使用这些真气时会有"凝滞感"
- 在灵气稀薄之地强行聚气会消耗自身气血精气作为补充，导致面黄肌瘦、精神萎靡，俗称"以血养气"，对根基有损
- 每月需以特制药浴浸泡一次，排出聚气过程中吸入的杂质与浊气，否则杂质沉积在经脉中，长期会形成"丹毒"，使修炼效率逐年下降

## 修炼进度

**初识气感**（约3-6个月）：能够清晰感知到周围灵气流动，如同微风拂面，但尚不能有效留住灵气

**丹田蓄气**（约6个月-2年）：丹田内形成稳定气旋，可自主吸附灵气。修炼者饭量增大、睡眠减少、精力充沛，初步体会到修炼带来的身体变化

**气满自溢**（约2-5年）：丹田真气充盈到一定程度后会自然向外溢出，沿经脉缓慢流动。此时修炼者会感到四肢百骸有一股暖流游走，舒适无比，这也是许多人沉迷修炼的原因
