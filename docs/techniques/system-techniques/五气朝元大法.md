# 五气朝元大法

## 基本信息
- **功法名称**：五气朝元大法
- **品级**：五阶（仙级）（仙级）
- **类型**：体系功法
- **适用境界**：化神期
- **修习难度**：★★★★★

## 功法介绍

五气朝元大法乃五气朝元功的仙级进阶，由上古时期人族五大医圣之一的"歧伯"在《黄帝内经》的基础上进一步完善创制。歧伯在与黄帝的对话中提出了"五脏化五气"的理论——心藏神、肺藏魄、肝藏魂、脾藏意、肾藏志，五脏不仅仅是生理器官，更是精神与灵魂的安居之所。

歧伯晚年隐居在祁连山脉深处的一处秘境中，花了整整两百年时间，将五气朝元功提升到了一个全新的境界。他发现五气朝元功仅仅能引五行灵气入五脏，这只是最基础的层次；更高层次的修炼应该是"五气化神"——将五脏中储存的五行灵气进一步提纯，转化为五种精神力量：心神（火）、肝魂（木）、脾意（土）、肺魄（金）、肾志（水），然后让这五种精神力量在泥丸宫中"朝元"，使修炼者的灵魂得到本质的升华。

## 功法特点

**优点：**
- 五脏化五神后，修炼者的灵魂强度是同阶修士的数倍，元神极为凝实
- 五种精神力量相互配合，使得修炼者的感知、意志、智慧、勇气、韧性全面提升
- 对夺舍、搜魂等灵魂攻击手段有极强的抵抗力，五神如同五道屏障守护灵魂
- 五脏得到五行灵气与五神的双重滋养，生理机能远超常人，在同阶中寿命最长

**缺点：**
- 五神修炼需要同时掌控五种精神力量，对心性的要求极高，任何情绪的剧烈波动都会影响五神的平衡
- 五神受损的修复极为困难——不仅仅是疗伤的问题，还需要弥补精神层面的创伤
- 修炼此功法后，五脏与五魂深度绑定，如果某个脏腑受到物理损伤，对应的"神"也会受伤
- 化神期的天劫会比普通化神修士强得多——因为五神同时渡劫，五道神魂之劫会同时降临

## 功法等级

**五神初醒**：五脏中的五神被初步唤醒——心神清明、肝魂安宁、脾意坚实、肺魄刚毅、肾志坚定。修炼者开始感受到五脏中"活"的力量

**五神各守**：五神各自在对应的脏腑中稳定下来，各司其职。心神掌管意识、肝魂掌管情绪、脾意掌管思维、肺魄掌管勇气、肾志掌管毅力。五神各守其位，修炼者的心智变得极为稳定

**五神共鸣**：五神之间建立起了联系，开始相互呼应。心神喜悦时肝魂随之舒畅，肺魄激昂时肾志随之坚定，脾意沉稳时其他四神也随之平和。五神共鸣的状态下，修炼者的精神状态达到了完美的和谐

**五神朝元**：五神从五脏中同时升起，在泥丸宫中汇聚合一，形成了一个更为强大的"元神圣胎"。这是化神期的真正标志——化神，就是化五神为一神

## 功法招式

1. **五脏内观法**：闭目内视，依次观想五脏。观想时不仅看其形状颜色（心红如莲、肝青如竹、脾黄如金、肺白如银、肾黑如墨），更要感受五脏中蕴含的精神力量——心的灵动、肝的生发、脾的包容、肺的肃杀、肾的收藏。此招旨在建立与五脏精神的连接。

2. **五神唤醒诀**：以特殊的声波共振法唤醒五脏中的五神。对心脏发出"呵"音以动心神，对肝脏发出"嘘"音以动肝魂，对脾脏发出"呼"音以动脾意，对肺脏发出"呬"音以动肺魄，对肾脏发出"吹"音以动肾志。五音齐鸣时，五脏同时共振，五神被一同唤醒。

3. **神意合一术**：调和五神之间的关系。人的五种精神力量天然就存在冲突——心神想要快乐、肝魂想要生长、脾意想要稳定、肺魄想要征服、肾志想要坚持。如果不加调和，五神会在体内相互争斗。此招式就是通过特定的冥想方法，让五神明白它们是一体的，彼此之间应该合作而非对抗。

4. **五行化神法**：将五脏中储存的五行灵气全部转化为对应的精神力量。火灵气化为心神之力——增加感知与智慧；木灵气化为肝魂之力——增加生机与活力；土灵气化为脾意之力——增加沉稳与包容；金灵气化为肺魄之力——增加勇气与决断；水灵气化为肾志之力——增加毅力与坚持。转化完成后，五行灵气不再以能量形态存在，而是化为了精神的养料。

5. **元神圣胎凝法**：五神朝元的最后一步——将心神、肝魂、脾意、肺魄、肾志五种精神力量在泥丸宫中融合，凝聚成一个"元神圣胎"。圣胎形成的过程极为痛苦，五种精神力量在泥丸宫中相互缠绕、磨合，如同五种颜色的丝线编织在一起。成功之后，元神圣胎会取代原来的元婴，变得更加强大且具有五种属性之力。

## 修炼条件

**前置功法**：五气朝元功达到圆满境界，五脏中五行灵气充盈且运转自如

**灵根要求**：五行灵根齐全且全部达到中品以上，缺一不可。此外，对灵魂资质也有极高要求

**修炼地点**：祁连山脉深处的五气朝元洞府（相传是歧伯当年的修炼之地）为最佳。其次可选择五行灵气均衡且气场宁静的洞天福地

**所需资源**：养魂木、凝神果、五行灵髓等滋养神魂的天材地宝。五阶以上的五行妖兽内丹各一，用于辅助五神觉醒

## 使用限制/副作用

- 五神之间若长期失衡，会导致精神类疾病——心神太旺则狂躁、肝魂太盛则易怒、脾意过重则固执、肺魄过剩则残忍、肾志过量则偏执
- 五神朝元过程中，五种精神力量融合的瞬间会释放出巨大的精神冲击，如果修炼者的识海不够坚固，可能会被冲击成白痴
- 凝聚元神圣胎后，原来的元婴会消失。如果在融合过程中失败，元婴和五神都会受到重创，修为可能从化神期跌落到元婴期甚至金丹期
- 五神与五脏深度绑定后，如果某个内脏被毁（例如心脏被刺穿），对应的神也会消散，元神圣胎会变得不完整，需要漫长的时间来修复

## 相关典故

- **歧伯的五气朝元洞府**：歧伯在祁连山脉的洞府被称为"五气圣府"，洞府中有一口五色灵泉，泉水从五个方向汇入中央的池子——五色水在池中交汇却不相混，各自保持纯净。据说喝下此泉水可以暂时开启五脏内视的能力，是修炼五气朝元大法的至宝。但此洞府被歧伯用大阵封锁，只有有缘人才能进入。

- **华佗的五禽戏真解**：华佗临刑前在狱中烧毁了自己毕生的医术手稿，但《五禽戏真解》的一份副本被狱卒偷偷保留了下来。这份副本中除了五禽戏的招式外，还记载了华佗将五气朝元大法的原理融入医术的心得——他用肝魂之力激发患者生机、以肺魄之力驱散病邪、以肾志之力固本培元。这份手稿如今下落不明，据传藏于某座古墓之中。

## 修炼进度

**内观期**（约10-30年）：通过持续的内视修炼，能够清晰感知五脏中五神的"存在"。此阶段修炼者会频繁做梦——梦见五色光芒、五种动物、五种景象，这些都是五神的具象化表达

**唤醒期**（约20-50年）：五神逐一被唤醒，修炼者的精神状态开始发生显著变化——思维变得更加敏锐、情绪更加稳定、意志更加坚定

**调和期**（约30-60年）：五神之间建立共鸣，五种精神力量协同运作。此阶段的修炼者心性极度成熟，遇事沉着冷静、处变不惊，已具备了大修士的风范

**朝元期**（约50-100年）：五神朝元合一，凝聚元神圣胎。化神期的修炼达到顶点，为冲击炼虚期做好了充分准备——因为五神合一后，修炼者的灵魂已经具备了一部分"虚"的特性
