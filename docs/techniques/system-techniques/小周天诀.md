# 小周天诀

## 基本信息
- **功法名称**：小周天诀
- **品级**：三阶（地级）（地级）
- **类型**：体系功法
- **适用境界**：金丹期
- **修习难度**：★★★☆☆

## 功法介绍

小周天诀的起源可追溯到春秋时期的老子李耳。据《道藏》记载，老子西出函谷关时，被关令尹喜强留，不得已著书五千言，是为《道德经》。然而世人鲜知的是，老子在函谷关停留期间，还暗中传授了尹喜一套修炼法门——那便是最初版的小周天诀。

老子在传授时言道："天地之间，其犹橐龠乎？虚而不屈，动而愈出。"意思是说，天地之间就像一个风箱，看似虚空却蕴含着无穷的能量，越是鼓动它，能量就越是用之不尽。人体亦是如此，任督二脉就是人体的"橐龠"，打通任督二脉、形成真气的小周天循环，就相当于在人体内造了一个永不枯竭的风箱，让真气在其中生生不息地运转。后世的修炼者将老子的这一理论不断丰富完善，最终形成了今天的小周天诀——一部专注于打通任督二脉、建立体内真气小循环的功法。

## 功法特点

**优点：**
- 专注于任督二脉的贯通，目标明确、路径清晰，是打通任督二脉效率最高的功法之一
- 任督二脉一通，真气在体内的运转速度会翻倍，修炼效率大幅提升
- 小周天循环建立后，修炼者将进入"无意识修炼"状态——即使不刻意修炼，真气也会自动循着小周天的路线运转
- 是几乎所有高阶功法的必修基础，许多高阶功法都要求小周天诀达到大成方可修炼

**缺点：**
- 修炼过程极为痛苦——打通任督二脉时需要强行冲击人体最关键的几个关卡，过程如同用针在经脉中穿行
- 除了打通任督二脉外，此功法没有太多其他用途，战斗能力几乎为零
- 若在打通过程中中断或失败，可能会导致经脉损伤，需要休养数月甚至数年
- 小周天诀只涉及任督二脉，对其他经脉的修炼没有帮助，是一个"窄而深"的功法

## 功法等级

**任脉初通**：任脉（前正中线）被初步打通，真气可以从丹田沿任脉上行至咽喉。此阶段修炼者可感受到一股暖流从腹部升起，经过胸口到达喉咙，被称为"气贯中庭"

**督脉初通**：督脉（后正中线）被初步打通，真气可以从尾闾沿督脉上行至头顶。此阶段修炼者可感受到一股热流从尾骨升起，沿着脊柱直上百会，被称为"气冲华盖"

**周天循环**：任督二脉全部打通，且真气可以沿着"丹田→会阴→尾闾→命门→夹脊→玉枕→百会→印堂→鹊桥→膻中→丹田"的路线完成一个完整的循环

**周天自转**：经脉通道被彻底拓宽，真气运转不再需要意念引导，而是如同心脏跳动般自动持续运转。此时真气每时每刻都在自我循环、自我精炼

## 功法招式

1. **丹田点火法**：修炼前的准备功夫。将全部真气收束于丹田，以意念不断压缩，直到丹田处的真气产生"燃烧"感——仿佛有一团火焰在丹田中燃烧。这团"火"就是后续冲击经脉的动力来源，火力越旺冲击力越强。

2. **会阴冲关法**：小周天的第一大关。将丹田中压缩好的真气引导至会阴穴，然后猛然发力，如同攻城锤撞击城门一般冲击会阴关卡。会阴穴打通时，修炼者会感到一阵剧烈的刺痛从下体传遍全身，随后是一股强烈的快感——这是真气通过会阴穴后进入督脉的信号。

3. **三关破障诀**：督脉上有三处最关键的关卡——尾闾关、夹脊关、玉枕关，被称为"后三关"。每一关都需要积蓄足够的真气后发动强冲。尾闾关在尾骨末端，打通时可听到"咔嚓"声如骨节错位；夹脊关在背部中央，打通时如重锤砸背；玉枕关在后脑枕骨处，最为凶险，打通时如当头棒喝，眼前会白光一闪。

4. **鹊桥接引法**：当真气沿督脉上行至百会后，需要下行到任脉，中间经过印堂、鼻梁、上颚——这段路程被称为"鹊桥"。最关键的是舌尖抵住上颚的动作（搭鹊桥），真气通过舌尖的桥梁从上颚的龈交穴过渡到下颚的承浆穴，从而完成从督脉到任脉的交接。

5. **周天蕴养诀**：任督二脉打通且形成稳定循环后，不再强行冲击，而是以温养为主。用意念引导真气沿着小周天路线缓慢运行，每运行一周天就壮大一分，如同用砂纸打磨管道，使经脉越来越光滑、通道越来越宽阔。每日至少运行三百六十周天。

## 修炼条件

**前置功法**：基础吐纳法或聚气诀达到圆满。修炼者必须体内真气充盈、经脉基础良好，否则强行冲击关卡会导致经脉永久性损伤

**灵根要求**：至少一条中品灵根。小周天诀对灵根属性无特殊要求，但灵根品质决定了冲击关卡时的真气质量和恢复速度

**修炼地点**：安静、温暖、无风的环境为佳。冲击关卡时修炼者全身会出汗，毛孔张开，若受风寒容易导致真气逆行。建议在专门的修炼室中进行

**所需资源**：大量补充气血的丹药，因为冲击关卡会消耗大量体力与气血。"通脉丹"是小周天修炼的必备丹药，可软化经脉壁、降低冲击阻力

## 使用限制/副作用

- 冲击关卡时若用力过猛，会导致经脉撕裂，真气从撕裂处泄漏到血肉中，造成内出血。严重时需要以丹药修复经脉且休养半年以上
- 小周天循环建立后，修炼者的体温会比常人略高（约高0.5-1度），这是真气持续运转产生的热量
- 修炼此功法期间不可进行剧烈战斗，因为战斗可能打乱真气运转节奏，导致正在冲击的关卡功亏一篑
- 小周天打通后的一段时间内，修炼者会感到浑身燥热、精力过剩、难以入睡，这是经脉通畅后真气运行加速的正常反应，一般持续一到三个月

## 相关典故

- **老子传道函谷关**：《道藏·尹喜内传》记载，尹喜在得到老子传授的小周天诀后，于函谷关中闭关修炼七七四十九日，成功打通了任督二脉。出关之日，函谷关上空紫气东来三万里，老子见状微笑点头，跨青牛西去。尹喜后来将小周天诀与《道德经》一同流传于世，成为道家修炼的基石。

- **吕祖百日筑基**：八仙中的吕洞宾早年修炼小周天诀，以百日时间打通任督二脉，创造了"百日筑基"的传说。他在《太乙金华宗旨》中记载了自己打通三关时的感受："尾闾关如烈火焚身，夹脊关如万仞穿心，玉枕关如霹雳击顶。三关过后，周身通泰，如登极乐。"他的百日筑基经验成为后世无数修炼者的参考标准。

## 修炼进度

**蓄力期**（约1-3年）：全力积累真气，为冲击关卡做准备。此阶段修炼者需大量服用补气丹药，将丹田真气压缩到极限，如同拉满的弓弦

**破关期**（约3-7年）：依次冲击尾闾、夹脊、玉枕三关，以及会阴、鹊桥等关卡。每一关的突破都需要数月至数年的努力，且充满痛苦与风险

**贯通期**（约7-15年）：所有关卡全部打通，真气可以完整地运行小周天。初次完成周天循环时，修炼者会有一种"醍醐灌顶"的畅快感，仿佛全身经脉被彻底清洗了一遍

**自转期**（约15-30年）：小周天运转如呼吸般自然，不需要刻意控制。达到此境界后，修炼者即使睡觉、吃饭甚至战斗时，小周天都在自动运转，时时刻刻都在修炼
