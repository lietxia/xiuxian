# 灵气引导术

## 基本信息
- **功法名称**：灵气引导术
- **品级**：一阶（黄级）（黄级）
- **类型**：体系功法
- **适用境界**：聚气期
- **修习难度**：★☆☆☆☆

## 功法介绍

灵气引导术并非人类独创，其源头可追溯至太古时期的"风语者"部落。在那个蛮荒年代，有一支人族部落生活在风暴肆虐的大荒平原上，族人常年与狂风为伴。部落中的一位智者"风伯"，在观察旋风卷起落叶、江河奔流入海的自然现象时，顿悟了"引导"的奥秘——灵气如同流水，不会主动进入人体，需要以意念为渠、以经脉为道，将之引导入丹田。

风伯将这套方法传授给族人，使原本体弱的人族部落逐渐强大起来，成为大荒平原上的霸主。后人将风伯的经验整理成书，名为《引灵策》，经万载流传，最终演变为今日的**灵气引导术**。此功法与基础吐纳法的"被动吸引"和聚气诀的"主动收束"不同，强调的是"引导疏通"——不是粗暴地将灵气拉入体内，而是温柔地引导灵气按照经脉的走向自然流入，如同疏浚河道让水流自行通过。

## 功法特点

**优点：**
- 对经脉的冲击极小，是体弱多病或年老体衰者最适合的入门功法
- 修炼过程中同时疏通经脉，对经脉的养护效果极佳，被誉为"经脉的瑜伽"
- 可精确控制灵气在体内的流向，为后期的炼丹、炼器等精细操作打下基础
- 对灵气的利用率极高，吸入的灵气几乎不会逸散

**缺点：**
- 修炼速度极慢，是所有一阶功法中最慢的，比基础吐纳法还慢三成
- 对意念控制力的要求较高，心神不宁者难以掌握
- 初期效果不明显，修炼三五年可能都感觉不到明显进步，极易打击信心
- 不擅长爆发性的真气运用，修炼者往往真气绵长但爆发力不足

## 功法等级

**感气**：能够感知到体内真气流动的方向和速度，如同闭眼感受到血液在血管中流动。此境需要极高的专注力和身体感知能力

**引气入脉**：能以意念引导真气从丹田出发，沿指定经脉路线前进，如同用手托着一片羽毛在迷宫中穿行。真气走到哪里，哪里就会有温热感

**气随意动**：意念所至，真气随之而至，不再需要刻意集中精神。心念一动，真气便已到达指定位置，如臂使指，灵活自如

**引导自如**：真气可同时在多条经脉中并行流动，互不干扰，如同同时拨弄多根琴弦。此境界下，修炼者可一边引导真气冲击关卡，一边维持丹田运转，一心多用

## 功法招式

1. **顺水推舟法**：吸气时意念引导真气从丹田出发，沿任脉上行；呼气时引导真气沿督脉下行，回到丹田。每一呼一吸完成一个小循环，如顺水行舟，不施外力，只靠呼吸的起伏推动真气流动。此招旨在让修炼者熟悉真气的"习性"。

2. **九曲回廊法**：将经脉想象成一座九曲回廊，真气是廊中漫步的行人。引导真气依次经过手三阴、手三阳、足三阴、足三阳，每经过一个穴位停留三息，感受穴位处的气感变化。全套走完如同逛完一座园林，悠然自得。

3. **潮汐引导法**：模仿海洋潮汐的涨落节奏——吸气时真气如潮水般涌向四肢末端，呼气时真气如退潮般收回丹田。一涨一落之间，经脉被反复冲刷，如同海浪打磨礁石，使经脉更加光滑柔韧，灵气通过时阻力越来越小。

4. **灯芯引火法**：将丹田比作灯盏，真气比作灯油，意念比作灯芯。以意念为引，将丹田中的真气"点燃"，而后引导这团"火焰"沿经脉缓缓移动。每到一处穴位，火焰便将该穴位的淤堵"烧"通。此招对打通经脉关卡有奇效。

5. **百川归海诀**：引导术的终极奥义——同时引导全身各处散落的真气微粒向丹田汇聚，如同千百条溪流同时汇入大海。这需要修炼者分化意念，同时感知和控制全身各处的真气流动。成功之时，丹田处会形成一股强烈的吸引力，将体内所有真气瞬间收束归一。

## 修炼条件

**前置功法**：建议先修习基础吐纳法半年以上，使体内有基本的气感。但直接修炼亦可，只是初期气感形成会慢一些

**灵根要求**：至少有一条下品灵根。引导术对灵根的依赖稍低，但完全没有灵根者无法精确控制真气的流向

**修炼地点**：安静无风的室内为佳，因为引导术需要极为专注的精神状态，外界干扰越少越好。灵气浓度倒不是最重要的

**所需资源**：清心宁神的辅助物品最佳，如檀香、安神香、静心玉佩等。初期可配合"引气丹"服用，此丹药可在短时间内提升真气对意念的响应灵敏度

## 使用限制/副作用

- 过度引导会导致"神疲"——长时间高度集中意念控制真气流动，会大量消耗精神力，导致头痛、眼涩、耳鸣，严重时可能出现幻觉。每日修炼时间不宜超过四个时辰
- 引导过程中若突然受到惊吓，真气可能岔入错误的经脉，引发"岔气"，表现为对应经脉区域的剧痛。岔气不严重时可自行运转引导术将之导回正轨
- 引导术修炼者长期处于"精细控制"模式，导致对粗暴的、大功率的真气运用方式不适应，在需要爆发大量真气的战斗中会感到力不从心
- 过分沉迷于引导技巧可能导致忽视真气的积累，出现"控气技巧一流但真气储量不足"的偏科现象

## 相关典故

- **风伯与《引灵策》**：大荒平原上的风语者部落至今保留着古老的祭祀传统，每年风季到来时，部落中的长者会登上最高峰，迎着狂风施展最原始的灵气引导术，将风暴中的狂暴灵气引导入地下灵脉，以平息天灾。据说风伯晚年被风暴卷上九霄，在雷电中化为了一缕清风，永远守护着大荒平原。

- **盲眼琴师**：三百年前修真界有一位盲眼修士，名唤"弦音子"。他幼年失明，却修炼灵气引导术达到了前无古人的境界——他无法用眼睛看，却能以真气感知周围的一切，甚至能以真气引导琴弦弹出能够治愈伤势的乐曲。他的引导术造诣之高，可以在同一时间为三十六个人同时引导真气疗伤，且互不干扰。

## 修炼进度

**感知期**（约3-6个月）：能够清晰感知到丹田中真气的存在和流动方向，但引导能力非常有限，真气常常"不听使唤"，需要反复尝试

**控气期**（约6个月-2年）：能够基本控制真气在主要经脉中的流向，但控制精度不高，容易"走过头"或"半路停下"。此阶段需大量练习来建立意念与真气的默契

**精通期**（约2-5年）：真气感应如臂使指，可以精确控制真气到达身体任何一处。此阶段的修炼者即使闭着眼也能以内视之法"看到"自己经脉的全貌

**化境期**（约5-10年）：进入了"不引导而引导"的境界——意念不需要刻意驱动真气，一个微小的念头波动，真气便会自动做出最合适的反应。此境已触及"道"的边缘
