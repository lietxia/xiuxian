# 金丹结成诀

## 基本信息
- **功法名称**：金丹结成诀
- **品级**：五阶（仙级）
- **类型**：体系功法
- **适用境界**：化神期
- **修习难度**：★★★★★

## 功法介绍

金丹结成诀是一部极为特殊的高阶功法。一般来说，金丹期修士的金丹是在筑基期圆满后自然而然凝聚而成的，但金丹结成诀却反其道而行之——它是在化神期以强大的修为与境界，重新淬炼和升华自己已经成型的金丹，将其从普通金丹提升为"九转金丹"。

此功法的创始人是被誉为"丹道之祖"的太上老君——当然，修真界流传的版本是老君的一道分身降临人间，化身为一号"青牛老人"的炼丹师所创。青牛老人在一次炼丹时失手，将一炉即将成型的九转还丹打翻，丹液溅到了一旁修炼的弟子身上。诡异的是，这名弟子体内的金丹竟然吸收了丹液的精华，发生了质变——金丹表面出现了九道丹纹，威力提升了数倍。青牛老人由此受到启发，创出了这套以"炼外丹之法炼内丹"的金丹结成诀。

## 功法特点

**优点：**
- 将普通金丹淬炼为九转金丹后，金丹的品质会发生质变，真气的纯度和储量都是普通金丹的数倍
- 金丹表面的九道丹纹各自拥有不同的特效——有的增加恢复速度、有的增强攻击威力、有的提升防御能力
- 九转金丹与元婴的契合度极高，为后期孕育更强大的元神元婴奠定基础
- 金丹结成诀在淬炼金丹的过程中也会淬炼经脉和丹田，使修炼者的根基更加稳固

**缺点：**
- 需要在化神期重修金丹——这意味着修炼者要打破已经稳固的金丹，重新凝聚，过程极为痛苦且危险
- 修炼资源消耗极为恐怖，需要以炼丹之法收集大量的天材地宝作为淬炼金丹的"药材"
- 九转金丹的每一次"转"都是一次生死考验，九次转炼失败任何一次都可能导致金丹破碎
- 整个修炼过程需要消耗大量时间，且在此期间修炼者的修为增长极度缓慢

## 功法等级

**一转金丹**：打破原有金丹，重新凝聚。新凝聚的金丹上出现第一道丹纹，丹纹如同金丝缠绕在金丹表面，使金丹更加坚固。一转完成后，真气纯度和储量提升约三成

**三转金丹**：连续完成三次转炼，金丹表面出现三道丹纹。三转金丹已经超越了普通金丹的范畴，真气中开始带有淡淡的金色光泽

**六转金丹**：完成六次转炼，金丹表面的丹纹增加到六道。六转金丹已经具备了一丝"不朽"的特性——金丹中的真气即使被消耗掉，也能在极短的时间内恢复

**九转金丹**：九次转炼全部完成，金丹表面布满了九道完整的丹纹，金丹整体呈现出完美的圆形，金光灿灿，如同一颗微型的太阳。九转金丹一成，修炼者的根基就无比稳固，为冲击下一个大境界奠定了最坚实的基础

## 功法招式

1. **碎丹重凝法**：第一步也是最危险的一步。以强大的真气之力将体内的金丹震碎——不是真的粉碎，而是沿着金丹原本的纹理将其"拆解"成无数个碎片。然后以精神力包裹这些碎片，引导它们重新组合。整个过程中修炼者会感到撕心裂肺的痛楚，因为金丹与经脉、丹田紧密相连。必须一气呵成，若中途停止则金丹无法复原。

2. **五行淬丹法**：将五种属性的天材地宝炼化，以五行之力轮流淬炼金丹。先将火焰属性的赤焰果精华引入金丹，灼烧其中的杂质；再用寒冰属性的玄冰髓冷却，使金丹凝固；接着以木属性的青木之气滋养，修复灼烧带来的微小损伤……如此五种属性轮替，每轮替一次金丹就会被淬炼得更加纯粹。

3. **丹纹烙印术**：每次淬炼完成后，以神识在金丹表面烙印一道丹纹。丹纹的图案极为复杂，包含了空间法则的奥义——每一道丹纹都在微小的尺度上折叠空间，使金丹能够储存远超体积限制的真气量。烙印丹纹时神识需要极度专注，稍有偏差就会导致丹纹破碎，前功尽弃。

4. **丹火内炼法**：将丹田化作一座炼丹炉，以自身真元为燃料，点燃"丹火"——一种介于实体和能量之间的火焰。将金丹投入丹火中焚烧，如同炼丹师用火焰炼制丹药一般。丹火的热度控制在金丹刚好可以承受的临界点，过高则金丹融化，过低则无法淬炼。此法对火候的掌控要求极高。

5. **九转归元诀**：九次转炼全部完成后，将九道丹纹的力量同时激活。九道丹纹在金丹表面形成一个复杂的符文阵列，将金丹与天地法则连接起来。这一瞬间，修炼者会感受到天地法则的浩瀚——金丹不再仅仅是一个储存能量的容器，而是成为了修炼者与天地沟通的桥梁。

## 修炼条件

**前置功法**：任意三阶以上的修炼功法达到圆满境界，金丹必须已经稳固且品质不低于上品。品质太差的金丹经不起九转淬炼

**灵根要求**：至少一条上品灵根。金丹结成诀的真气消耗量极大，灵根品质不够的话，灵气吸收速度跟不上消耗速度

**修炼地点**：必须在一处拥有地火（天然火焰灵脉）的地方修炼，因为丹火内炼法需要借助地火之力。最佳地点是火山口下方的地火溶洞

**所需资源**：赤焰果、玄冰髓、青木之心、大地之精、太白金精——五种属性的天材地宝各一份（年份越高越好）、护脉丹、固丹丹、九转还丹（辅助丹药）

## 使用限制/副作用

- 碎丹的过程极度痛苦，约有三分之一的修炼者因为无法忍受这种痛苦而中途放弃，而放弃就意味着金丹受损，修为倒退
- 九转过程中每一次转炼完成后，金丹都需要一段时间的"休养"来稳定，在此期间修炼者的战斗力会大幅下降，需要尽可能避免与人争斗
- 如果九转全部完成但丹纹烙印有细微的偏差，金丹虽然看似圆满但实则存在隐患，可能在未来的某次战斗中突然爆发，导致金丹碎裂
- 九转金丹的品质太高，可能会引起天妒——天道可能会在修炼者渡劫时降下更强的天劫来"平衡"

## 相关典故

- **青牛老人的丹炉**：传说青牛老人的炼丹炉并非凡品，而是以一块天外陨铁铸造的九转神炉。他飞升后，这座丹炉被保存在大陆中央的丹神宫中。每年丹道大会时，丹炉会自动燃起炉火，若是真正的炼丹天才靠近，炉火会变成金色——据说这就是青牛老人留下的考验。

- **吕洞宾的九转金丹**：八仙之一的吕洞宾据说是继青牛老人之后成功炼出九转金丹的第二人。他在《纯阳文集》中记载了自己碎丹时的感受："碎丹之时，痛入骨髓，魂魄欲散。然念及大道在前，忍一时之痛换长生之基，何乐不为？"吕洞宾的九转金丹在他渡劫飞升时化作了一道金光，冲破天际，照亮了半边天空。

## 修炼进度

**碎丹期**（约5-15年）：破碎原有金丹，在剧痛与新生的交替中重塑丹基。此阶段修炼者的修为会暂时跌落到金丹初期甚至筑基期，是最脆弱的时期

**转炼期**（约15-50年）：逐次完成三转到九转的淬炼。每完成一转，修为就恢复一成并额外增长。此阶段修炼者需要不断收集天材地宝，奔波于各地寻找资源

**纹成期**（约30-70年）：九道丹纹全部烙印完毕，金丹达到完美状态。修炼者的修为会超过碎丹之前的水平，且根基之稳固远超同阶

**丹成期**（约40-90年）：九转金丹大成，金丹中蕴含的能量已经远超普通金丹的范畴。此阶段的修炼者虽然境界仍是化神期，但真正的实力已经可以媲美炼虚期修士
