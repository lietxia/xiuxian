# 五气朝元功

## 基本信息
- **功法名称**：五气朝元功
- **品级**：三阶（地级）（地级）
- **类型**：体系功法
- **适用境界**：金丹期
- **修习难度**：★★★☆☆

## 功法介绍

五气朝元功的核心理念源自人体五脏与天地五行的对应关系。传说在上古时期，医道圣贤"岐伯"在编纂《黄帝内经》时，首次系统阐述了五脏与五行的对应：心属火、肝属木、脾属土、肺属金、肾属水。然而岐伯虽知五脏对应五行，却并未将其应用于修炼。

真正将这一理论转化为修炼功法的是战国时期的方士"邹衍"。邹衍一生钻研五行学说，提出了"五德终始说"，晚年更是将自己的理论付诸实践，创造出了五气朝元功的雏形。他通过特殊的呼吸法门和意念引导，将天地间的五行灵气分别引入对应的五脏——以心引火、以肝引木、以脾引土、以肺引金、以肾引水，使五脏如五座宝库般储存对应的五行灵气。当五脏的灵气充盈到一定程度，就会"朝元"——五气同时上朝于脑，汇聚于泥丸宫中，形成五气朝元之态。

## 功法特点

**优点：**
- 五脏得到五行灵气的长期温养，生理功能大幅增强。修炼者几乎不会生病，寿命比同级修士长约两成
- 五气朝元后，泥丸宫中汇聚的五种灵气可以随时调配使用，战斗时可发出混合属性攻击
- 对炼丹术有极强的辅助作用——炼丹需要掌控火候与药性，而五脏的五行感应可以帮助炼丹师精准判断药材的属性与变化
- 修炼至大成后，五脏会变得异常强韧，即便受到重击也不易受损

**缺点：**
- 需要使用五行灵气分别灌溉五脏，操作极为繁琐，修炼一次需要同时控制五种不同属性的灵气流入对应的脏腑
- 若某种属性的灵气吸入过多而对应脏腑无法承载，会导致该脏腑"过载"，出现对应的病症（如心火过旺则心慌失眠、肾水过盛则畏寒浮肿）
- 修炼过程中需要同时保持五脏的五行平衡，难度极高，稍有疏忽就会失衡
- 五脏对应五气，若有脏腑天生虚弱或有暗疾，则该脏腑对应的灵气修炼会受到极大阻碍

## 功法等级

**五气初感**：能感知到五脏各自的"气"——心脏的跳动带来火属性的温热感，肝脏的舒展带来木属性的生机感，脾脏的运化带来土属性的厚重感，肺脏的呼吸带来金属性的清凉感，肾脏的藏精带来水属性的滋润感

**五气入脏**：成功将五种属性的灵气引导进入对应的五脏。每次吸入灵气时，有意地将灵气按照属性分流——火灵气入心、木灵气入肝、土灵气入脾、金灵气入肺、水灵气入肾

**五气充盈**：五脏中的五行灵气积蓄到了饱和状态，五脏开始散发出对应的光晕——心红、肝青、脾黄、肺白、肾黑。此时五脏功能大幅提升，修炼者的感知变得极为敏锐

**五气朝元**：五脏中的灵气同时上冲，沿着任脉、经咽喉、过舌尖、上达于脑，在泥丸宫中汇聚成五色光团。光团稳定后，修炼者的眉心会出现一个淡淡的五色印记

## 功法招式

1. **五脏辨气法**：盘坐闭目，将意念依次集中于心、肝、脾、肺、肾五个脏器，感受每个脏器天生的属性气息。心如火炉般温暖，肝如春木般舒展，脾如大地般沉稳，肺如金石般清凉，肾如深潭般寒润。先辨别清楚，才能进行后续的引导。

2. **五色呼吸法**：吸气时意念中将吸入的灵气想象为五色——金色灵气走肺，青色灵气走肝，蓝色灵气走肾，红色灵气走心，黄色灵气走脾。呼气时将五脏中的浊气从对应的体表穴位排出（心浊气从腋下极泉穴出，肝浊气从期门穴出等）。一吸一呼之间，完成灵气摄入与浊气排出的完整循环。

3. **五脏共鸣功**：当五脏中的灵气都充盈后，以意念引导五脏同时发出振动——心火振动发出"呵"音，肝木振动发出"嘘"音，脾土振动发出"呼"音，肺金振动发出"呬"音，肾水振动发出"吹"音。五音共鸣产生的声波会在体内形成一个强大的能量场，将五脏中的灵气彻底激活。

4. **五气贯顶诀**：以意念引导五脏中的灵气从各自对应的经脉出发——心经走手少阴、肝经走足厥阴、脾经走足太阴、肺经走手太阴、肾经走足少阴——五条经脉的灵气同时上行，在咽喉处汇聚成一股五色洪流，直冲泥丸宫。此招的关键在于五股灵气必须同时到达咽喉，否则会相互冲突。

5. **朝元灵光术**：五气朝元后，将泥丸宫中的五色光团之力释放到体外，在身体周围形成一个五色光环。光环范围内，可感知到所有物体的五行属性构成，并能以自身五行之力进行微调——如火属性不足则补充火灵气，木属性过盛则消耗木灵气。

## 修炼条件

**前置功法**：五行基础功或类似五行功法需修炼至大成，因为五气朝元功是中级的五行应用法门，需要修炼者已经具备五行灵气的基础操作能力

**灵根要求**：五行灵根俱全者为最佳，至少需要三条以上不同属性的灵根。单属性天灵根修炼此功法反而最为困难

**修炼地点**：五行灵气均衡之处。大自然中的绝佳地点包括森林（木旺）、温泉（水旺）、高山（土金旺）、火山（火旺）附近。但最好还是找到一处五行兼备的宝地

**所需资源**：五行灵石各数块、滋养五脏的"五灵丹"。"五灵丹"由五种属性的灵药炼制而成，可强化五脏对五行灵气的承载能力

## 使用限制/副作用

- 五脏失衡是最严重的副作用——若某一种五行灵气在对应的脏器中积累过多，会导致该脏器功能紊乱。如心火过旺可致心绞痛、肝木过盛可致头晕目眩、脾土过厚可致消化不良、肺金过利可致干咳、肾水过泛可致水肿
- 五气朝元发动时，五脏的灵气同时上冲，对经脉的压力极大。若经脉不够坚韧，可能会出现经脉撕裂的严重后果，需要事先服用护脉丹
- 修炼此功法后，修炼者的味觉会变得异常敏感（五脏对应五味——心苦、肝酸、脾甘、肺辛、肾咸），对某些味道会产生强烈的排斥或渴望
- 在五气朝元状态下受到重击，五脏中的灵气可能会失控暴走，造成严重的内伤，修复起来极为麻烦

## 相关典故

- **邹衍的五行洞天**：传说邹衍晚年找到了一处五行灵气完美平衡的洞天福地，在那里他完成了五气朝元功的最后完善。这处洞天后来被称为"五行洞天"，据说每三百年的特定时刻，洞天中会同时出现五色霞光，那便是邹衍留下的五气朝元功传承的开启信号。无数修士寻找这处洞天，但至今无人找到确切位置。

- **五气医圣华元化**：东汉时期的神医华元化（华佗）其实是五气朝元功的修炼者。他将五气朝元的原理应用于医术，创出了名震天下的"五禽戏"——虎（金、肺）、鹿（木、肝）、熊（土、脾）、猿（水、肾）、鸟（火、心）。五禽戏看似是健身之术，实则是以五气原理调理五脏的修炼法门。

## 修炼进度

**感知期**（约2-4年）：能够清晰感知五脏的五行属性，能将对应的五行灵气引导入对应的五脏。此阶段修炼者会频繁出现"脏气反应"——如引火入心时感到心胸发热、引水入肾时感到腰腹清凉等

**积蓄期**（约4-10年）：五脏中的五行灵气逐渐充盈，五脏功能大幅提升。修炼者的面色变得极好——心好则面色红润、肝好则目明、脾好则唇润、肺好则鼻通、肾好则耳聪

**贯顶期**（约10-20年）：五脏灵气充盈到极限后开始向头部汇聚。此阶段修炼者会经常感到头部发热、眉心发痒，这是五气朝元的前兆。此时若修炼不当，可能会导致"气冲脑门"的剧痛

**朝元期**（约20-40年）：五气在泥丸宫中稳定汇聚，形成五色光团。修炼者眉心浮现五色印记，可随时进入五气朝元状态。此状态下修炼者的战斗力、感知力、恢复力全面大幅提升
