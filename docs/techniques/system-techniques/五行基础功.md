# 五行基础功

## 基本信息
- **功法名称**：五行基础功
- **品级**：二阶（玄级）
- **类型**：体系功法
- **适用境界**：筑基期
- **修习难度**：★★☆☆☆

## 功法介绍

五行基础功由上古五行宗的开派祖师"五行真人"所创。五行真人本是一介书生，偶然在一次落水后被激流冲入一处地下溶洞，洞中竟有五色灵光闪烁不定——那是五种属性的灵石矿脉在此交汇的奇观。他在洞中昏迷了三日，醒来后发现自己的身体被五色灵气洗伐，竟同时具备了金木水火土五种灵根的雏形。

五行真人出洞后，以自己为实验体，耗费百年光阴，总结出了一套均衡修炼五种属性灵气的方法。他认为天地万物皆由五行构成，人体亦是小五行，唯有五行平衡、相辅相成，方能成就大道。五行基础功并非追求某一种属性的极致，而是追求五行的和谐运转，如同调音师将五根琴弦调至同一音律，奏出的乐曲方能和谐美妙。

## 功法特点

**优点：**
- 五种属性均衡发展，不偏不倚，为后期修炼任何属性的高阶功法留下最大灵活性
- 五行相生——金生水、水生木、木生火、火生土、土生金，修炼时五种真气相互滋养，修炼效率可叠加
- 稳固根基的效果极佳，修炼此功法的修士在后续境界中走火入魔的概率比其他修士低三成
- 对环境适应性强，无论在何种属性为主的环境中都能找到对应的灵气来源

**缺点：**
- 进度比单属性功法慢五成，因为需要同时修炼五种真气，精力分散
- 需要同时具备五种属性的灵根或至少中品以上的杂灵根，资质要求较高
- 五行真气在体内共存，一旦某一种属性真气失控，会导致五行失衡，轻则内伤，重则爆体
- 初期战斗力远不如同阶的单属性功法修炼者，属于"厚积薄发"型

## 功法等级

**五行初识**：初步感知到五种属性的灵气差异——金色锋锐、青色生机、蓝色流动、红色炽热、黄色厚重。能在丹田中分别储存五种真气而不相互冲突

**五行并行**：五种真气在体内各自形成独立的运行路线，互不干扰。修炼时可根据需要选择吸收某一种属性的灵气，在经脉中五种真气各行其道

**五行相生**：掌握了五行相生的规律，修炼时可将一种属性的真气通过相生关系转化为另一种，大大提升修炼效率。例如将多余的土属性真气转化为金属性，再转化为水属性

**五行合一**：五种真气在丹田中形成了一个五色循环的太极图，五种属性达到完美的动态平衡。此时真气可随心所欲地在五种属性间切换，一掌拍出可蕴含五行之力

## 功法招式

1. **五色辨气法**：闭上双目，以灵识感知周围的灵气属性。金色为金、绿色为木、蓝色为水、红色为火、黄色为土。先从单一属性开始辨识，逐步增加难度，直至能在复杂环境中一眼分辨出五种属性灵气的分布。此招是五行基础功的"眼力"训练。

2. **丹田分储法**：将丹田划分为五个区域，分别储存五种属性的真气。金行真气存于丹田西方，木行真气存于东方，水行真气存于北方，火行真气存于南方，土行真气存于中央。每次吸收灵气时要有意识地引导到对应的区域，不可混淆。

3. **相生运转法**：以木属性真气为起点，发动相生链条——木生火、火生土、土生金、金生水、水生木。每完成一个循环，五种真气都会壮大一分，如同一个闭环的流水线，原料进去转一圈出来就增值了。每日至少运转九九八十一个循环。

4. **五行动功**：以五种肢体动作对应五行——劈掌（金，刚猛）、推掌（木，绵长）、指法（水，连绵）、拳法（火，爆发）、按掌（土，沉稳）。在演练动作的同时运转对应属性的真气，做到意到气到、形神合一。此招兼具修炼与实战训练双重功能。

5. **五气归元阵**：同时从五种不同属性的灵气源头（如火属性的岩浆裂缝、水属性的深潭、金属性的矿脉等）吸收灵气，在体内汇聚成五色洪流。此招威力巨大但极为危险，五种灵气在体内交汇的瞬间会产生剧烈的能量碰撞，需以强大的意念力镇压。成功后可一次性获得海量的五行真气。

## 修炼条件

**前置功法**：任意一阶功法（基础吐纳法、聚气诀、灵气引导术三者之一）达到圆满

**灵根要求**：至少三条不同属性的下品灵根，或一条中品杂灵根。单一属性的天灵根无法修炼此功

**修炼地点**：最好的地点是五行灵气均衡分布的区域，如原始森林中的温泉旁（木水）、火山脚下的矿坑旁（火金土）。也可在修炼室中布置五行聚灵阵来模拟

**所需资源**：五行灵石各一块（筑基期修士身价的全部）、五行丹（调和五种属性的丹药，每月需服用一粒）

## 使用限制/副作用

- 五行冲突是最危险的副作用——当两种相克属性（如金与木、水与火）的真气在体内意外接触时，会产生剧烈的排斥反应，如同在体内引爆了一颗炸弹。轻则经脉断裂，重则丹田破碎
- 修炼此功法需要极为规律的作息与饮食，任何一方失调都会导致五行紊乱。例如连续多日食用辛辣食物会使火行真气亢奋，压倒其他四行
- 在某一属性灵气极度匮乏的环境中（如纯粹的火属性岩浆地宫），五行平衡会被打破，修炼者会感到浑身不适，实力大减
- 五行基础功修炼者在金丹期面临的天劫会比普通修士强三成，因为天道对五行俱全者更为苛刻

## 相关典故

- **五行真人的溶洞**：五行真人当年落水的地下溶洞至今仍是一处修炼圣地，名为"五行源洞"。洞中的五色灵光据说从未熄灭过，每甲子会有一次大喷发，届时五种属性的灵气如彩虹般从洞口冲天而起，方圆千里可见。无数五行功法修炼者会聚集在此感悟修炼。

- **五彩琉璃体**：传说将五行基础功修炼到最高境界后，修士的身体会逐渐变为半透明的琉璃状，五脏六腑呈现出对应的五色——心红、肝青、脾黄、肺白、肾黑。据说这种"五彩琉璃体"万邪不侵、百毒不避，是极为罕见的后天体质。历史上仅有三人达到此境界。

## 修炼进度

**辨识期**（约1-3年）：能区分五种属性灵气，并在丹田中初步建立分区储存体系。此阶段最容易出现属性混淆，经常把木属性真气存入火行区域，导致真气相冲

**分合期**（约3-7年）：五种真气各行其道，互不干扰。开始尝试相生转化，但转化效率极低，十份真气只能转化一份。此阶段需要大量练习来培养五行真气的"默契"

**圆融期**（约7-15年）：五行相生运转如行云流水，五种真气浑然一体。此时修炼者的真气已经带上了五行属性，一掌拍出可令草木枯荣、金石碎裂

**道基期**（约15-30年）：丹田中五色循环成型，形成了稳定的五行道基。此时修炼者可正式冲击金丹期，其金丹将会是极其罕见的"五行金丹"，威力远超普通金丹
