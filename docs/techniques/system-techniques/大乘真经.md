# 大乘真经

## 基本信息
- **功法名称**：大乘真经
- **品级**：七阶（圣级）（圣级）
- **类型**：体系功法
- **适用境界**：合体期
- **修习难度**：★★★★★

## 功法介绍

大乘真经并非人族独创的功法，而是源自西方佛国的"大乘佛法"。传说在万年之前，西方佛国有一位名为"龙树菩萨"的大能，他通晓三藏十二部经典，以无上智慧著写了《大智度论》《中论》等佛门至典。然而龙树菩萨在晚年时发现了一个问题——佛门经典虽多，但大多是讲"理"的，讲如何修心、如何悟道，但缺少一部直接指导修士从合体期向大乘期突破的功法。

于是龙树菩萨发大宏愿，要在佛门经典的基础上创出一部"即身成佛"的功法。他深入龙宫取得《华严经》，又游历人间观摩各大宗门的修炼法门，最后在菩提树下入定七七四十九年，终于将佛门的"空性"智慧与道门的"炼虚合道"功法融合，创出了这部大乘真经。大乘真经的核心要义是"自度度人、自觉觉他"——修炼者不仅要自己超脱，还要普度众生。这与小乘佛教的"自了汉"截然不同，故而称为"大乘"。

## 功法特点

**优点：**
- 大乘真经修炼出的"佛光金光"具有极强的净化效果，可以驱散邪魔、净化煞气、治愈伤势
- 修炼者普度众生的理念会积累大量功德，功德可以抵消天劫的威力
- 对心灵类的攻击几乎免疫——因为大乘真经最重修心
- 修炼至大成后，可凝聚"佛国法相"，法相一出，万佛朝宗

**缺点：**
- 修炼者必须发菩提心、行菩萨道——也就是说必须真正地做好事、度众生，不能虚伪做作，否则功法会退转
- 杀戮过重、业力缠身者无法修炼大乘真经，强行修炼会导致佛魔相冲，走火入魔
- 大乘真经注重顿悟而非积累，有时候卡在某个境界数百年都无法突破，需要一次"顿悟"才能继续前行
- 佛门功法与道门功法在理念上有根本性的冲突——道门追求"长生久视"，佛门追求"超脱轮回"，修炼大乘真经后可能会与道门修士产生理念分歧

## 功法等级

**发菩提心**：修炼者发自内心地立下"普度众生"的宏大誓愿。这不是嘴上说说，而是要从心底里真正认同"我要帮助所有众生脱离苦海"的理念。菩提心一发，修炼者的心境就与普通人截然不同了

**修菩萨行**：将菩提心付诸行动——开始行菩萨道，帮助他人、利益众生。这不是刻意的行善积德，而是发自本心的行为。每一件善事都会在修炼者的佛光中增加一分光明

**证空性智**：通过深入的禅定和思考，证悟"诸法皆空"的真理——认识到世间万物都是因缘和合而生，没有永恒不变的实体。证悟空性后，修炼者不再执着于任何事物，心中了无挂碍

**成无上道**：空性智慧圆满，菩萨道行圆满，功德圆满——修炼者达到了"大乘"的极致。此时修炼者已经具备了成佛的资格，只等合适的机缘便可证得佛果

## 功法招式

1. **慈悲禅定法**：盘坐闭目，以"慈悲心"入定。观想自己化作一道温暖的金光，照耀着世间所有的苦难众生。每一个呼吸都在传递善意——吸气时吸入众生的痛苦，呼气时呼出温暖的光芒治愈众生。此招式看似简单，实则是最难的——因为慈悲必须是真实的，不能有一丝一毫的虚伪。

2. **功德积累法**：将修炼融入日常生活的每一个行动之中。吃饭时感恩食物、走路时不踩虫蚁、说话时不出恶言、遇人困难必伸援手。每一个善念、每一句善言、每一个善行，都会化作一缕金色的功德之光，融入修炼者的佛光之中。功德积累到一定程度，天劫会自动减弱。

3. **空性观想法**：选择一件身边的事物（如一朵花、一片叶子），深入地观察它。思考它的来源——从种子而来，种子从上一朵花而来，上一朵花从更早的种子而来……如此追溯下去，直到无穷。再思考它的归宿——花会凋谢、化作泥土、滋养下一代花的生长。通过这样的思考，领悟到"万物皆空、因果相连"的道理。

4. **佛国法相术**：以佛光在身后凝聚一尊巨大的佛陀法相。法相的形象由修炼者自身的佛性决定——有人凝聚的是阿弥陀佛法相（接引众生）、有人凝聚的是药师佛法相（治愈伤痛）、有人凝聚的是释迦牟尼法相（智慧觉悟）。法相凝聚后，可以发挥出各种神奇的能力。

5. **无量光普照**：大乘真经的最强招式。将全部佛光在一瞬间释放出去，化作一片无边无际的金色光海。光海覆盖的范围内，所有的邪魔外道都会被佛光净化，所有的友方都会得到治疗和加持，所有的恶念都会被消除，所有的善念都会被增强。

## 修炼条件

**前置功法**：合体归元功或任何能够完成"合体"阶段修炼的七阶功法。大乘真经需要修炼者已经完成了元婴与肉身的融合，具备了"圣体"的基础

**灵根要求**：至少一条极品灵根。但更重要的是"慧根"——对佛法的领悟能力。没有慧根的人，即使灵根再好也无法修炼大乘真经

**修炼地点**：佛门圣地或清净之处为佳——古刹寺院、灵山圣境、菩提树下。但最关键的不是地点，而是修炼者的心境——心中有佛，处处都是道场

**所需资源**：佛门舍利（辅助修炼佛光）、金檀香（安神定心）、贝叶经（记载佛门真意的经典，用于研读领悟）

## 使用限制/副作用

- 修炼大乘真经后，修炼者不能主动杀人——哪怕是罪大恶极之人也只能度化而非灭杀。如果破戒杀人，佛光会立刻消退，修为大降
- 行菩萨道必须是真心实意的，如果是为了积累功德而行善（带着功利心），佛光的增长效果会大打折扣
- 长期禅定和空性观想可能会导致修炼者变得"消极出世"——觉得世间一切都无意义，失去了修行的动力。这是"顽空"的误区，需要以慈悲心破除
- 大乘真经的修炼进境极不稳定——有时候一次顿悟可以连升数个层次，有时候数百年都卡在一个瓶颈毫无寸进

## 相关典故

- **龙树菩萨入龙宫**：龙树菩萨年轻时以智慧闻名，他听说龙宫藏有《华严经》——一部记载了佛国无尽世界奥秘的经典。于是他以神通力进入龙宫，见到了龙王。龙王问他："你为何而来？"龙树答："为取真经。"龙王说："真经不在龙宫，在你心中。"龙树恍然大悟，他在龙宫中入定三月，将心中的《华严经》写了出来，这就是流传后世的《华严经》版本。

- **达摩一苇渡江**：达摩祖师从印度来到中国，面见梁武帝后话不投机，于是渡江北上。他来到江边，没有船只，于是折了一根芦苇扔到江中，踏苇而过。世人皆以为这是神通，其实是达摩将大乘真经的"空性"发挥到了极致——在他的认知中，江水和芦苇都是空的，没有本质区别，因此"踏苇渡江"和"踏地走路"对他来说没有区别。

## 修炼进度

**发心期**（约20-50年）：从内心深处发起真实的菩提心。此阶段修炼者会经历"菩提心考验"——天界会降下各种诱惑和磨难来测试菩提心是否真实。通过了，菩提心就稳固了；通不过，菩提心会退转

**行愿期**（约30-80年）：将菩提心付诸行动，行菩萨道。此阶段修炼者会在人间游历，帮助有需要的人。每一次度化众生，佛光就明亮一分

**悟空期**（约50-150年）：在行愿的过程中逐渐证悟空性。此阶段修炼者会经历"顿悟"——可能在扫地时、可能在吃饭时、可能在与人交谈时，突然之间就明白了"空"的道理

**圆满期**（约80-300年）：空性圆满、功德圆满、慈悲圆满。大乘真经修炼至极致，修炼者只需要最后一个契机就可以成就佛果、飞升极乐
