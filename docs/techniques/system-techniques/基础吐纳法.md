# 基础吐纳法

## 基本信息
- **功法名称**：基础吐纳法
- **品级**：一阶（黄级）（黄级）
- **类型**：体系功法
- **适用境界**：聚气期
- **修习难度**：★☆☆☆☆

## 功法介绍

基础吐纳法乃万法之源、修炼之始。传说在上古时期，人族先民尚未掌握修炼之法时，一位名为"苍鼋老人"的猎人在深山中追猎时，偶遇一尊万年灵龟盘踞于灵泉之畔。他发现此龟每一次呼吸皆与天地的韵律完美契合，一呼一吸之间，周围草木随之荣枯，灵泉水位随之涨落。苍鼋老人静坐观龟七日七夜，终于悟出了模仿灵龟呼吸的法门，这便是最初的"龟息吐纳法"，后经无数先贤改良，演变为今日流传最广的**基础吐纳法**。

此功法核心理念为"以呼吸沟通天地，以吐纳淬炼凡躯"，认为人体乃一个小天地，通过有规律的呼吸节奏，引导体外灵气与体内真气共振，逐步改造凡人之躯，使之具备承载灵气的根基。万丈高楼平地起，基础吐纳法是所有高阶功法的基石，即便飞升大能，在修炼陷入瓶颈时也常回溯此法以正本源。

## 功法特点

**优点：**
- 门槛极低，无灵根者亦可修炼入门，是凡人踏上修仙路的唯一途径
- 极为安全，修炼出错也不会导致走火入魔，最多气息紊乱休养数日即可恢复
- 与其他任何功法均不冲突，可作为一切功法的辅助根基
- 长期坚持可潜移默化改善体质，延年益寿，对凡人而言可活百余岁

**缺点：**
- 修炼速度极为缓慢，单纯靠基础吐纳法突破至筑基期至少需五十年苦功
- 对战斗无直接帮助，毫无攻击力与防御力
- 对灵气的转化效率低下，约七成的吸入灵气会在吐纳过程中逸散
- 修炼过程枯燥单调，九成初学者在三五年内放弃

## 功法等级

**初悟**：掌握基本的腹式呼吸节奏，能在安静环境中感知到体内微弱气感，每日可聚气一个时辰，修炼效率约10%

**入门**：呼吸节奏融入本能，行走坐卧皆可自然吐纳，体内真气初步成形，可在经脉中做简单循环，每日可聚气三个时辰

**贯通**：十二正经全部贯通，真气运行再无阻碍，呼吸之间周身毛孔皆可吸纳灵气，修炼效率提升至50%，可边修炼边做其他简单事务

**化境**：胎息境界，口鼻呼吸近乎停止，全身毛孔代行呼吸之能，与天地气息融为一体，即便在睡梦中亦在自动修炼，此时修炼效率已不在普通玄级功法之下

## 功法招式

1. **静坐调息**：盘膝端坐，五心朝天，舌抵上腭，以鼻吸气、以口呼气，一呼一吸为一息，初练者每日子时、午时各修一次，每次半个时辰。此招旨在安定心神，排除杂念，感受体内气的萌动。

2. **龟息沉脉**：吸气时意想清气沉入丹田，呼气时意想浊气从四肢末端排出。模仿灵龟呼吸之法，呼吸频率逐渐放慢至正常人的三分之一，每次呼吸间隔延长至十二息以上。此招可强化经脉韧性，拓宽窍穴容量。

3. **毛孔吐纳**：当体内真气充盈到一定程度后，以意念引导真气从丹田散至体表，通过全身毛孔向外释放，再吸气时引导外界灵气从毛孔吸入体内。此招可将修炼面积从口鼻扩大到全身，效率提升数倍。

4. **日月采气法**：清晨对东方日出方向，吸食"太阳紫气"；夜晚对明月方向，吸纳"太**华"。配合观想法——观想太阳化为金球入腹，月亮化为银球入体。此招乃基础吐纳法中唯一带属性的修炼法门。

5. **天人合息**：在深山幽谷、瀑布之畔、古木之下等自然环境极佳处，调整自身呼吸频率与环境中的自然节律同步——与风同息、与水同流、与木同生。达到"我不呼吸，天地为我呼吸"的境界，此为化境之关键。

## 修炼条件

**前置功法**：无。基础吐纳法不依赖任何前置功法，凡人即可直接修习

**灵根要求**：无灵根要求。即便没有灵根的凡人亦可修炼至初悟、入门两级，但若要达到贯通以上，仍需至少一条下品灵根辅助

**修炼地点**：安静无障碍之所即可。初期推荐深山幽谷、灵气稀薄但空气清新之处；后期可在任何地方修炼

**所需资源**：初期无需任何资源；到了贯通阶段可配合黄级聚气丹使用，可提升30%效率

## 使用限制/副作用

- 过度修炼会导致"气胀"——体内真气过多但经脉未通，腹部胀痛如鼓，需以排功法将多余真气散去
- 初学者若在情绪波动剧烈时修炼，容易导致气息紊乱，出现胸闷、眩晕等症状，严重时可能暂时失去对气的感知（俗称"气盲"），休养数日可恢复
- 切勿在污浊之地修炼（如战场尸地、沼泽瘴气区），否则浊气入体，轻则大病一场，重则污染丹田根基，需要灵药调理数月
- 修炼此法期间需禁欲节食，过度的房事与暴饮暴食会使真气涣散，修为一朝尽废

## 相关典故

- **苍鼋老人的传说**：记载于《异兽志·灵龟篇》，苍鼋老人观龟七日悟出吐纳法后，灵龟化作一位老者，授予他一卷龟甲天书，上书"呼吸即道"四字。苍鼋老人后来活到八百岁，在寿元将尽之际跨上一只巨龟，沉入东海不知所踪。

- **乞丐修仙**：三百年前，天阙城有一位叫王二狗的乞丐，无意中捡到一本残破的基础吐纳法手抄本。他无灵根、无资源、无师承，仅凭日夜不辍的吐纳修炼，花了七十年时间硬生生从凡人修炼到了筑基期，成为一段传奇。他后来创立了"无根门"，专门收无灵根的凡人弟子，至今仍在修真界边缘艰难传承。

## 修炼进度

**萌芽期**（约1-3年）：初次感知气感，体内真气若有若无，如风中烛火，稍不注意就会熄灭。此阶段最易放弃，十人中有七人停留于此

**蓄气期**（约3-10年）：真气由气感转为实质，能在丹田处凝聚成一团温热的气团。修炼者面色红润、精神饱满、疾病减少。此阶段开始真正体会到修炼的妙处

**通脉期**（约10-20年）：真气开始主动冲击经脉关卡，逐一打通十二正经。每打通一条经脉，身体都会有明显变化——手经通则手力大增，足经通则身轻如燕

**归真期**（约20-50年）：经脉全通，真气如江河般在体内奔流不息。此时返璞归真，外表与凡人无异，但内里已脱胎换骨，寿元可达一百五十岁以上，为冲击筑基期打下最扎实的根基
