# 阴阳入门法

## 基本信息
- **功法名称**：阴阳入门法
- **品级**：二阶（玄级）
- **类型**：体系功法
- **适用境界**：筑基期
- **修习难度**：★★☆☆☆

## 功法介绍

阴阳入门法源自上古时期的"阴阳道"，据传其创始人为东海的"玄素散人"。玄素散人本是一位渔民，某日在海上捕鱼时遭遇风暴，船只被打翻，他被海浪卷入一处海底洞穴。洞穴中有一黑一白两条巨鱼在相互追逐，形成一个完美的太极图案。玄素散人在昏迷前看到这个画面，脑中闪过无数明悟。

他醒来时已躺在海滩上，虽然身体虚弱，但脑海中那副黑白双鱼追逐的画面却挥之不去。他花了三十年时间研究这个画面，终于悟出了一套完整的阴阳修炼理论——世间万物皆有阴阳两面，修炼的本质就是调和体内的阴阳二气，使之达到平衡。阳气过盛则亢奋易怒、走火入魔；阴气过盛则消沉萎靡、寿元亏损。唯有阴阳调和，方能长生久视。阴阳入门法则是将这套理论付诸实践的第一步。

## 功法特点

**优点：**
- 阴阳二气是万气之母，掌握了阴阳之道的修炼者转修任何功法都能事半功倍
- 修炼者可自行调节体内的阴阳平衡，对大多数由阴阳失调引起的疾病和隐患有天然的抵抗力
- 对男女双修类功法有极佳的辅助效果
- 到了高层，可利用阴阳相生之力大幅提升修炼速度

**缺点：**
- 阴与阳的感知比例较难掌握，初学者极易偏向其中一方
- 在某些极端环境中（如极阴之地或极阳之地），体内的阴阳平衡会被环境影响而打破
- 战斗时缺乏爆发性手段，阴阳之力以绵长持久见长而非刚猛速决
- 需要修炼者有较好的悟性，否则很难真正理解"阴阳互根"的深层含义

## 功法等级

**识阴辨阳**：能够清晰分辨体内的阴气与阳气——阴气清凉如月色，阳气温暖如日光。能在丹田中将阴阳二气区分存放，使之不互相冲突

**阴阳交汇**：阴气与阳气在丹田中初步交汇，形成一个旋转的阴阳鱼图案。此时修炼者体内会产生一种特殊的"中和真气"，兼具阴阳两种属性

**阴阳相济**：阴中有阳、阳中有阴——阴气中孕育出一丝纯阳，阳气中孕育出一丝纯阴，如同太极图中的鱼眼。此境界标志着修炼者真正触摸到了阴阳互根的本质

**阴阳合一**：阴阳二气彻底融合，不再分彼此。真气呈现灰色——非阴非阳，亦阴亦阳，可以随时转化为任何属性。这是阴阳入门的最高境界，也是更高阶阴阳功法的起点

## 功法招式

1. **日月观想法**：白天修炼时面向太阳，观想太阳的金色光芒从双目、百会穴灌入体内，化作纯阳真气储存于丹田右侧；夜晚修炼时面向月亮，观想月亮的银色光华从涌泉穴、劳宫穴吸入体内，化作纯阴真气储存于丹田左侧。此法利用日月之力直接产**阴阳真气，效率极高。

2. **水火既济法**：在体内同时运起两股真气——一股炽热如岩浆（阳），一股清凉如寒泉（阴）。先用寒泉真气冲刷经脉以降火，再用岩浆真气温暖丹田以驱寒，使两者在体内形成良性循环。此招源自易经"水火既济"卦象，寓意阴阳调和、万事亨通。

3. **子午调衡法**：子时（23:00-1:00，阴气最盛之时）修炼纯阳功法，以阴中求阳；午时（11:00-13:00，阳气最盛之时）修炼纯阴功法，以阳中求阴。此法利用天地阴阳转换的节点来强化自身阴阳修炼，事半而功倍。

4. **双鱼游身法**：引导阴阳二气在体内沿两条相反的路线运行——阳气走手三阳、足三阳（阳经），阴气走手三阴、足三阴（阴经）。两股真气如同两条鱼在体内交错游动，每交汇一次就会产生新的变化。整套功法完成时，阴阳二气正好在丹田交汇，形成一个完整的太极。

5. **阴阳变阵诀**：将阴阳真气外放，在周身形成一个无形的阴阳力场。力场范围内，可根据需要将局部区域的阴阳属性进行调整——对火属性敌人增大阴气占比以削弱其火焰威力，对阴寒属性敌人增大阳气占比以压制其功法。

## 修炼条件

**前置功法**：任意一阶功法达到大成以上。阴阳入门法需要修士已经具备一定的真气基础，否则难以同时掌控两种不同属性的真气

**灵根要求**：至少有一条灵根，对属性无特殊要求。阴阳法不挑灵根属性，但拥有水（阴）和火（阳）双属性灵根的修士修炼速度最快

**修炼地点**：最好在阴阳交替的时间段修炼——清晨（卯时，阴阳平衡）或黄昏（酉时，阴阳平衡）为最佳。地点上，山洞之中（阴）和山顶之上（阳）结合最好

**所需资源**：一块至阳石和一块至阴石（如太阳石与月华石），用于辅助感知阴阳气息。可配合"阴阳调和丹"服用

## 使用限制/副作用

- 阴阳失衡是最常见的副作用——若连续多日在阳气旺盛的环境中修炼而忽视频率阴气的摄取，会导致体内阳盛阴衰，出现烦躁易怒、失眠多梦、口干舌燥等症状；反之则会阴盛阳衰，出现畏寒怕冷、情绪低落、嗜睡无力等症状
- 子午修炼的时间要求严格，若在错误的时间修炼错误的属性（如子时练阴、午时练阳），效果会大打折扣甚至会起反效果
- 阴阳入门法修炼者在修炼其他极端属性功法时（如纯阳焚天诀或玄冥寒冰掌），体内的阴阳平衡可能会被打破，需要重新调和
- 阴阳合一境界后，修炼者的性格会趋向"中庸"——不再大喜大悲、大爱大恨，有些人认为这是心性修炼的成果，也有人认为这是丧失了人之本性

## 相关典故

- **玄素散人与双鱼图**：玄素散人留下的《双鱼图》真迹至今保存在东海玄冰宫中。据说这幅图并非画在纸帛上，而是悬浮在玄冰宫的一面冰壁上，两条鱼活灵活现，时时刻刻都在缓慢游动。每隔千年的冬至之日，双鱼会合二为一，化作一条完整的太极鱼，只存在一炷香的时间，然后再次分开。无数大能在此期间守候观摩，试图从中领悟更深的阴阳奥秘。

- **阴阳医圣**：千年前有一位以阴阳入门法入道的修士，名为"秦缓"，他穷尽一生研究阴阳平衡在人体中的应用，最终成为一代医圣。他的医术理论全部建立在阴阳学说之上——疾病是阴阳失衡的表现，治疗就是恢复阴阳平衡。他留下了《阴阳医典》三十六卷，至今仍是修真界医学的必修经典。

## 修炼进度

**感知期**（约1-2年）：能够区分体内阴阳二气，但每次只能单独操控其中之一，无法同时运转。修炼者在白天精力充沛，夜晚沉静安详，初步感受到阴阳变化对身心的影响

**交汇期**（约2-5年）：阴阳二气在丹田中形成初步交汇，产生第一缕中和真气。此阶段修炼者的体质开始发生显著变化——寒暑不侵、百病不生，面色呈现出一种健康的红润

**相济期**（约5-12年）：阴阳互根，阴中藏阳、阳中藏阴。此时修炼者可做到举重若轻——发招时看似绵软无力，实则暗含刚猛；看似刚猛霸道，实则暗藏阴柔变化

**合一期**（约12-25年）：阴阳合而为一，真气可任意转化属性。到了这个境界，修炼者的寿命会得到极大延长，面容也会停留在最佳状态，通常看起来比实际年龄年轻数十岁
