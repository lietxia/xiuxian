# 阴阳合一法

## 基本信息
- **功法名称**：阴阳合一法
- **品级**：四阶（天级）
- **类型**：体系功法
- **适用境界**：元婴期
- **修习难度**：★★★★☆

## 功法介绍

阴阳合一法源自一对传奇道侣——"阳真子"与"阴素心"。两人本是两个敌对宗门的弟子，阳真子出身至刚至阳的"大日神宗"，阴素心出身至阴至寒的"月影仙宫"。两派世代为仇，弟子相遇必分生死。然而阳真子与阴素心在一次秘境探险中相遇，历经生死磨难后，两人放下了宗门仇恨，走到了一起。

两人结合后发现，他们在修炼上互为补充——阳真子的阳气过盛，常感燥热难耐、心浮气躁；阴素心的阴气过重，常感寒冷刺骨、情绪低落。两人尝试双修之后，惊喜地发现彼此体内的阴阳二气竟然能相互中和——阳真子的阳气注入阴素心体内后，她不再感到寒冷；阴素心的阴气注入阳真子体内后，他也不再感到燥热。两人花了三十年时间，共同创出了这部阴阳合一法——不是简单的双修之术，而是从根本上解决阴阳二气在体内共存与融合问题的顶级功法。

## 功法特点

**优点：**
- 阴阳合一后，修炼者的真气兼具阴阳两种属性，可刚可柔、可攻可守、可热可寒，变化无穷
- 阴阳相生，真气恢复速度极快，几乎是同阶修士的两倍
- 对阴阳属性的攻击有极强的免疫力——极寒不侵、极热不伤
- 修炼至高深后，可以吸收日月精华直接转化为自身真气，不需要依赖灵石

**缺点：**
- 修炼者自身的阳气和阴气必须保持完美的平衡，任何一方的失衡都会导致功法的失效甚至反噬
- 修炼节奏受制于天时——必须在子时（阴气最盛）和午时（阳气最盛）分别修炼对应的部分，不可颠倒
- 如果修炼者是男性，阳气天生比阴气重，需要花费额外的功夫来弥补阴气的不足；女性则相反
- 此法对单身修士极为不友好——没有道侣辅助调和，单靠自己修炼的难度加倍

## 功法等级

**阴阳分识**：能够精准区分体内阴阳二气的比例——知道自己体内阳有多少、阴有多少。同时开始矫正天生的阴阳不平衡，使之趋向各占一半的均衡状态

**阴阳互济**：阴气和阳气不再相互排斥，而是开始相互配合——阳气为阴气提供动力，阴气为阳气提供根基。两者如同配合默契的舞伴，在体内和谐共舞

**阴阳合一**：阴气与阳气彻底融合，形成了完美的"太极真气"。这种真气可以在阴阳两种状态之间任意切换——前一秒还是灼热如火，后一秒就变得冰寒刺骨

**太极无极**：阴阳合一到了极致，反而超越了阴阳的范畴，进入"无极"状态。此时真气既不阴也不阳、既阴又阳，已经超脱了属性的束缚，万法归宗

## 功法招式

1. **日月同修法**：清晨日出时面向东方修炼阳气——吸收太阳初升时蕴含的"少阳之气"；傍晚日落时面向西方修炼阴气——吸收夕阳余晖中的"少阴之气"。每月初一、十五的日月交替之际是最佳修炼时机，可以同时吸收日月精华。

2. **水火交融诀**：在体内同时运起一阴一阳两股真气。阳气炽热如烈火，运行于阳经；阴气寒冷如寒冰，运行于阴经。当两股真气在丹田中相遇时，以意念控制它们相互缠绕、旋转，形成一个水火交融的太极图。初始时两股真气会相互排斥，需要用强大的意念力强行将它们压在一起。

3. **阴阳互根术**：在阳气中培养一丝阴气（阳中求阴），在阴气中培养一丝阳气（阴中求阳）。这一丝"对立属性"的种子虽然微小，但却是阴阳合一的关键——它打破了阴阳之间的绝对壁垒，使两者有了相互转化的通道。当阳中阴和阴中阳都稳定后，阴阳合一的道路就铺平了。

4. **双人合练法**：双修之道。男女修士面对面盘坐，四掌相抵，男修将阳气渡入女修体内，女修将阴气渡入男修体内。两人的阴阳二气在彼此体内循环一周后，带着新的变化回到各自体内。如此往复，两人的阴阳二气都会变得更加纯粹且均衡。此招需要双方绝对的信任和默契。

5. **太极领域**：阴阳合一后的终极能力。将太极真气外放，在周身形成一个太极形状的领域。领域内，所有阴阳属性的攻击都会被太极真气同化吸收，所有具有阴阳属性的生命体都会受到压制。太极领域的大小和强度取决于修炼者对阴阳合一的理解程度。

## 修炼条件

**前置功法**：阴阳入门法达到圆满境界。修炼者必须已经掌握了阴阳二气的基本控制和调和能力

**灵根要求**：至少一条中品灵根，对属性无特殊要求。水属性灵根（偏阴）和火属性灵根（偏阳）同时具备效果最佳

**修炼地点**：最佳修炼地点是天然的阴阳交汇之处——如山顶（阳）与山谷（阴）交界处的平台、海边日出时分、月华照射的山洞等

**所需资源**：至阳石和至阴石各一块、阴阳调和丹、辅助双修的合气香。以及——如果条件允许的话——一位志同道合的道侣

## 使用限制/副作用

- 阴阳合一的平衡极为脆弱。修炼者若情绪大起大落（大喜属阳、大悲属阴），体内的阴阳平衡就会被打破，轻则真气紊乱，重则阴阳分离导致修为倒退
- 在极阳之地（如火山腹部）或极阴之地（如万年寒潭）长时间停留，体内的阴阳平衡也会受到影响
- 修炼此功法后，修炼者的性格会趋向"阴阳平衡"——不再大喜大悲，情绪波动变得很小。外人看来可能会觉得此人变得冷漠无情
- 双人合练时若其中一方心怀不轨或心存杂念，可能会对另一方的阴阳平衡造成严重破坏，甚至导致走火入魔。因此选择道侣极为重要

## 相关典故

- **阳真子与阴素心的传说**：阳真子和阴素心创出阴阳合一法后，两人联手无敌于天下。但好景不长，阳真子在一场大战中受了致命伤，临死前他将自己全部的阳气渡给了阴素心，并叮嘱她一定要把阴阳合一法传承下去。阴素心怀抱着阳真子的尸体哭了七天七夜，她的眼泪一半是冰一半是火，落在地上化作了两种截然不同的石头——冰泪石和火泪石。据说这对道侣的坟墓至今仍在某处，两人的阴阳合一法真迹就藏在墓中。

- **太极张三丰**：武当派的创始者张三丰早年醉心于道家阴阳学说，后来得到了阴阳合一法的残篇，从中领悟出了"太极拳"和"太极剑"的武学至理。他将阴阳合一法的理念由修炼拓展到了武学领域，创造了以柔克刚、以静制动的太极武学体系。

## 修炼进度

**调和期**（约3-10年）：纠正天生的阴阳不平衡，使体内阴阳二气达到各占一半的初始均衡状态。此阶段修炼者会经历"阴阳交替"的不适应期——时而燥热难耐，时而寒冷刺骨

**融合期**（约10-25年）：阴阳二气开始初步融合，产生第一缕太极真气。此阶段的太极真气极不稳定，可能在阴和阳之间剧烈切换，需要长时间的磨合才能稳定下来

**合一期**（约25-45年）：阴阳彻底融合，太极真气稳定。此阶段的修炼者举手投足都带有太极的韵律，动作圆融无碍、滴水不漏。真气可以在阴阳之间自由切换，战斗风格变化多端

**无极期**（约45-80年）：超越了阴阳的范畴，进入无极状态。此境界的修炼者已经不再受阴阳属性的限制，任何属性的真气都可以直接吸收利用，真正的万法归宗、大道至简
