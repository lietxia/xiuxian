# 五行圆满诀

## 基本信息
- **功法名称**：五行圆满诀
- **品级**：四阶（天级）（天级）
- **类型**：体系功法
- **适用境界**：元婴期
- **修习难度**：★★★★☆

## 功法介绍

五行圆满诀乃五行宗的镇宗之宝，由五行宗第七代宗主"五行老人"于三千年前创制。五行老人天资卓绝，将五行基础功修炼到了前无古人的境界——他的五行真气已经达到了完美的动态平衡，五种属性可以在瞬息之间随意转换。但他并不满足于此，他认为五行基础功只是"入门"，真正的五行大道应当是"圆满"。

他闭关四十年，游历五湖四海，观察天地间的五行运转——太阳（火）东升西落、江河（水）奔流不息、大地（土）承载万物、金石（金）深埋地底、草木（木）春生秋收。他发现天地间的五行是生生不息、循环无端的，每一刻都在变化但又从未改变——这便是"圆满"的真谛：不是静止的完美，而是动态的平衡。五行圆满诀就是在这一理念下诞生的，它不仅仅是一部功法，更是一套认识世界、理解天地的哲学体系。

## 功法特点

**优点：**
- 五行圆满后，修炼者的真气可随时在五种属性间任意切换，战斗中可以根据敌人的弱点选择最有利的属性攻击
- 五行相生的叠加效应使得修炼速度在同阶功法中属于上乘
- 对五行属性的攻击有极高的抗性——火伤减半、水伤减半，以此类推
- 修炼至圆满后，可在周身形成一个五行力场，力场内五行能量全部受到修炼者的掌控

**缺点：**
- 对灵根资质要求极为苛刻，必须五行灵根齐全且均为中品以上
- 修炼难度极高，需要同时掌控五种属性真气的动态平衡，稍有不慎就会失衡
- 初期战斗力反而比专精单属性的元婴修士弱，因为精力被分散到了五个方向
- 修炼资源消耗惊人，需要同时收集五种属性的天材地宝

## 功法等级

**五行圆转**：五种属性的真气在丹田中形成一个五色圆环，可以在圆环中自由流转、相互转化。从火转木、从木转水……所有相生转化都能在一念之间完成

**五行相抱**：五色圆环开始收缩，五种颜色逐渐融合，出现了相互"拥抱"的趋势。此时五种属性不再是各自独立的能量，而是开始融合成一种更高层次的能量——"混沌真气"的雏形

**五行归虚**：五行圆环进一步融合，五种属性几乎融为一体，真气呈现出淡淡的灰色——这是五行归一的征兆。此阶段可同时发挥出两到三种属性的叠加效果

**五行圆满**：五种属性彻底融合归一，真气的灰色褪去，变为透明无色的"无属性真气"。看似回到了起点，实则超越了五行——因为这种真气可以根据需要随时转化为任意一种或多种属性

## 功法招式

1. **五行环修炼法**：在丹田中构建一个五色圆环，将五种属性的真气按照相生的顺序排列（木→火→土→金→水→木），形成一个闭环。用意念推动这个圆环旋转，每旋转一周，五种真气就相互滋养一次。初始时转速极慢，随着修炼日深逐渐加快。

2. **五脏共振诀**：利用五气朝元功中五脏对应五行的原理，以五行圆满诀的真气同时激活五脏——心火、肝木、脾土、肺金、肾水同时发出振动。五脏的共振会产生一个强大的内五行场，将体内所有的杂质与浊气全部排出，使修炼者的身体达到一种"先天"的状态。

3. **五行变阵**：将五种属性的真气外放，在周身形成五个不同颜色的光球，分别悬浮在五个方位——东方木、南方火、中央土、西方金、北方水。根据敌人的进攻方式和属性弱点，可以随时调整五个光球的比例和位置。例如，对水属性敌人，增强土球（土克水）并减弱火球（避免火生土对敌人有利）。

4. **五行遁法**：利用五行相生的原理，将自身融入周围的五行环境之中——入火则化火遁、入水则化水遁、入林则化木遁、入山则化土遁、入矿则化金遁。此招并非真正的隐身，而是将自身的五行属性调整到与环境完全一致，使敌人无法通过灵识感知到差异。

5. **归元一击**：五行圆满诀的最强攻击招式。将五种属性的真气在丹田中压缩成一个微小的五彩光点，然后在一瞬间释放出来。光点击中目标后会引发五行的连锁反应——先爆发出火焰伤害、紧接着是冰霜、然后是雷电、再然后是腐蚀、最后是震荡，五种伤害在瞬息之间依次爆发，令敌人防不胜防。

## 修炼条件

**前置功法**：五行基础功达到圆满，五气朝元功达到大成以上。这两门功法是五行圆满诀不可或缺的根基

**灵根要求**：五行灵根齐全均为中品以上，或者拥有一条极品杂灵根。天资要求极高，万中无一

**修炼地点**：四季分明、五行齐全的洞天福地。最佳地点是"五行灵脉"交汇之所——金脉、木脉、水脉、火脉、土脉五条灵脉在地下交汇之处

**所需资源**：五行属性的天材地宝各一份、五阶五行属性的妖兽内丹各一颗、五行凝气丹大量。资源消耗是普通功法的五倍以上

## 使用限制/副作用

- 五行圆满的状态极其不稳定——修炼者每时每刻都需要维持五种属性的动态平衡，任何一个微小的疏忽都会导致失衡。失衡的后果轻则修为倒退，重则五种属性真气在体内相互冲突导致爆体而亡
- 修炼此功法后，五行属性会对修炼者的性格产生影响——木性仁慈、火性暴躁、土性固执、金性刚烈、水性多变。五种属性在体内交织，可能导致修炼者的性格变得喜怒无常
- 在与单属性极致的修士交手时，虽然五行圆满有多种应对手段，但每一种属性的威力都不如对方专精的强度，容易陷入"样样通、样样松"的窘境
- 突破至五行圆满的最后一关需要经历"五行劫"——五种属性的天劫依次降临，间隔极短，是修真界公认的十大至难天劫之一

## 相关典故

- **五行老人的五色石**：五行老人当年闭关的山洞中有一块五色石，是他用来辅助参悟五行圆满之道的至宝。传说这块五色石是女娲补天时遗落的一块五彩石碎片，蕴含着天地间最原始的五行之力。五行老人飞升后，此石不知下落，但据说谁能找到五色石，就能直接继承五行老人的五行圆满之道。

- **五行宗与五行使者**：千年之前，五行宗出了五位惊才绝艳的弟子，各自将五行圆满诀中的一种属性修炼到了极致，被称为"五行使者"——金使白子墨、木使柳青烟、水使蓝若水、火使赤炎天、土使黄厚土。五人联手，曾以五行大阵困杀了一名炼虚期魔修，名震修真界。

## 修炼进度

**圆转期**（约5-15年）：五种属性在丹田中形成稳定的五行环，可以在环中自由转化。此阶段的修炼者可以同时使用两种属性进行攻击，战斗方式开始多样化

**融合期**（约15-30年）：五行属性开始融合，出现混沌真气的雏形。修炼者的真气颜色时而五彩斑斓、时而灰蒙蒙一片，极不稳定。此阶段需要在实战中反复磨合，找到五行融合的最佳比例

**归一期**（约30-50年）：五行属性几乎合为一体，真气呈现透明无色的状态。修炼者的攻击看似平淡无奇，实则蕴含五行之力，一掌拍出可以有五种不同的变化，令人防不胜防

**圆满期**（约50-100年）：五行圆满，返璞归真。真气的无色状态已经稳定，可以随心所欲地转化为任意属性。到了此境界，修炼者举手投足间都暗合五行至理，可以在任何环境中自由调动五行能量为己所用
