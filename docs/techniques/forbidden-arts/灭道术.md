# 灭道术

## 基本信息
- **功法名称**：灭道术
- **品级**：六阶（神级）（神级）
- **类型**：禁术功法
- **适用境界**：炼虚期
- **修习难度**：★★★★★

## 功法介绍

灭道术的源头令人不寒而栗——它源自一位道祖走火入魔时斩下的恶念。传说在遥远的太古时代，有一位名为"太初"的道祖，他修炼万道归一的至高法门，掌握了世间所有的法则。然而在他冲击天道境时，他发现自己修炼的大道中混入了一丝杂质——那是最原始的"恶"。太初道祖为了保持道心的纯净，将这一丝恶念从体内斩出。这丝恶念脱离太初后，化为人形，自称"灭道"。灭道继承了太初道祖对万道的理解，但继承的方式却是扭曲的——他领悟到，大道本身就是一种束缚，众生因道而存在，也因道而受限。真正的自由在于"灭道"——将一切规则、秩序、法则全部摧毁。灭道花了十万年时间创造出这套专门用于摧毁大道的功法。

## 功法特点

**优点：**
- 专破法则类防御和大道类神通，效果显著
- 可以直接攻击敌人的道基，使其修为跌落
- 对天道规则有特殊的破坏力
- 灭道之力不受法则的约束，可以"无法破有法"

**缺点：**
- 使用灭道术会永久损害自身对道的感悟，越用越远离大道
- 灭道之力对自身也有反噬，长期使用会导致道心崩塌
- 此术无法被天道感知，但也无法获得天道的加持
- 修习者终生无法飞升（天道不会允许灭道者进入仙界）

## 功法等级

**初灭·道伤**：可以在一击中对敌人的道基造成微小损伤，削弱对方的神通威力

**中灭·道崩**：可以摧毁低阶修士的道基，让金丹期以下的修士修为全废

**高灭·道陨**：可以破坏化神期修士的道基，让对方修为跌落一到两个大境界

**极灭·道绝**：可以彻底抹除一方天地中的所有法则，让那片区域变成"无法之地"，任何人都无法使用神通

## 功法招式

1. **破道指**：一指点出，专门攻击敌人的功法运转节点。被点中的修士，神通会瞬间中断，经脉中的灵力会暴走反噬。一指破万法。

2. **道基震荡**：以灭道之力振动对方的道基，如同地震摧毁房屋的地基。道基受损的修士，修为会暂时跌落，且修炼时效率大减。

3. **法则切割**：以灭道之力凝结为无形之刃，专门切割天地法则。可以切断敌人的法则类神通，让其"法则无效化"。

4. **道心种魔**：在敌人的道心中种下一丝"灭道之念"。这丝念头会不断质疑敌人的道心，使其对自己修炼的大道产生怀疑。道心一旦动摇，修为就会停滞不前。

5. **万道归墟**：在自身周围形成一个"道之真空"，将周围的法则全部排斥出去。在这个真空中，无人能施展法则类神通，包括施术者自己——但施术者可以用肉身和基础灵力作战，而依赖法则的敌人会瞬间战力归零。

6. **绝道·末法天劫**：将灭道之力引向天空，强行引动"末法天劫"。这不是普通的天劫，而是让天地灵气暂时消散的劫数。在末法天劫期间，所有修士都无法使用灵力，沦为凡人。此招不分敌我，是最后的玉石俱焚之策。

## 修炼条件

**前置功法**：必须对大道法则有极深的理解（至少三门六阶法则功法圆满），否则连"灭"的资格都没有

**灵根要求**：无特殊灵根要求，但需要极高的悟性——需要先悟道，再灭道

**修炼地点**：最好在天道法则最稳固的地方修炼，这样才能感受到"灭道"的反差

**所需资源**：道石（蕴含大道气息的奇石）一枚、斩道剑一柄（用于帮自己斩去对道的执念）、忘道茶三斤

## 使用限制/副作用

- 每次使用灭道术，自身对大道的感悟就会模糊一分。用多了会忘记道是什么
- 灭道之力会逐渐侵蚀使用者的道心，最终使用者会变成一个"不信道"的虚无主义者
- 修习此术者会遭到所有正统修士的排斥，被视为"道敌"
- 若对天道使用灭道术，会引来"末法天罚"——天道会不惜一切代价铲除灭道者

## 相关典故

灭道的野心最终引来了太初道祖的注意。太初道祖看着自己斩出的恶念在世间兴风作浪，终于决定亲自出手清理门户。两位掌控了万道和灭道的至高存在在九天之上大战了整整十年。据说那一战打得天崩地裂，无数星辰被余波震碎。最终太初道祖以自身道基受损为代价，将灭道封印在了"无道深渊"的最深处。灭道在封印中发出了最后的诅咒："道不灭，我亦不灭。"果然，十万年过去了，灭道术仍然在世间流传，每一个修习此术的人，都是灭道的意志在人间的延伸。

## 修炼进度

**初期**：理解"灭道"的概念，成功用破道指打断一次低阶神通。成功标志为第一次让敌人神通反噬。

**中期**：掌握道基震荡，成功让一名同阶修士修为暂时跌落。成功标志为让对方三天内无法动用灵力。

**后期**：可以展开万道归墟，让周围百丈内的法则消失。成功标志为在归墟中击败一名依赖法则的对手。

**圆满**：灭道之力收发自如，不再侵蚀自身道心。成功标志为可以同时使用道法和灭道术而不冲突——这意味着已经找到了"道"与"灭道"之间的平衡。
