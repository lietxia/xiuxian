# 虚无禁术

## 基本信息
- **功法名称**：虚无禁术
- **品级**：八阶（道级）
- **类型**：禁术功法
- **适用境界**：大乘期
- **修习难度**：★★★★★

## 功法介绍

虚无禁术来源于虚空中不可名状的存在——那些在宇宙诞生之前就已经存在的"旧日支配者"。与噬神术的虚空邪神不同，虚无禁术的力量来源更加古老和可怕。在宇宙诞生之前的"虚无纪元"，存在着一群没有形体的原始意识，它们是纯粹的概念体——没有善恶、没有目的、没有形态，只是"存在"。当宇宙诞生后，它们被排斥到了宇宙的边缘，存在于"有"与"无"的夹缝中。它们偶尔会向宇宙中投下一些"概念碎片"，这些碎片落入有智慧的生灵脑中，就会变成诡异的功法和知识。虚无禁术就是其中最知名的产物——它是一位大乘修士"无念尊者"在靠近宇宙边缘时，被一团虚无概念击中后脑海中被写入的功法。

## 功法特点

**优点：**
- 攻击方式诡异莫测，不受常规法则约束
- 可以将自身部分"虚无化"，免疫物理攻击
- 虚无之力可以吞噬一切"存在"的事物
- 修炼到极致可以化身为虚无，超脱轮回

**缺点：**
- 使用虚无之力会逐渐失去自我，变得不再像"人"
- 虚无化的身体部位可能会永久消失，无法恢复
- 每次使用都会让施术者感到"存在的空虚"，严重时会失去求生欲
- 虚无禁术会让修炼者被"旧日支配者"注视，被它们视为同类，可能被拉入虚无的世界

## 功法等级

**初虚·虚实转换**：在虚实之间切换，可以让自己的一部分身体暂时虚无化，穿墙遁地。也可以在攻击时让攻击带上虚无属性。

**中虚·虚无侵蚀**：让虚无之力侵蚀现实，将一部分空间"虚无化"。被虚无化的空间会变成空洞，任何东西掉进去都会消失。

**高虚·虚无领域**：展开一片虚无领域，领域内的一切都会逐渐被虚无吞噬。在领域内，施术者可以任意切换虚实状态，立于不败之地。

**极虚·虚无化身**：彻底抛弃肉身，化身为纯粹的虚无存在。从此不再受物理法则约束，但也失去了作为"生灵"的一切——没有情感、没有欲望、没有自我。

## 功法招式

1. **虚无之手**：右手虚化，变为半透明的虚无之手。被这只手触碰的一切都会被"虚无化"——石头变成灰尘、法宝失去灵性、修士的修为被短暂封印。

2. **存在消音**：以虚无之力包裹自身，让自己的"存在感"降为零。在此状态下，无人能用神识感知到施术者，视线中也会自动忽略施术者。是终极的潜行之术。

3. **虚空裂隙斩**：用虚无之力在半空中撕开一道裂隙，裂隙的边缘可以切割一切。此招不是用锋利的刃切割，而是用"不存在"来抹除——被裂隙触碰的部分，会直接消失。

4. **概念吞噬**：直接吞噬敌人的某种"概念"。比如吞噬对方的"痛觉概念"，让对方感觉不到疼痛（但也因此不会察觉自己受伤）；吞噬"灵气概念"，让对方暂时失去对灵气的感知和控制。这是最诡异的攻击方式。

5. **虚无镜像**：制造一个由虚无构成的镜像分身。这个分身在物理上不存在，但能攻击到敌人的灵魂层面。本体越虚弱，分身越强——因为分身是本体"存在"的映射。

6. **归虚·宇宙尘埃**：将自身完全虚无化后，扩散到天地之间。施术者会变成无数微小的虚无粒子，这些粒子可以渗透到任何地方、吞噬任何东西。但施术者化为粒子后，很难重新聚合，可能永远以粒子的形态存在——换句话说，死了。

## 修炼条件

**前置功法**：必须达到大乘期，且对空间法则有极深的领悟（至少八阶空间功法圆满）

**灵根要求**：虚空灵根或混沌灵根，普通灵根无法理解和承载"虚无"

**修炼地点**：必须在宇宙边缘或虚空深处修炼，凡间的法则太"充实"，难以感受虚无

**所需资源**：虚无结晶（宇宙边缘的特产）三百枚、虚灵石一枚、空冥草十株

## 使用限制/副作用

- 每次使用虚无之力，施术者的"存在感"就会减弱一分。身边的人会逐渐忘记施术者的存在
- 虚无化的身体部位可能会在实体化失败时永久消失
- 旧日支配者的低语会不断传入耳中，诱惑修炼者"归于虚无"
- 虚无之力使用过度会导致修炼者失去七情六欲，变成冷冰冰的"活死人"

## 相关典故

无念尊者在获得虚无禁术后，花了三千年将其修至极虚之境。他在修真界留下了无数传说——他曾用"存在消音"在大宗门山门口站了三年无人发现；他曾用"概念吞噬"一口气吞噬了一座城池所有居民的"睡眠概念"，导致全城三十年无人能入睡。然而随着力量的增长，他发现自己越来越不像人——他不再感到快乐和悲伤，不再关心任何事情，连修炼的动力都在消失。最终在一个普通的午后，他选择了彻底虚无化，化为虚无粒子消散在天地之间。他消失前说的最后一句话是："我不是死了，我只是不再存在了。"

## 修炼进度

**初期**：在虚空深处感受虚无的存在，成功将一根手指虚无化并恢复。成功标志为手指在虚实之间转换超过十次而不出问题。

**中期**：能够将手臂或腿部完全虚无化，并在战斗中运用虚实转换。成功标志为用虚无之手吞噬一件天级法宝。

**后期**：成功展开虚无领域，维持超过三息。成功标志为在领域内击败一名大乘期对手。

**圆满**：虚无化全身超过十次而不留下永久损伤，能够抵御旧日支配者的低语诱惑。此时已无限接近虚无的本质，但每一步前行都在失去人性。
