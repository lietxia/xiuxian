# 血河大法

## 基本信息
- **功法名称**：血河大法
- **品级**：四阶（天级）
- **类型**：禁术功法
- **适用境界**：元婴期
- **修习难度**：★★★★☆

## 功法介绍

血河大法的起源与冥界的冥河有关。冥河是冥界的一条巨大河流，河中流淌的不是河水，而是亿万生灵的血液。传说世间所有生灵死后，体内的血液会汇聚到冥河中，冥河是血液的最终归宿。万年前，一位名为"血河老祖"的元婴期魔修在探索冥界裂隙时，坠入了冥河。他在冥河中浸泡了百年而不死，反而与冥河产生了奇异的共鸣——冥河中的血液记忆涌入他的脑海，他看到了亿万生灵的一生。在这些记忆的冲击下，他领悟了一套以血液为核心的大法。他发现自己可以操控血液，不仅是他自己的血液，还有别人的血液。他离开冥河后，将这套法门整理为血河大法，创立了"血河宗"。

## 功法特点

**优点：**
- 可以直接操控敌人的血液，让敌人自爆或自残
- 只要有血液的地方，施术者就能获得力量
- 可以吸收敌人的血液来补充自身，续航能力极强
- 血河大法的修炼不受资质限制，只要不怕杀生

**缺点：**
- 极度依赖血液环境，在无血之地（如沙漠、真空）战力大减
- 控血之术会被高阶修士以灵力强行压制
- 血液中含有他人的记忆碎片，吸收多了会精神错乱
- 使用血河大法会散发浓郁的血腥气，难以隐藏行踪

## 功法等级

**初河·血引**：能够感知到周围血液的存在，并操控血液流动。可用于控敌血液使其眩晕，或止血疗伤。

**中河·血控**：能够强行操控低阶修士体内的血液，让对方按照自己的意志行动。也可以让对方的血液逆流，使其重伤。

**高河·血河真身**：将自身化为血河形态，免疫物理攻击。在血河形态下可以同时操控大量血液进行攻击和防御。

## 功法招式

1. **血引术**：以自身血液为引，远程操控敌人体内的血液。可以令敌人血液加速流动导致心跳过速昏厥，也可以令血液凝固导致器官坏死。

2. **血刺**：将血液凝结为尖刺，从敌人体内爆出。先在敌人体内凝集一滴血，然后令其瞬间化为尖刺，刺穿内脏。防不胜防。

3. **血河护体**：在身体周围形成一道血液护盾。护盾可以吸收攻击，并将吸收的攻击转化为血河之力补充自身。护盾越厚，防御越强。

4. **血河风暴**：释放出体内的血液，化为一场血雨风暴。风暴中的每一滴血都可以作为攻击武器，也可以作为感知的延伸。血雨覆盖之处，一切都在感知之中。

5. **血液分身**：用血液凝聚一个分身，分身拥有本体五成战力。分身被打散后会化为血雾，血雾可以干扰敌人视线，也可以被本体回收。

6. **血河滔天**：释放自身全部血液，化为一条血河冲击敌人。血河具有强大的冲击力和腐蚀性，被血河卷入的敌人会被血液侵入七窍，从内部被摧毁。此招使用后施术者会处于失血状态，需立即补充。

## 修炼条件

**前置功法**：需对血液有基本的掌控能力（燃血术小成即可），且肉身足够强健以承受血液的大量流失

**灵根要求**：水灵根最佳（血液也是水的一种），血灵根或煞灵根也可

**修炼地点**：最好在血液充足的地方修炼，如屠宰场、战场遗址、血池等

**所需资源**：百兽血（百种妖兽血液混合）一大缸、血晶石九块、凝血丹九九八十一枚

## 使用限制/副作用

- 每次大规模使用血河大法，都会大量失血，如果不及时补充，会因失血过多而死
- 吸收他人的血液会同时吸收对方的记忆碎片，吸收多了会导致人格混乱
- 血液中可能含有毒素或诅咒，吸收前需要仔细净化
- 血河大法的修炼者身上血腥味极重，难以融入正常社会

## 相关典故

血河老祖创立血河宗后，广收门徒，将血河大法发扬光大。血河宗最鼎盛时有三千弟子，全部修炼血河大法。他们屠杀了数十万妖兽和凡人，用血液来修炼。然而血河老祖忽略了冥河中的一个隐患——冥河是有意志的。冥河的意志发现血河老祖在盗用自己的力量，勃然大怒。一夜之间，血河宗三千弟子体内的血液全部暴走，将他们从内部撕裂。血河老祖本人被冥河意志拖入了冥河深处，变成了冥河的一部分。血河宗遗址如今被称为"血河禁地"，方圆百里都是血红色的土壤，寸草不生，被血液浸透的土地至今仍在散发血腥气。

## 修炼进度

**初期**：掌握血引术，能够感知和操控小范围内的血液。成功标志为成功让一只妖兽短暂眩晕。

**中期**：能够凝聚血液分身，并对低阶修士进行血液操控。成功标志为血液分身能独立战斗超过一炷香。

**后期**：血河真身大成，可以在血河形态和人体形态之间切换。成功标志为血河形态下击败三名同阶对手的围攻。

**圆满**：血河大法运转自如，控血范围扩大到方圆十里。此时举手投足之间都能引动敌人的血液，同阶对手在没有防备的情况下很可能被一招制敌。
