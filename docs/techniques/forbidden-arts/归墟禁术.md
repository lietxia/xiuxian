# 归墟禁术

## 基本信息
- **功法名称**：归墟禁术
- **品级**：九阶（混沌级）
- **类型**：禁术功法
- **适用境界**：渡劫期
- **修习难度**：★★★★★

## 功法介绍

归墟禁术源自天地间最神秘的地方——归墟。归墟是万物的终点，所有破灭的世界、陨落的生灵、消散的法则最终都会流入归墟，被吞噬为虚无。在归墟的深处，沉睡着上古时代的"墟兽"——一种以世界残骸为食的恐怖存在。三十万年前，一位名为"空寂"的渡劫期修士为了寻求突破，孤身闯入归墟。他在归墟中走了三千年，看到了无数世界的毁灭，也看到了墟獸的苏醒。墟兽睁开眼看了他一眼，就是这一眼，将无数关于"湮灭"和"终结"的法则灌入了他的脑海。空寂在归墟中枯坐万年，将这些法则整理为此术。当他从归墟走出时，世间已过了三万年，他的师门早已化为尘土。

## 功法特点

**优点：**
- 可令万物归于虚无，无视大多数防御
- 对法则类攻击有吞噬效果，可吸收对方攻击中的法则之力
- 归墟之力不可被推演、不可被追踪、不可被天道感知
- 修炼至大成可短暂开启归墟之门，放逐任何敌人

**缺点：**
- 每使用一次，自身的一部分存在感会被归墟吞噬，逐渐从世间"消失"
- 归墟之力会侵蚀使用者的记忆，越用越忘记自己是谁
- 过度使用会导致肉身被归墟同化，变成没有实体的虚无存在
- 此术修炼过程中会不断听到墟兽的低语，意志不坚者会被引入归墟永世不得出

## 功法等级

**初墟·虚无触**：初步掌握归墟之力的微弱投影，可在掌心凝聚一团"虚无"，触碰之物会分解为最原始的粒子

**中墟·归墟之门**：可短暂开启一道通往归墟的裂隙，将敌人或攻击放逐进去。开启时间越长，自身被吸入的风险越大

**高墟·万象归虚**：以自身为中心，将周围一切拉入"归墟领域"。领域内的一切存在都会被缓慢分解为虚无，包括法则和因果

**极墟·墟兽降临**：召唤归墟深处的墟兽投影降临此界。墟兽会吞噬周围的一切存在，不分敌我。此招一出，施术者也未必能活下来

## 功法招式

1. **虚无之握**：右手被归墟之力包裹，握住的任何东西都会开始分解。若握住的是修士的身体，对方的灵力、血肉、魂魄会一层层被剥离，消散于无形。

2. **归墟裂隙**：在半空中撕开一道归墟裂隙，裂隙会产生强大的吸力，将周围的一切吸入归墟。吸力范围随修为增长，最高可覆盖方圆百里。

3. **湮灭波纹**：以自身为中心释放一道无形的归墟波纹。波纹所过之处，一切事物都会失去"存在"的属性——颜色褪去、声音消失、温度归零，最终分解为虚无。

4. **存在抹除**：最恐怖的招式。将目标的存在从因果线上抹除，让世间所有人都忘记这个人的存在。被抹除者不会死，但会永远迷失在"不存在"的状态中，比死亡更可怕。

5. **归墟投影**：将归墟的景象投影到现世，让周围的敌人看到万界毁灭的震撼画面。目睹此景者，道心不坚会直接崩溃，道心坚定者也会短暂失神。

6. **终墟·万物归零**：以自身为祭品，将一方天地完整地拖入归墟。此招不可逆转，施术者和目标区域将一同永远消失在归墟中，连轮回转世的机会都没有。

## 修炼条件

**前置功法**：必须掌握至少一门九阶空间法则和一门九阶毁灭法则，且对"虚无"有深刻的理解

**灵根要求**：虚空灵根或归墟道体，世间罕有

**修炼地点**：必须在归墟边缘修炼，每次修炼不能超过七日，否则会被归墟同化

**所需资源**：墟兽鳞片一枚（极难获取，需入归墟深处寻找）、虚空结晶三百枚、忘情水十滴（用于抵抗归墟的记忆侵蚀）

## 使用限制/副作用

- 每用一次归墟之力，自己的存在感就淡薄一分。用满九次后，世间将无人能记住施术者
- 归墟之力会在体内积累，积满时施术者会被动开启归墟之门，将自己吞噬
- 墟兽的低语会越来越清晰，最终墟兽会询问施术者是否愿意成为它的化身
- 此术无法在阳光下修炼，归墟之力与阳气相冲，强行修炼会导致灵力暴走

## 相关典故

空寂从归墟归来时，发现自己已经被世界遗忘——没有人记得他，他的洞府被他人占据，他的功法被冠以他人之名。他在世间游荡了百年，试图找到自己的存在痕迹，却发现自己就像一个幽灵。最终他回到了归墟边缘，在那里留下了一枚记录着此术的玉简。玉简上刻着一行字："人之存在，不过归墟梦中一瞬。"后来得到此术的修士共有七人，其中五人修至中途被墟兽的低语引走，永堕归墟；一人用此术复仇后自我了断；最后一人修至极墟之境，召唤墟兽降临，毁灭了一个小世界后不知所踪。此术因此被列为九阶禁术之首。

## 修炼进度

**初期**：感应到归墟的存在，在归墟边缘打坐百年而不迷失。成功标志为凝聚出第一缕归墟之力而不被其反噬。

**中期**：成功开启归墟裂隙并控制其大小和吸力，能够放逐同阶敌人的攻击。成功标志为裂隙维持超过三息而不失控。

**后期**：能够展开归墟领域，在领域内掌握绝对优势。成功标志为领域展开后，同阶敌人在三息内开始被分解。

**圆满**：可与墟兽进行精神层面的对话而不被诱惑，掌握了存在抹除的入门之法。此时距离归墟的终极奥秘只有一线之隔——但那一线，可能是万丈深渊。
