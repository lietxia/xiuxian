# 天道禁术

## 基本信息
- **功法名称**：天道禁术
- **品级**：八阶（道级）（帝级）
- **类型**：禁术功法
- **适用境界**：大乘期
- **修习难度**：★★★★★

## 功法介绍

天道禁术并非由任何人所创，而是天道本身的一次"故障"。远古时期，天道规则曾因不明原因出现了一次短暂的崩坏——那三天三夜之间，天机混乱，法则失序，世间的一切规则都陷入了混沌。一些站在修真界巅峰的大乘期修士在这三天中窥见了天道的"源代码"，看到了法则运行的本相。其中一位名为"道玄子"的修士在崩坏结束后，根据记忆拼凑出了这门天道禁术——一种能够直接干预天道运行、篡改法则秩序的逆天之法。天道修复后，道玄子被天道打上了"窃密者"的烙印，他和他创造的这套功法成为了天道要彻底抹除的目标。

## 功法特点

**优点：**
- 可直接修改方圆百里内的天道法则，让火燃烧得更旺或水不再流动
- 可短暂屏蔽天道对自身的气运感知，避开杀劫
- 能够推演出天道运行的轨迹，预知未来片段
- 在自身领域内，可制定临时法则，让敌人无法使用某些神通

**缺点：**
- 每次篡改天道法则都会被天道记录，累积到一定程度会触发"天谴"
- 修改法则需要消耗大量心神，使用后需要长时间恢复
- 若修改法则时出现失误，会导致法则反噬，后果不可预测
- 天道会不断修复被篡改的法则，修复过程中会对施术者产生排斥力

## 功法等级

**初窥·法则感知**：能够感知到天道法则的运行轨迹，看到灵气流动的规则本质。对推演和悟道有极大帮助。

**掌控·法则篡改**：可在小范围内修改非核心法则，比如改变重力方向、让火焰温度降低。修改持续时间和效果与修为成正比。

**通天·法则创造**：可在一片区域内创造全新的临时法则，如"在此区域内，禁制飞行"或"在此区域内，灵力回复速度提升十倍"。创造的法则越逆天，持续时间越短。

**至高·法则抹除**：可短暂抹除一方天地的某条基础法则，如抹除"引力法则"导致一切悬浮，或抹除"时间法则"导致时间静止。这是真正的神明手段，但会引来天道的全力反噬。

## 功法招式

1. **天机推演**：以天道法则为蓝本，推演未来可能发生的事。推演的时间跨度越长，消耗越大。可用来预知天劫、寻找机缘、避开杀局。

2. **法则封锁**：在自身周围构建一道法则屏障，屏障内的法则由施术者控制。敌人进入后，无法使用任何神通，只能依靠肉身力量战斗。

3. **因果篡改**：修改小范围内的因果关系。比如将"因攻果守"改为"因守果攻"，让敌人的攻击招式变为防御姿态。极其消耗心神，一次篡改需休养三日。

4. **天道审判模拟**：模拟天道的审判之力，对敌人降下"伪·天劫"。伪天劫的威力只有真正的天劫的三成，但足以重创大乘期以下的修士。

5. **法则共鸣**：与天地法则建立共鸣，短时间内获得天道的"加持"，所有神通威力翻倍。但此举会惊动天道意志，被天道注视的感觉极其危险。

6. **归无·法则崩坏**：引爆自身对法则的理解，让方圆千里的法则陷入短暂的混沌状态。混沌期间，无人能使用任何神通，天地陷入原始的无序。使用此招后，施术者将对法则的理解全部归零，数千年悟道成果毁于一旦。

## 修炼条件

**前置功法**：至少三门八阶法则类功法修炼至圆满，且必须对五行法则均有深刻理解

**灵根要求**：道体天成者最佳，须是先天对法则有亲和力的体质

**修炼地点**：必须在天地法则最稳固的地方修炼，如天柱山、不周山遗址等地

**所需资源**：天道碎片（天道崩坏时留下的残片，当世仅存三枚）、混沌灵石三百枚、悟道茶百斤

## 使用限制/副作用

- 每次使用都会在神魂上留下一道"法则烙印"，烙印越多，越容易被天道锁定
- 篡改法则会消耗自身寿元，篡改的法则越核心，消耗越大
- 天道有灵，会记恨使用此术者，在渡劫时降下加倍的惩罚
- 若在法则被篡改期间有人因此死亡，业力会计入施术者头上

## 相关典故

道玄子创造此术后，自知已被天道盯上，于是将功法刻在一枚天道玉简中，藏于不周山深处。他自己则选择了兵解轮回，试图通过转世来躲避天道的抹杀。然而天道岂会轻易放过他——他的每一世转世都活不过三岁，要么夭折，要么被天雷劈死，永世不得修行。三十万年后，他的功法玉简被一名采药的散修发现，那名散修就是后来的"天机老人"。天机老人凭此术修至大乘，但他在飞升前夕被九九八十一道天道神雷劈得灰飞烟灭，死前他仰天长叹："窥天者，天必诛之。"

## 修炼进度

**初期**：感悟天道法则的存在，能够在入定状态下看到灵气运行的规则脉络。成功标志为第一次成功预测到一次小型天象变化。

**中期**：掌握法则篡改的基础，能够改变方圆十丈内的简单法则（如让水变粘稠）。成功标志为连续三次篡改法则而不被天道反噬。

**后期**：能够在战斗中临时创造简单的法则，如制造一片"禁止灵气流动"的区域困敌。成功标志为在法则被天道修复前完成了战术目的。

**圆满**：法则篡改的范围扩大到方圆百里，可以创造持续十二个时辰的临时法则。此时已有与天道短暂抗衡的资本，但每一次出手都在玩火。
