# 噬魂术

## 基本信息
- **功法名称**：噬魂术
- **品级**：二阶（玄级）
- **类型**：禁术功法
- **适用境界**：筑基期
- **修习难度**：★★☆☆☆

## 功法介绍

噬魂术的源头可以追溯到冥界深处的一道裂隙。五百年前，冥界与人间的壁垒在某次天地大劫中出现了微小的裂缝，一缕冥界的死寂之气渗入了凡间。一位名叫"鬼手婆婆"的筑基期散修偶然发现了这道裂缝，她大胆地将一缕魂力探入冥界，触碰到了冥界中游荡的亡魂。那一刻，无数的亡魂记忆涌入她的脑海——她看到了冥界亿万亡魂的悲鸣、怨念和不甘。鬼手婆婆花了三十年时间，从这些亡魂记忆中提炼出了一套吞噬魂魄的法门。此术一经问世，立刻成为了鬼道修士的必修之法。

## 功法特点

**优点：**
- 可以吞噬亡魂增强自身魂力，魂力越强，神识越敏锐
- 可读取被吞噬魂魄中的记忆碎片，获取情报
- 能够驱使吞噬的亡魂为己战斗，以寡敌众
- 魂力强大后可以施展神魂攻击，防不胜防

**缺点：**
- 吞噬亡魂会将亡魂的怨念也带入识海，长期积累会侵蚀心智
- 使用此术时身上阴气弥漫，烈日下会感到虚弱
- 被吞噬的亡魂若生前修为高于施术者，反噬风险极大
- 正道修炼场所（寺庙、道观）对此术有天然的压制效果

## 功法等级

**初层·魂食**：可吞噬普通凡人亡魂，增强自身魂力的基础量。对修士亡魂吞噬效率较低。

**中层·魂噬**：可吞噬筑基期及以下的修士亡魂，获得对方的记忆碎片。同阶亡魂吞噬无压力。

**高层·魂王**：可吞噬金丹期修士的亡魂，并能同时驱使上百只亡魂组成魂军。对魂力的运用已达入微之境。

## 功法招式

1. **噬魂爪**：右手凝聚魂力化为鬼爪形状，一爪撕出可直接抓取对方的魂魄进行撕扯。中招者三魂七魄受损，轻则头痛欲裂，重则当场昏迷。

2. **魂体转换**：将自身化为半虚半实的魂体状态，免疫物理攻击，但会受到法术攻击的双倍伤害。在此状态下可以穿墙遁地，也可以直接攻击敌人的魂魄。

3. **万魂噬**：将吞噬来的亡魂一次性释放出去，形成亡魂洪流。每一只亡魂都会撕咬敌人的血肉和魂魄，数量越多越恐怖。此招一出，方圆百里的气温骤降，天空昏暗如夜。

4. **记忆窃取**：从吞噬的魂魄中提取指定的记忆片段。可以用于拷问情报，也可以用来学习对方掌握的技能——前提是对方的技能在自己的理解范围内。

5. **魂甲附体**：将亡魂附着在自己体表，形成一层由魂力构成的护甲。魂甲可以吸收法术攻击，并对近战攻击者造成魂力反噬。魂甲的强度取决于附着亡魂的数量和质量。

## 修炼条件

**前置功法**：化魂术小成，或任意一门鬼道基础功法小成

**灵根要求**：阴灵根最佳，幽冥灵根亦可；纯阳灵根无法修习

**修炼地点**：必须在阴气浓郁之地修炼，最好是乱葬岗、古战场或冥界裂隙附近

**所需资源**：引魂香三十根、聚阴阵盘一套、百年棺材钉九枚（用于布置聚阴阵）

## 使用限制/副作用

- 每次吞噬亡魂后，施术者身上会留下一道"魂痕"，积累到一定程度会吸引冥界使者的注意
- 吞噬亡魂过多会导致自身七魄混乱，出现人格分裂症状
- 在阳气旺盛之地（如正午阳光下）战力减半
- 若吞噬了含怨气极重的厉鬼，可能会被厉鬼反噬夺舍

## 相关典故

鬼手婆婆晚年时，已经吞噬了上万亡魂，魂力强大堪比金丹期修士。她妄图冲击金丹，却在结丹的关键时刻被体内的亡魂集体反噬——上万道怨念同时爆发，将她的识海撕碎。鬼手婆婆的肉身在三天内化为了一具枯骨，但她的魂魄却被困在体内，被万魂日夜啃噬，求生不得求死不能。当地修士路过她坐化的山洞时，仍能听到洞中传来令人毛骨悚然的惨叫声。后来有人将此洞封印，称为"万魂窟"，列为禁地。

## 修炼进度

**初期**：感应到亡魂的存在，成功吞噬第一只凡人亡魂。成功标志为魂力有明显增长，且能感知到周围是否有亡魂存在。

**中期**：吞噬筑基期修士亡魂而不被反噬，能从亡魂记忆中提取有用信息。成功标志为同时驱使十只亡魂而不感到吃力。

**后期**：魂力凝实，可在虚实之间切换自如。成功标志为成功吞噬一只金丹期厉鬼并将其怨念压制在识海深处。

**圆满**：体内积累的亡魂达到千只，但能够保持自我意识不被怨念侵蚀。此时可尝试进阶修习更高级的噬魂类禁术。
