# 血祭术

## 基本信息
- **功法名称**：血祭术
- **品级**：三阶（地级）
- **类型**：禁术功法
- **适用境界**：金丹期
- **修习难度**：★★★☆☆

## 功法介绍

血祭术源自人族最原始的野蛮时代——那时人类还未掌握修仙之法，以部落和氏族的形态生存。在那个蒙昧的年代，人们相信通过献祭鲜血可以取悦神灵、获得庇佑。最初的"血祭"是用牲畜的血液来祭祀天地。后来，一些部落发现用人类血液的效果远超牲畜——因为人类的血液中含有灵性。于是，一些原始部落开始用战俘和奴隶的血来进行祭祀。这种原始血祭代代相传，在无数代巫师的改良下，逐渐从原始仪式演变为了一套系统的修炼功法。血祭术是所有血道功法的根基，也是最为人熟知、流传最广的禁术。

## 功法特点

**优点：**
- 可以通过血祭快速获取力量，不需要长时间的积累
- 血祭的对象不限，可以是妖兽、修士、凡人，甚至天材地宝
- 可以用来突破瓶颈——血祭的能量可以直接推动修为提升
- 可以用来强化法宝——血祭过的法宝会带有"嗜血"属性

**缺点：**
- 血祭获得的力量根基不稳，容易导致走火入魔
- 血祭时会积累"血煞"，血煞会侵蚀神智
- 血祭的动静较大，容易引来正道修士的注意
- 依赖血祭突破的修士，后续修炼会比常人艰难十倍

## 功法等级

**初祭·牲祭**：献祭妖兽或凡人，用其血液和生命力换取短暂的力量加持。献祭一条人命可维持一个时辰的战力提升。

**中祭·灵祭**：献祭修士或高阶妖兽，用其精血和修为换取更强大的力量。献祭一名金丹期修士可获得其三成的修为积累。

**高祭·命祭**：献祭与自己有血缘关系的至亲，以血脉之力换取极限的力量。命祭的力量远超其他祭祀方式，但会遭到天谴。

## 功法招式

1. **血祭之刃**：以献祭得来的血煞之力凝聚一柄血刃。血刃锋利无比，且造成的伤口难以愈合。被血刃伤到的人，血液会不断流失，直到流干。

2. **血祭之阵**：在地上刻画血祭阵纹，将阵中的祭品献祭。阵法会自动抽取阵内生灵的血液和生命力，汇聚到施术者体内。阵法可以提前布置，用于埋伏。

3. **血祭强化**：在战斗中临时献祭自己的部分血液（燃血术的变体），强化自身战力。也可以在炼器或炼丹时献祭血液，提升成品的品质。

4. **血祭诅咒**：以血祭之力对目标施加诅咒。诅咒的形式多样——可以是让目标持续失血的"血崩咒"，也可以是让目标血液腐败的"血毒咒"。需要获得目标的一滴精血作为媒介。

5. **血祭召唤**：以大量的血液为引，召唤冥界或血狱中的生物降临。召唤的生物强大但难以控制，可能反噬施术者。血液越多，召唤的生物越强。

## 修炼条件

**前置功法**：燃血术小成，对血液的掌控有基本了解

**灵根要求**：无特殊灵根要求，但煞灵根或火灵根对血祭有加成效果

**修炼地点**：需在隐蔽之地修炼，因为血祭的动静和血腥气会引起注意

**所需资源**：血灵石（产自血矿的特殊灵石）十枚、血引香三根、以及足够的祭品（妖兽或修士）

## 使用限制/副作用

- 血祭积累的血煞会对身体造成负担，血煞过重会导致早衰
- 每次血祭都会折损少许寿元，献祭的生命越强，折损越多
- 血祭的祭品若含有怨念，怨念会附着在施术者身上，引来冤魂索命
- 使用血祭术的人身上带有血煞之气，容易被仇家追踪

## 相关典故

北疆有一个古老的蛮族部落叫做"血祭族"，他们世代以血祭术为立族之本。血祭族的大祭司曾在一次祭天中，献祭了一百名战俘，换取了天降血雨的异象——血雨淋过的地方，庄稼一年内疯长十倍，族人战力翻倍。然而好景不长，血祭族的大祭司发现，每次血祭之后，族人的寿命都会缩短。他算了算，经过三代人的血祭，族人的平均寿命已经从六十岁降到了三十岁。血祭族的末代族长在临死前下令销毁了所有血祭术的记载，但已经太晚了——整个部族的人体内都积累了血煞，每一个新生儿都活不过二十岁。血祭族就此灭绝。

## 修炼进度

**初期**：第一次进行血祭，献祭一只妖兽并成功吸收其血液能量。成功标志为吸收后战力有明显提升且没有严重副作用。

**中期**：掌握血祭之阵，能够用阵法献祭多个目标。成功标志为一次献祭三只妖兽而不出意外。

**后期**：能够精准控制祭品的献祭程度，做到"只取所需，不浪费"。成功标志为献祭一名修士后，吸收效率达到七成以上。

**圆满**：血祭术的基础已经扎牢，可以为后续修习更高阶的血道功法（如血神经、血河大法）打下基础。圆满的标志是能够在不伤害自身的前提下完成一次血祭。
