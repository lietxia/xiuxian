# 噬天术

## 基本信息
- **功法名称**：噬天术
- **品级**：三阶（地级）
- **类型**：禁术功法
- **适用境界**：金丹期
- **修习难度**：★★★☆☆

## 功法介绍

噬天术并非如名所示真的吞噬苍天，而是一门窃取天机、掠夺天地灵气的禁忌法门。此术由散修"吞海真人"在东海孤岛上参悟三十年所创。吞海真人原本只是金丹期的普通修士，因灵根资质低劣，修炼速度极慢。他在一次渡金丹劫时被天雷劈中，九死一生之际，竟意外感知到了天地灵气运转的"缝隙"——他发现天地间的灵气并非均匀分布，而是循着某种规律流动。若能截取这些灵气流，就能以他人百倍的速度修炼。他将这种感悟整理成法，便是噬天术。

## 功法特点

**优点：**
- 修炼速度极快，堪比天灵根修士
- 可在灵气稀薄之地强行抽取周围的天地灵气
- 能够感应到灵脉走向和天材地宝的位置
- 修炼至大成可短暂屏蔽天道感知，躲避天劫追踪

**缺点：**
- 掠夺灵气会破坏当地生态，导致草木枯萎、灵兽死亡
- 被掠夺的地方法则会记录下施术者的气息，正道修士可据此追踪
- 使用次数过多会引发天地气运反噬，出门必遇灾祸
- 掠夺来的灵气蕴含杂质，需要大量时间提纯，否则会堵塞经脉

## 功法等级

**初窥·灵气掠夺**：感知灵气流动的规律，可小范围（方圆十里）掠夺灵气为己用，提升修炼速度三倍

**掌控·地脉截流**：可感知地下灵脉走向，强行截断灵脉抽取灵气，但会永久破坏该条灵脉

**通天·天机窃取**：短暂屏蔽天道感知，在渡劫时偷取天劫之力转化为自身修为，极度危险

## 功法招式

1. **吞灵漩涡**：在头顶三尺处凝聚一个无形的灵气漩涡，疯狂吸取方圆三十里内的天地灵气。漩涡持续一炷香时间，期间施术者修炼速度提升十倍。

2. **地脉锁链**：以灵力凝聚锁链刺入地下，锁定地底灵脉进行强行抽取。锁链扎根之处，方圆百里的草木会在一刻钟内全部枯萎。

3. **天道隐息**：暂时屏蔽自身气息，使天道无法感知到自己的存在。持续时间内渡劫不会触发、占卜无法追踪、推演一片混沌。最长持续十二个时辰。

4. **灵爆穿刺**：将掠夺来的未经提纯的狂暴灵气直接打入敌人体内。灵气中的杂质会在敌人体内引爆，造成经脉寸断、丹田碎裂的恐怖效果。

5. **劫力偷取**：在他人渡劫时，暗中窃取天劫之力化为己用。每偷取一道天雷，自身修为就增厚一分，但被渡劫者发现后两人都会遭受加倍天劫。

## 修炼条件

**前置功法**：需将任意一门三阶功法修炼至大成，金丹期修为稳固

**灵根要求**：对灵根无特殊要求，但灵根品质越差，修习此术的渴望越强——此术本就是为劣质灵根者准备的逆天之法

**修炼地点**：首次修炼必须在灵气充裕之地，否则无法感知灵气流动规律

**所需资源**：聚灵阵盘一套、上品灵石百枚、引灵香三根

## 使用限制/副作用

- 掠夺灵气后，当地天道会记下施术者的气息，此后施术者在此区域内运气大幅下降
- 长期掠夺灵气会导致自身灵力"杂质化"，灵力纯度下降，同阶对战处于劣势
- 被掠夺之地的修士和妖兽会循着气息前来复仇
- 天道隐息使用后，下次被天道感知时会引来双倍天劫

## 相关典故

吞海真人凭借此术只用了一百二十年就从金丹修炼至元婴期，震惊东海修真界。然而他因常年掠夺灵气，导致东海三座大型灵脉枯竭，引发了东海龙族的震怒。龙王亲自出手追杀吞海真人，他逃入南海深处，在天道隐息的状态下躲藏了三十年。但当他解除隐息的瞬间，积攒了三十年的天道感知一次性降临，降下了前所未有的"九重叠加天劫"。吞海真人被劈得魂飞魄散，连转世投胎的机会都没有。他的洞府后来被渔民发现，洞中留下了完整的噬天术功法玉简。

## 修炼进度

**初期**：感悟灵气流动的规律，能够在入定状态下"看到"灵气运行轨迹。成功标志为第一次成功聚拢灵气漩涡，使修炼速度提升一倍。

**中期**：能够感知地底灵脉，并在不破坏灵脉的前提下进行有限度的抽取。成功标志为成功截流一条小型灵脉而不引发地陷。

**后期**：掌握天道隐息之术，可短暂躲避天道探查。成功标志为在隐息状态下成功渡过一次小天劫而不被天道锁定。

**圆满**：可自由切换掠夺与正常修炼模式，灵力杂质比例控制在安全范围内。此时已为此术之巅峰，再进一步就需要进军更高阶的掠夺类功法。
