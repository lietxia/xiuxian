# 血遁术

## 基本信息
- **功法名称**：血遁术
- **品级**：二阶（玄级）
- **类型**：禁术功法
- **适用境界**：筑基期
- **修习难度**：★★☆☆☆

## 功法介绍

血遁术是最为人所知的逃命禁术，几乎所有修士都知道它的存在。它的诞生源于一个残酷的故事——五百年前，散修"血燕子"被仇家追杀，身负重伤，灵力枯竭。他的仇家布下了天罗地网，封死了他所有逃生的路线。血燕子被逼到了绝路，他看着自己流出的鲜血，忽然想到：既然灵气可以催动遁术，血液为什么不行？他燃烧了自己的精血，以血为燃料，发动了一次惊天遁术——他的身体化为一道血光，瞬间穿越了仇家布下的三层禁制，逃出了百里之外。那次遁术消耗了他七成精血，他养了半年才恢复。但血遁术就此诞生，成为了低阶修士保命的不二法门。

## 功法特点

**优点：**
- 发动速度极快，几乎是瞬间完成
- 可以突破大多数禁制和阵法（血遁术的本质是以血破法）
- 不需要灵力支持，灵力枯竭时也能使用
- 修炼门槛低，筑基期即可掌握

**缺点：**
- 消耗精血，每次血遁都会折损寿元（约一年）
- 血遁的距离和精血消耗成正比，遁得越远消耗越大
- 血遁后会极度虚弱，短时间内失去战斗力
- 血遁的血光轨迹清晰可见，容易被追踪

## 功法等级

**初遁·血光遁**：燃烧一成精血，化为血光遁出十里。消耗较小，适合短距离逃命。

**中遁·血影遁**：燃烧三成精血，化为一道血影遁出百里。速度快到肉眼无法捕捉，但血影的轨迹仍然可以被神识锁定。

**高遁·血空遁**：燃烧五成精血，强行撕裂空间进行空间跳跃。可以无视大部分禁制，遁出千里之外。但空间跳跃的危险性极高，可能被空间乱流绞杀。

## 功法招式

1. **血光闪**：最基本的血遁之法。身体化为一道血光，以极快的速度向指定方向移动。距离十里以内，可以用来躲避致命一击。

2. **血影分身**：在血遁的同时留下一个血影分身迷惑追兵。分身会向另一个方向逃窜，吸引敌人的注意力。分身持续一炷香后消散。

3. **血遁·破阵**：专门用于突破禁制和阵法的血遁。以血液中的灵性来"欺骗"禁制，使其误判为阵内气息，从而穿行无阻。

4. **血遁·逆流**：在血遁过程中改变方向一次，让追兵措手不及。正常的血遁是直线，逆流可以让轨迹变成折线。

5. **血遁·血爆**：在血遁的终点引爆残留的血液，制造一次血爆。血爆可以杀伤追兵，也可以炸毁地形阻断追击。但引爆会消耗额外的精血。

## 修炼条件

**前置功法**：燃血术小成且无后遗症，对血液燃烧有基本的掌控

**灵根要求**：无特殊要求，但水灵根或血灵根的血遁效果更好

**修炼地点**：最好在开阔地带练习，避免血遁过程中撞上山体或禁制

**所需资源**：补血丹数百枚（修炼中会大量失血）、血灵石数枚（用于辅助修炼）、回春草若干

## 使用限制/副作用

- 血遁后精血亏损，需要至少七日静养才能恢复
- 精血亏损期间战力大幅下降，是血遁后最危险的时期
- 如果在一个月内连续使用多次血遁，可能会永久损伤精血上限
- 血遁术的血光会暴露逃跑方向，强者可以根据血光追踪

## 相关典故

血燕子凭此术在修真界闯下了"天下第一难杀"的名号。他被追杀过无数次，每一次都用血遁逃脱。他的仇家们想尽办法克制血遁——有人布置了禁空大阵，有人准备了锁血法宝，有人请来了速度比他血遁还快的合体期大能。但血燕子总能在绝境中找到生机——他把血遁术练到了出神入化的境界，甚至可以连续血遁三次。后来他的仇家们联合起来，设下了一个陷阱：他们在方圆千里内布下了"噬血阵"，此阵会疯狂吸收阵内的血液。血燕子在发动血遁时，血液被阵法吸走了大半，血遁到一半就因失血过多而昏迷。他被抓住后，仇家们将他囚禁在了一处地牢中。但他在地牢中自创了一门"血遁·穿墙"，用仅剩的血液穿过了地牢的墙壁——虽然只逃出了三丈就被抓回，但他的创造力让所有人都感到震惊。血燕子最终被处死，但他的血遁术传遍了天下。

## 修炼进度

**初期**：成功发动血光遁，遁出至少一里，且没有撞上障碍物。成功标志为血光遁后精血消耗在可接受范围内（不到一成）。

**中期**：掌握血影遁，能在被追杀时快速逃离战场。成功标志为在战斗中发动血影遁成功逃脱。

**后期**：尝试血空遁，撕裂空间进行跳跃。成功标志为在开阔地带成功进行第一次空间跳跃而没有受伤。

**圆满**：血遁术已登峰造极，可以做到"心念所至，血遁即至"。此时的血遁已融入本能，遇到危险会自动触发——这也是血燕子巅峰时的水平。
