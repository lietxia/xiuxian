# 燃魂术

## 基本信息
- **功法名称**：燃魂术
- **品级**：三阶（地级）（地级）
- **类型**：禁术功法
- **适用境界**：金丹期
- **修习难度**：★★★☆☆

## 功法介绍

燃魂术的诞生源于一场绝望的求生。八百年前，鬼道散修"魂灭散人"被三大金丹期修士追杀至冥界边缘。他身受重伤，灵力枯竭，逃生无望。在冥界的阴风中，他感受到自己的灵魂正在被冥界吸引——那是死亡的召唤。在绝境中，魂灭散人产生了一个疯狂的念头：既然横竖都是死，不如把灵魂当作燃料来换取最后一搏的力量。他点燃了自己的魂力，那一刻他的神识扩大了十倍，感知到了方圆千里的一切。他用爆发出的魂力轻易地击杀了追兵，但他的灵魂也因此燃烧了三分之一，陷入了长达十年的昏迷。醒来后，他根据这次经历整理出了燃魂术。

## 功法特点

**优点：**
- 燃烧魂力可以获得强大的神识力量，感知范围扩大数倍
- 燃魂状态下，幻术和精神攻击的威力暴增
- 可以用来增强魂魄类功法的效果，弥补灵力不足
- 在濒死时燃烧部分魂魄可以拖延死亡时间，争取救援

**缺点：**
- 魂力燃烧不可逆，烧掉的魂魄无法再生
- 魂魄受损会直接影响神智，燃烧过多会导致痴呆
- 每次燃魂后都会陷入虚弱期，时间长短视燃烧量而定
- 长期燃魂会导致魂魄"枯萎"，最终魂飞魄散

## 功法等级

**初燃·魂火**：点燃一丝魂力，在识海中升起一团魂火。魂火可以照亮识海的黑暗角落，增强神识感知，同时小幅提升精神类攻击的威力。

**中燃·魂焰**：点燃一成魂力，魂焰在体外燃烧，形成一层淡蓝色的灵魂火焰。魂焰可以直接灼伤敌人的魂魄，对鬼修和魂修有奇效。

**高燃·魂炽**：点燃三成魂力，魂焰冲天而起，形成一道灵魂火炬。此时施术者的神识可以覆盖整个战场，一切都在感知之中。魂力强度暴涨。

## 功法招式

1. **魂火术**：在指尖点燃一朵魂火，魂火可以照亮识海中的迷雾。在对敌时可以将魂火打入对方识海，灼烧对方的魂力。中招者会感到识海中被点燃了一团火，痛苦不堪。

2. **魂焰外放**：将魂焰从体内释放出去，形成一道火焰屏障或者火焰攻击。魂焰直接灼烧灵魂，无视物理防御和大部分法术防御。被魂焰沾身，如灵魂放在火上烤。

3. **灵魂燃烧**：主动点燃自身魂力，换取神识和魂力的爆发式增长。燃烧期间，所有魂力类神通的威力翻倍。但每燃烧一息，魂魄就永久损耗一分。

4. **燃魂咒印**：在目标身上种下一道燃魂咒印，咒印会缓慢地点燃对方的魂力。中术者会感觉自己的灵魂在不知不觉中被燃烧，魂力持续流失。若不及时驱散咒印，最终会魂力燃尽而亡。

5. **魂爆术**：将燃烧的魂力凝聚成一个魂力炸弹，打入敌人体内后引爆。魂爆可以直接炸碎敌人的魂魄，威力取决于注入的魂力量。这也是燃魂术中最危险的招式——若魂力控制不稳，会在自己体内提前引爆。

## 修炼条件

**前置功法**：需修炼过化魂术、噬魂术或任意魂魄类基础功法，魂力基础扎实

**灵根要求**：阴灵根或幽冥灵根最佳，纯阳灵根燃魂会加速魂力消耗

**修炼地点**：最好在阴凉宁静之处，避免阳气过盛加速魂力消耗

**所需资源**：养魂木一段、凝魂香三根、魂晶十块（用于补充修炼中消耗的魂力）

## 使用限制/副作用

- 魂力燃烧后不可恢复，每燃烧一丝，魂魄就永久少一丝
- 燃魂过度会导致失忆——燃烧到一定程度会忘记自己是谁
- 魂力不足时强行燃魂，会直接烧毁灵智，变成白痴
- 燃魂的状态下，施术者会被鬼物和冥界生物感知到，容易引来麻烦

## 相关典故

魂灭散人从昏迷中醒来后，发现自己忘记了十年的记忆——他的妻子是谁、他为什么被追杀、他的仇人是谁，一切都不记得了。他只记得燃魂术的完整口诀。他在世间游荡，靠燃魂术一次次在危机中活下来，但每用一次，他就忘记更多的东西。一百年后，他忘记了自己的名字，忘记了自己是人类，甚至忘记了为什么要活着。他变成了一个在世间游荡的"燃魂者"，遇到敌人就燃烧魂魄战斗，打完就走，没有目的，没有方向。后来有人在一处荒山的山洞中发现了他——他的魂魄已经完全燃尽，肉身保持着打坐的姿态，但已经没有了灵魂。

## 修炼进度

**初期**：在识海中成功点燃魂火而不被烧毁神智。成功标志为魂火稳定燃烧一炷香而不熄灭。

**中期**：掌握魂焰外放，能够在体外维持魂焰形态攻击敌人。成功标志为用魂焰烧伤一名同阶妖兽而不伤及自身。

**后期**：能够精准控制燃烧的魂力比例，做到"烧多少换多少"。成功标志为燃魂状态下击败对手后仍能保留七成以上的魂力。

**圆满**：燃魂术的运用已经炉火纯青，魂火可以随心而燃、随心而灭。但圆满不等于安全——无论技巧多熟练，损耗的魂力终究是回不来的。
