# 灵气感知

## 基本信息
- **功法名称**：灵气感知
- **品级**：一阶（黄级）（黄级）
- **类型**：秘法功法
- **适用境界**：聚气期
- **修习难度**：★☆☆☆☆

## 功法介绍

《灵气感知》是所有修仙者踏上修行之路的第一门功课。它的起源可以追溯到远古时期的精灵族——那是一群与自然和谐共处的生灵，天生就拥有感知灵气流动的能力。精灵族不需要修炼这门秘法，因为对他们来说，感知灵气就像人类感知空气一样自然。

但人类修士没有这种天赋。于是，一位名叫"灵曦"的精灵族公主嫁给了一位人类修士后，将精灵族的感知法门用人类的语言整理成了系统的修炼之法。《灵气感知》就此诞生。

此秘法的核心是"开窍"——打开人体七窍之外的"第八窍"：灵窍。灵窍打开后，修士就能像精灵一样感知到周围灵气的流动、浓度、属性变化，甚至能感知到隐藏在物体内部的灵气痕迹。这门秘法本身没有任何攻击力，但它是所有高阶秘法的基础——如果你连灵气都感知不到，还谈什么操控它呢？

## 功法特点

**优点：**
- 修行门槛极低——只要有一只灵根就能修习，不挑资质
- 一旦学会终身不忘——灵窍一旦打开就不会关闭，你会永远拥有感知灵气的能力
- 实用性极强——寻找灵脉、探测天材地宝、追踪敌人、发现陷阱，全都要用到灵气感知
- 辅助效果出众——感知能力越强，修炼其他功法的效率就越高

**缺点：**
- 本身没有任何攻击力和防御力，纯粹是辅助性秘法
- 感知范围越大、精度越高，对精神的消耗就越大
- 在灵气狂暴的环境（如雷劫中心、灵气风暴中）感知能力会严重受阻
- 如果感知到不该感知的东西（比如强大的远古存在），可能会对精神造成冲击

## 功法等级

**灵窍初开**：首次成功感知到灵气的存在。在修炼者的"视野"中，原本空无一物的地方出现了微弱的光点——那是游离在空气中的灵气粒子。

**百步感知**：感知范围扩展到百步左右。能够分辨出不同属性的灵气颜色——火灵气是红色的、水灵气是蓝色的、木灵气是绿色的。

**千步感应**：感知范围扩展到千步。可以感知到地下深处的灵脉走向、隐藏在物体内部的灵气印记、甚至其他修士体内的灵气运转情况。

**万物灵视**：感知能力达到极致，眼中世界不再是原本的样子——你看到的是"灵气版"的世界。每一座山、每一条河、每一棵树，都散发着独特的灵气光芒。

## 功法招式

1. **灵嗅术**：将感知能力集中在鼻窍，如同猎犬一样通过"气味"来感知灵气的种类和来源。每一种灵石、每一株灵草都有独特的灵气气味。

2. **地听术**：将感知能力集中在耳窍，倾听地下深处灵气流动的声音。灵脉在地下流动会发出特有的"灵力回响"，可以隔着厚厚的地层找到灵脉的走向。

3. **灵眸术**：将感知能力集中在双眼，看到灵气的颜色和亮度。这是最常用的感知方式——通过灵气的颜色判断属性，通过亮度判断浓度。

4. **心神网**：将感知能力编织成一张无形的网，均匀覆盖在周身的空间中。任何进入"网"中的灵气波动都会被立即感知到。

## 修炼条件

**前置功法**：无——这是修行者的入门第一课

**灵根要求**：有任何一种灵根即可，无属性要求。但如果连下品杂灵根都没有，则无法修行

**修炼地点**：任何地方都可以，但灵气浓度较高的地方更容易感知到灵气，适合初学者

**所需资源**：不需要任何资源。一枚下品灵石（作为感知目标）就够了

## 使用限制/副作用

- 长时间开启感知能力会导致精神疲劳——感知能力不是被动技能，需要主动开启
- 在灵气浓度极低的区域（如一些绝灵之地），感知能力会失效
- 过度依赖灵气感知会让修士的常规五感（视觉、听觉等）退化
- 某些秘境中的"假性灵气"（由幻阵模拟出的灵气波动）会产生误导

## 相关典故

传说精灵族公主灵曦在嫁给人类修士时，带来了精灵族的至宝"灵曦之泪"——那是一枚水滴形状的水晶，佩戴者可以永久性地获得超强的灵气感知能力。后来这枚水晶不知所终。有人说它被灵曦带入了坟墓，有人说它碎裂成了无数碎片散落在世界各地。

每隔几百年，就会有人声称找到了"灵曦之泪"的碎片。但由于真正的灵曦之泪早已失传，市面上流传的都是仿制品。不过有趣的是，即便仿制品也有一定的效果——因为制作仿制品的材料本身就有微弱的灵气感知增幅作用。

## 修炼进度

**开窍期（7-49天）**：灵窍的打开时间因人而异——最短七天，最长四十九天。资质越好开窍越快。如果四十九天还打不开灵窍，说明灵根资质太过低劣，不推荐继续走修仙之路。

**感知期（1-3个月）**：从能感知到灵气到能分辨灵气属性和流向。此阶段需要大量的感官练习。

**扩展期（3-12个月）**：感知范围从十步到百步到千步的逐步扩展。此阶段需要配合"心神网"的练习。

**极致期（1-3年）**：达到万物灵视的境界，可以随心所欲地调整感知的广度和精度。至此，灵气感知秘法已经圆满。
