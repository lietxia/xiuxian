# 灵气化形

## 基本信息
- **功法名称**：灵气化形
- **品级**：二阶（玄级）
- **类型**：秘法功法
- **适用境界**：筑基期
- **修习难度**：★★☆☆☆

## 功法介绍

万余年前，一位半人半妖的混血修士白泽，在觉醒体内上古神兽"白泽"血脉时，发现自己可以用灵气模仿各种神兽的形态和气息。他花了五百年时间游历四海，观察真龙、凤凰、麒麟、玄武、白虎等五方神兽的形态特征，最终创出了《灵气化形》秘法。

此秘法的核心在于"以意塑形，以神赋灵"——不单单是用灵气捏出一个空壳外形，而是要让灵气模拟出对应事物的神韵和特质。比如化形成虎，则要有虎的威猛杀气；化形成龙，则要有龙的高贵威严。形似易，神似难，这是此功法的精髓所在。

最初白泽将此术用于隐匿和伪装，后来发现化形后的灵体还具有独特的战斗能力，于是将其发扬光大，成为了一门攻防兼备的实用秘法。

## 功法特点

**优点：**
- 极强的伪装能力，可以变化成各种飞禽走兽甚至草木山石，用于侦查和潜行
- 化形出的灵体可以独立行动，相当于多了一个分身帮手
- 不同的化形有不同特性：化鹰可飞行侦察，化鱼可水下潜行，化虎可增强战力
- 修炼门槛不高，是筑基期修士少有的兼具实用性和趣味性的秘法

**缺点：**
- 化形出的灵体只有本体十分之一的实力，不堪正面战斗
- 维持化形需要持续消耗灵气，时间越长消耗越大
- 遇到修为高出一个大境界以上的修士，化形很容易被看穿
- 对灵气操控的精细度要求较高，手笨之人可能一辈子都化不成像样的形态

## 功法等级

**形似神离**：能用灵气捏出一个粗略的外形，但细节模糊，缺乏神采。化形的虎看起来像是一只臃肿的猫，化形的鹰翅膀不对称飞不稳。

**形神兼备**：外形逼真，神韵初具。化形的动物已经能够模仿其叫声和基本动作，不仔细看难以分辨真假。

**灵体分离**：化形出的灵体可以脱离修炼者独立行动，最远距离可达百丈。灵体所见所闻可实时传回修炼者的意识中。

**万物化生**：臻至大成，不仅可以化形动物，还可以化形植物、山川甚至云雾。化形之物不但外形逼真，还具备基本的灵性，可以自主做出简单反应。

## 功法招式

1. **灵鹰探云**：化形一只苍鹰，翱翔于千丈高空俯瞰大地。鹰眼所见即是己眼所见，用于侦查和追踪敌人效果极佳，是散修们最常用的招式之一。

2. **灵虎啸山**：化形一头白虎，伴随一声虎啸震慑心神。虎啸带有灵气震荡，可以让低阶修士短暂失神，为后续攻击创造机会。

3. **灵鱼潜渊**：化形一条游鱼，在水中自由穿梭。灵气鱼可以在水下潜伏长达一个时辰，且能感知水流的微妙变化，用于水下寻宝或躲避追捕。

4. **灵藤缠绕**：化形数条藤蔓从地下钻出，缠绕敌人的四肢。藤蔓上带有倒刺，刺入皮肤后会释放麻痹毒素——当然，这毒素也是由灵气模拟的。

5. **万灵朝宗**：同时化形上百只小型灵兽（蜂鸟、蝴蝶、甲虫等），形成一片灵兽潮。每一只小灵兽都带有微弱的灵气爆炸效果，密集轰炸下威力不容小觑。

## 修炼条件

**前置功法**：需掌握"灵气凝聚"基础，对灵气的操控达到一定精细度

**灵根要求**：木灵根和水灵根最佳，这两种属性的灵气最擅长模仿形态。火灵根修士化形难度最大

**修炼地点**：最好在动物种类繁多之处修炼，方便观察和模仿

**所需资源**：需要一些妖兽的精血或羽毛鳞甲作为"化形样本"，以及少量灵石维持修炼消耗

## 使用限制/副作用

- 长时间维持化形会产生"形态错乱"的后遗症，解除化形后可能暂时无法恢复人形
- 若化形过程中受到强力攻击，灵气形态会被打散，修炼者会感到如同肢体被撕裂般的剧痛
- 不可化形为比自己修为高出两个大境界以上的生物，强行模仿会被对方的气息反噬

## 相关典故

相传白泽的后人将这门秘法代代相传。三千年前，白家一位名叫白素素的女子，用灵鱼潜渊之法潜入南海龙宫，盗走了龙王珍藏的"定水珠"。她将灵鱼留在龙宫作为替身，真身早已带着宝珠远遁千里。龙王发现后大怒，却怎么也找不到她的踪迹——因为她化作了一株路边的野草，在风中摇曳了整整三天三夜，等追兵全部撤走才恢复人形。

## 修炼进度

**初形期（1-6个月）**：从最简单的化形开始——一片树叶、一块石头、一朵花。这些静态物体最容易模仿，是新手练手的最佳选择。

**动形期（6个月-2年）**：开始化形动物，从青蛙、麻雀等小型动物开始，逐步过渡到虎狼鹰等大型猛兽。

**离体期（2-5年）**：灵体脱离本体独立行动。此阶段需要极强的精神集中力，大部分修士需要数年才能熟练掌握。

**化境期（5-10年）**：万物化生，随心所欲。此时的化形已臻化境，化形出的灵体甚至可以施展简单的法术——虽然威力只有本体的百分之一，但已经足够以假乱真。
