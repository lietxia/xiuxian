# 灵气创世

## 基本信息
- **功法名称**：灵气创世
- **品级**：九阶（混沌级）（混沌级）
- **类型**：秘法功法
- **适用境界**：渡劫期
- **修习难度**：★★★★★

## 功法介绍

《灵气创世》并非由任何人类修士所创，它源自天地初开时，第一批先天神魔在混沌中留下的道痕。传说盘古开天后，其脊椎骨化为不周山，山壁上天然铭刻着三千道纹——其中最深的一道，便是《灵气创世》的原始版本。

此秘法的核心理念是"以灵气模拟混沌，以混沌再造世界"。修炼者需要将自身纯粹的灵气回溯至混沌状态（即五行不分、阴阳未判的先天一气），然后以此为根基，在自己的体内世界中重新演绎开天辟地的过程。古往今来，能够修成此秘法的修士不超过五指之数，每一位后来都成为了主宰一方的天帝级存在。

## 功法特点

**优点：**
- 修炼成功后可在体内开辟出一个完整的微型世界，拥有独立的天地法则
- 此世界中的灵气可自行循环生生不息，修炼者等于拥有了一个永不枯竭的灵气源泉
- 微型世界中的天道法则可由修炼者自行定义，在己方世界中战力近乎无敌
- 即便肉身被毁，只要微型世界尚存，便可借世界之力重塑肉身，几乎不死不灭

**缺点：**
- 修炼过程极度危险，稍有差池便会被混沌反噬，神魂俱灭，连转世的机会都没有
- 开辟世界需要消耗海量灵气，一位渡劫期修士的全部修为可能只够完成最初的一步
- 微型世界成长所需的资源极其庞大，会不断吞噬修炼者的修为和寿元
- 若微型世界崩溃，修炼者的神魂将随世界一同湮灭，比自爆元婴还要彻底

## 功法等级

**混沌初开**：将体内全部灵气逆转为混沌状态，这一过程如同将自己打回胚胎，期间修炼者会失去所有修为，变成一个空有境界的"凡人"。

**鸿蒙分化**：在混沌中劈开阴阳，分清浊二气。此时体内会出现一个极小的空间泡，约莫拳头大小，内部混沌翻涌，极不稳定。

**三才定鼎**：在空间泡中固定天地人三才之位，使世界初步稳定。此时微型世界约方圆十里，可容纳生灵进入，但环境极其恶劣。

**万物滋生**：世界内部的法则稳定后，开始演化万物。木生火、火生土、土生金、金生水、水生木，五行循环始成，世界进入良性发展。

**世界之主**：微型世界大成，面积可扩至方圆千里。修炼者与世界彻底绑定，一念之间可调动整个世界的力量，在己方世界中战斗等同于天道本身。

## 功法招式

1. **归混沌**：将自身所有属性的灵气逆转融合，返归为无色无味的混沌之气。施展时周身会浮现一层灰色迷雾，触碰者灵力会被分解为原始粒子。

2. **辟天地**：以意念为斧，在混沌中劈开一线光明。此招一出，可在现实世界中撕开一道空间裂缝，裂缝中涌出的混沌之气具有极强的腐蚀性。

3. **定五行**：在混沌空间中依次点亮五行之光，确立世界的基本规则。此招可用于封印天地法则，在万米范围内暂时屏蔽敌人的属性攻击。

4. **言出法随**：在自己开辟的世界中，修炼者的话语即是法则。说"火"，虚空生火；说"雷"，天降雷霆。离开自己世界后此招失效，但在世界内几乎无敌。

5. **世界投影**：将体内世界的虚影投射到现实世界，形成一个临时领域。在投影范围内，修炼者可有限度地调用世界法则，是此秘法最强的战斗招式。

## 修炼条件

**前置功法**：必须修习至少一门九阶以上的空间或造化类功法，且对天地法则有深刻理解

**灵根要求**：混沌灵根或至少四种以上的天灵根方可修炼，单灵根或双灵根修士无法承受混沌之力的冲刷

**修炼地点**：需在空间壁垒最薄弱之处（如天裂之地、虚空裂缝附近）进行初次修炼，日常修炼则必须在灵气浓度极高的洞天福地

**所需资源**：需要至少十条上品灵脉作为能量储备，以及大量稳定空间的至宝（如虚空石、混沌玉、定界珠等）

## 使用限制/副作用

- 每使用一次"归混沌"，修炼者的修为会跌落一个小境界，需数月才能恢复
- 微型世界每成长一圈，修炼者的寿元便会减少百年——这是世界成长的代价
- 若在微型世界未大成时强行使用"世界投影"，可能造成世界崩塌，后果不堪设想
- 修炼此功法后不可再修习其他任何九阶功法，混沌之力对其他至高法则有排他性

## 相关典故

太古时期有一位名叫"苍"的修士，是唯一一个将此秘法修至"万物滋生"境界的凡人出身者。传说他的体内世界中有山川河流、飞禽走兽，甚至还诞生了第一批智慧生灵。那些生灵称苍为"造父"，将他奉为神明。后来苍渡劫飞升时遭遇九九八十一道灭世天雷，他的世界替他挡下了其中七十二道，最终苍成功飞升上界，但他的世界也因此四分五裂。据说那些世界碎片坠入凡间，化作了如今的三十六洞天、七十二福地。

## 修炼进度

**混沌逆转期（未知）**：每个修士的混沌逆转速度不同，快的需要百年，慢的可能耗尽一生也无法完成。这一阶段没有任何捷径可走，全凭悟性和机缘。

**世界萌芽期（约千年）**：空间泡成形后，需要千年时间的温养才能稳定。期间修炼者会进入一种"胎息"状态，每年清醒的时间不超过七天。

**法则确立期（三千年）**：五行法则的确立需要三千年左右，期间修炼者不得插手凡尘事务，必须全神贯注于体内世界的演化。

**世界大成期（万年）**：从开始修炼到世界大成，至少需要万年光阴。但一旦成功，修炼者便会拥有与天地同寿的资格。
