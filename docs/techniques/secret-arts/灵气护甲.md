# 灵气护甲

## 基本信息
- **功法名称**：灵气护甲
- **品级**：二阶（玄级）（玄级）
- **类型**：秘法功法
- **适用境界**：筑基期
- **修习难度**：★★☆☆☆

## 功法介绍

在远古战场遗址中，考古修士们发现了大量刻有防御符文的盔甲碎片。这些符文虽然已经残缺不全，但其中蕴含的"以气凝甲"的原理却引起了当时一位炼器大师——"甲魂"的兴趣。

甲魂花了三十年的时间研究这些符文碎片的排列规律，发现这些符文之所以能产生防御效果，不是因为盔甲本身有多坚固，而是因为符文可以引导穿戴者体内的灵气在体表形成一层"灵气甲"。换句话说，盔甲只是符文的载体，真正起作用的是灵气。

于是甲魂将这些符文简化改良，创造出了一套可以直接在身体表面凝聚出灵气战甲的秘法。不需要穿戴任何实体盔甲，只需要意念运转，灵气就会按照符文的排列在体表凝结成一副完整的铠甲——从头盔到战靴，一应俱全。

## 功法特点

**优点：**
- 可以随时随地在体表凝聚出一套完整的灵气铠甲，不需要携带任何装备
- 灵气铠甲的形态和颜色可以由修炼者自行调整——既可以是威武的重甲，也可以是轻便的皮甲
- 被击碎后可以立即重新凝聚——只要灵气还没有耗尽
- 灵气铠甲的重量几乎可以忽略不计，不影响行动的灵活性

**缺点：**
- 灵气铠甲的防御力不如同阶的实体防御法器——毕竟它是由灵气凝结而成的
- 凝聚灵气甲需要持续消耗灵气，被击碎后重新凝聚的消耗更大
- 灵气甲遇到专门"破气"的法术或法器时，防御力会大幅下降
- 对穿透性攻击（如箭矢、飞针）的防御效果不太好——灵气甲的表面张力容易被穿刺

## 功法等级

**气甲初凝**：能够在体表凝聚出简单的灵气铠甲——一对护腕和一个护心镜。这些部位的防御力约等于下品防御法器。

**半身甲**：灵气铠甲覆盖上半身（胸甲、肩甲、护腕、头盔）。防御力达到中品防御法器的水平。

**全身甲**：灵气铠甲覆盖全身，包括腿部、脚部和背部。此时防御力接近上品防御法器，并且关节处的灵气膜不会影响活动。

**魂甲合一**：灵气铠甲与修炼者的神魂绑定，可以在受到攻击的瞬间自动凝聚在被攻击的部位。此境界的灵气甲已经拥有了"灵性"——会根据敌人的攻击方式自动调整防御形态。

## 功法招式

1. **重甲形态**：将灵气集中凝聚为厚重的板甲形态，防御力最大化但灵活性降低。适合正面硬抗攻击。

2. **轻甲形态**：将灵气分散为轻薄的链甲形态，防御力降低但灵活性最大化。适合游击战和躲避攻击。

3. **反伤尖刺**：在灵气甲的肩部、肘部和膝部凝聚出灵气尖刺，近身肉搏时可以给敌人造成额外的穿刺伤害。

4. **铠甲爆破**：将全身灵气甲在一瞬间引爆，化作无数灵气碎片向四面八方激射。此招是同归于尽的用法——引爆铠甲后你将暂时失去防御，但周围的敌人也会被碎片击伤。

## 修炼条件

**前置功法**：需要掌握"灵气凝聚"和"灵气化形"的基础

**灵根要求**：金属性灵根最佳（金主坚毅，与铠甲特质相合），土灵根次之。木灵根最不适合

**修炼地点**：最好在炼器工坊或古战场遗址中修炼，方便感悟符文的构造

**所需资源**：需要一块刻有防御符文的盔甲碎片作为参考样本

## 使用限制/副作用

- 灵气甲覆盖全身时，头部的感知能力会略有下降（因为灵气会阻隔部分感官）
- 灵气甲被击碎时，修炼者会感到如同真的被击中一般的剧痛——这是灵气与神经的连接造成的
- 长时间穿着灵气甲会让修炼者的皮肤变得敏感，脱下后短暂时间内不能直接接触粗糙物品

## 相关典故

甲魂在创出此秘法后，将之传给了自己的弟子。其中最出色的一位弟子——"铁衣"，在正魔大战中凭借灵气护甲独守一座要塞。他在七天内被击碎了四十七次灵气甲，又重新凝聚了四十七次。最后一次被击碎时，他已经没有灵气再次凝聚了——但他用最后一丝灵气催动了"铠甲爆破"，与冲入要塞的魔将同归于尽。

铁衣死后，他的灵气甲在他身体表面残留了三天才消散——仿佛连灵气都不愿意离开这位勇敢的战士。

## 修炼进度

**初凝期（1-3个月）**：从最简单的护腕开始，每天练习凝聚和消散。此阶段最大的挑战是让灵气按照符文的排列方式精确凝结。

**半身期（3个月-1年）**：覆盖上半身。胸甲的凝聚是最难的——因为它面积最大、形状最复杂。

**全身期（1-3年）**：全身甲的完成。此阶段的难点在于关节处的处理——既要保证防御，又不能影响活动。

**魂甲期（3-10年）**：神魂绑定和自动反应。此阶段考验的是修炼者与灵气甲之间的"默契"——你需要把它当成身体的一部分，而不是一件穿在身上的装备。
