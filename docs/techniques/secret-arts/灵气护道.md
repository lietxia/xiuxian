# 灵气护道

## 基本信息
- **功法名称**：灵气护道
- **品级**：六阶（神级）
- **类型**：秘法功法
- **适用境界**：炼虚期
- **修习难度**：★★★★★

## 功法介绍

在修真界，有一句老话："宁发毒誓，不立道誓。"原因很简单——毒誓只是口头上的威胁，而道誓是与大道绑定、由天道监督和执行的契约。一旦违背道誓，天道就会降下"大道反噬"，轻则修为尽废，重则魂飞魄散。

《灵气护道》秘法的创造者——"守道真人"，曾经是一个违背了道誓的修士。他在年轻时为求一门功法立下道誓，后来因为种种原因未能履行。天道反噬降临，他的修为在七天内从炼虚跌落到筑基。在绝望中，他尝试用灵气包裹住自己的道心，试图隔绝天道反噬的影响。

没想到，这个方法居然有效——虽然不能完全消除反噬，但至少延缓了修为跌落的速度。守道真人用了三百年时间研究"以气护道"的方法，最终创出了一套完整的秘法：用灵气在道心周围构筑一道"护道结界"，抵御一切对道心的攻击和侵蚀。

后来，这套秘法被广泛应用于对抗心魔劫、抵御搜魂术、保护道心不受外界污染等方面。

## 功法特点

**优点：**
- 可以保护道心不受外邪侵扰——对于容易走火入魔的修士来说，这是救命的神技
- 可以抵御心魔劫——在渡劫时，护道结界能为你争取到宝贵的应对时间
- 可以防止被搜魂术读取记忆——护道结界会主动屏蔽对识海的入侵
- 可以让修炼者更加坚定自己的道心——不容易被外界的干扰所动摇

**缺点：**
- 护道结界会消耗大量的精神力——长时间维持会导致精神疲劳
- 护道结界保护下的道心会变得"固执"——难以接受新的道法和感悟
- 过度依赖护道结界会让修士对心魔的抵抗力下降——因为道心没有得到真正的磨练
- 护道结界在面对天道直接降下的惩罚时效果有限——毕竟天道是至高的

## 功法等级

**道心微光**：感知到道心的存在——道心不是一个实物，而是一种"意志核心"的存在。修士需要在内视中找到自己的道心，然后用一缕灵气将其包裹。

**结界初成**：在道心周围形成一层灵气结界。这层结界很薄，但足以抵御普通的心魔侵扰。此阶段的修炼者可以在心魔劫中保持半个时辰的清醒。

**壁垒森严**：结界加厚到三层。第一层抵御外邪入侵，第二层过滤有害信息，第三层稳固道心根基。此时即便是搜魂术也难以突破。

**道心如铁**：结界与道心融为一体，变成道心自身的"免疫力"。到这一境界，道心已经强大到不需要刻意保护——任何外邪都无法动摇它分毫。

## 功法招式

1. **心壁**：在识海中构筑一道灵气墙，阻止外来的精神攻击直接冲击道心。此招对搜魂术、蛊惑术、迷魂术等精神类攻击有奇效。

2. **道韵过滤**：在护道结界上设置"过滤器"——只让有益的感悟通过，阻挡有害的信息。修炼者在参悟功法或聆听讲道时开启此招，可以过滤掉不适合自己的部分。

3. **心魔感应**：将护道结界的一部分延伸到体外，用来感应周围的心魔气息。在秘境或古战场中，此招可以用来预警潜藏的心魔。

4. **道心共鸣**：将自己的护道结界与他人连接，让多个人的道心相互共鸣。共鸣状态下，所有人的道心强度会叠加，一人受到攻击时其他人可以帮忙分担。

## 修炼条件

**前置功法**：需要将"灵气化神"修至小成——只有神魂强大到一定程度，才能感知到道心的存在

**灵根要求**：水灵根最佳（水性柔韧，适合构筑保护性结界），木灵根次之

**修炼地点**：最好在心魔较多的地方修炼——如古战场、极阴之地、魔域边缘等，这样才能在实战中检验护道效果

**所需资源**：需要"护心莲"或"定神香"等护持心神的宝物辅助修炼

## 使用限制/副作用

- 护道结界虽然能保护道心，但也会延迟天劫的感知——让天道觉得你的修为还在增长，导致天劫来得更晚但更猛
- 长期保护下的道心会变得"脆弱"——一旦结界被打破，道心崩溃的速度比普通人更快
- 此秘法无法阻止"自己对自己的欺骗"——如果你自己都不确定自己的道心是什么，护道结界也无法帮你决定

## 相关典故

守道真人在完善了灵气护道秘法后，用三百年的时间慢慢恢复了修为。但他发现了一个问题——虽然他靠着护道结界保住了修为，但他违背道誓的事实并没有改变。他的道心虽然还在，但已经不再"纯粹"了。

他最终做出了一个惊人的决定——主动散去修为，重新履行当年的道誓。他花了五百年时间完成了那个已经几乎不可能完成的任务，然后在天道的见证下重新立誓。这一次，他没有用护道结界保护自己——因为他已经不需要了，他的心已经足够坚定。

守道真人后来寿终正寝，享年两千八百岁。临终前他说："护道者，护的不是道心，而是对道的信念。信念不灭，何须护之？"

## 修炼进度

**感知期（1-3年）**：在无数次的打坐内视中找到自己的道心。很多人终其一生都找不到——不是道心不存在，而是他们不够"真诚"。

**初成期（3-10年）**：结界构筑和基本防护。此阶段最大的考验是"心魔"——在你最脆弱的时候，心魔会来试探你的道心。

**强化期（10-30年）**：三层壁垒的建设和完善。每一层都需要对道心有不同的理解，才能构建出相应的防护。

**化境期（30-100年）**：结界与道心的融合。到了这一阶段，护道已经变成了一种本能——你不再需要刻意去保护道心，因为道心已经足够强大，不需要保护了。
