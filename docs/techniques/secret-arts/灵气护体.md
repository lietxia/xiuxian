# 灵气护体

## 基本信息
- **功法名称**：灵气护体
- **品级**：三阶（地级）
- **类型**：秘法功法
- **适用境界**：金丹期
- **修习难度**：★★★☆☆

## 功法介绍

在上古时期，有一位名叫"金刚"的体修大能，他一生追求肉身的极致——认为肉身才是修士最强大的法宝。然而在他渡金丹劫时，天雷劈碎了他引以为傲的肉身，让他意识到了纯粹的肉身修炼的局限性。

在肉身重塑的过程中，金刚突发奇想：既然灵气可以作为攻击手段，为什么不能作为防御手段呢？于是他尝试将灵气均匀地分布在全身皮肤之下，形成一层"灵气膜"。这层灵气膜不仅可以化解外来的攻击力道，还可以在受伤时自动修复伤口。

经过数百年的完善，金刚创出了《灵气护体》秘法。这套秘法不需要结印、不需要念咒、不需要法宝——只需要一个念头，灵气就会自动形成防护。金刚后来凭借此秘法，硬扛了九九八十一道天劫而毫发无损，最终肉身成圣。

## 功法特点

**优点：**
- 被动防御，不需要主动激活——只要体内还有灵气，护体效果就始终存在
- 全方位无死角防御，不像护盾只能防御一个方向
- 可以自动调节防御强度——遇到强攻击时自动增强，遇到弱攻击时自动减少消耗
- 与体修功法配合极佳——肉身越强，护体效果越好

**缺点：**
- 防御力有限，无法抵挡超过自身境界两个等级以上的攻击
- 持续消耗灵气——虽然消耗不大，但在长时间战斗中会影响续航
- 对灵魂攻击和精神攻击的防御效果极差
- 遇到专门破罡的法器或法术时，护体效果会大打折扣

## 功法等级

**气溢体表**：灵气开始从毛孔中自然溢出，在体表形成一层薄薄的灵气层。这层灵气层只有纸一样薄，但也足以接下普通的物理攻击。

**气膜成形**：灵气层加厚到约一指厚，形成一个贴身的"灵气膜"。此时可以抵挡下品法器的劈砍，以及金丹期以下修士的法术攻击。

**气甲初现**：灵气膜在受到攻击时可以在局部瞬间加厚，形成类似"灵气铠"的效果。被攻击的部位会自动浮现出半透明的灵气护甲。

**金刚不坏**：灵气护体修炼到极致，体表的灵气膜已经固化到近乎实质。此时修炼者的防御力堪比中品防御法器，同阶修士的攻击几乎可以无视。

## 功法招式

1. **灵气反弹**：在灵气膜上附加反震之力，当敌人攻击你时，部分攻击力道会被反弹回去。反弹的比例取决于修炼者的修为和对手的攻击强度。

2. **局部强化**：在预判到攻击到来时，主动将灵气集中在被攻击的部位，使该部位的防御力瞬间提升数倍。此招需要极快的反应速度。

3. **卸力流转**：将受到的攻击力道通过灵气膜的流转分散到全身，从而将"点攻击"转化为"面承受"，大幅降低局部伤害。

4. **灵气愈合**：在受伤后，将灵气集中在伤口处加速愈合。此招无法断肢重生，但对于普通的刀剑伤和法术灼伤有极好的效果。

## 修炼条件

**前置功法**：需要将"灵气凝聚"修至小成以上，且肉身强度达到一定标准

**灵根要求**：土灵根最佳（土主防御），水灵根和木灵根次之。火灵根修士修习此秘法效果最差

**修炼地点**：最好在重力异常之地或肉身修炼场所，如重力洞天、淬体秘境等

**所需资源**：需要一些淬体的天材地宝配合修炼，如金刚果、铁骨草等

## 使用限制/副作用

- 此秘法对灵气的消耗会随着战斗强度的增加而增加，高强度战斗中消耗极快
- 灵气膜被击穿后，修炼者会进入"灵气真空"状态——短时间内无法再次凝聚护体灵气
- 长期使用此秘法会导致皮肤对外界灵气的敏感度下降，影响灵气感知能力
- 修炼此秘法的修士在洗澡时会感到不适——灵气膜会让水珠无法接触皮肤

## 相关典故

金刚在创出此秘法后，曾去拜访当时的第一剑修——"剑无名"。剑无名一剑刺向金刚，金刚不闪不避，用灵气护体硬接。那一剑刺穿了金刚的灵气膜，但刺入肉中一寸后就再也前进不了了。剑无名收剑后说了一句话："你的龟壳真硬。"金刚笑了笑回答："你的剑真快。"两人就此成为知己。

后来金刚飞升时，剑无名前来送行。金刚在飞升通道关闭前的一瞬间，将《灵气护体》的秘籍扔给了剑无名。剑无名后来将这套秘法发扬光大，开创了"以剑为盾、以气护体"的新流派。

## 修炼进度

**溢出期（3-6个月）**：学会让灵气自然溢出体表。此阶段的难点在于"放松"——你不能刻意去做，而是要像呼吸一样自然地让灵气流出。

**成膜期（6个月-2年）**：灵气膜的稳定和加厚。此阶段需要大量的实战练习，在挨打中找到灵气膜的平衡点。

**化甲期（2-5年）**：局部强化和自动反应。此阶段考验的是反应速度和灵气调配能力。

**圆满期（5-10年）**：金刚不坏。到了这一阶段，修炼者已经可以无视同阶修士的大部分攻击——但记住，防御终究是有限的，真正的强者懂得什么时候该防御，什么时候该躲开。
