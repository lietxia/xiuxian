# 灵气凝聚

## 基本信息
- **功法名称**：灵气凝聚
- **品级**：一阶（黄级）
- **类型**：秘法功法
- **适用境界**：聚气期
- **修习难度**：★☆☆☆☆

## 功法介绍

三万年前，星辰宗第三代弟子沈夜于天枢峰顶夜观星象，见北斗七星光芒汇聚于一星的奇景，心有所感，由此创下《灵气凝聚》这一基础秘法。沈夜本人资质平平，但在观星中悟出了"以念聚灵，以神束气"的法门，将原本散逸在空气中的灵气强行压缩为液态灵液，大幅提升了修炼效率。

此秘法看似简单，实则暗合天道"聚散无常"之理。通过意念引导，将周身的灵气如同旋涡般向内收缩，最终在丹田处形成高密度的灵气核心，为后续修炼打下坚实基础。星辰宗曾将此功法列为入门必修，后因宗门覆灭流落坊间，成为散修们最推崇的基础秘法之一。

## 功法特点

**优点：**
- 入门门槛极低，有灵根者皆可修习，不挑资质
- 灵气提纯效果显著，凝聚后的灵气精纯度提升三倍
- 修炼速度远超普通吐纳法，一日之功抵得上寻常七日
- 与其他功法兼容性极佳，可作为所有高阶秘法的基础

**缺点：**
- 凝聚过程中灵气损耗较大，约有三成灵气散逸浪费
- 长时间修炼会造成经脉轻微胀痛，需配合药浴缓解
- 过度凝聚会导致丹田产生"灵气惯性"，更换功法时阻碍明显
- 修炼至后期效果逐渐递减，无法替代更高深的修炼法门

## 功法等级

**初窥门径**：能够在感应到周身灵气流动，勉强将一缕灵气引入丹田旋转，耗时约一炷香可凝聚芝麻大小的灵液一滴。

**凝气成旋**：丹田灵气形成稳定的旋涡状结构，每分钟可自动旋转三十六圈，凝聚灵液的速度提升五倍。

**液满自溢**：丹田灵液蓄满后自动流向经脉，初步打通小周天循环，此时修炼者举手投足间已有灵气外溢。

**气液转化**：掌握了气态与液态灵气之间的自由转换，战斗中可将灵液瞬间气化爆发，威力倍增。到此境界，才算真正掌握了灵气凝聚的精髓。

## 功法招式

1. **北斗吸星**：以意念模仿北斗七星阵势，在周身形成七处灵气旋涡入口，同时从七个方向吸纳灵气，效率远超单一入口。

2. **天枢镇元**：将凝聚的灵液在天枢穴位置凝成一颗固态"灵珠"，作为全身灵气的镇守核心，大幅提升灵气稳定性。

3. **摇光合光**：双手结摇光印，将体内灵液均匀散布至四肢百骸，使全身细胞都与灵气共振，达到短暂的"灵气充盈"状态。

4. **七星连珠**：接连在七处主穴各凝聚一颗灵珠，以灵力丝线串联成环，形成体内小周天的永动循环，修炼至大成时可持续自行运转。

## 修炼条件

**前置功法**：无，凡有灵根者皆可修习

**灵根要求**：无特定要求，五行灵根均可。变异灵根（雷、风、冰）效率略低，但无碍修习

**修炼地点**：灵气浓度中等以上的环境即可，初学阶段最好在灵脉附近或有聚灵阵辅助

**所需资源**：初期需准备温养经脉的灵药浴汤（最常见的"温脉散"即可），每月消耗约十块下品灵石

## 使用限制/副作用

- 每次修炼不可超过两个时辰，否则经脉可能因灵液冲刷过度而受损
- 凝出的灵珠若被打碎，修炼者将遭受反噬，轻则经脉逆乱，重则丹田受损
- 长期使用此功法会导致体内灵气浓度过高，若不及时疏导，有"灵气化毒"的风险
- 月经期间的女性修士不建议修习，此时经脉脆弱，容易造成灵气失控

## 相关典故

据说星辰宗覆灭当晚，沈夜的七世徒孙用七星连珠之法，将一身灵气凝聚成一颗拳头大小的"星核"，硬生生接下魔道三位元婴期长老的联手一击，为宗门弟子争取了逃生的时间。那颗星核后来不知所终，有人说它坠入了凡间，化为了一座灵石矿脉。

## 修炼进度

**初窥期（1-3个月）**：学习北斗吸星的基础手法，每日苦练两个时辰，三个月内必能凝聚出第一滴灵液。

**成旋期（3-6个月）**：丹田旋涡初步成形，修炼效率大幅提升。此阶段最容易出现"旋涡失控"，需有师者从旁指导。

**盈满期（6个月-1年）**：灵液蓄满丹田，开始冲击经脉。此阶段为瓶颈期，约有三成修士在此停滞不前。

**圆满期（1-3年）**：七星连珠大成，体内永动循环成形。至此该功法已无可精进之处，可转而修习更高阶的秘法。
