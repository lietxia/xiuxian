# 灵气化神

## 基本信息
- **功法名称**：灵气化神
- **品级**：六阶（神级）
- **类型**：秘法功法
- **适用境界**：炼虚期
- **修习难度**：★★★★★

## 功法介绍

《灵气化神》源自上古时期一个神秘的魂修宗门——"魂兮宗"。此宗门修士专修神魂之力，认为肉身不过是灵魂的牢笼，终有一日要舍弃。魂兮宗第七代宗主魂无极，在一次深入冥界的神游中，偶然发现了灵气与神魂之间的隐秘联系：灵气并非只能滋养肉身，它同样可以被神魂直接吸收和转化。

经过四百年的钻研，魂无极创出了这套将灵气直接转化为神魂之力的秘法。普通的修士修炼神魂，靠的是日积月累的感悟和境界突破的洗礼；而灵气化神的修炼者，却可以像吃饭喝水一样，用灵气来"喂养"神魂，使其以远超常人的速度成长。

魂兮宗覆灭后，此秘法辗转流落到一位散修手中，他凭此在短短百年内从炼虚修至大乘，震惊了整个修真界。可惜他晚年神魂膨胀过快，肉身承载不住，最终魂飞魄散。

## 功法特点

**优点：**
- 神魂修炼速度是普通修士的数十倍，神识覆盖范围可在短时间内扩展百倍
- 神魂强大后，可施展高阶魂术（搜魂、夺舍、神魂攻击等），在同阶战斗中占据绝对优势
- 对天地法则的感悟速度大幅提升，突破境界的瓶颈比常人容易得多
- 即便肉身被毁，强大的神魂也能长时间独立存在，寻找夺舍或重塑肉身的机会

**缺点：**
- 神魂增长过快会导致"魂盛身虚"，肉身跟不上神魂的成长速度，容易出现肉身崩解
- 强大的神魂会吸引虚空中的"噬魂者"——一种以神魂为食的异界生物
- 过度依赖神魂之力会导致对肉身的掌控力下降，战斗时反应速度反而变慢
- 神魂越强，在渡天劫时遭遇的心魔劫就越恐怖——心魔会直接攻击你的神魂本源

## 功法等级

**魂引气归**：开辟识海中的一条通道，使灵气可以直接流入神魂之中。此过程极其痛苦，如同在脑海中凿开一条河渠。

**神魂初凝**：神魂从虚幻的意识形态凝结为一个半实体的"神魂核"，位于识海中央。自此以后，神魂可以离体出游，但最远不可超过十里。

**魂力外放**：神魂之力可以穿透肉身直接作用于外界，形成"神魂力场"。在力场范围内，一切风吹草动都逃不过修炼者的感应。

**神游太虚**：神魂可以脱离肉身远游，最远可达千里之外。此时肉身如同空壳，需要有可靠的人守护。神魂出游期间可穿越阵法禁制，无视物理障碍。

**神魂不灭**：神魂已经强大到可以在肉身毁灭后独立存在至少百年。到这一境界，修炼者已经触及了"以灵化神"的终极奥义——灵即是神，神即是灵。

## 功法招式

1. **神念搜魂**：释放神魂之力扫描大范围内的一切生灵，可以直接读取修为低于自己的修士的思维波动。用于审讯和情报收集无往不利。

2. **魂刺**：将神魂之力凝聚成一根无形的尖刺，直接攻击敌人的识海。中招者会感到头痛欲裂，严重者可能直接变成白痴。

3. **神游万里**：神魂离体出游，一日之内可游历万里山河。此招用于探索秘境、寻找天材地宝最为实用——神魂无视地形障碍，可穿透岩层和水域。

4. **魂影分身**：分出部分神魂之力凝聚成一个"魂影分身"，具有本体的部分意识和战斗力。魂影被打散后不会伤及本体，只需休养数日便可恢复。

5. **夺舍造化**：在肉身濒临崩溃时，神魂直接离体入侵他人的识海，摧毁对方的灵魂后占据其肉身。此招极其邪恶且风险极高，一旦失败自身神魂也会遭受重创。

## 修炼条件

**前置功法**：需要将"灵气感知"修至圆满，另需掌握至少一门灵魂类基础功法

**灵根要求**：水灵根或变异冰灵根最佳（水性柔和，适合神魂温养）。火灵根修士修习此秘法风险最高，容易被神魂之火反噬

**修炼地点**：阴气较重的场所（如极阴之地、古战场、乱葬岗等）反而比灵气充沛之地更适合，因为阴气可以中和神魂的躁动

**所需资源**：需要大量养护灵魂的天材地宝，如养魂木、凝魂草、魂晶石等，这些资源极其稀缺，每一样都价值连城

## 使用限制/副作用

- 每施展一次"神游万里"，神魂都会受到空间罡风的磨损，需要至少三日静养恢复
- 若在神魂出游期间肉身被毁，神魂将变成"孤魂野鬼"，必须在七七四十九天内找到新的肉身，否则将魂飞魄散
- 此秘法修至深处会逐渐磨灭修炼者的情感，使其变得冷漠无情，如同天道一般冷酷
- 神魂过度强大可能引来天道注意，被判定为"不容于世"的异数，降下专门针对神魂的"诛魂天劫"

## 相关典故

三千年前有一个名叫"夕颜"的女修，将此秘法修至"神游太虚"境界。她为了寻找死去道侣的转世之身，神魂出窍游历六界，跨越了凡、修、冥三界。最终她在冥界的奈何桥边找到了道侣尚未投胎的魂魄，以自身一半的神魂为代价，从生死簿上抹去了道侣的名字，带他重返人间。但她付出的代价是永远失去了三成的记忆和情感——她记得她爱过一个人，但再也想不起那种爱的感觉了。

## 修炼进度

**开窍期（1-3年）**：打通识海与丹田之间的灵气通道，让灵气能够流入神魂。此阶段需要极其小心，稍有不慎就会损伤识海，造成不可逆的伤害。

**凝核期（3-10年）**：神魂核的凝结需要三到十年，具体时间取决于闭关环境和资源充足程度。魂晶石可以大幅缩短此阶段的时间。

**外放期（10-30年）**：神魂力场的形成和扩张，需要不断练习。此阶段最忌急躁，强行扩大力场可能导致神魂核出现裂痕。

**神游期（30-100年）**：神魂出游的练习从十里到百里再到千里，每一步都需要稳固之后再前进。据统计，此阶段约有四成修士因为玩忽职守（肉身被毁）而陨落。

**不灭期（百年以上）**：臻至大成，但同时也意味着修炼者已经不再仅仅是纯粹的"人"了——他/她已经变成了一个介于神魂与灵气之间的存在。
