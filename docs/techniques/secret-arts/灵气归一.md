# 灵气归一

## 基本信息
- **功法名称**：灵气归一
- **品级**：五阶（仙级）
- **类型**：秘法功法
- **适用境界**：化神期
- **修习难度**：★★★★★

## 功法介绍

三千年前，西域佛宗出了一位异类——法号"归一"的僧人。他本是佛门弟子，却偏偏对道家法门情有独钟。别人修佛他修法，别人念佛他念经，被同门视为异端。归一也不争辩，只是一个人躲到深山老林中参悟。他在山中一待就是六十年，不吃不喝不睡，每天都在观察自然界的灵气流转。

六十年后，归一从山中走出，枯瘦如柴但双目炯炯有神。他悟出了一个道理：世间灵气虽有五行之分、属性之别，但追根溯源，所有的灵气都来源于同一个本源——"混沌灵气"。五行灵气不过是混沌灵气演化出的不同形态而已。

基于这一发现，归一创出了《灵气归一》秘法。此秘法的核心是"化繁为简，万法归宗"——将五行灵气全部还原为混沌本源状态，然后用本源灵气施展任何法术，效果都会得到数倍的提升。归一后来凭借此秘法，成为了佛道双修的一代宗师，被誉为"万法归一"。

## 功法特点

**优点：**
- 能够将任意属性的灵气转化为纯净的混沌灵气，无视灵根属性的限制
- 使用归一灵气施展任何法术，威力都会得到30%-100%的提升
- 归一灵气的兼容性极强，可以同时驱动任何属性的法器和符箓
- 修炼此秘法可以净化体内的杂质灵气，有效延缓"灵气污染"导致的修为倒退

**缺点：**
- 转化过程有灵气损耗，每将十份五行灵气转化为归一灵气，大约会损耗三分
- 归一灵气虽然万能，但缺乏特性——不如火灵气的灼烧效果、水灵气的治愈效果突出
- 长时间使用归一灵气会使修炼者的灵根属性"钝化"，再次使用单一属性灵气时会感到生疏
- 归一过程会产生大量的"灵气废热"，若不及时排出，会灼伤经脉

## 功法等级

**五行初归**：能够将一种五行属性（如火灵气）还原为混沌灵气。这个过程就像将染色的水重新过滤成透明的——看似简单，实则需要极高的操控力。

**阴阳并济**：能够同时处理两种相生或相克的属性灵气（如水和火），将其同时还原。这一阶段的修炼者已经能够在战斗中现场转化灵气，不再需要提前准备。

**三分归一**：能够处理三种及以上属性的灵气混合转化。此时归一灵气的纯度大幅提升，施展法术的威力加成可达50%以上。

**万法归宗**：天地间任何形式的能量——灵气、魔气、妖气、佛光甚至凡人的气血之力——都可以被转化为归一灵气。到这个境界，修炼者已经无敌于能量的运用。

## 功法招式

1. **归一气旋**：在头顶上方形成一个灵气旋涡，自动将周围的一切灵气吸入并转化为归一灵气。此招可用于快速补充灵气，也可用于驱散敌人的灵气供给。

2. **万法同源**：将归一灵气分别转化为不同属性的攻击同时释放。例如同时打出一记火球、一道冰锥、一根地刺，三种不同属性的攻击让敌人防不胜防。

3. **净世莲华**：以归一灵气凝结成一朵莲花，莲花绽放时释放出净化之光。所有被光芒照射到的修士的灵气都会被强行"归一化"——不分敌我，全变成归一灵气。

4. **本源汲取**：直接从大地、空气、甚至敌人的法术中抽取灵气，瞬间转化为归一灵气补充自身。在灵气充沛的环境中，修炼者几乎拥有无限的续航能力。

5. **归元一击**：将全身的归一灵气压缩到极限，然后一次性释放出去。此招的威力取决于灵气压缩的程度——归一灵气压缩得越狠，爆炸的威力就越大。

## 修炼条件

**前置功法**：需要至少掌握三种不同属性的四阶以上功法，对五行相生相克有深入理解

**灵根要求**：五行俱全的杂灵根反而比天灵根更适合此秘法（因为需要处理多种属性的灵气），变异灵根也可

**修炼地点**：五行灵气均衡之地最佳，如五行汇聚之地、太极秘境、阴阳泉眼等

**所需资源**：需要"五行灵石"各一块（用于辅助感知不同属性的灵气），以及"混沌石"碎片一枚（作为归一灵气的引子）

## 使用限制/副作用

- 每次使用"归元一击"后，修炼者会进入"灵气枯竭"状态，三天内无法使用任何法术
- 归一灵气虽然万能，但在对抗某种特定属性时威力不如纯属性灵气
- 长期使用归一灵气会让修炼者的经脉"中性化"，以后如果想转修单一属性的功法，效率会大打折扣

## 相关典故

归一僧人在创出此秘法后，曾与西域魔教教主在沙漠中大战七天七夜。魔教教主的魔气对佛门弟子有天然的克制作用，但归一用"万法同源"将魔气也转化为归一灵气，反过来用魔教教主的魔气攻击他自己。魔教教主到死都没想明白——为什么自己的魔气会打自己人。

归一后来回到佛宗，将《灵气归一》秘法刻在了寺中的石碑上。但佛宗弟子大多不屑一顾，认为这是"外道"之法。如今，归一僧人的石碑已经不知所踪，但《灵气归一》的抄本仍在修真界秘密流传。

## 修炼进度

**初归期（3-5年）**：熟练掌握一种属性灵气向归一灵气的转化。从最简单的火灵气开始，每天练习转化，直到形成肌肉记忆。

**双归期（5-10年）**：两种属性的转化和同时处理。此阶段的难点在于防止两种属性在体内冲突，需要极强的掌控力。

**多归期（10-20年）**：三种及以上属性的转化，归一灵气的纯度不断提升。此阶段需要大量练习。

**大成期（20-50年）**：万法归宗的掌握，可以处理任何形式的能量。能走到这一步的修士，已经站在了修真界的顶端。
