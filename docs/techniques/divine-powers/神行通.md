# 神行通

## 基本信息
- **功法名称**：神行通
- **品级**：四阶（天级）
- **类型**：神通功法
- **适用境界**：元婴期
- **修习难度**：★★★★☆

## 功法介绍

神行通的起源与上古巨人夸父有着直接的关系。传说夸父为了让族人摆脱黑夜的恐惧，发誓要追上太阳、将太阳固定在天空中。他跨过千山万水，日行万里，身上的每一块肌肉都在极限奔跑中被淬炼。虽然夸父最终未能追上太阳，含恨渴死，但他奔跑时与大地的摩擦、与风的对话、与光影的追逐——这些感悟被后来一位路过的修仙大能记录下来，从中提炼出了一套关于"速度"的功法。

这位大能发现，夸父的奔跑不仅仅是肉体的移动，更是一种"与天地竞速"的道——速度到了一定程度，时间和空间都会变得不同。他将这份感悟整理成《逐日步法》，经过历代改良，最终形成了今天的"神行通"。

神行通的核心在于"借力"——不是用自己的法力蛮横地推动身体前进，而是借助风的力量、大地的弹力、甚至空间本身的"弹性"来让自己移动。修炼到极致时，一步跨出可越百里，如同缩地成寸。

## 功法特点

**优点：**
- 移动速度极快——同阶修士中无人能及，天级遁速
- 身法灵活——可在高速移动中做出各种匪夷所思的变向
- 可以用于长途赶路——金丹期时一日可行三万里，元婴期可到十万里
- 对敌时身法飘忽不定，让对手难以锁定

**缺点：**
- 修炼过程极为考验体力——每天要跑数百里，对肉身消耗巨大
- 高速移动时视野受限——太快了看不清路
- 无法在密闭空间发挥——施展不开
- 遇到空间封锁类的法宝或禁制时完全失效

## 功法等级

**疾行如风**：奔跑时脚下生风，速度达到普通修士御气飞行的水平。一步可跨越十丈，日行千里不是梦。

**踏雪无痕**：身法变得轻盈无比——踩在雪上不留下脚印，踩在水面不沉下去。可在树梢、屋顶等轻脆表面自如奔跑。

**缩地成寸**：跨出一步的实际距离远超表面距离——明明只迈了一步，人却已在十里之外。空间在脚下被压缩了。

**身化流光**：整个人化作一道流光向前冲刺——速度之快如同瞬间移动。同阶修士的肉眼根本无法捕捉到移动轨迹。

**逐日之境**：一步可跨越百里——在极速奔跑中，你能感觉到时间在变慢，因为你的速度已经短暂超越了时间的感知界限。

## 功法招式

1. **乘风步**：借助风力推动自身前进——不需要消耗太多法力，顺风时速度加倍。在辽阔的平原地带最为实用。

2. **弹影闪**：以极短的距离做极快速的变向——如同一个弹球在墙壁之间弹射。近身战斗中让对手完全抓不到你的衣角。

3. **风神腿**：一腿踢出，伴随着强大的风压。这不仅是移动招式，也是攻击招式——在高速奔跑中顺势踢出的一脚威力堪比同阶的全力一击。

4. **流光遁**：化为一道流光远遁千里——是神行通中最强的逃命招式。施展后速度暴涨十倍，一息之间已在百里之外。但消耗极大，一次遁走就会耗空大半法力和体力。

5. **时间慢流**：在速度达到极致时，施术者眼中的世界会变慢——不是时间真的变慢了，而是你的反应速度太快了。在这个状态下，你可以从容地躲开箭矢、拦截飞剑甚至精准地抓住敌人打出的暗器。

## 修炼条件

**前置功法**：需将炼体功法修至一定的强度——没有足够强韧的肉身支撑，高速移动会让你的身体散架

**灵根要求**：以风灵根为最佳——天然对风之力有亲和力；其次为雷灵根

**修炼地点**：初期需要在开阔的平原或山谷中练习奔跑，进阶后可在瀑布、树林等复杂地形中训练身法

**所需资源**：疾风靴（加持速度的法器）、追风丹（服用后短时间内提升速度感）、风灵石（风属性灵石，辅助修炼风之力）

## 使用限制/副作用

- 在速度过快时，如果突然撞到障碍物——即使有护体灵气保护也会重伤
- 神行通使用后会有一段"法力真空期"——因为消耗太大了，需要恢复
- 过度使用可能损伤腿部的经脉——导致跑完后双腿剧痛
- 在空间不稳定区域使用神行通可能撕裂空间，被卷入空间裂缝

## 相关典故

夸父逐日失败后，他的桃木手杖化为了一片桃林——"邓林"。后世的修士发现，在邓林中修炼神行通会有额外的加成，因为这片桃林中残留着夸父不屈的意志——那种追赶太阳的决心。传说有一位体修在邓林中修炼神行通整整十年，最后悟出了"夸父逐日步"，一步迈出可跨越两界壁垒。这位体修后来跨入了仙界，被称为"追日神君"。

## 修炼进度

**疾步入门**：奔跑速度超过普通修士的御风飞行速度，达到日行千里

**踏水无痕**：身法轻盈到可以踏水而行、踏叶而飞，轻功大成

**缩地初成**：初步领悟缩地成寸——看似一步其实已跨越数里

**流光瞬息**：可化身为流光，在战场上穿梭自如，同阶难以锁定

**逐日追风**：一步百里，风在身后追不上你的脚步——至此，神行通大成
