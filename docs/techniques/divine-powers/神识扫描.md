# 神识扫描

## 基本信息
- **功法名称**：神识扫描
- **品级**：一阶（黄级）（黄级）
- **类型**：神通功法
- **适用境界**：聚气期
- **修习难度**：★☆☆☆☆

## 功法介绍

神识扫描的创制者是一个极具传奇色彩的人物——散修联盟的创始人"无门散人"。他出身低微，没有宗门背景，全靠自己摸索修炼。在聚气期时他最大的困扰就是：没有宗门提供的探查类法器，他根本无法感知周围的危险，每次外出历练都险象环生。

在经历了三次险些丧命的遭遇后，无门散人决定创造一门不需要任何法器、仅靠自身神识就能探查周围环境的功法。他通过反复试验，发现如果将神识从"被动感知"转为"主动释放"——不等待信息进入脑海，而是主动将神识发射出去再回收——就能大幅提升神识的感知范围和精度。经过五年的摸索，他整理出了一套完整的神识释放与回收的方法，这就是神识扫描的雏形。

如今神识扫描已经成为修仙界最基础、最普及的功法之一。几乎所有修士进入聚气期后学的第一门神通就是神识扫描——它没有任何门槛，也不需要额外的资源，只需要学会如何将自己的神识主动"发射"出去即可。

## 功法特点

**优点：**
- 学习门槛为零——聚气期第一天就能学会
- 不消耗法力——只消耗神识精力，而神识精力可通过休息快速恢复
- 可探索视线以外的区域——转弯、穿墙、入水皆可
- 是修士的"第三只眼"——在黑暗中、浓雾中、水下都能"看到"周围

**缺点：**
- 扫描范围极小——初期不过三五丈，最高也不过百丈
- 精度低——只能感知到"有东西"，无法精确分辨是什么
- 会被高阶修士的神识轻松察觉并被屏蔽
- 遇到神识类的禁制或法宝会被完全阻挡

## 功法等级

**神识初探**：能将神识主动释放到体外三丈的范围。在这个范围内，你能感知到物体的轮廓——如同一个模糊的雷达图。

**神识扩展**：扫描范围扩展到十丈，精度提升——能分辨出是人还是石头、是树还是建筑。

**神识精扫**：扫描范围扩展到三十丈，能做到"精细扫描"——比如隔着墙"看到"墙那边桌子上放了几本书、书页翻到了第几页。

**神识笼罩**：扫描范围扩展到百丈，能同时感知范围内的一切动静——如同一个人形的雷达塔。

## 功法招式

1. **脉冲扫描**：以自己为中心，向外发出一圈圈的神识波纹。波纹触碰到物体后反弹回来，在脑海中形成一幅周围环境的"回波图"。如同蝙蝠的回声定位。

2. **定向深探**：将所有的神识能量凝聚成一束，朝着一个指定的方向进行深度探测。穿透力极强，可以穿透岩石和薄弱的禁制，看到远处的景象。

3. **神识标记**：将一缕神识附在目标身上，之后无论目标移动到哪里，你都能感知到它的位置。标记效果可持续一个时辰。

4. **范围警戒**：将神识散布在周围一定范围内，形成一个"警戒圈"。一旦有东西进入这个圈子，你的神识就会被触发，立即提醒你——即使在睡觉时也能生效。

## 修炼条件

**前置功法**：无需任何前置——只要踏入聚气期、识海打开了就可以学习

**灵根要求**：任何灵根均可，无特殊要求

**修炼地点**：任何地方都可以，但初期最好在安静无干扰的地方练习

**所需资源**：无需任何资源——神识扫描只需消耗神识精力

## 使用限制/副作用

- 长时间大范围扫描会导致神识疲劳——头昏脑涨，需要休息才能恢复
- 如果在扫描中突然遭遇高阶修士的神识反击，可能会让识海受创
- 扫描到某些极其可怕的场景（如远古凶兽、天罚降临）时，神识会受到冲击
- 在某些禁地中扫描会触发禁制——人还没到，机关已经触发
