# 造化神通

## 基本信息
- **功法名称**：造化神通
- **品级**：九阶（混沌级）（混沌级）
- **类型**：神通功法
- **适用境界**：渡劫期
- **修习难度**：★★★★★

## 功法介绍

造化神通是天地间最为玄妙的几种神通之一——它关联的不是战斗或推演，而是"创造"。传说女娲大神在造人时，从自身本源中分出了一缕"造化之力"，用它揉捏泥土、赋予泥人以生命。造人结束后，剩余的一丝造化之力化为了九枚"造化之种"，散落人间。

其中一枚造化之种被一片荒芜的沙漠吸收，在那里沉睡了一亿年。直到一位名叫"青木道人"的修士路过这片沙漠时，他的神魂无意中触动了这枚造化之种。刹那间，方圆千里的沙漠中开满了鲜花——青木道人被这景象惊呆了。他发现自己竟然拥有了"让植物瞬间生长"的能力。他顺着这股力量的源头寻找，最终在沙漠深处找到了那枚造化之种。他用了五百年时间消化了这枚种子中的造化之力，创出了造化神通。

造化神通的力量不是破坏，而是"赋予"——赋予无生命的物质以生命，赋予枯萎的灵草以新芽，赋予残缺的法宝以完整。它是所有神通中最"温柔"的一种，但也是最接近造物主权柄的一种。

## 功法特点

**优点：**
- 可以催生灵植——让一株百年灵草瞬间长到千年药龄
- 可以修复破损的法宝——只要有部分碎片，就能用造化之力重塑完整
- 可以创造低等生命——用泥土造出灵蜂、灵蝶等低等灵兽
- 可以用造化之力为他人治疗——断肢重生、经脉修复、神魂修复，无所不能

**缺点：**
- 在战斗中几乎无用——造化之力创造需要时间，不可能临场创造
- 每次使用都消耗大量的造化本源——这种本源不可再生，用完就没
- 创造出的生命虽然是真的生命，但智力低下，无法升级
- 过度使用造化神通会加速自身的"本源枯竭"——寿命缩短

## 功法等级

**造化初悟**：感知到体内出现了一股"暖流"——那就是造化之力。此时可以让枯萎的花朵重新绽放，让受伤的灵草快速愈合。

**造物入门**：可以用造化之力改变物体的形态——比如将一块石头捏成石碗的形状。但创造出的物品没有内在的结构，容易破碎。

**生命创造**：可以用泥土调制出低等生命体——如人造灵蜂、人造灵蝶。它们能存活三年左右，有基础的采集能力。

**造化修复**：可以修复七阶以下的破损法宝——只要本源还在，碎成十块的法宝也能重塑。生灵的断肢也可以再生。

**万物造化**：理论上可以创造一切——包括高阶灵兽、有灵智的生命、甚至小型的生态系统。但每一次大型创造都会消耗不可估量的造化本源。

## 功法招式

1. **催生术**：将造化之力注入一株灵植中，使其加速生长。可以从种子直接催到开花结果。十年份的灵药可以催到百年份——但超过千年份需要多次施术。

2. **造化修复**：以造化之力包裹破损的物品，将其恢复到完好状态。不仅限于法宝——灵草折断的茎叶、炼丹炸开的丹炉、写错的符箓都可以修复。

3. **点石成灵**：用手指碰触一块石头（或其他无机物），注入一缕造化之力，石头就会活过来变成一只石灵。石灵有基础的生命特征——能移动、能听从简单的指令。

4. **生命之泉**：凝聚造化之力化为一口灵泉。泉水具有神奇的功效——喝一口可以加速伤势恢复，浇灌灵植可以让其品阶提升。但灵泉会随着使用逐渐干涸。

5. **造化领域**：展开一个"造化领域"。领域内的一切都会获得"加速生长"的增益——灵草疯长、伤势愈合、灵气快速恢复。但领域每展开一息都在消耗本源。

## 修炼条件

**前置功法**：需将木系功法和生命法则修至大成，且对"生命"有深刻的理解——不能只是杀伐，要有对生命的敬畏

**灵根要求**：木灵根为最佳——木主生发，与造化之力最为亲和；木系天灵根更佳

**修炼地点**：需在生命力最为旺盛的地方——如远古森林的树心、灵泉之眼、万物复苏的春天的大地之上

**所需资源**：生命之水（晨曦中叶片上的露珠采集万滴凝成一滴）、万年古木的树心（蕴含最纯粹的生命力）、造化玉碟碎片（女娲留下的至宝碎片，可遇不可求）

## 使用限制/副作用

- 造化本源是有限的——一旦耗尽，神通将永远消失，无法恢复
- 创造出的生命虽然是真的，但它们没有灵魂——只有本能没有灵智
- 用造化神通过度干预自然法则，会被天道记为"扰乱生态"——对天道而言这是重罪
- 造化神通的修习者通常都很短命——因为把本源都用在创造上了

## 相关典故

青木道人在创出造化神通后，没有用它来战斗或争夺资源，而是用它做了一件震惊天地的事——他将一片方圆万里的荒漠变成了绿色的森林。他用了整整一百年的时间，以一己之力将沙漠变成了绿洲。森林中所有的树都是他亲手催生的，所有的花都是他亲手创造的。他在这片森林中生活了三千年，最后在森林深处化作了一株参天大树——他用自己最后的造化之力，将自己的生命化作了这片森林的守护灵。后人将这片森林命名为"青木之森"，并称他为"造化神君"。

## 修炼进度

**生机初感**：体内出现了一缕温暖的生机——它能感知到周围植物的"情绪"，能帮助受伤的小草快速愈合

**催生入门**：能让种子在三日内发芽生长到开花——一株普通灵草的催生已经不成问题

**造物初试**：成功创造出了第一个生命——虽然只是一只笨拙的泥土蜜蜂，但它真的在振翅飞翔

**造化通达**：能在短时间内修复天级法宝的残片，能让断肢重生的速度加快十倍

**万物造化**：已领悟造化之真谛——创造不是"从无到有"，而是"让沉睡的生命苏醒"
