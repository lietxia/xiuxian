# 灵力感知

## 基本信息
- **功法名称**：灵力感知
- **品级**：一阶（黄级）（黄级）
- **类型**：神通功法
- **适用境界**：聚气期
- **修习难度**：★☆☆☆☆

## 功法介绍

灵力感知是所有神通功法中最基础、最原始的一门。它的起源可以追溯到上古灵族——一个天生对灵气有着极强感知力的种族。灵族的修士出生时，就能看到空气中飘浮的灵气光点，如同凡人看到空气中的尘埃一般自然。他们不需要任何功法，就能感知到灵气的浓度、流向和品质。

上古灵族灭亡后，人族继承了他们的修炼体系，却发现人族天生没有这种"灵觉"。于是人族大能根据灵族留下的记载，花了数百年时间研发出了一套专门用来"模拟"灵族灵觉的基础功法——这就是灵力感知。它通过将自身的神识与体表皮肤结合，让皮肤成为一张巨大的"灵气感应膜"，从而感知周围的灵气变化。

灵力感知是所有高阶神通的基础——天眼通、他心通、彻地神通等都需要以精确的灵力感知为前提。因此它也是修仙界的"必修课"，几乎所有宗门都会在入门第一年教授这门功法。

## 功法特点

**优点：**
- 修炼门槛为零——只要能感受到灵气就能修习
- 可以帮助修士快速判断灵石品质、灵药年份和丹药功效
- 可以感知到隐藏的灵脉和秘境入口的灵气波动
- 是后续所有高阶神通功法的前置基础

**缺点：**
- 感知范围有限——初期不过方圆十丈，最高不过三里
- 无法精确判断对手的修为——只能感知到灵气的大致强弱
- 对高阶修士刻意收敛的气息无效
- 在灵气稀薄或煞气弥漫之地效果大幅降低

## 功法等级

**灵气初感**：能模糊感知到周围是否有灵气存在，如同用手触摸微风的流动

**灵气可视**：闭上眼睛后在识海中"看到"灵气的颜色——普通灵气为白色，高品质为金色，煞气为黑色

**灵气追踪**：能追踪灵气移动的轨迹——无论目标如何隐藏，只要它调动过灵气，就会留下痕迹

**灵气精辨**：能精确分辨出不同灵气的细微差异——如分辨出某个修士独有的灵气气息、某株丹药的药气成分

## 功法招式

1. **灵气触须**：从体表延伸出无数无形的灵气触须，如同蜘蛛网的丝线般向四面八方扩散。触须触碰到其他灵气时会产生反馈，告诉你那个方向有灵气的存在。

2. **灵气嗅探**：深吸一口气，将周围的灵气吸入鼻腔（不是肺部），通过灵气的"气味"来判断灵气的来源——灵脉的气息是清冽的，丹药的气息是馥郁的，妖兽的气息是腥臊的。

3. **灵压感应**：感知周围灵气的压力变化。灵气的流动方向是由高浓度向低浓度扩散的，通过感知灵压的变化可以判断哪里有高浓度的灵气源——可能是灵脉，可能是天材地宝，也可能是高阶修士。

4. **灵气共鸣**：调整自身灵气的频率，与周围的灵气产生共振。共振状态下，你对灵气的感知变得异常敏锐——可以感知到百丈外一枚灵石内部的灵气纯度。

## 修炼条件

**前置功法**：无需任何前置——只要踏入聚气期就可以开始修习

**灵根要求**：任何灵根均可修习，天生对灵气敏感者更佳

**修炼地点**：在灵气充沛的山门中修炼效果最佳，灵气稀薄的地方会让修炼进度极为缓慢

**所需资源**：聚气丹（加快灵气感知的灵敏度训练）、灵泉水（洗练灵觉）

## 使用限制/副作用

- 灵力感知虽然消耗极低，但长时间开启会让神识疲劳，需要休息恢复
- 在灵气混乱的地方（如战场、突破现场），感知到的信息会非常嘈杂难以分辨
- 过度依赖灵力感知会让其他感官退化
- 若被高阶修士以"气机锁定"的方式反追踪，反而可能暴露自身位置

## 相关典故

传说有一位资质平庸的散修，因为灵根太差，在聚气期停留了整整三十年无法突破。他没有放弃，而是将这三十年全部用来修炼灵力感知——他把这门基础功法练到了前无古人的境界，能在千里之外感知到一枚灵石的灵气波动。后来一次偶然的机会，他感知到了万里之外一座上古秘境开启时泄露的一丝灵气，靠着这丝感知找到了秘境入口，在秘境中得到了逆天机缘，从此一飞冲天。他用亲身经历告诉所有资质差的人：没有废物的功法，只有不精的修士。

## 修炼进度

**灵气初触**：能感知到一丈内的灵气存在——闭眼能"看"到一团模糊的光雾

**灵觉扩展**：感知范围扩展到十丈，能分辨出灵气的大致浓度高低

**灵气可视**：睁开眼睛也能"看到"灵气——空气中飘浮的金色光点就是灵气颗粒

**灵觉如肤**：灵觉如同皮肤一样自然——不需要刻意运转就能时刻感知周围的灵气变化
