# 灵气外放

## 基本信息
- **功法名称**：灵气外放
- **品级**：一阶（黄级）
- **类型**：神通功法
- **适用境界**：聚气期
- **修习难度**：★☆☆☆☆

## 功法介绍

灵气外放的发现纯属偶然。上古时代有一位名叫"百草仙翁"的炼丹宗师，在一次炼制定颜丹时，因为火候过大，丹炉内的灵气膨胀到了极限。为了防止炸炉，他本能地将体内的灵气从掌心逼出，试图引导丹炉内的灵气外泄。没想到这一逼，掌心竟然射出了一道肉眼可见的白色气柱——这是修仙界历史上第一次有人有意识地"将灵气释放出体外"。

在此之前，修士们都认为灵气只能存在于体内经脉中，一旦离开身体就会消散。百草仙翁的这一发现打破了所有人的认知——原来灵气可以在体外短暂保持凝聚状态，甚至可以形成威力不俗的气劲。这个发现后来被整理成系统性的功法，命名为"灵气外放"，成为聚气期修士学习"御气术"之前的基础功。

如今，灵气外放是所有修士最早接触的攻击性法术修炼法门之一。它的原理简单——将丹田中的灵气通过经脉加速压缩，再从指尖或掌心释放出去，形成一道气劲。虽然威力远不如高阶法术，但它为修士打开了"让法力离体"的第一道门。

## 功法特点

**优点：**
- 修炼门槛极低——只要有灵气就能修炼，第一天就能见效
- 消耗极小——一次外放不过消耗一丝灵气，片刻即可恢复
- 是所有御气类法术（剑气、掌风、指劲）的基础
- 可用作开关机关、传递信号、吹灭烛火等日常用途

**缺点：**
- 威力极弱——甚至无法击穿一层兽皮，只能击碎普通的瓦片
- 有效距离极短——初期不过三尺，最高不超过十丈
- 无法穿过任何法力护盾或禁制
- 在风雨天气中威力大幅衰减

## 功法等级

**气感外放**：能将掌心的灵气推出体外，形成一阵微风。可以吹熄三丈外的蜡烛。

**气劲初成**：灵气外放时形成一道白色的气柱，可将三丈外的树叶击落。用来打开远处的机关开关非常方便。

**气形凝聚**：能将灵气凝聚成各种形态——气剑、气掌、气盾。虽然威力有限，但已经可以用于日常切磋和防身。

**气随意动**：灵气外放不再需要刻意运功——一个念头就能从全身任意穴位释放灵气，而且可以同时释放多道气劲。

## 功法招式

1. **灵气弹**：从指尖弹出一粒黄豆大小的灵气弹。击中目标时会炸开，造成轻微震荡——用来驱赶低阶妖兽效果不错。

2. **气刃斩**：将灵气压缩成薄薄的刀刃形状向前挥出。可切断普通的藤蔓和绳索，对付炼气期的妖兽也能破皮见血。

3. **气墙术**：在身前释放出一道半透明的气墙。虽然挡不住真正的攻击，但可以阻挡灰尘、毒烟和昆虫。

4. **气劲传物**：用灵气包裹住一件轻小物品（如飞剑传书、丹药），隔空送到十丈内的指定位置。是修士日常生活的便利技能。

## 修炼条件

**前置功法**：无需前置功法——只要在聚气期、丹田中凝聚了灵气即可修炼

**灵根要求**：无任何要求——所有灵根均可修习

**修炼地点**：任何地方都可以练习——野外、洞府、屋顶，空旷处最好

**所需资源**：无特别需求——日常打坐恢复的灵气就足够练习

## 使用限制/副作用

- 灵气外放虽然消耗小，但在战斗中频繁使用也会快速耗空丹田中的灵气储备
- 灵气外放的气劲会被禁制反弹——小心自己的气劲打在自己脸上
- 在灵气稀薄的地方，灵气外放的威力会进一步减弱
- 过度练习可能导致经脉轻微劳损——需要适当休息

## 相关典故

传说百草仙翁在发现灵气外放后，兴奋地在他的小药童身上做实验——他隔空用灵气弹打落了药童的帽子。药童吓了一跳，以为师尊在用妖法。百草仙翁笑着解释："这不是妖法，这是每个修士都能做到的事。" 后来药童长大了，也成为了一名修士，他始终记得师尊那个简单却伟大的发现——有时候最了不起的创造，就藏在最不经意的尝试之中。

## 修炼进度

**气出体外**：能将丹田中的灵气引导到掌心，并推出体外——虽然只是一团散乱的气流，但这已经是零到一的突破

**气劲成形**：灵气从掌心的孔窍中射出时形成一道收敛的气柱，能击倒三丈外的木桩

**气化万象**：可自由控制灵气外放的形态——细如发丝的气针、宽如蒲扇的气掌、薄如蝉翼的气刃

**气随心动**：灵气外放如同呼吸一般自然——心念起时气已至，不需要任何运功前摇
