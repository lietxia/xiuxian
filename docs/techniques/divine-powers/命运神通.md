# 命运神通

## 基本信息
- **功法名称**：命运神通
- **品级**：七阶（圣级）
- **类型**：神通功法
- **适用境界**：合体期
- **修习难度**：★★★★★

## 功法介绍

命运神通由上古隐世大能"天命老人"所创。天命老人在凡俗之时本是一名观星师，因缘际会踏入修仙之路后，他将凡人观星术与修仙推演法相结合，在万丈高峰之巅连续观测星辰轨迹千年之久。一日夜中，他观测到紫微星移位、北斗七星逆旋，天象出现前所未有的异变。就在这一刻，天道降下一缕玄妙道蕴，将命运的奥秘展现在他眼前——天命老人看到了过去、现在与未来的无数条命运线，如蛛网般交织在一起。他豁然顿悟：命运并非一成不变，而是无数可能性汇聚成的洪流。他花了三千年将这一瞬间的领悟书写成《天命经》，命运神通由此诞生。

这门神通不修法力，不炼肉身，专修"命数感知"。修至大成者能窥见他人命运的轨迹，甚至能以自身意志干涉命运线的走向。但命运乃天道之核心，妄图操控命运者必遭天谴，因此历代修炼命运神通的人极少有好下场。

## 功法特点

**优点：**
- 可预见短时间内（三日至三月）的命运走向，趋吉避凶
- 能感知到他人身上缠绕的因果业力，分辨善缘与孽缘
- 可为自己和他人"改运"——调整命运线的走向
- 在关键时刻能窥见一丝"天道意志"，领悟天地大势

**缺点：**
- 每次窥探命运都会折损自身阳寿，逆天改命更是以命换命
- 看到越多的命运线，就越难走自己的路——可能陷入宿命论的迷茫
- 命运反噬极难化解，一旦出手干涉他人命运，自身就会被牵连
- 修炼到深处会被天道"标记"，天劫威力倍增

## 功法等级

**命运初窥**：能看到身边人三日内的小运——如会不会捡到灵石、会不会摔一跤，准确率约三成

**命线可见**：能感知到命运线的存在，可分辨一个人命格的大致走向——是富贵命还是早夭命

**命运推演**：可通过生辰八字、面相气运综合推演出一人百年内的大致命运走向

**命途改易**：能用自身气运为他人"续命"或"改运"，但每次改动都会消耗大量寿命

**天命在握**：能隐隐触摸到天道运转的规律，看到世界线的分叉与汇合——这是接近大道本源的状态

## 功法招式

1. **命眼**：在瞳孔中凝聚命运之力，看到他人头顶的"气运之色"——紫色为贵、金色为福、黑色为厄、红色为血光之灾。同阶仅能看到颜色，高阶可看到具体的命运画面。

2. **宿命推演盘**：以自身识海为盘、星辰之力为子，在脑海中构建一个巨大的命运推演阵列。可同时推演数千人的命运线交叉影响。

3. **命运截击**：当预见到未来某一刻会发生对自己不利的事件时，提前以命运之力"截断"那条命运线。这并非改变因果，而是在因果链条上制造一个中断点。

4. **因果转移**：将自身遭遇的厄运通过命运线的连接，转移给与自己有因果纠缠的目标。极为阴损的招数，为正道所不齿。

5. **天命共鸣**：以自身命格与天道产生共鸣，短暂获得"天道视角"——在这一瞬间，你能看到整个世界的大势走向。每次施展后都会陷入长达一月的虚弱期。

## 修炼条件

**前置功法**：需精通《易经》《推演术》《占星术》中至少一门推衍类法术，且将因果类神通修至小成

**灵根要求**：天灵根或变异灵根为佳，尤其是带有"命运""因果"属性的异灵根

**修炼地点**：需在天机汇聚之地修行——如古观星台、天外陨石坑、世界树的树冠之上

**所需资源**：星辰石（观星修炼的媒介，每月消耗一颗）、天命草（百年份以上，冲击瓶颈用）、九窍灵石（辅助命运推演）

## 使用限制/副作用

- 窥探命运一次折寿三年，出手改命一次折寿三十年到百年不等
- 过度使用会使自己的命运线变得混乱，最终沦为"无命之人"——天道不再庇护，任何意外都可能致命
- 命运反噬会以最残酷的方式应验——比如你救了某人一命，那人日后可能会害死你更重要的人
- 同修命运神通的人相遇会产生命运线干扰，双方推演的准确度都会大幅下降

## 相关典故

传说天命老人在创出命运神通后，曾为三位弟子推演命运。大弟子的命运线显示他将成为一代宗师，二弟子将成为魔道巨擘，三弟子将死于非命。天命老人心有不忍，强行将三弟子的死劫转移给了大弟子。结果三弟子果然平安无事，并成为了一代明君，造福苍生；而大弟子却在一次普通的历练中被一只低阶妖兽咬死，死状凄惨。天命老人痛哭道："这就是命运——你永远不知道改动一个结，整张网会变成什么样。" 此后他将《天命经》封印于天外虚空，自己坐化于封印之侧，以神魂永镇此经。

## 修炼进度

**命运初觉**：能偶尔在梦中预见未来片段，睡醒后模糊不清，如同记不清的梦境

**命眼初开**：能看到他人气运的模糊颜色，但无法精确解读，需要配合面相手相辅助判断

**命线可见**：能清晰看到方圆十丈内的命运线交织，可分辨出重大事件的走向

**命盘初成**：可独立推演一个宗门的百年气运走向，为宗门大计提供参考

**天命难违**：修至最高境界后反而更加敬畏命运——因为你知道得越多，就越明白命运之力不可轻用
