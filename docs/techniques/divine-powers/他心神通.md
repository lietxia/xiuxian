# 他心神通

## 基本信息
- **功法名称**：他心神通
- **品级**：五阶（仙级）
- **类型**：神通功法
- **适用境界**：化神期
- **修习难度**：★★★★★

## 功法介绍

他心神通源自西域佛宗上古尊者"天耳通尊者"。传说这位尊者曾在菩提树下入定三千载，日复一日聆听众生心声。起初他只能听到风吹落叶的低语，三百年后能听到百里外的鸟鸣，五百年后能听到凡人心中的悲喜，一千年后他听到了修士的思虑，两千年后连妖兽的意念都清晰可辨。待到第三千年，他忽然发现——他听到的不仅是声音，更是众生的念头本身。天耳通尊者由此创下他心神通，能直接读取他人内心所想，无所遁形。后经佛宗高僧改良，这门神通传入中土修仙界，成为化神期修士梦寐以求的精神秘术。

此神通不靠言语，不借法力波动，以纯粹的心灵之力渗透对方识海。修习者需有一颗澄澈无垢的禅心，否则极易被外界的杂念反噬。

## 功法特点

**优点：**
- 无需任何言语交流即可读取对方真实想法，博弈中对敌先机尽在掌握
- 可同时监听多个目标的表层念头，范围随修为增长
- 可用意念向他人传递信息，实现无声对话
- 对低阶修士有压倒性克制，对方连撒谎都做不到

**缺点：**
- 强行读取高境界修士的内心会遭识海反噬，轻则头痛欲裂，重则神魂受损
- 长期使用会模糊自我意识，容易混淆自己与他人的念头
- 被读心者若拥有护魂法宝或修炼过精神力防御秘术，读取难度剧增
- 每次施展对心力消耗极大，需休整数日才能恢复

## 功法等级

**初窥心门**：能感应到他人剧烈波动的情绪念头，如愤怒、恐惧、狂喜，需双方距离在十丈内

**心音入耳**：可清晰读取普通修士的表层思维，能分辨谎言与真话，范围扩展至百丈

**心海潜行**：不仅能读取表层念头，还能潜入对方记忆深处翻阅过往片段，且对方不易察觉

**万念归一**：能同时监听百人以上的思维流，并在瞬间筛选出对自己有用的情报

**他心即我心**：能达到短暂的"心念同步"，让对方以为你是他最信任的人——这是他心神通的至高境界

## 功法招式

1. **心弦探**：射出一道无形心念丝线，轻轻触碰对方思维表层，感知其当前最强烈的情绪。隐蔽性极高，几乎不会被发现。

2. **念镜术**：在识海中凝聚一面"心镜"，将被读取者的思维画面投影其上。可清晰看到对方脑海中浮现的场景，如同观看他人的记忆。

3. **心声窃语**：持续监听目标的心念，不打断对方思维，如同偷听内心的独白。适合在谈判、审讯时使用。

4. **念茧封**：将自己的心念化作茧丝，包裹住对方的某些记忆片段，将其暂时封印。这是攻防兼备的招式，可让对方遗忘关键信息。

5. **心念共振**：将自己的意志强行嵌入对方识海，制造短暂的精神共鸣。可让对方在短时间内接受你的建议，误以为是自己的想法。

6. **万念归墟**：他心神通的终极奥义——释放全部心力，在一瞬间读取方圆百里内所有生灵的念头。施展后施术者会陷入三日的识海沉寂，期间如同凡人，毫无抵抗之力。

## 修炼条件

**前置功法**：需将佛宗基础心法《净心咒》修至大成，能自如控制心念波动；或修炼过《凝神术》《心经》等精神类功法

**灵根要求**：对灵根无特定要求，但天生神魂强大者修炼效率高出一倍

**修炼地点**：初期需在绝对安静的环境修行——如深山古刹、地下密室，后期则需在闹市中磨砺抗干扰能力

**所需资源**：宁神香（每日一支）、养魂玉（佩戴修行可加速三成）、空灵果（冲击瓶颈时服用）

## 使用限制/副作用

- 每月施展次数有限，超越上限会引发"心焚"——自己的念头如烈火灼烧识海
- 读取凡人过多会沾染红尘浊念，需定期以佛法净化
- 若被读取者心有执念，执念会顺着心念丝线倒灌入施术者识海，造成人格污染
- 长期修习他心神通者，会渐渐失去"信任他人"的能力——因为你总是知道别人在想什么

## 相关典故

传说天音寺有一位高僧将他心神通修至"他心即我心"的境界。一次他路过一个村庄，感应到一个屠夫心中深藏的愧疚——三十年前他杀了一头怀崽的母牛。高僧便化身为那头母牛的灵魂，在屠夫梦中与他对谈。屠夫惊醒后痛哭流涕，放下屠刀，剃度出家，后来也成为了一代高僧。这个故事在佛门中广为流传，称为"一念度人"。

## 修炼进度

**初闻心音**：能在打坐入定时偶尔捕捉到身边人的强烈念头，如同听到远方的回音

**心门半开**：可主动探查他人的表层思维，但精度有限，常把杂念与真实意图混淆

**心念如丝**：能精准分辨数百种不同情绪与念头，读心准确率可达八成，范围扩至一里

**心如明镜**：读取记忆如同翻阅典籍，可在战斗中同步预判对手的下一步动作

**万念皆空**：已臻化境——既能读尽众生心，也能让自己的心归于空寂，不为外念所动
