# 天眼神通

## 基本信息
- **功法名称**：天眼神通
- **品级**：五阶（仙级）（仙级）
- **类型**：神通功法
- **适用境界**：化神期
- **修习难度**：★★★★★

## 功法介绍

天眼神通源于远古神兽烛龙的血脉传承。传说烛龙睁眼为昼、闭眼为夜，它的双眼能洞穿九幽、窥破虚妄。烛龙陨落之后，它的血脉散布于天地之间，其中一支传承演化成了"天眼族"。天眼族的修士在化神期时，额骨会裂开一道缝隙，从中长出一只竖立的"天眼"。这只天眼并非普通的肉眼，而是由纯粹的道蕴凝结而成的"法眼"，能看破世间一切幻象、禁制和隐身之术。

后来天眼族与人类通婚，这种血脉之力逐渐在人类修仙者中流传。但人族天生没有天眼的根基，只能通过修炼功法来"伪造"出一只天眼。天眼神通便是经过历代人族大能不断改良后形成的完整修炼体系。虽然人造的天眼终究比不上天眼族天生的神通，但也足以让修习者在同阶修士中占据绝对的信息优势。

## 功法特点

**优点：**
- 能看破一切五行遁术和隐身法诀，让刺客无所遁形
- 可透视禁制和阵法，找到阵眼和薄弱点
- 能直接看到灵气的流动方向，在战斗中预判对手的法力输出
- 可以观察他人的经脉状况，找出其功法的破绽和暗伤

**缺点：**
- 修炼过程极为痛苦——额骨开裂、眉心灼烧如同炼狱
- 使用过度会导致视力模糊、头晕目眩，严重时永久失明
- 天眼的光芒太过显眼，容易被对手提前防备
- 遇到专门的"闭目术"或"天机遮蔽"类法术无效

## 功法等级

**眉心灼热**：额骨眉心处开始发热，能隐隐感知到前方有障碍物或禁制，如同盲人的第六感

**天眼初开**：眉心裂开一条细缝，透出一道金光。能看穿土墙、普通禁制和金丹期以下的幻术

**天眼通明**：天眼完全睁开，瞳孔呈金色竖瞳。能看穿地级阵法的运转，分辨出真假灵脉

**天眼如炬**：天眼中射出两道实质性的金光，可以"灼烧"所见的禁制和诅咒。眼神所及之处，邪祟消退

**烛龙之眼**：天眼的瞳孔变为竖立的龙瞳。能看穿空间折叠、时间迷锁，甚至能看到一丝天道法则的流转

## 功法招式

1. **金光勘破**：天眼中射出一道金光，扫过之处所有禁制和幻阵都会显露出原本的符文结构。如同用光照亮黑暗，一切隐藏无所遁形。

2. **灵视追踪**：锁定目标身上的灵气波动，即使对方逃到千里之外，只要天眼一开就能看到那道灵气轨迹。追踪效果可持续七日。

3. **破妄金芒**：天眼凝聚一道金色光束射出，直接摧毁所见的幻象核心。对幻术类功法的克制效果极佳，甚至能将对手的反噬回去。

4. **洞虚凝视**：天眼凝视某一处空间，可看穿空间裂缝后的场景——秘境入口、储物法宝内部、甚至异度空间的景象都能尽收眼底。

5. **天眼审判**：将天眼的金光照射在目标身上，将其体内的灵气运行路线、功法性质、修为虚实全部看透。此招一出，对手的所有秘密都暴露无遗。

## 修炼条件

**前置功法**：需将炼体功法修至能承受骨骼重塑的程度，且修炼过《明目诀》《清心咒》等辅助功法

**灵根要求**：以金灵根为最佳——金光属性与天眼最为契合；雷灵根次之

**修炼地点**：需在光元素浓郁之地修炼——如极光笼罩之地、日光汇聚的峰顶、或者万丈高空之上

**所需资源**：千年灵芝（熬制成药汁洗眼）、金乌羽（炼制天眼开光符的核心材料）、天河星沙（淬炼天眼瞳力）

## 使用限制/副作用

- 天眼每使用一炷香的时间，就需要休养一个时辰。连续使用超过三次，天眼会流血甚至暂时失明
- 用天眼窥视比自己高两个大境界的修士，会被对方察觉并遭受气机反噬
- 天眼看到某些"不该看的东西"——如天机、死兆、大凶之兆——会遭受天道惩罚，折损寿元
- 天眼无法关闭的时候是最危险的——在极暗之地天眼会持续发光，暴露自身位置

## 相关典故

传说天眼族最后一位纯血族人在北冥极光之地留下了一座"天眼试炼塔"。塔有九层，每一层对应天眼的一个境界。无数人族修士前去挑战，想要获得天眼族的传承，但大多数人在前三层就失败了——不是因为修为不够，而是因为每一层的幻境会直接攻击试炼者的内心。只有心志最坚定的人才能走上塔顶。八百年来只有三人成功登顶，其中一位就是后来名震修仙界的"天眼神君"上官破。

## 修炼进度

**眉心发热**：感觉到眉心有异物感，如同有什么东西想要破骨而出，修炼时眉心会微微发光

**裂缝初现**：额头出现一道竖直的红线，如同闭着的第三只眼。修炼时可透过额头看到模糊的灵气光影

**天眼半开**：额头竖眼半睁半闭，能看穿百丈内的禁制和幻术，但每次使用不超过一盏茶的时间

**金瞳大成**：天眼完全睁开，瞳孔呈金色，可直视日光而不伤。能看破天级以下的所有阵法

**烛龙觉醒**：天眼瞳孔变成竖立的金色龙瞳，目光所及万物无所遁形——至此，天眼神通大圆满
