# 神念通

## 基本信息
- **功法名称**：神念通
- **品级**：四阶（天级）
- **类型**：神通功法
- **适用境界**：元婴期
- **修习难度**：★★★★☆

## 功法介绍

神念通是北海龙宫的不传之秘。传说龙族天生神识强大，一头刚出生的幼龙就能用神识覆盖方圆百里。但龙族并不满足于天赐的强大神识——他们希望将神识转化为实质性的力量。经过龙族数代大能的钻研，终于有一位名为"敖广"的龙王创出了神念通——一种以神念驱动物质、干涉现实的功法。

神念通的核心原理是将神识压缩到极致，使其从"感知"转变为"力量"。普通修士的神识只能用来感知周围环境，而神念通修炼者的神识可以托起物体、打开禁制、甚至直接攻击敌人的识海。因为龙族一直垄断着这门功法，修仙界的其他修士很长一段时间都以为这只是个传说。

直到三百年前，北海龙宫的一位龙女与一位人族修士相恋，违反了龙族不得外传功法的禁令，将神念通偷偷传给了那位修士。那人族修士靠着这门功法在修仙界闯出了赫赫威名，从此神念通才为人族所知。虽然龙族勃然大怒，但功法已经散播出去，无法全部追回了。如今神念通已成为元婴期修士追求神识极致的重要功法。

## 功法特点

**优点：**
- 可以用神念操控物品——飞剑、法宝甚至敌人的兵器，不接触即可控制
- 神念攻击无形无相——直接攻击敌人的识海，防不胜防
- 修炼神念通后，神识的强度和抗干扰能力远超同阶
- 可以"一心多用"——同时操控多件物品或同时探查多个方向

**缺点：**
- 修炼神念通需要对神识进行高强度压缩训练——过程极其痛苦，头痛欲裂是常态
- 神念操控的重量有限——初期只能控起一把剑，大成也不过千斤
- 神念被斩断会反噬识海，轻则呕吐，重则昏厥
- 对专修肉身的体修效果有限——体修的神魂与肉身高度绑定，难以被撼动

## 功法等级

**神念初凝**：开始压缩神识，能感受到神识从轻飘飘的气态变成了黏稠的液态。可用神念推动轻小的物品——如一片树叶、一根羽毛。

**神念化物**：神念压缩到足以托起常规兵器的程度——一柄飞剑、一面盾牌皆可操控。可实现"御剑术"的初步效果。

**神念如臂**：神念操控如同自己的手臂一般灵活。可以同时操控三件物品做不同的动作——左手用剑、右手用法宝、脚下踩着飞行法器。

**神念化形**：神念可以凝聚成实质性的形态——神念之剑、神念之盾、神念之手。这些"神念造物"可以物理攻击和防御。

**神念化域**：在周身创造一个"神念领域"。领域内的一切都在你的神念感知和操控之下——敌人的动作会因为你神念的干扰而走形，友方的攻击会因为你的神念辅助而更精准。

## 功法招式

1. **神念御物**：以神念代替双手操控物体。小到一根银针，大到千斤巨鼎，只要有足够的强度皆可操控。修仙界的"御剑术"就是从此招演化而来的。

2. **神念穿刺**：将神念凝聚成一根无形之针，瞬间刺入敌人的识海。此招不伤肉身，专伤神魂。中招者会感到剧烈的头痛，严重时直接昏迷。

3. **神念干扰**：用神念包裹住对手的大脑，干扰其思维。让对方在战斗中产生瞬间的恍惚——在高手对决中，一瞬间的失神就足以决定胜负。

4. **神念屏障**：以神念在周身构筑一道无形的屏障。这道屏障不能挡住物理攻击，但可以挡住一切神识探查和灵魂攻击。

5. **万念齐发**：将神念分裂成无数细丝，同时攻击敌人的识海。如同万箭齐发，让对方的神魂防御瞬间崩溃。但此招消耗极大，一月只能使用一次。

## 修炼条件

**前置功法**：需将《凝神术》《神魂经》等神识类功法修至大成，神识强度达到同阶巅峰水平

**灵根要求**：以雷灵根和水灵根为佳——雷灵根的爆发力有助于神识压缩，水灵根的包容性有助于神识扩展

**修炼地点**：需在安静之地，避免外界干扰。最理想的是北海龙宫的深海静室——深海隔绝一切噪音和灵气波动

**所需资源**：养魂木（做成的蒲团，打坐时滋养神魂）、凝神香（加速神识压缩）、龙涎香（龙族特供的神念修炼圣品）

## 使用限制/副作用

- 每次高强度使用神念通后都会剧烈头痛，需要服用镇痛丹药
- 神念被斩断如同灵魂被割掉一块——需要数月才能恢复
- 过度使用会让神念产生"疲劳"——感知迟钝，操控失准
- 神念攻击如果遇到了同样修炼神念通的对手，双方会陷入"神念角力"——非常危险，败者可能神魂破碎

## 相关典故

那位与龙女相恋的人族修士后来成为了修仙界的传说——"神念天尊"。他靠着神念通，在元婴期时就能力战化神不落下风。有一次他被三个化神期修士围攻，他神念一发，同时操控三十六柄飞剑布下剑阵，三位化神修士联手才勉强挡住。但神念天尊后来因为过度使用神念，识海出现了不可逆的损伤。他在临终前对弟子说："龙族的力量不属于人族，我强行使用了一辈子，代价就是现在——我的神魂已经千疮百孔。" 后人用他的故事告诫世人：外借的力量再强，也不如自己脚踏实地修炼得来的稳固。

## 修炼进度

**神念初发**：能感受到神识的"重量"——以前轻飘飘的神识有了质感，可以推动轻小物品

**神念御器**：可同时操控两柄飞剑进行简单的攻击和防守，神念覆盖范围扩展到三里

**神念如手**：神念已可以代替双手做精细操作——如空中穿针引线、隔空开锁

**神念化域**：周身五丈之内皆为神念领域，任何风吹草动尽在掌握
