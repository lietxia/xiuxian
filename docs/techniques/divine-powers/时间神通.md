# 时间神通

## 基本信息
- **功法名称**：时间神通
- **品级**：八阶（帝级）
- **类型**：神通功法
- **适用境界**：大乘期
- **修习难度**：★★★★★

## 功法介绍

时间神通的创始者是一位名为"时"的古老存在——后世尊称其为"时光老人"。传说时光老人在未入道之前是凡界的一个沙漏工匠，他一生都在与时间打交道——制作沙漏、日晷、水钟。有一天他突发奇想：如果我能让沙漏倒转，是不是时间也能倒流？带着这个疯狂的念头，他抛下了一切，踏上了寻找时间本源的修行之路。

他游历了三千世界，在每一个世界都停留千年，观察该世界的时间流速和时间法则。他看到了星辰的诞生与毁灭、文明的兴衰更替、沧海变成桑田又变回沧海——世间万物都在时间的洪流中起落沉浮。在最后一站——混沌之海——他终于接触到了时间的本源。那一刻他明白了：时间不是一条单向的河流，而是一个多维度的旋涡。过去、现在、未来同时存在，只是因为人类的感知局限，才觉得时间是线性的。时光老人将自己的全部领悟写入了《时之书》，时间神通由此而生。

## 功法特点

**优点：**
- 可让局部区域的时间流速变慢或加快——战斗中让对手的动作如同慢放
- 能短暂回溯某物数息之前的状态——比如将一瓶已经倒出的灵液收回到瓶中
- 可让自己进入"快进"状态——三天的修炼缩为一天
- 大成者能看到未来的数种可能走向

**缺点：**
- 修炼极为凶险——稍有不慎就会让自身的时间线错乱，导致衰老或逆生长
- 每使用一次都会消耗生命力——时间的力量不可能凭空而来
- 改变的只是"局部时间"，世界的时间洪流会以更大的力量"纠正"这个改变
- 对抗同样精通时间法则的敌人时，双方会陷入"时间对抗"，极其危险

## 功法等级

**时间感知**：能精确感知时间的流逝——不再需要日晷，能凭借感觉判断过了多久，精确到呼吸之间

**时间加速**：可以让自己或小范围内的物体时间流速加快——修炼时加速，战斗时加速攻击频率

**时间减速**：在周身形成一个"慢速领域"，领域内的时间流速减慢到外界的十分之一。对手的攻击在你眼中如同慢镜头

**时间回溯**：能将某个小范围内的时间倒退数息——受伤了可以回溯到受伤前，物资耗尽了可以回溯到消耗前

**时间停滞**：在极小的范围内（一丈之内）让时间完全停止一息。这是时间神通的最强控制招式

## 功法招式

1. **时之沙漏**：在目标头顶幻化出一个沙漏虚影。沙漏中的沙子流速代表了目标周围的时间流速——你可以加速或减速沙子的流动来操控时间。

2. **岁月如刀**：加快目标周围的时间流速，让他在数息之间经历数年甚至数十年的时光流逝。对寿元本就无多的敌人尤其致命——一息之间便可让其老死。

3. **时光回溯**：选定一个小范围的目标（如一柄断剑、一株枯萎的灵草），倒流其时间，让它恢复到数息前甚至数日前完好无损的状态。不可用于活物。

4. **刹那永恒**：让自身进入一种极致的"顿悟状态"——外界过去一息，体内却已过去百日。在突破瓶颈和参悟功法时效果卓绝。

5. **时间裂隙**：在空间中撕开一条通往"时间夹缝"的裂隙。时间夹缝是时间洪流的盲区，藏身其中的人不会被时间的因果追踪到。但迷失在时间夹缝中的人永远无法返回。

## 修炼条件

**前置功法**：需将空间类神通修至大成，且精通因果法则的基础原理——时间与空间、因果不可分割

**灵根要求**：变异时间灵根为最佳——这种灵根百万年难遇；其次为雷灵根或光灵根，对时间法则有一定亲和力

**修炼地点**：需在时间法则最为薄弱的"时间褶皱"地带修炼——如万年古钟的内部、日月的交替点、时间流速异常的秘境

**所需资源**：时光砂（时间尽头才能采集到的特殊矿物，一粒可让修习者感受百年时光的流逝）、日月石（蕴含日夜交替之力）、永恒冰（时间流速为零的绝对静止区域产出的冰晶）

## 使用限制/副作用

- 每一次使用时间神通都在"透支"自身的时间——你的生命可能比同龄人短得多
- 时间法则的修习者容易患上"时间紊乱症"——分不清过去、现在和未来，记忆混乱
- 如果操作失误让自己陷入时间循环，可能会永远困在同一段时间内无法脱身
- 天道对时间法则的修习者极度"敏感"，天劫的威力往往是普通修士的三倍以上

## 相关典故

时光老人在创出时间神通后，曾在一场大战中使用"岁月如刀"将一位魔尊变成了白发苍苍的老者。但代价是——他自己的力量也随之消逝，因为他发现时间法则有一个无法打破的规则：你施加于别人的时间之力，等同于施加于自身的时间之力。这意味着，如果你让别人衰老了十年，你自己也会衰老十年。时光老人最终接受了这个法则，他平静地说："时间是公平的，对所有人都一样。" 此后他不再用时间神通战斗，而是用它在各个世界之间旅行，观察时间的流逝。

## 修炼进度

**时感初成**：能精确感知每一息的时间流逝，在黑暗中也能知道过了多久

**快慢由心**：可让自身时间流速加快一倍或减慢一半，修炼效率提升显著

**时间领域**：能形成一个十丈范围的"时间场"，场内时间流速由你掌控

**回溯初通**：能将一丈范围内的非生命物体回溯到一日前的状态

**时之主宰**：能在五丈范围内做到时间暂停一息——一息足够你做很多事情
