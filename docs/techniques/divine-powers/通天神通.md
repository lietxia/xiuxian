# 通天神通

## 基本信息
- **功法名称**：通天神通
- **品级**：六阶（神级）
- **类型**：神通功法
- **适用境界**：炼虚期
- **修习难度**：★★★★★

## 功法介绍

通天神通的传说与上古神树"建木"有关。建木是天地初开时生长在天地之间的神树，它的树冠直达天庭，树根深入九幽——它是连接天、地、人三界的通路。传说凡人只要爬上建木的树冠，就能到达仙界。但后来天帝嫌凡人太多通过建木偷入仙界，一怒之下斩断了建木，天地从此隔绝。

建木被斩断时，它的枝叶散落四方，其中一段树枝落入了一位名叫"通天道人"的修士手中。通天道人发现这段树枝中蕴含着一种奇特的力量——它虽然不能像建木一样连接天地，但可以让持有者的"感知"直通天际。他拿着这段树枝闭关百年，领悟出了一门新的神通——通天神通。

通天神通的本质是"借天之力"。它将修习者的神识与高处的天道法则连接起来，让修习者能够借用天道的力量来增幅自己的法术。站在越高的地方使用通天神通，效果越强。传说将通天神通修至极致者，在万丈高空之上可以引动天雷、召唤星辉——如同仙人临凡。

## 功法特点

**优点：**
- 在视野开阔的高处使用时威力倍增——山顶、云端、高空都是主场
- 可以借用天雷和星辰之力——施展雷法和星辉类法术时有天然加成
- 神识可借天道之力延伸到极远的地方——在高处时，神识范围可扩大十倍
- 通天神通的气息对低阶修士有天然的威压

**缺点：**
- 在封闭空间或地底使用时威力不到正常情况的三成
- 需要站在高处才能发挥最大威力——但高处也最容易被攻击
- 借用天道之力会受到天气的影响——暴风雨反而会干扰通天神通
- 每次借用天道之力都会在自身留下"天道印记"——天劫时会被天道特别"照顾"

## 功法等级

**通天感应**：站在高处时，能感受到九天之上传来的"召唤"——那是天道法则在高空的流转。此时施法会感觉到法力更加流畅。

**通天视野**：在高处时，视野和神识范围都大幅提升。站在山顶可看清百里外的一根针，神识可覆盖整座山脉。

**通天共鸣**：能在高处引动天地灵气与之共鸣——法术威力提升五成，施法范围翻倍。

**通天引雷**：能引动九天之上的天雷为己用——虽然不是真正的天劫神雷，但也拥有天雷的七成威力，对邪祟有奇效。

**通天彻地**：站在天地之间，上可沟通天道、下可连接大地——此时你自身就像一株建木，成为天地之间的桥梁。法术威力达到极致。

## 功法招式

1. **通天视野**：借助天道之力将视野延伸到极远的距离。站在万丈高峰上时，可以看到千里之外的景象——如同在天空中有一只无形的眼睛。

2. **天雷引**：以通天神通引动高空中的雷霆之力，化为一束天雷从天而降。天雷对阴邪、魔气有克制效果，一击之下妖邪俱灭。

3. **星辉术**：引动星辰之力，将星辉凝聚在手中。星辉可以用来照明、驱散黑暗，也可以化作星辉之剑斩敌。在夜晚威力倍增。

4. **天道加持**：短暂借用天道法则加持己身——全属性提升两成，法术威力提升五成。但持续时间内身体会承受法则的压力，如同负山而行。

5. **建木之桥**：在头顶召唤出一段建木的虚影，从你的位置直通天际。站在建木虚影之下修行，灵气吸收速度翻倍、感悟天地法则的效率大幅提升。

## 修炼条件

**前置功法**：需掌握至少一门雷法或天象类功法，且对天道法则有基本的感悟

**灵根要求**：雷灵根或光灵根为最佳——雷灵根与天雷呼应，光灵根与星辉呼应

**修炼地点**：必须在高处修炼——山顶、悬崖、高塔、云端。越低的地方修炼速度越慢，甚至不进反退

**所需资源**：天雷石（被天雷劈过的灵石，蕴含雷霆之力）、陨铁（天外陨石中提取的金属，用于制作通天法器）、云锦（采集云气织成的布料，可制成通天法袍）

## 使用限制/副作用

- 通天神通离开了高处后威力大减——在平地和地底几乎无法使用
- 引动天雷时如果控制不好，天雷会劈到自己——"引火烧身"
- 每次借用天道之力都在消耗"天道恩情"——欠天道的账越多，天劫越重
- 在高处使用通天神通时，自己也成了最显眼的靶子

## 相关典故

传说通天道人拿着建木树枝，一路爬上了修仙界最高的山峰——"通天峰"。他在峰顶建了一座道观，日日感悟天道。有一天风雨大作、雷电交加，通天道人竟然在这一天用通天神通引下了九道天雷，将通天峰的山顶削平了百丈。事后他在被削平的山顶上刻下了一行大字："天地之间，唯此一柱。" 后人把这座山改名为"通天峰"，并在山顶修建了一座"通天道观"。如今通天道观已经成了通天神通修炼者的圣地，每年都有无数修士前来朝拜——希望能像通天道人一样，一窥天道之秘。

## 修炼进度

**登高望远**：站在高处时，神识范围和视野都得到了显著提升——如同登高望远的自然效果被强化了

**天威初感**：在高处时能感受到天空中的"威严"——那是天道的气息。适应了这种威压，才能进一步修炼

**引雷初试**：第一次成功从天际引下一缕雷霆——虽然只有头发丝粗细，但证明了天雷是可控的

**星辉在手**：能凝聚星辉在掌心——夜晚时如同握住了一颗星星

**通天彻地**：站在天地之间，上通天、下彻地——至此通天神通大成
