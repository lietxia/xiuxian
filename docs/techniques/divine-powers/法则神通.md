# 法则神通

## 基本信息
- **功法名称**：法则神通
- **品级**：七阶（圣级）（圣级）
- **类型**：神通功法
- **适用境界**：合体期
- **修习难度**：★★★★★

## 功法介绍

法则神通的来历极为神秘——它并非由任何已知的修士所创，而是在天地初开时，由天道化身在混沌中播撒下的"法则之种"之一。传说天道化身在开辟天地后，将自己对法则的理解凝聚成九枚种子，散落在天地之间。这些种子如果落在合适的地方，就会生根发芽，长成一棵"法则之树"。而其中最特殊的一枚种子落入了凡人界的一片荒原，没有发芽——因为它需要一个有缘人的灵魂之火来唤醒。

数万年后，一个名叫"玄道子"的修士来到了这片荒原。他修为不高，但对天地法则有着天生的好奇心。他在荒原上打坐了七七四十九天，不吃不喝，全神贯注地感受这片大地的"意志"。第四十九天的午夜，一枚金色的种子从他的眉心钻入了他的识海——法则之种选择了它。玄道子由此悟出了法则神通。

与其他神通不同，法则神通不教你怎么使用某一种法则，而是教你怎么去"感应"和"解析"万物的法则。理解了法则，就能预判法则的运转，从而找到一切功法的破绽。这是一门"元神通"——神通之上的神通。

## 功法特点

**优点：**
- 可感应到天地间各种法则的波动——火之法则、水之法则、风之法则、雷之法则等等
- 能快速解析对手功法的"法则结构"，找到其运转的底层逻辑，从而破解
- 可模仿他人的法则运转——看过一次的招式就能用同样的法则力量复现
- 对阵法有极高的洞察力——任何阵法都是法则的具现，法则神通可一眼看穿

**缺点：**
- 入门极难——法则之种的共鸣需要天大的机缘，不是想修就能修
- 法则神通本身没有直接的攻击力，需要配合其他功法使用
- 每领悟一种新的法则都会让原有的法则感悟产生"混乱"
- 过多的法则感悟会让人陷入"法则迷障"——看什么都是法则的线条，失去对实物的直观感知

## 功法等级

**法则初感**：能模糊感觉到天地间除了灵气之外的另一种"东西"在流动——那就是法则的脉动

**法则解析**：能主动释放神识去"触摸"周围的法则，分辨出不同法则的区别——如火之法则的灼热、水之法则的柔润

**法则共鸣**：能与某种法则产生共鸣，借助法则之力增强对应的功法威力——比如与火之法则共鸣时，火系功法威力翻倍

**法则编织**：能将多种法则编织在一起，创造出全新的法术效果——这是法则神通的创造性应用

**法则掌控**：在一定范围内，可以暂时压制或增强某一种法则的强度——让对手的火系法术失效，或者让你的雷系法术威力暴增

## 功法招式

1. **法则之眼**：双瞳中浮现出法则符文的虚影——能看到万物表面之下的法则结构。一棵树在你眼中不再是一棵树，而是一团由"生命法则""木之法则"编织成的能量体。

2. **法则剥离**：从对手的功法攻击中剥离出它的法则核心。比如对手发出一道火球，你用"法则剥离"将它拆解成"火之法则+风之法则+灵气"，就能从中找到破解的关键。

3. **法则共鸣术**：让自己的神魂与某一法则产生共振，短时间内获得该法则的"加持"。在与修炼相同法则的对手对战时，可以用来抵消对方的法则优势。

4. **法则镜像**：复制对手施展的法则攻击，以同样的法则力量回击。这不是简单的法术复制，而是连法则结构都完全复刻的精确映射。

5. **法则领域**：以自身为中心创造一个"法则领域"。领域内由你制定的某一条法则的规则可以发生变化——比如让"重力法则"增强十倍，或者让"光之法则"完全消失。

## 修炼条件

**前置功法**：需将至少三种不同属性的功法修至大成，掌握五行生克之理，且对天地大道有初步领悟

**灵根要求**：天灵根是基础要求——只有最纯净的灵根才能与法则之种产生共鸣；混沌灵根最佳

**修炼地点**：法则最为混乱的地方最适合修炼法则神通——如上古战场（多种法则残留）、混沌裂缝（法则尚未稳固）、天道碑林（法则直接显化）

**所需资源**：法则结晶（大能陨落后留下的法则碎片）、悟道石（辅助法则感悟）、五行精髓（金木水火土五种本源）

## 使用限制/副作用

- 法则感悟每增加一种，都要消耗更多的神识去"维护"——法则越多，神识负担越重
- 与掌握了相反法则的对手战斗时，法则会相互排斥，受到反冲伤害
- 法则领域每次展开都会消耗大量法力，维持时间不超过百息
- 长期沉浸在法则的世界中，会渐渐产生"万物皆法则"的漠然心态——对生命失去敬畏

## 相关典故

玄道子开悟法则神通后，曾在上古遗迹中遇到了一只法则妖兽——它是由无数破碎法则凝结而成的怪物。正常修士对上它完全束手无策，因为任何法术攻击都会被它吸收分解。玄道子却用"法则剥离"将它一层层拆开，最终看到了它的核心——一枚破碎的法则之种。他将那枚种子的碎片吸收，从此他的法则神通中多了一种"吞噬法则"的能力。后来他用这种能力帮修仙界清理了多处法则紊乱之地，被誉为"法则清洁工"。

## 修炼进度

**法则初醒**：感觉到天地间有某种看不见的"纹理"在流动，如在空气中触摸水波

**法眼初开**：能看到灵气的流动实际上是由各类法则驱动的——五行法术的本质一眼可见

**法则通晓**：能解析天级以下的各类功法法则结构，一眼看穿破绽

**法则编织**：能将两种以上法则编织在一起创造新法术，如"水之法则+冰之法则"创造绝对零域

**法则归一**：所有法则归于一道——万法归宗，此时任何一种法则在你手中都能发挥出极致威力
