# 聚火诀

聚火诀乃一阶火系控火功法，修习者通过特定的呼吸法门与经脉运转，将体内灵气转化为精纯的丹火，为炼丹炼器提供稳定热源。此功法是修真界流传最广的入门控火术，几乎所有火灵根修士的炼丹之路都由此起步。

## 功法来历

聚火诀的创立者乃上古丹修"赤炼子"。赤炼子生于南疆火山脚下，幼年便对火焰有着天生的亲近。据《南疆火经》记载，他少时曾目睹火山喷发，漫山岩浆奔涌而下，所过之处万物焚毁。旁人皆惊恐逃命，他却盘坐于远处山石之上，目不转睛地盯着岩浆流动的轨迹，喃喃自语"火如此，丹亦如此"。此后他花费三十年时间在火山口闭关，反复体悟地火喷发时的灵气暴动，最终悟出"以丹田为炉、以灵气为薪、化气为火"的聚火法门。

赤炼子出关后创立了"火云宗"，聚火诀便是火云宗的镇派基础功法。后来随着火云宗弟子在外游历，这套功法逐渐传入各派，历经数千年演变分化出诸多版本，但核心法门始终未变。如今修真界通行的聚火诀经过历代丹道宗师反复打磨，已是公认最稳妥的入门控火功法。

## 修炼条件

- **灵根要求**：火属性灵根为最佳，单火灵根修炼一日之功抵得上杂灵根十日。火木双灵根亦可，木能生火，反而比单一火灵根在火力持久性上略胜一筹。无水灵根者皆可修习，但水灵根修士修炼此功事倍功半，因水火相克，体内水灵气会自然压制火灵气，需多花数倍苦功方能凝聚火种。
- **境界要求**：炼气期一层即可入门，三层后方可真正用于炼丹。金丹期以上修士多已将聚火诀融入自身丹火，举手投足间便可聚火成炉。
- **心境要求**：火性热烈而暴戾，修炼聚火诀者须有"火中取栗"的胆识，又须有"以柔御刚"的智慧。过分畏火者灵气运转畏首畏尾，火苗刚起便灭；而性子过于急躁者则容易火力过猛，烧毁药材甚至炸炉。真正的高手恰如赤炼子观火山——身在火中而不为火所动。
- **特殊机缘**：若能在火山口或地火灵脉附近初次凝聚火种，地火之气会融入灵气，使丹火带上"地心炎"的特性，温度更高、火力更持久。另有秘法称，在丹田中种下一枚火灵石作为火种根基，可使聚火诀的威力提升三成，但此法风险极大，火灵石若控制不当会焚毁丹田。

## 修炼方法

**第一步：凝火种。** 盘膝端坐，双手结火印于丹田前。闭目内视，于丹田气海深处寻找体内那一丝先天火气——它隐于真气流转之间，微不可察，暖如春阳。运转口诀"离火归位，炎上为根"，以意念引导火气汇聚丹田正中，凝聚为一粒芝麻大小的火种。这一步最为艰难，有人数月不得其门而入，有人三两日便成。天资平庸者可用"借火法"——在炭火盆旁修炼，借外火引动体内火气。

**第二步：引火线。** 火种凝聚之后，引导它沿经脉缓缓游走。路径为：丹田起，经任脉上行至膻中，入心包经，经曲泽、郄门至劳宫穴。全程火种须如蚕丝般纤细，不可过粗，否则经脉灼痛难忍。火种每经过一个穴窍，该处便会微微发热，此乃经脉被火灵气滋养的正常现象。若剧痛则是火势过旺，须立即回撤丹田重新凝炼。

**第三步：掌心吐火。** 火种到达劳宫穴后，伸掌向外，以意念将火种从掌心缓缓吐出。初时不过是掌心一缕青烟，若有若无；气定神闲地维持呼吸，烟中会慢慢出现一点火星，继而扩展为一簇跳动的寸许火焰。初学者吐火不过持续三五息便会熄灭，待丹田灵气充足后可持续一炷香以上。火焰的颜色是衡量功力的标志——淡黄为初入门，橙黄为小成，青白为上乘，若能练至无色透明近乎无形，则是炉火纯青之境。

**第四步：控火炼丹。** 以吐出的火焰加热丹炉底部，运转灵力调节火势大小。口诀有云"文火武火，存乎一心"——文火如蚕吐丝，火力绵长不断，适合慢炖药性；武火如猛虎下山，烈焰汹涌，适合瞬间提纯。初习者先练文火，待能稳定维持丹炉底部受热均匀后，再学文火武火交替使用以应对不同药材的炼制需求。

**第五步：收火归元。** 炼丹完毕，不可直接将火焰熄灭。须将剩余火焰沿原路——从劳宫穴经心包经、任脉缓缓收回丹田。火焰归位后，在丹田中化为数缕温和的火气潜伏下来，待下次调用时再次凝聚。此举既可节省灵力，又能温养丹田。曾有修士炼丹后随意散去火焰，导致火灵气白白浪费，日后修为进展缓慢。

## 经脉运行路线

聚火诀的核心经脉路径为：丹田（气海）→ 任脉 → 膻中穴 → 手厥阴心包经 → 曲泽 → 郄门 → 间使 → 大陵 → 劳宫穴（吐火）。收火时沿原路返回。此外，在炼丹过程中需分出一缕火灵气走足阳明胃经至足三里穴，以稳定下盘，方便长时间站立炼丹。

## 威力表现

- **文火熬药**：运转聚火诀以文火加热丹炉，炉壁均匀升温，炉中药液缓慢翻腾，气泡细密如鱼眼，药香层层释放。一炉三转回春丹需文火熬炼六个时辰，火力稳定者炼出的丹药色泽均匀、药力充沛，远非火候不稳者可比。
- **武火提纯**：提炼矿石或提纯剧毒药材时，将聚火诀催至极致，掌心火焰暴涨至半尺有余，炉内温度瞬间飙升。杂质在白炽火焰中化为青烟消散，留在炉底的只有精纯的药液或金属精华。曾有火云宗弟子当众演示，以武火提纯一块黑铁矿，半柱香工夫便将矿石炼成一团赤红的精铁，杂质尽去。
- **应急煮丹**：在野外缺少丹炉的情况下，聚火诀可直接以灵气化火包裹药材进行简易炼制。此法虽然成丹率低，但关键时刻能救命。某散修被困妖兽森林，以聚火诀徒手炼化止血草敷在伤口上，硬是撑到了救援到来。

## 使用限制与副作用

- **丹田灼伤**：长时间高强度催动聚火诀会使丹田过热，轻则丹田隐隐作痛数日，重则火灵气灼伤丹田壁，需以寒冰属性的药材调理数月方能恢复。炼气期弟子每日练习聚火诀不宜超过两个时辰。
- **心火过旺**：长期修炼火系功法会导致体内火气过盛，性情变得暴躁易怒、睡眠减少。许多火云宗弟子都有"火气上头"的毛病——一言不合便脸红脖子粗，需以水系或木系功法调和心性。清心丹是火系修士的常备丹药。
- **火焰失控**：火势一旦超出自身掌控范围，极易引发火灾甚至炸炉。新手炼丹十炉五炸的惨剧多半与聚火诀火候失控有关。修炼此功必须循序渐进，不可贪功冒进。
- **经脉火毒**：吐火时若火种路径偏移或火力过猛，火毒会侵蚀手三阴经，导致手掌发黑、经脉萎缩。此症状被称为"火毒掌"，严重者可致手掌废用。一旦发现掌心出现黑色纹路，须立即停功并以寒玉冰敷，同时服用清火化毒丹。

## 著名使用者与典故

- **赤炼子**：功法创始人。相传他晚年已不需要结印吐火，只需心念一动，方圆百丈内的火灵气便会自动汇聚于他掌心。他炼制九品丹药"涅槃丹"时，九天九夜不眠不休，丹炉火焰从未熄灭，出丹时整座火云宗的山峰被丹火映得通红，方圆十里可见。
- **火云真君**：火云宗第三代宗主，将聚火诀与剑法融合，创出"火云剑诀"。他的成名之战是在南疆火山口独战三名元婴期魔修——剑锋所过之处烈焰滔天，三名魔修一死两逃，战后火山口被削平三丈。
- **巧手柳三**：两百年前的散修炼丹奇才，天生长有一双不怕烫的手。他将聚火诀练到了出神入化的地步，能在掌心同时凝聚六团不同温度的火焰，同时炼制六种不同的丹药。据说他曾当众表演——左手炼丹、右手烤肉，两不耽误，食客皆称烤肉外焦里嫩，火候绝佳。

## 进阶方向

- **衔接功法**：聚火诀修炼纯熟后可转修二阶《南明离火功》，将丹火的温度与纯度提升一个档次，可用于炼制四品以上丹药。
- **法器搭配**：配合火属性法器"聚火盆""火灵珠"使用，可增强火力同时降低自身灵气消耗。一阶丹炉"赤铜炉"底部刻有聚火阵纹，与聚火诀配合使用效果最佳。
- **合击技巧**：聚火诀与灵香引气诀一刚一柔、一动一静，同时运转可达到"火借香势、香随火行"的互补效果，大幅提升炼丹成功率。
