# 穿甲镗法

## 基本信息

- **功法名称**：穿甲镗法
- **品级**：一阶（黄级）
- **适用境界**：炼气期1-3层
- **类型**：攻击类
- **属性**：金属性

## 功法介绍

穿甲镗法来自水军镗兵的训练。镗是一种重型长杆兵器，头部宽大如铲又似枪尖，可刺可砸。水军镗兵在战船上使用镗来钩住敌船、刺穿敌兵、推开登船之敌。

穿甲镗法是镗兵的基础训练科目，由水军教头根据多年水战经验总结而成。由于镗的造型特殊，其用法也与其他长杆兵器不同——镗头的宽面可用于格挡和推挡，镗尖可刺击，镗侧月牙可勾割。

## 功法特点

- **一兵多用**：镗可刺、可砸、可钩、可推、可挡
- **破甲强劲**：镗头沉重，刺击威力大可破甲
- **水战利器**：在水战中镗的优势尤为明显
- **身材优势**：镗的长度使其在远程攻击中占优

## 功法等级

- **基础**：掌握镗的基本用法
- **熟练**：能用镗完成各种攻防动作
- **精通**：镗法熟练攻防一体

## 功法招式

### 1. 直刺

- **描述**：双手握镗向前直刺，镗头宽大命中率高
- **用途**：正面攻击

### 2. 横扫

- **描述**：以腰部带动镗身横扫，镗头的宽度增大了打击面
- **用途**：范围攻击

### 3. 钩挂

- **描述**：用镗侧的月牙刃钩住对手兵器或腿部
- **用途**：控制对手

## 修炼条件

- **体魄要求**：镗较重需要一定力量
- **身高要求**：身高适中即可
- **灵根**：金属性为佳

## 使用限制/副作用

- **镗重**：携带不便
- **灵活不足**：镗不如枪灵活
- **小众兵器**：镗较为少见

## 相关典故

水军镗兵在抵御海盗的战役中发挥了关键作用。海盗登船时被镗兵用镗一一推入水中，镗的宽度让海盗根本无法近身。
