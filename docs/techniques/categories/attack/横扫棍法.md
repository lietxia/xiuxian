# 横扫棍法

## 基本信息

- **功法名称**：横扫棍法
- **品级**：一阶（黄级）
- **适用境界**：炼气期1-3层
- **类型**：攻击类
- **属性**：无属性

## 功法介绍

横扫棍法脱胎于少林寺棍僧的入门训练。少林寺的棍法素来以扎实稳健著称，所有棍僧入门第一年只练一个动作——横扫。从清晨扫到日暮，从春日扫到冬雪，在日复一日的横扫中领悟棍法的根基。

少林寺方丈曾言："棍法万变，不离横扫。扫之一字，乃百棍之祖。"横扫棍法虽只有扫、挑、劈、点四个基本动作，但每一个动作都经过千锤百炼，是最纯粹的基础棍法。

## 功法特点

- **根基扎实**：专注于棍法最基础的动作，为后续高阶棍法打下坚实基础
- **动作规范**：少林寺千年传承，动作标准无偏差
- **身心同修**：配合少林心法修炼，可强身健体
- **攻防兼备**：扫可为攻，收可为守，进退有据

## 功法等级

- **入门**：掌握扫挑劈点四式
- **熟练**：四式切换行云流水
- **精通**：一棍在手攻防自如

## 功法招式

### 1. 平扫

- **描述**：握棍中段水平横扫，棍身与地面平行，扫向对手腰部
- **用途**：中段攻击

### 2. 上挑

- **描述**：棍头自下而上猛然挑起，攻击对手下巴或手腕
- **用途**：破敌兵器

### 3. 下劈

- **描述**：高举长棍垂直劈下，以棍端砸击对手头顶或肩膀
- **用途**：重击

### 4. 点棍

- **描述**：以棍端如枪般向前点击，速度快力量集中
- **用途**：快速突袭

## 修炼条件

- **协调性**：手脚协调能力好
- **耐心**：能忍受枯燥的重复训练
- **灵根要求**：无

## 使用限制/副作用

- **威力有限**：基础棍法威力不足
- **变化少**：招式简单容易被预判

## 相关典故

少林寺历史上有一位觉远禅师，将横扫棍法练至化境，下山云游时只用一根扁担战胜了一伙山贼数十人，一棍扫出山贼兵器尽数脱手。
