# 玉面狼

> 玉面狼者，啸月天狼之遗脉也。通体银白如月光铸就，面如冠玉，目似寒星。它独行于月夜之下，对月长啸时声震九霄。玉面狼在所有狼族灵兽中品阶最高，血脉最纯，是月属性修士梦寐以求的伙伴。有诗云：银狼啸月天地寒，玉面生辉照夜阑。

## 外形

玉面狼体长六尺，肩高近丈，体型匀称健美。通体覆盖着银白色的长毛，在月光下泛出珍珠般的光泽。最引人注目的是它的面部——面部毛发更短，呈白玉般的质地，故而得名"玉面"。

**体态特征：** 额头正中有一枚银色的月牙印记，是血脉纯度的标志。双目呈银灰色，瞳孔在夜间会发出幽幽银光。双耳直立，耳尖有银色绒毛。獠牙外露，长三寸，如月牙般弯曲。四肢修长有力，狼爪锋利。尾部蓬松修长，末端有一团银白色的绒球。

**气息：** 玉面狼的气息清冷如月华，带着孤傲的寒意。它凝视你的时候，你会感到灵魂被月光穿透。月圆之夜，玉面狼的气息最为强盛。

## 血脉与进化

**进化路线：** 玉面狼 → 银月狼 → 天狼 → 啸月天狼（终极）

**血脉溯源：** 玉面狼是啸月天狼的后裔。传说啸月天狼是太阴星君的坐骑，以月华为食，可引动太阴之力。凡间狼族在月圆之夜对月长啸，便是源自对啸月天狼的原始记忆。

---

## 天赋神通

**神通一：月华天狼啸。** 玉面狼对月长啸，声波携带月华之力扩散。友方被声波笼罩后恢复力大增、战意高涨；敌方则神魂震荡、灵力紊乱。月圆之夜此神通威力翻倍。一声长啸可覆盖方圆十里。

**神通二：银月之爪。** 玉面狼的利爪上覆盖一层月华之力，爪击附带月属性伤害和冰寒效果。被爪伤的敌人伤口会持续冻结，难以愈合。银月之爪对阴邪鬼物有额外克制效果。

**神通三：月影分身（啸月天狼专属）。** 啸月天狼在月光下可分出三道与本体完全相同的分身。分身拥有本体三成战力，且可独立行动。更可怕的是——本体可在分身之间自由切换，令人防不胜防。

## 培养方法

**食物：** 月华露、银光草、月灵果。玉面狼以月华为主要能量来源，食物反而次要。每月月圆之夜让它吸收整夜月华，远胜于十日进食。

**环境：** 居于高处空旷之地，便于吸收月华。巢穴以月光石筑成，反射月光效果最佳。不可养在不见天日的密室中。

**要点：** ①月圆之夜是玉面狼修炼的黄金时间，不可错过；②玉面狼性孤傲，它的尊重需要靠实力赢得；③银白色毛发需要定期梳理，否则会打结；④它只认一个主人，不可转赠。

## 与主人羁绊

**契约方式：** 月印魂契。在月圆之夜，以月华为媒，在双方灵魂上烙印一枚月印。契约完成后，双方共享月华感应。

**心灵感应：** 玉面狼通过月印与主人交流，可在心中直接传递意念。主人遇险时玉面狼瞬间感知，不惜一切代价赶往救援。

**生死相随：** 玉面狼一生只认一主。主人若陨落，它将对月哀嚎七日七夜，然后绝食而亡。有传说玉面狼的哀嚎能打开冥界之门，让主人灵魂得以转世。

## 著名灵宠/典故

**天狼北望：** 传说北方有一颗天狼星，乃是啸月天狼飞升后所化。每逢夜空，天狼星明亮如月，俯瞰大地。凡间玉面狼拜月之时，便是向那颗天狼星致敬。

## 同类对比

玉面狼与血蝙蝠同为夜行性灵兽，但玉面狼以月华为力量之源，血蝙蝠以鲜血为食。玉面狼高贵孤傲，血蝙蝠阴森嗜血。若论正面战力，玉面狼碾压血蝙蝠。
