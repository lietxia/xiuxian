# 玉兔

> 玉兔者，月之灵兔也。通体洁白如玉，双目如红宝石，耳长而灵敏，捣药长生，通灵祥瑞。它是最具仙气的灵宠——传说它是月宫中嫦娥仙子的伙伴，在桂树下捣制长生不老药。玉兔体内流淌着月华之力，拥有感知吉凶、捣制仙药、祈福消灾的天赋，是修仙者最喜爱的祥瑞灵宠。

## 外形

玉兔体型娇小，成年个体约小猫大小，通体洁白如雪，散发着柔和的银色光芒。

**体态特征：**

- **皮毛**：全身覆盖纯白色绒毛，柔软如丝缎，在月光下泛出银色光泽。毛尖有微弱的荧光，夜间如同一个小月亮
- **眼睛**：一双大眼呈红色，如同两颗红宝石，在黑暗中发出柔和的红光。眼神温柔灵动，充满智慧
- **耳朵**：耳朵极长，可自由转动，耳廓薄如蝉翼，内有粉色血管纹路。听觉极为灵敏，可听到数里外的细微声响
- **四肢**：前肢短小，后肢发达有力，善于跳跃。趾端有白色短爪
- **尾巴**：尾巴短小蓬松，如同一个白色绒球
- **药臼**：玉兔的前肢可化为一个小型药臼，用于捣制仙药

**气息：** 玉兔气息清冷祥和，带着淡淡的桂花香。它所居之处，空气清新，灵气纯净，周围的人会感到心神安宁。

## 血脉与进化

**血脉溯源：** 玉兔是月宫中"玉兔"的后裔。月宫玉兔是嫦娥仙子的伙伴，负责捣制长生不老药。玉兔继承了月华之力和捣药天赋。

**进化路线：** 玉兔 → 灵兔 → 月兔 → 玉蟾（传说）

## 天赋神通

### 神通一：月华捣药

玉兔的核心天赋，以月华之力捣制仙药。

- 可将灵草和矿石捣成药泥，炼制成丹药
- 捣制的丹药品质更高，药力更纯
- 可捣制一些特殊丹药，如"月华丹"、"清心丸"等
- 捣药速度视药材硬度而定，普通灵草片刻可成
- 每日捣药量有限，过度使用会损伤玉兔的前肢

### 神通二：吉凶感知

玉兔能感知未来的吉凶祸福，为主人预警。

- 危险临近时，玉兔会耳朵竖起，躁动不安
- 吉事将至时，玉兔会格外安静，双眼放光
- 可感知方圆百里内的杀意和恶意
- 对自然灾害（地震、洪水等）也有预警能力
- 感知结果以行为方式表达，需主人自行解读

### 神通三：月华祝福

玉兔释放月华之力，为主人祈福。

- 可为主人恢复灵力和精神力
- 可驱散主人身上的诅咒和负面状态
- 可提升主人的悟性，帮助突破瓶颈
- 祝福效果温和，需持续使用方显成效
- 每日最多使用三次，过度使用会损伤玉兔自身

### 神通四：月影分身（月兔专属）

进化至月兔后觉醒的辅助神通。

- 可分出数个幻影分身，迷惑敌人
- 分身无攻击力，但可吸引敌人注意力
- 分身持续约一炷香时间
- 月兔本体在分身存在期间可隐匿气息
- 一日最多使用两次

## 培养方法

### 喜好食物

| 食物 | 效果 | 推荐度 |
|------|------|-------|
| 灵草 | 基础食物，维持生存 | ⭐⭐⭐ |
| 月华草 | 提升月华之力 | ⭐⭐⭐⭐⭐ |
| 桂花瓣 | 促进进化 | ⭐⭐⭐⭐⭐ |
| 灵芝 | 增强捣药能力 | ⭐⭐⭐⭐ |

### 栖息环境

- **最佳环境**：月华充沛的山顶、灵药园、洞府
- **巢穴**：干燥温暖的洞穴或木箱，需铺柔软干草
- **光照要求**：喜月光，白天多睡觉，夜间活动
- **温度**：适应性强，偏好凉爽环境

### 培养要点

1. **月光浴**：每月需让玉兔在满月下沐浴月光，补充月华之力
2. **定期喂药**：喂食灵芝等灵药可增强玉兔的捣药能力
3. **避免惊吓**：玉兔胆小，突然的惊吓会使其逃跑
4. **陪伴需求**：玉兔需要主人的陪伴，长期独处会抑郁

## 与主人羁绊

### 契约方式

**月魂契约**：在满月之夜，以主人精血滴入玉兔额头。月光为见证，契约自成。此契最为温和，几乎不会失败。

### 心灵感应

- 玉兔通过月华波动与主人沟通
- 主人可感知玉兔的情绪——愉悦时耳朵竖起，恐惧时耳朵贴背
- 玉兔能感知主人的精神状态，主人疲惫时会主动为主人祈福

### 忠诚度

玉兔性格温顺可爱，对主人极为依恋。它喜欢趴在主人膝上，感受主人的气息。玉兔寿命中等，约千年，但在这漫长岁月中，它会一直陪伴主人，为主人捣药祈福。

---

## 使用限制

- **战斗乏力**：玉兔几乎无战斗力，不适合战斗
- **胆小易惊**：突然的惊吓会使玉兔逃跑
- **日间虚弱**：白天玉兔的实力下降三成
- **月华依赖**：长期不见月光，玉兔会萎靡

## 著名灵宠/典故

### 月宫捣药

据《山海经》记载，月宫中有一只玉兔，在桂树下捣制长生不老药。嫦娥奔月之后，玉兔成为她唯一的伙伴。此后玉兔成为月亮的象征，"玉兔"也成为月亮的别称。

### 兔报恩

民间传说中，有一只玉兔被猎人所伤，被一位善良的药师救下。玉兔伤愈后认药师为主，每日为药师捣制灵药，帮助药师炼制出了无数灵丹妙药。药师成为一代丹道大师，玉兔功不可没。药师飞升之后，玉兔化为月宫中的一颗星辰，永远照耀着药师曾经居住的地方。

## 同类对比

### 玉兔 vs 寻宝鼠

两者俱为辅助型灵宠，但定位不同：

- **能力**：玉兔主捣药和祈福，寻宝鼠主寻找宝物
- **战斗能力**：两者都几乎无战斗力
- **稀有度**：玉兔更稀有，寻宝鼠相对常见
- **寿命**：玉兔寿命约千年，寻宝鼠寿命约五百年

### 玉兔 vs 赤焰狐

- **属性**：玉兔主月属性，赤焰狐主火属性
- **定位**：玉兔偏辅助，赤焰狐偏攻击
- **外形**：玉兔洁白可爱，赤焰狐赤红妖媚
- **性格**：玉兔温顺胆小，赤焰狐狡黠多变
