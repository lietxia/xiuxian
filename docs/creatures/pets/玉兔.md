# 玉兔

> 月宫灵兔，上古月华之精所化。通体雪白如玉，一双赤瞳如红宝石，专精于灵植培育与炼丹辅助。有玉兔相伴，炼丹成丹率可提升三成，药性感知之精准，远超凡人之鼻。

## 外形

玉兔通体雪白，无一根杂毛，毛色温润如羊脂白玉，在月光下会泛出淡淡的银色光晕。

**体态特征：**

- **体型**：体长约一尺半，比寻常野兔略大。身形圆润可爱，行动却异常敏捷
- **皮毛**：毛发细密柔软，触感如最上等的丝绸。毛发中蕴含月华之力，夜间会发出微弱的银白荧光
- **赤瞳**：一双赤红色的眼睛，如两颗打磨过的鸽血红宝石。赤瞳是玉兔品阶的标志，颜色越深红，品阶越高
- **耳朵**：双耳修长，耳尖有一小撮银色绒毛。耳朵极为灵敏，可听闻百里之外落叶之声
- **四足**：前足短小灵巧，擅长抓握；后足强健有力，一跃可达三丈
- **尾部**：极短的绒球尾，蓬松如雪球
- **额头印记**：品阶达到四级后，额头会出现一枚银色的月牙印记，乃是月华之力凝结的标志

**气息：**

玉兔气息柔和纯净，如月光洒落大地，令人心神安宁。它周身萦绕着一层淡淡的月华银辉，夜间望去宛如一轮小型明月。

## 血脉与进化

### 进化路线

玉兔的血脉源自月宫仙兔一族，进化方向以增强月华亲和与药性感知为主。

```
玉兔 → 银月玉兔 → 月华玉兔 → 月宫仙兔（终极形态）
```

### 进化阶段

**第一阶段·玉兔（二级·妖兽）**
- 初生灵智不高，性情胆怯
- 对灵草有天然的亲和力，喜食百年以上的灵草
- 可感知到灵草中蕴含的药力强弱
- 与主人亲密度提升后，可辅助炼制低阶丹药

**第二阶段·银月玉兔（三级·灵兽）**
- 毛色转为银白，赤瞳颜色加深
- 额头隐约浮现月牙印记
- 可吸收月华之力转化为精纯的阴属性灵力
- 辅助炼丹时，丹炉火候感知极为精准
- 能辨别千种以上灵草的药性

**第三阶段·月华玉兔（四级·玄兽）**
- 额头月牙印记清晰可见，可引动月华之力
- 赤瞳变为深红，可直视灵草内部药力流动
- 自身可炼制简单的月华丹
- 辅助高阶炼丹时，可将月华之力注入丹炉提升品质
- 灵智已开，可与主人以心念交流

**终极形态·月宫仙兔（六级·圣兽）**
- 全身月华笼罩，夜间宛如明月降世
- 可化形为七八岁的小女孩，银发赤瞳，精致如瓷娃娃
- 拥有完整的炼丹传承记忆
- 可炼制九阶仙丹
- 传说中月宫中嫦娥仙子的玉兔便是此等存在

### 进化条件

| 阶段 | 关键条件 | 辅助资源 |
|------|---------|---------|
| 玉兔→银月 | 五百年修为 + 吸收千年月华 | 月华露百滴 |
| 银月→月华 | 千年修为 + 太阴真水一滴 | 月桂叶三片 |
| 月华→仙兔 | 三千年修为 + 太阴本源洗礼 | 月桂枝一段 |

## 天赋神通

### 神通一：药性感知

玉兔核心天赋，对天地灵草的药性有着超乎常理的感知能力。

- 可精准判断灵草的年份、药力、毒性
- 仅凭气味，便可知晓一株灵草生长于何种环境、采撷于何时
- 可感知灵草之间是否相生相克，杜绝丹方配伍失误
- 月华玉兔阶段，甚至可"看到"灵草内部的药力流动路径
- 辅助炼丹时，能感知丹炉内每一味药材的融合状态，及时提醒主人调整火候

有玉兔辅助，炼丹失败率降低七成。

### 神通二：月华淬炼

玉兔引动月华之力，对丹药进行二次提纯。

- 在月圆之夜，玉兔可将月光引入丹炉，淬炼丹药
- 经月华淬炼的丹药，杂质减少三成，药力提升两成
- 可祛除丹药中的火毒和燥性，使丹药性质更加温和
- 长期服用月华淬炼的丹药，容貌有驻颜之效

### 神通三：草木亲和

玉兔天生受草木喜爱，可以安抚灵植的"情绪"。

- 玉兔触碰过的灵草，生长速度提升五成
- 濒死的灵植，经玉兔日夜照料可起死回生
- 可感知灵草的"喜怒哀乐"，知晓哪株灵草需要浇水、哪株需要松土
- 在玉兔的照料下，灵草的病虫害几乎绝迹

### 神通四：月华变身（月华玉兔专属）

月华玉兔可在月圆之夜临时变身，体型暴涨十倍。

- 变身期间战斗力大幅提升
- 可操控月华之力形成护盾或攻击波
- 但变身消耗极大，一年最多使用三次
- 玉兔通常不喜战斗，这个神通更多用于自保

## 培养方法

### 喜好食物

| 食物种类 | 效果 | 推荐频率 |
|---------|------|---------|
| 百年灵草（灵芝/人参/黄精） | 基础食物，促进修为 | 每日 |
| 月华露 | 提升月华亲和力 | 每日饮用 |
| 灵果（朱果/玉灵果） | 滋补气血 | 每周一次 |
| 太阴真水 | 激发血脉进化 | 进化时使用 |
| 桂花/月桂枝 | 嗜好之物，提升心情 | 偶尔投喂 |

### 栖息环境

- **最佳环境**：月华充沛的高地，如山顶、天台
- **巢穴**：以月光石搭建巢穴，铺垫以月华蚕丝
- **禁忌**：不可长时间暴露在烈日下，玉兔畏强光
- **灵脉要求**：太阴（阴属性）灵脉最佳

### 培养要点

1. **月华为主**：每天夜间需让玉兔在月光下静卧至少两个时辰，吸收月华之力
2. **药草储备**：养成玉兔需要大量的灵草储备，这是一笔不小的开销
3. **胆小易惊**：玉兔天性胆小，不可大声呵斥，否则会吓得不敢见人
4. **炼丹搭档**：玉兔适合与炼丹师搭配，两者相辅相成
5. **月圆机遇**：每月月圆之夜是玉兔修炼的黄金时间，此夜不可错过
6. **桂花情结**：玉兔对桂花有着天然的喜爱，一株桂花树可让玉兔心情愉悦数月
7. **不可喂肉**：玉兔纯素食，喂肉会拉肚子，甚至会绝食抗议

### 注意事项

- 玉兔极为记仇。你若惹了它，它会趁你不注意时把你的灵草咬成秃头
- 但玉兔也极为感恩。你对它好，它会把自己的珍藏——偷偷攒了百年的月华露送给你

## 与主人羁绊

### 契约方式

**心意魂契**：玉兔灵魂纯净，不可用强迫性的血契。心意魂契以双方自愿意念缔结，契约温和，重在心意相通。

### 心灵感应

- 玉兔对主人的情绪变化极为敏感，主人不开心时，它会跳到主人怀里蹭蹭
- 炼丹时与主人心念相连，可预判主人的每一个动作
- 当主人生病或中毒时，玉兔会焦急地寻找药草为主人疗伤

### 忠诚度

玉兔的忠诚度建立在"你对我好，我就对你好"的朴素逻辑上。它的忠诚不是赴汤蹈火的忠勇，而是润物无声的陪伴。

### 特殊关系

玉兔有一个独特的习惯——喜欢把自己珍藏的最好的灵草偷偷塞到主人的枕头底下。许多饲主早上起来，发现枕头下多了一株千年灵参，必定是自家玉兔干的好事。

## 著名灵宠/典故

### 嫦娥玉兔

上古传说中，嫦娥仙子飞升月宫后，有一只通体雪白的玉兔陪伴在侧。此兔在月宫中日夜以玉杵捣药，所炼仙丹可令人长生不老。每逢中秋月圆，人间可看见月宫中玉兔捣药的剪影。这便是"玉兔捣药"典故的由来，也是所有玉兔灵宠的最高追求——如那月宫仙兔一般，以丹道济世。

### 太白金星的白玉兔

据《神仙传》记载，太白金星身边也有一只玉兔，名为"白玉"。此兔曾下凡间，化作一位白胡子老者，指点一位凡间药农如何辨识灵草。那药农后来成为一代丹道宗师，弟子遍布天下。临终前，老者在药庐的墙角留下一行字："月宫白玉兔，曾到药庐来。"

### 兔儿爷

凡间有供奉"兔儿爷"的习俗。相传古时某地瘟疫横行，一只玉兔下凡，化作人身兔首的神人，以月华仙草救治百姓。瘟疫平息后，百姓感念其恩，每年中秋以泥塑兔首人身像祭拜，尊称为"兔儿爷"。此习俗流传至今。
