# 金丝蚕

> 金丝蚕者，金灵之蚕，织甲之虫也。其形如蚕，其丝如金，通体金黄，吐出的金丝坚韧无比，是炼制护身宝甲的顶级材料。金丝蚕虽无强大的攻击力，却以其独特的金丝闻名修仙界——以金丝蚕丝织就的"金丝软甲"，轻薄如纱却刀剑不入，是无数修士梦寐以求的护身至宝。

## 外形

金丝蚕体型如成人小指粗细，长约两寸，通体呈半透明的金色，体内可见流动的金色灵力，如同一块有了生命的金晶。

**体态特征：**

- **蚕体**：身体呈圆柱形，分为多节，每一节都覆盖着细密的金色绒毛。蚕体柔软有弹性，触感温润如玉。
- **金丝**：头部两侧各有一个细小的吐丝口，可吐出金色的蚕丝。金丝在阳光下闪闪发光，细如发丝却坚韧无比。金丝的颜色随修为增长而变化——初生时为淡金色，进阶后转为赤金色，蚕王阶段则化为纯金色的仙金丝。
- **口器**：一对金色的颚齿，可咬碎金属性矿石，咀嚼时发出细微的金属摩擦声。
- **眼睛**：两粒金色的复眼，虽视力不佳，却能感知金属性灵力的波动。
- **足部**：三对金色的短足，用于爬行与抓握，行动缓慢但稳健。

**金丝蚕王形态：**

金丝蚕王体型可达尺许，通体金灿如纯金铸造，吐出的金丝粗如麻绳，坚韧度提升十倍。背后生出一对金色的薄翅，可短距离飞行。

**气息：**

金丝蚕散发的气息温和而纯净，带着淡淡的金属清香。其所过之处，空气中会残留细微的金色光点，如同微型的金色星辰。

## 血脉与进化

### 进化路线

金丝蚕以吞噬金属性灵物与日月精华进化：

```
幼蚕金丝蚕 → 金纹金丝蚕 → 赤金蚕 → 金丝蚕王 → 天蚕（传说）
```

### 进化阶段

**第一阶段·幼蚕金丝蚕**
- 初生之蚕，通体淡金色，吐出的金丝细如发丝
- 以金属性矿石碎屑与灵桑叶为食
- 吐丝量有限，每日仅能吐出尺许长的金丝

**第二阶段·金纹金丝蚕**
- 吞噬金属性灵物后进阶，体表浮现金色纹路
- 吐出的金丝更加坚韧，可承受百斤拉力
- 每日吐丝量增至丈许

**第三阶段·赤金蚕**
- 吞噬精金后进阶，体色转为赤金色
- 吐出的金丝坚韧度堪比玄铁，可抵挡中品法器切割
- 每日吐丝量增至十丈

**第四阶段·金丝蚕王**
- 虫群中诞生王者，通体金灿如纯金
- 吐出的金丝坚韧度堪比龙鳞，可抵挡上品灵器切割
- 每日吐丝量可达百丈，且金丝附带破魔属性

**传说阶段·天蚕**
- 吞噬仙金后蜕变，化为天蚕
- 吐出的天蚕丝可织就仙甲
- 寿元无尽，与天地同存

## 天赋神通

### 神通一：金丝吐纳

金丝蚕的核心天赋，吐出坚韧的金丝。

- 幼蚕期：金丝细如发丝，可承受百斤拉力
- 金纹期：金丝坚韧度提升，可承受千斤拉力
- 赤金期：金丝坚韧度堪比玄铁，可抵挡中品法器切割
- 蚕王期：金丝坚韧度堪比龙鳞，可抵挡上品灵器切割，且附带破魔属性

金丝蚕每日吐丝量有限，过度吐丝会导致其虚弱。金丝可用于织甲、织网、缝补法宝等。

### 神通二：金丝缠丝

金丝蚕吐出金丝缠绕敌人，限制其行动。

- 金丝缠绕时，敌人如同被金色的绳索缚住
- 金丝坚韧无比，同阶修士难以挣脱
- 金丝附带金属性侵蚀效果，会逐渐侵蚀敌人的护体灵光
- 蚕王的金丝缠丝可同时缠绕多个目标，且金丝可自动追踪

此神通对火属性修士效果减半，高温可使金丝软化。

### 神通三：金蚕脱壳（保命技）

金丝蚕在面临死亡威胁时，可脱去外壳，化为一个金色的光球逃脱。

- 脱壳后速度暴增，可瞬间逃出百丈
- 脱壳后的金丝蚕会进入虚弱期，需休养一月方可恢复
- 脱下的外壳化为一个金色茧，可抵挡一次致命攻击
- 每只金丝蚕一生仅能脱壳三次

### 神通四：天蚕宝甲（金丝蚕王专有）

金丝蚕王吐出毕生精华，织就一件金丝宝甲。

- 天蚕宝甲轻薄如纱，却可抵挡极品灵器攻击
- 宝甲附带破魔属性，可削弱法术伤害三成
- 宝甲可自动修复，受损后以金属性灵气温养即可恢复
- 织就天蚕宝甲后，金丝蚕王会陷入沉睡，需休养一年方可恢复

## 培养方法

### 喜好食物

金丝蚕以金属性物质与灵桑叶为食：

| 食物种类 | 效果 | 推荐度 |
|---------|------|-------|
| 灵桑叶 | 基础食物，维持生存 | ⭐⭐⭐ |
| 金属性矿石碎屑 | 促进金丝生长 | ⭐⭐⭐⭐ |
| 精金粉 | 提升金丝坚韧度 | ⭐⭐⭐⭐⭐ |
| 日月精华 | 促进进化 | ⭐⭐⭐⭐ |
| 普通桑叶 | 可食但无助于成长 | ⭐ |

### 栖息环境

- **最佳环境**：金属性灵脉附近的桑林
- **温度要求**：温和，不喜极寒或极热
- **湿度要求**：适中，过于干燥会影响吐丝
- **巢穴**：以灵桑叶与金属性灵木筑巢，保持清洁

### 培养要点

1. **桑叶品质**：灵桑叶的品质直接影响金丝的质量，需选用上品灵桑
2. **金属喂食**：每周喂食一次金属性矿石碎屑，可提升金丝坚韧度
3. **定期清理**：保持蚕房清洁，防止病害
4. **避免惊扰**：金丝蚕性格胆小，惊扰会导致其停止吐丝
5. **认主时机**：幼蚕期最易认主，以精血混合灵桑汁喂食可建立羁绊

### 常见误区

- 不可喂食含杂质过多的金属，会导致金丝质量下降
- 不可将金丝蚕带至火灵力充沛之地，高温会使其金丝软化
- 金丝蚕吐丝时不可强行打断，否则会造成内伤

## 产地/分布

金丝蚕主要分布金属性灵脉附近的桑林：

- **金桑林**：位于中州的广袤桑林，金属性灵脉纵横，是金丝蚕最大的栖息地
- **万宝山脉**：金属性矿脉丰富的山脉，桑林茂密，金丝蚕品阶普遍较高
- **天蚕谷**：传说中的天蚕栖息地，据说谷中有一只万年金丝蚕王
- **各大宗门蚕房**：许多宗门都设有蚕房，专门培育金丝蚕

## 使用限制

1. **火属性克制**：高温可使金丝软化，火属性功法是金丝蚕的天敌
2. **攻击力薄弱**：金丝蚕几乎无攻击力，不适合直接战斗
3. **吐丝限制**：每日吐丝量有限，过度吐丝会导致其虚弱
4. **寿命限制**：普通金丝蚕寿元约两百年，金丝蚕王可达千年
5. **环境敏感**：金丝蚕对环境变化极为敏感，温度骤变会导致其死亡

## 著名灵宠/典故

### 天蚕宝甲

上古时期，天蚕谷曾有一只万年金丝蚕王，吐丝织就了一件天蚕宝甲。这件宝甲轻薄如纱，却可抵挡仙器攻击，被誉为"天下第一软甲"。无数修士为争夺这件宝甲展开大战，最终宝甲在战乱中下落不明。

### 金蚕寺的传说

金蚕寺以金丝蚕为护宗灵虫，寺中培育了上万只金丝蚕。传说金蚕寺的祖师以金丝蚕丝织就了一件袈裟，名为"金丝袈裟"，可抵挡一切物理攻击。这件袈裟至今仍存于金蚕寺中，被视为镇寺之宝。

### 蚕仙飞升

古籍《万虫志》记载，一只金丝蚕王在金桑林中修炼万年，吞噬了一缕仙金之气，化为天蚕。天蚕吐丝织就了一件仙甲，穿上后渡过天劫，飞升而去。此传说激励了无数御虫修士，将金丝蚕视为最有潜力的灵虫之一。

## 同类对比

### 金丝蚕 vs 冰蚕

两者皆为灵蚕，但属性与定位不同：

- **属性差异**：金丝蚕为金属性，金丝坚韧锋利；冰蚕为冰属性，冰丝寒冷柔韧
- **丝的用途**：金丝蚕丝适合织就防御型宝甲；冰蚕丝适合织就攻击型法宝
- **战斗能力**：冰蚕有冰属性攻击能力，战斗力更强；金丝蚕几乎无攻击力
- **辅助价值**：金丝蚕的金丝织甲价值更高；冰蚕的冰丝攻击价值更高
- **稀有度**：冰蚕更加稀有，金丝蚕相对常见

### 金丝蚕 vs 噬金虫

- **食性差异**：噬金虫以金属为食，可吞噬法宝；金丝蚕以金属性矿石碎屑为食，不吞噬法宝
- **战斗能力**：噬金虫群攻能力极强，是战斗型灵虫；金丝蚕几乎无战斗力，是生产型灵虫
- **价值体现**：噬金虫的价值在于战斗；金丝蚕的价值在于金丝生产
- **饲养难度**：噬金虫需要大量金属，饲养成本高；金丝蚕以灵桑叶为食，饲养成本低

### 金丝蚕 vs 血玉蜘蛛

- **丝线差异**：金丝蚕的金丝坚韧锋利，适合织甲；血玉蜘蛛的血丝粘稠嗜血，适合结网
- **属性差异**：金丝蚕为金属性；血玉蜘蛛为血属性
- **战斗风格**：金丝蚕偏向防御与辅助；血玉蜘蛛偏向攻击与控制
- **进化上限**：金丝蚕可进化为天蚕；血玉蜘蛛可进化为血蛛王
