# 玄甲龟

> 背生玄纹，甲坚如星辰；寿元万载，不动如山岳。玄甲龟乃玄武血脉之旁支，虽不及玄武圣兽之尊，却也继承了其至坚至厚的防御天赋。有此灵兽相伴，便如随身携带一座不破堡垒。

## 外形

玄甲龟体型庞大，成年龟甲直径可达三丈，重逾万斤。

**体态特征：**

- **龟甲**：背甲厚实，呈深玄色（黑中带青），表面布满天然玄奥纹路。这些纹路蕴含天地至理，防御力远超表面所见。每一圈年轮便是一道天然禁制
- **腹甲**：腹甲为淡黄色，平滑如镜，同样刻有玄纹，防御力不亚于背甲
- **头**：三角形头颅，皮肤粗糙如老树皮，双眼深陷，目光沉着如千年古井
- **四肢**：粗壮如柱，覆有坚硬的角质鳞片。五趾有蹼，水陆两栖
- **尾巴**：短小而粗，尾尖有一小截骨质硬刺，可做近身攻击之用
- **玄纹**：龟甲上的玄纹会随着修为增长而愈发复杂深奥，完整玄纹可引动天地之力

**特殊形态·玄甲灵龟：**

当玄甲龟修为突破至五级时，龟甲边缘出现一圈金色光晕，玄纹中隐隐有流光转动。此时龟甲防御力已经堪比上品防御灵宝。

**气息：**

玄甲龟气息沉稳厚重，宛如一座移动的山岳。它静卧之时，气息几乎完全收敛，与普通岩石无异。发怒时气息暴涨，周遭地面龟裂，空气中弥漫着一股沉重的压迫感。

## 血脉与进化

### 进化路线

玄甲龟的血脉可追溯至远古玄武圣兽，进化路径虽缓慢，却胜在稳固。

```
玄甲龟 → 玄甲灵龟 → 玄甲宝龟 → 玄甲圣龟（终极形态）
```

### 进化阶段

**第一阶段·玄甲龟（三级·灵兽）**
- 初生龟甲直径一尺，体态笨拙可爱
- 玄纹初现，简单朴素
- 防御力堪比下品防御法器
- 寿元已有三千年

**第二阶段·玄甲灵龟（四级·玄兽）**
- 龟甲直径一丈，玄纹开始复杂
- 防御力堪比上品防御灵器
- 开始领悟土系和水系法术
- 寿元八千年

**第三阶段·玄甲宝龟（五级·神兽）**
- 龟甲直径三丈，玄纹密布如天书
- 防御力堪比下品防御法宝
- 可引动大地之力形成防御领域
- 寿元两万年

**终极形态·玄甲圣龟（七级·仙兽）**
- 龟甲直径十丈，玄纹演化成天然阵法
- 防御力堪比仙器，非大乘期修士不可破
- 可化身为人，多为白发老翁模样
- 寿元十万年，见证沧海桑田

### 进化条件

| 阶段 | 关键条件 | 辅助资源 |
|------|---------|---------|
| 龟→灵龟 | 千年静修 + 吸收土灵脉 | 土灵珠三枚 |
| 灵龟→宝龟 | 三千年修为 + 渡一次龟劫 | 玄武精血一滴 |
| 宝龟→圣龟 | 万年苦修 + 悟透玄纹真意 | 九天息壤一份 |

## 天赋神通

### 神通一：玄甲不动

玄甲龟核心防御神通，龟甲上的玄纹激活后，形成绝对防御。

- 玄甲激活时，龟甲硬度暴增十倍
- 金丹期修士全力一击，龟甲上连白痕都不会留下
- 元婴期修士的飞剑，也难刺穿三寸
- 玄甲圣龟形态下，玄甲可硬抗大乘期修士攻击而不损

玄甲龟防御时全身缩入壳中，只留缝隙观察敌人。它最擅长的事情便是——你打它半天，它探头问一句："打完了？"

### 神通二：厚德载物

玄甲龟引动大地之力，形成土系防御领域。

- 以自身为中心，方圆百丈内大地之力汇聚
- 处于领域内的队友防御力提升五成
- 敌人足下地面软化如沼泽，行动受阻
- 进化至宝龟后，领域内可形成土石壁垒

### 神通三：玄纹反震

玄纹的进阶运用，将受到的攻击转化为反震之力。

- 敌人攻击越猛，反震力越强
- 相当于让敌人自己打自己
- 反震之力为纯粹物理伤害，无法防御
- 很多不知深浅的修士打到玄甲龟后，自己的手先骨折了

### 神通四：玄武真水（圣龟专有）

进化至圣龟阶段后，觉醒一丝玄武控水之力。

- 可调动江河湖海之水，形成大水漫灌
- 玄冥真水，至寒至重，可冻结一切
- 攻防兼备，弥补了玄甲龟攻击不足的缺陷
- 但相比防御，攻击力仍然只是锦上添花

## 培养方法

### 喜好食物

| 食物种类 | 效果 | 推荐频率 |
|---------|------|---------|
| 灵草/灵果 | 基础食物，促进生长 | 每日 |
| 土属性矿石（玄铁/土晶） | 增强龟甲硬度 | 每周一次 |
| 灵泉水 | 日常饮水，不可或缺 | 每日大量 |
| 地髓/石髓 | 促进玄纹生长 | 每月一滴 |
| 龟族内丹 | 大幅提升修为 | 进化时使用 |

### 栖息环境

- **最佳环境**：有灵脉的深潭或湖底，水陆两处皆可
- **温度要求**：适应性强，但偏好温暖水域
- **巢穴**：需在潭底或山腹中开辟洞穴，铺垫灵沙
- **同伴**：玄甲龟性格温和，可与其他灵兽共处

### 培养要点

1. **耐心第一**：玄甲龟的成长极慢，需要以百年为单位来培养。性急者不适合饲养
2. **玄纹养护**：玄纹是玄甲龟的核心，需要定期以土灵力温养。可用土晶石磨粉与灵泉水混合，涂抹在龟甲上
3. **定期晒太阳**：玄甲龟虽喜水，但每日需上岸晒背一个时辰，吸收太阳精华滋养玄纹
4. **不要催熟**：强行用丹药催熟会让玄纹发育不全，反而降低上限
5. **冬眠注意**：玄甲龟每年冬季会进入长达三个月的冬眠，期间不可打扰
6. **龟甲清洁**：龟甲上的青苔和泥垢需要定期清理，否则会堵塞玄纹影响防御力
7. **防御训练**：可定期以低强度攻击轰击龟甲，刺激玄纹生长

### 注意事项

- 玄甲龟虽温和，但不可踩踏其龟甲，这是它最大的逆鳞
- 不要强迫玄甲龟做它不想做的事情——你推不动一座山的

## 与主人羁绊

### 契约方式

**共生血契**：玄甲龟寿元极长，故共生血契最为合适。此契将主人与玄甲龟的寿元绑定，共享生命，同生共死。

### 心灵感应

- 玄甲龟性格沉稳，不喜多言，但内心通透
- 主人可借助玄甲龟的感知，探查地脉走向和矿藏
- 遇险时玄甲龟会以龟甲震颤发出预警

### 忠诚度

作为长寿灵兽，玄甲龟对时间的感知与人类不同。它一旦认主，便会将其视为一生的伙伴。从人类的视角看，玄甲龟的忠诚是跨代的——许多玄甲龟在主人去世后，仍会守护主人的后代数千年。

### 特殊关系

玄甲龟以其长寿见证了无数主人的兴衰。它有一个"不吉利"的习惯——每当主人有血光之灾，玄甲龟便会提前三天不吃不喝。因此老辈修士常说："玄甲拒食，主人避祸。"

## 著名灵宠/典故

### 玄甲公

一千二百年前，天玄宗有一位名叫玄真子的长老，机缘巧合下获得一只幼年玄甲龟。玄真子为其取名"玄甲公"，倾尽毕生心血培养。玄甲公陪伴玄真子度过两次天劫，每次天劫降临时，玄甲公都以龟甲为主人挡住致命一击。后来玄真子飞升仙界，玄甲公却因修为不够无法跟上。它便一直守在天玄宗后山的寒潭中，至今仍在等待主人归来。天玄宗的弟子们世代相传，每逢月圆之夜，玄甲公会爬上山巅，朝着仙界的方向发出低沉的长鸣。

### 亀虽寿

曹操《步出夏门行》有云："神龟虽寿，犹有竟时。腾蛇乘雾，终为土灰。"所述神龟，据考便是玄甲龟一脉。玄甲龟寿元万载，却终究难逃天道轮回。然其在有生之年，稳如山岳，不动如钟，恰似大丈夫立世之品格。

### 龟甲卜卦

上古时期，先民有以龟甲卜卦的传统，所用龟甲正是玄甲龟蜕下的旧壳。玄甲龟每千年蜕甲一次，蜕下的甲壳上的玄纹天然形成卦象，蕴含天地至理。上古大能伏羲氏据龟甲玄纹参悟，画出了八卦。故玄甲龟之玄纹，实乃天地大道之具现。
