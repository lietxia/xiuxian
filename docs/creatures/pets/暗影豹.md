# 暗影豹

> 暗影豹，生于九幽之渊，长于永夜之地。通体漆黑如最深沉的夜色，在黑暗中可完全隐形。它无声无息，来去如风，一击必杀，远遁千里。在修仙界，暗影豹便是"暗杀"二字的代名词。

## 外形

暗影豹体型健硕，成年豹体长八尺至一丈二尺，肩高五尺，体态流畅优雅，每一块肌肉都蕴含着惊人的爆发力。

**体态特征：**

- **皮毛**：通体漆黑，不反光，不折射。在最明亮的光线下也只是一团模糊的黑影。皮毛短而密，触感如丝绒，却坚韧如灵甲
- **体型**：流线型的身躯，肌肉结实但不臃肿，行动时宛如黑色液体流淌
- **头部**：头部线条凌厉，吻部较短，一双琥珀色的眼眸是它全身唯一的色彩。瞳孔为竖瞳，可在极微弱的光线下视物
- **耳朵**：三角形的立耳，听觉极其灵敏。耳尖有一小撮黑色绒毛，可感知最细微的空气流动
- **四肢**：强健有力，肌肉线条分明。前爪有可伸缩的利爪，平时缩在爪鞘中行走无声，出击时弹出如黑色弯刀
- **尾巴**：与身体等长的细尾，末端微微卷曲。暗影豹在潜行时尾巴会紧紧贴住背脊，不会碰到任何物体发出声音
- **额纹**：品阶达到四级后，额头会出现一道暗紫色的神秘纹路，形如一只竖起的眼睛，名曰"暗影之眼"

**特殊形态·暗影潜行：**

当暗影豹进入潜行状态时，周身会被一层暗影之力包裹，完全融入环境之中。即使是神识扫描，也难以发现它的存在。

**气息：**

暗影豹的气息收敛能力是灵兽中的极致，它不释放任何气息。若非亲眼所见，你完全不会察觉到它就在你身边。偶尔，在它情绪波动时，会散发出一丝冰冷的杀意，令人脊背发凉。

## 血脉与进化

### 进化路线

暗影豹的血脉源自九幽深渊的暗影之力，进化之路便是不断加深与黑暗的融合。

```
暗影豹 → 幽影豹 → 暗夜豹王 → 九幽冥豹（终极形态）
```

### 进化阶段

**第一阶段·暗影豹（三级·灵兽）**
- 初生时已掌握基础的暗影潜行
- 可在月光下产生模糊的隐身效果
- 速度极快，爆发力惊人
- 利爪可撕裂下品灵甲

**第二阶段·幽影豹（四级·玄兽）**
- 皮毛完全不反光，阳光下也只能看到一团人形黑影
- 可在移动中保持隐身
- 速度翻倍，短距离冲刺可追上飞剑
- 利爪可撕裂中品灵甲
- 额头出现暗影之眼印记

**第三阶段·暗夜豹王（五级·神兽）**
- 可完全融入任何阴影，包括敌人的影子
- 可在影子之间瞬移
- 攻击时附带暗影腐蚀之力，伤口难以愈合
- 可操控方圆十丈内的阴影攻击敌人
- 灵智完全成熟，可设下复杂的伏击计划

**终极形态·九幽冥豹（七级·仙兽）**
- 通体化为一团流动的黑暗，不再有实体形态
- 可穿梭于阴阳两界
- 攻击时附带幽冥之力，中者魂魄受损
- 可召唤九幽深渊的暗影兽群
- 传说中曾刺杀过真仙

### 进化条件

| 阶段 | 关键条件 | 辅助资源 |
|------|---------|---------|
| 暗影→幽影 | 三百年修为 + 在黑暗中潜行万里 | 暗影珠一枚 |
| 幽影→豹王 | 千年修为 + 刺杀一名修为高于自己的对手 | 暗影精华十滴 |
| 豹王→幽冥 | 三千年修为 + 赴九幽深渊沐浴暗影本源 | 幽冥石一块 |

## 天赋神通

### 神通一：暗影潜行

暗影豹核心神通，将自身融入阴影之中。

- 静止状态下完全不可见，神识也无法扫描（消耗极低，可无限维持）
- 移动时会产生极轻微的气流波动，但极难察觉（移动速度降至七成，以换取消音效果）
- 可潜入敌人的影子中移动——敌影到哪里，暗影豹就能跟到哪里
- 暗夜豹王阶段，可在影子之间瞬移，一息之内跨越百丈
- 九幽冥豹阶段，可在阴阳两界的缝隙中穿行
- 暗影潜行状态下，暗影豹无法发动攻击（一旦攻击则显形）
- 破除暗影潜行的方法：大范围光属性法术（如烈日术）、超高密度神识扫描（元婴期以上修士方可做到）、某些特殊灵兽的嗅觉（如寻宝鼠的天嗅通）

暗影豹是唯一一种能在元婴期修士眼皮底下潜行的灵兽。曾有元婴期修士被一只幽影豹跟踪了三天，毫无察觉。

### 神通二：暗影刺杀

暗影豹的必杀技，从阴影中发动致命一击。

- 攻击时从阴影中现出实体，速度在瞬间提升五倍
- 利爪上附带暗影腐蚀之力，伤口无法以常规手段愈合（需要光系或神圣系治疗法术方可止血）
- 一击不中，立即远遁，绝不恋战——这是暗影豹的生存铁律
- 攻击部位选择极为精准：咽喉、后心、丹田。每一处都是致死要害
- 暗夜豹王阶段，可同时从三个方向发动攻击，令敌人防不胜防
- 消耗：灵力一成（蓄力一击），冷却时间三十息
- 此神通的伤害取决于暗影豹与目标的修为差距——若目标修为高出两个大境界，则刺杀成功率骤降至不足一成

暗影豹的刺杀哲学是："一击必杀，杀不了就走。"

### 神通三：暗影之息（被动技）

暗影豹天生不带任何气息波动的天赋。

- 收敛气息的能力凌驾于一切灵兽之上
- 情绪波动时仅散发一丝极淡的杀意，可被高修为修士感知，但无法定位
- 受伤流血时，血液会在离体瞬间化为暗影消散，不留下任何气味
- 此被动技能使暗影豹成为修仙界最完美的跟踪者

### 神通四：暗影领域

暗夜豹王专属神通，将战场转化为自己的主场。

- 释放暗影之力，将方圆百丈化为永夜（持续一炷香，消耗五成灵力）
- 领域内一切光源都会被吞噬（包括火系法术、发光法宝、甚至天光）
- 暗影豹在领域内速度再提升三成，恢复能力翻倍
- 敌人失去视觉，神识也被压制到正常范围的三成
- 领域内可召唤暗影触手纠缠敌人，触手持续三十息
- 冷却时间：两个时辰
- 领域弱点：在空旷无影的沙漠或极昼之地，暗影领域持续时间缩短一半

### 神通五：幽冥穿梭（九幽冥豹专属）

九幽冥豹的终极神通，可短暂进入幽冥界。

- 进入幽冥界后完全与现世隔离，不受任何攻击
- 可在幽冥界中行走，观察现世而不被发现
- 从幽冥界突然现身发动致命一击——这是真正的防不胜防
- 此神通极其消耗本源，一日最多使用一次，每次不超过三十息
- 使用后九幽冥豹会陷入三日的虚弱期，实力降至六成
- 传说中，曾有九幽冥豹以此神通刺杀了半仙之体的大能，震惊修仙界

## 培养方法

### 喜好食物

| 食物种类 | 效果 | 推荐频率 |
|---------|------|---------|
| 妖兽鲜肉（最好是活的） | 基础食物，维持体能 | 每日 |
| 暗属性灵果（暗影果/幽冥果） | 提升暗影亲和力 | 每周一次 |
| 妖兽精血（越强越好） | 增强血气，提升爆发力 | 每月一次 |
| 暗影珠碎片 | 加速血脉进化 | 每月一小块 |
| 纯净水 | 饮水 | 每日 |

### 栖息环境

- **最佳环境**：永不见光的洞穴、密林深处
- **巢穴**：布置有多层帷幕的暗室，地面上铺以黑曜石
- **活动范围**：喜欢在夜间活动，白天沉睡
- **灵脉要求**：暗属性灵脉或阴属性灵脉

### 培养要点

1. **夜间训练**：暗影豹的所有训练都应在夜间进行，日间是它的休息时间
2. **狩猎训练**：从小训练捕猎技巧，从猎物到妖兽逐步升级
3. **潜行练习**：在密林中设置障碍和陷阱，让暗影豹练习无声通过
4. **暗杀实战**：成长到一定程度后，可接一些铲除妖兽的任务让暗影豹实战
5. **信任第一**：暗影豹天性多疑，需要较长时间的相处才能建立信任
6. **不要关笼**：暗影豹绝不接受被关在笼子里，否则会自残
7. **定期磨爪**：提供硬木或铁桩供其磨砺利爪

### 饲养禁忌

- 暗影豹极度厌恶强光，不要强迫它在白天活动
- 不可以链子拴它，它宁死不受束缚
- 不要将暗影豹与其他灵兽混养——它会把它们都当成猎物
- 暗影豹吃醋极重，主人若当它的面摸别的灵兽，它会离家出走

## 与主人羁绊

### 契约方式

**暗影血契**：在月黑风高之夜，以主人精血在暗影豹额头绘制暗影之眼印记。暗影豹信任一个人极难，此契约必须建立在深厚的感情基础上，不可强迫。

### 心灵感应

- 暗影豹可通过影子与主人沟通
- 战斗时无需语言，一个眼神暗影豹便知道该攻击哪个目标
- 暗影豹对主人的杀意极其敏感，主人心中闪过一丝杀机，它便已冲了出去

### 忠诚度

暗影豹的忠诚是"你给我信任，我还你性命"式的。它极难认主，但一旦认主，便生死相随。如果你信任它，它会为你赴汤蹈火；如果你怀疑它，它会头也不回地离开。暗影豹的主人必须是一个没有秘密的人——因为在暗影豹面前，一切都无所遁形。

### 特殊关系

暗影豹喜欢在主人睡觉时守在床边，隐身于房间的阴影中。主人若是做噩梦，它会跳上床，用头蹭蹭主人。第二天早上你只会觉得枕头边有一团黑色的毛球——然后发现那是你的暗影豹，正睡得四仰八叉，完全没有平日里暗影之王的威风。

## 同类对比

### 暗影豹 vs 雷鹰

- **昼与夜的对决**：雷鹰统治白昼的天空，暗影豹统治黑夜的大地。若在黄昏相遇，胜负难料
- **战斗风格**：雷鹰正面轰击，光明正大；暗影豹背刺偷袭，诡异莫测
- **属性克制**：雷鹰的雷电自带光芒，可照亮暗影豹的潜行，但暗影豹若先手发动袭击，雷鹰根本没有反击的机会
- **环境依赖**：暗影豹对环境的依赖远大于雷鹰——没有阴影的地方，它就废了一半
- **战略价值**：雷鹰适合大规模战场和正面冲突；暗影豹适合斩首行动和情报任务

### 暗影豹 vs 碧鳞蛇

- **暗杀 vs 毒杀**：两者都是"一击制敌"的类型。暗影豹追求物理上的秒杀，碧鳞蛇追求毒性的慢慢侵蚀
- **追踪能力**：暗影豹靠视觉和听觉追踪，碧鳞蛇靠热感和气味追踪。在完全黑暗的环境中，碧鳞蛇的蛇信探测比暗影豹的视觉更可靠
- **隐蔽性**：暗影豹的潜行碾压碧鳞蛇。碧鳞蛇的毒雾会暴露它的位置——暗影豹不会犯这种错误
- **培养风险**：暗影豹一旦认主忠心耿耿；碧鳞蛇天性阴冷，随时有反噬风险

### 暗影豹 vs 噬金虫

- **刺客 vs 军团**：暗影豹是单人精锐，噬金虫是人海战术。前者负责精确清除目标，后者负责战场覆盖
- **生存能力**：单只暗影豹的生存能力远超单只噬金虫，但噬金虫群无穷无尽
- **情报能力**：暗影豹潜入刺探信息的能力远超噬金虫。噬金虫虽然有庚金共鸣可探测金属，但无法像暗影豹那样潜伏在敌人身边偷听
- **战术配合**：这是一个令人胆寒的组合——暗影豹潜入斩杀敌方首领，噬金虫虫潮淹没敌方军团

## 著名灵宠/典故

### 黑影

五百年前，修仙界出现了一位神秘的刺客，人称"影杀"。他从不在白日现身，每次出手都在深夜。被他盯上的目标，活不过三天。后来人们才知道，影杀的身边有一只暗影豹，名为"黑影"。影杀与黑影配合无间，一人一豹在黑夜中完成了近百次刺杀任务，从未失手。据说影杀晚年解散了杀手组织，带着黑影隐居深山。有人曾在深山中见过一个老人和一头黑豹在月光下散步，彼时暗影豹已经老得走不动了，老人便背着他走。

### 暗影之王

传说在九幽深渊的最深处，沉睡着一头上古级别的九幽冥豹，被称为"暗影之王"。它是所有暗影豹的始祖，也曾是某位上古大能的灵宠。那位大能陨落后，暗影之王便回到了九幽深渊，陷入永眠。传说当它醒来之时，便是天地大劫降临之日。每一只暗影豹的潜意识里都回荡着暗影之王的呼唤——那是来自血脉深处的召唤。

### 永夜追踪

据《驭兽秘录》记载，某次一个中型宗门得罪了一位御兽大师。那位大师什么都没说，只是放出了自己的暗影豹。七天后，那个宗门的宗主在重重护卫的密室中被发现——喉咙被切开了一个整齐的口子，没有发出任何声音。密室的门窗完好无损，所有护卫都没有发现任何异常。从此以后，再没有人敢招惹那位御兽大师。而那只暗影豹，也成为修仙界传说中最令人恐惧的灵宠之一。

### 月下之约

天玄宗的一位女修在秘境中偶遇一只受伤的暗影幼豹。她没有像其他修士那样试图捕获或杀死它，而是为它包扎伤口，留下食物后便离开了。三年后，女修在一次外出历练中被仇家追杀至绝境。危急关头，一道黑影闪过——她的三个仇家在瞬间倒地，喉咙各有一道整齐的切口。女修惊魂未定，看到月光下立着一头优雅的黑豹，额头上暗紫色的暗影之眼印记闪烁。黑豹看了她一眼，转身消失在阴影中。此后女修的洞府外时常出现猎物的尸体，却从不见送礼者。直到五十年后女修渡元婴劫时力竭，一头巨大的暗影豹从夜色中现身，以自身灵力助她渡劫成功。劫云散去后，暗影豹虚弱地卧在她脚边，喉咙里发出咕噜咕噜的声音。女修这才认出——这就是当年那只幼豹。她给它取名"夜歌"，从此一人一豹再不分离。
