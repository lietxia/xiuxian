# 暗影豹

> 暗影豹者，暗夜之猎手也。通体漆黑如墨，双目幽绿如鬼火，行走于阴影之中，无声无息。它是最优秀的刺客型灵宠——在你看到它之前，你已经死了。暗影豹天生掌握暗属性灵力，可遁入任何阴影，从敌人最意想不到的角度发起致命一击。

## 外形

暗影豹体型修长矫健，肩高约四尺，体长丈余，通体漆黑如最深沉的夜色。

**体态特征：**

- **皮毛**：全身覆盖短而密的黑色皮毛，在月光下泛出紫黑色金属光泽。皮毛可吸收光线，使其在黑暗中几乎完全隐形
- **斑纹**：身上有隐约可见的暗紫色斑纹，只有在高速移动时才显现，如同暗夜中的闪电
- **眼睛**：一双竖瞳呈幽绿色，夜间发出冷冽荧光，可在完全黑暗中视物
- **爪牙**：四爪锋利如弯刀，可自由伸缩，爪尖含有微量麻痹毒素。犬齿长而弯曲，可一口咬断猎物咽喉
- **尾巴**：尾长近丈，尾尖有一簇长毛，可在跳跃时调节平衡
- **肉垫**：足底肉垫厚实柔软，行走时毫无声息

**气息：** 暗影豹气息极为内敛，可完全收敛灵力波动，如同普通野兽。但杀意爆发时，周身会散发出令人毛骨悚然的阴冷气息。

## 血脉与进化

**血脉溯源：** 暗影豹是上古神兽"幽冥豹"的后裔。幽冥豹是冥界的守护兽，负责追捕逃逸的亡魂。暗影豹继承了幽冥豹的暗属性天赋和猎杀本能。

**进化路线：** 暗影豹 → 暗纹豹 → 幽冥豹 → 幽冥暗豹（终极）

## 天赋神通

### 神通一：影遁术

暗影豹的核心天赋，可融入任何阴影之中，实现瞬间移动和完美隐匿。

- 可在方圆百丈内的任意两个阴影之间瞬移
- 融入阴影后完全隐匿气息，金丹期以下修士无法察觉
- 在阴影中停留时间越长，下一次攻击的威力越大（最多蓄力三倍伤害）
- 强光可破解影遁，使其被迫现形

### 神通二：暗影突袭

暗影豹从阴影中暴起发难，对敌人发动致命一击。

- 突袭速度极快，同阶修士往往来不及反应
- 第一击附带"暗蚀"效果，可腐蚀护体灵光
- 若击中要害，可造成双倍伤害
- 每次影遁后只能发动一次突袭，之后需重新隐匿

### 神通三：暗夜领域

暗影豹释放暗属性灵力，在周围制造一片黑暗领域。

- 领域范围内光线被完全吞噬，敌人陷入致盲状态
- 暗影豹在领域中移动速度和攻击力大幅提升
- 领域持续约一炷香时间，需消耗大量灵力
- 冷却时间：一日最多使用两次

### 神通四：幽冥爪（幽冥豹专属）

进化至幽冥豹后觉醒的终极攻击神通。

- 爪击附带幽冥之力，可直接伤害魂魄
- 被幽冥爪击中的敌人，伤口难以愈合，会持续流失生命力
- 对鬼修和灵体生物有额外伤害加成
- 每次使用后需休息三日方可再次使用

## 培养方法

### 喜好食物

| 食物 | 效果 | 推荐度 |
|------|------|-------|
| 暗夜蝙蝠 | 基础食物，维持暗灵力 | ⭐⭐⭐⭐ |
| 影狼肉 | 提升速度和敏捷 | ⭐⭐⭐⭐ |
| 暗灵草 | 促进暗属性灵力增长 | ⭐⭐⭐⭐⭐ |
| 幽魂花 | 促进进化 | ⭐⭐⭐⭐⭐ |

### 栖息环境

- **最佳环境**：密林深处、山洞、废弃建筑
- **光照要求**：喜暗厌光，白天多睡觉，夜间活动
- **温度**：适应性强，但偏好阴凉环境
- **领地意识**：每只暗影豹需要至少方圆十丈的独立空间

### 培养要点

1. **夜间训练**：暗影豹在夜间最为活跃，训练应在夜间进行
2. **阴影丰富**：栖息处需有充足的阴影供其练习影遁
3. **不可强光**：避免让暗影豹长时间暴露在强光下，会损伤其暗属性天赋
4. **猎杀本能**：定期让暗影豹自由猎杀，保持其野性和战斗力

## 与主人羁绊

### 契约方式

**暗影血契**：在午夜时分，以主人精血在暗影豹额头绘制契约符文。此契需在完全黑暗中进行，任何光线都会导致契约失败。

### 心灵感应

- 暗影豹与主人之间通过暗属性灵力建立联系
- 主人可在黑暗中通过暗影豹的视角观察环境
- 暗影豹会主动预警周围的危险，通过低吼和肌肉紧绷传递信息

### 忠诚度

暗影豹性格孤傲，一生只认一个主人。它不会像狗一样摇尾乞怜，但会在主人遇到危险时毫不犹豫地挡在前面。暗影豹表达忠诚的方式是——把自己的猎物放在主人脚边。

---

## 使用限制

- **光属性克制**：光属性法术对暗影豹伤害加倍，可破解影遁
- **日间虚弱**：白天暗影豹的实力下降三成
- **强光致盲**：突然的强光会使暗影豹短暂失明
- **群体作战**：暗影豹擅长单体刺杀，不擅长面对多个敌人

## 著名灵宠/典故

### 夜杀三千里

据《暗兽志》记载，两千年前有一位号称"夜君"的杀手，座下暗影豹已进化至幽冥之境。夜君凭借暗影豹的影遁之术，曾在一夜之间穿越三千里，连杀七名金丹期修士，全身而退。此事震动修仙界，暗影豹也因此被列为"危险灵宠"。

### 幽冥豹传说

上古传说中，幽冥豹是冥界之主座下的神兽，负责在阴阳两界之间巡逻。它的一只眼睛看阳间，一只眼睛看阴间，任何亡魂都逃不过它的追捕。暗影豹作为其后裔，据说也保留着感知亡魂的能力。

## 同类对比

### 暗影豹 vs 风刃豹

两者俱为豹类妖兽，但战斗风格迥异：

- **战斗方式**：暗影豹偏隐匿刺杀，一击必杀；风刃豹偏正面强攻，以风刃压制
- **属性**：暗影豹主暗属性，风刃豹主风属性
- **速度**：风刃豹直线速度更快，暗影豹短距离瞬移更灵活
- **适用场景**：暗影豹适合暗杀和侦察，风刃豹适合正面战斗

### 暗影豹 vs 玉面狼

- **体型**：暗影豹体型更大，玉面狼体型中等
- **群居性**：玉面狼群居，暗影豹独居
- **攻击方式**：暗影豹靠突袭和暗蚀，玉面狼靠群体围攻和撕咬
- **驯服难度**：暗影豹极难驯服，玉面狼相对容易
