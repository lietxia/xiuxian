# 寻宝鼠

> 寻宝鼠，天地异种，以寻宝为天职。其嗅觉之灵敏，可穿透岩层百丈，感知深埋地下的灵脉矿藏。一双乌溜溜的小眼睛，专识人间至宝。修仙界有句话："宁舍一把飞剑，不换一只寻宝鼠。"

## 外形

寻宝鼠体型小巧，成年体长约六寸，尾长与体长相仿。全身皮毛呈淡金色，腹部为乳白色。

**体态特征：**

- **体型**：娇小玲珑，可轻松立于人的掌心。体重不过二两
- **毛发**：背毛淡金色，在光线下泛着柔和的金属光泽。腹部乳白，触感如丝绸
- **鼻子**：寻宝鼠最标志性的器官——粉红色的鼻头永远在微微翕动，即使睡觉时也在下意识地嗅探。鼻头湿润，触感冰凉
- **胡须**：两撇长长的银色胡须，是它的"天线"，可感知微弱的灵气波动
- **眼睛**：乌黑明亮，圆溜溜的，如同两颗黑曜石。眼神灵动，透着几分狡黠
- **耳朵**：小而圆，薄如蝉翼，可捕捉到地底深处的细微声音
- **尾巴**：与身体等长的细尾，无毛，粉红色，用于保持平衡
- **前爪**：极其灵巧，可像人类的手一样抓握物品

**气息：**

寻宝鼠没有任何攻击性的气息，反而有一种淡淡的、类似灵草晒干后的清香。它出现的地方，往往意味着附近有好东西。

## 血脉与进化

### 进化路线

寻宝鼠的进化路线是一条从寻宝到"盗天机"的奇诡之路，最终形态的偷天鼠据说连天道气运都能偷。

```
寻宝鼠 → 灵嗅鼠 → 寻宝灵鼠 → 偷天鼠（终极形态）
```

### 进化阶段

**第一阶段·寻宝鼠（一级·妖兽）**
- 初生即可嗅到方圆十丈内的灵物气息
- 主要寻找地面以上的灵草和散落的灵石
- 灵智不高，容易被美食诱惑
- 是最常见的寻宝鼠形态

**第二阶段·灵嗅鼠（二级·妖兽）**
- 嗅觉范围扩展至方圆百丈
- 可穿透岩层一丈，感知地下矿脉
- 可分辨三千种以上的灵物气息
- 灵智提升，可理解主人大部分指令
- 前爪更加灵活，可为主人取来小物件

**第三阶段·寻宝灵鼠（三级·灵兽）**
- 嗅觉范围扩展至方圆十里
- 可穿透岩层百丈，感知深埋地下的上古遗迹
- 能嗅到禁制和陷阱的气息，帮助主人规避危险
- 灵智完全开启，可与主人讨价还价
- 身上开始散发淡淡的金光，夜晚可见

**终极形态·偷天鼠（六级·圣兽）**
- 嗅觉可达百里之外，穿透一切障碍
- 不仅能寻宝，还能"嗅到"气运和机缘
- 传说中连天道运转的漏洞都能感知
- 可化形为七八岁的机灵孩童，瘦小精悍
- 但因太过逆天，极易招惹天劫

### 进化条件

| 阶段 | 关键条件 | 辅助资源 |
|------|---------|---------|
| 寻宝鼠→灵嗅鼠 | 嗅探超过一万件灵物 | 灵嗅果一枚 |
| 灵嗅鼠→寻宝灵鼠 | 找到至少一件上古宝物 + 三百年修为 | 开灵丹一枚 |
| 寻宝灵鼠→偷天鼠 | 找到一件逆天级别的至宝 + 渡偷天劫 | 天道碎片（极其罕见） |

## 天赋神通

### 神通一：天嗅通

寻宝鼠的核心天赋，嗅觉能力远超一切修仙者的认知。

- 能嗅到灵气浓度最细微的差异，从而定位灵脉走向（精确到三丈之内）
- 能分辨不同灵草之间的气息，哪怕是长在千丈深的绝地之中
- 能闻出禁制的"气味"，许多上古禁制在触发前都会散发出微弱的气息波动
- 甚至能嗅到人心中的"贪念"——如果有人想抓它，它会提前跑掉
- 寻宝鼠的鼻子在进化至灵嗅鼠后，可同时追踪上百种气味而不混乱
- 天嗅通自动生效，无需消耗灵力，但嗅探到浓烈毒瘴区域时鼻子会打喷嚏示警

曾有寻宝鼠在拍卖会上，隔着三个包厢嗅到斜对面修士怀里揣着一株万年血参，当场扑过去不撒手。

**局限性**：天嗅通对超出了解范围的宝物无效（如从未见过的上古异宝），且若宝物被封印在隔绝气息的法阵中，寻宝鼠也无能为力。

### 神通二：灵眼识珍

寻宝鼠的双眼能看穿伪装和障眼法，识别宝物的真伪。

- 任何伪装和幻术在它面前都无所遁形（品阶差距过大者除外，如大乘期修士的幻术）
- 能看出法宝的真实品阶，不被表面的灵光所迷惑
- 能鉴别古董法器的年代和来历，误差不超过五十年
- 对赝品的嗅觉尤其敏锐——假货在它眼里就像暗夜中的萤火虫一样刺眼
- 消耗微量灵力，可持续开启，但连续使用三个时辰后视觉会疲劳

修仙界的古董商贩，见寻宝鼠如见阎王。因为这小东西进店逛一圈，哪个是真货哪个是假货，全写在它脸上。

### 神通三：遁地潜行（寻宝灵鼠专属）

进化至寻宝灵鼠后，可在土地中自由穿行。

- 在土中潜行如游鱼入水，速度极快（约为在地面奔跑速度的七成）
- 可携带主人一同遁地，但消耗极大——每带一人灵力消耗翻三倍
- 能在岩层中开辟出一条临时通道，宽度可容一人通过
- 逃跑时往地下一钻，谁都抓不住
- 消耗灵力两成，可在土中持续潜行半个时辰
- 冷却时间：无，但一旦灵力耗尽便会卡在岩石中，需主人救援
- 不可穿过灵脉核心或禁制加固的地层

### 神通四：灵气共振（寻宝灵鼠专属·定位技）

以自身灵力与周围天材地宝产生共鸣，通过回音判断宝物方位。

- 发出无声的灵力波动，如同蝙蝠超声波一般探测周边环境
- 可在漆黑的洞穴或迷雾中使用，替代视觉
- 能感知三十丈内的地形轮廓，包括隐藏的暗门和密室
- 对矿物类宝物的定位最为精准，对活物类（灵草灵果）则稍逊
- 消耗极低，几乎可常时开启
- 需要注意的是——灵力波动也可能被强大妖兽感知到，从而暴露位置

### 神通五：盗天机（偷天鼠专属）

偷天鼠的终极神通，已超越寻宝范畴。

- 可预感到即将出世的宝物时间和地点，误差不超过三日
- 能"嗅到"一个人的气运强弱，知晓对方最近是否有机缘
- 可感知天道运势的流转方向——"哪里有宝贝即将出土，哪里有机缘正在酝酿"
- 传说中可偷取天道的一缕气运转嫁到主人身上
- 但每次使用都会折寿（偷天鼠的寿命会缩短百年），且会引来天道惩罚
- 冷却时间：十年。神通用后偷天鼠会陷入长达数月的沉睡
- 天劫惩罚：每一次盗天机都会引来一次小型天劫，九次之后天劫强度暴涨十倍

偷天鼠在修仙史上只出现过五次，其中四只都在渡劫中化为飞灰，只有一只活了下来——而那一位的结局至今无人知晓。

## 培养方法

### 喜好食物

| 食物种类 | 效果 | 推荐频率 |
|---------|------|---------|
| 灵谷/灵米 | 基础食物 | 每日 |
| 松子/核桃（灵果） | 嗜好之物 | 每日少量 |
| 小块灵石（下品即可） | 补充灵力 | 每周一块 |
| 灵泉蜂蜜 | 改善嗅觉灵敏度 | 每月一次 |
| 珍稀灵物（观摩即可） | 虽不吃，但看看就开心 | 找到后给它看看 |

### 栖息环境

- **最佳环境**：温暖干燥的巢穴，铺以柔软的天蚕丝
- **巢穴**：寻宝鼠喜欢收集闪闪发光的小物件，所以它的窝里常有一堆亮晶晶的"藏品"
- **活动范围**：需要较大的活动空间，每天至少放出活动两个时辰
- **同伴**：不建议与其他灵兽同养，尤其是猫科和蛇类

### 培养要点

1. **寻宝训练**：定期在院子里埋下灵石让寻宝鼠练习寻找，找到后要给予奖励
2. **奖励机制**：寻宝鼠是典型的"给块糖就干活"的性子，找到宝物后分它一点甜头，下次会更卖力
3. **防止偷窃**：寻宝鼠有偷窃癖，看到亮晶晶的小东西就想搬回自己的窝，要注意看管储物袋
4. **不要苛责**：若是寻宝鼠带错了路，不要打骂，它会记恨在心，下次故意带你绕远路
5. **安全第一**：寻宝鼠体质脆弱，前往危险地域时要把它放在灵兽袋里
6. **宝物上缴**：寻宝鼠找到的宝物归主人所有，但最好给它留一两件小东西当"玩具"

### 饲养禁忌

- 不可在寻宝鼠面前放置大块未经切割的宝石——它会发疯般地试图搬回窝
- 不可长时间把寻宝鼠关在笼子里，它会抑郁到不吃不喝
- 寻宝鼠有"认主不认亲"的特性——你的好朋友来借它寻宝，它理都不理
- 不可在寻宝鼠面前故意把宝物藏起来又拿走——它会认为你戏弄它，记仇数月

> 寻宝鼠的价值不在战力，而在它那独一无二的寻宝天赋。修仙界有句话说得好："战力型灵宠让你活下来，寻宝鼠让你活得好。"

## 同类对比

### 寻宝鼠 vs 噬金虫

- **寻宝能力**：寻宝鼠的寻宝能力碾压噬金虫。噬金虫只能感知金属，寻宝鼠可感知一切天材地宝
- **防御力**：噬金虫防御无双，寻宝鼠一碰就碎
- **战斗价值**：噬金虫是战场杀器，寻宝鼠是后勤宝贝
- **培养成本**：寻宝鼠吃几颗灵果就满足，噬金虫吃金属如无底洞
- **结伴出行**：寻宝鼠进遗迹寻宝，噬金虫护法——这是修仙界最经典的组合之一

### 寻宝鼠 vs 玉兔

- **寻宝 vs 炼丹**：寻宝鼠擅长寻找天材地宝的原矿和野生灵药，玉兔则擅长辨认成熟灵草和辅助炼丹
- **智慧程度**：寻宝鼠机灵狡黠，常跟主人耍心眼；玉兔温顺乖巧，从不捣蛋
- **战斗能力**：两者都不善战，但玉兔有一项寻宝鼠没有的天赋——它的毛发可入药，是制作多种灵丹的辅料
- **性格对比**：寻宝鼠是"给好处才干活"的实用主义者；玉兔是"只因喜欢你"的理想主义者

### 寻宝鼠 vs 冰蚕

- **价值取向**：寻宝鼠提供的是信息价值（找到宝物），冰蚕提供的是材料价值（吐丝结茧）
- **风险系数**：寻宝鼠几乎没有危险；冰蚕饲养极为挑剔，环境稍有不适便死
- **赚钱效率**：寻宝鼠找到一件宝物可能一夜暴富；冰蚕稳定产出，年年有进账
- **哪个更好**？——看你是想一夜暴富还是细水长流

## 与主人羁绊

### 契约方式

**美食契约**：寻宝鼠不需要复杂的血契魂契，用美食就能收买它的心。给它取个名字，每天喂它爱吃的灵果，它自然会把你当成"长期饭票"。若想要更稳固的关系，可在它吃饱喝足时顺势种下一缕简单的灵魂印记。

### 心灵感应

- 寻宝鼠找到宝物时，会用爪子抓主人的手指，示意"跟我来"
- 它对危险也有预感，若是前方有陷阱，它会咬着主人的裤脚不让走
- 开心时会发出吱吱的叫声，在主人肩膀上蹦来蹦去

### 忠诚度

说句实在话——寻宝鼠的忠诚度约等于你口袋里灵石的厚度。它不会背叛你，但如果有人拿出更美味的灵果，它会犹豫那么一小会儿。不过真到了生死关头，它还是会选择跟主人一起跑路的。

### 特殊关系

每个寻宝鼠都有自己的"小金库"。它们会偷偷把主人赏赐的小灵石小宝石藏在窝里的某个角落。当主人真的穷困潦倒时，寻宝鼠会一脸肉疼地把它的小金库拖出来给主人——大概相当于把存了一辈子的压岁钱都掏出来了。

## 著名灵宠/典故

### 金鼻子

三百年前，北域有一位名叫"金宝真人"的元婴期散修，筑基期时机缘巧合获得一只寻宝鼠，取名"金鼻子"。这只寻宝鼠带他找到了三座大型灵石矿脉、两处上古遗迹和无数天材地宝。金宝真人原本只是一个资质平平的散修，硬是靠寻宝鼠堆出来的资源修到了元婴期。他晚年写了一本《寻宝心得》，开篇第一句便是："吾一生所得，九成归功于吾的鼻子。"

### 鼠王宝藏

传说在十万大山的深处，有一座鼠王城，是无数代寻宝鼠积累的宝藏。每一只寻宝鼠在弥留之际，都会本能地前往这座地下城，将自己一生收集的宝物留在那里。千百年来，这座地下宝藏的规模已不可想象。曾有无数修士试图寻找鼠王城，但至今无一人成功。因为寻宝鼠自己就是最好的藏宝者——它们藏的宝藏，连同类都找不到。

### 偷天鼠的传说

上古时期有一位名为"空空道人"的大能，他的灵宠便是一只偷天鼠。据传空空道人靠偷天鼠盗取了天道的一缕气运，借此渡劫飞升。但偷天鼠也因此遭到天谴，化为飞灰。空空道人飞升前留下一句话："盗天机者，天亦盗之。"意思是偷天道的东西，天道迟早会连本带利地讨回去。这成为后世所有御鼠师代代相传的警训。

### 寻鼠记

五百年前，北域有一对筑基期的散修夫妇，在山中救下一只受伤的寻宝鼠。夫妇二人悉心照料三月，寻宝鼠伤愈后竟不愿离去。夫妇本无大志，只求安稳修炼，却不想这只寻宝鼠隔三差五便从山里叼回灵石和灵草放在门口。三年间，靠着寻宝鼠的"供奉"，夫妇二人竟攒够了冲击金丹的资源。后来丈夫感慨道："我夫妇修行数十载，所获不及这只小老鼠三年之功。"他给寻宝鼠取名"转运"，视若亲子。此事在北域传为佳话，也令无数散修动了寻一只寻宝鼠的念头。
