# 冰蚕

> 冰蚕，生于万年玄冰之下，长于极北寒冰之中。通体晶莹如冰雪，吐丝成缕，至寒至坚。冰蚕丝织就的灵甲，轻如蝉翼，坚胜金刚，乃修仙界所有炼器师梦寐以求的至宝灵材。而冰蚕本身，亦是极为难得的辅助型灵宠。

## 外形

冰蚕通体半透明，如冰晶雕琢而成，长约三寸，粗如成人拇指。

**体态特征：**

- **体色**：通体透明至乳白色，体内隐约可见淡蓝色的内脏。修为越高，体色越透明，至高级阶段几乎完全隐形
- **体型**：肥硕而柔软，体表有环形节纹，每节之间镶有一道银白色的冰纹
- **头部**：头部较小，有一对深蓝色的复眼，如同两颗蓝宝石。口器中有一根细如发丝的吐丝管
- **触角**：一对细长的银白色触角，用于感知温度和气流
- **足**：腹部有八对短足，末端有吸盘，可在冰面垂直攀爬
- **吐丝器**：位于口器下方，可喷出细如蛛丝却坚韧无比的冰蚕丝
- **休眠形态**：结茧后化为冰白色的蚕茧，表面覆盖着霜花般的纹路

**气息：**

冰蚕周身散发出极寒之气，靠近它便会感到刺骨的寒意。它所在之处，温度会比周围低上十度。进食时，冰蚕会呼出一口白雾状的寒气，令人如坠冰窟。

## 血脉与进化

### 进化路线

冰蚕的进化之路，是一场从极寒到极致的蜕变。

```
冰蚕 → 寒冰蚕 → 冰玉蚕 → 玄冰天蚕（终极形态）
```

### 进化阶段

**第一阶段·冰蚕（二级·妖兽）**
- 初生时乳白色，长约一寸
- 可吐下品冰蚕丝，坚韧堪比凡铁
- 喜食冰属性灵草，畏火
- 灵智低下，凭本能行动

**第二阶段·寒冰蚕（三级·灵兽）**
- 体色转为半透明，冰纹显现
- 所吐冰蚕丝韧性堪比下品灵器级布料
- 可喷出寒气攻击来犯之敌
- 灵智开启，可认主
- 一年吐丝一次，每次一丈

**第三阶段·冰玉蚕（四级·玄兽）**
- 通体如冰玉，晶莹无瑕
- 所吐冰蚕丝堪比上品灵器级布料，水火不侵
- 寒气可冰冻筑基期修士
- 三月吐丝一次，每次三丈
- 灵智不输人类五六岁孩童

**终极形态·玄冰天蚕（六级·圣兽）**
- 体色完全透明，肉眼几乎不可见
- 所吐冰蚕丝堪比仙器级布料，至寒至坚
- 寒气所至，可冰封百里
- 可化形为一袭白衣的冷艳少女
- 一月吐丝一次，每次十丈，丝线中蕴含一丝太阴真冰之力

### 进化条件

| 阶段 | 关键条件 | 辅助资源 |
|------|---------|---------|
| 冰蚕→寒冰蚕 | 三百年修为 + 吸收千年玄冰之气 | 冰灵珠一枚 |
| 寒冰蚕→冰玉蚕 | 千年修为 + 太阴真水三滴 | 万年玄冰一块 |
| 冰玉蚕→玄冰天蚕 | 三千年修为 + 渡寒劫 | 太阴本源一缕 |

## 天赋神通

### 神通一：冰丝吐纳

冰蚕核心天赋，以体内寒气凝结灵力，吐出坚韧无比的冰蚕丝。

- 冰蚕丝纤细如发丝，但坚韧度远超同等粗细的钢丝
- 一条成年的寒冰蚕所吐丝线，可吊起千斤重物而不断
- 冰蚕丝天然蕴含极寒之力，织成衣物可抵御烈焰焚烧
- 冰蚕丝是炼制防御灵甲的最佳材料之一
- 丝线带有麻痹效果，被冰蚕丝缠绕的敌人会感到肢体僵硬

冰蚕丝的品阶分为：下品（冰蚕）、中品（寒冰蚕）、上品（冰玉蚕）、极品（玄冰天蚕）。

### 神通二：寒冰领域

冰蚕释放体内寒气，在周身形成一片寒冰领域。

- 领域内温度骤降至零下百度
- 修为不足者进入领域，血液都会凝固
- 能在领域内召唤冰锥、冰墙攻击
- 冰蚕在领域内恢复速度加倍

### 神通三：冰茧重生

冰蚕的保命神通，在重伤时可结冰茧进入假死状态。

- 结茧后防御力提升十倍，外物难以破坏
- 在茧中缓慢修复伤势，破茧后完好如初
- 一年最多使用一次，每次持续三至七日
- 相当于一条额外的性命

### 神通四：万里冰封（玄冰天蚕专属）

玄冰天蚕的终极神通，一念之间冰封千里。

- 可瞬间冻结一座湖泊
- 可将一座山峰变为冰山
- 威力堪比大乘期冰系法术
- 但使用后玄冰天蚕会进入虚弱期，需要休养数月

## 培养方法

### 喜好食物

| 食物种类 | 效果 | 推荐频率 |
|---------|------|---------|
| 冰属性灵草（寒冰草/雪灵芝） | 基础食物 | 每日 |
| 玄冰碎片 | 促进冰纹生长 | 每周一块 |
| 太阴真水 | 大幅提升寒气品质 | 进化时使用一滴 |
| 雪莲/冰晶果 | 提升丝线品质 | 每月一株 |
| 纯净雪水 | 日常饮用 | 每日 |

### 栖息环境

- **最佳环境**：万年玄冰洞穴，温度常年保持在零下五十度以下
- **巢穴**：以玄冰为巢，铺以冰蚕丝编织的小窝
- **禁忌**：绝对不可暴露在高温或火焰中，冰蚕极为怕火
- **灵脉要求**：冰属性或太阴属性灵脉

### 培养要点

1. **冰属性环境**：冰蚕对温度极其敏感，饲养环境的温度直接影响丝线品质。温度越低，丝线品质越高
2. **定期取丝**：冰蚕吐丝后会盘绕在巢中，需要定期收集。取丝时动作要轻柔，不可拉扯
3. **寒毒注意**：冰蚕身上带有寒毒，徒手触碰会被冻伤，采集蚕丝需戴冰蚕丝手套
4. **冬眠管理**：冰蚕每年冬季会进入深度休眠，期间不需要喂食，但要注意环境温度
5. **蜕皮护持**：冰蚕每十年蜕皮一次，蜕皮期间极为脆弱，需要主人护持
6. **丝线保存**：采集的冰蚕丝需放入冰玉盒中保存，否则会因温度升高而失去灵性
7. **结茧时机**：冰蚕结茧前食量会大增，此时要多喂冰属性灵草，以提升茧的质量

### 饲养禁忌

- 严禁火属性修士接近——冰蚕会被火灵力灼伤
- 取丝时不可贪多，每次取丝不能超过冰蚕总量的三分之一
- 不可同时饲养火属性灵宠，水火相冲会影响冰蚕的生长

## 与主人羁绊

### 契约方式

**冰心魂契**：以主人一滴精血混入玄冰之中，冰蚕吞噬后便与主人心意相连。冰蚕性寒，契约过程也是一场意志的考验——主人会在契约时感受到刺骨的寒意，需以灵力护住心脉。

### 心灵感应

- 冰蚕通过寒气的变化来表达情绪：开心时寒气温和，愤怒时寒气刺骨
- 主人可通过魂契感知冰蚕是否饥饿、是否需要取丝
- 冰蚕对主人的体温极为敏感，主人发热时它会主动靠近降温

### 忠诚度

冰蚕性格冷淡，不喜与人亲近，但其忠诚却极为可靠。一旦认主，便不会有二心。即便主人修为不及旁人，冰蚕也不会嫌弃。只是它表达忠诚的方式比较"冷"——默默吐丝，默默守护，绝不甜言蜜语。

### 特殊关系

冰蚕虽冷淡，却有自己独特的温柔。主人修炼走火入魔、体内灵力暴走时，冰蚕会主动爬到主人身上，以自身的寒气帮主人压制暴走的灵力。那种冰冷刺骨的感觉，反而能将主人从走火入魔的边缘拉回来。

## 著名灵宠/典故

### 冰蚕仙子

三千年前，极北冰原有一位著名的炼器宗师，人称"冰蚕仙子"。她幼年时在万年玄冰洞中发现了一只冰蚕，从此与冰蚕相伴一生。冰蚕仙子以冰蚕丝炼制了无数名震天下的灵甲，其中最著名的一件"玄冰天蚕甲"，据传可挡大乘期修士全力一击而无损。冰蚕仙子飞升后，那只冰蚕也随之消失。有人说冰蚕进化成了玄冰天蚕，随主人一同飞升了。

### 《天蚕诀》

修仙界有一部著名的炼器功法名为《天蚕诀》，便是以冰蚕的吐丝之道为灵感所创。此功法讲究以柔克刚、以静制动，如冰蚕吐丝般绵绵不绝。修炼此功法的修士，需先饲养一只冰蚕，观摩其吐丝之法方能入门。

### 千年冰蚕丝

据《炼器宝典》记载，一件上品灵甲的价值不过千枚灵石，但一件以千年冰蚕丝织成的灵甲，价值可达十万灵石以上。曾有拍卖会上拍出一件冰玉蚕丝织就的"寒玉甲"，最终以十五万灵石成交。而织成此甲的冰玉蚕丝，据说来自一只活了三千年的冰玉蚕。
