# 金翅雕

> 金翅雕者，天空之霸主。双翅如金铸，翎羽似刀锋，翱翔九天之上，俯瞰苍茫大地。其目可辨百里之外兔毫之微，其爪可裂三寸精铁之坚。修仙界中，金翅雕是最受器重的巡山灵禽和战斗坐骑。

## 外形

金翅雕体长四尺，双翼展开可达三丈。通体羽毛呈耀眼的金色，阳光下如身披金甲。头颈部为纯白色，与金色身躯形成鲜明对比。

**体态特征：** 头部圆大，弯喙如钩，呈暗金色，喙尖极为锋利，可轻易刺穿铁甲。双目深陷，瞳色金黄，目光锐利如剑，被它盯住的猎物如芒在背。双翼末端翎羽硬如刀片，振翅时可发出金属摩擦声。腿部覆满金色鳞片，四趾三前一后，爪尖漆黑如墨，一爪之力可碎石裂碑。

**气息：** 金翅雕气息锐利如出鞘之剑，靠近它便感到皮肤隐隐刺痛。展翅时金芒万丈，如一轮金色大日当空。

## 血脉与进化

**进化路线：** 金翅雕 → 金冠雕 → 大鹏雕 → 大鹏金翅鸟（终极）

**血脉溯源：** 金翅雕的血脉可追溯至上古神鸟大鹏金翅鸟。佛经中记载，大鹏金翅鸟双翼展开三百六十万里，一振翅可穿越三界。金翅雕虽有此血脉，却已稀薄，需经重重进化方有可能返祖。

## 天赋神通

**神通一：金羽飞刀。** 金翅雕振翅射出数十根金色翎羽，翎羽化为飞刀，漫天飞舞。金羽锋利无比，可切割护体灵气。翎羽射出后会自动回收，损耗极低。此招范围极广，是金翅雕的标志性群攻神通。

**神通二：鹰击长空。** 金翅雕从高空俯冲而下，双翼紧收，身形化为一道金色闪电。俯冲速度突破音障，产生音爆。冲击之力可穿透护山大阵。品阶高的金翅雕一冲之下，元婴期修士也难以正面抵挡。

**神通三：金身不坏（大鹏金翅鸟专属）。** 大鹏金翅鸟的身躯化为不灭金身，刀枪不入，水火不侵。佛法加持之下，万法不沾身。

## 培养方法

**食物：** 金灵石为主食，辅以灵兽肉、铁羽鸡。喜食各种金属灵材，有助于强化翎羽硬度。每月喂食一块玄铁可提升爪力。

**环境：** 居于高山绝壁之上，巢穴建在常人不可及的悬崖之巅。需要开阔的天空供其翱翔。不可长期关押，否则金翅雕的羽翼会退化。

**要点：** ①每日至少放飞三个时辰；②金羽需定期修剪，过长会影响飞行；③金翅雕性傲，宁可饿死也不食嗟来之食，驯服需以诚相待；④换羽期是其最虚弱的时候，需要大量金属性灵材补充。

## 与主人羁绊

**契约方式：** 金羽魂契。取金翅雕一根翎羽，融入主人精血，炼化为本命羽。主人可借此羽召唤金翅雕。

**心灵感应：** 金翅雕目光所及，主人亦可通过魂契共享视野。常用于高空侦察和追踪敌踪。战斗时心意相通，配合默契。

**忠诚度：** 金翅雕一生只认一主。主人若陨落，金翅雕会在葬主之地绝食而亡，绝不另投他主。

## 著名灵宠/典故

**大鹏怒飞：** 《庄子·逍遥游》有云："北冥有鱼，其名为鲲。鲲之大，不知其几千里也。化而为鸟，其名为鹏。"大鹏金翅鸟的传说深深影响了修仙界，金翅雕一族皆以大鹏为最高追求。

**灵山护法：** 传说西方灵山之上有大鹏金翅鸟守护，乃佛陀座下护法神鸟。它双翼一展可遮蔽日月，凶恶如迦楼罗亦不敢犯。

## 同类对比

金翅雕与青云鹤同为灵禽，金翅雕主杀伐，青云鹤擅承载。金翅雕爪喙锋利可碎金裂石，青云鹤仙风道骨宜为坐骑。若论战友情谊，金翅雕更为可靠。
