# 雷鹰

> 雷鹰，雷霆之子。双翅展开，电弧闪烁如银蛇乱舞；一声长啸，九天惊雷应声而落。此鸟生于九天雷海之中，以雷电为食，以风暴为翼。在修仙界的天空，雷鹰便是无可争议的霸主。

## 外形

雷鹰体型巨大，成年后展翅可达二十丈，体重却不到五百斤，因为其骨骼中空，充满雷电之力，轻盈而坚固。

**体态特征：**

- **羽毛**：通体羽毛为深蓝色到蓝紫色渐变，每一根羽毛表面都流转着淡淡的电弧。颈部羽毛最为浓密，呈银白色，如同披着闪电织就的围巾
- **双翅**：翅展极大，翅尖的飞羽长达丈余，边缘锋利。双翅扇动时，会有银色的电弧在翅间跳跃，发出噼啪之声
- **头**：头型威猛，有一张弯曲如钩的黑色铁喙，喙尖有一截银色印记，那是雷力最为凝聚之处。头顶有三根深蓝色的冠羽，发怒时会竖起如天线
- **眼睛**：鹰目如电，瞳孔为金黄色，虹膜边缘有一圈银白色的雷纹。视力极佳，可在万丈高空看清地面的兔子
- **利爪**：四趾铁爪，爪尖呈银白色，覆盖着细密的雷电纹路。一爪可碎金裂石
- **尾部**：尾羽修长，呈扇形展开，尾羽尖端有银色的电光圆点

**气息：**

雷鹰身上带有浓郁的雷电气息，方圆百丈内都能感受到空气中的静电。它振翅时，空气中臭氧的气味弥漫开来。发怒时，周身雷电大作，银蛇狂舞，宛如雷神降世。

## 血脉与进化

### 进化路线

雷鹰的血脉源自上古雷兽，进化之路便是不断掌控更强的雷电之力。

```
雷鹰 → 银翎雷鹰 → 金瞳雷鹰 → 九天雷鹰（终极形态）
```

### 进化阶段

**第一阶段·雷鹰（三级·灵兽）**
- 初生时羽毛为灰色，随着成长逐渐转为深蓝
- 可操控基础雷电，释放闪电攻击
- 飞行速度极快，日行三万里
- 灵智初开，可理解主人指令

**第二阶段·银翎雷鹰（四级·玄兽）**
- 颈部羽毛完全转为银白色，翅尖出现银色雷纹
- 雷电威力大幅提升，可释放雷球
- 飞行速度日行五万里
- 可在雷暴中吸收雷电之力补充自身

**第三阶段·金瞳雷鹰（五级·神兽）**
- 瞳孔转为纯金色，虹膜雷纹密布
- 周身羽毛出现金色电弧
- 可引动九天惊雷，召唤天雷攻击
- 飞行时身后拖着长长的雷电尾迹
- 速度日行八万里，快到肉眼无法捕捉

**终极形态·九天雷鹰（七级·仙兽）**
- 通体转为银白色，羽毛透明如水晶，内部雷光流转
- 可化为人形，多为银发雷瞳的威猛大汉
- 掌控天雷法则，一念之间可召万千雷霆
- 速度几乎等于瞬移，可借助雷电穿梭空间
- 实力堪比大乘期修士

### 进化条件

| 阶段 | 关键条件 | 辅助资源 |
|------|---------|---------|
| 雷鹰→银翎 | 三百年修为 + 吸收一场雷暴 | 雷灵石百枚 |
| 银翎→金瞳 | 千年修为 + 渡一次小天劫 | 雷劫液一滴 |
| 金瞳→九天 | 五千年修为 + 吞服雷道本源 | 渡九九天劫不死 |

## 天赋神通

### 神通一：九霄雷引

雷鹰核心神通，引动天雷轰击敌人。

- 双翅向天，召唤九天雷霆降临
- 一道天雷的威力堪比金丹期修士全力一击
- 银翎雷鹰可连续召唤三道天雷
- 金瞳雷鹰可召唤九道天雷，且可精准锁定敌人
- 九天雷鹰形态下，一念之间万雷齐发

天雷降临时，方圆百丈内的修士都会感到头皮发麻，毛发竖立，这是空气中电荷极度密集的表现。

### 神通二：雷电化身

雷鹰将自身化为一道雷电，在战场中极速穿梭。

- 化身雷电期间免疫一切物理攻击
- 移动速度快到产生残影，同时攻击多个目标
- 可在雷电状态下穿透护体罡气
- 是偷袭和突围的神技

### 神通三：雷狱领域

金瞳雷鹰专属神通，在战场中制造雷电监狱。

- 以自身为中心，方圆百丈内形成雷电场域
- 领域内的敌人行动迟缓，每走一步都要承受电击
- 雷鹰在领域内速度和威力翻倍
- 如有多个敌人，可用雷电锁链将其束缚

### 神通四：雷劫淬体（九天雷鹰专属）

九天雷鹰可通过主动引雷入体来淬炼肉身。

- 雷电之力淬炼骨骼，使其坚硬如仙金
- 每一次淬体都是一次重生
- 淬体次数越多，羽毛中储存的雷电越多
- 据说淬体九次后，可肉身硬抗天劫

## 培养方法

### 喜好食物

| 食物种类 | 效果 | 推荐频率 |
|---------|------|---------|
| 妖兽活食（大型） | 基础食物，提供能量 | 每两日一次 |
| 雷灵石 | 补充雷电之力，促进羽毛生长 | 每日一枚 |
| 雷劫液 | 大幅提升雷电亲和度 | 进化时使用 |
| 雷击木（已碳化的灵木） | 磨喙和利爪 | 每周一根 |
| 纯净灵泉水 | 饮水 | 每日 |

### 栖息环境

- **最佳环境**：万丈高峰之巅，常年雷暴区域最好
- **巢穴**：以雷击木搭建巢穴，辅以雷灵石装饰。巢穴建在最高处，要有开阔的视野
- **活动范围**：每日需要在高空飞至少三千里，不可圈养
- **灵脉要求**：雷属性灵脉，越强越好

### 培养要点

1. **雷电为食**：雷鹰需要定期吸收雷电之力，暴风雨天气是最佳的进补时机
2. **高空为王**：雷鹰在高空才能发挥全部实力，低矮处会让它感到压抑
3. **顺毛不逆**：雷鹰性格刚烈，训斥要讲究方式。它做错了事，要等它冷静下来再讲道理
4. **磨爪磨喙**：雷鹰的爪和喙会不断生长，需要定期提供硬物给它磨砺
5. **雷劫机遇**：每次雷劫是天大的机缘，如果条件允许，带雷鹰去渡劫现场吸收雷劫余波
6. **静电注意**：饲养雷鹰需要做好防静电措施，否则每天都会被电得头发竖立
7. **羽毛保养**：雷鹰的羽毛需要定期以雷灵力温养，可用雷灵石磨粉涂抹

### 饲养禁忌

- 不可在雷鹰活动区域放置水属性灵兽，雷鹰的电流会误伤
- 不可强行拔取雷鹰的羽毛，它身上的电流会瞬间释放
- 雷鹰极度厌恶雨天被困在室内，会暴躁到拆家

## 与主人羁绊

### 契约方式

**雷魂契约**：在雷雨交加的夜晚，将主人的一缕神魂与雷鹰的雷魂印记相融，契约便在雷电的见证下结成。此契约要求主人心志坚定，否则会被雷电之力震伤。

### 心灵感应

- 雷鹰可通过雷电共振与主人沟通
- 主人情绪激动时，雷鹰身上的电弧会随之跳跃
- 战斗时心意相通，配合默契

### 忠诚度

雷鹰的忠诚不是奴性的服从，而是对"战友"的认可。它认定你为伙伴后，会与你并肩作战，不畏生死。但若你在战斗中表现得懦弱怕死，雷鹰会对你大失所望。

### 特殊关系

雷鹰有一个非常特别的表达感情的方式——它会轻轻地用喙梳理主人的头发。被雷鹰"梳头"意味着它把你当成了最信任的伙伴。当然，第一次被雷鹰梳头的人往往会被它身上的静电电得龇牙咧嘴。

## 著名灵宠/典故

### 九天雷公

上古时期有一位名为"雷公"的仙君，他的坐骑便是一只九天雷鹰。每逢雷公出行，九天雷鹰展翅高飞，万里雷云相随。雷公所过之处，妖魔辟易，邪祟消散。后人尊雷公为雷部正神，专司天地雷霆之力。而那只九天雷鹰，则化作了天上的雷鹰星宿。

### 雷鹰救主

据《异兽录》记载，某位金丹期修士带着自己的雷鹰外出历练，遭遇了一头元婴期的妖兽。修士不敌，危在旦夕。雷鹰见状，毫不犹豫地引动自身全部雷电之力，以自爆的方式重创了妖兽。修士因此得救，雷鹰却化为飞灰。修士悲痛欲绝，将雷鹰的遗骨葬于雷山顶峰。据说每年雷暴之夜，那座坟茔上空都会出现一只雷电凝聚的鹰形虚影，展翅盘旋，久久不散。

### 北冥雷鹰

北冥之海有一座雷岛，终年被雷暴笼罩。岛上生存着一群雷鹰，它们以天雷为食，在闪电中筑巢。曾有修士误入雷岛，被雷鹰群围困。正当他绝望之时，一只雷鹰王从天而降，竟开口说出人言："凡人，你是千年来第一个抵达此地的修士。留下一件有趣的故事，我便放你离去。"修士讲述了自己的经历，雷鹰王听得津津有味，最终放他离去。后来那修士成为一代炼器大师，他炼制的最得意的一件法宝，便名为"雷鹰之羽"。
