# 墨小白

> 墨小白者，暗夜之狐，墨影之灵也。其色如墨，其形如狐，生于幽冥之地，长于暗夜之中。墨小白通体漆黑，与夜色融为一体，行走时无声无息，如同一个流动的影子。它不似九尾狐那般魅惑众生，却以隐匿与幻术见长——它是暗夜中的刺客，阴影里的猎手。

## 外形

墨小白体型如普通家猫大小，通体漆黑如最上等的松烟墨，皮毛柔软光滑，在月光下泛着淡淡的墨色光泽。

**体态特征：**

- **皮毛**：全身覆盖着纯黑色的短毛，毛尖在月光下泛着幽蓝色的微光。墨小白的皮毛具有天然的隐匿效果——在黑暗中几乎完全隐形，在月光下也只是一个模糊的墨影。
- **眼睛**：一双眼睛呈琥珀金色，在黑暗中发出幽幽的金光，如两粒悬浮在虚空中的星辰。这双眼睛能在完全黑暗的环境中视物，也能看破大多数幻术与隐匿。
- **尾巴**：一条蓬松的大尾巴，长度几乎与身体相等。尾巴尖端有一小撮白毛，如同蘸了墨的毛笔尖端的一点白——这也是"墨小白"之名的由来。
- **肉垫**：四足肉垫漆黑如墨，行走时完全无声，踏雪无痕，落地无风。
- **耳朵**：一对尖长的狐耳，耳廓内侧有细密的银色绒毛，能捕捉到极微弱的声音。

**墨影天狐形态：**

进化至墨影天狐后，墨小白体型增大如大型犬，生出三条尾巴，通体漆黑中浮现出银色的符文纹路。三条尾巴展开时，可释放覆盖方圆百丈的墨色幻境。

**气息：**

墨小白的气息极为淡薄，如同深夜中的一缕墨香。它善于将自身气息完全收敛，即使站在敌人身后，对方也难以察觉。

## 血脉与进化

### 进化路线

墨小白以月华与暗属性灵物进化：

```
幼狐墨小白 → 墨影狐 → 暗月狐 → 墨影天狐 → 幽冥狐仙（传说）
```

### 进化阶段

**第一阶段·幼狐墨小白**
- 初生之狐，通体漆黑，仅尾尖有一点白毛
- 以月华与暗属性灵虫为食
- 具备基础的隐匿能力，可在黑暗中完全隐身

**第二阶段·墨影狐**
- 吞噬暗属性灵物后进阶，皮毛更加漆黑
- 可化为墨影形态，穿越狭窄缝隙
- 幻术能力初现，可制造简单的幻象

**第三阶段·暗月狐**
- 吸收满月精华后进阶，眼中金光更盛
- 可在任何光线条件下隐匿身形
- 幻术大成，可制造以假乱真的幻境

**第四阶段·墨影天狐**
- 生出三条尾巴，体型增大
- 可释放墨色幻境领域
- 灵智大开，智慧不输人类

**传说阶段·幽冥狐仙**
- 渡过天劫后飞升
- 可自由穿梭于阴阳两界
- 拥有沟通幽冥之能

## 天赋神通

### 神通一：墨影潜行

墨小白的核心天赋，可将自身化为一道墨色影子，完全隐匿于黑暗之中。

- 在黑暗环境中，墨小白完全隐形，神识难以探测
- 化为墨影后移动速度提升三倍，且完全无声
- 可穿越狭窄的缝隙与孔洞，如同液体般流动
- 攻击时会短暂现形，但攻击后立即恢复隐匿
- 墨影天狐的墨影潜行可在月光下使用，且完全免疫元婴期以下的神识探测

此神通在强光环境下效果大减，正午阳光下隐匿效果降低七成。

### 神通二：墨幻千影

墨小白以墨色灵力制造幻象，迷惑敌人。

- 可制造1-3个与自身完全相同的墨色分身，持续一炷香
- 分身无攻击力，但可模拟动作与气息，迷惑敌人
- 暗月狐阶段可制造覆盖十丈范围的幻境，让敌人看到虚假的场景
- 墨影天狐的墨幻千影可制造覆盖百丈的墨色幻境，在幻境中墨小白可随意改变位置

此神通对修炼有破幻瞳术的修士效果大减。

### 神通三：暗影突袭（暗月狐以上专有）

墨小白从暗影中发动致命一击，速度与威力暴增。

- 从隐匿状态发动攻击时，速度与攻击力提升五成
- 攻击附带暗属性侵蚀效果，伤口难以愈合
- 被袭击者会陷入短暂的"墨盲"状态——眼前一黑，持续三息
- 墨影天狐的暗影突袭可连续瞬移三次，每次瞬移后发动一次攻击

此神通消耗极大，连续使用三次后需休息一个时辰。

### 神通四：墨界天幕（墨影天狐专有）

墨影天狐展开三尾，释放覆盖天地的墨色天幕，将战场化为自己的领域。

- 墨色天幕覆盖范围内，光线被完全吞噬，敌人陷入绝对黑暗
- 墨影天狐在墨界中完全隐形，且实力提升三成
- 敌人在墨界中神识被压制，感知范围缩减至丈许
- 墨界天幕可持续一炷香，冷却时间三日

此神通被强光类神通（如大日真火、光明咒）克制，强光可撕裂墨界。

## 培养方法

### 喜好食物

墨小白以暗属性物质为食：

| 食物种类 | 效果 | 推荐度 |
|---------|------|-------|
| 暗属性灵草（夜明草、墨灵芝） | 基础食物，维持成长 | ⭐⭐⭐ |
| 月华精华 | 夜间吸收，大幅提升修为 | ⭐⭐⭐⭐ |
| 暗属性妖兽肉 | 促进进化 | ⭐⭐⭐⭐ |
| 幽冥石 | 暗月狐进阶的关键材料 | ⭐⭐⭐⭐⭐ |
| 光属性材料 | 厌食，会导致不适 | ❌ |

### 栖息环境

- **最佳环境**：幽暗的森林深处、古墓、地下洞穴
- **光照要求**：喜暗厌光，白天通常睡觉，夜间活动
- **灵脉要求**：需要暗属性灵脉或阴气汇聚之地
- **巢穴**：以黑色丝绸或暗属性灵木筑巢，保持黑暗与安静

### 培养要点

1. **夜间活动**：墨小白是夜行动物，白天强行让其活动会导致烦躁与反抗
2. **月华喂养**：每月满月之夜以月华精华喂养，可大幅提升修为
3. **黑暗适应**：保持饲养环境黑暗，光线过强会导致墨小白皮毛褪色
4. **陪伴互动**：墨小白性格孤僻但渴望陪伴，主人需每日与其互动
5. **认主时机**：幼狐期最易认主，以自身精血混合夜明草喂食可建立羁绊

### 常见误区

- 不可将墨小白带至强光环境，会导致其隐匿能力暂时失效
- 不可喂食光属性材料，会导致其暗属性灵力紊乱
- 墨小白换毛期（每年一次）会暂时失去隐匿能力，需特别保护

**暗影血契**：在满月之夜，以自身精血在墨小白额头绘制暗影符文。墨小白会将主人的气息融入暗影之中，从此与主人形影不离。

### 心灵感应

- 主人可通过墨小白感知周围黑暗中的动静
- 墨小白能预警潜伏的敌人，在危险来临时会轻触主人示意
- 战斗时主人可通过心灵感应指挥墨小白的行动

### 忠诚度

- 墨小白对主人极为依赖，一旦认主便形影不离
- 若主人殒落，墨小白会在主人墓旁守护至寿终

## 产地/分布

墨小白主要分布阴暗潮湿的区域：

- **幽冥森林**：位于修真界北部的广袤暗林，是墨小白最大的栖息地
- **古墓群**：上古修士的墓穴中常有墨小白栖息，以墓中阴气为食
- **暗影峡谷**：终年被阴影覆盖的峡谷，墨小白群落密集
- **月影湖**：传说月圆之夜，墨小白会聚集在月影湖畔吸收月华

## 使用限制

1. **强光克制**：强光类神通与法器可破除墨小白的隐匿，使其暴露
2. **瞳术克制**：修炼有破幻瞳术的修士可看破墨小白的幻术与隐匿
3. **白天削弱**：白天墨小白的实力下降三成，隐匿效果大减
4. **暗属性依赖**：长期离开暗属性灵力充沛之地，墨小白会逐渐虚弱
5. **性格孤僻**：墨小白性格孤傲，强行命令可能导致其反抗

## 著名灵宠/典故

### 墨影刺客

三千年前，暗影宗曾培育一只墨影天狐，专门用于暗杀。这只墨影天狐在暗夜中无声无息地潜入敌方阵营，连续暗杀了七位元婴期长老，震惊修真界。暗影宗凭借这只墨影天狐，一度成为最令人闻风丧胆的暗杀宗门。

### 月下狐仙

传说月影湖畔曾有一只墨小白，每月在湖边吸收月华，千年后化为墨影天狐。一位失意书生路过湖畔，与墨小白相伴数月。墨小白化为少女形态，与书生共度一段美好时光。书生去世后，墨小白守护其墓千年，最终飞升而去。此传说在民间广为流传，成为"狐仙报恩"的经典故事。

### 墨宗护宗灵狐

暗影谷的护宗灵狐是一只活了五千年的墨影天狐，被尊为"墨祖"。墨祖平时沉睡于暗影谷最深处的暗穴中，只有在宗门遭遇灭门危机时才会苏醒。据记载，墨祖曾三次苏醒，每一次都将来犯之敌尽数歼灭于墨界天幕之中。

## 同类对比

### 墨小白 vs 九尾狐

两者皆为狐族灵宠，但定位截然不同：

- **战斗风格**：墨小白偏向隐匿与暗杀，暗夜中的刺客；九尾狐偏向幻术与魅惑，战场上的控场大师
- **属性差异**：墨小白为暗属性，擅长隐匿与幻术；九尾狐为幻属性，擅长魅惑与变化
- **稀有度**：九尾狐为天地唯一，极其稀有；墨小白虽稀少但可遇可求
- **进化上限**：九尾狐可进化为九尾天狐（九级仙兽）；墨小白最高为墨影天狐（六级圣兽）
- **饲养难度**：九尾狐几乎不可驯服，全凭缘分；墨小白可通过暗影血契收服

### 墨小白 vs 幻影狐

- **血脉关系**：幻影狐是墨小白的远亲，但血脉更加稀薄
- **隐匿能力**：墨小白的墨影潜行更加彻底，完全融入黑暗；幻影狐的隐匿仍有破绽
- **幻术水平**：墨小白的墨幻千影更加精妙，可制造领域级幻境；幻影狐的幻术较为基础
- **进化潜力**：墨小白可进化为墨影天狐；幻影狐最高进化为五级灵兽

### 墨小白 vs 暗影豹

- **体型差异**：墨小白体型小巧，适合潜入与侦察；暗影豹体型较大，适合正面战斗
- **攻击方式**：墨小白以暗影突袭为主，爆发力强但不持久；暗影豹以肉搏为主，持续输出能力强
- **辅助价值**：墨小白的幻术与侦察能力更出色；暗影豹的战斗能力更强
- **饲养难度**：墨小白需暗属性灵物与月华，饲养成本较高；暗影豹以普通妖兽肉为食，更易饲养
