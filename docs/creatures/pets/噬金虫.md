# 噬金虫

> 奇虫榜第十二位，群居灵虫，以五金为食，刀剑难伤，水火不侵。噬金虫一出，铺天盖地，金石为开，乃御虫修士梦寐以求之灵宠。

## 外形

噬金虫成虫约指甲盖大小，通体漆黑如墨，泛金属光泽。其甲壳坚硬无比，寻常飞剑难伤分毫。

**体态特征：**

- **口器**：一对锋利巨颚，如精钢锻造，可轻易咬碎下品法器
- **复眼**：暗红色复眼，夜间可发幽光，百丈之内洞察秋毫
- **翅翼**：薄如蝉翼的透明翅翼，振翅时发出嗡嗡金属颤音
- **甲壳**：背甲遍布细密金色纹路，宛如天然阵法，品阶越高金纹越密

**虫王形态：**

噬金虫王通体转为紫金之色，大小如拳，可化人形。化作人形时，多为三寸高的紫金小人，或七八岁女童模样，身着金甲，眉目如画。

**气息：**

噬金虫群聚时，散发浓郁庚金之气，锋芒毕露，令人皮肤生寒。虫王现世时，周遭所有金属器物皆会共鸣轻颤。

## 血脉与进化

### 进化路线

噬金虫以同类相噬之法进化，乃修仙界极少数靠"内卷"晋升之灵虫。

```
普通噬金虫 → 甲壳噬金虫 → 金纹噬金虫 → 噬金虫王 → 噬金仙虫（传说）
```

### 进化阶段

**第一阶段·普通噬金虫**
- 初生之虫，吞噬五金百斤后可进阶
- 甲壳漆黑，刀剑难伤
- 灵智未开，只凭本能行事

**第二阶段·甲壳噬金虫**
- 吞噬五金千斤，甲壳增厚三倍
- 金纹初现，防御力堪比中品灵器
- 可抵御筑基期修士全力一击

**第三阶段·金纹噬金虫**
- 吞噬五金万斤，背甲金纹密布
- 飞行速度暴增，口器可碎上品灵器
- 灵智初开，可理解主人简单指令

**第四阶段·噬金虫王**
- 虫群中诞生唯一王者
- 通体紫金，可化人形
- 智慧不输人类，可独自修行
- 吞噬仙器碎片可继续进化

**传说阶段·噬金仙虫**
- 传闻中噬金虫终极形态
- 吞噬过大罗金仙之器，蜕去虫身
- 化为人形，与真仙无异
- 极少出现，多存于上古记载

### 进化条件

| 阶段 | 所需材料 | 吞噬量 | 特殊条件 |
|------|---------|--------|---------|
| 普通→甲壳 | 精铁/玄铁 | 千斤 | 无 |
| 甲壳→金纹 | 玄铁/庚金 | 万斤 | 吸收一滴金精之髓 |
| 金纹→虫王 | 庚金/仙金碎片 | 十万斤 | 吞噬所有同类，百虫争王 |
| 虫王→仙虫 | 仙器碎片/混沌金母 | 不计 | 需渡虫劫，九死一生 |

## 天赋神通

### 神通一：庚金吞噬

噬金虫核心天赋，口器可分解一切金属之物，将其转化为自身养分与灵力。

- 下品法器，数息之间啃噬殆尽
- 中品灵器，半柱香功夫化为碎片
- 上品灵器，亦难抵挡虫群轮番啃咬
- 传闻虫王连仙器也能咬出缺口

吞噬之物品阶越高，进化速度越快。

### 神通二：金甲护体

噬金虫甲壳蕴含天然庚金禁制，防御力远超同阶妖兽。

- 普通噬金虫：可挡炼气圆满修士全力一击
- 甲壳噬金虫：硬抗筑基期法宝无恙
- 金纹噬金虫：金丹期修士亦难破防
- 虫王：寻常攻击如同瘙痒，唯有仙术或至宝方能伤之

### 神通三：虫海聚形（虫群专有）

当噬金虫数量超过万只时，可聚合成巨大形态。

- **虫球**：聚为直径数丈的黑球，碾压一切
- **虫剑**：化为一柄百丈巨剑，斩金断铁
- **虫甲**：覆盖主人全身，化为金刚战甲
- **虫潮**：铺天盖地，遮蔽日月，所过之处寸铁不留

### 神通四：噬灵破禁（虫王专有）

虫王可吞噬灵气形成的禁制与阵法。

- 寻常护山大阵，虫王一日可啃出缺口
- 上古禁制，亦难抵挡虫王持久吞噬
- 甚至能以对方法宝中的灵力反噬其主

## 培养方法

### 喜好食物

噬金虫以金属为食，不同金属对进化效果各异：

| 金属种类 | 效果 | 推荐度 |
|---------|------|-------|
| 凡铁/精钢 | 基础食物，维持生存 | ⭐⭐ |
| 玄铁/精金 | 促进甲壳生长 | ⭐⭐⭐ |
| 庚金/星辰铁 | 大幅提升进化速度 | ⭐⭐⭐⭐ |
| 仙金碎片/混沌金母 | 虫王进阶至宝 | ⭐⭐⭐⭐⭐ |
| 玉石/灵木 | 厌食，会萎缩**（注意：玉木可克制噬金虫）** |

### 栖息环境

- **最佳环境**：矿脉深处，尤其是庚金矿脉
- **适宜温度**：偏热，地火附近最佳
- **灵脉要求**：需要金属性灵脉，品阶越高越好
- **巢穴**：以玄铁筑巢，温养百年可与虫群心意相通

### 培养要点

1. **数量为王**：噬金虫强在群攻，至少培育千只以上方显威力
2. **定时喂食**：每月至少喂食一次精铁，否则虫群会互相残食
3. **优胜劣汰**：定期让虫群互相吞噬，可自然产生强者
4. **虫王培育**：百虫争王时，在战场中央投放天材地宝，可加速虫王诞生
5. **灵植克制**：噬金虫畏玉木之气，培养处不可植灵玉之木
6. **认主时机**：虫王初生时最易认主，一旦错过便极难驯服

### 常见误区

- 不可喂食杂质过多的凡铁，会导致虫群体质下降
- 不可将不同批次的虫群强行合并，会发生死斗
- 虫王诞生后需立即认主，否则虫王会率众逃离

## 与主人羁绊

### 契约方式

**血魂双契**：以精血混合神魂印记，种入虫王识海。虫王认主后，整个虫群皆受驱使。

### 心灵感应

- 主人可通过虫王感知每一只噬金虫的位置与状态
- 虫群可视为主人的"金属性天眼"，方圆百里矿脉一目了然
- 战斗时心念所至，虫群如臂使指

### 忠诚度

- 虫王对主人极为忠诚，一旦认主，至死不渝
- 普通噬金虫灵智未开，只听从虫王指令
- 若主人殒落，虫王会带领虫群为主人守墓百年

### 特殊关系

噬金虫王若化为女童形态，往往以"父亲"或"主人"称呼，性格天真烂漫，唯独在吞噬宝物时异常凶悍。曾有记载，某位虫王化形后，因主人一句"小金子"，羞恼三日不食。

## 著名灵宠/典故

### 金童

《凡人修仙传》中韩立之噬金虫王。韩立于乱星海偶获噬金虫卵，精心培育，令虫群自相吞噬，终诞生虫王。虫王化形为三寸紫金小人，后化为女童，名唤"金童"。金童跟随韩立历经无数生死大战，吞噬无数仙器法宝，最终进化为道祖级别存在。其忠勇与战力，堪称修仙界灵宠传奇。

### 上古虫灾

据《万虫录》记载，上古时期曾有噬金虫群脱离控制，在一处修真星上泛滥成灾。虫群所过之处，法宝化为碎屑，灵脉啃噬殆尽，护山大阵形同虚设。最终三位大乘期修士联手，以玉木灵阵围困，耗时百年方才平息。此役之后，噬金虫被列为禁忌灵虫，寻常宗门不敢轻易培育。

### 虫王认主异象

传说噬金虫王诞生之时，天地异象频现。矿脉中所有金属共鸣震颤，方圆百里的飞剑无故出鞘，若有人在场，其储物袋中的法器皆会自行飞出，朝虫王方向顶礼膜拜。能得此异象者，方为真命虫主。
