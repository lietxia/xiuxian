# 噬金虫

> 奇虫榜第十二位，群居灵虫，以五金为食，刀剑难伤，水火不侵。噬金虫一出，铺天盖地，金石为开，乃御虫修士梦寐以求之灵宠。

## 外形

噬金虫成虫约指甲盖大小，通体漆黑如墨，泛金属光泽。其甲壳坚硬无比，寻常飞剑难伤分毫。

**体态特征：**

- **口器**：一对锋利巨颚，如精钢锻造，可轻易咬碎下品法器
- **复眼**：暗红色复眼，夜间可发幽光，百丈之内洞察秋毫
- **翅翼**：薄如蝉翼的透明翅翼，振翅时发出嗡嗡金属颤音
- **甲壳**：背甲遍布细密金色纹路，宛如天然阵法，品阶越高金纹越密

**虫王形态：**

噬金虫王通体转为紫金之色，大小如拳，可化人形。化作人形时，多为三寸高的紫金小人，或七八岁女童模样，身着金甲，眉目如画。

**气息：**

噬金虫群聚时，散发浓郁庚金之气，锋芒毕露，令人皮肤生寒。虫王现世时，周遭所有金属器物皆会共鸣轻颤。

## 血脉与进化

### 进化路线

噬金虫以同类相噬之法进化，乃修仙界极少数靠"内卷"晋升之灵虫。

```
普通噬金虫 → 甲壳噬金虫 → 金纹噬金虫 → 噬金虫王 → 噬金仙虫（传说）
```

### 进化阶段

**第一阶段·普通噬金虫**
- 初生之虫，吞噬五金百斤后可进阶
- 甲壳漆黑，刀剑难伤
- 灵智未开，只凭本能行事

**第二阶段·甲壳噬金虫**
- 吞噬五金千斤，甲壳增厚三倍
- 金纹初现，防御力堪比中品灵器
- 可抵御筑基期修士全力一击

**第三阶段·金纹噬金虫**
- 吞噬五金万斤，背甲金纹密布
- 飞行速度暴增，口器可碎上品灵器
- 灵智初开，可理解主人简单指令

**第四阶段·噬金虫王**
- 虫群中诞生唯一王者
- 通体紫金，可化人形
- 智慧不输人类，可独自修行
- 吞噬仙器碎片可继续进化

**传说阶段·噬金仙虫**
- 传闻中噬金虫终极形态
- 吞噬过大罗金仙之器，蜕去虫身
- 化为人形，与真仙无异
- 极少出现，多存于上古记载

### 进化条件

| 阶段 | 所需材料 | 吞噬量 | 特殊条件 |
|------|---------|--------|---------|
| 普通→甲壳 | 精铁/玄铁 | 千斤 | 无 |
| 甲壳→金纹 | 玄铁/庚金 | 万斤 | 吸收一滴金精之髓 |
| 金纹→虫王 | 庚金/仙金碎片 | 十万斤 | 吞噬所有同类，百虫争王 |
| 虫王→仙虫 | 仙器碎片/混沌金母 | 不计 | 需渡虫劫，九死一生 |

## 天赋神通

### 神通一：庚金吞噬

噬金虫核心天赋，口器可分解一切金属之物，将其转化为自身养分与灵力。

- 下品法器，数息之间啃噬殆尽（消耗灵力极少，可连续使用）
- 中品灵器，半柱香功夫化为碎片（冷却时间：半盏茶）
- 上品灵器，亦难抵挡虫群轮番啃咬（需百只以上同时啃噬）
- 传闻虫王连仙器也能咬出缺口，然消耗极大，一口需歇息三日

吞噬之物品阶越高，进化速度越快。若连续吞噬超出自身承受品阶之物，虫体可能爆裂而亡。

### 神通二：金甲护体

噬金虫甲壳蕴含天然庚金禁制，防御力远超同阶妖兽。

- 普通噬金虫：可挡炼气圆满修士全力一击
- 甲壳噬金虫：硬抗筑基期法宝无恙
- 金纹噬金虫：金丹期修士亦难破防，反弹三成物理伤害
- 虫王：寻常攻击如同瘙痒，唯有仙术或至宝方能伤之。虫王金甲自动吸收周遭庚金之气修复，破口越大修复越慢

此神通被动生效，不消耗灵力，但遭受重击后金纹会暗淡，需以庚金之气温养三日方可复原。

### 神通三：虫海聚形（虫群专有）

当噬金虫数量超过万只时，可聚合成巨大形态。虫群之间以庚金共振相连，形成统一的灵力网络。

- **虫球**：聚为直径数丈的黑球，碾压一切。转速越快破坏力越强，但内部虫子的离心力会使其疲惫
- **虫剑**：化为一柄百丈巨剑，斩金断铁。虫剑维持时间与虫群耐力相关，最多持续一炷香
- **虫甲**：覆盖主人全身，化为金刚战甲。虫甲状态下主人防御力暴增，但移动速度下降两成
- **虫潮**：铺天盖地，遮蔽日月，所过之处寸铁不留。虫潮可持续三日三夜，但之后虫群需休整十日

虫海聚形的弱点在于——若敌人以大面积火焰或玉木之气攻击，虫群会瞬间溃散。

### 神通四：噬灵破禁（虫王专有）

虫王可吞噬灵气形成的禁制与阵法。

- 寻常护山大阵，虫王一日可啃出缺口（消耗：虫王灵力总量的三成）
- 上古禁制，亦难抵挡虫王持久吞噬（需时三日以上，且虫王会进入虚弱期）
- 甚至能以对方法宝中的灵力反噬其主，使对方短暂失去对法宝的掌控
- 冷却时间：每次使用后需休整七日，否则虫王有反噬之险

此神通极其逆天，故天道有所限制——每名噬金虫王一生最多使用九次噬灵破禁，超则必遭天谴。

### 神通五：庚金共鸣（虫王专有·探测技）

虫王进阶至金纹后觉醒的辅助神通，以自身庚金之气感应周遭金属。

- 方圆百里之内，所有金属矿脉的分布如掌上观纹
- 可感知地下深处的法宝、飞剑、灵矿
- 战斗时可预判对手金属性法宝的来路与轨迹
- 消耗极低，可常时开启

## 培养方法

### 喜好食物

噬金虫以金属为食，不同金属对进化效果各异：

| 金属种类 | 效果 | 推荐度 |
|---------|------|-------|
| 凡铁/精钢 | 基础食物，维持生存 | ⭐⭐ |
| 玄铁/精金 | 促进甲壳生长 | ⭐⭐⭐ |
| 庚金/星辰铁 | 大幅提升进化速度 | ⭐⭐⭐⭐ |
| 仙金碎片/混沌金母 | 虫王进阶至宝 | ⭐⭐⭐⭐⭐ |
| 玉石/灵木 | 厌食，会萎缩**（注意：玉木可克制噬金虫）** |

### 栖息环境

- **最佳环境**：矿脉深处，尤其是庚金矿脉
- **适宜温度**：偏热，地火附近最佳
- **灵脉要求**：需要金属性灵脉，品阶越高越好
- **巢穴**：以玄铁筑巢，温养百年可与虫群心意相通

### 培养要点

1. **数量为王**：噬金虫强在群攻，至少培育千只以上方显威力
2. **定时喂食**：每月至少喂食一次精铁，否则虫群会互相残食
3. **优胜劣汰**：定期让虫群互相吞噬，可自然产生强者
4. **虫王培育**：百虫争王时，在战场中央投放天材地宝，可加速虫王诞生
5. **灵植克制**：噬金虫畏玉木之气，培养处不可植灵玉之木
6. **认主时机**：虫王初生时最易认主，一旦错过便极难驯服

### 常见误区

- 不可喂食杂质过多的凡铁，会导致虫群体质下降
- 不可将不同批次的虫群强行合并，会发生死斗
- 虫王诞生后需立即认主，否则虫王会率众逃离

## 与主人羁绊

### 契约方式

**血魂双契**：以精血混合神魂印记，种入虫王识海。虫王认主后，整个虫群皆受驱使。

### 心灵感应

- 主人可通过虫王感知每一只噬金虫的位置与状态
- 虫群可视为主人的"金属性天眼"，方圆百里矿脉一目了然
- 战斗时心念所至，虫群如臂使指

### 忠诚度

- 虫王对主人极为忠诚，一旦认主，至死不渝
- 普通噬金虫灵智未开，只听从虫王指令
- 若主人殒落，虫王会带领虫群为主人守墓百年

### 特殊关系

噬金虫王若化为女童形态，往往以"父亲"或"主人"称呼，性格天真烂漫，唯独在吞噬宝物时异常凶悍。曾有记载，某位虫王化形后，因主人一句"小金子"，羞恼三日不食。

## 同类对比

### 噬金虫 vs 冰蚕

两者俱为奇虫榜上的著名灵虫，然定位迥异：

- **战斗方式**：噬金虫以数量取胜，虫海战术铺天盖地；冰蚕以质胜，单只即可独当一面
- **属性克制**：冰蚕吐丝冰寒，可冻结噬金虫的行动；噬金虫的庚金之气则可斩断冰蚕丝
- **培养成本**：噬金虫需海量金属，成本高昂；冰蚕只需桑叶灵露，培育更加亲民
- **寿命**：冰蚕寿不过三百年，噬金虫王可活上万年
- **稀有度**：冰蚕更难捕获，野生噬金虫群相对常见

御虫师有云："养虫千日用虫一时，噬金在量，冰蚕在质。"

### 噬金虫 vs 赤焰狐

- **属性相克**：赤焰狐的火属性可克制噬金虫的金属性——烈火熔金，正是噬金虫的克星
- **速战速决**：赤焰狐爆发高但后继乏力，噬金虫若扛住第一波火攻，消耗战必胜
- **群体 vs 单体**：噬金虫群的优势在于数量，赤焰狐的优势在于单体爆发
- **环境适应性**：噬金虫几乎可在任何矿脉环境生存；赤焰狐离了火灵力充沛之地便实力大减

### 噬金虫 vs 金翅风鹏

- **空中对决**：风鹏飞遁速度天下无双，噬金虫群即便围堵也难以追上
- **克制关系**：风鹏的罡风可吹散虫群阵型，噬金虫的虫海则能耗尽风鹏的体力
- **战略价值**：风鹏适合侦察与追击，噬金虫适合阵地战与消耗战

## 著名灵宠/典故

### 金童

《凡人修仙传》中韩立之噬金虫王。韩立于乱星海偶获噬金虫卵，精心培育，令虫群自相吞噬，终诞生虫王。虫王化形为三寸紫金小人，后化为女童，名唤"金童"。金童跟随韩立历经无数生死大战，吞噬无数仙器法宝，最终进化为道祖级别存在。其忠勇与战力，堪称修仙界灵宠传奇。

### 上古虫灾

据《万虫录》记载，上古时期曾有噬金虫群脱离控制，在一处修真星上泛滥成灾。虫群所过之处，法宝化为碎屑，灵脉啃噬殆尽，护山大阵形同虚设。最终三位大乘期修士联手，以玉木灵阵围困，耗时百年方才平息。此役之后，噬金虫被列为禁忌灵虫，寻常宗门不敢轻易培育。

### 虫王认主异象

传说噬金虫王诞生之时，天地异象频现。矿脉中所有金属共鸣震颤，方圆百里的飞剑无故出鞘，若有人在场，其储物袋中的法器皆会自行飞出，朝虫王方向顶礼膜拜。能得此异象者，方为真命虫主。

### 天剑宗遗案

七百年前，天剑宗曾培育一支噬金虫群，用于看护藏剑峰。藏剑峰上插有历代宗主的本命飞剑，共计三千六百柄，皆是难得的通灵法器。天剑宗本意让噬金虫以剑气为食，促进进化。不料虫群在百年间悄然繁衍至百万之数，某夜突然暴动，将三千六百柄飞剑吞噬大半。天剑宗宗主大怒，欲灭虫群，却发现虫王已进化至金纹之境，刀剑不入。最终天剑宗不得不请来万宝阁的御虫大师，以玉木香诱捕虫王，方平息这场"噬剑之乱"。经此一事，各大宗门对噬金虫的警惕提高到了前所未有的高度。
