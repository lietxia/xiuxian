# 碧水蟾

> 碧水蟾者，水泽之灵蟾也。通体碧绿如玉，双目金睛，居于深潭沼泽之中，吞吐水雾，解毒疗伤。其声如鼓，可震散邪祟；其毒攻心，亦可活人——毒与药，只在一念之间。碧水蟾虽非顶级灵宠，却是散修最实用的伙伴之一。

## 外形

碧水蟾体型硕大，成年个体约磨盘大小，通体覆盖碧绿色鳞片，隐隐泛出玉石般的光泽。

**体态特征：**

- **头部**：扁平宽阔，两侧各有一只金色圆睛，瞳孔竖裂如缝，夜间可发出幽绿光芒
- **皮肤**：背部鳞片呈深碧色，有不规则黑色斑纹；腹部洁白如凝脂，柔软而富有弹性
- **毒囊**：耳后两侧各有一个鼓起的透明毒囊，内有碧绿色毒液缓缓流动，清晰可见
- **四肢**：粗短有力，趾间有蹼，趾端有吸盘，可在光滑岩石上自由爬行
- **声囊**：咽喉处有一个可膨胀的薄膜声囊，鸣叫时鼓起如气囊，声如牛吼

**气息：** 碧水蟾气息阴寒潮湿，周身常年笼罩一层薄薄的水雾。它所居之处，空气清新湿润，草木格外茂盛。

## 血脉与进化

**血脉溯源：** 碧水蟾是上古异兽"三足金蟾"的旁支后裔。三足金蟾主招财进宝，碧水蟾则继承了水与毒的天赋。

**进化路线：** 碧水蟾 → 碧鳞蟾 → 碧玉蟾 → 碧玉金蟾（终极）

## 天赋神通

### 神通一：碧水毒雾

碧水蟾从口中喷吐碧绿色毒雾，覆盖方圆数十丈。毒雾具有双重效果——对敌人造成麻痹和侵蚀，对友军则可解毒疗伤。

- 毒雾浓度可随心调节，最浓时可腐蚀下品法器
- 毒雾中含有特殊酶素，可解百种蛇虫之毒
- 持续时间：一炷香至一个时辰不等
- 冷却时间：喷吐后需休息半日方可再次使用

### 神通二：蟾鸣震魄

碧水蟾鼓胀声囊，发出低沉而震撼的鸣叫声。此音波可震慑心神、驱散邪祟。

- 对鬼修和邪物有极强的克制作用，可震散筑基期以下的鬼物
- 鸣叫时音波范围内的低阶妖兽会陷入短暂眩晕
- 若连续鸣叫三次以上，碧水蟾会进入短暂的虚弱期

### 神通三：水遁潜行

碧水蟾可在水中自由遁行，瞬间融入水体，消失无踪。

- 水遁距离：成年碧水蟾一次可遁出百丈
- 在水中移动速度是陆地上的三倍
- 可在水底潜伏数日不出，呼吸通过皮肤进行
- 冷却时间：每次水遁后需浮出水面换气

### 神通四：碧玉疗光（碧玉蟾专属）

进化至碧玉蟾后觉醒的治疗神通。从体内散发出碧绿色光芒，可治愈外伤和驱除毒素。

- 可治愈骨折、内伤等物理创伤
- 可驱除金丹期以下修士所中之毒
- 对诅咒类法术也有一定的净化效果
- 每次使用消耗大量体力，一日最多使用三次

## 培养方法

### 喜好食物

| 食物 | 效果 | 推荐度 |
|------|------|-------|
| 灵蚊、灵蛾 | 基础食物，维持生存 | ⭐⭐⭐ |
| 毒蛇、毒蝎 | 促进毒囊发育 | ⭐⭐⭐⭐ |
| 水灵藻 | 提升水灵力 | ⭐⭐⭐⭐⭐ |
| 月华草 | 促进进化 | ⭐⭐⭐⭐⭐ |

### 栖息环境

- **最佳环境**：深潭、沼泽、瀑布下的水潭
- **水质要求**：需富含灵气的活水，死水会导致其萎靡
- **温度**：喜阴凉，水温以凉爽为宜
- **巢穴**：水底岩石缝隙或泥洞中，需有露出水面的换气石

### 培养要点

1. **定期晒背**：碧水蟾需每日上岸晒背一个时辰，以助鳞片生长
2. **毒囊管理**：每月需为碧水蟾排毒一次，否则毒液反噬自身
3. **水质清洁**：栖息之水需保持清洁，否则易患皮肤病
4. **冬眠习性**：碧水蟾有冬眠习惯，冬季活动减少属正常现象

## 与主人羁绊

### 契约方式

**水魂契约**：以主人精血滴入碧水蟾头顶，建立心灵连接。碧水蟾灵智不高，但认主后极为忠诚。

### 心灵感应

- 碧水蟾通过鸣叫的频率和节奏表达情感
- 主人可通过心灵感应感知碧水蟾的健康状态
- 碧水蟾能感知主人是否中毒，会主动靠近为主人驱毒

### 忠诚度

碧水蟾认主后终身不离不弃。若主人殒落，碧水蟾会在主人墓旁守候至终老，期间不断鸣叫，声嘶力竭，闻者心酸。

## 使用限制

- **火属性克制**：碧水蟾畏火，火属性法术对其伤害加倍
- **干旱环境**：离开水超过三日，碧水蟾会脱水虚弱
- **噪音敏感**：对尖锐金属声极为敏感，会陷入狂乱
- **行动迟缓**：陆地移动速度缓慢，不适合快速追击战

## 著名灵宠/典故

### 蟾医济世

据《百草经》记载，三千年前有一位号称"蟾医"的散修，以一只碧玉蟾行走天下。此蟾已进化至碧玉之境，碧玉疗光可解天下万毒。蟾医凭此蟾救人无数，从不收钱，只要求被救者种下一株水灵藻。百年后蟾医飞升，碧玉蟾化为石像立于其洞府门前，至今仍有人前去祭拜。

### 金蟾聚财

民间传说中，三足金蟾能口吐金钱。碧水蟾作为金蟾旁支，虽不能吐财，但有一种特殊能力——能感知地下水源和灵脉。许多散修收服碧水蟾，正是为了寻找灵泉和矿脉。

## 同类对比

### 碧水蟾 vs 玄水龟

两者俱为水属性灵宠，但定位不同：

- **战斗方式**：碧水蟾以毒雾和音波攻击为主，偏控制；玄甲龟以防御和撞击为主，偏肉盾
- **治疗能力**：碧水蟾有碧玉疗光，可治疗他人；玄水龟仅能自愈
- **机动性**：碧水蟾水遁灵活，玄水龟水中速度较慢
- **培养成本**：碧水蟾需定期排毒，维护较繁琐；玄水龟几乎无需特别照料

### 碧水蟾 vs 碧眼金蟾

- **血脉**：碧眼金蟾是三足金蟾的直系后裔，血脉更纯正
- **能力**：碧眼金蟾主招财和感知宝物，碧水蟾主毒与疗
- **稀有度**：碧眼金蟾极为罕见，碧水蟾相对常见
- **进化上限**：碧眼金蟾可进化至仙兽级别，碧水蟾上限为圣兽
