# 赤焰马

> 赤焰马者，火中神驹也。通体赤红如火，四蹄踏焰而行，奔腾时如一条火龙划过大地。它是修仙界中最受欢迎的坐骑灵兽之一——既英武不凡，又速度极快。骑赤焰马出行，千里之遥半日可达。大宗门的真传弟子，莫不以一匹赤焰马为荣。

## 外形

赤焰马体高八尺，体长一丈二，体型匀称健美，线条流畅如烈火燃烧。通体无一丝杂毛，皮毛呈赤红色，在阳光下如火焰般耀眼。

**体态特征：** 头部清秀，双目如赤金，瞳孔中仿佛有火焰跳动。鬃毛如同燃烧的烈焰，随风飘舞时火星四溅。四蹄下半截始终燃烧着赤色的火焰，但火焰不会灼伤主人——只有赤焰马可以控制。马尾亦如火焰，摆动时带起一串火星。肌肉线条分明，充满力量感。

**气息：** 赤焰马周身温热，靠近便感到一阵暖意。它奔跑时身后留下一道火焰尾迹，久久不散。它的嘶鸣声高亢嘹亮，如同火焰呼啸。

## 血脉与进化

**进化路线：** 赤焰马 → 炎蹄马 → 赤炎驹 → 赤焰天马（终极）

**血脉溯源：** 赤焰马的血脉源自上古神马"炎蹄"。传说炎蹄是天帝的坐骑，四蹄踏火，可奔驰于九天之上。赤焰马便是炎蹄在凡间的血脉延续。

---

## 天赋神通

**神通一：踏焰奔行。** 赤焰马的四蹄燃烧着火焰，在地面奔跑时如履平地。此神通使赤焰马的速度倍增，最高可达日行万里。火焰蹄印在地面留下燃烧的足迹，对追击的敌人造成阻碍。

**神通二：腾空踏火。** 赤焰马可踏着火焰在空中奔跑，虽不能如飞禽般自由翱翔，却可在空中借火而行，跨越深渊、越过城墙。踏空距离受限于修为，品阶越高踏空时间越长。

**神通三：烈焰护体（赤焰天马专属）。** 赤焰天马周身燃起护体真火，形成一个火焰护罩。冲锋时火焰护罩可撞飞敌人，同时保护骑乘者不受攻击。火焰护罩对阴寒类攻击有额外克制效果。

## 培养方法

**食物：** 火灵石、火属性灵草（火焰草、赤阳花）。饮用水需加热至沸腾放凉后饮用。每月喂食一枚火榴果可提升火焰品质。

**环境：** 马厩需建在火属性灵脉上，地面铺设赤铜板。温度需保持在较高水平。需要有足够的奔跑空间——马场至少十里见方。

**要点：** ①赤焰马每日需要足够的奔跑量，否则会焦躁；②马蹄火焰的马蹄铁需要特殊材质（赤铜），否则会被烧化；③鬃毛和尾巴需要定期梳理，否则火焰会变得暗淡；④赤焰马性格温顺，易于驯养，适合作为新手的第一只坐骑灵宠。

## 与主人羁绊

**契约方式：** 火缰魂契。以火灵力凝成一条无形的缰绳，连接主人与赤焰马的灵魂。契约后主人可以意念控制赤焰马的方向和速度。

**心灵感应：** 赤焰马懂得主人的骑乘意图，加速/减速/转弯全凭心念。主人紧张时它会放慢速度，主人兴奋时它会加速狂奔。

**忠诚度：** 赤焰马性情温顺忠诚，对主人极好。但它毕竟是火属性灵兽，遇到水属性妖兽时会本能地不安，需要主人安抚。

## 著名灵宠/典故

**赤兔的传说：** 凡间有赤兔马日行千里的传说。在修仙界中，赤兔马被认为是最低阶的赤焰马返祖失败品。虽未觉醒火属性，却保留了赤焰马的奔跑速度和耐力，故而有了"赤兔追风"的美名。

## 同类对比

赤焰马与青云鹤同为坐骑灵宠，赤焰马擅长陆地奔行和短途冲刺，青云鹤则精于高空飞行和长途跋涉。赤焰马更英武霸气，青云鹤更仙风道骨。论拉风程度，赤焰马更胜一筹。
