# 火须子

> 火须子者，火精所凝，炎灵所化也。其形如蚕，其须如焰，通体赤红，游走于地火熔岩之间。火须子虽为虫属，却具火灵之体，须动则焰起，息吐则炎生。古之炼器师视其为地火之友，御火修士奉其为火中灵宠。

## 外形

火须子体型如成人拇指粗细，长约三寸，通体呈半透明的赤红色，体内可见流动的岩浆般的光泽，仿佛一团凝固的火焰有了生命。

**体态特征：**

- **火须**：头部两侧各生三根火焰长须，须长可达虫体两倍，如六条灵动的火蛇随风飘舞。火须并非实体，而是由纯粹的火灵力凝聚而成，温度极高，触物即燃。火须的颜色随修为增长而变化——初生时为橙红色，进阶后转为赤金色，虫王阶段则化为纯白色的三昧真火须。
- **甲壳**：背部覆盖细密的赤色鳞片，如熔岩冷却后的黑曜石般光滑坚硬。鳞片缝隙间隐隐透出火光，仿佛随时会喷出火焰。
- **口器**：一对赤铜色的颚齿，可咬碎火属性矿石，咀嚼时火星四溅。
- **眼睛**：两粒黑豆般的复眼，呈暗金色，能看透火焰与烟雾，在熔岩中视物如同白昼。

**火须王形态：**

火须王体型可达尺许，通体转为金白之色，六根火须化为纯白真火，温度堪比地火核心。背后生出一对火翅，振翅时热浪滚滚，可短暂飞行。

**气息：**

火须子散发的气息灼热干燥，靠近者如置身烘炉之旁。其所过之处，草木焦枯，土石龟裂。火须王出现时，方圆十丈内的温度骤升百度，凡人难以靠近。

## 血脉与进化

### 进化路线

火须子以吞噬火精与地火精华进化，进化路线清晰：

```
幼生火须子 → 赤须火须子 → 金须火须子 → 火须王 → 地火灵蚕（传说）
```

### 进化阶段

**第一阶段·幼生火须子**
- 初生之虫，通体橙红，火须短小
- 以火晶碎屑为食，需十年方可成熟
- 可喷出尺许长的小火苗，威力有限

**第二阶段·赤须火须子**
- 吞噬百斤火精后进阶，体色转为深红
- 火须增长，可延伸至虫体两倍
- 喷出的火焰可达丈许，可熔金化铁

**第三阶段·金须火须子**
- 吞噬地火精华后进阶，体表鳞片转为金色
- 火须温度骤升，可融化中品法器
- 灵智初开，能理解主人指令

**第四阶段·火须王**
- 虫群中诞生王者，通体金白
- 六须化为三昧真火，可焚毁上品灵器
- 生出火翅，可飞行，灵智接近人类

**传说阶段·地火灵蚕**
- 吞噬一缕地火本源后蜕变
- 褪去虫身，化为火焰灵体
- 寿元无尽，与地火同存

## 天赋神通

### 神通一：烈焰喷吐

火须子以火须聚集天地火灵力，压缩后从口器喷出高温火焰。

- 幼生期：喷出尺许火苗，可点燃凡物
- 赤须期：火柱丈许，温度可熔金化铁
- 金须期：火柱三丈，可融化中品法器
- 火须王：喷出三昧真火，火柱所过之处，上品灵器亦会受损

此神通消耗火须子体内火灵力，连续喷吐三次后需休息半个时辰恢复。

### 神通二：火须缠绕

火须子以六根火焰长须缠绕敌人，火须温度极高，可灼烧肉身与法宝。

- 火须缠绕时，敌人如同被六条火蛇紧紧缚住
- 火须可延伸攻击，最远可达三丈
- 被缠绕者不仅承受灼烧，火须还会吸取敌人体内的灵力
- 火须王的真火须缠绕，甚至可灼伤元婴期修士的神魂

此神通对水属性修士效果减半，若敌人修炼了玄冰类功法，火须可能被冻结。

### 神通三：地火共鸣（火须王专有）

火须王可与地脉深处的地火产生共鸣，引动地火之力为己用。

- 在火山或地火脉附近，火须王的实力提升五成
- 可引发小范围的地火喷发，攻击范围覆盖方圆百丈
- 能从地火中快速恢复伤势与灵力
- 冷却时间：引动地火喷发后需休整三日

此神通在远离地火的环境中威力大减，火须王若长期离开地火脉，会逐渐虚弱。

### 神通四：火灵自爆（舍命技）

火须子在面临死亡威胁时，可选择自爆体内全部火精，化为一颗高温火球与敌人同归于尽。

- 自爆威力相当于火须子全力的十倍
- 赤须火须子自爆可重创筑基期修士
- 火须王自爆甚至能威胁到金丹期修士
- 此乃不可逆的舍命之术，使用后火须子必死

## 培养方法

### 喜好食物

火须子以火属性物质为食：

| 食物种类 | 效果 | 推荐度 |
|---------|------|-------|
| 火晶石/火精 | 基础食物，维持生存与成长 | ⭐⭐⭐ |
| 地火熔岩 | 大幅提升进化速度 | ⭐⭐⭐⭐ |
| 火属性灵草（赤阳草等） | 温养火须，增强火焰纯度 | ⭐⭐⭐ |
| 火属性妖兽内丹 | 促进进阶的珍贵食材 | ⭐⭐⭐⭐⭐ |
| 普通草木/灵石 | 不食，喂食无用 | ❌ |

### 栖息环境

- **最佳环境**：地火脉附近、火山口、熔岩洞穴
- **适宜温度**：极热，常温下会进入休眠
- **灵脉要求**：需要火属性灵脉，品阶越高越好
- **巢穴**：以火曜石筑巢，可助火须子温养火须

### 培养要点

1. **温度恒定**：火须子对环境温度极为敏感，温度骤降会导致其休眠甚至死亡
2. **定期喂食**：每月至少喂食一次火精，否则火须会逐渐萎缩
3. **同类共养**：火须子喜群居，单独饲养易抑郁，建议至少饲养三只
4. **水源隔离**：火须子畏水，饲养处需保持干燥，否则火须会熄灭
5. **认主时机**：幼生期最易认主，以精血喂养七日可建立初步羁绊

### 常见误区

- 不可将火须子带至水灵力充沛之地，会导致其火须熄灭、修为倒退
- 不可喂食寒属性材料，轻则火须萎缩，重则爆体而亡
- 火须子进入休眠时不可强行唤醒，否则会造成不可逆的损伤

## 产地/分布

火须子主要分布在地火活动频繁的区域：

- **南荒火域**：最大的火须子栖息地，地下熔岩纵横，火须子群落数以万计
- **炎洲火山群**：数十座活火山组成的区域，火须子品阶普遍较高
- **地火洞窟**：各大宗门炼器阁下方的地火脉中，常有野生火须子出没
- **火焰山**：传说中的火焰山深处，据说栖息着一只万年火须王

## 使用限制

1. **水属性克制**：水属性功法与法器对火须子伤害倍增，玄冰类更是其天敌
2. **环境依赖**：离开火灵力充沛之地，火须子的实力会大幅下降
3. **温度极限**：火须子虽耐高温，但超过其承受极限（如天火、太阳真火）仍会被焚毁
4. **寿命限制**：普通火须子寿元约三百年，火须王可达千年，需珍惜使用
5. **自爆风险**：火须子在极度痛苦或恐惧时可能自爆，主人需时刻关注其状态

## 著名灵宠/典故

### 炎帝的火须

上古时期，神农炎帝曾驯养一只火须王，用于辨识草药的火属性。传说炎帝尝百草时，火须王以火须触碰草药，根据火焰颜色变化判断药性温寒。这只火须王跟随炎帝千年，最终化为一颗火灵珠，至今仍存于炎帝祠中。

### 地火炼器宗的护宗灵虫

地火炼器宗以炼器闻名，其护宗灵虫便是一群火须子。宗门以地火脉为基，饲养了上万只火须子。这些火须子平时协助炼器师控制炉温，战时则化为火海御敌。三千年前，外敌入侵，地火炼器宗的火须王率众引发地火喷发，将来犯之敌尽数焚灭。

### 火须化龙传说

古籍《万虫志》记载，火须王若得机缘吞噬一缕龙气，可进化为"火龙蚕"，拥有龙族之威。然此进化条件极为苛刻，修仙界历史上仅有一例记载——南海曾有一只火须王吞噬了陨落的火龙残魂，化为火龙蚕，纵横南海千年，最终飞升而去。

## 同类对比

### 火须子 vs 火鸦

两者皆为火属性灵宠，但定位不同：

- **攻击方式**：火须子以火须缠绕与喷火为主，攻击灵活多变；火鸦以俯冲与火球攻击为主，爆发力更强
- **环境适应**：火须子依赖地火脉，离开则实力大减；火鸦适应性强，可在任何环境战斗
- **培养成本**：火须子需大量火精，成本较高；火鸦以火属性妖兽肉为食，成本较低
- **灵智**：火须王灵智接近人类，可执行复杂指令；火鸦灵智较低，仅能执行简单命令
- **稀有度**：火鸦较为常见，火须子相对稀有

### 火须子 vs 赤焰狐

- **属性纯度**：火须子为纯粹的火灵之体，火焰威力更纯粹；赤焰狐兼具火与兽性，攻击方式更野蛮
- **战斗风格**：火须子偏向远程火焰攻击与辅助控场；赤焰狐偏向近身肉搏与突袭
- **进化上限**：火须王为五级灵兽，赤焰狐可达六级圣兽
- **饲养难度**：火须子需要特殊的高温环境，饲养难度更高；赤焰狐适应性强，更易饲养

### 火须子 vs 冰蚕

- **属性相克**：冰蚕的冰属性天然克制火须子，两者相遇必有一场恶战
- **战斗方式**：冰蚕以冰丝束缚与寒气攻击为主；火须子以火焰喷吐与火须缠绕为主
- **辅助价值**：冰蚕吐丝可织甲，辅助价值高；火须子可辅助炼器控温，各有千秋
