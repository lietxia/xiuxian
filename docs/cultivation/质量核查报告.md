## 二、问题详解

### 问题 A：内容重复 + AI模板化痕迹（高严重度）

**涉及文件**：`灵根.md`、`体质.md`、`根骨.md`、`悟性.md`

**症状**：
- 这4个文件与 `灵根体系.md`、`体质血脉.md`、`悟性根骨.md` 内容高度重叠
- 4个文件使用**完全相同**的 AI 模板结构：
  ```
  → 定义（一句话）
  → 分类（bullet list + 描述/特点/代表）
  → 测试（"使用特殊的法器，如XX"）
  → 对修仙的影响（5-6条相同句式）
  → 的改变（"洗髓伐毛/夺舍/重生/特殊宝物"）
  → 不同小说中的XX设定（模板标志语句）
  ```
- 文风偏说明文，缺乏修仙韵味，与详细版的半文半白风格不统一

**修复方案**：将4个文件改为**简洁入口页**，保留核心定义+快速分类，详细内容指向对应完整版。

---

**涉及文件**：`realms/佛界境界.md`

**症状**：佛界基础四境的寿元与 `寿命体系.md` 中修真界标准数据不符：

| 境界 | 原值 | 标准值（寿命体系） | 状态 |
|------|------|------------------|------|
| 沙弥 | 120-150年 | 150-200年（炼气期） | ❌ → ✅ 已修正 |
| 沙门 | 200-300年 | 300-500年（筑基期） | ❌ → ✅ 已修正 |
| 比丘 | 500-800年 | 800-1500年（金丹期） | ❌ → ✅ 已修正 |
| 上座 | 1000-2000年 | 1500-3000年（元婴期） | ❌ → ✅ 已修正 |

**修复方案**：统一为 `寿命体系.md` 中的标准寿元数据。

### 问题 D：仙界境界 frontmatter 格式错误（低严重度）

**涉及文件**：`realms/仙界境界.md`

**症状**：description 字段被截断，缺少闭合引号：
```
description: 仙界境界是修仙者飞升仙界后的修炼阶段划分，仙界的修炼与修真界有很大的不同，更加注重对天地规则的感悟和运用。仙界境界的划分通常比修真界更加复杂和严格，修炼的难度也
```

原文在「修炼的难度也」处截断，导致 frontmatter 解析异常。

**修复方案**：补全 description 为完整句子。

### 问题 E：天劫文档间潜在冲突（低严重度）

**涉及文件**：`tribulations/天劫详解.md` vs `tribulations/天劫分类与渡劫机制.md`
