# 灵根

> 本文为**简洁入口版**，仅提供灵根的核心定义与分类概述。完整版（含五行灵根详解、变异灵根、特殊灵根、检测方法、修炼速度对照表等）请参见 **[灵根体系](灵根体系.md)**。

## 核心定义

灵根是修仙者体内与天地灵气相呼应的特殊经脉回路，是吸纳、储存和运转灵气的根本所在。无灵根者无法感应灵气，纵使有再好的功法也无法修炼。

## 快速分类

| 分类方式 | 类型 | 说明 |
|---------|------|------|
| 按数量 | 天灵根（单灵根） | 只有一种五行灵根，修炼最快 |
| 按数量 | 双灵根 | 两种五行灵根，修炼较快 |
| 按数量 | 三灵根 | 三种五行灵根，修炼中等 |
| 按数量 | 四灵根 | 四种五行灵根，修炼较慢 |
| 按数量 | 五灵根（杂灵根） | 五种俱全，修炼最慢 |
| 按属性 | 五行灵根 | 金、木、水、火、土五种基础属性 |
| 按属性 | 异灵根 | 雷、冰、风、暗、光等变异属性 |
| 按属性 | 特殊灵根 | 混沌灵根、超灵根、空间灵根、时间灵根 |

## 灵根与修炼速度

灵根数量越少、纯度越高，修炼速度越快。天灵根修士的修炼速度是五灵根修士的数十倍。
