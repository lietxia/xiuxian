# 常规仙侠境界

> 炼气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫，这是修仙小说最通用的九境体系。本文汇总各境界核心特征，便于快速查阅。

---

## 九境总览

| 境界 | 核心变化 | 灵力形态 | 寿元 | 子阶段 |
|------|---------|---------|------|--------|
| **炼气期** | 引气入体，打通经脉 | 气态 | 150~200岁 | 初期/中期/后期/巅峰/圆满 |
| **筑基期** | 凝气成液，筑造道基 | 液态 | 300~500岁 | 同上 |
| **金丹期** | 真元固化，结成金丹 | 固态 | 800~1500岁 | 同上 |
| **元婴期** | 碎丹成婴，元神出窍 | 元婴态 | 1500~3000岁 | 同上 |
| **化神期** | 元婴化虚，天人感应 | 化虚态 | 5000~8000岁 | 同上 |
| **炼虚期** | 炼化虚妄，掌控法则 | 法则态 | 1~2万岁 | 同上 |
| **合体期** | 形神合一，精气神融 | 合一态 | 2~3万岁 | 同上 |
| **大乘期** | 万法归一，灵力化仙 | 半仙态 | 3~5万岁 | 同上 |
| **渡劫期** | 九重天劫，逆天改命 | 天劫态 | 渡过则飞升 | 无子阶段，按天劫重数划分 |

## 各境详解

### 1. 炼气期

**感应灵气 → 打通经脉 → 洗髓伐骨**

炼气期是修仙的起点。修士通过感应天地间的灵气，将其引入体内，沿经脉运转，最终汇聚于丹田。这一阶段的修士虽然已迈入修仙门槛，但本质上仍是凡人。

- **初期**：感应灵气，打通前三经，体内开始有真气流转
- **中期**：经脉大半贯通，可施展火球术、御风术等低阶法术
- **后期**：丹田气海初成，真气充盈，可驱使低阶法器
- **巅峰**：真气接近液化，经脉扩张到极限
- **圆满**：真气液化临界点，随时可冲击筑基

> **参考写法**：「修士盘膝而坐，双手掐诀，周围的灵气如游丝般从毛孔钻进体内，沿经脉缓缓流淌。每运转一周天，丹田中的真气就壮大一分。」

### 2. 筑基期

**真元化液 → 气海成型 → 奠定道基**

筑基是修仙路上第一次质变。气态真气压缩百倍，凝结成液态真元。筑基成功后，修士可辟谷、御器飞行，寿元大幅延长。

- **初期**：丹田中出现第一滴真元之液，气液共存
- **中期**：真元占比过半，气海成型，可施展中阶法术
- **后期**：真元完全取代真气，气海稳固
- **巅峰**：真元开始自发性凝聚，隐现丹形虚影
- **圆满**：假丹境——真元凝聚成固体丹胚

### 3. 金丹期

**丹纹品质 → 本命法宝 → 法则初触**

金丹品质决定修士的未来上限。金丹按一转至九转划分，转数越高，丹纹越多，潜力越大。

- **初期（一至三转）**：金丹初凝，丹纹模糊，需真火温养
- **中期（四至六转）**：金丹稳固，丹纹清晰，可炼制本命法宝
- **后期（七至九转）**：金丹圆满，丹气外溢，开始触摸法则
- **巅峰**：金丹达到该品级极限，丹气充盈溢出
- **圆满**：丹破婴生的前夜——金丹表面出现自发的细微裂纹

### 4. 元婴期

**破丹成婴 → 元神出窍 → 夺舍重生**

元婴是修士的第二生命。即使肉身被毁，元婴也可以夺舍或重塑肉身，继续修行。

- **初期**：元婴初成，寸许高，如幼童蜷缩在丹田中
- **中期**：元婴生长至尺许，可短暂出窍离体
- **后期**：元婴与本体等大，可自由出窍同时操控多件法宝
- **巅峰**：元婴圆满，一念影响百里天象
- **圆满**：元婴开始「化虚」，与肉身界限模糊

### 5. 化神期

**元婴化虚 → 天地之力 → 领域雏形**

化神期的核心是元婴从实体转为化虚态，与天地灵气产生共鸣，从而可以调用天地之力。

- **初期**：元婴初步虚化，可调用天地之力，领域雏形出现
- **中期**：虚化过半，可短距离瞬移
- **后期**：虚化接近完成，可小范围改变天象
- **巅峰**：神魂虚化九成以上，随时可冲击炼虚
- **圆满**：虚实自如转换，洞天稳固

### 6. 炼虚期

**炼化虚妄 → 掌控法则 → 洞天世界**

化神修士「借」用天地之力，炼虚修士「掌」控天地之力。一字之差，天壤之别。

- **初期**：开始炼化法则虚妄，领域由雏形进化为半成品
- **中期**：领域趋于完善，可在领域中制定简单规则
- **后期**：领域完全成型，洞天世界初步开辟
- **巅峰**：洞天面积扩大，可容纳灵脉和建筑
- **圆满**：洞天稳固如小世界，随时可冲击合体

### 7. 合体期

**形神合一 → 精气神融 → 言出法随**

元婴与肉身不再分离，精气神三者浑然一体。合体期修士举手投足都能引动天地法则，不需要施法动作——意念所至，法则随行。

- **初期**：元婴与肉身初步融合，实力暴涨
- **中期**：融合稳定，可操控玄天之宝
- **后期**：融合圆满，精气神开始「归一」
- **巅峰**：三者融合度超九成，举手投足引动法则
- **圆满**：精气神完美合一，随时可踏入大乘

### 8. 大乘期

**万法归一 → 灵力化仙 → 半步登仙**

大乘期修士已转化为半仙之体，体内灵力正在被仙力取代。他们是凡界的最强存在，通常不会出手——因为力量太强，凡界空间承受不住。

- **初期**：半仙之体初成，灵力开始向仙力转化
- **中期**：转化过半，已具有部分仙人之力
- **后期**：转化接近完成，随时可引动天劫
- **巅峰**：压制修为，选择最佳渡劫时机
- **圆满**：天道感应将至，天劫将在三年内降临

### 9. 渡劫期

**九重天劫 → 心魔考验 → 成则飞升败则道消**

渡劫期不是一个稳定境界，而是修士渡劫到飞升之间的阶段。这一阶段没有子阶段划分，按天劫重数（一九天劫到九九天劫）来区分。

> 天劫完整机制详见 [天劫分类与渡劫机制](../tribulations/天劫分类与渡劫机制.md)

## 各境界突破难点速查

| 突破 | 最大难点 | 常见辅助手段 | 失败代价 |
|------|---------|-------------|---------|
| 炼气→筑基 | 灵气液化，需百倍积累 | 筑基丹 | 经脉受损 |
| 筑基→金丹 | 真元固化，需凝练丹纹 | 凝金丹、灵脉加持 | 跌回筑基初期 |
| 金丹→元婴 | 碎丹成婴，九死一生 | 孕婴丹、聚灵阵 | 金丹碎，修为全废 |
| 元婴→化神 | 心魔劫，道心考验 | 清心丹、前辈护法 | 元婴受损 |
| 化神→炼虚 | 法则炼化，悟性考验 | 悟道茶、法则碎片 | 感悟中断，百年不得寸进 |
| 炼虚→合体 | 形神融合，极其凶险 | 融魂丹、秘法辅助 | 走火入魔 |
| 合体→大乘 | 万法归一，需圆满无瑕 | 天道果、大还丹 | 法则反噬 |
| 大乘→渡劫 | 引动天劫，需充分准备 | 渡劫丹、防御法宝 | 被天道压制 |
| 渡劫→飞升 | 九重天劫，混沌神雷 | 上古防御法宝 | 形神俱灭 |

## 常见小说变异版本

不同修仙小说对九境体系的调整方式：

| 变异方式 | 代表作 | 说明 |
|---------|--------|------|
| 炼气分十三层 | 《凡人修仙传》 | 将炼气细分为十三层，增加前期成长感 |
| 金丹之前加「旋照」 | 《飘渺之旅》 | 增加「旋照、开光、融合」三境 |
| 元婴之后加「出窍、分神」 | 部分古典仙侠 | 将元婴到化神拆分为更多细节境界 |
| 大乘和渡劫合并 | 部分网文 | 将大乘与渡劫视为一体，渡劫成功即大乘 |
| 人界和灵界区分 | 《凡人修仙传》 | 炼气~化神为人界境界，炼虚~大乘为灵界境界 |
