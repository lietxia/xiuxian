# 师徒关系

> 师徒者，修仙之根本也。无师则无传承，无徒则道统断绝。一日为师，终身为父——此非虚言，乃修仙界千百年之铁律。

---

## 一、拜师之制

拜师非儿戏，需讲机缘、看资质、察心性。

### 拜师条件

| 条件 | 要求 |
|------|------|
| 资质 | 至少具备灵根，资质越高越受青睐 |
| 心性 | 品行端正，心性坚韧，非奸恶之徒 |
| 机缘 | 师徒相遇自有天定，强求不得 |
| 诚意 | 真心求道，非为权势利益而来 |

### 拜师五礼

1. **寻师**——访明师，择良徒，双向选择
2. **陈情**——弟子表明心迹，请求收录门墙
3. **考察**——师傅试其心性，或设下考验
4. **拜师**——行叩拜之礼，敬茶献礼
5. **赐号**——师傅赐予道号或法号，正式确立师徒名分

## 二、师徒之义

师徒之道，非单向传授，乃双向义务。

### 师傅之责

- **传道**——倾囊相授功法，不藏私（亦有"留一手"之传统）
- **解惑**——指点修炼迷津，助弟子突破瓶颈
- **护道**——弟子遇险，师傅当出手庇护
- **正身**——以自身言行端正弟子品德

### 弟子之义

- **尊师**——事师如父，不得忤逆
- **勤修**——刻苦修炼，不负师望
- **传承**——将师傅一脉道统发扬光大
- **维护**——维护师门声誉，与师门荣辱与共

---

## 三、师徒类型

### 按亲疏分

| 类型 | 关系 | 说明 |
|------|------|------|
| 亲传弟子 | 最亲密 | 师傅亲自传授，衣钵传人，如父子 |
| 内门弟子 | 较亲密 | 师傅定期指导，可入内门修习 |
| 外门弟子 | 一般 | 仅得基础功法，自行修炼为主 |
| 记名弟子 | 疏远 | 挂名学艺，未正式入门 |

### 按传承方式分

| 方式 | 特点 |
|------|------|
| 单传 | 只收一徒，传承集中，风险极高 |
| 少传 | 收徒数人，择优而教 |
| 多传 | 广收门徒，因材施教 |
| 普传 | 开坛讲道，有教无类 |

## 四、师徒之情

师徒之情，始于传道，久于相处，终成羁绊。

**初期**——弟子敬师傅之能，师傅观弟子之诚。

**中期**——信任日增，师傅因材施教，弟子渐入佳境。

**后期**——情同父子，师傅将平生所学倾囊相授，弟子誓报师恩。

**极致**——师陨弟子披麻，弟子遇难师傅出关。此乃修仙界最令人动容之情。

---

## 五、师徒之忌

### 五大禁忌

1. **欺师灭祖**——弑师叛门，修仙界共诛之
2. **泄露师传**——私传本门功法，废除修为
3. **忤逆师长**——不尊师命，警告或逐出
4. **同门相残**——残害同门，重罚
5. **忘恩负义**——受师大恩而背叛，天理不容

### 师徒冲突

理念不合、资源分配、功法传承之争，皆可能引发师徒冲突。化解之道在于沟通与理解——师傅需放下架子，弟子当恪守本分。若冲突不可调和，可请长老会调解，或弟子自请逐出师门。

## 六、师徒传承

### 功法传承

| 方式 | 说明 |
|------|------|
| 口传心授 | 最核心传承，口诀心法不立文字 |
| 功法秘籍 | 辅助手段，记载招式与修炼法门 |
| 实战演示 | 师傅出手示范，弟子观摩领悟 |
| 心得手札 | 师傅毕生修炼感悟，价值连城 |

### 法宝传承

师傅赐予弟子法宝，既是护身之物，亦是师徒情谊之象征。师傅陨落后，本命法宝通常传于亲传弟子。
