# 宗门制度

> 宗门者，修仙之依凭也。上承天道，下育万修，以功法为根，以传承为脉，以门规为纲。修士独修则孤，聚宗则强，此宗门之所以兴也。

---

## 一、宗门等级

修仙界宗门，以最强者修为、传承年岁、弟子多寡定品，由一品至九品，泾渭分明。

| 品级 | 坐镇境界 | 传承年岁 | 弟子规模 | 势力范围 |
|------|----------|----------|----------|----------|
| 一品 | 渡劫期 | 万年以上 | 数万 | 修真界巨头，话语权极重 |
| 二品 | 大乘期 | 数千年 | 数万 | 顶级势力，称霸一方 |
| 三品 | 合体期 | 数千年 | 数千至万 | 大型势力，区域主导 |
| 四品 | 化神期 | 千年左右 | 数千 | 中大型势力 |
| 五品 | 元婴期 | 千年左右 | 数百至千 | 中型势力 |
| 六品 | 金丹后期 | 数百年 | 数百 | 中小型势力 |
| 七品 | 金丹期 | 数百年 | 数百 | 小型势力 |
| 八品 | 筑基期 | 百年左右 | 数十至百 | 微型势力 |
| 九品 | 筑基期 | 百年以下 | 数十 | 起步阶段，朝不保夕 |

**品级评定要则：** 一品宗门必有渡劫期老祖坐镇，传承万载不绝；九品宗门不过草创，随时有覆灭之危。品级非一成不变——天才崛起可令宗门升格，老祖陨落亦使宗门跌落。

## 二、弟子分级

宗门弟子，以资质定等级，以等级定待遇。资质越好，资源越厚，责任亦越重。

| 等级 | 资质要求 | 资源待遇 | 宗门定位 |
|------|----------|----------|----------|
| 核心弟子 | 天灵根或变异灵根 | 顶级功法、灵脉核心洞府、长老亲授 | 宗门未来掌门或长老候选人 |
| 内门弟子 | 双灵根 | 中阶功法、灵脉洞府、定期指导 | 宗门中坚力量 |
| 外门弟子 | 三灵根 | 基础功法、公共资源、自行修炼 | 宗门基础，量大而质参差 |
| 记名弟子 | 四灵根 | 有限资源、需完成杂务 | 预备弟子，表现优异者可晋升 |
| 杂役弟子 | 五灵根或无灵根 | 仅得温饱、无暇修炼 | 服劳役，维持宗门运转 |

**晋升之途：** 杂役→记名→外门→内门→核心，层层筛选，择优而取。外门大比、宗门试炼、长老举荐，皆为晋升之阶。然修仙界残酷——杂役弟子若三十年未能晋入外门，便只能沦为凡人。

## 三、贡献体系

贡献点乃宗门内部之通货，弟子以劳绩换取修炼资源。

### 获取途径

| 方式 | 说明 | 贡献值 |
|------|------|--------|
| 完成宗门任务 | 采集、猎杀、护送、探索等 | 视任务难度，10-10000点不等 |
| 缴纳灵材宝物 | 以灵石、灵药、矿石等折算 | 由藏宝阁估价 |
| 传授功法心得 | 开坛讲道、撰写心得 | 50-500点 |
| 立下战功 | 宗门战争、抵御外敌 | 100-10000点，重功厚赏 |

### 兑换资源

| 资源 | 消耗贡献点 | 说明 |
|------|-----------|------|
| 功法 | 100-100000点 | 按品阶定价，镇派绝学非贡献可换 |
| 丹药 | 50-5000点 | 培元丹、筑基丹、结丹丹等 |
| 法宝 | 200-20000点 | 法器、灵器、法宝各有定价 |
| 修炼场所 | 10-1000点/次 | 聚灵室、试炼塔、秘境名额 |
| 长老指导 | 100-1000点/次 | 一对一指点，突破瓶颈 |

## 四、门规戒律

门规者，宗门之纲纪也。违者轻则受罚，重则废除修为、逐出宗门。

### 五条基本门规

1. **忠于宗门**——不得背叛，不得勾结外敌
2. **尊重师长**——欺师灭祖者，修仙界共诛之
3. **团结同门**——禁止同门相残，私斗者罚
4. **保守机密**——功法、阵法、情报不得外泄
5. **不得叛宗**——叛宗者废除修为，追杀至死

### 惩戒等级

| 罪行 | 惩罚 |
|------|------|
| 轻微违规（迟到、懈怠） | 警告、罚跪、扣贡献点 |
| 中等违规（私斗、偷盗） | 禁闭、降等、废除部分修为 |
| 严重违规（叛宗、弑师、泄密） | 废除修为、逐出宗门或处死 |

## 五、宗门设施

### 修炼设施

| 设施 | 用途 | 使用条件 |
|------|------|----------|
| 聚灵室 | 灵气浓度十倍于外，闭关突破 | 贡献点兑换 |
| 试炼塔 | 幻阵模拟战斗，磨练实战 | 贡献点兑换 |
| 藏经阁 | 收藏功法典籍，分四层 | 按弟子等级开放对应层 |
| 炼丹房 | 提供地火丹炉，自行炼丹 | 贡献点兑换或租用 |
| 炼器室 | 提供炼器炉、材料加工 | 贡献点兑换或租用 |

### 生活设施

| 设施 | 说明 |
|------|------|
| 弟子居所 | 按等级分配，核心弟子独院，杂役弟子通铺 |

| 疗伤殿 | 受伤弟子可免费或低价治疗 |

## 七、宗门兴衰

宗门非永盛亦非永衰，其兴也勃焉，其亡也忽焉。

**兴盛之因：** 天才降世、机缘降临、传承不绝、管理有方、盟友扶持。

**衰落之因：** 强者陨落、传承断裂、资源枯竭、内斗不止、树敌过多。

> 千年宗门，可因一人之兴而崛起，亦可因一人之陨而崩塌。此乃修仙界之常态。
