# 修仙历法与纪年体系

> 修仙界的时间量级横跨刹那与元会——修士一息之间可感知灵气波动，而天地大劫以数万年为周期。一套统一、自洽的历法体系，是确保世界观不崩溃的基础。

## 一、时间单位体系（规范版）

### 微观时间单位

| 单位 | 换算关系 | 约合现代时间 | 说明 |
|:----:|:--------:|:-----------:|:-----|
| **刹那** | 20念 = 1刹那 | 0.018秒 | 佛教《僧祇律》：一念之间为时间最小感知单位 |
| **念** | — | 0.0009秒 | 心念生灭的最小间隔，仅大乘以上修士可感知 |
| **弹指** | 20刹那 = 1弹指 | 0.36秒 | 修士弹指一次的时间 |
| **息** | 20弹指 = 1息 | 约7.2秒 | 修士一次完整呼吸（一呼一吸）|
| **刻** | 10息 = 1刻 | 约72秒 | 最短的实用计时单位，日常功课以刻为限 |
| **时辰** | 100刻 = 1时辰 | 约2小时 | 十二地支对应十二时辰 |
| **日** | 12时辰 = 1日 | 24小时 | 昼夜一轮回 |

> **写作提示**：斗法中描述"电光石火间"可用刹那（0.018s），打坐入定用"息"描述（一息7.2s），宗门功课以"刻"为计量单位（一刻约72秒）。

### 宏观时间单位

| 单位 | 换算关系 | 约合现代时间 | 含义 |
|:----:|:--------:|:-----------:|:-----|
| **月** | 30日 = 1月 | 30天 | 月相盈亏一周 |
| **年** | 12月 = 360日 | 360天 | 灵气完成一次大循环 |
| **纪** | 360年 = 1纪 | 360年 | 凡间王朝更替的完整周期 |
| **运** | 3纪 = 1运 | 1080年 | 宗门兴衰的标准周期 |
| **会** | 10运 = 1会 | 10800年 | 天地灵气潮汐的小周期 |
| **元** | 12会 = 1元 | 129600年 | 天罡地煞之数，从末法到灵气复苏的完整循环 |
| **劫** | 不定长 | 视天地大劫间隔而定 | 非固定时间单位，指两次天地大劫之间的间隔 |

### 换算速查

```
1日 = 12时辰 = 1200刻 = 12000息 = 240000弹指 = 4800000刹那
1年 = 360日
1纪 = 360年
1运 = 3纪 = 1080年
1会 = 10运 = 30纪 = 10800年
1元 = 12会 = 120运 = 360纪 = 129600年
```

> **关键设计决策**：本体系将「纪」定义为360年（与太阳系公转周期对齐），而非某些设定中的100年。这样保证了：1运=3纪=1080年、1会=30纪=10800年、1元=360纪=129600年的整数递增，数学自洽。

## 二、当前纪年

**修真纪年**：第五十三元·第三会·第三运·第三十七纪·第三年

换算：53 × 129600 + 3 × 10800 + 3 × 1080 + 37 × 360 + 3 = 约687万年

即当前距离天道定元已过去约七百万元年。

## 三、纪年体系对照

修仙界存在多种纪年方式，适用于不同场景。写作时可根据叙事视角选择：

| 纪年法 | 格式示例 | 适用范围 | 特点 |
|--------|---------|---------|------|
| **修真纪年** | 第五十三元第三会第三运 | 藏经阁典籍、天道文书 | 最权威，连续性强 |
| **王朝纪年** | 大周·永昌历·丙午年 | 凡间界、修真界底层 | 不够连续，换朝重置 |
| **甲子纪年** | 今古纪元第360甲子·丙午年 | 金丹期以上修士通用 | 六十甲子一轮回，不受王朝更替影响 |
| **宗门纪年** | 太虚历·一万八千零二十一年 | 宗门内部藏书 | 各宗不同，换算繁琐 |
| **天道纪元** | 今古纪元·丙午年 | 通史、飞升总结 | 以大事件为分界 |

### 甲子纪年与灵气属性

六十甲子每一组合对应灵气属性偏向：

| 甲子组合 | 主导属性 | 影响 |
|---------|---------|------|
| 甲子年 | 木气主导 | 木系修士大运之年 |
| 丙午年 | 火气主导 | 天劫威力增加 |
| 庚申年 | 金气主导 | 剑修昌盛之年 |
| 壬子年 | 水气主导 | 妖修活跃之年 |

## 四、灵气潮汐（修炼节律）

灵气浓度呈多周期叠加波动，是安排修炼日程的基础：

### 日内潮汐

| 时辰 | 时间段 | 灵气特征 | 最佳修炼 |
|:----:|:------:|:---------|:---------|
| 子时 | 23:00-01:00 | 阴气最盛 | 水属性功法、鬼修 |
| 寅卯时 | 03:00-07:00 | 阳气上升，木气萌发 | 吸纳紫气东来，剑修晨练 |
| 午时 | 11:00-13:00 | 阳气鼎盛 | 阳属性功法、雷法 |
| 酉时 | 17:00-19:00 | 金气最盛 | 剑修、法宝祭炼 |

### 月相潮汐

| 月相 | 时间 | 影响 |
|:----:|:----:|:------|
| 朔日（初一） | 新月 | 灵气混乱含生机，宜炼器布阵 |
| 望日（十五） | 满月 | 月华最强，妖修效率+100%，宜突破 |
| 晦日（廿九/三十） | 无月 | 阴气最重暗藏杀机，魔修战力巅峰 |

### 年度潮汐

- **春分**：木气极盛，木系功法修炼效率+80%
- **夏至**：阳气巅峰，阳极生阴，火系修士突破良机
- **秋分**：金气极盛，剑修最佳修炼日
- **冬至**：阴气巅峰，阴极生阳，鬼修一年中最重要修炼日

> **渡劫择时**：选择与自身功法属性相克的节气渡劫，可提升成功率。例如火属性功法修士选大寒渡劫，借助天地寒气抵消火劫威力。

## 五、各界时间流速

| 界域 | 与凡人界时间比 | 说明 |
|:----:|:-------------:|:------|
| 凡人界 | 1:1 | 基准锚点 |
