# 时辰与节气修炼

> 天地灵气并非均匀分布——子时阴气最盛，午时阳气最旺；春分木气生发，秋分金气肃杀。对时辰和节气的把握，是区分「会修炼」和「不会修炼」的第一道分水岭。

> 📌 完整历法体系请见[修仙历法](修仙历法.md)，本文聚焦「时间属性与修炼」这一核心应用。

---

## 一、十二时辰的灵气属性

修仙界的灵气并非一整天的属性都一样——随着太阳和月亮的运行，天地间的五行灵气分布会周期性变化。

| 寅时 | 03:00~05:00 | 阴阳交替，木气萌发 | 木属性修炼效率+40% | 木系功法、灵植培育 |
| 卯时 | 05:00~07:00 | 日出阳升，木气旺盛 | 木属性修炼效率+60% | 吸纳紫气东来、剑修晨练 |

## 二、二十四节气与修炼契机

### 节气对不同功法的影响

| 节气 | 能量特征 | 最适合的修炼 | 注意 |
|------|---------|------------|------|
| **立春** | 木气生发 | 木系功法、灵植师 | 此时种植灵草成活率最高 |
| **春分** | 阴阳平衡，木气极盛 | 木系功法、平衡阴阳类功法 | 突破瓶颈的好时机 |
| **清明** | 天地清朗，阴气微现 | 鬼修、观想类功法 | 阴气开始活跃，鬼修效果倍增 |
| **谷雨** | 水气充沛 | 水系功法、炼丹（水炼法） | 适合炼制水系丹药 |
| **立夏** | 火气初现 | 火系功法 | 可以开始准备渡雷劫（雷属火） |
| **夏至** | 阳气至盛，阳极生阴 | 火系功法、阳属性功法 | 但要注意「阳极生阴」——此时魔修可能借助极阳中的一点真阴修炼 |
| **小暑/大暑** | 火气鼎盛，土气次之 | 炼器（火焰最旺）、体修 | 最适合肉身淬炼的季节 |
| **立秋** | 金气初生 | 金属性功法、剑修 | 剑修最喜欢的季节 |
| **秋分** | 金气极盛 | 剑修、金属性功法、炼制杀伐法宝 | 一年中最适合炼制攻击类法宝的时机 |
| **霜降** | 金气带寒 | 冰属性功法、寒属性法宝 | 冰属性修士的狂欢 |
| **立冬** | 水气生发 | 水系功法 | 水系修士进入修炼旺季 |
| **冬至** | 阴气至盛，阴极生阳 | 冰属性功法、鬼修、阴属性功法 | 鬼修一年中最重要的修炼日 |
| **小寒/大寒** | 阴寒之气笼罩 | 冰属性功法、炼器淬火 | 淬火效果最佳的时机 |

### 节气对渡劫的影响

渡劫选择一个「对的」节气，成功率能提升一成以上：

| 天劫属性 | 最佳渡劫节气 | 原因 |
|---------|------------|------|
| 火属性雷劫 | 大寒 | 天地寒气可抵消部分火劫威力 |
| 水属性雷劫 | 大暑 | 阳气最盛时，水劫威力减弱 |
| 金属性雷劫 | 立春 | 金被木泄，以木气泄金气 |
| 木属性雷劫 | 立秋 | 金克木，以金气压制木劫 |
| 土属性雷劫 | 清明 | 土气被木气疏泄 |
| 心魔劫 | 春分/秋分 | 阴阳平衡时，心魔最弱 |

## 三、月相与修炼

月亮的圆缺变化同样影响修炼——尤其是对妖修、鬼修和某些特殊功法。

| 月相 | 出现时间 | 对修炼的影响 |
|------|---------|-------------|
| 新月 | 每月初一 | 阴气初生，适合鬼修开始新周期的修炼 |
| 上弦月 | 初七~初八 | 阴阳各半，适合正常修炼 |
| 满月 | 十五 | 月华之力最强，妖修修炼效率+100%，鬼修实力巅峰 |
| 下弦月 | 廿二~廿三 | 阴阳各半，适合炼丹制符 |
| 晦日 | 廿九~三十 | 阴气最重但暗藏杀机，魔修在此日战力最强 |

**月华修炼法**（妖修专用）：
妖修在满月之夜面向月亮吐纳，吸收月华之力，可以加速妖丹凝聚。满月一夜的修炼效果，相当于平时修炼三十天。

## 四、特殊时间节点

### 灵气潮汐

修仙界的灵气浓度并非恒定不变，而是呈周期性波动：

| 周期 | 持续时间 | 灵气浓度变化 | 影响 |
|------|---------|------------|------|
| 每日潮汐 | 24小时 | ±10% | 子时和午时是灵气浓度的两个峰值 |
| 每月潮汐 | 30天 | ±20% | 满月夜灵气浓度最高 |
| 每年潮汐 | 360天 | ±30% | 灵气在夏至和冬至达到年度峰值 |
| 元会潮汐 | 129600年 | ±200% | 灵气潮汐的大周期，影响整个时代的修炼难度 |

### 甲子纪年

修仙界最常见的纪年方式是甲子纪年——六十甲子一轮回，分别对应不同的天干地支组合。天干决定修士在这一年的气运走向，地支决定这一年的灵气属性侧重。

- **甲子年**：木气主导，木系修士大运之年
- **丙午年**：火气主导，天劫威力增加（每年雷修的噩梦）
- **庚申年**：金气主导，剑修昌盛之年
- **壬子年**：水气主导，妖修活跃之年

| 界域 | 与凡人界的时间比 | 说明 |
|------|----------------|------|
| 凡人界 | 1:1 | 基准时间流速 |
| 修真界 | 1:1~1:2 | 灵脉核心区域时间流速可能不同 |
| 仙界 | 约1:10 | 天上一天，人间十年（部分设定） |
| 魔界 | 约1:0.5 | 魔界时间比凡人界慢 |
| 冥界 | 无固定 | 冥界几乎没有时间概念 |
| 小世界/洞天 | 1:0.1~10 | 由开辟者的实力决定流速比例 |
