# 修仙纪年与历史分期

> 时间单位换算和基础历法请见[修仙历法](修仙历法.md)——本文不再重复单位换算，聚焦「如何用纪年体系构建历史感」。

---

## 一、不同量级下的历史观

纪年方式的选择本质上是**叙事视角**的选择：

| 视角 | 时间单位 | 历史感 | 适合的叙事 |
|:----:|:--------:|:-------|:-----------|
| **凡人** | 年 | 一生不过百年 | 街头巷尾的小人物故事 |
| **低阶修士** | 纪（360年） | 一次闭关就是一纪 | 宗门内部的恩怨情仇 |
| **高阶修士** | 运/会 | 见证王朝兴衰 | 界域之间的大博弈 |
| **天地** | 元 | 一元复始，万象更新 | 神话史诗、宇宙尺度叙事 |

> **写作建议**：不要让金丹期修士的行为尺度停留在"天"——金丹寿元五百年，他考虑事情应该以"年"和"纪"为单位。角色的时间观要与修为匹配。

## 二、常见的纪年体系设计

### 2.1 王朝纪年法

**格式**：大周·永昌历·丙午年

以当朝皇帝年号纪年，王朝更替时重置。缺点是历史连续性差，优点是接地气。

使用人群：凡人、底层修士、民间坊市。

### 2.2 甲子纪年法

**格式**：丙午年（第360甲子）

六十甲子一轮回，连续性强，不受王朝更替影响。每个甲子的天干地支组合预示该年灵气属性偏向。

使用人群：金丹期以上修士、各大宗门正式文书。

### 2.3 宗门纪年法

**格式**：太虚历·一万八千零二十一年

以宗门创立为元年。每个大宗门都有自己的一套，换算极为繁琐，但内部凝聚力强。

> **写作妙用**：可以利用两宗纪年差异制造冲突——A宗说"三百年前"的事件，B宗的纪年里可能压根不存在这个年份。

### 2.4 天道纪年法

**格式**：今古纪元·丙午年

以大事件为纪元分界，是修仙界最宏大的纪年方式。常见纪元划分如下：

| 纪元 | 持续时间 | 标志事件 |
|:----:|:--------:|:---------|
| 混沌纪元 | 不可考 | 天地初开，万物混沌 |
| 上古纪元 | 百万元会 | 神魔并立，第一批生灵诞生 |
| 远古纪元 | 十万元会 | 人族崛起，修真体系成型 |
| 中古纪元 | 万元会 | 宗门林立，正魔分化 |
| 近古纪元 | 千元会 | 末法时代，灵气衰退 |
| 今古纪元 | 至今 | 灵气复苏，新的修仙时代 |

## 三、历史分期模型：灵气循环论

修仙界的历史不是线性发展的，而是随灵气浓度呈周期波动：

### 黄金 → 白银 → 青铜 → 末法 → 复苏

| 时代 | 灵气浓度 | 修士水平 | 社会特征 | 叙事潜力 |
|:----:|:--------:|:---------|:---------|:---------|
| **黄金时代** | 极高（凡人也能吸收） | 金丹满地，元婴不如狗 | 大能遍地，资源充足 | 上古秘闻、失落传承 |
| **白银时代** | 中等（需功法才能吸收） | 元婴为顶层，金丹中层 | 格局稳定，宗门垄断 | 门派政治、权力博弈 |
| **青铜时代** | 较低 | 筑基中层，金丹罕见 | 传承断裂，正魔对立 | 末世求生、道统守护 |
| **末法时代** | 极低 | 炼气艰难，筑基传说 | 修仙文明衰退 | 最绝望的暗夜 |
| **灵气复苏** | 从低谷回升 | 突破速度加快 | 新秩序建立 | **最适合开篇的时代** |

### 为什么推荐「灵气复苏」作为开篇设定？

1. **解释主角的快速成长**：灵气浓度在上涨，修炼效率天然高于前辈
2. **冲突自然产生**：旧势力垄断资源，新力量挑战秩序
3. **世界有探索空间**：末法时代封闭的秘境陆续开启，剧情触发点密集
4. **设定留有余地**：灵气继续复苏会产生什么？——为后续换地图保留空间

## 四、年表设计方法论

### 4.1 基本原则

1. **间隔合理**：金丹寿元约千年，重大事件的间隔至少在一个金丹寿元以上，主角才会感到"这发生在很久以前"
2. **传承链不断**：元婴寿元约三千年，最近三次大事件应有元婴老怪作为"活历史"
3. **有意留白**：几百年甚至上千年的空白期很正常——可能什么也没发生，只是在积累
4. **挂钩灵气周期**：灵气涨，修仙文明兴；灵气落，修仙文明衰——大事件应与灵气周期匹配

### 4.2 年表模板

| 距今年数 | 事件 | 所属时代 | 备注 |
|:--------:|:-----|:--------:|:-----|
| 100万+ | 混沌初开 | 神话时代 | 不可考 |
| 50万 | 第一批先天神魔诞生 | 上古 | 信息极少 |
| 10万 | 人族出现，灵智初开 | 远古 | 模糊传说 |
| 5万 | 第一位人族修士出现 | 远古末 | 修真起点 |
| 1万 | 正道三大宗门建立 | 中古 | 有典籍记载 |
| 8000 | 第一次正魔大战（持续3000年） | 中古 | 宗门记录完整 |
| 5000 | 魔道六宗成立 | 中古末 | 格局奠定 |
| 3000 | 末法时代开端 | 近古 | 灵气开始衰退 |
| 1000 | 末法最深处·筑基已成传说 | 近古 | 修仙文明最低谷 |
| 500 | 灵气复苏开始 | 今古 | **故事最好的起点** |
| 0 | **故事开始** | 今古 | — |

## 五、写作避坑指南

| 常见错误 | 为什么是坑 | 正确做法 |
|---------|-----------|---------|
| 让低阶修士参与万年前的秘密 | 寿元对不上，除非有轮回/转世设定 | 万年尺度的事件只由化神以上或特殊存在参与 |
| 所有历史事件间隔太短 | 世界缺乏沧桑感，像发生在同一年 | 合理使用「纪」和「会」来拉开间距 |
| 年表塞得太满 | 每一年都有大事，世界显得很累 | 留白，一段平淡期反而让大战更珍贵 |
| 灵气与历史脱节 | 设定变成两张皮 | 每个大时代都对应灵气浓度变化 |
| 忽略不同势力的纪年差异 | 整个世界用一个日历 | 合理利用纪年差异制造冲突 |

---

> *纪年不只是为了知道「今年是哪一年」——不同的纪年方式反映了不同的历史观。仙界用「元会」计数，说明他们的时间感与凡人截然不同。选择哪一种纪年，本身就是一种设定宣言。*
