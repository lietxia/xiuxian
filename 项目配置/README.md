## 简介

林夜，一个普普通通的现代社畜，一觉醒来穿越到了正魔不两立的修仙界，还成了魔道巨头的少主。

手底下的小魔头们整天喊打喊杀要跟正道开战，正道那边也摩拳擦掌要除魔卫道。作为魔道少主，他夹在中间左右为难——真要打起来，他是冲呢还是跑呢？

幸好，这个时候他觉醒了**神级手机制造系统**：

- ✅ 能批量制造智能手机
- ✅ 每台手机预装抖音修仙版
- ✅ 用户在App内消费，他获得返利

于是林夜悟了——只要让修仙界都沉迷手机，就没人有空修炼，没人修炼就不会打仗，不打仗他就安全了。还能赚钱，简直一举两得！

林夜推出来第一款App——**抖音修仙版**。

自这一天开始，修仙界彻底变天了。

- 魔门妖女换上JK和嗨丝大跳擦边舞，一场直播赚取数万灵石
- 宗门弟子沉迷番茄小说无法自拔，一看一整晚，修为日渐倒退
- 炼器宗飞剑滞销，宗主泪洒直播间，含泪3折大甩卖
- 大乘尊者王者连败，一气之下线下单杀队友
- 女帝沉迷电视剧，无心上朝
- 番茄金番作者的真实身份竟然是圣地老祖

当隐世圣地的老祖出关，看到自家天才弟子整天抱着手机刷擦边视频——

"毁了，全毁了！我的圣地被抖音给毁了！"

而这一切，才只是开始……
