## 1. 项目全景

**一句话**：现代社畜穿越成魔道少主，激活手机制造系统，用抖音让整个修仙界玩物丧志——但手机能腐蚀人心，也腐蚀了自己人。

| 项目 | 说明 |
|------|------|
| 主角 | 无名现代人 → 魔道少主，普通人，略懂互联网 |
| 金手指 | 手机制造系统——批量生产智能手机，自带App预装 |
| 核心矛盾 | 手机腐蚀正道，也腐蚀魔道；系统越成功，自己人越堕落 |
| 智斗逻辑 | 娱乐降维打击：信息战、舆论战、注意力争夺、消费主义碾压 |
| 世界线 | 正魔对立修仙界，因手机介入全面崩坏（或升级？） |

## 2. 核心理念与原则（优先级排序）

1. **角色真实 > 情节推进**——老祖不会突然变傻，圣女不会无缘无故沉迷
2. **系统逻辑 > 随意发挥**——手机能做什么不能做什么，有清晰边界
3. **展示 > 叙述**——"她刷了三个时辰抖音，眼睛比看到仙器还亮"而非"她很沉迷"
4. **简练 > 华丽**——短句驱动节奏，修仙术语点缀即可
5. **冲突驱动 > 平铺直叙**——每个场景必须有"But/Therefore"而非"And Then"

**Canon Hierarchy**（矛盾时谁胜出）：
`世界规则 > 系统设定 > 角色设定 > 情节大纲 > 风格偏好`

## 3. 工作流程

### 阶段1：规划
1. 检查 `01_设定/核心设定/连续性台账.md` → 确认角色当前状态
2. 审查前场景摘要 → 锚定"谁、在哪、刚发生什么"
3. 创建场景简报（只含本场景角色+动机+冲突+钩子）

### 阶段2：写作
1. 加载本场景角色档案（`01_设定/人物/角色圣经.md`）
2. 加载 `01_设定/核心设定/世界规则台账.md` 相关规则
3. 生成初稿 → 逐段风格自检

### 阶段3：验证
1. 角色一致性：台词是否符合声音指纹？行为是否符合弧线阶段？
2. 时间线：角色是否拥有不应知的信息？
3. 系统一致：手机功能是否超出现有科技树？
4. 更新连续性台账：角色状态+资源变化+新伏笔

## 4. 写作风格与质量标准

### 展示 vs 叙述（本项目实例）

| ❌ 叙述 | ✅ 展示 |
|---------|---------|
| 魔主很震惊 | 魔主盯着屏幕里跳舞的女修，手里的茶杯悬在半空，忘了放下 |
| 老祖很愤怒 | 老祖的胡子抖了三抖，指尖雷光噼啪作响，半天憋出一句"此...此物..." |
| 圣女很沉迷 | 圣女倚在软榻上，手机蓝光映着脸，窗外的掌门召令已经响了五遍 |
| 某修士刷上瘾 | 他的手指机械地向上划，灵石一颗颗自动扣款，洞府已三天没打扫 |

### 词汇黑名单

| 类别 | 禁用词 |
|------|--------|
| AI废词 | 总而言之、不可否认、值得注意的是、不禁、竟然、仿佛、似乎 |
| 过滤动词 | 感到、意识到、注意到、发现（改用动作呈现） |
| 现代穿越（对话中） | OK、没问题、老板、战略（用"筹策""方略"）、系统（主角内心OS除外） |
| 陈词滥调 | 心跳加速、倒吸凉气、瞳孔骤缩、一股暖流涌上心头 |

### 核心场景类型

| 场景类型 | 特点 | 例子 |
|---------|------|------|
| 手机发布 | 震惊+真香循环 | 第一次卖手机、新功能上线 |
| 抖音入侵 | 娱乐腐蚀 | 魔门妖女直播、圣地弟子刷视频 |
| 舆论战 | 网暴/公关 | 正道声讨、魔道洗白、直播PK |
| 消费主义 | 带货/氪金 | 丹药直播带货、灵石打赏、剁手党 |
| 产业革命 | 修仙界经济重塑 | 手机产业链、网红经济、物流体系 |

## 5. 连续性系统

### 四层记忆架构
```
L1 设定文档（持久源真相）→ 角色圣经+世界规则台账+大纲
L2 连续性台账（每章更新）→ 角色状态+资源+伏笔，200-500词
L3 场景简报（单次使用）→ 只含本场景信息，防剧情溢出
L4 定期审计（每卷一次）→ 全卷一致性+时间线+未兑现承诺
```

## 6. 边界与禁令

### ✅ 始终做
- 每次写作前检查连续性台账
- 每场景写完更新角色状态
- 每场景必须有冲突和变化
- 对话必须匹配角色声音指纹
- 手机出现时先写"拿到手机"的反应

### ⚠️ 先问人类
- 修改已确立的世界规则
- 偏离大纲的情节走向
- 引入大纲未提及的新角色
- 手机系统增加新功能

### 🚫 绝不做
- 使用AI废词和过滤动词
- 角色透露其不应知的信息（未来剧透）
- 现代概念在对话中穿越（主角内心OS除外）
- 降智对手——圣地老祖/正道魁首永远智商在线
- 让手机解决人心问题——手机只能腐蚀，不能建设
- 系统中的科技超出当前手机能力（摄像头、5G等要有清晰边界）

## 8. 质量门

### 场景级（每场景写完必检）
- [ ] 本场景有冲突+变化+悬念（缺一重写）
- [ ] 所有台词符合角色声音指纹
- [ ] 无AI废词/过滤动词/现代穿越词
- [ ] 角色未透露不应知信息
- [ ] 连续性台账已更新

### 章节级（每章完成必检）
- [ ] 章节推进了至少一条主线（手机入侵/舆论战/消费主义）
- [ ] 角色弧线有可感知的变化
- [ ] 手机能力符合同级设定
- [ ] 有"手机改变修仙界"的新发现或新玩法
