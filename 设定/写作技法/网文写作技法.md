## 一、网文常见致命错误

### 1.1 新手最常犯的20个错误

| # | 错误 | 破解方法 |
|---|------|---------|
| 1 | 完美主义 | 接受"烂初稿"，先完成再完美 |
| 2 | 无大纲写作 | 15分钟极简提纲，明确每章冲突和钩子 |
| 3 | 开头没冲突 | 第一段必须有事故 |
| 4 | 信息倾倒(Info Dump) | 用场景和冲突透出信息 |
| 5 | 节奏太均匀 | 张弛有度，紧张段短句，平静段正常 |
| 6 | 对话不推进剧情 | 每句台词至少完成一个任务 |
| 7 | 角色说话都一样 | 建立每个角色的"语言档案" |
| 8 | 章末无钩子 | 最后三行必须制造悬念/反转/情绪炸弹 |
| 9 | 无视读者期待 | 每章至少1个小爽点，每3-5章1个中爽点 |
| 10 | 过度修饰 | "说人话"，用具体名词和强动词 |
| 11 | 开头三章浪费 | 签约编辑只看前500字决定生死 |
| 12 | 伪冲突 | 让主角面临不可逆的损失 |
| 13 | 角色降智 | 反派必须有自洽的利益逻辑 |
| 14 | 上帝式便利 | 底牌必须提前埋伏笔 |
| 15 | 连续打脸疲劳 | 交替不同爽点类型 |
| 16 | 长线伏笔不碰 | 中间每20-30章"碰一下"那条伏笔 |
| 17 | 对话过于直白 | 潜台词比台词重要 |
| 18 | 过滤动词 | "他感到/意识到/注意到"→直接写感受本身 |
| 19 | And叙事 | 改为But/Therefore叙事（ABT模型） |
| 20 | 闭门造车 | 找写作伙伴互评 |

### 1.2 AI写作的24种可识别模式

**语言模式（最致命）**：
- "此外、至关重要、深入探讨、不仅…而且…"
- 否定式排比"不是……而是……"
- 三段式法则（强行分三组）
- 刻意换词（同义词循环）

**格式模式**：
- 破折号过度使用
- 粗体过度使用
- 每段长度过于均匀（150-200字）
- 句子长度过于均匀（15-25字）

**交互模式**：
- 填充短语："值得注意的是""不难发现"
- 过度限定："可能""或许""某种程度上"
- 通用积极结论

### 1.3 去AI味5法

1. **反向人设法**：让AI扮演特定角色润色
2. **翻译打乱法**：中→英→日→中
3. **标点混乱法**：故意混用全角半角
4. **句式打乱术**："首先…其次…最后"→"所以……另外……对了……"
5. **风格锚定法**：喂给AI自己写的3-5篇样本

### 1.4 过滤动词替换

| 过滤动词 | 替代方案 |
|---------|---------|
| 他感到…… | "寒意爬上脊背" |
| 他意识到…… | "门没锁。" |
| 他注意到…… | "窗台上有一排脚印" |
| 他看见…… | "墙上刻着一行字" |
| 他听到…… | "远处传来一声尖叫" |

## 二、节奏控制

### 2.1 三阶爽点体系

| 级别 | 频率 | 示例 |
|------|------|------|
| 小爽点 | 每章至少1个 | 一句拍手叫好的话、路人甲的惊讶 |
| 中爽点 | 每3-5章1个 | 完整打脸、实力跃升、谜题揭晓 |
| 大爽点 | 每卷高潮1个 | Boss战逆转、多重伏笔同时回收 |

### 2.2 章末悬念7种类型

| 类型 | 写法 | 适用 |
|------|------|------|
| 悬念式 | "门外传来一个不可能出现的声音" | 通用 |
| 反转式 | 整章暗示A是凶手，最后一行发现B的手上有血 | 悬疑 |
| 情绪炸弹式 | 积蓄3章的矛盾章末爆发 | 情感 |
| 信息投放式 | 章末扔出重磅信息 | 解谜 |
| 断章取义式 | 秘密揭晓前直接截断 | 秘密 |
| 危机降临式 | 主角突然遭遇生命威胁 | 战斗 |
| 情绪反转型 | 顺利局面突然崩塌 | 权谋 |

### 2.3 经典节奏模板

**起承转爽（最通用）**：
1. 起（500字）——回顾+引出冲突
2. 承（800字）——冲突升级
3. 转（300字）——出现转折
4. 爽（400字）——主角反击+钩子

**铺垫管理铁律**：
- 铺垫最长不超过2章
- 如需5章铺垫，中间穿插小爽点
- 压抑不超过2章，否则弃文

### 2.4 种田文/基建文节奏

- **核心爽感**：从无到有
- 每10章设一个"阶段性成果展示"
- 马斯洛需求层次驱动：生理→安全→社交→尊重→自我实现

## 三、角色塑造

### 3.1 三种可被读者爱上的弱点

1. **可成长的弱点**（胆小→勇敢）
2. **有代价的弱点**（为某样东西牺牲另一样）
3. **与金手指配对的弱点**（无敌金手指配一个无法弥补的短板）

### 3.2 对手POV正确使用

- 制造信息差时切换
- 塑造反派厚度时切换
- **不切到对手正在策划的阴谋**——破坏悬念
- 用"有限的对手视角"——只展示特定场景下的所思所想

### 3.3 反派魅力学

1. 自洽的利益逻辑
2. 可理解的动机
3. 实力对等甚至压制
4. 偶尔的"人性闪光"

### 3.4 角色弧线

- **每章必须有可感知的变化**
- 微观变化→中期里程碑（10-15章）→宏观弧线（3-5大转折点）

## 四、对话写作

### 4.1 对话句≤15字/句

| 节奏类型 | 特征 | 适用场景 |
|---------|------|---------|
| 快节奏 | 短句，无对话标签 | 冲突、争吵 |
| 慢节奏 | 长句，频繁动作插入 | 亲密、回忆 |

### 4.2 每句台词至少完成一个任务

1. 推进剧情
2. 展示性格
3. 传递信息

### 4.3 古代背景文白比例

**70%白话 + 20%文言词汇 + 10%典故化用 = 最佳"古韵感"**

### 4.4 语言指纹设计

- 句式偏好、比喻体系、词汇边界、口头禅
- **实测**：配上语言档案后，对话辨识度从30%提升到65%

## 五、智斗写法

### 5.1 五种经典智斗模式

1. **信息差博弈**：主角知道对手不知道的
2. **资源博弈**：用有限资源打无限仗
3. **人心博弈**：操控对手心理预期
4. **制度博弈**：用规则改写游戏
5. **时间博弈**：在时间窗口内完成目标

### 5.2 智斗核心原则

- **所有反转必须有前文伏笔**
- **对手必须聪明**（越聪明打脸越爽）
- **绝境必须真绝**（读者一看就有退路的"绝境"，破局时没有惊喜感）
- **底牌必须提前埋**

### 5.3 伏笔回收节奏

| 伏笔类型 | 埋设距离 |
|---------|---------|
| 小型 | 3-10章内回收 |
| 中型 | 一卷内回收 |
| 大型 | 50万字以上 |
| 终极 | 贯穿全书 |

### 5.4 弱者翻盘公式

**弱势主角 × 特定优势 × 对手的特定盲点 × 付出代价 = 合理的胜利**

"三小胜一大挫"法则：三次小提升后安排一个看似无法逾越的瓶颈

### 5.5 钩子强度公式

**钩子强度 = 信息缺口 × 情感投入 × 紧迫程度**

## 六、历史架空小说特殊技巧

### 6.1 三层考据体系

1. **第一层：核心史料**——以信史搭建叙事脉络
2. **第二层：学术成果**——融入史学研究，填充骨血
3. **第三层：生活细节**——还原衣食住行，增添魂魄

### 6.2 蝴蝶效应推演步骤

1. 确定改变点
2. 直接后果
3. 连锁反应（第二层、第三层效应）
4. 系统纠偏（原有历史系统如何"反抗"）
5. 新平衡

**三个限制原则**：
- 时间限制（改变越晚，蝴蝶效应范围越小）
- 地理限制（偏远地区影响力小于政治中心）
- 结构限制（制度惯性远大于个人变化）

### 6.3 已知结局如何制造悬念

| 层次 | 类型 | 案例 |
|------|------|------|
| 第一层 | 事件悬念（"怎么发生的？"） | "这次能避免悲剧吗？" |
| 第二层 | 身份悬念（"这个人是谁？"） | "穿越者何时暴露？" |
| 第三层 | 动机悬念（"为什么这么做？"） | "改变历史的真正目的？" |

### 6.4 历史人物文学化重塑四条边界

1. **基本评价不变**——大事不含糊
2. **多面性展现**——小事可灵活
3. **不刻意翻案**——避免为吸引眼球而颠覆
4. **价值判断明确**——善恶是非要有基本态度
